# 物联网平台投融资风向在这里 ：《中国物联网平台产业市场研究报告（2020版）》发布-报告

- 公众号：万联网
- 栏目：万联网-观察
- 日期：2020-06-02
- 来源：
- 作者：
- 原文：https://info.10000link.com/newsdetail.aspx?doc=2020060290008

---

近日，万联网记者发现，中国物联网产业应用联盟、深圳市物联网产业协会联合物联传媒发布了《中国物联网平台产业市场研究报告（2020版）》。



 




 报告指出，智慧生活和工业互联网是物联网平台最为典型的两类应用，其产生的投融资事件最能体现行业风向变化。其中，在智慧生活场景方面，物联网平台产业在2019年及以后产生的融资事件逐渐减少，企业转而更强调业务的持续开发与积累；在工业互联网场景上，行业整体的创业和投资热情并未消减，抓住细分市场深耕或者具有清晰商业模式的企业被资本选中的机会反而增大。



 




 从内容上看，报告调研了工业、能源、地产、社区、园区、家居、物联网安全等多领域的典型平台企业，并对企业的战略演变、产品方向、商业模式和标杆案例等内容进行了研究。 



 




 IoT Analytics 调研发现，2019 年全球物联网平台数量有 620 家，整体数量不降反升，呈现出产业向好的重要趋势特点。而从企业属性来看，进入物联网平台产业的企业主要有5种类型，分别为云服务提供商，电信运营商、虚拟运营商、通信设备厂商，面向企业应用的软件系统服务商，垂直领域的传统企业，初创企业。这5类企业构建了物联网行业的基本产业图景。



 




 在发展潜能上，目前，很多企业看好物联网平台的未来发展，总体上可以从两个方面看出： 



 




 一、物联网平台市场空间大。其整体的价值链由终端、网络、平台和应用服务四大部分组成，业内预估其价值比例分配为 30:10:20:40，这意味着在未来迅速增长的物联网市场中，连接的价值依然是最低的，应用服务中透露的数据价值依然是最高的。而实现这从低价值到高价值的跃升，就是物联网发展的潜能所在。



 




 二、越往后平台带来的利润和价值将越高。对物联网企业来说，即使最初投入的开发成本很高，但是随着用户规模的扩大，边际成本会越来越低，呈现出典型的规模效应的特点，加之其规模、技术、价格是一个正向驱动的飞轮，将能帮助物联网企业在后期获得收益。



 




 在商业模式上，在物联网这一片蓝海中，物联网平台根据自身特色，走出了几种不同的商业化之路：模式一：按基础资源的使用收费；模式二：按流量套餐收费；模式三：按平台及软件产品的授权收费，此外，咨询服务往往也是平台厂商对外提供专业服务的重要方式之一；模式四：按软件 + 硬件解决方案的形式收费。



 




 除此以外还有部分企业，不仅有提供硬件、软件和解决方案的能力，还能直接提供实施和运维的服务，对此又是另一项收费内容。



 




 在物联网平台在垂直领域的应用分析上，报告指出，目前物联网的市场规模正以客观的速度实现上涨。在应用层面，“物联网+”的趋势正在进一步升级，将与大数据、云计算、人工智能等创新技术融合，带动细分产业转型升级。研究发现，物联网平台基础设施的定位没有改变，平台本身能够应用的场景非常之多，其中，工业制造、智慧生活、公共事业、能源环保、农业养殖、智慧物流、车联网、智慧零售、智慧医疗这九个场景更为物联网平台所关注。



 




 在物联网平台投融资事件分析上，报告认为，在所有细分领域中，智慧生活和工业互联网是物联网平台最为典型的两类应用场景，这两者产生的投融资事件最能体现行业风向变化。 



 




 其中，在智慧生活场景领域，其融资历程体现为这3大特点： 



 




 1.企业多成立于 2013、2014 年间，当时市场以智能硬件开发为普遍模式，大量创企在期间获得了融资；



 




 2.随着 2017 年以后智能硬件的风口逐渐消失，行业开始出现洗牌，只有一些典型的头部创企在 2017、2018 年间获得了持续的资本注入，融资进程达到 C 轮及以后；



 




 3.因为有较高的市场成熟度，该领域在 2019 年及以后产生的融资事件逐渐减少，企业转而更强调业务的持续开发与积累。



 




 在工业互联网场景领域，报告指出，政策的风向会影响到市场的反应和资本的决策，主要表现为以下3个特点： 



 




 1.一批企业在该政策颁布之前就已经成立并围绕工业互联网展开工作，2015、2016 年陆续获得试水性质的投资；



 




 2.到 2018 年政策推动“工业互联网元年”概念出现以后，行业内的投融资事件明显增多，且一线资本开始围绕一些典型标的包括树根互联、徐工汉云等展开大额的市场化融资；



 




 3.从整体看，工业互联网领域的企业融资多集中在 B 轮及 B 轮以前，市场成熟度不高，行业整体的创业和投资热情并未消减，抓住细分市场深耕或者具有清晰商业模式的企业此刻被资本选中的机会反而增大。



 




 万联网记者发现，从物联网投融资的情况及特点来看，在万物互联的时代下，物联网行业已将应用触角伸向不止于物流的众多领域，企业可随风口逐浪而上，但仍需注意的是，不少应用场景在某一阶段可能会因各种因素的影响爆发热潮，但随着资本市场的冷却和考量，热潮极有可能归于平淡，企业必须立足自身，注重利用物联网技术本身对业务的开发与积累，同时抓住市场痛点，深耕垂直领域，方有可能走出不一样的天地。
