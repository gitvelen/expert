概要：本文试图从供应链应用及供应链金融应用的业务架构的角度出发，讨论区块链技术底层技术，并分析如何在供应链及供应链金融的业务中应用区块链技术。

区块链是一个新兴的概念，但组成区块链的技术实际一点都不新：如非对称加密技术，P2P网络中的分布时存储，共识过程的技术。让我们回顾供应链系统常用的技术就能更加了解，特别是区块链底层技术解决问题和供应链系统中要解决问题实际是类同的，甚至未来区块链面临的问题也和供应链系统面临问题是类似的。

数据交换通讯与共识问题

供应链系统要解决一个主要问题是企业之间的数据交换通讯问题。一般来说，市场上产品主要有两种类型解决方案：一种是由供应链的核心企业构建一个系统，让上下游的企业使用核心企业的系统。当然这种系统这些年逐步从传统CS 结构系统，转化为门户，或者是SaaS 云化的系统。它把企业之间数据交换问题转化为系统内部数据处理问题，让数据交换通信变成不是问题。但这类产品在推广使用程度取决与核心企业对生态伙伴的掌控能力，当核心企业的上下游企业需要与多企业进行业务协作，就不得不面临使用多个无法整合的系统。依靠中央系统比较适合紧密生态群体如文沥供需链中分公司管理、控股或专营经销商管理系统。

另一种供应链系统搭建方式就是在多系统中通过通讯的方式来解决数据交互的问题。国际上比较多的方式是类似EDI，ebXML，RosettaNet 等国际标准文档交换技术或叫做广义EDI，国内应用比较多的是Web Service或者API 技术。 
 
EDI 技术在互联网兴起的过程中，从最早的VAN（Value Added Network）发展到互联网上，为解决互联网上数据交互的安全性和不可抵赖性，实际上也是使用非对称加密技术，对传输文档进行加密和签名，并通过回执及重试等多种方式保证数据交互的可靠性。EDI技术在国际应用广泛，但在中国却有点水土不服，究其原因是EDI实施成本偏高（实际上现在区块链也有这个问题），而中国又处在经济高速发展阶段，业务模式变化比较快，EDI实施成本更高的问题。

在EDI 互联网技术兴起中，另一项技术XML 技术也在兴起，随后发展出Web Service技术来进行数据交互。特别是近年移动应用的兴起，为能快速进行应用整合，大家觉的Web Service还太重，又进一步发展出API的数据交互技术并得到大量推广应用。所以目前国内大量电商和供应链系统数据交互的方式的通过API方式进行处理。

API 方式交互最大的优点是实时，简单，易用，解决掉EDI 实施成本高的问题 但EDI很多的优点也是API技术的缺点如：如大批量数据交互，数据交互过程中的不可抵赖性，可追踪性等问题。文沥的网关软件（B2BGateway 和API Gateway）实际是是融合EDI 数据交换及API 技术，在不同的业务场景中，组合使用两种技术。交易银行可使用强大的网关技术构建供应链数据整合和交易场景融合等称为交易银行网关。 

协同式的供应链系统另一个问题：共识问题。虽然有数据交互，但每个系统各自记账， 由于各种原因，系统长时间的运行后往往导致各自系统最终计算的结果不同（如应付款， 库存等），传统的解决这种问题的方式是定期对账。对账如何对呢？就要求系统记录台账，台账就是流水账，实际上有点类似区块链中后一块链指向前一块链。如发现差异，对账就是找到两个链从哪里开始分叉（不同的点），然后人工处理中间的差异点。 只是供应链系统对账仅仅的两点之间对账，区块链上是多点对账， 解决共识问题。
 
新的挑战和区块链应用

供应链系统中的数据交互和对账技术实际上能比较好处理两个企业之间的业务协同的需求。但随着供应链实践的发展，如物流外包，协同计划，柔性生产，深度营销，产融结合等思想和实践的执行，使得每个供应链业务所涉及的不再简简单单的买卖双方，而是多方等都参与在协同业务中，这又对供应链应用又提出新的挑战，上述两种解决方法都面临各自难题，而区块链技术提供了很好的解决方案。下面从供应链金融应用场景为例，来讨论如何在区块链技术上如何处理多方业务协作的数据交互。

供应链金融按照类型划分可以分为应收类，库存类，预付类等几种方式。 先从保理来说，保理是卖方将自己的应收转让给金融机构来获取融资的方式。保理业务需要买方，卖方，金融机构的三方协作。这三方不论哪方构建供应链金融系统，在实际业务中都很难让各方都积极使用本方的系统，更可能的方式是由中心管理机构构建系统，三方都与此系统沟通。这就是所谓的中心化。区块链提供一种去中心化来完成此类业务协作。它可以将下图中业务台账记录逐笔记录在区块链中，来完成各方系统的协作。

未来区块链的发展与新产品

未来区块链的发展，能够在电子货币及电子账户方面得到广泛应用，上述协作图中资金流转方面（绿色线条部分）也能在区块链上直接操作处理，使得上述协作流程变得更加高效流畅自然。

文沥即将发布的交易网关(SCF Gateway) 也是按照上述流程描述， 通过部署于企业端的网关软件系统与金融机构的业务系统进行交互协作，将企业与金融机构各类供应链金融模式下需要协同的数据整合集成工作标准化，加速供应链金融业务互联互通。交易网关与金融机构的通讯采用与区块链底层同样的技术（非对称加密技术），对内容进行加密，签名传输。交易网关支持在非区块链场景下将处理后数据放入在金融机构方。 同时支持在区块链场景下如（如R3，HyperLedger，以太坊等）下的分布记账和智能合约。交易网关应是文沥作为领先的B2B电商供需链管理和供应链金融服务商对区块链趋势响应的首款产品，也是全球首款区块链数据网关产品。
