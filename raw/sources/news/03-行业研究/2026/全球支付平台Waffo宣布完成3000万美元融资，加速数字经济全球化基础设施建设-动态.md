# 全球支付平台Waffo宣布完成3000万美元融资，加速数字经济全球化基础设施建设-动态

全球支付与变现平台 Waffo 今日宣布完成累计 3000 万美元融资，其中本次 A 轮融资超过 1500 万美元，由总部位于伦敦的金融科技投资机构 Illuminate Financial 与高榕创投共同领投，汇丰（HSBC）与 BAI Capital 参与投资。



 本次新增投资方 Illuminate Financial 专注于金融科技与金融基础设施领域，其背后拥有包括纽约梅隆银行（BNY Mellon）、欧洲清算银行（Euroclear）、摩根大通（J.P. Morgan）、标普全球（S&P Global）、Jefferies Financial Group、德意志交易所集团（Deutsche B?rse Group）、巴克莱银行（Barclays）、花旗集团（Citi）、新加坡交易所（SGX）以及汇丰（HSBC）等全球领先金融机构组成的豪华战略投资者阵容。此次融资将加速 Waffo 全球支付基础设施的建设，帮助游戏、AI、SaaS、数字内容等行业企业解决支付难题，实现规模化变现。



 统一 API 连接全球 430+支付方式，为数字企业提供全球化变现解决方案 



 Waffo 通过单一 API 接口整合全球 50+国家/地区的 430+种本地支付方式，为数字企业提供一站式全球收款、订阅管理、合规风控及结算解决方案。平台支持 2000TPS 高并发处理，实现 99.99% 服务可用性，为出海企业提供稳定可靠的支付基础设施。



 Waffo 提供模块化的支付解决方案，包括：全球支付网关，支持快速集成本地支付方式；智能路由系统，根据用户位置自动推荐最优支付路径；订阅管理平台，支持订阅支付、一次性支付、账单支付等多种模式，满足不同业务场景需求；统一结算服务，实现多地区、多币种的集中化财务管理；以及完善的合规风控体系，覆盖 KYC、PCI DSS 等国际标准。



 重塑出海支付体验，从工具到基础设施的跨越 



 随着数字经济的全球化扩张，企业在全球支付方面面临多重挑战：本地支付方式高度碎片化、监管环境复杂多变、跨市场结账体验割裂。对于游戏、AI、SaaS 等数字产品而言，构建可扩展的变现能力和合规的支付基础设施已成为出海刚需。



 Waffo 通过现代化、可扩展的支付基础设施直击这些痛点。平台不仅整合了传统银行卡支付，更深度覆盖了各地区的电子钱包、银行转账、二维码支付等本地化支付方式，帮助客户在北美、东亚、东南亚、拉美等全球主要市场提供更优质的全球支付体验，显著提升支付成功率。



 标杆客户构建完整支付生态 



 在游戏、AI、SaaS、数字内容等线上领域，Waffo 已为多家头部企业提供全球支付与变现基础设施服务，客户涵盖头部游戏公司、AI 创新企业，包括知名 AI 大模型应用、设计与创作者提效工具、AI 视频生成平台、智能对话助手及 AI 图像处理平台等。依托 Waffo 的本地化支付与结算能力，这些企业在北美、东亚、东南亚、拉美等全球主要市场显著提升了用户转化率与留存水平，加速实现规模化商业化与可持续变现。



 在金融支付领域，Waffo 的支付基础设施已被多家领先金融机构与支付平台采用，为其全球收单、本地支付接入及结算能力提供底层支持。其中，Waffo 为连连国际及汇丰（HSBC）等机构提供全球支付能力与技术服务，助力其更高效地服务全球商户与企业客户，提升跨市场支付体验与运营效率。



 融资赋能解决方案创新与全球支付网络拓展 



 据悉，本轮融资将重点用于三大方向：在解决方案层面，为游戏、AI、SaaS 等不同行业客户构建更专业的支付解决方案，提升行业适配性和用户体验；在收单能力层面，搭建更广泛的全球收单能力网络，增加新兴市场本地支付方式覆盖；在分发能力层面，拓展更广阔的全球支付渠道合作，围绕不同场景为客户提供更精准的支付服务。



 投资方观点：支付基础设施的重新定义 



 高榕创投合伙人胡朔表示：“在这一波以AI应用为代表的数字经济全球化浪潮中，企业的商业模式和增长路径正在重构，能够支撑AI企业灵活定价策略、高效现金流周转的支付基础设施至关重要。Waffo通过技术驱动的本地化支付解决方案，帮助AI、游戏、娱乐等企业更高效地实现国际化，帮助华人创业者加速全球变现。我们相信，Waffo 将持续以更高效的集成体验与稳固的底层能力，支持AI与数字原生企业在全球范围内实现更快、更稳健的商业化增长。”



 关于 Waffo 



 Waffo是统一的全球支付与变现平台，连接50+国家/地区的430+种本地支付方式，助力数字企业一站式管理全球收款、订阅、合规、风控及结算，简化全球运营流程，驱动全球营收增长。公司已获得PCI DSS v4.0一级认证，覆盖全球支付收单、结算和退款等关键流程，支持2000TPS高并发处理，实现99.99%服务可用性。
