# 查询：智慧供应链4.0阶段2017年后实际落地核验

丁俊发 2017 年预测：供应链 4.0 阶段将呈现"与互联网、物联网深度融合、基于大数据的人工智能应用、组织形态更扁平、虚拟生产与云制造普及、供应链生态圈"等特征。这是预测性论述，需跟踪 2017 年后实际落地情况，避免将预测当事实。

## 待核验问题

1. 智慧供应链在制造业与流通业的实际渗透程度如何？哪些行业案例可验证？
2. 虚拟生产、云制造在中国的普及程度是否符合预测？
3. "供应链生态圈"是否成为主流组织形态，还是更多停留在平台企业话语层面？
