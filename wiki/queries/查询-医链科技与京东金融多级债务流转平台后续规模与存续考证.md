# 查询：医链科技与京东金融多级债务流转平台的后续规模与存续考证

[[医链科技]] 于 2018-05-29 与 [[京东金融]] 联合发布的多级债务流转平台，在 2019 年论坛上被宣称已跨行业输出。需考证：

1. 平台此后实际业务规模（累计流转/融资金额）；
2. 公司后续存续状态（是否更名、注销或转型）；
3. 与 [[京东金融]] 合作是否延续。

依据仅为 2019 年会议自述口径，无独立验证。
