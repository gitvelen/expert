# 查询：瑞茂通2019年后保理风险是否实际暴露及公司处置结局

2018 年底第一财经/贸易金融报道对瑞茂通提出风险预警：保理放款断崖收缩、102 亿应收压顶、坏账率 0.4% 是否为风险延后、大股东 86.5% 质押、短期债务现金覆盖率仅 20%。这些当时均为推断性表述。

## 待验证问题

1. 2019 年煤价走低后，瑞茂通供应链管理与供应链金融“两条腿”业务是否实际滑坡？
2. 0.4% 的保理坏账率最终是“风控到位”还是“风险延后暴露”？是否有大额坏账、应收保理款减值或审计非标？
3. 大股东郑州瑞茂通高质押链条是否引发平仓/控制权变动？
4. ABS/ABN 融资渠道后续是否持续，公司流动性危机是否实际发生？
