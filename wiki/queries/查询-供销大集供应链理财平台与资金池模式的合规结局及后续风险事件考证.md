# 查询：供销大集供应链理财平台与资金池模式的合规结局及后续风险事件考证

**开放问题**：供销大集 2017 年中报披露的"供应链理财线上平台 + 产业链信贷产品 + 资金池 + 基金融资 + 拟申保理/基金牌照"布局，事后是否发生债务或合规风险事件？是否与 2018 年后海航系流动性危机存在关联？

**考证方向**：
1. 供销大集 2018 年后的财报、债务重组与控制权变更情况（海航系背景）；
2. 其供应链理财平台是否被认定自融/资金池，是否有兑付纠纷或监管处置；
3. 拟申请的保理、基金牌照最终是否落地；
4. 与 [[entities/怡亚通]] 的流通企业金融化路径对照（见 [[queries/查询-怡亚通新流通模式后续经营验证与供应链服务公司金融化演变考证]]），提炼"零售产业银行"模式的共性风险结构。
