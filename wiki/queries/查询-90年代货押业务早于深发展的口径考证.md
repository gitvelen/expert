# 查询：90 年代货押业务早于深发展的口径考证

文中作者自述："我行供应链金融起步还是较早的，**90 年代总部就开始推货押业务，早于后来在供应链领域颇有名气的深发展**"（2021 自述口径）。

## 冲突点

- 主流口径：深发展（深圳发展银行）为国内货押/供应链金融发端（约 1999 年前后），见 [[queries/查询-深圳供应链金融发源地时间线1998与1999口径考证]]
- 本文口径：某股份制银行 90 年代总部已推货押业务

## 处理

- 双说并存，各自标注年份与证据强度：主流口径证据充分（多来源），本文为单方自述（强度低）
- 可作为深圳发源地时间线 query 的旁证材料，但不可据此改写主流结论
- 待查证方向：90 年代国有银行与股份制银行货押/仓单质押业务的早期案例与文献
