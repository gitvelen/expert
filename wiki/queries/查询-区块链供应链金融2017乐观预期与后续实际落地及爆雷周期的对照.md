# 查询：区块链供应链金融 2017 乐观预期与后续实际落地及爆雷周期的对照

## 开放问题

2017 年爱保理文章主张区块链可保障数据真实、降低信贷成本、减少中介、实现金融脱媒。但 2019–2020 年代供应链金融爆雷周期中数据造假仍频发。需要核验：

1. 区块链电子仓单 / 数字债权凭证等实际落地案例中，"上链数据真实性"（源头造假、链下真实性问题）是否真正被解决？
2. "金融脱媒、去中介"预期与实际中区块链平台反而新增平台方/核心企业主导结构之间的落差。
3. 2025–2026 年监管语境（如数字凭证监管收紧）下，区块链+供应链金融的现状与 2017 年预期的差异。
