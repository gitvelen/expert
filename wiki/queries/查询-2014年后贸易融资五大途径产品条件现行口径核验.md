# 查询：2014年后贸易融资五大途径产品条件现行口径核验

本文各产品条件均为 2014 年媒体转述口径，待核验其现行演变：

1. 进出口银行出口买方信贷的合同金额门槛（200 万美元）、贷款比例（85%/80%）、期限（15 年）是否有调整？
2. 信保融资的付款期限上限（180 天）与适用结算方式（D/P、D/A、O/A、信用证）现行口径？
3. 工行订单融资"两年合作记录+非关联企业"的准入条件是否仍有效？
4. 渣打 Straight2Bank 供应链融资的经销商信贷评估方法在数字化后的实际演进。

两说处理：2014 年口径保留于上述 concept/finding 页并标注年份；确认最新官方口径后在本页裁决并回填。
