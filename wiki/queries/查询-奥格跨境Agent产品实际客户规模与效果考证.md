# 查询：奥格跨境出海问问/鸭梨匠的实际客户规模与效果数据考证

## 开放问题

2025 年来源为奥格跨境自述软文，宣称其 Agent 产品已在跨境供应链落地并成为"参考标杆"，但**无具体客户名、无量化效果数据（效率提升百分比、成本节约等）、无独立验证**。需考证：

1. 出海问问、鸭梨匠的实际客户数量与代表性客户是谁？
2. "40～60 个智能体"的大客户案例是否真实存在，对应哪家企业？
3. 部署 Agent 后的效率/成本改善有无第三方可验证数据？

## 关联开放问题

- AI Agent 在供应链金融**授信环节**（而非物流操作环节）是否存在落地案例？目前知识库内 Agent 应用仅见于跨境物流操作（单证、配舱、费用匹配），与 [[场景数字化-数字信用化-信用资产化三段论-2025口径]] 所述金融数字化路径的衔接尚未有证据。
