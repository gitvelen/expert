# 查询：2018年潜力垂直行业供应链金融2018年后实际发展兑现情况核验

2018 年众润金控调研将物流、农业、零售业、化工（塑料）、餐饮业列为供应链金融潜力垂直领域，并附乐观论据（物流 60-90 天账期、专业市场控商户、塑料万亿市场、餐饮 3 万亿营收等）。需核验：

1. **物流**：2018 年后围绕物流企业运费应收账款的供应链金融产品（运费保理、网络货运平台金融等）实际规模与坏账情况如何？60-90 天账期口径是否仍成立？
2. **农业**：畜禽养殖产业链供应链金融（饲料龙头主导模式）2018 年后的发展，猪周期冲击下的风险表现？
3. **零售/专业市场**：专业市场小 B 融资模式在电商冲击与经济下行下的存续情况？
4. **化工（塑料）**：塑料 B2B 平台（文中称“已初具规模”）2018 年后的经营结局与供应链金融落地真实性？
5. **餐饮**：文中提及的筷来财等平台 2018 年后结局；餐饮供应链金融是否仍处“起步阶段”？

## 相关背景
- 该文对 B2B 平台“容易做出规模”的乐观判断，与同期伪供应链/融资性贸易风险叙事存在张力，核验时应对照风险案例。
