# 查询：江苏高院保理十项倾向性意见在民法典与保理司法解释后的存废对照

## 开放问题

江苏高院民二庭课题组2015年提出的十项倾向性意见，在《民法典》（保理合同章）及保理合同司法解释实施后的存废状况需逐项对照：

| 意见 | 初步判断（待核验） |
|---|---|
| 拆分定性论 | 民法典设保理合同有名合同章，“拆分定性”论证基础已变 |
| 并案审理/按基础关系定管辖 | 需对照2021年保理司法解释管辖规则 |
| 虚假应收账款可撤销论 | 与民法典虚构应收账款不得对抗善意保理人规则（765条）关系待理清 |
| 未来应收账款有效论 | 民法典761条已明文肯定“将有的应收账款”，结论被吸收 |
| 禁止让与善意保护 | 民法典545条已明文化，已有页面标注被取代 |
| 通知效力/受让人通知 | 通知规则经民法典修改，需对照 |
| 通知对抗主义 | 民法典768条确立的优先规则体系（登记/通知/比例）与通知对抗说的差异待对照 |
| 转让与出质冲突 | 民法典768条统一处理，原《物权法》228条路径废止 |
| 双重受偿防范主文规则 | 实务规则，预计延续但需实证 |
| 串通虚假应收账款侵权责任 | 需对照民法典侵权编与765条 |

## 待办

逐项检索民法典第545-546、761-769条及2021年保理合同司法解释，完成存废对照并沉淀入 synthesis 页。
