# 查询：钢铁电商平台供应链金融与信用体系论在2017年后的落地与验证考证

## 待考问题

2017 年业内解读认为钢铁电商平台将以真实交易数据构建供应链信用体系，银行可直接对接平台提供服务。这一乐观预测在 2017 年后是否兑现？

1. **数据信用模式落地**：钢银、找钢网、欧冶云商等钢铁电商平台的供应链金融业务实际规模、风控模式与坏账表现如何？
2. **风险事件**：是否出现平台交易数据造假、重复质押、虚构贸易背景等爆雷案例，证伪或修正“平台数据=信用基础”的假设？
3. **平台整合**：文中指出的“重复建设多、信息相互独立”短板是否通过整合联合或资本合作解决？
4. **产能预售**：产能预售模式是否形成稳定实践，钢厂履约与终端违约风险如何处置？
5. **钢贸转型结局**：钢贸/物流企业自建平台路线与平台合作路线的存活率对比。

## 关联背景

- 2017 年同期保理行业“贸易虚假成纠纷主因”（金杜口径），提示平台数据信用的有效性不可默认。
