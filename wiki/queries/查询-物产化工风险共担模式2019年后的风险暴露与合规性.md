# 查询：物产化工风险共担模式 2019 年后的风险暴露与合规性

## 开放问题

1. 浙江物产化工 2019 年自述的“十多个供应链业务”在 2019 年后（尤其在国资委对融资性贸易、“空转”“走单”贸易监管收紧背景下）是否出现风险暴露或亏损？
2. 其“国企信用输送 + 贸易性参与 + 风险共担”模式是否曾被认定为融资性贸易或违规托盘业务？合规隔离机制如何？
3. “破产也不停产”式救助介入的实际案例与回收结果是否有公开可查证信息？
