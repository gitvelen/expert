# 查询：蚂蚁金服京东金融农村供应链金融模式2017年后演变考证

2017 年来源对"龙头企业+合作社(农户)+保险+电商金融"模式（见 [[电商农村供应链金融N1N1到NNN结构升级-2017口径]]）持乐观预期。以现行视角看，阿里/京东农村金融业务后续均有收缩与调整，该"新趋势"判断可能已被现实修正。

## 待考证

1. [[旺农贷]] 及网商银行农村信贷业务后续规模、坏账与策略调整情况。
2. [[京东金融]]（后重组为京东科技）农村"3F战略"（[[京东3F战略]]）的实际落地与终结时点。
3. "N+N+N"多对多组合模式是否有真实规模化案例，抑或停留于 2017 年叙事。
4. 农村数字普惠金融监管（如农村数字金融相关规范）对上述模式的约束。

证据强度：本文为观点性公众号分析；后续演变需以年报、监管文件与可靠新闻报道为准。
