# 政策性资金嵌入数字化供应链平台（农发行×数链科技2022口径）

## 模式要点

政策性银行（[[entities/中国农业发展银行]] 河南省分行）不直接面对分散小农，而是向平台核心企业（[[entities/农开供应链]]）发放农业政策性资金，再借助产业数字化平台（[[entities/数链科技]]）的交易数据与控货能力，向链属小农/中小贸易商精准放款。

结构链条：

```
农发行河南分行 ——10亿元政策性资金——> 农开供应链（核心企业）
                                        │
                              数链科技数字化平台
                                        │
                     应收账款保理/装车付款/订单融资/港口仓单质押
                                        │
                              链属小农、中小贸易商
```

## 模式意义

- 政策性资金 + 产业平台协同：以平台的交易数据（数据信用）与智慧粮仓/云监管控货（物的信用），弥补小农与中小贸易商主体信用不足。
- 与知识库工作论点直接相关：让融资依附于真实交易结构，以数据信用与物的信用替代对主体信用的迷信。
- 是"数据信用 + 物的信用"结合的落地样本，关联 [[concepts/三种信用互联互通-主体数据物的-刘江2022口径]] 与 [[concepts/供应链金融官方政策背书-2022口径]]。

## 开放问题

农发行资金的具体投放结构（是否直达小农、如何计息与风控）来源未交代；该模式在 2023 年后是否有复制案例待查——见 [[queries/查询-数链科技100亿元授信口径与后续存续考证]]。
