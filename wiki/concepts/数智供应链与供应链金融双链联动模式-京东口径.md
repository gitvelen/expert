# "数智供应链+供应链金融"双链联动模式（京东口径）

京东科技自2022年起对外输出的战略模式：以数智供应链能力（上游数智采购、数智物流仓储、下游全渠道履约、数智研发生产C2M等）与供应链金融科技（京东供应链金融科技平台）相互加持，形成产业数字化与金融科技的联动输出。

## 组成

- **供应链金融侧**：应收融资、采购融资、动产融资、融资租赁、小微金融、票据秒贴等平台，以及保理/仓单/票据/信用等业务系统。
- **产业数字化侧**：供应商管理、集采商城、电子招投标、仓网优化、智能物流、数字化仓储、全渠道履约、C2M反向定制、工业互联平台等。
- **支付侧**：企业支付SaaS科技服务平台（SaaS+OPEN API 双接入，企业电子钱包、快捷支付、资金管理、收款专户认款自动核销），既可单独输出也可作为供应链金融平台内嵌模块。

> 本页为厂商自述口径（2023），无第三方核验，引用时注意宣传性成分。
