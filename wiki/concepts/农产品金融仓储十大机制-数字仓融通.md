# 农产品金融仓储十大机制（数字仓融通）

## 背景

四川某地（全国现代农业示范区，年产蔬菜230余万吨、产值约120亿元，拥有西南最大农产品集散物流中心“四川国际农产品交易中心”，年交易额500亿元）自2013年起尝试以耐储存、价值高的果蔬作为抵质押物。**2016年**，当地人民银行支行、农业农村局、国资金融局构建农产品金融仓储服务等“十大机制”，奠定“数字仓融通”项目基础。果蔬类农产品易损耗、季节性强、价格波动大、品质难统一，传统融资面临估值难、监管难、处置难。以下为许书川演讲（2026-06）转述口径。

## 十大机制与关键参数

| 聚焦难点 | 机制 | 要点 |
|---|---|---|
| 评估 | 价值评估机制 | 依托“专家库”+经纪人“智囊团”组建市场化评估机构 |
| 价格 | 价格推送机制 | 农业农村局与蔬菜产销协会共建价格信息平台，在一级批发市场设信息采集员，定期向银行推送价格 |
| 存储 | 金融仓储服务机制 | 组建市场化金融仓储机构，出具仓单并提供贷前调查、质押物管理 |
| 存储 | 保险机制 | “财产一切险”纳入政策性农业保险，剔除人为因素后自然灾害、火灾、丢失等由保险公司赔偿；借款人享 **50% 保费补贴** |
| 风控 | 平仓机制 | 农产品价值降至评估价值 **70%** 时启动，通知补仓或直接平仓处置 |
| 风控 | 风险分担机制 | 纳入市级“农贷通”风险基金和区级乡村振兴风险补偿金，贷款损失由风险基金按 **8:2** 与银行分担 |
| 交易 | 提前解质机制 | 通过合作农村资金互助社获得解质资金 |
| 交易 | 仓单置换机制 | 质押期内按等价原则进行品种调换 |
| 运行 | 巡查机制 | 金融仓储公司定期巡查质押物并向银行、保险公司报告 |
| 运行 | 政策支持体系 | 农产品仓单质押贷款享 **LPR 30% 贴息**；制定特色产品仓单操作规范；人民银行支行统一规范金融格式文书 |

## 五类参与方

1. 政府：分险基金、贴息保费补贴、仓单标准化（惩戒之外的“分险型”政府角色）
2. 仓储平台运营方：金融仓储机构，承担运营协调
3. 专业服务机构：保险公司、评估公司
4. 行业协会与大型贸易商：价格采集、仓储标准、优先采购协议与处置通道
5. 科技公司（享宇科技）：构建协作商业模式与数字化基础设施
