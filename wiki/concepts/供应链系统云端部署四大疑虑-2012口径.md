# 供应链系统云端部署四大疑虑（2012口径）

## 概述

2012 年企业将供应链系统部署到云端（SaaS 化）时普遍存在的四大疑虑，由明基逐鹿贾林斌基于与用户的多年沟通归纳（媒体转述口径，定性归纳，证据强度弱）。作为数字化供应链落地瓶颈的早期历史快照，具有史料价值。

## 四大疑虑

1. **可靠性**：供应链系统需同内部系统大量集成、数据交互频繁，放云端如何保证可靠性
2. **数据安全**：云模式如何保障供应链系统大量机密数据的安全性
3. **定制化**：供应链系统每家都有特色，SaaS 模式是否能够支持
4. **服务商能力**：云供应商能否有效支持众多的供应商服务

## 时代特征

文章一面强调云/IT 是供应链解法，一面列举上云疑虑，反映了 2012 年企业信息化“既推崇又观望”的过渡期心态。文中自述这些仅是“冰山一角”，CIO 面临的挑战远高于预期。
