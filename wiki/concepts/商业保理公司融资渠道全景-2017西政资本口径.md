# 商业保理公司融资渠道全景（2017 西政资本口径）

> **时效状态**：本页为 2017 年历史口径。P2P 渠道、金交所渠道、契型资管/信托计划、私募保理基金此后已被监管封堵或严重受限（封堵时间线考证见 [[queries/查询-2017年后保理融资渠道逐一封堵时间线考证]]），不作现行业务参考。

## 核心判断

保理公司融资能力取决于三要素：

1. **股东背景**——决定银行综合授信的可得性与成本（大股东担保 → 低成本银行资金）
2. **资产包质量（评级）**——决定资管/信托计划渠道的可行性（一般要求 AA+/AAA）
3. **渠道合规性**——决定互金、金交所等通道的存续风险

## 十大渠道与现状对照

| 渠道 | 要点 | 2017 后现状 |
|---|---|---|
| 股东融资 | 借款/信托贷款/委托贷款/认购定向资管 | 视股东实力，仍为基本渠道 |
| 银行综合授信 | 大股东担保，或保证金/信用保险/应收账款质押增信 | 仍有效，但监管趋严 |
| 银行再保理 | 要求底层债权优质、资产包评级高 | 仍有效，属合规主流 |
| 资管/信托计划 | 打包保理资产，看资产不看股东 | 契型模式已被资管新规压制 |
| 泛金融机构 | 尽调宽松，依赖回购+商票质押增信 | 受融资性贸易/商票风险整治冲击 |
| 私募保理基金 | 收益权/债权转让两模式 | 私募监管收紧后严重受限 |
| 再保理与双保理 | 再保理商不限于银行；双保理跨国常见 | 制度性模式，跨时代有效 |
| 资产证券化（ABS） | 文中仅列基本架构 | 仍为合规主渠道之一 |
| P2P 平台 | 打包债权转让+回购承诺 | **已被封堵**（负面清单+平台清退） |
| 金交所 | 收益权/债权挂牌转让 | **已被清理整顿** |
| 发债与外债 | 受评级与外债额度限制 | 允许但门槛高 |

## 历史意义

该全景图是"监管演进持续重塑产品边界"的典型样本：2017 年"通道式融资"生态与 205 号文之后商业保理回归主业、穿透监管的路径形成鲜明对照。来源见 [[sources/4-news--7-02-产品案例--4-2017--11-保理公司的花式融资保理--18kfiky]]。
