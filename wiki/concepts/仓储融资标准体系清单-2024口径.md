# 仓储融资标准体系清单（2024 口径）

## 清单（来源报道原文，2024-09-10 启动会口径）

| 层级 | 标准 |
|------|------|
| 国家标准 | 《仓单要素与格式要求》 |
| 国家标准 | 《担保存货第三方管理规范》 |
| 团体标准 | 《全国性可流转仓单体系运营管理规范》系列 |
| 技术标准 | 《智慧仓储存货监管技术管理规范》 |
| 技术标准 | 《国家工业互联网体系现代仓库标识要素规范》 |

## 作用表述

按报道口径，该标准体系“基本上厘清了仓储融资相关的概念、角色、职责、方法”。2024 年生态体系建设以“2 项国标 + 1 项团标 + 行业基础设施服务”为依据。

## 关联

- 《全国性可流转仓单体系运营管理规范》与 [[concepts/电子货权凭证与三登记两确认-中仓登马令海2024口径]] 中的可流转仓单体系实践直接相关。
- 政策法规脉络关联 [[entities/银保监发2022-29号文]]。

## 证据强度

标准名称清单可独立核实（较强）；“基本健全”等评价为协会自述（中等）。
