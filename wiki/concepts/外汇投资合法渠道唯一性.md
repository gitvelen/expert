# 外汇投资合法渠道唯一性

银监会消费者保护局局长邓智毅在 API 骗局事件（2015-03 报道）中的监管表态：

- 截至当时，**国家尚未批准任何国外投资公司来中国进行外汇投资**；直接向未经批准的境外公司投资存在巨大风险。
- 国内进行外汇投资的**唯一合法途径是通过各商业银行**。
- 正规外汇投资有**严格的第三方资金监管**；而 API 骗局中大量投资者把资金直接打入对方提供的**个人账户**，这是识别非法平台的关键红旗信号。

## 实务含义

对个人投资者而言，可用两条硬性标准快速筛查：其一，交易对手是否为商业银行等持牌境内机构；其二，资金是否进入受第三方监管的账户而非个人/公司自有账户。参见 [[境外外汇传销骗局]] 与 [[api卓越瑞士信托公司]]。
