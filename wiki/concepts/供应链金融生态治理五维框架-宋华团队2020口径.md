# 供应链金融生态治理五维框架（宋华团队2020口径）

**出处**：2020 年 3 月《疫情下企业融资与供应链金融调研报告》第二部分（万联网 2020-03-31 分享），宋华教授专业指导。核心主张：中小微融资难题非单一主体或政策可解，需全社会利益相关方通过治理规范行为与互动，形成相互推动又相互约束的供应链金融体系。

## 一、生态结构：五类参与方各司其职

| 参与方 | 职责 |
|---|---|
| 核心企业/平台组织 | 组织中小微进入供应链，保障交易质量，将完整有效业务信息穿透给金融机构，确保基础资产保全、可视、可追溯 |
| 科技金融公司 | 合规前提下将产业运营数据客观、系统、零延迟传递给融资决策方，降低信息不对称 |
| 第三方物流 | 存货管理方，库存融资下担负质押监管重任，确保货物保全与透明可视（供应链金融基础设施） |
| 金融机构 | 贷前、贷中、贷后全周期供应链风险管理体系，鉴别优质中小微，多样化信贷产品 |
| 政府 | 建立公平制度环境 + 监管经营秩序、防范金融风险 |

任何一方缺失或行为失当，信贷风险即上升。因此不能把责任全推给金融机构，或单纯要求其提高坏账容忍度。

## 二、管理体系：可靠、关联、有效

- **可靠**：建立全周期产业运行预警与监测机制，因产业、地域、时间而异精准施策（建议由地方金融局协同工商、商务、经信等部门及行业协会、供应链试点企业联合建设）
- **关联**：供应链金融须置于业务场景中，强化产业集群地区行业协会、龙头企业、供应链服务企业的责任与配合
- **有效**：按实际状况制定制度——调研显示绝大多数金融机构认为贴息与风险补偿政策"作用有限"

## 三、行为规则

- **核心企业**：应尽确权责任、明确付款期限，不得拖欠账期；可通过在线化将应收账款单证化并以自身信用额度确保到期支付；转让的应收账款须在管理部门公认平台登记公示。65.5% 金融机构反映核心企业不确权/不配合是重要阻碍
- **金融机构**：改变单纯"看报表看资产"，具备监督管理供应链基础资产的能力 + 信息化数字化能力，实现**结构信用（基于业务把握）与数字信用（基于数字化分析）相融合**的智慧供应链信用体系；杜绝"打摆子"式连带抽贷
- **中小微企业**：主动及时共享信息（77% 金融机构将信息数据共享力度与及时性列为借贷决策重要因素；64.2% 看重真实应急方案），强化运营改进、创新与信息分享能力

## 四、制度环境

1. **数据支持**：85.5% 金融机构希望"开放政府公共数据，支持企业征信"
2. **线上化制度创新**：68.6% 需求"线上审查尽调"、46.9%"允许在线开户"、26.1%"在线面签"；52.2% 需求"增加流动性"、57.5% 需求"风险容忍度改变"
3. **公平交易环境**：推行标准化电子单证（电子签章、电子合约、电子仓单、电子运单、电子面单）；立法限制大企业赖账、不确权、拖延账期；规范商业承兑汇票与寄售使用比例

## 五、多元金融与风险可控并行的秩序

- 资金不足是放贷阻碍之一（30.5%），需引导更多金融机构与产品进入，丰富资金端
- 防止供应链金融成为博取暴利的投机热点
- 应收账款资产证券化须强化基础资产**穿透管理**；监管方需平衡金融创新与风险管理
