# 深圳供应链金融创新示范园区区级布局

征求意见稿按各区产业禀赋规划差异化供应链金融园区，形成"一区一特色"格局：

| 区 | 产业优势 | 定位 |
|---|---|---|
| 福田区 | 金融与金融科技集聚 | 供应链金融特色街区 |
| 罗湖区 | 黄金珠宝、商贸 | 黄金供应链金融特色园区 |
| 南山区 | 科技创新 | 供应链金融科创示范产业基地 |
| 盐田区 | 港口、保税燃料加注 | 围绕大型船舶设备与油气贸易创新供应链金融模式 |
| 宝安区 | 制造业产业链 | 粤港澳大湾区先进制造业供应链金融服务中心 |
| 龙华区 | 数字龙华 | 特色产业供应链金融数字园区 |
| 大鹏新区 | 食品谷国家级项目、文旅 | 食品和文旅特色供应链金融示范基地 |

其他各区可依托产业集群或区域龙头企业打造特色园区；有条件的区可对园区运营机构及园内企业给予奖励。
