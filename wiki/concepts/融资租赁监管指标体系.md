# 融资租赁监管指标体系

银保监发〔2020〕22 号文（[[融资租赁公司监督管理暂行办法2020]]）确立、[[上海市融资租赁公司监督管理暂行办法2021]] 第三十二、三十三条原样承接的硬性监管指标：

| 指标 | 要求 |
|---|---|
| 租赁资产比重 | 融资租赁和其他租赁资产 ≥ 总资产 60% |
| 风险杠杆 | 风险资产总额 ≤ 净资产 8 倍（风险资产 = 总资产 − 现金 − 银行存款 − 国债投资） |
| 固收投资 | 固定收益类证券投资 ≤ 净资产 20% |
| 单一客户融资集中度 | ≤ 净资产 30% |
| 单一集团客户融资集中度 | ≤ 净资产 50% |
| 单一客户关联度 | ≤ 净资产 30% |
| 全部关联度 | ≤ 净资产 50% |
| 单一股东关联度 | ≤ 该股东出资额 |

## 弹性机制

- 上海办法措辞为“一般不得超过”，集中度指标存在个案弹性。
- 上海办法第五十六条：对航空航运、海工装备、集成电路、医疗器械、人工智能、高端制造、节能环保、基础设施、城市更新、民生保障等导向领域，可结合监管评级适当调整集中度与关联度要求。
- 过渡期：存量企业 2023 年 6 月 30 日前达标，飞机、船舶等长租赁期业务可申请延长。
