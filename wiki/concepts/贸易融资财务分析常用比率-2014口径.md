# 贸易融资财务分析常用比率（2014口径）

本页汇编贸易融资授信尽调中常用的财务比率工具箱（2014 年口径，转引自 [[sources/4-news--7-04-业务基础--4-2014--17-干货50套会计常用公式贸易融资产品--qyk24q]]）。该套比率属**传统主体信用分析范式**——以企业报表评估偿债能力；在供应链金融语境下，它是对"交易/数据信用"风控范式的补充而非替代，使用时应结合贸易背景真实性与货权控制力判断。

## 一、偿债能力比率

```
流动比率       ＝ 流动资产 / 流动负债
速动比率       ＝（流动资产 − 存货）/ 流动负债
保守速动比率   ＝（现金 + 短期证券 + 应收票据 + 应收账款净额）/ 流动负债
资产负债率     ＝ 负债总额 / 资产总额
产权比率       ＝ 负债总额 / 所有者权益
有形净值债务率 ＝ 负债总额 /（股东权益 − 无形资产净值）
已获利息倍数   ＝ 息税前利润 / 利息费用
```

## 二、营运效率与周转比率

```
营业周期           ＝ 存货周转天数 + 应收账款周转天数
存货周转率（次）   ＝ 销售成本 / 平均存货（原文"平均存货"漏 ÷2，应为（年初+年末）÷2）
存货周转天数       ＝ 360 / 存货周转率
应收账款周转率（次）＝ 销售收入 / 平均应收账款（收入为扣折扣折让净额；应收账款未扣坏账准备）
应收账款周转天数   ＝ 360 / 应收账款周转率
流动资产周转率     ＝ 销售收入 / 平均流动资产
总资产周转率       ＝ 销售收入 / 平均资产总额
```

## 三、盈利能力比率

```
销售净利率   ＝ 净利润 / 销售收入 × 100%
销售毛利率   ＝（销售收入 − 销售成本）/ 销售收入 × 100%
资产净利率   ＝ 净利润 / 平均资产总额
净资产收益率 ＝ 净利润 / 平均净资产 × 100%（或＝销售净利率 × 资产周转率 × 权益乘数）
```

## 四、现金流量比率

```
现金到期债务比   ＝ 经营现金净流入 /（到期长期债务 + 应付票据）
现金流动负债比   ＝ 经营现金流量 / 流动负债
现金债务总额比   ＝ 经营现金流入 / 债务总额
销售现金比率     ＝ 经营现金流量 / 销售额
全部资产现金回收率＝ 经营现金净流量 / 全部资产 × 100%
```

## 五、与保理/存货质押期限设定的关联（第37-38条）

```
应收账款应计利息 ＝ 日销售额 × 平均收现期 × 变动成本率 × 资本成本
平均余额         ＝ 日销售额 × 平均收现期
占用资金         ＝ 平均余额 × 变动成本率
折扣成本增加     ＝ 新销售水平 × 新折扣率 × 享受折扣比例 − 旧销售水平 × 旧折扣率 × 享受折扣的顾客比例
```

- **应收账款周转天数**是保理账期设定与折扣成本测算的直接输入，支撑反向保理定价。
- **存货周转天数**是存货质押融资期限设定与质物流动性评估的参考基准。

## 使用注意

原文多处公式存在讹误（如平均存货漏 ÷2），引用时须以权威会计教材核校，见 [[queries/查询-50套会计公式原文讹误与权威版本核验]]；360 天/年、结息规则等为 2014 年口径。
