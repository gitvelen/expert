# N+1+N 架构演变（2016 口径）

洪锦屏（2016）提出的链条架构演变：传统供应链金融采用 **"1+1+N"**（一个银行 + 一个核心企业 + N 个上下游企业），银行对核心企业授信；互联网浪潮下上下游融资企业可直接接触核心企业，改由**核心企业对上下游授信**，核心企业以自有资金加外部融资补充，形成 **"N+1+N"** 架构，核心企业作用更加凸显。

与 [[1即N-N即1金融服务生态圈-2015口径]] 的"生态圈"叙事、[[核心企业信用转移论-2015科普口径]] 呼应：三者均刻画授信重心由银行向掌握交易数据的核心企业/平台转移的趋势。
