# 2014年银行供应链融资11类行业场景产品组合清单

2014年营销文章中归纳的"行业场景 × 产品组合"匹配清单，反映当时银行对公客户经理按核心企业产业链开发供应链融资客户的营销思路。证据强度：弱（营销清单，无案例与数据）。其中医疗设备买方信贷与租赁联动是两类有细节价值的组合：

- **医疗设备买方信贷+租赁保理联动**：银行为医院提供定向买方信贷，向供应商采购医疗设备；同时与租赁公司合作开展保理融资，形成"买方信贷 + 租赁 + 保理"的联动结构。
- **租赁公司三方融资**：电信设备供应商、火车设备供应商、水电建设公司分别与租赁公司及银行组成融资操作结构。

## 清单快照（2014年口径）

| 场景 | 产品组合 |
|------|----------|
| 汽车 | 零部件供应商保理/票据；经销商票据 |
| 钢铁 | 铁矿石供应商银票预付款、存货融资；一/二级经销商融资；物流市场网络融资 |
| 家电 | 供应商商票、保理；经销商票据 |
| 油料 | 原油经销商货押、应收账款；进口商进口押汇+银票 |
| 政府供应商 | 应收账款监管；担保公司物资监管；城投应收账款保理 |
| 医疗设备 | 医院定向买方信贷；租赁公司合作保理 |
| 工程机械 | 供应商应收账款、铺货保证金；经销商票据、代理贴现；终端按揭 |
| 交通厅 | 水泥、钢材供应商及建设单位融资 |
| 电信 | 商票采购+银行免追索买入（详见专页） |
| 租赁 | 供应商+租赁公司+银行三方结构 |

## 注意

- 油料、钢铁场景的货押类产品关联 [[concepts/货押融资产品组合-静态动态质押与入库实地监管-2014文章口径]]。
