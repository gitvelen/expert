# 金融科技三功能与三类信息（2019 宋华口径）

## 天平论

任何微观金融都是一座天平。金融科技的赋能方向：

- **资产端**：底层交互客观化、末端业务自治化
- **资金端**：债项结构客观化、主体信用自治化

## 三大功能

1. 识别、搜集有用的信息
2. 过滤客户不需要的信息
3. 结构化整合信息

前提：**必须结合场景**——"不结合场景看金融科技都是没有用的"。

## 三类可采集信息

| 类型 | 说明 |
|------|------|
| 完全不可控信息 | 企业无法操纵的客观环境/行为数据 |
| 无意识行为信息 | 由企业行为自然呈现、非刻意操纵的信息 |
| 部分可控信息 | 如研发能力、评管能力，但须由第三方判定 |

三类信息齐备，才能实现资产透明与主体透明，进而呈现信用。

## 单一区块链不可行论

供应链场景复杂，须多项技术融合：IOT 与 AI 负责信息捕捉获取，移动边缘计算与云计算负责挖掘分析决策，区块链负责电子单证/票据等电子凭证流转。"严格意义上单纯的区块链+供应链金融不存在"——这是对 2019 年区块链乐观叙事的克制立场，见 [[comparisons/单一区块链不可行论与区块链赋能乐观论对比-2019口径|单一区块链不可行论与区块链赋能乐观论对比]]。
