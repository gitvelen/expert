# JIT 生产低库存与疫情期汽车业结构性供应链风险（花长春2020观点）

## 核心论点

国泰君安全球首席经济学家花长春（2020 年 3 月口径）指出：整车组装采用 JIT（及时生产）模式，天然带来零部件低库存特征；一旦上游（如湖北这一重要汽车生产基地）停产持续较长时间，汽车制造业内部即暴露出结构性供应链风险。有观点进一步认为，若各大车企在华生产延后，可能在圈球范围产生"多米诺骨牌效应"。

## 机制链条

```
JIT 整车组装 → 零部件低库存 → 对上游中断容忍度极低 → 区域性停产（湖北疫情）→ 全球组装线停摆（如现代汽车因中国零部件耗尽暂停韩国生产）→ 全球性连锁传导
```

## 意义

- 该机制在 2020 年被现代汽车停朝鲜产、苹果下调 iPhone 出货预期 10% 等事件实证。
- 与供应链库存管理一般理论呼应：JIT 效率与韧性之间存在权衡，极端冲击下低库存放大牛鞭效应（参见 [[牛鞭效应与需求变异放大]]、[[供应链库存管理四模式演进-JMI-VMI-CPFR-2020口径]]）。
- 事后看，这一风险结构比同期机构的乐观经济预测更深刻——2020 年后供应链多元化、近岸化讨论兴起即由此触发。
