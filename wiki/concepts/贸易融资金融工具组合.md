# 贸易融资金融工具组合

深圳《推动货物贸易进口高质量发展行动计划（2023—2025年）》保障措施中列明的银企合作金融工具清单：加强银企合作，推动银行业金融机构运用**关税保函、保证担保、未来货权质押、仓单质押、远期结售汇**等多种金融服务，满足企业日常经营合理资金需求，降低融资成本，帮助企业规避汇率风险。

## 各工具定位

| 工具 | 功能 |
|---|---|
| 关税保函 | 缓解进口环节关税资金占用 |
| 保证担保 | 增信支持 |
| 未来货权质押 | 以在途货物货权为押品，覆盖进口在途周期 |
| 仓单质押 | 以仓储货物仓单融资，与冷链/保税仓场景结合 |
| 远期结售汇 | 汇率风险对冲 |
