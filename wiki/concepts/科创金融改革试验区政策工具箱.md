# 科创金融改革试验区政策工具箱

指济南科创金融改革试验区通过财政奖补构建的多层次金融扶持政策组合，集中体现于 [[济南市建设科创金融改革试验区加快现代金融产业发展若干扶持政策]]。

## 工具箱构成

| 类别 | 代表性工具 | 力度 |
|---|---|---|
| 金融机构落户 | 法人金融机构按实缴注册资本分档补助 | 最高 1.2 亿元 |
| 私募股权 | 设立/募资按 1% 补助；投早投小按投资额 5% 补助 | 最高 2000 万元 |
| 地方金融组织 | 注册资本分档补助（含商业保理、融资租赁） | 最高 1000 万元 |
| 企业上市 | 辅导备案/受理/上市分阶段补助 | 累计最高 1000 万元 |
| 金融科技 | 落户补助；供应链金融服务平台共建补助 | 300 万 / 100 万 |
| 风险分担 | "政银保"贷款保证保险，财政承担 20% | — |
| 融资担保 | 500 万以下科创小微担保费率 ≤1%，按 8‰ 补贴 | 见 [[政府性融资担保降费机制]] |
| 科创信贷 | 新增科创贷款余额 0.2‰ 补助 | 上限 200 万元/年 |
| 知识产权 | 交易转化按交易额 1%/2% 补助转让方/购买方 | 单项 ≤20 万元 |
| 标准制定 | 国际/国家/地方标准一次性补助 | 100/30/20 万元 |
| 金融人才 | 高管安家补助 + 工作性补助 | 20 万 + 每年 12 万×3 年 |

## 机制设计特征

1. **就高不重复**：同一机构不得就相同项目重复申请补助。
2. **5:5 市区分担**：市本级与纳税区县按 5:5 共同承担。
3. **实质重于形式**：拆分设立、非货币增资不在奖补范围，防范政策套利。
4. **绿色门槛**：违规/骗补取消资格、追回资金、依法追责。
