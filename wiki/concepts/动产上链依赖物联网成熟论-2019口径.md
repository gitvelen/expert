# 动产上链依赖物联网成熟论（2019 口径）

2019 年链圈对"供应链资产上链"瓶颈的清醒判断，出自《区块链技术重塑供应链金融》第四节。

## 论点要点

1. **资产分类上链难度**：供应链金融三类资产中，应收账款、预付账款"天然可以数字化"，收付双方可在链上登记互认形成链上契约，具备链上数字化交易条件（需出资方贸易真实性审核）。
2. **动产的根本困难**：动产为实物，规格、品质、状态多样，真实性与价值难以准确评估确认——这正是伪造仓单骗贷案件频发的原因，且该问题在区块链出现之前即已存在。
3. **链上效力从属于物理占有**：链上完成的动产质押即使合法转移流通，一旦发生质权保全，"真正的价值并非来自于链上，而是来自于对物理世界质物的占有"。
4. **结论**：物理物品与链上资产绑定的方案"目前来看并没有十分有效的方法"，**区块链自身不能解决此问题**，需物联网技术在实物信息采集、评估、监控、管控方面成熟后，方能产生杀手级应用。

## 定位与关联

- 该论点与 [[区块链溯源上链前数据真实性问题]]（上链前数据真实性问题）、宋华"四大局限"、段伟常"联系论"一脉相承，是"区块链不能自证物理真实性"共识的一个 2019 年独立表述。
- 与 [[物联网监管仓与云监管平台-2019高达口径]]、155 号文物联网条款构成问题—方案—政策呼应链。
- 证据强度：一般公众号评论转载层级，但为行业长期共识性判断。
