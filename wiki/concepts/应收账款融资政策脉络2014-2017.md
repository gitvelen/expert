# 应收账款融资政策脉络（2014-2017）

据郇公弟梳理（本部分为可核实的客观政策罗列，证据较强），2014-2017 年“应收账款/应收账款融资/应收账款资产证券化”在政策文件中出现频率极高：

| 时间 | 文件/事件 | 要点 |
|---|---|---|
| 2014-03 | 证监会全面推动 ABS 业务 | 应收账款证券化，落实“用好增量、盘活存量” |
| 2015-04 | 国资委《关于进一步做好中央企业增收节支有关事项的通知》 | “加大资本运作力度，推动资产证券化” |
| 2015-05 | 国资委《关于中央企业开展两金占用专项清理工作有关事项的通知》 | 央企应收账款占总资产不超过 50%，年末数不得高于年初数 |
| 2016-02 | 八部委《关于金融支持工业稳增长调结构增效益的若干意见》 | 扩大应收账款质押融资、加强动产融资统一登记、推进应收账款证券化 |
| 2016-10 | 国务院《关于积极稳妥降低企业杠杆率的意见》 | 按“真实出售、破产隔离”原则开展应收账款、租赁债权等 ABS |
| 2016-10 | 发改委《促进民间投资健康发展若干政策措施》 | 动产质押统一登记立法、全国集中统一登记系统 |
| 2017-05 | 七部门《小微企业应收账款融资专项行动工作方案(2017-2019年)》 | 普及融资知识、政府采购项下融资、核心企业支持在线应收账款融资、健全登记公示制度 |
| 2017-11 | 国办发〔2017〕84号文 + 央行修订《应收账款质押登记办法》 | 现代供应链、供应链金融服务平台、与人民银行征信中心应收账款融资服务平台对接、线上应收账款融资 |
