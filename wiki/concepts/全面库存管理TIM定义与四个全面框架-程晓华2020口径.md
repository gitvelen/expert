# 全面库存管理（TIM）定义与"四个全面"框架（程晓华2020口径）

## 正式定义

> 全面库存管理，即 TIM（Total Inventory Management），是指从库存角度全面透视企业供应链管理与 ERP/IT 问题。它是一套审核、设计并持续改善企业供应链管理的方法论。

（2020 年口径，程晓华首次正式给出；概念于 2008 年首次提出，2011 年收录入《制造业库存控制技巧》第 2 版。）

## 根本目的链条

降低呆滞库存（E&O, Excess & Obsolete）→ 提高及时交货率（OTD, On-time Delivery）→ 提高库存周转率（ITO, Inventory Turn-over）→ 提高现金周转速度（C2C, Cash to Cash）→ 提高股东投资回报率（ROI, Return of Investment）。

## 核心价值观与口号

- 客户至上（OTDD）、信守承诺（OTDC）、现金为王（C2C）、持续改善（E&O）
- 口号："（库存）转就是赚（钱）"；"Fast and Fast！天下武功，唯快不破！"
- 愿景：No Surprise；使命："我们是驱动者。"

## 理论基座

1. **SCOR 模型**：供应链五大要素——计划（Plan）、采购（Buy）、生产（Make）、交付（Deliver）、退货（Return）——谈的都是库存问题；各节点企业都是"玩库存的"，整个需求链、供应链本质是一个**库存链**。
2. **PLC 产品生命周期模型**：新产品导入（NPI）、量产（MP，含爬坡/成熟/衰退）、产品生命周期结束（EOL），实质也都是库存问题。

## 突出特点："四个全面"

1. **全参与**：含客户、供应商在内的供应链合作伙伴与企业内部全员参与；
2. **全意识**："一切都是库存"——销售及应收（AR）、采购及应付（AP）、生产及交付（Delivery）都是库存问题；
3. **全流程**：库存存在于计划、采购、生产、交付、退货各流程之中，产品生命周期管理过程也是库存管理过程；
4. **全考核**：企业经营的最终结果可能就是库存。

TIM 将纷繁复杂的传统供应链管理理论简单化、模型化，以库存为核心审核、设计、优化并持续改善供应链的流程（Process）、组织（People）、绩效（Performance）及例会（Meetings）（"3P+M"）。

## TIM 10 个流程（TIM 10 Processes）

| 流程 | 含义 |
|------|------|
| ORG | 供应链管理组织架构及其管控体系 |
| ITO | 库存规划与监控 |
| S&OP | 客户与产品分类及销售与运作计划管理 |
| PLC | 新产品导入、产品生命周期结束流程 |
| MRP | 物料计划、设计更改与 MRP 运算流程 |
| T&C | 供应商认证与合同履行 |
| OTD | 执行采购与交付管控流程 |
| OTD | 生产计划与控制流程 |
| MRB | 物料评审 |
| CC | 循环盘点 |

## 适用边界与知识库定位

TIM 是**制造业运营管理视角**的方法论，强调整体运营改善；知识库的供应链金融视角更关注库存作为融资标的的可控性。二者互补但不宜混同——本页限定在制造业运营管理语境。TIM 与存货质押类供应链金融的结合点（如 TIM002 库龄/呆滞分析作贷后监控工具、ITO/C2C 指标与"物的信用"评估的衔接）为开放探讨方向。证据强度：作者自述口径（2020），客户案例缺乏第三方验证。
