# "战时"放款绿色通道机制

2020年疫情防控期间金融机构执行[[疫情防控专项再贷款]]的应急模式：开通绿色通道、简化审批流程、及时高效放款。

## 典型速度记录

| 案例 | 审批时长 | 说明 |
|---|---|---|
| [[上海五色石]] | 8小时 | 工行绿色通道，首笔200万元 |
| [[江苏爱特福84]] | 1天 | 交行江苏省分行与淮安分行同步审批 |
| [[联影医疗]] | 1天授信批复 | 中行以电话会议敲定融资方案 |
| [[际华集团]] | 1.5天 | 邮储银行在无既往信贷合作背景下完成 |
| [[广东一方制药]] | 48小时全流程 | 国开行广东分行"急事急办、特事特办" |
| [[宁波凯福莱]] | 2天 | 含开户、授信申报和贷款审批全流程 |

## 内部张力

极速审批（如对成立和经营时间较短的国药卫勤放款）与银行常规风控要求之间存在天然张力，报道未说明风险控制如何平衡。这一点与2019年监管政策严防虚构融资的取向（如[[银保监办发2019年155号文]]）形成对照。
