# AHP与模糊综合评价组合评价法（2011口径）

针对成熟度指标中定性指标（如目标一致性、企业文化兼容性）难以量化的问题，2011 年该文建议采用 AHP（层次分析法）+ 模糊综合评价的多层次组合评价模型：

1. 建立目标指标评价体系；
2. AHP 确定权重：1–9 标度法构造判断矩阵，一致性检验采用 CR = CI/RI，CR < 0.1 视为满意一致（n=1~9 时 RI = 0, 0, 0.58, 0.94, 1.12, 1.24, 1.32, 1.41, 1.46）；
3. 建立模糊评语集 V =（优、良、中、差）；
4. 专家调查法/德尔菲法确定隶属度矩阵 R；
5. 模糊矩阵运算逐级合成隶属向量；
6. 按赋分 Z =（10, 7, 5, 3）加权加总得最终测评值 M。

**证据强度**：方法论惯例，无实证验证数据；属定性定量结合的通行做法，非本文独创。
