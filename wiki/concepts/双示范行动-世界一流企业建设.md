# “双示范”行动与世界一流企业建设

“双示范”行动指国务院国资委 2023 年组织中央企业和地方国资委同步开展的“创建世界一流示范企业 + 创建世界一流专精特新示范企业”行动，是深化“创建示范、管理提升、价值创造、品牌引领”**四个专项行动**的重要内容。

## 目标定位

- 既在总体规模效益上创建世界一流企业，也在细分行业或专精特新领域探索世界一流水平。
- 目标是培育“专精特新”“小巨人”和单项冠军企业，在不同领域形成**百家以上不同层级典型示范企业**。
- 2023 年官方工作目标（彭华岗，2023-01-17 国新办发布会）：力争 **10 家以上央企率先成为行业公认的世界一流企业**。
- 张玉卓（2023 年 2 月《学习时报》署名文章）：强化对标提升和分类施策，**分行业建立可量化可操作的世界一流企业评价体系**，建设一批主导全球产业链供应链价值链的龙头企业。

## 演进脉络

| 阶段 | 内容 |
|---|---|
| 2018 | 遴选 11 家“世界一流”试点中央企业（航天科技、中国石油、国家电网等） |
| 2023-01-17 | 彭华岗发布 2023 年世界一流企业建设目标 |
| 2023-02 | 张玉卓署名文章：评价体系、国资央企云体系/大数据体系/司库体系建设，适时组建新的国有资本投资运营公司 |
| 2023-02-23 | 张玉卓：央企科技创行驶“三个突破”（“卡脖子”攻关、研发投入产出效率、创新体系效能） |
| 2023-03-03 | 价值创造行动动员部署（见 [[央企价值创造行动2023]]） |
| 2023-03-16 | 印发“双示范”名单：7 家地方国企 + 200 家专精特新示范企业，首次将示范企业扩容至地方国企 |

## 动态调整机制

国资委将“强化跟踪指导，适时总结评估，动态调整示范企业名单”，名单并非固定，后续变动需持续跟踪（见 [[查询-207家双示范企业动态调整与世界一流企业建设进展]]）。
