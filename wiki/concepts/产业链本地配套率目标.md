# 产业链本地配套率量化目标

桂政办发〔2020〕43 号文中最可核查的量化指标集合：

| 产业链/领域 | 目标 |
|---|---|
| 汽车零部件本地配套率 | 提高到 70% |
| 工程机械本地配套率 | 提高到 60% |
| 内燃机本地配套率 | 提高到 50% |
| 手机产业本地一级配套率 | 提高到 50% |
| 新型显示器本地一级配套率 | 提高到 50% |
| 电声产品本地一级配套率 | 提高到 60% |
| 新能源汽车本地配套率 | 提高到 60% |
| 5G 设备本地一级配套率 | 提高到 30% |
| 高端装备制造本地配套率 | 提高到 30% |
| 前沿新材料本地转化率 | 提高到 50% |
| 电解铜本地转化率 | 力争提高到 60% |
| 电解铝本地转化率 | 力争提高到 70% |

这些目标为后评估（见 [[queries/查询-广西43号文2022年底成链目标与配套率达标情况]]）提供了明确基准；但同时 50–70% 的目标与广西产业链配套基础薄弱的现实之间存在执行风险。
