# 渠道数据融资 N+N 模式（文沥 2017 口径）

[[文沥]] 2017 年模式：将渠道数据打包为融资依据的"N+N"融资服务（品牌商+N 家经销商+N 家资金方），品牌商减少赊销、货款受托支付回品牌商。落地情况见 [[查询-文沥N加N渠道融资2018年后落地与经营结局核验]]；快照数据见 [[2017年文沥DQM与N加N渠道融资模式快照-企业自述口径]]（企业自述，弱）。
