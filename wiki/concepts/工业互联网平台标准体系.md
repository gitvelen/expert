# 工业互联网平台标准体系

指由工业和信息化部持续推进、以标准化加速工业互联网平台规模化普及的标准工作框架（2023 年口径）。

## "选平台 / 建平台"双轨逻辑

- **需求方轨道（选平台）**：以 [[工业互联网平台领域国家标准GB-T-42562-42568-42569-2023|GB/T 42562-2023《工业互联网平台选型要求》]] 为代表，为企业评价工业互联网平台赋能水平、选择适宜平台提供依据。
- **供给方轨道（建平台）**：以 GB/T 42568-2023（微服务参考框架）与 GB/T 42569-2023（开放 API 功能要求）为代表，指导工业微服务与应用接口开发，加速工业知识模型化沉淀与平台互联互通，为构建平台生态奠定基础。

## 目标与执行

以标准引领企业技术进步、管理变革、模式创新，提升企业核心竞争力；由工业和信息化部信息技术发展司指导 TC28 及起草单位进行标准研制与宣贯，最终服务于新型工业化技术底座建设。

## 与供应链金融的关联（延伸视角，知识库立场）

工业互联网平台是产业数字金融的技术底座语境之一：平台沉淀的工业数据与互联互通能力，是 [[可信产业数字底座-66云链口径]]、产业数字资产确权等供应链金融数字化路径的行业基础设施背景。此为知识库的关联性解读，非来源原文内容。
