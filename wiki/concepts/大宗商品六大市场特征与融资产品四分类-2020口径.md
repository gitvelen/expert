# 大宗商品六大市场特征与融资产品四分类（2020口径）

## 六大市场特征

广义大宗商品指可进入流通领域但非零售环节、用于工农业生产与消费的大批量买卖物质商品（原油、有色金属、农产品、铁矿石、煤炭等）。市场特征为：

1. 供需量大
2. 价格波动大
3. 标准化高
4. 易存储和运输
5. 影响国计民生
6. 金融属性强

## 融资产品四分类（2020口径）

| 类别 | 具体方式 |
|------|----------|
| 主体信用类 | 核心厂商担保、回购、调剂销售、保购 |
| 存货担保类 | 动产抵押、动产质押、仓单质押 |
| 权益质押类 | 应收账款质押、保理、付款凭证质押 |
| 组合管控类 | 购销通、担保+动产+债权组合、商业数据信息验证 |

## 金融需求二分

- **融资需求**：动机包括锁定价格、稳定库存、获取返利、实现收入、抢占市场；主体含生产型与贸易型企业，以贸易型企业为主。
- **结算需求**：交易规模大、笔数多、频率高，对资金使用效率与路径要求高，需配套专业银行账户结算体系与现金管理类产品。
