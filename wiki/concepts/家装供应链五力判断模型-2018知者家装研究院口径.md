# 家装供应链五力判断模型（2018知者家装研究院口径）

**五力判断模型**是知者家装研究院于 2018 年提出的、用于检验一家家装企业供应链能力强弱的评估框架（2018 媒体观点口径，证据强度为弱，无实证数据支撑）。

## 五力内容

| 力 | 含义 |
|---|---|
| A 需求数字化处理能力 | 对需求端信息的分析处理能力，建立需求分析模型，个性化需求输入、最大程度标准化输出 |
| B 资源有效组织力 | 厂商、品牌、价格、物流、服务等要素高效组织，实现可持续双赢；通过 F2C、标准化规模集采降本，最终建立 C2F 柔性供应链 |
| C 区域单量密度力 | 一定范围内的有效单量密度，实现高效配送：每次配送量饱和且次数少 |
| D 落地服务力 | 测量、安装和售后（自做或与第三方合作），直接影响工期与质量 |
| E 信息化能力 | 装企、厂商、工地、服务商及物流配送的信息化协调与信息流交互效率，快速达成工期标准 |

## 配套的三种能力建设建议（本文作者口径）

1. **IT能力**：把人、物、场数字化、标准化，通过云计算智能匹配调度资源；即使缺乏云计算基因，也须在数字化、信息化领域跟上时代。
2. **上下游资源整合能力**：整合行业优质资源，或成为有被整合价值的优质资源；并非每个企业都适合成为整合者，细分领域做到极致亦可。
3. **内部管理能力**：信息化/数字化管理，现代人力资源、财务、运营管理体系。

## F2C→C2F 转型路径

借电商从大众商品向奢侈品渗透的类比，主张传统装企先以 **F2C 集采**突破规模化短板，同时加强数字化基础能力建设，长远实现 **C2F 柔性供应链**转型。此路径为 2018 年推演性判断，无实证。
