# 供应链金融资源驱动三要素论（2019 口径）

## 论点内容

2019 年从业者 PM奇异果提出：供应链金融的本质是**通过信用关系扭转提升资金效率**，作为信用结构服务工具，其积累过程属资源驱动型，因此供应链金融科技产品的核心竞争力与商业模式和系统产品"没有绝对关系"，而是取决于三要素：

1. **客户资源**（获客能力，"重要的核心竞争力，没有之一"）
   - 核心企业资源：稀缺、供不应求，需强关联资源与后端维护实力；N+1、N+1+N、N+N+N 均离不开核心企业支持。文中以"XX云链"（特征吻合 [[中企云链]]，原文匿名）为例说明强资源驱动。
   - 小微企业资源：传统金融机构获客投入产出比低，给互联网金融留出空间。
   - 金融机构资源：对接资金方数量反映平台能力，如 2019 年流行的 API Bank 模式——接入资金方越多，资金路由与定价优势越大。
2. **服务态度**：对客户的门槛设定（哪些坚决不做）与留存能力（核心企业靠专门团队项目化服务，小微企业靠资金成本、审批效率等产品硬实力）。
3. **资金成本**：分层结构——银行（牌照类，成本最低）→ 保理、小贷（准持牌）→ P2P、高利贷（2019 年口径，P2P 后被清退）。"没有融不到的钱，只有能否接受的成本"。

## 内部张力

作者同时认为：三件套（区块链/大数据/风控模型）虽非业务合作必要条件，但在任一细分产品上形成"不可替代性"并巩固优势即可生存——技术无用论与技术护城河论并存，未调和。
