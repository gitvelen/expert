# 商业保理新模式谱系（2017口径）

据《中国商业保理行业发展报告2016》（2017 年口径），中国商业保理与银行保理、电子商务、互联网金融、资产证券化呈融合创新趋势，在不同细分领域涌现的新模式包括：

| 模式 | 要点 |
|------|------|
| 双保理 / 合作保理 | 商业保理企业间合作开始形成，国内双保理、合作保理项目成功实施 |
| 再保理 | 保理资产的再转让与风险分散 |
| 联合保理 | 多家保理商共同承接业务 |
| 反向保理 | 依附核心企业信用服务上游供应商，2017 年行业报告称"反向保理受青睐"，佐证见 [[反向保理定义与信用替代机制-2016石磊口径]] |
| 在线保理 | 依托在线交易数据评估支付能力与风险，使无固定资产可抵押的中小企业获得保理融资；在线交易同时推动中小企业经营规范化 |
| 保理资产证券化 | 2016 年调研 51 家企业中 24 家再融资企业的主要融资渠道，呼应 [[应收账款ABS非标转标逻辑-2017口径]] |

## 行业特点背景

产业金融化推动拥有金融背景与产业背景的大企业涌入；与互联网结合顺应供应链金融对交易过程可视化的要求，形成各细分行业的保理模式与创新产品。
