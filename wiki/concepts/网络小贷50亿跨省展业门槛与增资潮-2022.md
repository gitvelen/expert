# 网络小贷 50 亿跨省展业门槛与增资潮（2022）

指 2020 年《网络小额贷款业务管理暂行办法（征求意见稿）》确立“跨省经营网络小贷注册资本不低于 50 亿元一次性实缴”门槛后，头部平台在 2021–2022 年出现的“保一撤多 + 增资达标”双线动作：一边注销/整合多余小贷牌照，一边集中增资旗下一家小贷公司至 50 亿以上，以保留全国性展业资格。

## 50 亿门槛俱乐部（10 家名单，《国际金融报》2022 统计口径）

| 公司 | 注册资本 |
|---|---|
| 重庆蚂蚁小微小贷 | 120 亿 |
| 财付通小贷（腾讯） | 100 亿（2022-06 第四次增资，自 50 亿） |
| 中融小贷（字节跳动） | 90 亿（2022-04 自 50 亿） |
| 南宁金通小贷 | 89.89 亿 |
| 重庆度小满小贷 | 74 亿 |
| 重庆星雨小贷（苏宁） | 60 亿 |
| 京东盛际小贷 | 50 亿（2021-08 由 16 亿→30 亿→50 亿） |
| 重庆美团三快小贷 | 50 亿 |
| 中新（黑龙江）互联网小贷 | 50 亿 |
| 三六零小贷 | 50 亿（2022 年两轮增资 5 亿→50 亿） |

## 未达门槛的关联方

滴滴金融、陆金所、天星数科、新浪金融、国美金融、携程金融旗下网络小贷未达 50 亿门槛，但其母公司/关联公司均已参股持牌消费金融公司，存在业务转承接的可能（传闻，未证实）。

## 牌照整合案例（2022）

- 重庆万达小贷：注销备案，万达旗下网络小贷从 3 家变 2 家；
- 湖南普惠小贷（平安普惠）：2022-05-23 注销全国性网络小贷牌照；
- 京汇小贷（京东）：2022-06-13 北京金融监管局取消试点资格，京东科技称系主动申请整合，"牌照主体最终将仅保留一家"；
- 全年约 30 家地方小贷被注销，江苏、江西、安徽、内蒙古、湖南、河南等地金管局披露取消试点名单。

## 增资三缘由

抢全国互联网小贷牌照的入门准备；助贷渠道承压下的注册资本储备与调剂；夯实合规与业务可持续性。
