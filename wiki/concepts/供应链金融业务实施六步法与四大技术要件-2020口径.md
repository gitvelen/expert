# 供应链金融业务实施六步法与四大技术要件（2020口径）

来源：[[sources/4-news--7-03-行业研究--4-2020--20-供应链金融业务实施路径深度解析供应链融资--msqts5]]（2020）。

## 本质与产品四分类

供应链金融的本质是**"加速"与"放大"**：对供应链运作中形成的存货、应收、预付等流动性较差的流动资产进行流动性加速与融资能力放大。操作方式是以确定性未来现金流为直接还款来源，以"自偿"闭合性资金运作模式为主要风控手段。

产品四类型：
1. 短期存货融资类（有存货周期、自偿性好的存货）
2. 短期应收账款融资类（有应收周期、自偿性好的应收账款）
3. 短期预付款融资类（有预付周期、自偿性好的预付款）
4. 短期信用融资类（对信用良好的供应链战略伙伴、基于实际发生的业务）

## 四大技术要件（服务提供者必须具备）

1. 供应链金融产品方案设计技术
2. 风险精算与管理技术
3. 评估标的物的产业运作技术
4. 标的物产权控制技术（以仓储和管理信息系统为支撑的货控技术、信用评估技术）

## 四大支撑系统

1. 产权控制系统
2. 资金支持与结算系统
3. 交易流程支持系统
4. 风险管理系统

## 六大实施步骤

1. 识别并定义供应链金融业务场景
2. 供应链模式优化设计
3. 供应链金融产品设计
4. 供应链金融支撑系统设计
5. 供应链金融平台运营系统设计
6. 供应链金融全面风险管理系统设计
