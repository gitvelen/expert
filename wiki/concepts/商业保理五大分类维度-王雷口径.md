# 商业保理五大分类维度（王雷口径，2019）

出自王雷《供应链金融》（经贸易金融公众号 2019-08-26 转载）。核心主张：国内商业保理可按五个维度完备分类，**任一业务均为各维度取值的组合**（如"有追索 + 暗保理 + 池保理 + 短期"）。

## 维度一：追索权 / 无追索权

- **追索权保理**：买方到期未付款或未足额付款时，保理公司有权要求卖方**无条件偿付**保理预付款。
- **无追索权保理**：保理公司提供账款管理、预付款和信用风险担保；因买方信用风险致不能足额支付时，保理公司**在其为买方核定的信用风险担保额度内**承担全额付款责任。

> 注意：这是"额度内承担付款责任"的国内实操口径，与严格意义的真买断（卖断）有差别，参见 [[concepts/卖断式保理与国内不做卖断式保理的原因]] 与 [[queries/查询-卖断式保理国内罕见主因之争]]。

## 维度二：明保理 / 暗保理

- **明保理**：按保理公司认可方式立即向买方发送书面转让通知。
- **暗保理**：不立即通知买方，但卖方须向保理公司提交书面通知，保理公司**可随时向买方发出**。通知效力问题参见 [[concepts/保理债权转让通知效力认定规则]]。

## 维度三：逐笔保理 / 池保理

- **逐笔保理**：预付款支用、偿付与受让应收账款逐笔对应。
- **池保理**：对受让应收账款实行动态余额管理，在可支用额度内向卖方提供一笔或多笔固定期限预付款。与 [[concepts/循环池保理]] 同义合并。

## 维度四：短期 / 中长期保理

- **短期保理**：预付款期限最长不超过 **1 年**。
- **中长期保理**：期限超过 1 年，**原则最长不超过 5 年（含）**——产品设计中可引用的期限红线口径。

## 维度五：按特定需求的五类专项保理

| 类型 | 要点 |
|---|---|
| 信用保险保理 | 三方"赔款转让协议"；拒赔时由卖方偿付预付款（保留对卖方追索），见 [[concepts/融信达信用保险保理模式]] |
| 工程保理 | 受让工程承包商符合条件的工程应收账款，见 [[concepts/工程保理]] |
| 融资租赁保理 | 以租赁公司为卖方受让未到期应收租金，见 [[concepts/融资租赁保理]] |
| 定向保理 | 与核心企业合作受让供应商对核心企业的全部应收账款（反向保理 / "1+N"原型），见 [[concepts/供应链金融三大主导模式2019]] |
| 服务保理 | 仅提供账款管理、不转让债权，见 [[concepts/服务保理]] |

## 口径定位

本分类与 [[concepts/商业保理十大业务模式2018]]（2018 十大模式）、12 种商业保理模式（2019，同出贸易金融）构成口径谱系，三套口径对照见 [[comparisons/商业保理分类口径对比2018-2019]]。证据强度：书籍口径，定义性内容、无案例佐证。
