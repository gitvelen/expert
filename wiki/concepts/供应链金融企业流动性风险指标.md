# 供应链金融企业流动性风险识别指标

从 2018 年瑞茂通案例中提炼的识别指标集，可用于评估“供应链 + 保理”类企业的资金链脆弱性。

## 指标集

| 指标 | 危险信号 | 瑞茂通 2018 年读数 |
|---|---|---|
| 保理放款/回笼净额 | 急剧净回笼，或被解读为风险前置预警 | 前三季放款 37 亿 vs 回笼 61 亿，净流入 24 亿 |
| 对外担保余额占净资产比 | 超过 100% | 177.43%（子公司担保）+ 32.12%（关联/参股担保） |
| 流动负债占总负债比 | 快速上升 | 79% → 93.66% |
| 短期债务现金覆盖率 | 低于 50% | 约 20%（60.69 亿短期债务 vs 约 10 亿可动用资金） |
| 速动比率（剔除应收保理款） | 显著低于账面值 | 1.1 → 剔除 65 亿应收保理款后约 0.63 |
| 受限货币资金占比 | 保证金类受限比例高 | 账面 31.4 亿中 19.53 亿受限 |
| 大股东质押率 | 高质押 + 大股东借款回笼 | 86.5% |
| 融资渠道切换 | 转向 ABS/ABN、票据融资、上游占款 | 10 亿元应收账款 ABS；应付票据及应付账款合计 44 亿，较 2016 年末翻倍 |
| 单项重大应收账款认定标准 | 放宽 = 审计样本减少、风险揭示弱化 | 500 万/100 万 → 3000 万/500 万 |

## 使用注意

- 单一指标异常不足以定论，需组合判断（如“净回笼 + 高担保 + 高质押 + 渠道切换”同时出现）。
- 保理业务常在子公司/孙公司层级发生，母公司通过其他应收款向子公司输送资金（瑞茂通 2018 中报达 65 亿），母子风险捆绑，“一荣俱荣，一损俱损”。
- 对比参照：同业飞马国际速动比率 1.24、[[entities/怡亚通]] 0.81。
