# 商业保理监管指标

《天津市商业保理公司监督管理暂行办法》第二十八条规定的四项硬性监管要求（量化数据为该文件核心内容）：

| 监管指标 | 限额/要求 |
|---|---|
| 受让同一债务人的应收账款 / 风险资产总额 | ≤ 50% |
| 受让关联企业为债务人的应收账款 / 风险资产总额 | ≤ 40% |
| 逾期90天未收回或未实现的保理融资款 | 纳入不良资产管理 |
| 计提风险准备金 / 融资保理业务期末余额 | ≥ 1% |
| 风险资产 / 净资产 | ≤ 10倍 |

## 关键定义

- **风险资产**：企业总资产减去现金、银行存款、国债后的剩余资产总额。
- **主要股东**：所在商业保理公司出资额最高股东。

## 适用范围与时点

- 指标仅针对**商业保理公司**，不适用于供应链金融其他业态。
- **存量公司**（办法印发前设立）：不符合集中度（50%/40%）与杠杆（10倍）要求的，可在银保监会清理整顿期限内达标；**新增公司**须即时满足。
- 指标源自银保监办发〔2019〕205号文的统一要求，天津办法予以地方化落实。

## 监管意图

针对“名为保理实为借贷”的防控还体现为：虚构应收账款放贷的认定（第26条），以及年度内10次以上保理合同未被法院认定为商业保理法律关系列为重大风险（第43条）。
