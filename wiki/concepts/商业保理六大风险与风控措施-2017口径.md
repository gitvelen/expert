# 商业保理六大风险与对应风控措施（2017 口径）

2017 年综述文章中归纳的商业保理风险清单及一一对应的风控措施，属通用风控框架知识。

| 风险 | 内涵 | 对应控制措施 |
|---|---|---|
| 交易风险 | 履约风险：卖方无力完成合同、买方无力付款 | 历史贸易考察，多方凭证交叉检查 |
| 产业风险 | 产业衰退导致买方偿付能力恶化的信用风险 | 行业准入与买方信用考察 |
| 法律风险 | 贸易合同、债权转让瑕疵、债权转让通知等 | 法律风险管理贯彻业务全流程 |
| 道德风险 | 客户欺诈、员工道德瑕疵 | 对员工、税务、工商、银行全面调查 |
| 信用风险 | 买卖双方的信用风险 | 专业尽职调查，全面审核买卖双方信用 |
| 操作风险 | 保理商内部操作层面风险 | 制度化管理、规范操作流程、信息化管理 |

## 使用提示

该框架为 2017 年科普口径，条目化程度较高；落地产品设计时应结合贸易背景真实性核验与货权/债权控制等更深层的风控要求（参见 [[保理定义与分类框架]]），不能仅停留于清单式管理。
