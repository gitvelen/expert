# 互联网保理ABS双池循环结构（2016京东京保贝首单口径）

互联网保理资产证券化指以互联网平台保理债权为基础资产的ABS。2016年5月京东金融与华泰资管合作发行国内首单（上交所挂牌，20亿元），其披露的结构要点如下。

## 交易结构快照（发行人口径）

| 项目 | 内容 |
|---|---|
| 产品 | 京东金融-华泰资管2016年1期保理合同债权ABS |
| 底层资产 | [[concepts/京保贝]] 保理合同债权 |
| 规模 | 20亿元 |
| 管理人 | 华泰证券（上海）资产管理有限公司 |
| 优先A级 | 72%（14.4亿元），AAA评级 |
| 优先B级 | 27.95%（5.59亿元），AA评级 |
| 次级 | 0.05%（100万元），原始权益人关联方认购 |
| 优先1级利率 | 年化 4.1% |
| 优先2级利率 | 年化 5.9% |
| 期限结构 | 2年循环期 + 3个月摊还期 |

## 两项关键创新（保理业务负责人骆珞自述）

1. **全自动放款**：放款之前价值形成的全过程无任何人为参与，相较传统金融机构认可的保理资产是"最难的一关"。
2. **双池支撑**：在传统SPV结构之上增加应收账款池与资金池两个池，配合前期结构化处理，支撑"循环期+摊还期"的循环购买设计。

## 批判性注记与风险要点

- **风险留存极薄**：次级仅0.05%且由关联方自持，原始权益人风险自留与利益绑定非常有限。
- **贸易背景穿透**：保理ABS普遍需应对底层交易/贸易背景不清晰的问题（与本项目"贸易背景真实性"工作论点直接相关）。
- **买方确权**：应收账款确权在法律层面存在难点。
- **增信措施**：本单未见外部增信披露。
- 来源中"ABS将成为常态"的判断属发行人预期，兑现情况另见 [[queries/查询-互联网保理ABS常态化预期与2016年后实际发行考证]]。

## 证据强度

结构数据来自发行人公告与负责人专访，属**事实快照（发行人口径）**，经一般新闻（第一财经）转述；创新价值与"最难点已突破"的自我评价属观点。
