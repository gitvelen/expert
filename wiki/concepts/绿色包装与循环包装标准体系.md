# 绿色包装与循环包装标准体系

指围绕快递、电商、生鲜、外卖等物流场景，由国家标准、行业标准与团体标准构成的绿色/循环包装规范体系。2022年"全球数字物流与绿色供应链大会"（温州）曾集中宣贯并征求意见的10项标准清单如下（原文保留，出处为 [[4-news--7-01-政策合规--4-2022--24-关于举办全球数字物流与绿色供应链大会的通知-观点--berc55]]）：

| 层级 | 制定机构 | 标准名称 |
|---|---|---|
| 国家标准 | 国家邮政局 | 《快递循环包装箱》 |
| 行业标准 | 国家邮政局 | 《寄递包装射频识别（RFID）应用技术要求》 |
| 行业标准 | 商务部 | 《同城物流配送服务规范》 |
| 行业标准 | 商务部 | 《生鲜电商物流包装规范》 |
| 行业标准 | 商务部 | 《电子商务物流绿色包装技术和管理规范》 |
| 行业标准 | 商务部 | 《生鲜电商供应链管理指南》 |
| 团体标准 | 中国商业联合会 | 《外卖智能取餐柜》 |
| 团体标准 | 中国商业联合会 | 《大家电绿色包装循环共用管理要求》 |
| 团体标准 | 中国商业联合会 | 《物流包装循环使用管理要求》 |
| 团体标准 | 中国商业联合会 | 《城市绿色货运配送评价指标》 |

## 意义

- 覆盖包装循环共用、RFID 智能识别、绿色配送评价指标等环节，是物流绿色化落地的标准化基础。
- 与"双碳"目标下的供应链脱碳议题呼应（见 [[供应链脱碳]]、[[双碳目标下的绿色金融体系]]）。
- 标准后续正式发布与实施情况待跟踪（见 [[查询-全球数字物流与绿色供应链大会后续与标准发布情况]]）。
