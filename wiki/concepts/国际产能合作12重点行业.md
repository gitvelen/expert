# 国际产能合作12个重点行业

[[国发2015-30号指导意见]] 确定的重点行业，分类实施、有序推进，近期以亚洲周边国家和非洲国家为主要方向：

| 行业 | 关键措施（严格按文件归属） |
|------|------|
| 钢铁、有色 | 成套设备出口、投资、收购、承包工程，境外建钢铁生产基地；境外矿产资源开发延伸铜、铝、铅、锌冶炼深加工 |
| 建材 | 投资为主，建设水泥、平板玻璃、建筑卫生陶瓷、新型建材、新型房屋生产线 |
| 铁路 | 周边铁路互联互通、非洲铁路网络、高铁项目一揽子合作；轨道交通装备整合 |
| 电力 | 火电水电装备出口、核电磋商、风电光伏投资、境外电网投资运营 |
| 化工 | 石化、化肥、农药、轮胎、煤化工生产线，延伸下游精深加工 |
| 轻纺 | 境外棉纺、化纤、家电、食品加工项目，集群式加工基地 |
| 汽车 | 发展中国家设厂组装、欧美设研发中心，带动自主品牌整车零部件出口 |
| 通信 | 巩固传统市场、开拓发达国家市场；电信运营和互联网企业兼并收购“走出去” |
| 工程机械 | 农机、石油装备、机床工具全球网络；**积极开展融资租赁等业务**（与 [[融资租赁全国推广2015]] 相关） |
| 航空航天 | 合资航空运营企业、区域航空中心、国产飞机出口、对外发射服务 |
| 船舶和海洋工程 | 高端船舶、深海半潜式钻井平台、浮式生产储卸装置、LNG 船 |

## 与既有 wiki 叙事的张力

钢铁、有色恰是 2014 年大宗商品融资套利风险高发领域（参见 [[青岛港案后银行风控收紧措施]]、[[钢贸风险向上游传导]]），产能“走出去”政策的落地效果值得跟踪。
