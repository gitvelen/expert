# 农产品供需平衡表三维结构（2017 转述口径）

WASDE 各品种平衡表可从三个维度解构：

## 核心等式

```
期初库存 + 产量 + 进口量 = 国内消费量 + 出口量 + 期末库存
```

一个等式、六项内容；谷物品种增加“饲料消费”一栏，棉花增加“损耗”一栏。

## 三个维度

1. **时间**：上一年度实际值、当前年度估计值、下一年度预测值。
2. **内容**：上述等式的六项。
3. **区域**：世界、美国、主要进口国与出口国、其他重要国家。

## 美国平衡表的细化

- 生产信息增加播种面积、收获面积、平均单产。
- 消费信息细化为食物、种植、饲料。
- 最后一列增加平均价格（农场主销售价）。

## 知识库关联

平衡表是理解大宗农产品货值与价格波动的底层工具，与供应链金融中的质押物价格风险敞口管理、“货权真实性核验”的产业认知间接相关（产业本位原则）。
