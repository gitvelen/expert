# 长租公寓租金贷与应收租金保理风险模式

（2018 年深圳市商业保理协会预警口径；后续司法与监管处置进展见相关 query 页）

## 模式结构

1. 服务商与租客签订格式化租赁合同，以“押一付一”吸引租客。
2. 在未充分风险提示下，诱导租客在应收账款转让通知书回执上签字确认——租客实质在不知情下成为融资通道。
3. 服务商将租约项下应收租金转让给商业保理公司，一次性获得几乎等同于全部租期租金的融资。
4. 融资款本应支付房东，却被服务商截留自行占用，并通过持续期限错配滚动形成“资金池”。

## 风险机制

- **高杠杆 + 期限错配资金池**：沉淀资金缺乏有效监管，服务商资金链断裂即引发租客（损失押金和预缴租金、但仍需向贷款机构还本付息）与房东（收不到租金）的双重损失。
- **涉众传导链**：服务商跑路 → 租客/房东双向受损 → 租赁合同纠纷 → 群体性事件。
- **确权与资金用途监控失灵**：保理公司未核实资金流向房东这一真实交易闭环，基础资产的真实用途管控形同虚设。

## 与“真保理”的边界张力

本模式虽名为“应收租金保理”，但缺少真实贸易/租赁背景下的资金闭环管控与风险审查，实质是融资性/套利型资金池业务——与 74 号文时代“融资性贸易”的认定逻辑同构：脱离真实交易结构、以金融嵌套放大杠杆的“保理”即风险载体。此张力与 [[保理定义与四类服务]] 的正口径形成对照，也与数据类资产融资的确权欺诈问题（参见 [[查询-数据资产质押融资的确权欺诈风险与监管应对]]）逻辑相通。

## 证据强度说明

- 模式特征与违法定性均为 2018 年深圳市商业保理协会预警口径，属“涉嫌”表述，未经司法确认。
- 本警示为泛化提示，未点名具体企业；同期及后续实际爆雷案例（如蛋壳等）不在该文件范围内。
