# 商业保理风险计量与杠杆倍数

[[商业保理企业管理办法2015]] 第二十三条确立的量化风控核心，体现了对非银行保理企业施加准银行监管的思路。

## 计量公式

```
风险资产 = 资产总额 −（现金 + 银行存款 + 国债）
或有负债 = 还款保证责任应收账款余额 + 对外担保余额
（风险资产 + 或有负债）× 风险系数 ≤ 10 倍
再保理企业上限为 15 倍
```

## 风险系数（随不良率浮动）

| 不良应收账款率 | 风险系数 |
|---|---|
| ≤ 5% | 1 |
| 5% ≤ x ≤ 10% | 180 × 不良率 − 8 |
| ≥ 10% | 10 |

不良率依据 [[商业保理四级不良分类]]（次级+损失占融资保理应收账款比例）。

## 配套指标

- 风险准备金：税前计提 ≥ 融资保理业务期末余额 1%
- 集中度：同一债务人 ≤ 风险资产 50%（再保理 15%）；关联债务人 ≤ 40%（再保理 10%）
- 增信：可利用信用担保、信用保险、保证保险管理风险

## 评注

将杠杆倍数、风险系数联动不良率的动态机制引入非银行商业保理，监管强度接近准金融机构标准；但同期罚则上限仅 3 万元，监管要求与威慑手段不匹配。
