# 净流入额宏观审慎管理

[[concepts/跨境双向人民币资金池]] 的核心额度管理机制：以净流入额上限（而非外债额度）控制境外资金归集规模。

## 公式与算例

```
净流入额上限     = 资金池应计所有者权益 × 宏观审慎政策系数（初始值 0.1）
资金池应计所有者权益 = ∑（境内成员企业的所有者权益 × 跨国企业集团的持股比例）
```

文中算例：A 公司权益 30 亿、集团持股 70%；B 公司 20 亿、持股 30%：

```
应计所有者权益 = 30亿 × 70% + 20亿 × 30% = 27亿
净流入额上限   = 27亿 × 0.1 = 2.7亿元
```

## 管理规则

- 任一时点净流入额不得超过上限；净流出额暂不设限。
- 央行根据宏观经济形势和信贷调控需要动态调整宏观审慎政策系数（开放变量，后续调整见 [[queries/宏观审慎政策系数后续调整情况]]）。
- 境内成员企业位于前海、昆山、苏州工业园区、天津生态城等试点区域且已有境外人民币借款的，按借款额从上限中扣减（文中自我说明：这是净流入上限与外债额度两种制度衔接的处理方式）。
- 成员企业所有者权益变动超过 20% 的，可向人民银行申请调整净流入额。
