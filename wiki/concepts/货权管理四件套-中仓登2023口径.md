# 货权管理四件套（中仓登2023口径）

中仓登面向货物权利人（所有权人、质权人）提出的货权管理解决方案，2023年4月经马令海在万联网微课堂第162期介绍。是 [[中仓登五层公示登记体系与货单风险九场景]] 体系的客户侧延伸。

## 四件套内容

| 组件 | 功能 |
|------|------|
| **货权档案** | 记录货权从取得至终结的全生命周期内容；支持现场取证、多方数据采集，全流程司法采信存证 |
| **货权报告** | 时点货权状态凭证；支持内部汇报与多方分享；可通过司法鉴定、公证或接入高院司法生态链形成完整证据链 |
| **货权公示** | 中立第三方线上线下联动的精准货权公示；支持按库查询；提供智能货权牌 |
| **货权预警** | 四类预警：现场管理数据冲突、货权管理缺失项、多方行为数据异常、公示数据冲突 |

## 配套逻辑

- 若自建系统，应实现实时"货权一体"功能：同仓出现其他权利人或货物品类不一致时第一时间获知。
- 依据：动产融资贷后货权管理的比重甚至超过贷前、贷中管理。
- 提出背景：技术已能解决"在不在、少没少、坏没坏"，但"货归谁所有"缺乏统一法律支持，货权管理本质是对权利的管理（兜底依据为《民法典》）。
- 市场判断：货权管理服务市场规模不小于核心企业信用电子流转市场；期货交易所标准仓单为最佳样本。
