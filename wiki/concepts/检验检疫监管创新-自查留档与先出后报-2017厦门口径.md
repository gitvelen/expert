# 检验检疫监管创新：自查留档+抽查+事后监管与"先出后报"（2017 厦门口径）

厦门检验检疫局 2017 年为寄售维修型保税供应链量身打造的通关便利化组合措施（2017 年口径，机构已于 2018 年并入海关）：

## 四项措施

1. **检疫查验模式**：企业自查留档 + 检验检疫不定期抽查 + 事后监管——将查验重心从逐批现场查验转向企业自律与事后追责。
2. **清单预报备 + 预检验**：对法检目录内货物及旧机电实施清单预报备，创新预检验模式。
3. **二线出区"先出后报"**：合格货物可随时发往目的地，减少约检环节，有效缩短通关时长。
4. **CCC 免办数字化入境验证**：产品入库第一现场以认可的视频、图片代替传统现场查验；维修产品发往使用单位时以影像资料留档实施入境验证。

## 知识库定位

- **数字化监管早期实践**：CCC 免办的"视频/图片/影像留档"验证是检验检疫数字化（"以数据替代现场"）的较早案例，可关联数字化落地路径议题。
- **对保税维修类产品方案设计的参考价值**：监管便利化是寄售维修备件供应链可行性的前提；设计同类方案时应对照当时的"先出后报"与自查留档逻辑在现行综保区监管体系下的对应安排。
