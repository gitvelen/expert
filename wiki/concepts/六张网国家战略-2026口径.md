# “六张网”国家战略（2026口径）

2026年4月28日中共中央政治局会议提出，加强六张战略性网络的规划建设；5月9日国务院常务会议作具体部署，定位为战略性、基础性、先导性大事要事：

| 网络 | 功能定位 |
|------|----------|
| 水网 | 水资源时空均衡，粮食与城市安全生命线 |
| 新型电网 | 重塑能源格局，支撑新能源革命 |
| 算力网 | 数字经济底座，驱动智能经济 |
| 新一代通信网 | 信息大动脉 |
| 城市地下管网 | 城市韧性与安全 |
| 物流网 | 畅通经济循环，连接生产与消费，供应链“血液循环” |

## 投资测算（转述口径，待核验）

- 发改委测算：2026 年“六张网”及相关重点领域投资超 7 万亿元
- “十五五”期间：国家水网+新型电网+城市地下管网三项合计超 16 万亿元

## 对供应链知识库的意义

物流网从产业“配套环节”上升为国家基础支撑网络（中国物流与采购联合会口径）。物流深度嵌入真实产业链，与本库“产业本位”工作论点契合；央企物流整合（[[中国物流集团]] 四起并购）是该框架的微观落子。
