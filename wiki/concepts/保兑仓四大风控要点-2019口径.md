# 保兑仓四大风控要点（2019口径）

## 1. 核心企业推荐经销商（首要要点）

保兑仓本质是经销商信用 + 核心企业信用 + 货物质押三者的结合，其中最重要的是核心企业担保——无论"强担保"（入表担保）还是"软担保"（回购、调剂销售等隐性担保）。核心企业不愿推荐经销商，即意味着不愿承担担保，风险大。

## 2. 赊销场景下的杠杆套利风险（本文独有洞见）

赊销场景下，核心企业可能串通经销商提前回款：核心企业做销售担保、付出较小成本，实际是借经销商授信额度为自己加杠杆。金融机构须重点评估经销商是否有真实能力消化货物；若消化不了且核心企业杠杆过高，极易出现担保责任无法兑现的风险。必要时多备处置渠道。

## 3. 核心企业授信额度统一管理

不得盲目为核心企业开立新额度，额度总量须可控。依据：银保监会155号文（2019年7月）突出强调核心企业授信额度管理（见 [[银保监会关于推动供应链金融服务实体经济的指导意见]]）。经济下行期"大企业暴雷也很多"，勿盲信核心企业信用。

## 4. 银票送达与签收 + 控货抓手

- 银票必须真实、准确送达核心企业并确认签收，防止经销商截留银票、伪造公章背书给自己贴现——一旦银票未交付核心企业，核心企业不承担退款/回购责任。此与承兴案伪造确权函同构（见 [[承兴案交易结构与伪造确权函快照-2019口径]]），均属"单据造假致增信落空"。
- 控货不仅是融资方资产保障，对核心企业回款也是保障——保障本质来自未售货物可回购，而非银承信用。

## 口径说明

2019年万联网微课堂口径（专业公众号分析，证据强度：中）；"强担保/软担保"界说较粗，引用时注意。
