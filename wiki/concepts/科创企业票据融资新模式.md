# 科创企业票据融资新模式

## 模式机制

1. 根据政府管理部门发布的科创类企业名单，建立银行系统支持名录
2. 运用票据再贴现等货币政策工具引导银行给予融资支持；引导金融机构在风险可控条件下加快办理贴现，或引入市场化融资担保机构提供担保支持办理贴现
3. 遴选产业链上创新能力强、成长性好、发展潜力足的中小企业形成企业名录，由链主企业以商票等方式向链上配套企业支付款项，实现科创企业[[concepts/应收账款票据化|应收账款票据化]]
4. 科创企业借助供应链金融服务平台进行票据融资，平台提供票据询价、银企撮合贴现服务，入驻金融机构推出“贷款+贴现”综合授信

## 报送与推广主体

由[[中国人民银行西安分行]]和陕西自贸试验区西安区域报送；中国人民银行和[[国家金融监督管理总局]]负责全国复制推广。

## 运营数据（报送方自述）

| 指标 | 数值 |
|---|---|
| 覆盖科技型中小企业 | 2000余家 |
| 开票企业 | 1000余家 |
| 持票企业 | 3000余家 |
| 为科创企业授信 | 9.4亿元 |
| 票据融资 | 78亿元 |
| 再贴现 | 60亿元 |

## 评价

数据详实但为报送方自述，需地方核实；该模式与 [[供应链金融上下游分侧工具组合]] 中“一链一策一批”政策的票据化工具方向一致。
