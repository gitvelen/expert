# 金融反腐2020上半年数据（银保监会系统）

2020年上半年，金融领域反腐持续发力。据中央纪委国家监委网站2020年8月5日消息，仅银保监会系统的纪检监督统计如下：

| 指标 | 数量 |
|---|---|
| 受理检举控告 | 600 件 |
| 处置问题线索 | 515 件 |
| 立案 | 52 件 |
| 结案 | 28 件 |
| “四种形态”处理 | 491 人次 |

## 结构性观察

1. **中小银行是落马重灾区**：地方系中小银行公司治理结构相对不健全、地方监管职能缺位，管理层违纪违法易发。2020年7月山西农信联社崔联会、邢亮喜、王忠泽三高管集中落马，安庆农商行、广州农商行亦有人被查。（此为事实列举，无系统性统计支撑。）
2. **监管“内鬼”落网**：刘金明被“双开”、薛纪宁被立案审查调查，反映监管者自身被俘获的风险，详见 [[监管内鬼与监管俘获2020]]。
3. **办案模式制度化**：派驻纪检监察组与地方纪委监委协作办案渐成常态。

## 数据可信度

数据来自中央纪委国家监委官方网站通报，证据可信度高。
