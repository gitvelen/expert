# 全国供应链创新与应用示范创建

由[[商务部]]等8单位（商务、工信、生态环境、农业农村、市场监管、人民银行、银保监会、中国物流与采购联合会）组织的国家级示范城市与示范企业评选机制，依据[[国办发2017-84号指导意见]]和[[示范创建政策文件]]（113号文、123号文）实施。2021年公布首批名单，2022年7月启动第二批申报。

## 政策定位

将供应链创新提升至"畅通国民经济循环、统筹发展与安全"的高度，是供应链政策落地的国家级工具；通过示范引领促进供应链创新与应用的复制推广。

## 申报机制与硬性约束

| 环节 | 规则 |
|---|---|
| 牵头组织 | 省级商务主管部门会同有关部门 |
| 省级限额 | 每省申报城市 ≤ 5个，申报企业 ≤ 20家 |
| 直报 | 直辖市、计划单列市及国资委直接管理的中央企业直报商务部 |
| 时限（2022年批次） | 2022年8月1日前纸质版（一式三份） |
| 申报书结构 | 申报表 + 申报书正文 + 指标内容（可附证明材料） |
| 评审 | 商务部会同相关单位组织专家评估，必要时现场调研核实 |
| 编写要求 | 措施可操作、项目可落地、结果可考核 |

## 关联

- 央企直报安排与[[国务院国资委]]的管理职责衔接。
- 属于[[国家供应链金融政策脉络]]2022年节点，但本机制为产业/流通政策，不直接涉及供应链金融监管。
