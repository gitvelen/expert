# 普渔乐六大功能模块：渔业全产业链数字化（2023口径）

## 背景

浙江省数字化改革背景下，舟山市普陀区围绕"一条鱼"全产业链推进数字化。普渔乐平台针对**渔业产业场景、渔业服务场景**两大场景建设六大功能体系（2023 年宣传口径）。

## 六大模块

| 模块 | 要点 |
|------|------|
| 运营数据中心 | 渔业产业大脑；产业数据纵向挖掘、横向串联；全域数据资源体系 |
| 渔业产业供应链服务平台 | 渔获（生鲜农产品）生产、加工、流通全产业链连接，打通供应协同关系 |
| 渔需物资采购服务平台 | "在线采购补给服务"+"在线一件事"系统，解决海上作业补给与办事难题 |
| 渔业产业金融服务平台 | 核心圈多级穿透，产销存全链条可视化、透明化、可追溯，向金融机构输出数据与风控 |
| 渔业金融信用服务体系 | 四流线上化+多层级信用管理，构建 [[物信合一客观信用体系-信雅达2023口径|"物信合一"]] 体系 |
| 渔业创新贸易服务平台 | 海上直销+定制物流，区域品牌赋能，渔获"商品化"赛道 |

## 样本价值

本库此前案例集中于大宗商品、煤炭、白酒、制造业等品类，此为**水产/生鲜品类**的产业数字化与供应链金融新样本；其货权管控路径（生鲜无仓单）是区别于大宗品案例的关键差异点。
