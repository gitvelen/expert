# 供应链金融现代化五大内涵（陈祥锋2022口径）

## 框架

陈祥锋在 2022-11-01 京东云城市峰会演讲中提出，供应链金融现代化 = **中国化 + 时代化**相结合，包含五大内涵：

| 内涵 | 定位 |
|------|------|
| 数智化 | 手段 |
| 创新 | 目标 |
| 绿色 | 目标 |
| 安全 | 目标 |
| 高附加值 | 指引方向 |

## 中国化四要素

1. 国内大循环、国内国际双循环相互促进的发展格局
2. 高质量发展
3. 双碳经济
4. 供给侧改革

## "两手抓"与"1+1>2"

推进供应链金融现代化的两个抓手：

1. 推动数字化供应链场景建设
2. 推动数字化供应链金融的智慧化创新

两者结合可实现"1+1>2"的效果。
