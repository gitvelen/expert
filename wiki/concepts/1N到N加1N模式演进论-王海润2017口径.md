# "1+N"到"N+1+N"模式演进论（王海润 2017 口径）

[[王海润]] 2017 口径：供应链金融由"1+N"（银行依赖核心企业授信）向"N+1+N"（上下游企业直接与核心企业接触、核心企业直接授信并可自筹或外部融资）演进，"更加凸显核心企业作用"；配套服务方式从线下向线上迁徙。与 [[供应链金融发展四大特点-王海润2017口径]] 同源。
