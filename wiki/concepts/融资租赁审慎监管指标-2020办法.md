# 融资租赁审慎监管指标（2020《办法》）

《融资租赁公司监督管理暂行办法》（2020）第三章新设的审慎监管指标体系，旨在推动融资租赁公司专注主业、提升风险防控能力。

## 指标清单

| 指标 | 条款 | 要求 |
|---|---|---|
| 租赁资产比重 | 第26条 | 融资租赁和其他租赁资产 ≥ 总资产60% |
| 风险资产倍数 | 第27条 | 风险资产总额 ≤ 净资产8倍（风险资产=总资产−现金−银行存款−国债） |
| 固收证券投资比例 | 第28条 | 固定收益类证券投资 ≤ 净资产20% |
| 单一客户融资集中度 | 第29条(一) | 对单一承租人全部融资租赁业务余额 ≤ 净资产30% |
| 单一集团客户融资集中度 | 第29条(二) | 对单一集团全部融资租赁业务余额 ≤ 净资产50% |
| 单一客户关联度 | 第29条(三) | 对一个关联方全部融资租赁业务余额 ≤ 净资产30% |
| 全部关联度 | 第29条(四) | 对全部关联方全部融资租赁业务余额 ≤ 净资产50% |
| 单一股东关联度 | 第29条(五) | 对单一股东及其全部关联方融资余额 ≤ 该股东出资额，且满足单一客户关联度 |

## 补充规定

- 银保监会可根据监管需要对指标作出调整（第29条末款）。
- 重大关联交易定义（第53条）：与一个关联方单笔交易金额占净资产5%以上，或交易后余额占净资产10%以上。
- 省级实施细则可对租赁物范围、特定行业的集中度和关联度要求适当调整，报银保监会备案（第51条）。
