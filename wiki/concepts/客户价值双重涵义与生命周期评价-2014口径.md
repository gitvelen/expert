# 客户价值双重涵义与生命周期评价（2014口径）

2014 年文章《供应链协同视角下的客户识别与管理技术》的立论基础：客户价值存在两种流向相反但内在一致的涵义，且应沿客户生命周期综合评价。

## 双重涵义

1. **客户视角**：客户感受价值/客户让渡价值——从产品（或服务）中获得的总利益与付出总代价的权衡，即服务效用与过程质量之和相对价格与获得成本之比。客户满意与忠诚的基础。
2. **企业视角**：客户净现金流贡献——企业从客户处获得的收益减去相关成本后的净值，及未来净现金流的总体能力。

两者“相辅相成、互相促进，形成类似 DNA 螺旋结构般的循环向上关系”，构成客户关系的核心与本质。

## 生命周期评价

- 客户生命周期六阶段：潜在期 → 开发期 → 成长期 → 成熟期 → 衰退期 → 终止期；不同阶段企业投入与客户贡献大不相同。
- 客户终身价值：客户生命周期内给企业带来的净利润折现净值。
- 另引 TurboCRM 的“完全客户价值”三分法：既成价值、未来价值、影响价值。

## 评价五因素

1. 客户利润贡献
2. 客户生命周期（客户维系时间与客户销售周期）
3. 客户潜力（对质量、服务、价格的感知，需求满足状况，竞争对手信息）
4. 客户忠诚度（钱包份额、转换成本、品牌认知度）
5. 策略考量（形象客户、经验客户的隐性价值；文中引“美国消费者事务办公室：满意顾客会告诉另外五人”，作者自认仅为概念性数据、不完全准确，不作事实依据）
