# 供应链金融政策术语官方六条定义（驻马店 2019 口径）

以下为《驻马店市人民政府关于促进驻马店市供应链金融发展的意见》第（十二）条术语说明原文照录，属稀缺的地市级官方定义文本（2019 年口径）：

1. **供应链金融**：指商业银行、保险公司、商业保理公司、融资担保机构、小额贷款公司等金融机构通过与核心企业、第三方机构等的合作，从供应链整体结构和信用出发，运用自偿性融资、金融科技等方式控制风险，为供应链上的中小微企业所提供的、以融资为主的综合金融服务。
2. **供应链融资**：专指上述供应链金融定义中的融资服务部分，包括但不限于贷款、票据贴现、银行承兑汇票、保函、保理融资、融资租赁、信用证（含国际和国内）、押汇等。
3. **供应链金融企业**：指经国家金融监管部门或地方金融监管部门批准设立，围绕实体经济供应链提供各类供应链金融产品和服务的机构。
4. **供应链核心企业**：指在供应链上拥有该供应链关键资源和能力，具有相对较强实力，对其供应链上下游企业群体有较大影响和支配能力的企业，其规模应至少达到国家统计局关于《统计上大中小微型企业划分办法（2017）》大型以上标准。
5. **供应链金融配套服务机构**：指利用技术、管理和服务能力，围绕金融机构的供应链金融业务，提供基于真实交易的信息数据服务、物流管控服务、安全科技服务等非金融配套服务的法人企业。
6. **中小微企业**：划分参照国家统计局《统计上大中小微型企业划分办法（2017）》执行；其中享受驻马店市及各县区奖补政策的供应链金融企业，其服务的中小微企业应包含在驻马店市辖区注册、具有独立法人资格、且经各产业部门认定符合当地产业政策导向的中小微企业。

## 硬口径要点

- 核心企业"大型以上"划型标准与奖补对象"辖区注册 + 独立法人 + 产业导向"三重限定，是可核验的官方硬性口径。
- 明确区分"供应链金融（综合服务）"与"供应链融资（融资服务子集）"，并限定供应链金融企业须持牌。

## 三方定义对照

该官方定义可与 [[供应链金融定义-2019科普口径]] 及国际五组织 [[供应链金融技术的标准定义2016]]（八大技术产品体系，见 [[供应链金融八大技术产品-国际标准定义2016]]）形成"国际标准—科普—地方官方"三层次定义对比素材。
