# 货权生效证据链分层：四流合一仅为可能性（2024判例口径）

## 核心命题

四流合一（合同流、货物流、发票流、资金流）是**税务机关排查业务真实性最基本的证据链要求**，仅能满足税务排查口径；司法上货权（含质权）是否有效设立，依"**特定化 + 交付占有**"判定。据此形成证据链的三个层级：

```
税务证据链（四流合一） < 贸易真实性证据链（商业实质穿透） < 货权生效证据链（特定化+交付+公示+存证）
```

## 货权生效证据链四要件（万联网2024口径）

1. **货物特定化**：位置特定化（锁定仓库）+ 货物本身特定化（标签/喷涂/编号等标志），全过程记录取证；
2. **交付占有过程证据化**：交付与持续占有有迹可循；
3. **货权公示**：线下智能货权牌 + 线上公示联动，防范善意第三人；
4. **司法存证**：交易全周期证据司法可信存证，对接国家级区块链。

## 判例支撑

- **（2021）闽0802民初2696号**：四流齐备但货权归属依特定化与交付证据完善度判定——买方租集装箱贴封条完成特定化与实际控制，胜诉取得货权；
- **（2022）黑2761民初21号**：仅有四流合一（合同、发票、出入库统计表、放款记录），未明确仓库位置、无交付行为证据，**质权未生效**，监管公司不担责。
