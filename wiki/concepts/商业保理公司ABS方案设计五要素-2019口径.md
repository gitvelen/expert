# 商业保理公司ABS方案设计五要素（2019口径）

保理资产证券化指保理公司将从各卖方受让的应收账款形成资产池，经信用评级与分层后转变为可流通证券的融资方式。2019 年公众号"贸易金融"（转载自"保理法律研究"）将其方案设计归纳为五大要素，是 wiki 中保理 ABS 知识簇的"方案设计操作层"参照。

## 一、交易结构与九大参与主体

发起人（保理公司，转让其对融资人的保理融资债权）、发行人（SPV，由专项管理计划充任）、服务人（保理公司，负责现金流管理、循环购买、催收）、管理人（证券公司）、托管人（银行）、投资银行（券商承销）、信用增级机构、信用评级机构（常用中诚信、联合资信、大公国际）、投资者（以机构为主）。

## 二、基础资产选择

保理基础资产两大特征：
- **期限短**：取决于买方回款，账期一般 3-6 个月；
- **买方信用为第一还款源**："卖方借钱、买方还钱"——这是保理业务最大特点，也是本文最具产业本位价值的论断，与"以债项信用/物的信用替代主体信用"的工作论点一致。

筛选四标准（在一般资产选择原理之上）：
1. 优先选择买方信用好的（考察买方资信、行业、规模、实力）；
2. 选择有追索权的保理基础资产（卖方赎回构成额外风险屏障）；
3. 无法律瑕疵：依《合同法》第 80 条，转让效力取决于通知买方；买方禁止债权转让则资产无法律保障（见 [[债权转让通知与债务人确认设计-2019口径]]）；
4. 原始贸易合同下账期固定，保证回款时间稳定。

**循环购买机制**：产品存续期约三年与资产期限错配，须以回收款持续购买新资产。两大风险与四项对策：
- 后续资产不足风险 → 加速清偿/提前终止机制；
- 入池资产质量下降风险 → 初始资产优选（买卖双方贸易关系稳定、卖方与保理公司长期合作）+ 明确入池资产标准（资质、行业、保理成数、融资利率）；
- 保理商须建立完善 IT 系统，供管理人随时检查资产明细。

## 三、风险隔离

风险隔离必要性来自保理公司主体资质弱（文中口径：注册资本平均 5000 万、经营年限普遍不足 3 年——**注意：文中"由商务部监管"为滞后表述，商业保理 2018 年已划转地方金融监管局/银保监会体系，此处按 2019 年文章口径存档**）。

实现方式：由证券公司或基金子公司设立专项资产支持计划作为 SPV，保理公司将资产转让入计划，实现与原始权益人的破产隔离；签订基础资产买卖/转让协议，以**交割确认函**确认交割完成；附属担保权益（保证、质押担保）随保理融资债权同时转让。

## 四、现金流与收益分配

- 集中度高、单笔金额大的资产：按原始贸易合同结算周期画现金流量图，叠加违约率、提前偿还率预测；
- 小额分散资产：用平均账期、平均额度、历史违约率做概率统计预测；
- 定价常用现金流贴现估价法（另有相对估价法、期权估价法，国内以贴现法为主）；
- 收益分配通常按固定收益特征：按年或半年付息、到期一次还本；
- 分配顺序：税费 → 中证登 → 管理/托管人费用 → 优先级本息 → 劣后级本息，同一层级按比例。

## 五、信用增级

- **内部六方式**：优先/次级结构（次级由保理公司自持）、超额担保、利差账户、回购承诺（卖方在买方逾期时回购应收账款——术语口径待与书籍核对，部分文献视其为风控措施而非增级）、差额支付、母公司担保；
- **外部四方式**：外部保险、第三方担保、现金担保账户、流动性支持（仅代垫流动性、不承担信用风险）。
