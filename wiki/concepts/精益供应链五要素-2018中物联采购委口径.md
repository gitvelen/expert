# 精益供应链五要素（2018 中物联采购委口径）

**出处**：2018-01-28 文章《供应链中的精益生产思想》（中物联采购委），见 [[sources/4-news--7-04-业务基础--4-2018--16-供应链中的精益生产思想供应链技术--1ua3khy]]。证据强度弱，属观点性、规范性通识口径，非经验证事实。

## 五要素

1. **计划对整个供应链的可见性**：依托拉式生产的可追溯性，工序中每件在制品与最终客户订单关联；供应链各参与者协同对最终订单做计划并相互公开计划结果。技术基础为互联网 + APS。
2. **计划的快速反应能力**：跨企业环境下看板（广告牌）信号逐级传导会造成延误；应利用互联网使**信息流与物流分离**，计划变更第一时间向全链公开。
3. **有限能力计划**：每道工序按下游能力需求产出；任何"无限能力"假设的计划系统（如 MRP）必然造成链上库存积压、增加成本、降低反应能力。
4. **动态采购**：通过 Web 服务（上游为提供者、下游为使用者）在计划阶段即按成本、交货速度、供应商等级等规则动态选择供应商，替代静态的优先级选择。
5. **开放的思想**：供应链上数据公开、以客户为中心；各参与者对客户需求作出一致、公开、准确的反应。

## 口径局限

- 批判 MRP 但未讨论 ERP/MRP 在实践中长期广泛存续的现实。
- "数据公开"未正视商业机密与数据安全的现实矛盾，仅以规范性"开放思想"回应。
- 本文（2018 年口径）为理论设想，APS、动态采购等在中小企业供应链中的实际落地情况文中未给出证据。

## 与供应链金融的关系（注意：仅为潜在弱关联）

有限能力计划批判所对应的"库存积压"问题，与存货融资中贸易背景真实性的判断存在潜在关联，但**原文并未展开此关联**，不应引申为文章观点。本概念仅作产业知识背景使用。
