# 北京商业保理审慎监管指标（2020指引）

《北京市商业保理公司监督管理指引（试行）》第4条确立以风险为本的审慎监管框架，其量化指标集中于第7–9、24–28条。**这些阈值仅适用于北京地区商业保理公司，不得泛化至其他地区或其他业态。**

## 指标体系

| 指标 | 要求 | 条款 |
|---|---|---|
| 注册资本 | ≥1亿元人民币或等值可自由兑换货币，一次性实缴货币资本 | 第7条 |
| 风险资产/净资产 | ≤10倍 | 第25条 |
| 风险准备金 | ≥融资保理业务期末余额1% | 第26条 |
| 不良认定 | 逾期90天未收回或未实现的保理融资款纳入不良资产管理 | 第24条 |
| 同一债务人集中度 | ≤风险资产总额50% | 第28条 |
| 关联债务人集中度 | ≤风险资产总额40% | 第28条 |
| 参控股数量 | 参股≤2家、控股≤1家 | 第9条 |
| 股东锁定期 | 3年内不转让、不质押、不设信托 | 第8条 |

## 补充要求

- **融资来源（第27条）**：限银保监会监管的银行和非银行金融机构、发行债券、股东借款、再保理等合法途径。
- **关联交易（第28条）**：对关联公司服务定价应合理公允，交易条件不得明显优于非关联公司。
- **保理专户（第29条）**：原则上要求卖方开立应收账款回笼专户，专人监控资金进出。
- **基础交易真实性审核（第23条）**：审核合同真实性与合法性、债务人资信、应收账款质量（出质、转让、账龄结构），与 [[底层资产穿透监管]]、[[真实贸易背景要求]] 相呼应。

## 与205号文的关系

这些量化指标与 [[银保监办发2019-205号文]] 的全国性框架（同为10倍杠杆、1%准备金、50%/40%集中度）基本一致；但1亿元实缴注册资本门槛为北京特有，205号文未设统一注册资本要求，故本指引准入层面严于全国规则。
