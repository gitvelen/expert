# C（成本）与I（库存）二元框架（程晓华2017口径）

## 概述

程晓华在其2017年文章中提出：供应链管理的两个基本出发点（或根本目的）就是 C（cost，成本）与 I（inventory，库存）。二者交织混杂、不可分割——把成本压得太紧，必然导致库存控制不力（"买的便宜，用的贵"）；库存问题归根结底又与成本决策和执行错位相关。该框架为作者个人经验性观点（"我个人认为"），无数据与案例支撑，属**作者断言口径**，不应推广为行业共识。

## 核心命题

### 1. C 与 I 的定义与范围

- **C（成本）**：寻源采购（sourcing）的核心 KPI 是 CR（cost reduction，成本降低 %）；物流涉及运输、仓储、清关成本；生产制造（按 SCOR 视角属于大供应链）同样在 C 与 I 之间权衡——C vs I 是供应链管理部门与生产运营部门斗争的焦点。
- **I（库存）**：包括原材料、成品、半成品库存，以及存放在供应商、客户处的库存；另一层含义即交付（D，delivery）——交付本质是库存的转移。

### 2. 库存即交付论与 5R

库存控制不仅是控制数量与价值，也包含及时交付——"仔细想想，其实是一码事"。理想状态为 **5R**：合适的产品、以合适的价格、在合适的时间、以合适的数量、到达合适的地点。客户化需求波动加大使"不合适"的矛盾日益突出，库存控制的地位也随之提升。

### 3. 库存是计划的产物 + 执行错位

库存是计划的产物（按计划采购、生产、交付），但从执行角度看，库存是时间（T-timing）与数量（Q-quantity）的错位问题——计划再好、执行不到位，库存仍会堆积。成本影响执行，执行结果最终形成库存持有成本。

### 4. QCDS 与 CR KPI 的激励扭曲

尽管有 QCDS（quality/cost/delivery/service）之说，实际工作中 C 因"容易出成绩、看得见摸得着"而压倒 Q、D、S，寻源采购与物流部门均如此，导致"买的便宜，用的贵"。这是对激励机制扭曲的定性判断。

### 5. TIM 全面库存管理审核与 T&C

程晓华的"全面库存管理审核"（TIM）中包含寻源采购与商务内容，如 T&C（terms & conditions 合同条款）中供应商呆滞责任、付款条件等——因 C 与 I 深度相关，合同条款直接影响库存责任与资金占用。这一点对供应链金融中的存货融资定价与监管率设计有启发价值。

### 6. 三流归一总结

文末公式化总结：**I = T（时间）+ Q（数量）；C = M（钱）**；T、Q、M 形成 I、C，最终归结为信息流（information flow）、物流（materials flow）、资金流（cash flow），即供应链管理的"三流合一"。该口径可与 [[供应链五流口径与三流一致问题-2017转述口径]] 的"五流"口径对照（属表述差异，非冲突）。
