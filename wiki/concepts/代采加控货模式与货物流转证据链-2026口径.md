# 代采+控货模式与货物流转证据链（2026口径）

## 模式定义

国企控货业务的正确定位不是"租个仓库看货"，而是**代采的自然延伸**：国企帮下游客户代理采购货物，货物进入国企自有或指定的第三方仓库全程监管，客户分批付款、国企分批放货，尾款结清后货权完全移交。

模式价值：上游供应商获得款到发货保障，下游中小制造企业缓解囤货资金压力，国企赚取服务费；因货物实际在国企手中，被质疑"走单不走货"空转贸易的风险大幅降低。

**示例**（医疗器械 CT 设备）：民企接三甲医院订单，上游总代要求全款 3000 万，民企仅有 800 万。违规玩法是国企直接垫资 2200 万、货直发民企、赚利息（易被认定融资性贸易）；合规玩法是国企垫资后货入指定第三方仓，民企每卖一台付款+服务费，国企放行一台，全程货权在国企。

## 货物流转证据链（七环）

```
采购合同 → 付款凭证 → 物流单 → 入库单 → 库存台账 → 出库指令 → 下游签收单
```

核心论点（张春艳，2026 培训口径）：只要能拿出完整证据链证明企业真实介入货物流转、承担货物风险，即使利润中包含资金成本补偿，也不易被认定为融资性贸易；反之只走单不走货，哪怕资金一进一出也会被认定为虚假贸易。此思想与 [[四流合一合规框架-大宗贸易2026口径]] 同源。
