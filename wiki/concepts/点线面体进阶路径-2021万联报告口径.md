# 点—线—面—体进阶路径（2021万联报告口径）

"点—线—面—体"进阶路径是《中国数字化供应链金融创新与实践报告（2021）》提出的中国数字化供应链金融发展框架：数字化供应链金融从单点业务数据化起步，逐步演进出数据资产化、产品精准化，最终形成产融生态圈的四层递进结构。

## 四层内容

| 层级 | 内容 |
|------|------|
| 点 | 科技推进业务、供应链的数据化 |
| 线 | 结合供应链场景的数据挖掘与分析，使数据成为有价值资产 |
| 面 | 据此提供精细化、精准化的供应链金融产品，顺畅供应链 |
| 体 | 创造新商业模式与服务机制，更大范围构建可持续产融生态圈 |

## 知识库定位

该框架属观点性分析框架（专业报告口径），可与其他分析框架对照：与 [[银发2020年226号文]] 第18条"主体信用、物的信用、数据信用一体化风控"体系是"发展路径"与"风控体系"两种维度的互补框架。使用时注意区分：本口径描述演进阶段，226号文描述风控要求。
