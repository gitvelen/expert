# 供应链发展四阶段论

[[丁俊发]]在解读84号文时提出的供应链演进框架：

| 阶段 | 内涵 |
|------|------|
| 1.0 | 企业内部资源整合 |
| 2.0 | 企业与外部资源整合 |
| 3.0 | 价值链协作 |
| 4.0 | 智慧供应链 |

该阶段论与《意见》"打造大数据支撑、网络化共享、智能化协作的智慧供应链体系"的提法相衔接，4.0 阶段即[[智慧供应链]]。作为框架性专家论述，可与后续政策演进及产业实践对照验证。
