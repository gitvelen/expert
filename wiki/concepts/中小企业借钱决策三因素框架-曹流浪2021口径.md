# 中小企业借钱决策三因素框架（曹流浪2021口径）

曹流浪（悦融易创始人，2021 年）提出的中小企业银行贷款决策模型，核心主张：贷款≠经营恶化，是否借钱应同时满足三个因素。

## 三因素

1. **借款资格**：能否借到——依赖抵押担保物，或长期积累的信用；无融资资格时讨论贷多贷少"如同比有风湿病的穷人讨论海边别墅"。
2. **成本覆盖**：回报能否覆盖利息及隐性成本（资产评估费、财务审计费、财务人员部分工资奖金、时间成本）；除纯财务回报外还应计入规模、市场地位、银行信用增强等非财务回报。例外情形：借钱救命，成本再高也须借，故"借钱要趁早"。
3. **还款能力**：按借款用途判断——
   | 用途 | 还款判断 |
   |------|----------|
   | 生产经营周转（原材料、商品） | 业务正常即回款可还 |
   | 应急（发工资、房租） | 有明确资金回笼可还 |
   | 研发/广告等"烧钱" | 原则上优先股权融资而非债权融资 |
   | 借新还旧 | 自评后续偿债能力 |
   | 消费 | 量力而行（企业不适用） |

## 融资能力前置的业务计划法

决策顺序：先评估企业融资资格、可贷额度与成本 → 再测算年度业务计划的资金缺口 → 无缺口可不借，有缺口依次考虑缩减目标、股东投入、内部资金优化、股权融资或银行贷款。若融资能力强，可反向调高业务目标。核心逻辑："经营企业本质上是对资源的整合利用，借钱本身就是在整合资源"。

## 评价与张力

- 该框架为融资顾问视角的方法论，未经实证核验；其"多少钱都不够"的表述与其自设的成本/还款约束存在张力，文章兼有咨询营销属性。
- 与 [[concepts/产业企业自金融二银行批判-宋华2021口径]] 形成互补：宋华批判产业企业自金融倾向，曹流浪则从企业侧论证正规银行融资的正当性。
