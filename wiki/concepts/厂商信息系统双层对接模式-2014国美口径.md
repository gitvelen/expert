# 厂商信息系统双层对接模式（2014国美口径）

## 内容

2014 年国美（Gome）为保障与厂家对接，自行开发 B2B 系统平台，按厂家信息化程度分两个层面对接（来源：2014-03 公众号转述）：

| 层面 | 适用对象 | 协同深度 |
|---|---|---|
| 深度对接 | 已有完善内部信息系统的厂家 | 系统内处理订单、互相了解对方库存情况、系统内财务结算 |
| WEB 平台 | 内部信息系统不完善或未建系统的厂家 | 提供可信息交互的电子商务网站 |

配套商业模式细节：当时国美 B2B 业务已在全国发放 300 多个厂家账号；使用 WEB 平台的厂家向国美信息中心缴纳一定费用。

## 在知识库中的定位

- 该分层协同思路是理解**核心企业主导的供应链数字化**的历史参照：核心企业按上下游信息化程度分层提供对接能力，并对下游使用方收费——与后来“数据信用”依赖核心企业数据接口的逻辑一脉相承。
- 证据强度弱：单一公众号转述、无数据出处、“目前”所指时间不明，仅作 2014 年历史口径记录。
