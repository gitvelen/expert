# ICC供应链金融五大困惑调查（2020 转述口径）

2020 年文章据称引自"国际商会每年的调查报告"，供应链金融主要困惑按比例排列：

| 困惑 | 占比 |
|---|---|
| KYC（了解你的客户）/ KYCC（客户的客户）/ KYCB（客户的业务）/ KYD（自己的文件） | 40% |
| 平台间缺乏共同一致标准交换数据 | 34% |
| 内部政策不明确 | 31% |
| 会计核算不清楚 | 27% |
| 缺乏政策、监管支持 | 11% |

作者据此论证"规范供应链金融是当务之急"，并称我国尚无同类调查但"情况大体相同"。

**证据强度**：专业公众号/资深从业者转述口径，无法直接核对 ICC 原报告，具体年份与样本不明，原始出处待溯源。
