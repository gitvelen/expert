# 农业供应链六类产品线（龙江银行口径）

[[龙江银行]] 按农业供应链从生产到销售各环节切分的产品线（2012 年口径）：

| 产品 | 对应供应链环节（依文推断） |
|------|------|
| 农资贷 | 农资采购环节（农资公司+农户） |
| 种植贷 | 种植生产环节 |
| 农机贷 | 农机具购置环节 |
| 农信通 | 综合金融服务（文中未详述） |
| 粮贸贷 | 粮食收储与贸易环节 |
| 养殖贷 | 养殖生产环节 |

## 设计要点

- 产品供给覆盖"农资公司+农户""合作社+农户""收储加工公司+农户""公司+合作社""核心企业+中小供应商"五种形式，体现融资依附真实交易结构的原则。
- 文中未披露各产品的定价、额度与准入标准，引用时避免过度推断。
