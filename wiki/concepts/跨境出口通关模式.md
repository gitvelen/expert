# 跨境出口通关模式（9610/1210/9710/9810/0110/1039）

中国海关为跨境电商及中小卖家出口设立的特殊监管代码体系，区别于一般贸易出口，自 2017 年国家发布跨境出口电商政策以来逐步形成。

## 主要代码

| 代码 | 监管方式 |
|------|----------|
| 9610 | 跨境电商零售出口（B2C 直邮） |
| 1210 | 保税跨境贸易（保税备货，含出口） |
| 9710 | 跨境电商 B2B 直接出口 |
| 9810 | 跨境电商出口海外仓 |
| 0110 | 一般贸易出口 |
| 1039 | 市场采购贸易 |

> 注：0110 即一般贸易；行云演讲将其与跨境电商代码并列作为可提供的履约方案选项。各代码的权威定义以海关总署监管方式代码表为准，本页暂以演讲口径整理，建议后续以官方文件补强。

## 与供应链金融的关联

通关模式决定了出口贸易背景的单证形态（报关单、清单、海外仓仓单等），是跨境电商供应链金融验证贸易真实性的基础性凭证，也是[[concepts/六大出海业务模块-行云2024口径|六大出海业务模块-行云2024口径]]中"履约服务"环节的合规载体。
