# "稳、续、增、降、简、容"六字方针

[[李均锋]]（银保监会普惠金融部主任）在2020年2月25日媒体通气会上对小微金融纾困政策的总括。

| 字 | 含义 |
|---|---|
| 稳 | 稳金融、稳小微信贷，以稳就业、稳预期 |
| 续 | 对受影响企业的贷款合理延期和续贷 |
| 增 | 积极支持小微企业的补偿性信贷需求 |
| 降 | 进一步降低企业融资成本 |
| 简 | 特事特办，简化首贷、续贷、展期手续和流程 |
| 容 | 提高不良容忍度，增强灵活性，对监管政策预调、特别是微调 |

另透露：银保监会正与央行研究增加支小再贷款及小微金融专项债额度；支持地方设立小微企业转贷基金。

六字方针后被 [[6号文-中小微企业贷款临时性延期还本付息通知2020]] 制度化。
