# 资产驱动与资金驱动及FinTech两条路径论（钟胜九2017口径）

> **时效标注**：本页为 2017 年金融科技乐观期观点口径，其中"FinTech 自营信贷完成 0 到 1 证明"的路径在 2017 年后互联网金融整治、金融科技持牌与降杠杆监管下已被实践部分修正，未修正部分仍具方法论参考价值。

## 核心命题

1. **FinTech 与金融 IT 的本质区别**：是否参与资产开发、资产风险评判或风险定价。只帮银行建系统、不做资产识别的，是银行 IT 公司。
2. **资产驱动 vs 资金驱动**：资金驱动范式下银行以资产负债表和资金成本取胜，技术价值无法体现；市场充分竞争后银行转向轻资产、优质资产驱动，通过技术获取识别优质资产时 FinTech 价值才凸显。
3. **"0 到 1"资产证明论**：银行天然低风险偏好，中小微信贷资产必须由新金融以实践数据完成资产属性证明——"0 到 1 靠技术，1 到 100 靠结构融资/证券化生态"。由此推出：有资金的金融科技公司需保留自营科技金融业务，否则退化为 IT 公司。
4. **两条路径**：
   - **零售商**：特定行业/族群/产品的资产开发零售商，银行变批发商；钟认为银行不必纠结客户资源掌握在零售商手中——零售商愿开放共享客户与场景，且客户"一直都在"（此处存在内部张力：共享意愿与客户掌控现实相矛盾，文中未解决）。
   - **金融基础设施**（更高理想）：横向——以特定产品为核心覆盖引流到资产交易全环节；纵向——反欺诈、电子合同、区块链（凭证合约）、支付、交易征信等点状服务。
5. **B2B 电商"订单入口≠融资需求"**：B2B 中 Order Entry 有时只是录入，未必掌握真场景，B2B 电商同样需建设金融科技。此论与本库"贸易背景真实性"工作论点直接相关——订单数据本身不构成贸易背景真实性证明。

## 证据强度

观点/逻辑推演，非实证；引证的中信银行生态金融、京东金融陈生强、德勤吴颖兰言论均属企业自述/媒体口径。
