# 核心企业信用传导与"1+N"模式（深发展2017口径）

## 概述

"1+N"是供应链金融的行业经典模式：以一个核心企业（"1"）为出发点，将其银行信用与交易关系传导给上下游 N 家中小企业，为整条供应链提供金融支持。

**背景说明（独立可查证的公共知识，非本来源内容）**：深圳发展银行是国内供应链金融"1+N"模式的开创者之一，2012 年与原平安银行合并为新的平安银行，相关产品线由平安银行延续。

## 核心企业信用传导论（2017 口径）

- 将资金有效注入相对弱势的上下游配套中小企业，解决中小企业融资难与供应链失衡；
- 将银行信用融入上下游购销行为，增强商业信用，促进中小企业与核心企业的长期战略协同，提升供应链竞争力。

**张力提示**：此"核心企业中心"叙事是 2017 年主流口径；其后监管（226/155/74 号文时代）与市场实践逐步转向"去核心化、数据信用"，并警惕核心企业确权难与融资性贸易套利问题。本口径保留供历史对照，不作为当前唯一口径。

## 中欧课题组产品配置总结（转述口径）

中欧国际工商学院课题组对深发展"1+N"模式研究后，按供应链主体特点总结的方案（二手转述，细节见 [[2017年供应链金融上下游产品配置快照-中欧课题组转述口径]]）：

- **上游供应商**：赊销为主 → 以应收账款类融资为主，配备保理、票据贴现、订单融资。
- **下游经销商**：先款后货/部分预付/限额赊销 → 以动产和货权质押授信中的预付款融资为主，配备短期银承、国内信用证、保函、附保贴函的商业承兑汇票。
