# 第三方支付切入供应链金融的数据/场景/风控路径（2019口径）

本概念整合 2019 年初媒体与机构对"第三方支付公司为何及如何切入供应链金融"的三种口径：汇付天下路径论、前瞻产业研究院三优势框架、中泰证券行业选择论。来源为一般新闻报道，证据强度弱-中，属观点性口径而非经核验事实。

## 一、汇付天下"支付为入口"四步路径（钟红波口径）

**支付为入口 → 场景渗透 → 数据沉淀 → 流量变现**

- 支付长期积累上下游资金收付数据：订单、应付款、应收账款
- 数据双重用途：自身增值业务拓展；与银行及外部金融机构合作，用于供应链企业资金资产评估、账户管理等
- 场景优势："支付连接场景十分自然，交易数据自带场景特征"，结构化处理后形成用户画像，在营销、信贷等场景精准匹配
- 盈利模式转移：不在支付本身，而在行业解决方案与增值服务

## 二、前瞻产业研究院三优势框架

1. **数据**：交易数据收集的天然优势，B 端支付企业可低成本获取中小企业交易信息，为银行等金融机构信贷业务提供数据支撑
2. **场景**：不同行业场景下企业资金流动性不同，支付公司可针对性了解企业资金处理需求，帮助盘活资金
3. **风控**：根据企业与其商户的交易情况，以"数据+场景"方式做好供应链金融核心——风控，帮助授信及资金出借方降低风险

## 三、中泰证券 B 端行业选择标准

- 移动支付双寡头垄断，独立第三方支付公司需深耕 B 端
- 选择标准：**市场空间大、集中度低**的行业最为合适；及时抓住新兴行业机遇、顺势而为、掌握先发优势

## 四、To B 与 To C 差异（钟红波补充）

To C 可"上个 APP 流量就起来"；To B 打磨周期长、技术投入重，需沉心深耕；先建共性基础功能，再捕捉细分行业具体应用需求。

## 与相关概念的关联

- 与 [[重债项轻主体与交易额度代替授信额度-王鹏虎2019口径]] 的"交易数据风控"思路同源，均属以数据信用替代主体信用谱系
- 该乐观路径形成于 2019 年初监管宽松预期期，与随后供应链金融强监管、爆雷频发的现实形成对照，实际成效待核验
