# 2019 金融科技五大趋势（李书文口径）

[[李书文]] 在 2019 年 [[万联网]] 论坛圆桌上提出的趋势判断（2019 转述口径，属个人观点）：

1. **2B 取代 2C 成为竞争热点**——中国没有世界级的 2B 公司，2B 自 2019 年开始成为热点。
2. **从资金的融通转向科技赋能**。
3. **银行包括 BATJ 的进入将加速金融科技的行业洗牌**。
4. **客户对金融科技的感知更强**。
5. **金融科技仍然面临强监管**。

配套批评：业内动辄人工智能/大数据/区块链，但"基本上没有开展过业务，开展过业务的供应链金融公司基本上都是处于概念化阶段"——该证词与 [[银行业金融科技三次转型与四方向论-2019杨凯生口径]] 的"赋能非颠覆"立场构成 2019 年同期的清醒声音，可用于校准当年宣传性叙事的成色。
