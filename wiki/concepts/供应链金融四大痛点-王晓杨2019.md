# 供应链金融四大痛点（王晓杨，2019）

2019年王晓杨（[[entities/中车商业保理]] 总经理）访谈提出：解决小微融资难融资贵 = 解决供应链"三流"高效对称问题（[[concepts/三流合一信息对称论]]），当前存在四大痛点：

1. **信用难以穿透**：链式交易参与方多层次，核心企业信用可传递至一级供应商，难以覆盖更远端长尾中小企业。大商票拆小商票、平台可流转信用凭证部分缓解，但支持的流动性有限。
2. **中小企业数字化能力弱**：多数中小企业不知道什么数据有用、如何建库、如何使数据可信。
3. **核心企业动力不足**：核心企业提供数据与权属确认服务后得到的利益不直观、不具象，缺乏配合"三流合一"的激励。
4. **大数据应用水平偏低**：数据真实性判断难度大、成本高；区块链等技术或可改善。

## 关联与印证

- 痛点3 与 [[concepts/确权难与商贸身份介入]]、[[concepts/核心企业模式六重瓶颈-沈敏华]] 的"核心企业激励不足"主题相互印证。
- 属专家观点（2019年口径），非经核验事实。
