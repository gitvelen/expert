# 跨境担保外汇管理框架（2014）

2014 年《跨境担保外汇管理规定》（汇发〔2014〕29号）及其配套《操作指引》确立了跨境担保外汇管理的总体框架：**分类管理 + 登记制 + 事后监管**。

## 四类业务分类

| 类型 | 管理方式 |
|---|---|
| 内保外贷 | 登记制 + 融资性限额 + 资金用途负面清单 |
| 外保内贷 | 四要件限定范围 + 履约负债限额 + 事后核查 |
| 物权担保 | 外汇局只管外汇事项，不管担保物权合法性 |
| 其他形式跨境担保 | 原则上免登记、免备案，自行签约 |

## 管理思路转变

从"事前审批"转向"登记 + 事后监管"：担保人在合规前提下可自行对外签约；外汇局负责登记、形式审核与事后核查；担保物权合法性、债务人清偿能力等实质风险由担保人自行确认承担（见 [[跨境担保物权担保外汇分工原则]]）。

## 内部张力

名义上放松管制，但保留大量"未经外汇局批准不得……"的兜底条款及移交外汇检查部门的处罚机制，实际是"松形式、紧实质"。

## 时点性

50% 净资产限额等具体数值为 **2014 年时点规则**，后续 SAFE 文件（如 2017 年汇发 3 号）已有调整，引用时须注意时点。

## 排除情形

六类跨境承诺不按跨境担保纳入外汇管理：不具契约性质、履行不含付款义务、不产生对应债权、已由其他部门有效管理（如即期信用证、进口远期信用证、信用保险）、多环节交易中已有一个环节受管（如境内保证金/反担保）、及其他外汇局认定的情形。
