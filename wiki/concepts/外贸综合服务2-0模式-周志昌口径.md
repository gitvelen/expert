# 外贸综合服务2.0模式（周志昌口径）

## 1.0 与 2.0 的区别

- **1.0（约2013年起的传统外综服）**：做好境内段的通关、物流、退税等代理服务即可生存。
- **2.0（约近五年演进）**：中小企业已变为多业态、跨链条、跨国经营主体，外综服必须将服务边界从境内延伸至境外，同步出海。

## 2.0 四特征

1. **平台化**：真平台 = 集聚能力 + 整合能力（将关务、物流、银行、税务、单一窗口等第三方接入平台系统）；初期宣称平台而无整合实质者为“伪平台”。
2. **本土化**：境外本地化服务（集中报关、海外落地“微服务”）；价格术语模糊化——CIF→FOB→DDP/DAP“送到海外仓”。
3. **金融化**：将中小企业经营数据整合入链条开展订单融资、应收账款融资，加强与银行合作；周自2014年尝试“牧羊犬”模式，十余年推进艰难，承认民企风控能力有限。
4. **生态化**：最高形态，衍生综服平台、产业链平台、跨境物流平台、电商服务平台、跨境服务平台等多个专业平台。

## 行业主力变迁（演讲判断，2026口径）

2024年起国企外贸集团（湖南、四川、广东等）凭借资源整合与抗风险优势成为外综服新主力；2025年底《对外贸易法》修改将外综服支持上升至法律层面（演讲转述，待核验）。
