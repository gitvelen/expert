# 应收账款融资四层还款来源与四类产品风控（2015口径）

2015 年互联网供应链金融平台以应收账款融资为主时的分层还款来源设计与四类典型产品，出自任军霞《供应链金融的交易模式和风控关键点》（[[sources/4-news--7-04-业务基础--4-2015--21-供应链金融的交易模式和风控关键点供应链培训--mkq20d]]）。是"核心企业/央企支付信用兜底"叙事的典型结构样本，与 [[concepts/核心企业兜底低风险叙事-2015口径]] 互相印证。

## 四层还款来源（原文结构）

1. 第一层：应付账款方（央企或大型国企）
2. 第二层：融资人/应收账款方（上游企业）
3. 第三层：产品增信机构（若有）
4. 第四层：保理机构

## 四类产品与风控关键点

### 1. 央/国企支付信用类

三重保障：央企支付信用 + 融资人承诺回购 + 第三方资产管理公司回购保障。风控关键点：把控支付核心——央企，自主研发准入模型（定性+定量指标）严格准入；自建动态跟踪监测系统（自主获取信息、公开披露、媒体报道、社交网络信息），预警即停止新增业务。

### 2. 核心企业支付信用类

三重保障同上（支付核心换为大型企业）。风控关键点：大型企业准入模型 + 贷后动态监测，预警即停止新增业务。

### 3. 融资租赁应收租金收益权类

五重还款来源：承租企业支付信用 / 担保企业保证支付 / 承租企业实控人连带责任保证 / 融资租赁公司不可撤销回购担保 / 第三方资产管理公司回购保障。风控关键点：把控承租企业、担保企业之外，还需贷前严格融资租赁公司准入、贷后动态监测其财务数据、运营机制与征信，预警即停止新增业务。

### 4. 商业写字楼租金收取权类

三重保障：租户支付信用 + 业主保证支付 + 第三方资产管理公司回购保障。风控关键点：严格物业公司/业主准入（租后管理机制、房产所有权属），动态监测租户企业性质、征信与出租率，预警即停止业务。

## 共同风控范式

定性+定量结合的准入模型（贷前）+ 自建动态跟踪监测系统（贷后）+ 预警即停止新增业务。交易主体众多（核心企业、融资企业、融资租赁公司、担保企业、物流企业、第三方资产管理公司），交易结构设计的严谨与贷前贷后风控的细致程度决定产品风险与平台存亡。

## 后续监管对照

该口径将"央企/大企业支付信用"列为第一还款来源、以"融资人回购+第三方资产管理公司回购"叠加兜底，此类回购担保兜底结构与主体信用依赖在后续监管演进中被压缩否定（见 [[queries/查询-第三方资产管理公司回购增信模式在后续监管下的演变与合规结局]]）。本页仅作 2015 年风控设计样本收录。
