# 融资租赁项目风险评审四原则与五步程序（2017口径）

## 定义

2017 年投融界科普文章（贸易金融转载）提出的融资租赁项目风险评审方法论框架：以**安全性为第一要义**，遵循重要性、真实性、稳健性、安全性四原则，按五步程序对项目进行综合评价。

## 四大原则

| 原则 | 要点 |
|---|---|
| 重要性 | 从报告使用者与具体环境判断关键因素，兼顾效率与效果 |
| 真实性 | 真实、可靠、可验证；应对承租人信息不对称与资料虚构 |
| 稳健性 | 或有收入按保守值、或有支出按最大值计算 |
| 安全性 | 第一要义；无切实风险防范措施的项目不予考虑 |

## 五步评审程序

1. **可行性报告评审**：先做“不可行性分析”，再综合评价；流动资金配套留有余地；预测盈利能力与经营现金流（偿还租金的第一来源）。
2. **承租人与供货厂商资信评审**：偿还能力（定量）+ 偿还意愿（实际控制人人格、信用记录）；供货商考核产品质量稳定性与处置履约能力。**局限**：资信调查因信息不对称与租赁期长，不能作为事前风险预防的主要依赖。
3. **租赁物件评审三要件**：质量技术可靠；价格相对稳定（防止承租人理性违约）；通用性强、易处置变现。
4. **交易结构评审（核心）**：结构应使承租人与供货商主观上不愿违约，违约时有人分担风险。
5. **担保评审（补充）**：仅在结构与物件存在评审缺陷时需要。优劣序列：连带担保＞一般保证；房地产抵押＞设备货物抵押；存单质押＞仓单质押；银行信用＞企业信用。

## 证据强度

专业公众号分析（经验性论述，无案例数据），弱于监管原文与书籍层级。
