# 融资租赁审慎监管指标体系（2020 征求意见稿口径）

《融资租赁公司监督管理暂行办法（征求意见稿）》（2020 年 1 月，银保监会）新增的审慎监管指标。证据层级：监管原文（强）。

## 指标原文数值

| 指标 | 上/下限 |
|---|---|
| 融资租赁和其他租赁资产比重 | ≥ 总资产的 60% |
| 风险资产总额 | ≤ 净资产的 8 倍（由原 10 倍收紧） |
| 固定收益类证券投资业务 | ≤ 净资产的 20% |
| 对单一承租人的全部融资租赁业务余额 | ≤ 净资产的 30% |
| 对单一集团的全部融资租赁业务余额 | ≤ 净资产的 50% |
| 对一个关联方的全部融资租赁业务余额 | ≤ 净资产的 30% |
| 对全部关联方的全部融资租赁业务余额 | ≤ 净资产的 50% |

## 配套安排

- 达标过渡期：不超过 2 年；过渡期内原则上暂停融资租赁公司登记注册；存量企业须在 1–2 年内达标
- 租赁物范围、集中度管理与《[[金融租赁公司管理办法]]》基本一致
- **区别对待**：不采用金租的资本充足率（资本净额与风险加权资产比例）要求，理由是融资租赁公司在金融属性、股东背景、成立目的上与金租差异较大（银保监会答记者问口径）

## 与保理监管对照

相较 [[关于加强商业保理企业监督管理的通知|银保监 205 号文]] 确立的 2020 年 6 月达标期限，本《办法》过渡期更为宽松。两套指标共同构成"三类机构强监管"框架（另见 [[上海三类机构监管红线-2019口径]]）。
