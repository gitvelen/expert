# 供应链金融1.0至3.0演进框架

将供应链金融发展划分为三个阶段的行业通用分析框架：由商业银行主导的1.0，到核心企业主导的2.0，再到平台生态化的3.0。本文口径出自2020年万联研修班课程纪要（"宋老师"主讲）。

## 三个阶段

| 阶段 | 主导方 | 特征 |
|---|---|---|
| 1.0 | 商业银行 | 银行围绕核心企业对上下游提供应收账款/存货类融资 |
| 2.0 | 核心企业 | 制造、流通、物流企业基于自身业务与资产嫁接金融服务 |
| 3.0 | 平台生态 | 多边/跨边市场平台连接供方、需方、金融方等众多参与者 |

## 3.0 平台生态化的三层面变化（以欧冶云商为例）

1. **组织层面**：连接更多产业主体，形成多边市场与跨边市场，创造丰富的产业场景。
2. **流程层面**：管理流程不限于交易、物流，扩展至支付、清算、资产交易等。
3. **风控层面**：除把握交易与物流要素外，还需通过先进分析等技术手段实施风险管理。
