# 前交所"N+N+N"模式ABS（2020口径）

前海金融资产交易所 2019 年开创的供应链金融 ABS 模式：每期专项计划可同时存在 **N 个原始权益人、N 个核心企业和 N 种资产确权方式**（商票/确权/电子付款承诺函）。

## 优势（原文口径）
- **风险分散**：风险从一家核心企业分散到 N 家核心企业。
- **降低发行门槛**：以往 ABS 围绕少数大型核心企业，进入门槛极高；以多家核心企业底层资产搭配发行，覆盖更多企业，朝普惠金融方向推进。

## 背景
2019 年供应链金融 ABS 市场发行提速明显，仅前 8 个月发行量即超越 2018 年全年。该模式与联易融的 [[concepts/1+N+N担保模式ABS-2020口径]] 构成两条 ABS 创新路径，对比见 [[comparisons/1加N加N与N加N加N两种供应链ABS模式对比-2020口径]]。
