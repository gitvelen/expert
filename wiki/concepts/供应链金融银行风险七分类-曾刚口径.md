# 供应链金融银行风险七分类（曾刚口径）

供应链金融银行风险七分类是 [[曾刚]]（上海金融与发展实验室主任）在 2024 年 7 月接受《中国经营报》采访时提出的银行视角供应链金融主要风险点分类框架（专家观点口径，证据强度中等）。

## 七类风险

| 风险类型 | 内涵 |
|---|---|
| 信用风险 | 核心企业或上下游企业违约，导致银行信用损失 |
| 操作风险 | 业务流程复杂，操作失误导致损失 |
| 欺诈风险 | 企业通过虚假交易、重复融资等方式欺诈 |
| 技术风险 | 系统故障、数据泄露影响业务运营与安全 |
| 法律风险 | 多方主体参与，合同纠纷及其他法律风险 |
| 市场风险 | 供应链所在行业市场波动影响企业还款能力 |
| 跨境风险 | 跨境业务面临更复杂的政策、汇率风险 |

其中"欺诈风险"（虚假交易、重复融资）与知识库"融资性贸易/虚假贸易"主题直接相关，可与货权管控、贸易背景真实性核验等风控概念对照使用。
