# 破产重整“资本公积转增+引入投资人”模式

司法重整中上市公司化债与控制权重塑的典型路径：以资本公积金转增股份，转增股票分三部分使用——引入产业投资人（低价、取得控制权）、引入财务投资人（较高价、补充增量资金）、以股抵债（直接削减债务）。实现“一举三得”：化解债务风险、引入真金白银、重塑治理结构。

## *ST新研案例结构（2025 年，公告口径）

```
总股本：约14.96亿股 → 32.9亿股（转增17.95亿股）
- 产业投资人：新疆商贸物流集团，1.3元/股 × 5亿股 = 6.5亿元（15.2%，取得控制权）
- 财务投资人：外贸信托等14家，1.7元/股 × 9.35亿股 = 15.89亿元（28.41%）
- 抵债股份：3.6亿股
- 重整投资款合计：约22.39亿元（2025-12-18到账）
```

## 结构性特征与风控视角

- 产业投资人与财务投资人存在价格差（1.3 vs 1.7 元/股），低价+低持股（15.2%，非绝对控股）取得控制权，其稳定性依赖原实控人稀释程度（本例稀释至 4.92%）与表决权安排，需逐案核验。
- 该模式是国资纾困本地上市公司、防止控制权外流的常用工具，也常成为国企“揽壳”的合法通道，需结合后续资产注入行为判断真实意图。
