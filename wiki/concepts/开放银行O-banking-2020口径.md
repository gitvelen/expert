# 开放银行（O-banking，2020口径）

**开放银行**是指开放自身的金融服务 API（Application Programming Interface）给第三方使用的银行。本文将其定位为直销银行与手机银行同质化日益严重之后商业银行的转型方向（2020 年口径）。

## 背景数据（原文口径）

- BCG 研究：全球零售银行互联网+移动渠道销售与咨询份额，2012 年 15% → 2020 年预期 40% 以上。
- 截至 2018 年 11 月底，国内 **135 家直销银行**（含直销银行、嵌入手机银行的直销银行和数字银行），产品以货币基金、存款、理财为主。

## 国内外案例

- **海外**：星展银行（DBS）、花旗银行（Citibank）、BBVA 积极打造 API 平台对外开放服务，提前占领与客户交互场景。
- **国内（2018 年以来试水）**：浦发银行 **API Bank 无界开放银行**；华瑞银行"**极限SDK**"；微众银行"**微动力**"开放平台；众邦银行"**众邦银行开放平台**"。

## 展望（2020 年口径）

商业银行应迭代开发移动端客户应用，突破理财销售平台的固有路径，运用大数据与云计算提供更复杂、精细、差异化的财富管理服务，避免同质化竞争。5G 将提升用户访问银行 API 交易的效率与安全性，并扩展至可穿戴支付、物联网授信等新场景（见 [[5G金融应用四场景-2020口径]]）。
