# 供应链金融A/B/C三层嵌套进口代理结构（2018口径）

出自 2018 年一篇问答式文章（[[sources/4-news--7-04-业务基础--4-2018--16-供应链金融仅仅是借贷吗供应链培训--max4pb]]），通过一笔典型进口代理业务拆解出一条供应链中嵌套三起供应链金融业务的结构，用以论证“供应链金融 ≠ 小微贷款，而是产业链中的串联模块”。

## 三层结构

| 层 | 内容 | 融资属性 |
|---|---|---|
| A | 境内委托人发起需求，供应链服务商向境外供应商（文中以 IBM 公司为例）开立信用证，并在境外完成物流、仓储、转运、报关、商检、保险等全流程服务后进口入境、按指定地点交货 | 信用证采购执行 + 境外全流程服务 |
| B | 境内委托人资金不足时，在三个月内向供应链公司争取灵活账期、阶梯性收费 | 占用供应链公司银行授信额度向下游企业融资 |
| C | 周期过长时，银行委托该供应链服务商看管货物做保理融资 | 供应链公司仅为收取保管费/服务费、具相应公允地位的货物监管商 |

## 菜单式融资品种与风险敞口

文中列举可能涉及的融资品种与服务：境内外采购执行、境外提货管理、远期外汇管理；支付方式涵盖信用证、押汇、代付、透支、提货担保、进口保函、备用信用证、委托人付款保函等。强调**按客户需求定制、如菜单摊开供选择，菜单不同意味着风险敞口完全不同**。

## 关联与复用价值

- C 环节“银行委托供应链公司监管货物 + 保理”与 [[concepts/反向明保理三要素与执行公司控钱结构-2018口径]] 中执行公司控货/控钱结构互相印证。
