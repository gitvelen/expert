# 地方政府供应链重点企业培育机制

国办84号文之后各省市普遍采用的供应链政策落地方式：由地方政府部门（通常多部门联合）发布培育通知 → 各市组织企业申报 → 专家按“公开公平公正”原则评选 → 公示认定名单 → 以政策倾斜培育龙头供应链企业、形成产业集群。本来源提供的样本是江苏2019年机制（详见 [[苏商建2019-476号通知]] 与 [[江苏省商务厅]]）。

## 机制要素（以江苏2019为例）

1. **目标设定**：数量化目标（“120家左右企业、20条左右产业链条”），叠加国家试点存量（33家国家试点企业）。
2. **多部门联合**：商务厅牵头，联合工信、农业农村、住建、地方金融监管等部门。
3. **程序**：各市正式上报 → 专家组评选 → 公示（含实名书面异议渠道）→ 确定。
4. **政策意图**：调动各地各行业企业参与积极性，培育行业带动力强的供应链领先企业，形成供应链体系完整、国内外市场竞争力强的产业集群。

## 知识库用途

此机制是各地普遍做法，跨来源可复用：可在分析报告中作为“中央政策 → 地方落地”的机制模板，与其他省市做法对比（如后续录入粤、浙、鲁等地名单来源后建 comparison 页）。

## 待核验
