# 供应链金融即服务（SFaaS）愿景（2018 口径）

## 内容

2018 年"区块链重塑供应链金融"一文对"新商业模式"的预言：区块链去除信任壁垒、交易透明化后，将催生真正意义上的供应链金融平台：

- **平台**：提供供应链信息、客户信息等"类似水电的基础服务"；
- **第三方中介机构**（保理机构、金融机构）：基于平台信息提供更精细、个性化的定制服务，如将应收账款按节点状态细分、建立差异化金融产品，并根据供应链实时状态持续评估标的资产与借款人；
- **算法公司**：基于平台 API 接口开发金融模型，出售给第三方金融机构和保理公司。

作者将此模式命名为"供应链金融即服务"（Supply Chain Finance as a Service），并设想了终端店主通过触摸屏 + 指纹验证 + 智能合同 + 区块链身份验证完成融资与自动理赔的场景。

## 证据强度

纯前瞻性推演，无落地证据，弱。属 2018 年区块链乐观叙事谱系，与 [[comparisons/区块链万能论与工具属性论对比]] 中"工具属性论"一方的怀疑立场相对。实际落地情况待追踪。
