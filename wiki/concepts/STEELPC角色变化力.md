# STEELPC角色变化力

[[产业链五力]]中的第五力，由[[赵今巍]]在《[[灰狼群效应]]》解读系列中提出，指在目标产业链市场内部推动交易结构变化的七类宏观因素：

| 字母 | 因素 |
|---|---|
| S | Social（社会/人口因素变化） |
| T | Technological（技术） |
| E | Economic（宏观经济变化） |
| E | Environmental / natural（环境/自然） |
| L | Legal（法律法规变化） |
| P | Political（政治） |
| C | Capital（产业金融资本） |

示例：餐馆冻品产业链市场中，"人造肉"新技术、新冠疫情、金融资本对冻品生产企业的兼并整合等。

## 与 PEST 的区别

传统 PEST 分析从宏观角度审视对特定产业链市场交易结构的影响；STEELPC 不仅考虑交易结构影响，还进一步基于"交易结构变动本质上是交易角色变动"的逻辑进行归类，故称"角色变化力"。
