# 票据包拆分机制

票据包拆分是 [[新一代票据业务系统]] 最显著的变化与标志性创新功能：出票人签发由标准金额（最小单位 0.01 元）票据组成的票据包，持票人在办理背书、贴现、保证、质押等业务时，可按实际支付金额将票据包分包流转使用，最小可拆至"分"。这大幅提升了票据作为支付/融资工具的颗粒度，尤其利好中小企业的零散支付结算场景。

## 机制要点

- 解决企业间结算金额不匹配的支付痛点，宋汉光概括为"想付多少、就付多少"。
- 票据业务首次在**全市场**实现"找零支付"功能。

## 票据号码编码规则

- **票据包号**：30 位数字票据号码，与原票据号码规则的区别在首位——5 为银票、6 为商票；通过供应链平台签发的银票、商票分别为 7、8。
- **子票区间**：数字区间，标识票据包中的单张标准金额票据。为"0"表示不可拆分；如 1-1000000 表示票据包金额为 10000.00 元。

## 分包环节边界

| 环节 | 是否支持分包 |
|---|---|
| 签发 | 否 |
| 转让背书 | 是 |
| 质押/解除质押 | 是 |
| 贴现 | 是 |
| 转贴现 | 暂不支持 |
| 回购 | 暂不支持 |

## 配套机制

- **批量清算专户**：拆分后票据包数量级大幅增长，票交所设专户居间收付款，实现"先收后付"批量清算，替代原逐笔清算。
- **提示付款**：银票到期自动发起/自动应答；商票自动发起、付款人或开户行手动应答。

## 落地状态（时效性口径）

- 2022-04-08 口径：系统即将上线，拆分功能待落地。
- **2022-06-13 专访口径：新系统已于 2022-06-03 正式投产，拆分/找零支付功能正式落地**；但 2022-08-20 起方组织首批市场成员投产，全市场切换至 2023 年底前完成（2022 年口径，后续实际进展见 [[查询-新一代票据业务系统上线时间与功能验收的实际落地情况]]）。

## 对中小微企业的意义

票据签发与贴现是中小微企业获得信用与资金支持的渠道，拆分功能缓解了票面金额与实际结算金额错配问题，并通过背书转让沿产业链传导信用支持，是支付结算工具数字化的典型基础设施案例。
