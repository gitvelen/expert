# 互金平台切入供应链金融的动因与物联网风控应用（2018口径）

## 一、切入动因（2018年报道口径）

1. **资产端争夺**：2017年网贷强监管"洗牌"下，互金平台焦点转向深度挖掘优质资产端。
2. **监管合规倒逼**：《网贷监管细则》《网贷信息披露指引》《网贷登记备案指引》《网贷资金存管指引》等出台，倒逼平台专注细分领域。
3. **政策红利**：国办发〔2017〕84号 [[entities/关于积极推进供应链创新与应用的指导意见]] 要求供应链金融服务实体经济。
4. **双端需求**：汽车等产业链同时产生 B 端（供应链贸易融资）与 C 端（个人消费）金融服务需求。

> 与 [[sources/4-news--7-02-产品案例--4-2017--25-投资需求量更强-好车贷加快布局供应链金融供应链方案--1yid650]] 的 P2P 转型叙事同源，本文提供平行进口车细分变体。

## 二、物联网+区块链风控应用（以诺云汇为例）

- **车联网/物联网**：电子标签、无线射频（RFID）、GPS 实现质押车与订单车的"车辆溯源""标的跟踪"，投资人可查询跟踪所投项目车辆状况。
- **区块链**：用于电子合同管理。
- **质押材料审查**：关单、商检、车辆一致性证书、车辆购置发票。
- **第三方核验**：通过海关、银行等核查，防止空单质押与重复质押。
- **资金端**：银行资金存管作为合规基础。

## 三、知识定位与时效提示

- 物联网货控与防重复质押核查是"以物的信用替代主体信用迷信"工作论点的落地实例。
- 本页为 **2018年软文口径**，效果未经第三方数据验证；网贷撮合模式在后续 205 号文及 P2P 清退监管下的合规性文中未讨论，引用时须标注时代局限。
