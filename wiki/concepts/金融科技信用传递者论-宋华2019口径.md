# 金融科技信用传递者论（宋华 2019 口径）

宋华在 2019 年第五届中国供应链金融创新高峰论坛上提出的角色定位论：**金融科技不是产业信用的创造者，而是产业信用的传递者与金融生态的促进者**。真正的信用创造者是供应链中的企业；技术的作用是让信息更透明从而传递信用，并通过预示风险让投资者了解和管理风险、促进资金流动。

## 与 2017 年技术乐观论的关系

该口径实际收窄了 2017 年媒体口径中"区块链从根本上解决贸易背景真实性"的乐观论（见 [[区块链解决贸易背景真实性的2017乐观论]]，已标注实践修正）：技术只能**客观反映与传递**信用，不能替代业务背景真实性本身。

## 对产品设计的含义

- 风控设计应以真实贸易背景为前提，技术用于细粒度管控而非凭空创造信用；
- 金融科技的价值验证标准是信用能否沿供应链传递、风险能否被预示，而非技术栈本身。

证据强度：专家演讲转述（专业公众号分析层），观点性论述，无实证数据。
