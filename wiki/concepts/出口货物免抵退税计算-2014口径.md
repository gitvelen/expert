# 出口货物"免、抵、退"税计算（2014口径）

"免、抵、退"税是针对生产企业自营出口货物的增值税处理办法："免"指出口环节免征增值税，"抵"指内销应纳增值税以内销项抵顶进项，"退"指未抵顶完的进项税额予以退还。该机制是出口贸易背景真实性核验与出口贸易融资风控（退税应收款核验）的基础工具。以下公式转引自 [[sources/4-news--7-04-业务基础--4-2014--17-干货50套会计常用公式贸易融资产品--qyk24q]]（2014 年口径，暗合国税总局通行规则；税率等以现行税法为准，17% 征税率为 2014 年口径，现行已为 13%）。

## 一、免抵退税额

```
免抵退税额 ＝ 出口货物离岸价 × 外汇人民币牌价 × 出口货物退税率 − 免抵退税额抵减额
免抵退税额抵减额 ＝ 免税购进原材料价格 × 出口货物退税率
```

免税购进原材料包括国内购进免税原材料和进料加工免税进口料件；后者价格为组成计税价格：

```
进料加工免税进口料件组成计税价格 ＝ 货物到岸价格 + 海关实征关税 + 海关实征消费税
```

## 二、当期应退税额与免抵税额

- 当期期末留抵税额 ≤ 当期免抵退税额时：应退税额 = 期末留抵税额；免抵税额 = 免抵退税额 − 应退税额
- 当期期末留抵税额 > 当期免抵退税额时：应退税额 = 免抵退税额；免抵税额 = 0（期末留抵税额为《增值税纳税申报表》"期末留抵税额"）
- 当期有应纳税额时：免抵税额 = 免抵退税额

## 三、免抵退税不得免征和抵扣税额

```
不得免征和抵扣税额 ＝ 当期出口货物离岸价 × 外汇人民币牌价 ×（征税率 − 退税率）− 抵减额
抵减额 ＝ 免税购进原材料价格 ×（征税率 − 退税率）
```

## 四、新发生出口业务企业

自首笔出口业务起 12 个月内，不计算当期应退税额，当期免抵税额等于免抵退税额；未抵顶完的进项税额结转下期继续抵扣，自第 13 个月起按上述公式计算应退税额。

## 五、前提条件与供应链金融意义

生产企业货物出口后，必须在**口岸电子执法系统出口退税子系统**查询到报关单出口信息，方能计算免抵退税。这一"报关信息可查询"前提正是出口贸易融资中核验退税背景真实性的抓手：退税应收款融资须以可核查的出口报关与免抵退核算为锚，防止虚构出口骗取融资。
