# 供应链金融五阶段演进（联易融杨强口径）

[[杨强]] 2021 年 12 月演讲提出的供应链金融发展阶段框架（厂商叙事口径）：

| 阶段 | 标志 |
|------|------|
| 1.0 | 线下 1+N 模式（1998-99 年深发展/现平安银行"第一单"起） |
| 2.0 | 线上化，银行对接核心企业 ERP |
| 3.0 | N+1+N 模式 |
| 4.0 | 技术渗透到经营 |
| 5.0 | N×N 生态圈模式 |

## 5.0 与 1.0-4.0 的关键区别

5.0 进入**生态圈模式**，脱离核心企业中心化带动；1.0-4.0 依然聚焦核心企业，依靠核心企业信用带动小微企业融资。

## 与学界框架的对比

- 与[[宋华]]的"天平模型"“三链融合”框架并存但立场不同：宋华批判核心企业中心化（"二银行"心态），杨强的 5.0 论从科技服务商视角出发主张生态圈化，二者在"去核心企业化"方向上呼应，但方法论与论证基础不同。
- 市场规模口径勿与宋华"27 万亿应收账款"混用：杨强口径为**应收账款融资规模**（2018 年约 5 万亿，年增 15%，2023E 12.6 万亿），宋华为应收账款总额口径。
