# 供应链金融 1.0/2.0/3.0 演进论（2017 鲍广口径）

海平线 CEO 鲍广在 2017 年提出的中国供应链金融三阶段演进框架（属专业观点，非行业定论）：

## 1.0 时期："1+N"模式
最早由银行子公司（如深发展）、核心企业及转型 ERP（如用友、汉得）主导，对接核心企业及其上下游和物流服务商，实时掌握经营情况以控制融资风险。

## 2.0 时期："互联网+"模式
互联网技术深度介入，以综合服务平台代替核心企业给中小企业提供信用支持，向更垂直细分、更精准专业的方向发展。代表：电商（苏宁、京东）、行业资讯（上海钢联）、信息化服务商（汉得）、供应链服务商（怡亚通）、核心企业（海尔、瑞茂通）。

## 3.0 时期：生态化
供应链金融趋向产融结合的平台化与生态化：不再单向流动的价值链，而是跨产业跨区域跨部门，与政府、行业协会、产业资本广结联盟，运用互联网、云计算、大数据、区块链等技术创建金融生态系统；平台是价值整合者、多边连接者、多方共赢的新型商业生态系统。鲍广将其概括为"互联网+产业+金融"。

## 评价

3.0 的"生态化"愿景由海航系平台提出，而海航集团后续破产重整，说明愿景叙事与落地能力之间存在巨大落差；该演进论可作为模式史脉络参考，不宜作为价值判断标准。可与 [[synthesis/中国供应链国家政策演进2016-2026]] 的政策脉络并列，构成"模式演进"与"政策演进"两条线索。
