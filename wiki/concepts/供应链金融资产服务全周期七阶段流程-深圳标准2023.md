# 供应链金融资产服务全周期七阶段流程（深圳标准2023口径）

依据《商业保理公司供应链金融资产服务操作指南》（2023）第 4 章，商业保理公司开展供应链金融资产服务的全周期依次为：**准入尽调 → 项目论证及申报 → 资产收集 → 资产审核 → 转让支付 → 存续期 → 回款**。以下为各阶段操作要点（原文结构保留）。

## 1. 准入尽调阶段

- **主体尽调**：
  - 对核心企业：偿债能力与盈利水平、付款流程规范性、应收账款审批支付流程与资料、资信与不良记录；
  - 对供应商：主体资格、交易资格（资质/许可/备案）、偿债能力与资信。
- **贸易背景尽调**：了解行业规则与该行业应收账款交易特点、付款周期；通过现场核实、材料交叉验证（实地走访抽查基础交易）核实交易真实性、购销关系稳定性、账龄结构、产品组成、周转率、坏账率。

## 2. 项目论证及申报阶段

配合提供尽调资料；从资产合规性与操作便利性角度为产品方案提供意见；提供适用的法律性文本模板。

## 3. 资产收集阶段

宜从核心企业获取资产数据，确认资产已通过核心企业内部审批但尚未支付、未收到其他债权转让通知；设专人对接债权人及债务人。

## 4. 资产审核阶段

总原则：审核"宜以保证资产真实性、合法性和有效性，防范重复融资或重复转让等风险为目的，不宜以满足审核流程的完整为目的"。八项要点：

a) 主体资格核查（债权人、债务人、核心企业合法设立并有效存续）；
b) 资质核查（公开网站核实资质证明）；
c) 贸易背景真实性核查（书面审查 + 第三方数据辅助核查 + 现场核实）；
d) 应收账款转让合法性核查（转让限制条款、转让通知手续）；
e) 中登网排他性查询和登记（[[中登网]]逐笔排查转让、质押记录，对无权利负担资产登记）；
f) 应收账款特定化核查（基础合同、发票、履约证明、转让合同、债权转让通知书及回执、确权文件真实有效）；
g) 控制入池应收账款集中度及关联交易比例；
h) 建立台账记录每笔资产信息及金额。

另宜设初审、复审、抽查等多道审核程序，专人专岗。

## 5. 转让支付阶段

与债权人签署转让协议 → 完成中登网排他登记 → 通知债务人及核心企业 → 取得债务人书面知悉文件 → 支付转让对价。**再转让**（再保理给商业银行、转让给专项计划发行 ABS）同样须签署转让协议、完成中登网排他登记、通知并取得书面知悉文件。

## 6. 存续期阶段

组建存续期管理团队；建立制度体系（对债务人及核心企业定期/不定期实地走访，关注重大诉讼、股权变更、负面舆情；标准化产品按监管要求定期汇报并持续监控基础资产合法性有效性）；记录管理结果；按需出具资产服务机构报告。

## 7. 回款阶段

回款到期日前提示债务人及核心企业按时偿付并跟踪进度；到期未兑付时协助追偿。

## 与知识库工作论点的关联

该流程将"贸易背景真实性"原则转化为可执行 checklist；中登网逐笔排他登记是登记优先规则的实务操作化；智能化审核（规则引擎 + 发票图像识别 + 中登网 NLP 解析）是"数据信用"替代人工审核的操作层落地路径。
