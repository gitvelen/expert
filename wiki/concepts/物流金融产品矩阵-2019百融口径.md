# 物流金融产品矩阵（2019 百融口径）

[[百融云创]] 自述基于物流管理服务平台、嵌入物流交易环节设计的核心物流金融产品：

| 产品 | 嵌入场景 |
|------|----------|
| 订单融资 | 物流业务订单环节 |
| 云仓融资 | 仓储环节 |
| 运费贷 | 运费结算环节 |
| ETC贷 | 高速通行/运输履约环节 |

定位为助力“物流、交易和金融服务高效协同”，覆盖信贷全流程与核心物流场景。作为 2019 年物流金融产品形态快照记录；实际放款规模与存续情况待考证（见 [[查询-百融云创物流金融产品实际放款规模与千亿信贷潜力出处考证]]）。
