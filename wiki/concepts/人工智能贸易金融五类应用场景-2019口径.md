# 人工智能贸易金融五类应用场景（2019口径）

2019 年"贸信数金"作者守仁提出的 AI 在贸易金融领域的五类应用场景框架，属框架性观点论述，无实证数据支撑（专业公众号分析层，观点性内容）。来源：[[sources/4-news--7-05-数字科技--4-2019--16-贸易金融的智能化研究贸易融资资讯--1j39nja]]。

## 五类场景

1. **信用风险管理智能化**：深度学习对客户与产品形成多维度认知，结合大数据实现信贷审查与审批智能化，作为"大数据信贷的升级版"。
2. **计算机视觉改造节点模式**：替代节点中人工的数据转换与确认，提高效率与准确性。
3. **智能语音语义处理标准报文**：对 SWIFT 标准格式报文的关键与常用条款进行解读，实现报文自动化处理，辅助识别风险条款。
4. **黑名单检测智能化**：整合联合国及各国制裁政策规则，与贸易金融涉及信息比对判断，优化检测减少误中概率。
5. **智能推荐优化整体服务方案**：整合全球市场与风险信息促进交易达成，整合金融机构产品为交易双方设计综合服务方案。

## 信用证8节点流程（原文要点）

进出口商签订买卖合同 → 进口商申请开证 → 开证行开证 → 通知行通知 → 出口商发货并交单 → 议付行审单并寄单 → 开证行审单 → 付汇。每个节点以人工驱动进行信息转换与确认；计算机视觉提效在节点越多时效果越明显，贸易金融复杂节点关系有望因此趋于扁平。
