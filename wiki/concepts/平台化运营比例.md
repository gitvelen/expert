# 平台化运营比例

《[[广州市重点供应链服务企业认定办法试行2022]]》定义的量化指标：企业运用信息平台进行业务运营或提供服务的比例。

计算公式：

```
平台化运营比例 = 企业运用信息平台进行业务运营或提供服务的单数 / 企业业务运营或提供服务的总单数
```

认定门槛：生产制造型、商贸流通型不低于40%，网络平台型不低于70%。该指标反映供应链服务企业信息化与平台化程度，与认定条件中"经营业务信息全部实现网络化管理、与主要客户实现电子数据交换"的信息化水平要求相呼应。
