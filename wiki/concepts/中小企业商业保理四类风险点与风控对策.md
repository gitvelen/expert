# 中小企业商业保理四类风险点与风控对策

2019 年实务科普口径（爱保理/贸易金融，无定量数据，属作者经验性归纳），作为面向中小企业的商业保理尽调与贷后管理检查清单有实用价值。

## 四类风险点

1. **财务管理不健全**
   - 财务与出纳岗位不分离，一人多岗，印章与网银盾由一人保管 → 资金易被恶意转移。
   - 财务人员专业能力不足，报表混乱 → 尽调成本高。
   - 货款打入经营者**个人账户**（避税动机）→ 回款失控与合规风险。
2. **经营不规范**
   - 无法务岗位、未签正式合同或合同不规范；缺政府许可/行业准入 → 转让的应收账款可能不合法。
3. **应收账款分散、核算量大**
   - 小额、多笔、客户数量大；典型场景：房屋租赁企业（租客个人化、退租频繁、应收账款持续更替）。
4. **资金易被挪用**
   - 轻资产、无可抵押物，违约后难向企业追偿。

## 六项风控对策

| 对策 | 要点 |
|------|------|
| 财务规范化 + 银企互联 | 签订银企互联协议，网银实时监控资金流；**要求应收账款回款全部回流保理公司账户，不得打入个人账户** |
| 经营规范化 | 合规培训、合同重新梳理、提醒取得许可/准入，使保理资产合法化 |
| 智能应收账款管理系统 | 授信、尽调、审核、放款、回款、利息/手续费核算、尾款清分全流程线上自动化 |
| 实控人个人担保 | 要求实际控制人/经营者提供**无限连带责任担保**或个人固定资产抵押 |
| 投保信用险 | 转移坏账风险；地方有保费补贴（见浦府【2015】152 号文） |
| 政府激励 | 建议性诉求，非风控手段 |
