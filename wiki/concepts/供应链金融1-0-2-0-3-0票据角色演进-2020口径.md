# 供应链金融1.0/2.0/3.0票据角色演进（2020口径）

来自2020年4月专业媒体文章（[[sources/4-news--7-03-行业研究--4-2020--29-票据在供应链金融中如何助力中小微企业缓解融资难题供应链融资--1g9ei91]]）的阶段划分，属2020年多种演进叙事并存之一（与 [[concepts/数字供应链金融三阶段-宋华2020口径]] 的"金融在线化—数字金融化—智慧金融化"为不同口径）：

- **1.0（1+N，线下）**：基于核心企业授信，上游供应商、下游分销商与核心企业赊销赊购，票据在其中发挥支付结算作用；但多发生在线下，效率低、信息不对称。
- **2.0（互联网网状）**：信息流、物流、资金流、商流经互联网传递，不再局限于一条产业链，形成以核心企业为中心的网络；票据除单一链条支付结算外，可在任一网络节点形成**票据池融资**。
- **3.0（N+1+N，平台）**："1"不再是核心企业，而是**供应链服务平台**，搭建网状平台，提高效率、实现批量授信；供应链从"1+N"走向"N+N"，需要贯穿全生命周期的金融产品匹配。

## 基础设施支撑

[[entities/上海票据交易所]] 的建立与 ECDS 系统的建成为票据业务线上化提供基础支撑；背书、交易在票交所系统中全部留痕，便于追查信用主体，为供应链金融生态提供可能。

## 张力提示

"供应链3.0 = N+1+N（1为平台）"的平台定义与沈亦文、宋华等口径的平台定义不完全一致，引用时须注明出处与语境。
