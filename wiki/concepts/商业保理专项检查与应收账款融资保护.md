# 商业保理专项检查与应收账款融资保护

指地方金融监管部门对商业保理公司开展的以保护中小企业应收账款融资权益为核心的定向合规检查。典型案例为2022年6月河南省对12家商业保理公司的专项检查。

## 核心内容（四个检查方面）

1. 大型企业利用优势地位设置不合理交易条件；
2. 垄断限制中小企业供应商应收账款融资；
3. 保理融资息费不合理；
4. 其他侵害中小企业供应商合法权益的行为。

## 监管方法论：问题导向 + 分级闭环

- **分级报送**：公司自查（7月14日前）→ 省辖市金融工作局现场检查与专项检查报告（8月21日前）→ 省局汇总；
- **全方位检查手段**：第三方中介参与、账册/合同/信息系统/供应链金融服务平台数据核查、举报电话、延伸调查、监管谈话等；
- **梯度处置**：约谈高管 → 立即整改 / 限时整改 → 行政处罚或约束惩戒 → 行业退出 → 移送司法。

## 内部张力

通知一方面以保护中小企业为目标，另一方面检查对象是商业保理公司而非拖欠账款的大型企业（行为主体），反映出监管以金融机构为抓手的间接治理路径。
