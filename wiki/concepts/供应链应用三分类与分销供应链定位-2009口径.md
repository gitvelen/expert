# 供应链应用三分类与分销供应链定位（2009口径）

该分类出自 2009 年 CIO 时代文章（经“供应链金融”公众号转载），将供应链管理应用按范围分为三类，并各自对应不同的系统平台：

| 类别 | 范围 | 实现平台 |
|------|------|----------|
| 广义供应链 | 企业对企业（B2B），属社会性问题 | 电子商务 B TO B / SCM 供应链管理系统平台 |
| 狭义供应链 | 企业内部，部门与部门之间 | ERP 系统平台 |
| 渠道分销供应链 | 销售型企业，销售渠道中的供应链问题 | 分销供应链管理系统平台 |

## 分销公司的双向数据结构

文章对具规模分销公司的物流管理数据结构做了抽象建模（依据文字描述还原，原刊配图未获取）：

```
a点（物料需求方向，多对一）：专卖店 → ... → d节点 → c节点 → b节点（分销总公司）
    终端需求逐级汇总上传，是公司产品计划的关键数据。
b点（物料供应方向，一对多）：分销总公司(b) → c节点 → d节点 → ... → 专卖店
    货物自总公司逐级配送到终端。
```

## 时效性说明

此为 2009 年媒体科普口径的分类框架，用于理解早期中文供应链管理的概念基座；当代实践中三类边界已因云平台与实时数据共享而模糊化，引用时须注明年份口径。相关主题见 [[concepts/牛鞭效应成因与在线分销计划多层次净需求推算法-2009口径]]。
