# 标准化投资品八分类及估值方法

[[商业银行理财产品核算估值指引征求意见稿2019|《商业银行理财产品核算估值指引（征求意见稿）》]]（2019）将标准化投资品细分为八类，并明确各自的会计分类与估值方法。整体格局为：多数按公允价值计量，存款按成本法。

| 类别 | 会计分类 | 估值方法 |
|---|---|---|
| 权益类证券 | 以公允价值计量且其变动计入当期损益的金融资产 | 公允价值；首次发行未上市股票在未上市期间按发行价格估值；送股/转增/配股/公开增发未上市且无明确限售期的，按估值日在交易所上市的同一股票收盘价或最近交易日收盘价 |
| 固定收益类证券 | 鼓励公允价值；满足[[理财产品摊余成本双条件约束]]可按摊余成本计量 | 公允价值或摊余成本；财政部、央行、银保监会另有规定从其规定 |
| 配股权 | 以公允价值计量且其变动计入当期损益的金融资产 | 活跃市场按估值日未经调整报价；无活跃市场采用估值技术 |
| 存款 | 以摊余成本计量的金融资产 | 成本法：以成本列示，按商定利率在实际持有期间内逐日计提利息 |
| 证券投资基金 | 以公允价值计量且其变动计入当期损益的金融资产 | 公允价值 |
| 衍生品 | 以公允价值计量且其变动计入当期损益的金融资产 | 三级路径：活跃市场未经调整报价→报价不代表性时调整→市场活动少时估值技术；非上市且第三方估值机构未提供价格的，采用估值技术 |
| 结构性理财产品 | — | 采用[[蒙特卡洛模拟估值]] |
| 其他衍生品 | 按估值基本原则判断 | 同衍生品三级路径 |

《指引》还另对非标准化债权类资产估值、非上市公司股权估值、金融资产减值做出规定，但征求意见通稿未展开细节。
