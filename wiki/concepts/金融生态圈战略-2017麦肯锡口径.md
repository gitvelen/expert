# 金融生态圈战略（2017 麦肯锡口径）

## 定义

银行通过“生态圈”（ecosystem）将多行业价值链捆绑，以客户为中心提供跨行业、无缝体验的金融服务，与平台公司（阿里、腾讯、亚马逊、乐天等）竞争或合作。

## 三种商业模式（按预期 ROE 排序，均为情景预测）

1. **自建平台**：银行创建自己的平台并进入非传统银行市场，ROE 可提至约 14%
2. **合作共建生态圈**：与伙伴共建平台、业务整合、交叉销售，ROE 可提至 9%–10%，未来三到五年可为银行业带来约 3500 亿美元新增利润
3. **退守模式**（利润较少）：白标资产负债表运营商；专注某类业务的专业银行

## 前提条件

麦肯锡强调生态圈战略“并非放之四海而皆准”，且银行须先完成全面数字化转型（数字化营销与分析、面向卖方的数字化工作台、机器人流程自动化、云、APP 与 API 等工具）。

## 后续观察

2017 年后中国的实际主导格局演变为核心企业/国企供应链平台与银行自建体系，与“银行被平台边缘化”的叙事存在张力，见 [[queries/查询-平台蚕食银行分销端预言2017-2026实际验证情况]]。
