# 链主企业激励与协作配套奖励机制（山西2023口径）

本概念描述山西省在"链长制"框架下，通过财政资金直接货币化激励链主企业及其上下游协作行为的机制设计，源自晋工信新材料规字〔2023〕2号《重点产业链培育激励方案》（2023年口径）。区别于以认定标准为中心的链主政策（如 [[findings/深圳链主企业认定标准快照-2021媒体转述口径]]），山西方案的核心是**以营收档位和协作配套率为奖励触发指标的量化激励结构**。

## 机制要点

1. **认定奖励 + 营收档位阶梯**：链主认定奖100万元；产业链年度营收按10亿→1000亿元五档，奖励100万→3000万元，同档只奖一次、高档不得再报低档——鼓励链主持续做大链上营收规模。
2. **协作配套率作为核心考核指标**：
   - 供应配套率 = 链主从链上供应单位年度采购金额 / 链主年度全部采购金额
   - 消纳配套率 = 链主向链上用户单位年度销售金额 / 链主年度全部销售金额
   - 每提高5个百分点，按增幅相应采购（销售）额的1%奖励，上限500万元。
3. **双向配套激励**：不仅奖链主，也奖链上企业——供应/消纳配套金额首破2000万至10亿元五档，奖20万至200万元，形成链主与链上企业的联动激励。
4. **链内交易门槛设计**：链上企业须与链主年度交易额≥1000万元，或与5家以上同链条企业交易额>2000万元方可获营收奖。
5. **反套利防线**：收入须第三方审计 + 市级以上部门审核；交易双方不得为关联企业（股权维度25%判定）；"承诺+追溯"监管；同一项目不得重复申报。

## 与供应链金融的关联与张力

- 该机制的**关联企业判定口径**（一方直接或间接持股达25%以上，或双方同被第三方持股达25%以上）与供应链金融尽调中常用的关联方识别口径一致，具跨域复用价值。
- 对"协作配套率"的财政奖励天然激励链内封闭交易，与供应链金融风控中警惕关联交易虚构贸易背景、防范融资性贸易的逻辑存在潜在张力：财政指标压力可能诱发链上企业间"为奖励而交易"的空转贸易。股权维度的排除条款未覆盖实际控制、协议控制等非股权关联形态。
