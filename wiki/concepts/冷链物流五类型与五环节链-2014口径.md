# 冷链物流五类型与五环节链（2014口径）

## 内容（2014 年行业口径，来源：[[sources/4-news--7-04-业务基础--4-2014--22-冷链物流发展滞后-供应链管理遇挑战供应链管理--1e2ec8t]]）

冷链物流按功能分为五类：

1. 全程冷链型
2. 仓储型
3. 物流型
4. 加工型
5. 落地配型

一件商品送达用户需经五个环节：

1. 发送地仓储
2. 发送地加工部门
3. 发送地→目的地的干线物流
4. 目的地接货部门
5. 目的地落地配部门

"冷链是由各类型的冷链企业串联起来的。任何一个环节断裂，都会造成送货不及时"（冷链物流公司创始人语）。这一"链条串联、环节断裂即失效"的结构解释了冷链为何难以简单下沉至低线城市。
