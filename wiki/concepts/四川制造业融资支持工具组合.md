# 四川制造业融资支持工具组合

《[[四川省促进工业经济稳定增长行动方案]]》第 8 条构建了省级制造业融资支持工具组合，由四川省发展改革委、经济和信息化厅、省地方金融监管局、人民银行成都分行、四川银保监局、四川证监局分工负责。

## 工具清单

| 工具/平台 | 性质 |
|---|---|
| “制惠贷” | 制造业企业融资试点 |
| “补贷保” | 联动试点（补、贷、保联动） |
| “园保贷” | 园区企业融资担保服务，方案要求扩大服务范围 |
| “信易贷”“天府信用通” | 信用信息平台建设与产品推广，是 [[全国一体化融资信用服务平台网络]] 的四川落地形式 |
| 应收账款融资、票据融资 | 产业链供应链金融推广方向，落实相关奖励政策（呼应 [[供应链金融上下游分侧工具组合]]） |
| 制造业中长期贷款 | 考核约束＋窗口指导＋评价激励办法推动持续较快增长 |
| REITs | 稳妥推进基础设施领域不动产投资信托基金试点 |
| 发债与中长期外债 | 支持制造业企业发债，在先进制造、绿色发展、新型基础设施领域合理利用中长期外债 |

## 说明

该组合以信用平台为基础（信易贷/天府信用通）、以试点贷款产品为主体（制惠贷/补贷保/园保贷）、以产业链供应链金融为延伸（应收账款/票据融资），与 wiki 中广州、青岛、南通、天津自贸区等地的供应链金融政策实践同属一类省级工具箱，可横向比较。
