# 数据评分动态授信模式（运满满司机贷 2017 口径）

以平台沉淀的行为与交易数据替代抵押物、对无固定资产的物流从业者进行授信的模式。标杆案例为 [[运满满]] 与 [[网商银行]] 合作的司机贷（2016 年立项）。

## 模式要素（企业自述口径）
1. **纯线上全流程**：无需面签。
2. **综合评分**：调取司机在平台的身份信息、行为特征、交易数据。
3. **动态调整**：额度与费率实时调整——评分越高额度越高、费率越低，兼具激励司机维护信用的作用。
4. **快速放款**：应对突发资金需求。

## 意义与证据强度
- 是 2017 年“数据也能变成钱”叙事在物流个人端的落地例证；属企业自述/媒体转述，弱—中等证据强度，效果与坏账表现待后续核验。
- 与专线甩挂授信案例（平台发货运货数据 + 恒丰银行授信）共同支撑企业端/个人端两类数据信用路径。
