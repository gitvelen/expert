# 供应链金融信息化系统建设关键要素（王晓东 2020 口径）

> **观点属性声明**：本页内容为专业公众号对专家讲课的二次转述（2020 年口径），属专家经验观点，非监管事实，不宜直接作为事实性结论引用。

## 供应链金融六大行业痛点

资产、资金、风险控制、业务开展方式、平台化、生态体系六个方面存在诸多行业痛点；克服痛点的关键在于供应链金融系统建设。

## 核心论断：系统承载操作风险控制

金融的本质是风控，供应链金融信息化系统的设计重点在于**对操作风险的控制**：

- 操作风险的防范可以通过增加操作成本实现，但会影响业务收益性（风控深度与收益性的权衡未给出解法，属内部张力）；
- 部分操作风险控制方法根本无法通过人工操作实现，因此具备操作风险控制功能的信息系统成为必然趋势。

系统建设失败的典型后果：系统先行业务后做容易走弯路、费钱费精力；系统与业务流程不契合则沦为空花架子，导致供应链金融业务"事倍功半"。

## 系统建设关键四要素

1. **业务需求**
2. **业务流程**
3. **业务模式**（包括业务开展模式与盈利模式）
4. **终极蓝图**

## 产品规划原则与方法

- **原则**：需求驱动——第一步分析产品受众需求，并尽可能看到隐藏需求；再把需求做深，挖掘用户深度需求。
- **方法**："沙盘模拟"，包括业务沙盘模拟、接口沙盘模拟等，可在沙盘上实现仿真模拟。

## X信模式平台建设考虑的关键要素

| 要素 | 说明 |
|------|------|
| 资产规模充分性 | 平台门槛较高，资产规模须充分 |
| 核心企业信用评级 | 核心企业信用基础 |
| 供应链实体 | 真实产业实体支撑 |
| 付款账期情况 | 账期结构影响融资空间 |
| 供应商成本接受度 | 融资成本可承受性 |
| 集团政策支持情况 | 集团层面的制度保障 |
