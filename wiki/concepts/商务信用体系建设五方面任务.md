# 商务信用体系建设五方面任务

《[[关于推动商务信用体系建设高质量发展的指导意见]]》提出的发展高水平商务信用经济框架：

| 方面 | 核心内容 |
|---|---|
| 信用销售 | 完善保障机制；信用报告、信用保险、保理、担保等工具；内贸信用保险与地方风险补偿；优化出口信用保险承保理赔 |
| 信用消费 | 汽车、家电、家居消费信贷；先用后付、减免押金等场景 |
| 信用融资 | 以销售数据、应收账款、信用保险保单为基础的中小微专项信贷产品（详见[[销售数据与应收账款为基础的信用融资]]）；依托[[全国一体化融资信用服务平台网络]]为外贸企业增信 |
| 信用评价 | 以公共信用综合评价为基础制定商务领域评价指引或标准；商圈/步行街/电商平台商户信用管理 |
| 企业信用建设 | 客户信用记录、信用评估、应收账款管理；运用大数据等新技术提升风险管控 |

其中"信用融资"与本项目供应链金融主线关联最强；信用消费、企业信用建设与主线关联较弱。
