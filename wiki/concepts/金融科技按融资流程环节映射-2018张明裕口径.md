# 金融科技按融资流程环节映射（2018 张明裕口径）

张明裕主张不能泛泛理解金融科技，须按单笔融资业务流程匹配具体技术（2018 年口径）：

| 环节 | 技术 |
|------|------|
| 营销获客 | 大数据（预测与筛选客户） |
| 客户服务 | AI 智能客服 |
| 贷款申请 | 生物识别、U盾/税控（企业实名，核实真实性） |
| 信用评估 | 大数据（信贷工厂、反欺诈）+ 征信 |
| 贷款调查 | 征信支持（反洗钱、社会化征信、涉税涉诉）+ 视频技术 |
| 贷款审批 | 机器学习 + 大数据（模型持续进化，如支付宝计算违约概率与授信额度） |
| 签订合同 | 电子签名 |
| 贷款发放 | 图像识别（放款身份核实） |
| 贷后检查 | 大数据（法院数据、交易数据监控）+ 物联网 |

核心观点："找准你能用的技术，而不是空讲金融科技。"该框架的启示价值在于**场景匹配**，但具体技术选型为 2018 年口径，后续技术演进需另行校准。
