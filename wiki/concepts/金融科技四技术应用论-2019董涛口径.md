# 金融科技四技术应用论（2019 董涛口径）

[[董涛]] 2019 年提出的金融科技四类技术在供应链金融中的应用（见 [[sources/4-news--7-04-业务基础--4-2019--23-27万亿市场-供应链金融发力中小企业供应链培训--nvbffh]]）：

1. **互联网**：降低金融服务交易成本，加快信息流通、减少信息不对称，增进金融服务可得性。
2. **大数据 + 云计算**：大数据帮助金融机构实现有效信息识别；云计算为数据存储完整性提供保证；已广泛探索于市场营销、风险控制、运营管理。
3. **物联网**：射频识别、传感器等应用成熟后，可辅助各类物资实现全流程系统化管理与自动化监控。
4. **区块链**：分布式账本使各参与方使用一致数据来源，保证可追溯与供应链透明化；具体抓手是**"区块链电子凭证"**——支付自由切分流转，解决多层次信用穿透难问题。

## 意义与关联

- "区块链电子凭证"论是后续**数字债权凭证**议题的前身。
- 与 [[供应链金融四层技术架构-2018宋华口径]]（感知层—计算层—流程层—模式层）同属 2018–2019 科技赋能叙事，可对照。
- 结合区块链的多维大数据风控、智能交叉验证是其提出的信息真实性保障路径。
