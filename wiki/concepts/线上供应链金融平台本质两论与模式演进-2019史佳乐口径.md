# 线上供应链金融平台本质两论与模式演进（2019 史佳乐口径）

来源：史佳乐《供应链金融的发展趋势与创新方向》，《中国银行业》2019 年。

## 本质两论

1. **信用创造**：线上供应链金融平台通过大数据了解企业运营情况并给予信用支持，而不仅看财务表面。传统风控审查三表（资产负债表、现金流量表、利润表），平台风控改为综合研究“四流”（商流、资金流、物流、信息流），将核心企业、供应商、经销商的经营数据提供给银行完成授信核定，使融资更快、风险预警更及时。
2. **不是革命而是提升**：①资金利用效率提升（钱以最快速度投向所需与创造价值之处）；②银行服务模式与理念提升（打破银行主导、银企各自为战局面）；③核心企业供应链管理水平提升。实现服务在线化、营销互联网化、流程标准化、风控自动化。

## 模式演进

“ERP + 银行供应链金融系统”旧模式正被取代，向两分支发展：

- 供应链协同平台 + 线上供应链金融服务平台
- 产业电商平台 + 线上供应链金融服务平台

## 四大创新点

1. 提升核心企业及上下游资金周转率、降低经营成本（一次流程后线上随借随还）
2. 提升核心企业管理效率（解决银企系统升级不匹配；金融服务渗透商务各环节）
3. 解决银企信息对称问题，动态数据支撑中小企业信用
4. 打破地域限制，跨区域服务上下游

## 四大新趋势

行业细分专业化 → 银行信用评估体系重构 → 大数据实时监控（企业“体检报告”）→ 与产业电商深度融合。

## 时效与对照

- 本页为 2019 年口径（观点性内容，作者判断，无量化数据）。
- 与 [[concepts/线上供应链金融平台信用创造与四大创新论-2018安华信达口径]] 的“信用创造/不是革命而是提升/四流风控”表述几乎一致，两稿关系见 [[comparisons/线上供应链金融信用创造与四大创新两稿对比-2018安华信达与2019史佳乐]]。
