# 供应链金融 1.0–4.0 四阶段演进与风控三点（黄奇帆口径）

## 总论

金融科技核心的基础是产业互联网，而非以消费互联网为基础的网贷；其服务对象是小微企业。以产业互联网为基础的金融科技即"产业互联网金融"，是科技金融的真正载体。供应链金融向产业互联网金融升级的**标志是风控方式的转变**。

## 四阶段演进

| 阶段 | 模式 | 特征 |
|---|---|---|
| 1.0 | 主办银行模式 | 银行与企业点对点连接，将上下游作为整个链条开展业务，未真正参与供应链运营 |
| 2.0 | 核心企业主导模式 | 核心企业有效掌控应收账款、应付账款、仓单等信息，银行据此对链条各类主体服务，效率与效益大幅提升 |
| 3.0 | 数字金融模式 | 以大数据、物联网、人工智能、区块链获取产业链上每个企业的动态数字信用；供应链生态圈打通、交易透明可信、资金流动清晰可见——是这一领域产业互联网的新生态 |
| 4.0 | 产业互联网金融 | 以产业互联网服务生态为基础，有机会在全国范围像自然人一样为中小微企业法人建立画像并提供金融服务，是最具想象空间的发展趋势 |

## 风控三点

供应链金融风控一般关注：

1. **贸易的真实性**
2. **资金的自偿性**
3. **交易的可控性**

黄奇帆（引自《数字化经济的底层逻辑》，《混沌大学》）指出：当前我国供应链金融风控仍以传统手段为主，区块链、物联网、大数据等信息化风控应用较少，**行业转型升级的标志在于风控手段的数字化转型**。

此三点与 [[真实贸易五大甄别要点-万联网2024口径]]、[[贸易虚实证伪要点-原地货转与双控原则-张春艳2024口径]] 相互印证，均锚定"贸易真实性"这一风险本质。

## 金融企业四优势（平台与金融企业分工）

1. **低成本融资优势** —— 储蓄资金与货币市场资金的低成本获取
2. **企业信用判断优势** —— 平台征信"相当于 X 光/CT/核磁，代替不了医生的诊断治疗"，放贷尽调、抵押与风险防范须金融企业独立担当
3. **资本金规模优势** —— 真正放贷须有融资规模 10% 以上的资本金，只有银行、信托、保险等专业金融公司具备
4. **社会信用/牌照信任优势** —— 监管与用户习惯更信任持牌金融企业

结论：网络数据平台与专业金融企业合作是"强强联合、优势互补"的最佳模式——这一分工判断与本库"以数据信用与物的信用替代对主体信用的迷信、但风控不可外包给平台"的产业本位论点高度契合。

## 开放问题

4.0 阶段"中小微企业法人画像"在数据要素流通与征信监管框架下的实际可行性尚待验证，可作为后续知识交流与跟踪议题。
