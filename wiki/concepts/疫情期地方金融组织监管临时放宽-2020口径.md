# 疫情期地方金融组织监管临时放宽（2020 口径）

指 2020 年新冠疫情期间，北京、深圳、广东、山东、湖南、河南、上海等多地地方金融监管部门对商业保理、融资租赁、小贷等"类金融"（地方金融组织）实施的**带期限、有条件**的监管指标临时放宽：对监管指标优良、积极支持中小微企业复工复产的机构，放宽融资杠杆倍数、拓宽融资渠道（金交所/交易所通道）、提高单户贷款上限与不良容忍度。

## 放宽形态

1. **杠杆放宽**：小贷融资余额/净资产倍数上调（各地倍数不一）
2. **融资渠道拓宽**：经金交所（北金所、前海金交所）或沪深交易所融资，前提为"风险可控、底层投资人可穿透"
3. **单户限额与展业范围上调**（如北京小贷单户 ≤ 注册资本 5% 且 ≤ 1000 万元，允许全市展业）
4. **准入与审批放宽、不良容忍度提高**（湖南、重庆、山东、广东等）

## 各地对照（2020 口径）

| 地区 | 小贷杠杆 | 其他 |
|---|---|---|
| 北京 | 3 倍 | 单户上限上调、全市展业；融资租赁+保理可经北金所融资 |
| 深圳 | 5 倍 | 保理可经前海金交所融资（条款 2020-06 末废止） |
| 广东、山东 | 5 倍 | 执行期 6 个月；提高不良容忍度 |
| 河南 | 3 倍 | 执行期暂定至 2020-09-30 |
| 上海 | 3 倍 | — |
| 湖南 | 不放宽 | 放宽准入和审批；执行期 6 个月 |
| 重庆 | — | 提高不良容忍度 |

（倍数数据来自《投实》统计，二手口径；深圳、北京数据来自文件原文转述。）

## 时效性说明

**本概念整体为已失效的历史口径**：所有放宽政策均带截止期限（至疫情结束、6 个月、2020-06 末或 2020-09-30），2020 年内已陆续到期废止，不得作为现行监管标准。

## 与严监管的关系

放宽并未改变 [[银保监会205号文]] 确立的严监管基调——205 号文同期推进商业保理"大清理"（深圳 2020-03 公示 5238 家疑似失联企业）。正确理解是：**严监管趋势不变 + 有条件放宽 = 去劣存优**。标题式"类金融监管大放松"属媒体修辞，不宜直接引用。
