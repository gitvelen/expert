# 价内税价外税"三变"与贸金中收考核衔接（2016口径）

2016年5月1日营改增后，银行贸金业务收入核算发生"三变"：

1. **价内税→价外税**：营业税时代报价为含税价、不细分税额，全部收入计入中收考核；增值税时代收入须拆分为收入部分（入营业收入科目）与税款部分（入增值税相关科目），条线业绩变为不含税口径，考核指标内涵出现缺口。
2. **只算收入→收支轧抵**：增值税申报时销项税与进项税轧抵；贸金业务收入远大于支出，应纳增值税额预计可观。
3. **回单/定额发票→增值税发票**：收支均需凭增值税发票落账与抵扣。

## 含税价还原公式

产品定价与税负测算须将含税价还原为不含税口径，否则税基计算不准确致成本预估不足，甚至少缴税款带来滞纳或罚款风险：

```
不含税价或不含税收入 = 含税价或含税收入 /（1 + 增值税及附加的税率）
```

## 中收考核口径前后衔接

2016年4月30日前的中收科目数据包含营业税及附加税费金额，5月1日后不含任何税费；用年初下达的含税费考核指标衡量业绩时，须调整为同一口径测算，方能准确反映实际业绩水平。

（银行内部绩效考核细节时效性强，此处仅保留口径衔接的方法论要点。）
