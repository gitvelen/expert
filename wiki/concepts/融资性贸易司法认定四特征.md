# 融资性贸易的司法认定特征（名为贸易、实为借贷四特征）

## 定义与监管出处

《关于进一步排查中央企业融资性贸易业务风险的通知》（国资财管〔2017〕652号）：融资性贸易业务是**以贸易业务为名，实为出借资金、无商业实质的违规业务**。其后 [[entities/国资委关于规范中央企业贸易管理严禁各类虚假贸易的通知]]（74号文）延续严禁口径；《关于加强地方国有企业债务风险管控工作的指导意见》第七条亦严禁融资性贸易和"空转""走单"等虚假贸易业务。

## 司法认定四特征

综合大量"名为贸易、实为借贷"判决案例：

1. **交易模式缺乏商业合理性**——如约定固定收益利率、高买低卖、增加不必要的中间方导致交易成本上升
2. **虚构标的货物或标的货物实际未发生流转**
3. **一方当事人不承担正常买卖合同项下义务**
4. **实际付款结算与是否交货无关**

## 对照：合规大宗贸易五要素

| 要素 | 要点 |
|------|------|
| 穿透视审查 | 核实合作方基本情况与经营情况，确保贸易真实性 |
| 市场化定价 | 固定价/随行就市/基准价+浮动价，各方自担价格风险，不获取固定收益 |
| 物流货控 | 自有物流、专人押车、实时监控，控制标的货物 |
| 验收仓储 | 专人验收与仓储管理 |
| 按验收结算 | 根据货物验收情况结算 |

符合上述流程的贸易行为一般不构成融资性贸易。

## 风险后果

- 虚假意思表示导致买卖合同无效（见 [[concepts/虚假意思表示合同无效与货款返还实务]]）
- 实际借款方无力清偿时，无法向下游买方主张货款的回款风险
- 虚构贸易背景开具增值税发票，可能被认定为虚开或非法买卖增值税专用发票

## 监管红线与民事效力的张力

B 公司以"融资性贸易违反国企监管规定、违背公序良俗"抗辩，但仲裁裁决依据是虚假意思表示而非监管规定本身——监管红线与民事效力认定的关系是实务经典张力，待 [[queries/查询-锌锭仲裁案B公司为何无需返还货款]] 跟踪裁决论证细节。

证据强度：四特征与五要素为专业律所归纳（万联网 2025 转述张春艳口径），属专业公众号分析层级，非监管原文。
