# 物联网金融四大场景（2020 平安银行口径）

彭妍（平安银行总行交易银行部）在 2020 论坛圆桌自述的物联网金融实践四场景（企业自述口径，速记未经审阅）：

1. **牧场活体融资**：物联网耳标应用于奶牛，从乳制品经销商融资下沉到牧场环节；
2. **油站数据直连**：物联网监测铺到油枪芯片，与油站收款 POS 机 API 直连，形成大数据风控；
3. **车联网**：全国汽车经销商融资中平安自述占 1/3，很大程度依托车联网技术；从 4S 庇延伸至无车承运人平台，以车辆运营数据作为风控模型重要监测点；
4. **大宗仓储物联网改造**：与已完成物联网升级改造的仓储物流企业合作，依托生态体系服务大宗贸易商。

## 平台化归集

上述油枪数据、牧场数据、大宗物联网仓储数据、仓单数据统一归集于平安集团级物联网服务平台，非散点应用。

## 风控逻辑

对应银行两大痛点中的"仓单真实性"：以物联网+区块链技术解决真实性与货权监控问题（登记问题则待统一登记制度，见 [[concepts/动产担保统一登记制度演进-2020论坛口径]]）。
