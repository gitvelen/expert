# 钢银五款供应链产品矩阵（2017 口径）

[[钢银电商]] 于 2017 年自称“不断推出”的基于用户真实交易场景的供应链产品：

| 产品 | 推断功能场景（名称自述，功能细节来源未展开） |
|------|------|
| 任你花 | 应收/账期类融资 |
| 帮你采 | 代采/采购融资 |
| 随你押 | 存货/货物质押融资 |
| 为你赚 | 闲置资金增值/理财类服务 |
| 订单融 | 订单融资 |

目标：帮助用户解决“资金及货物两大难题”。

## 备注

- 各产品的准入、额度、风控细节在来源中未展开；实际放款规模与后续存续情况见开放问题 [[查询-钢银五款供应链产品的实际放款规模与后续存续情况]]。
- 此矩阵是场景化融资 / 数据信用产品叙事（2017）的样本，可与库内数字债权凭证类概念做时间对照。

## 证据强度

厂商自述，强度弱；产品存在性可由平台公开资料佐证，规模与风控效果无独立验证。
