# 付款代理模式（招商银行2017口径）

**付款代理**是招商银行 2017 年推出的供应链金融综合解决方案：借助招行智慧供应链金融系统，基于核心企业赊购场景，银行代理核心企业管理应付账款并锁定到期付款路径，将核心企业闲置信用传导给上游供应商，批量为上游企业提供保理融资。

## 交易结构要点

1. **场景**：核心企业对上游供应商的赊购（应付账款）。
2. **信用来源**：**直接占用核心企业集团的空闲授信额度**——这是该模式最关键的机制（据 2017 媒体转述口径，强度中，待官方核验，见 [[查询-招行付款代理授信占用口径与票据新规影响核验]]）。
3. **控制手段**：银行为集团管理应付账款 + 锁定企业到期付款路径，使融资依附真实付款义务。
4. **传导方式**：核心企业闲置信用自动传输给上游供应商，经全业务渠道批量办理保理融资。
5. **收益逻辑**：降低全产业链融资成本，增加核心企业资金管理收益。

## 知识定位

- 付款代理是 [[核心企业信用传导与1N模式-深发展2017口径]] 中"1+N"信用传导思路在 2017 年的具体产品化，属延伸而非挑战。
- 其“依附核心企业信用与付款承诺”的风险逻辑可与数字债权凭证类产品对照。
- 与 [[N加1加N供应链金融模式-国美2017口径]] 同属核心企业信用向上游/下游辐射思路，可对比。

## 核心企业配合动力弱的四因（观点性内容，2017 口径）

来源文章解释为何核心企业需求较弱：收益不明显、供应商选择多、可能产生的新增工作量、固有赊销支付习惯。此为经验性论断（证据强度弱）。

## 注意

文章将付款代理定位为响应“供给侧改革”的载体，属宣传性话语，应与产品实质（应付账款管理 + 保理融资）区分。
