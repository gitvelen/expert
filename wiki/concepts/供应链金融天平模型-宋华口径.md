# 供应链金融天平模型（宋华口径）

宋华提出的供应链金融本质分析框架：供应链金融作为加速企业间资金往来、解决运营资金短缺而开展借贷的产业金融，如同一座天平——

| 天平部位 | 对应要素 |
|---|---|
| 底座 | 风险识别和控制 |
| 横梁 | 产业信息 |
| 一端 | 资产 |
| 另一端 | 资金 |
| 支柱 | 信用 |

## 2021 年对天平失衡的挑战诊断（宋华口径）

- **底座受压（风险识别与控制）**：商业周期变动、贸易保护主义、新冠疫情冲击、产业升级/数字化转型阵痛，导致贸易背景质量受到巨大挑战，风险识别与控制困难。
- **横梁不稳（产业信息）**：商业情景异质化程度高、缺乏公认的行业运营规范与标准、信息孤岛广泛存在，产业级供应链信息难以形成，信息真实性无法保证。
- **资产端失真**：资产在供应链不同环节/主体间转移与价值变动无法全程透明、实时反映与管理；金融机构仍以概率思维评估管控风险，未做资产细颗粒度管理。
- **资金端失控**：大企业不确权成为商业惯例，拖欠、不挂账被视为理所当然，业务闭合与收入自偿沦为理论设想。
- **总诊断（2021 年口径）**："传统的信用体系已经丧失效能，而新的信用体系尚未建立" → 对策为重构信用体系、确立数字信用（见 [[数字信用六特征-宋华口径]]），重建天平的支柱"信用"。

## 关联与对照

- 本模型是宋华理论体系的骨架，与 [[226号文第18条三种信用一体化风控原文口径]] 的"主体信用+物的信用+数据信用"一体风控可对照理解。
- 属学者观点口径，非政策或行业共识。
