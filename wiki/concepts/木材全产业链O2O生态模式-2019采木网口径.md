# 木材全产业链 O2O 生态模式（2019 采木网口径）

采木网在 2019 上线发布会上提出的自述模式：线上 + 线下 + 金融 + 整合的四层结构。

## 结构

1. **线上平台**：采木电商——指数、商城、团购、金融、运输、加工等线上品牌
2. **线下基础**：[[中木智慧]]实体物流与产业园品牌
3. **核心**：供应链金融
4. **抓手**：产业链整合，构建各产业相互依托、共生共赢共享的生态圈

## 点评

这是典型的产业互联网平台叙事（线上交易平台 + 线下物流/园区 + 供应链金融变现）。该口径为厂商自述，2019 年时点无落地数据佐证；"以供应链金融为核心"意味着平台风险实质上取决于贸易真实性与货权控制力，而非平台概念本身。
