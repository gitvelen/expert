# 金融生态圈战略与银行三模式选择（2017 麦肯锡口径）

## 生态圈战略

麦肯锡 2017 年提出：以客户为中心，将多行业价值链捆绑为"生态圈"，可降低成本、提升客户体验。典型例证为阿里巴巴（电商+资管+放贷+支付+B2B+出行）、腾讯、亚马逊（含对中小企业贷款与担保）、日本乐天（Rakuten Ichiba：积分/电子货币/信用卡/抵押贷款/证券经纪/在线旅游/Viber）。麦肯锡认为生态圈公司的威胁在于：掌握更多客户数据、效率更高，且在客户重大财务决策时"排在前列"。

## 银行的三种商业模式选择

1. **共建金融生态圈**：与合作伙伴携手建平台、业务整合、交叉销售、无缝体验；建成的银行 ROE 可达 9%–10%，未来三到五年为行业带来 3,500 亿美元新增利润。
2. **白标资产负债表运营商**：利润较少的替代模式。
3. **专业银行**：专注某一类业务，利润同样较少。

若银行自建平台进入非传统银行市场，ROE 可提升至约 14%。

## 前提条件

无论选择何种模式，"全面的数字化转型"是必需的入场券：数字化营销与分析、面向卖方的数字化工作平台、RPA、云、APP 与 API 等工具。麦肯锡估算全面数字化可为行业释放约 3,500 亿美元可用资金、平均 ROE +2.5 个百分点。

## 演进脉络注记
