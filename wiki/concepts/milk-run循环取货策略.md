# milk run 循环取货策略

## 定义

milk run（循环取货）是一种物流组织模式：由核心企业组织车辆按固定路线循环走访多个供应商，统一取货替代各供应商分别送货，通过合并零散运输批量获取规模优势。在 2009 年文章中，milk run 作为"合并以规模化"思路的典型做法出现，并被宝洁用于价值高、体积大的采购物料。

## 本文口径（2009）

- 出现场景一：各供应商分别送货不如核心企业组织统一取货（milk run 策略）。
- 出现场景二：宝洁差异化采购策略中，"价值高体积大"的物料可采用 milk run。
