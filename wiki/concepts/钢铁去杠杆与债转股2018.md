# 钢铁去杠杆与债转股（2018）

钢铁行业资本结构矛盾突出：资产负债率高、财务负担重。2018 年去杠杆成为新版钢铁产业发展指导意见的重点方向之一。

## 关键数据（来源：刘振江，中钢协"钢铁行业财务工作座谈会"，2018-05）

| 指标 | 数值 |
|---|---|
| 目标：平均资产负债率（3—5 年内） | 60% 以下 |
| 行业平均资产负债率（同比下降 2.59 个百分点后） | 67.23% |
| 2017 年行业利息支出 | 842.82 亿元 |
| 平均年化资金成本率 2016 → 2017 → 2018 年 3 月 | 5.06% → 6.22% → 7.22% |
| 银行一年期贷款利率（对比基准） | 4.35% |

钢企资金成本持续上行且远超基准贷款利率；长贷与短贷的债务结构调整仍未完成。

## 去杠杆路径（刘振江）

- 加大去产能过程中债务处置水平
- 协调落实与银行机构签署债转股方案
- 推进降本增效、调整投资策略
- 加大直接融资比重

## 相关表态

全国工商联副主席徐乐江在全联冶金商会调研时指出，应紧跟中央防范金融风险的部署，主动降低杠杆率，降低钢企负债率。
