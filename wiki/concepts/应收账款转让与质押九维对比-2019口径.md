# 应收账款转让与质押九维对比（2019口径）

应收账款融资存在**转让（保理、发票贴现、福费廷等债权移转逻辑）**与**质押（担保物权逻辑）**两条路径，理解二者差异是"应收账款融资双轨"的基座概念。本对比为《合同法》《物权法》时代（2019年口径，部分已被民法典取代）。

## 九维对比

| 维度 | 应收账款转让 | 应收账款质押 |
|---|---|---|
| 生效要件 | 通知债务人对债务人生效（《合同法》80条） | 信贷征信机构登记设立（《物权法》228条） |
| 权利性质 | 债权移转，受让人成为新债权人 | 担保物权 |
| 对债务人效力 | 债务人可主张抗辩（82条）、享有抵销权（通知后新债权不得抵销） | 无明文；通说通知前抗辩事由可对抗质权人 |
| 从权利 | 主从权利一并转移（81条，人身专属性除外：撤销权、解除权不当然转） | 质权效力可追及出质债权附带的抵/质押、保证担保利益 |
| 质权人/受让人权利清单 | 直接取得应收账款项下全部权利与收益 | 优先受偿、可诉出质人与应收账款债务人（担保法司法解释106条）、代位物追及、担保利益追及、破产别除权 |
| 运行机制 | 收多收少与转让人无关（商务纠纷除外） | 余额退还出质人、不足继续追偿 |
| 追索与风险 | 受让人独担坏账风险（无追索），另有约定除外 | 风险分散于出质人与应收账款债务人双方 |
| 收益 | 贴现差价＋保理费、管理费、发票处理费 | 仅融资利息 |
| 适用范围与通知 | 限销售/服务债权，排除信用证（不含备用信用证）、现金交易（FCI《国际保理通则》）；可暗保理不通知，逾期后补通知效力有争议 | 可质押范围广（销售、出租、服务、不动产收费权、贷款债权五类，修订征求意见稿拟增劳务及其他金钱给付债权）；银行实践要求通知并取得确认 |

## 禁止转让特约：两种立法例

- 国内《合同法》第79条采**有效主义**：特约对保理商有效，虽不使供应商与保理商之间转让无效，但保理商支付请求权将受债务人以此抗辩影响。
- 《国际保理公约》第6条第1款：即使基础合同有限制转让条款，应收账款转让仍有效。处理上区分善意与恶意：善意追究出让人违约责任；即使恶意，债务人不提出抗辩亦可。

此张力对暗保理、未来债权保理的合规设计有直接影响；民法典第545条及保理章下的裁判口径是否延续79条有效主义，见 [[queries/查询-合同法79、80条口径在民法典保理章下的对应与变化考证]]。

## 逾期后补通知效力争议

暗保理、商业发票贴现中可不通知债务人，但账款逾期后一定期间受让人仍会通知。该逾期后通知是否有效，《国际应收账款转让公约》与法律均无规定。关联 [[concepts/暗保理追索权不以通知债务人为前提-2016口径]]。

## FCI"商业结果一致论"（观点性注脚）

FCI 认为从商业角度转让与质押结果一致：保理商按折扣（如80%）购买应收账款，收回时多余的20%抵扣保理费用，与设置担保权益并支付超额收回资金给客户没有区别。此为 FCI 观点而非法律定性。
