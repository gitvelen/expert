# 跨境电商金融云模式（豆沙包口径）

跨境电商金融云（XFCloud）是指金融科技公司以 SaaS + API 云服务方式，将流量能力、服务能力、数据能力整体输出给银行等金融机构，使其能高效率、低成本切入跨境电商新场景的一站式赋能模式。本条目为 2022 年豆沙包公司自述口径。

## 输出内容
1. 创新金融产品设计
2. 店铺经营模型评估
3. 账户双锁（还款控制）
4. 获客/流量赋能（平台流量与贷款需求流量导入银行）
5. 数据合规：通过 API 与隐私计算联合建模获取电商平台店铺数据授权

## 解决的银行痛点
- 跨境电商链上中小微卖家的主体识别困难（店铺主体控制人、运营公司、收款主体不一致）。
- 平台店铺数据授权的合规获取路径。

## 自偿性贸易融资逻辑
演讲口径：跨境电商企业融资基于真实贸易背景，若金融机构掌握物流、资金流控制，即可实现自偿性贸易融资——账户双锁即为资金流控制手段。

## 收入模式
API 调用次数计技术服务费 + SaaS 订阅。

## 证据强度说明
模式描述与"超十几家机构使用"等规模数据均来自公司自述通稿，属一般企业宣传口径，可信度偏低；但浦发"跨商贷"、建行"豆方贷"、蚂蚁银行"美金贷"为公开落贷产品，可交叉验证模式的部分真实性。
