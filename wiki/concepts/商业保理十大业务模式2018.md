# 商业保理十大业务模式（2018年科普口径）

来源（保理人，2018-12-02）将商业保理业务归纳为九种模式（原文编号"10"重复，实为九种）：赊销信用风险管理、应收账款管理（销售分户账）、反向保理、双保理（含国内双保理创新）、信用保险（融信达）、应收账款过程监控、应收账款催收、坏账担保、行业专业、银行代理。

## 模式清单与关键能力要求

| 模式 | 关键点 | 能力要求 |
|---|---|---|
| 赊销信用风险管理 | 事前控制坏账，动态调整赊销额度 | 企业资信调查与信用风险评估 |
| 销售分户账管理 | 国内保理机构普遍回避；额度控制与核准的基础 | 账户管理系统、规模化运营 |
| 反向保理 | 核心企业信用与交易记录审核 | 对核心企业的营销能力 |
| 双保理 | GRIF 6 种反转让情形；已核准额度≠风险转移 | 进口商偿付能力与进口保理商信用双审 |
| 信用保险 | 责任免除、卖方履约风险、赔付滞后流动性风险 | 与保险公司协作、回款封闭管理 |
| 过程监控 | 第三方支付/机票款场景，笔数多金额小 | 第三方合作+业务处理系统 |
| 催收 | 保理基本要素，国内普遍缺失 | 法律人才与催收技巧 |
| 坏账担保 | 无追索权以费率覆盖风险（观点） | 风险识别、评估与承担能力 |
| 行业专业 | 深耕单一行业（如煤炭、医疗设备） | 行业专业背景 |
| 银行代理 | 存货监管/账款管理外包+营销渠道 | 银行协同、跨区域获客 |

## 来源观点

作者主张国内保理商普遍回避销售分户账管理、催收和无追索权，是行业短板；有追索权保理对风险降低无实质意义（"安慰药论"）。此为 2018 年专业公众号观点（已被后续监管实践部分检验），非官方口径。各模式间"没有优劣之分，只有适合与否"。
