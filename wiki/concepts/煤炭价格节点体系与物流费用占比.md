# 煤炭价格节点体系与物流费用占比

我国煤炭呈**北煤南运、西煤东运**格局，运距长、载具复杂（公铁水联运），物流费用很多场合下**占煤炭价格 50% 以上**（万联网/黄贵生 2025 口径，待独立核验，见 [[查询-煤炭物流费用占煤价50%以上口径核验]]）。

## 价格节点体系

按物流路径节点的价格：**坑口价 → 站台价 → 车板价 → 离岸价（港口离岸）→ 到岸价 → 到库价**。

## 成本加成公式（原文）

```
煤炭价格 = 坑口价 + 汽运费 + 站台费用 + 港口费用 + 海运费 + 资金成本 + 质检费 + 保险费 + 税费 + 利润 + 时间成本...
```

主要变动因素为坑口价与各类物流费用（可参考汽运、海运运价指数）；港口、站台费用相对稳定。

## 风控含义

- "会算账"是供应链公司业务与风控的基本能力要求。
- 盯市管理应覆盖产地、中转地、销地三地价格。
