# 无人店单店经济模型（2017厂商口径）

[[entities/缤果盒子|缤果盒子]] CEO 陈子林 2017 年 10 月专访中陈述的单店经济参数，属**厂商自述口径，未经第三方验证，弱证据**。

## 参数

| 参数 | 数值 |
|---|---|
| 盒子规格 | 12.8 平米 / 15.6 平米 |
| SKU 上限 | 800（传统便利店约 3000） |
| 定价 | 比传统便利店低 5% |
| 盈亏平衡点 | 日销售额 300 元 |
| 回本周期 | 日销 2000 元时约 5 个月 |
| 场景 | 封闭式小区为主 |
| 租金模式 | 交租金或流水分成，年均 6000–8000 元 |

## 内在张力

"低 5% 定价 + 低租金 → 更高毛利"的逻辑，其成立前提是"同样销售业绩"；而 SKU 宽度与选品能力恰是无人店的短板（见 [[concepts/无人零售供应链短板论-2017口径|供应链短板论]]），低成本可能以牺牲销售为代价。报道记者已点破此点。

## 时效

属 **2017 年口径**，仅作历史对照，不作为行业现状引用。
