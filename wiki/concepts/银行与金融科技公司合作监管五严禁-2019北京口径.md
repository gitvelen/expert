# 银行与金融科技公司合作监管"五严禁"（2019 北京口径）

指 2019 年北京银保监局《关于规范银行与金融科技公司合作类业务及互联网保险业务的通知》确立的合作红线，是助贷/联合贷合规框架的地方监管口径。

## 五个"严禁"

1. 严禁未经授权开展合作
2. 严禁与以金融科技之名从事非法金融活动的企业开展合作
3. 严禁与**虚构交易背景或贷款用途、套取信贷资金**的企业开展合作
4. 严禁与以非法手段催收贷款的企业开展合作
5. 严禁与以"大数据"为名窃取、滥用、非法买卖或泄露客户信息的企业开展合作

配套要求：授信审查、风险控制等**核心业务环节不得外包**，银行不得因助贷机构提供风控服务而削弱自身风控要求；不得为无放贷资质机构提供放贷资金（延续年初浙江口径）。

## 对供应链金融的意义

- 第 3 条"虚构交易背景禁令"与[[融资性贸易]]红线直接同构，适用于供应链金融对公合作场景
- 监管已注意到金融科技与银行合作进入 2B 领域（供应链金融、中小微金融、资管），2B 与 2C 在风险传导、管理方式、影响规模上差异较大；北京《通知》体现"提前关注"（2019 年观察口径）

## 时效性说明

2019 年地方口径，已被 2020 年《商业银行互联网贷款管理暂行办法》等后续规则部分取代（演进考证见 [[queries/查询-北京银保监局合作类业务通知与浙江年初助贷函的后续演变考证]]）。
