# 供应链柔性定义与八要素分析框架（2010口径）

## 定义

供应链柔性是指供应链**快速而经济地处理企业生产经营活动中环境或由环境引起的不确定性的能力**，一般由三种能力构成：

1. **缓冲能力**——以既有资源吸收波动
2. **适应能力**——随环境变化调整自身
3. **创新能力**——主动创造新方案应对变化

（来源未注明学术出处，属经典教科书式定义。）

## 提出背景

由于不确定性来源于供应商、制造商、顾客三方面，该文主张供应链柔性度应当成为新的供应链绩效评价指标。

## 分析框架：两维度八要素

### 流程维度（四系统柔性）

| 要素 | 要点 |
|------|------|
| 制造系统柔性 | 现有资源下低成本快速生产合格产品；含机床、产品、加工、工序、运行、产量、扩展、生产八项分柔性 |
| 物流系统柔性 | 以合理成本，在合适时间/地点，用合适运输方式收集配送合适的产品或服务 |
| 信息系统柔性 | 可重组、可重构、模块化、可扩展、热插拔，以适应供应链生命周期内的动态重组 |
| 供应系统柔性 | 适时调整供应/生产计划，改变零件或产品的产量、种类或组合 |

### 经营管理维度（四类柔性）

| 要素 | 要点 |
|------|------|
| 研发柔性 | 以合理成本快速开发不同种类新产品，及时发现市场机遇 |
| 组织柔性 | 动态、扁平化、网络化组织结构，是其它柔性要素的基础和组织保障 |
| 战略决策柔性 | 柔性决策四特点：决策者有限理性且目标柔性；偏好柔性；约束条件柔性；目标是求满意解并逐步放宽约束 |
| 文化柔性 | 以新型柔性文化体系替代高度牢固度、一致度和系统和谐性的硬性文化 |
