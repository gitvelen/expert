# 煤炭产业链上中下游结构与煤种定价逻辑（2024万联网口径）

## 三环节结构

- **上游**：煤炭生产设备供应方——民用爆破器材生产商（工业炸药、雷管、索类，区域性垄断、议价力强，消耗成本约占煤企固定资产投入 4%）与煤矿机械设备制造商（采掘机、掘进机、电线电缆、锚杆锚网、支护器具、运输工具、通信器材等）。
- **中游**：煤炭生产方，负责开采与洗选，是煤炭生产技术所有者。
- **下游**：运输方与需求端。资源分布“北多南少、西多东少”，消费集中在东部沿海与南方，形成“北煤南运、西煤东调”格局；运输分铁路、水路、公路；需求端为电力、钢铁、建材、化工四大传统消费部门，另有洗选加工与其他行业（散烧用煤为大气污染整治对象）。

## 三煤种定价逻辑

| 煤种 | 定价核心指标 | 主要下游 |
|---|---|---|
| 动力煤 | 热量为基准，水分、硫分、挥发分、灰分调整 | 发电（全行业最主要下游）、建材、供热 |
| 炼焦煤 | 灰分、硫分、挥发分（灰分损害黏结性与结焦性） | 70% 为钢铁；焦炭炼钢，炼焦环节无可替代材料 |
| 无烟煤 | 粒度为主，其次灰分、硫分、挥发分、固定碳 | 电力、建材、化工 |

炼焦煤资源稀缺 + 供给侧改革 → 供给相对依赖进口，常年紧张。

## 下游细分要点

- 电力：动力煤、煤矸石、褐煤均可，“技术上通吃不挑食”。
- 钢铁：炼焦煤、喷吹煤作还原剂与高炉骨架，炼焦煤作用不可替代。
- 建材：主要用动力煤；高端陶瓷/玻璃有天然气替代，免烧砖推广减少用煤。
- 化工：传统煤化工（合成氨、甲醇）vs 新型煤化工（煤制油、煤制天然气、煤制烯烃、煤制芳烃、煤制乙二醇）。

## 周期规律

经济快速增长 → 需求大增 → 供不应求 → 价格上涨 → 利润增加 → 供给增加 → 经济衰退 → 消费减少 → 供过于求 → 价格下跌 → 利润降低 → 供给减少。驱动煤价的核心变量是需求，最大消费来自电力。

## 典型企业模式（文中描述口径）

- **中国神华**：最大煤炭生产与销售企业、全球第二大煤炭上市公司；“煤炭+发电+铁路+港口+航运+煤化工”一体化经营模式。
- **陕西煤业**：优质动力煤与冶金用煤（低灰低硫低磷高发热量）；捣固焦配煤技术（主焦煤、肥煤 + 低价瘦煤、气煤）降本，焦炉煤气综合利用制 LNG、甲醇。
- **中煤能源**：第二大煤企、最大煤炭贸易服务提供商之一；经营中国最大的与钢企无附属关系的焦化业务之一。

## 对供应链金融的意义

煤种定价指标、运输格局与周期位置是煤炭贸易风控中判断货值、物流管控节点与价格风险的基础；该框架与 [[融资性贸易定义与买卖型增信型二分]] 的合规红线共同构成国企切入煤炭供应链的前置知识。
