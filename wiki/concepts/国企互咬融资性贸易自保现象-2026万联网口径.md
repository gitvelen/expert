# 国企互咬融资性贸易自保现象（2026 万联网口径）

## 现象描述

在国企间贸易纠纷中，中间方国企主动向法院主张本链条业务为“名为贸易、实为借贷”的融资性贸易，以免除自身付款/交货义务——即使这会给自己带来违规内部处罚。逻辑是：证明融资性贸易后，B 不必向 A 付款、不必向 C 交货，且未造成国有资产流失，“两权相害取其轻”。（2026 年万联网口径，观点性内容，证据强度中等偏弱）

## 典型链条结构

```
国企A（上游）— 国企B（中间方）— 国企C（下游）
C 委托 B 从 A 采购；货物由 A 直发 C（B 不控货）；
C 收货后付款给 B，B 扣价差后向上付款给 A。
```

出险场景：A 称已发货、C 向 B 否认收货并不付款 → B 主动自曝融资性贸易。

## 成因分析

1. **考核压力 vs 市场萎缩**：文中称 2025 年不少国企营收指标较 2024 年增长 10%–15% 以上（无出处，存疑），完不成即问责；终端优质客户饱和、终端业务有合规障碍（招投标内定等国企不敢碰）且周期长赶不上考核节奏。
2. **国企互信光环**：认为“都是国企跑不了庙”，互相做业务既冲营收又互相背书；出险后反成互相伤害。
3. **定义模糊**：融资性贸易并非严格法律概念，现行法律法规无统一定义；国资委界定为违规但口径模糊，反成纠纷中逃避合同义务的“耍赖利器”。

## 张力与局限

- 本文建议 C 方“该曝光就曝光”，与“都是国企抬头不见低头见”的行业生态叙事存在内部张力（观点性建议，非事实）。
- “定义模糊”既是企业钻空子的原因，也是监管严打的对象，这一口径缺口是本议题的核心张力。
