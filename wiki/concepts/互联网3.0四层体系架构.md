# 互联网3.0四层体系架构

[[北京市互联网3.0创新发展白皮书2023]]提出的架构划分：

1. **基础设施层**：为互联网3.0运行提供必需的基础设施保障。
2. **交互终端层**：XR终端等交互载体。
3. **平台工具层**：内容制作工具平台等。
4. **应用层**：数字人、数字藏品等落地应用。

说明：新闻稿仅概述四层划分并对基础设施层作注释，其余各层的白皮书原文具体内容未随新闻提供。
