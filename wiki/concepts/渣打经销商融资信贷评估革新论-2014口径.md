# 渣打经销商融资信贷评估革新论（2014口径）

据 2014 年《国际商报》转述，渣打银行经销商融资的最大突破在于**银行评估信贷风险方式的革新**：传统信贷评估主要分析财务报表，报表不满意则要求担保或抵押；而在经销商融资中，银行首先考虑：

1. 企业产品是否畅销（通常体现在**市场份额**上）；
2. 产品在市场中是否具有领先地位；
3. 所在行业门槛是否较高；
4. 核心企业是否具有完备的**经销商渠道管理体系**。

满足上述条件后，渣打银行可向核心企业直接付款，进而缩短核心企业的应收账款周期。

## 与装运前融资的延伸

渣打已将单纯的装运后融资延伸至**装运前融资**：凭核心企业订单向供应商提供原料采购与生产融资；成品装运后信贷风险减小，融资利率相应调低。供应商融资条件通常更为优惠，但买方（核心企业）也可能借此向供应商要求更好的采购价或更长付款账期——即核心企业可能部分截取融资红利。
