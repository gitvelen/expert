# 供应链票据十大价值点（2025 郇公弟口径）

郇公弟（中晟供应链执行总裁，2025 论坛演讲）：供应链票据作为数字化票据依托 API 技术嵌入交易场景，推动票据进入“数票时代”，解决传统商票不可拆分、流通性差的问题。

## 十大价值点

**企业端（5 项）：**
1. 拆票收费实现平台盈利闭环
2. 有限追索增强票据支付功能
3. 供票保理联动 ABS 等融资工具
4. ABCP 滚发匹配短期票据与批量资金
5. SAAS 建站与 API 输出灵活嵌入产业场景

**银行端（4 项，来源列举合计 9 项细分点）：**
6. 裂变获客（如日照银行将流贷授信转化为客户增量）
7. 普惠贴现支持小微融资
8. 引入担保降低风险并提升资本效率
9. 通过供票转、再贴等借力同业票据市场实现再融资

## 内在张力与挑战（同一演讲承认）

- 与传统 [[电子债权凭证]] 相比，供应链票据**盈利模式单一、银行参与动力不足**（利差受限）
- 需监管创新（合法身份界定）与技术深化（API 场景嵌入）

自述案例：协助陕建完成年融资 200 亿元（宣称口径，待考证）。证据强度：服务商宣讲口径，价值点属模式描述非经核验事实。
