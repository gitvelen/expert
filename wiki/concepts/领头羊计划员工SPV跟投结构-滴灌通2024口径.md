# 领头羊计划：员工SPV跟投结构（滴灌通2024口径）

滴灌通2024年5月全员信公布的"二级火箭"导航系统：员工自募100万元、公司配资900万元成立 SPV，员工作为合伙人组建小团队负责运营、决策与对外投资，挖掘优质资产到 [[滴灌通澳交所]] 挂牌。

## 结构与限制条款（保留原文结构）

- **投资限制**：项目须符合滴灌通风险偏好（如"爱跑路的健身房不能投"）；团队每年费用支出合计不超过100万元。
- **分成模式**：与投资门店相同，采用联营方式，SPV 向滴灌通提供净收入分成——滴灌通回本前分成比例70%，回本后35%；净收入减去分成与运营成本后的收益 SPV 可自由支配（奖金不超过当年结余）。

## 退出方式

1. **联营退出**：累计分成达到目标倍数后团队可提前结束联营并转让 SPV。倍数要求：第一年1.08、第二年1.16、第三年1.24、第四年1.32……
2. **风险退出**：滴灌通在年度、半年度、季度三个窗口期考核预期回本进度，未达回本底线即清算。

## 回本进度表

| 节点 | 累计回本比例 |
|------|------|
| 2024年12月底 | 5% |
| 2025年6月底 | 15% |
| 2025年12月底 | 40% |
| 2026年6月底 | 60% |
| 2026年12月底 | 75% |
| 2027年6月底 | 100% |

即100%回本周期约36个月，对比滴灌通投资门店48个月的平均联营期，压力明显。

## 亏损分担条款（草案）

| 情形 | 员工100万处理 |
|------|------|
| 滴灌通回本 | 全额退还 |
| 清算时剩余规模1000万 | 100万全退 |
| 资产净值小于600万 | 100万不退 |
| 净值600万–800万区间 | 少于1000万的部分由员工承担10% |

即599万与600万之间差的不是1万，而是60万（阶梯效应）。

## 舆论解读

据本来源，该计划"似乎不是强制报名"（公司称"推选一批优秀骨干……团队跟投一部分"）；但被外界解读为"付费上班"和面向员工变相募资，与同期裁员1/4叠加，构成"资金压力"叙事的一部分。实际执行与回本进展待验证，见 [[查询-领头羊计划SPV实际募资与回本进展]]。
