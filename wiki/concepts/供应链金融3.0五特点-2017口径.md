# "供应链金融3.0时代"五特点（2017口径）

2017 年行业叙事中的"供应链金融 3.0 时代"五特点（出自 [[sources/4-news--7-04-业务基础--4-2017--14-供应链金融创新模式供应链技术--taplw0]]）：

1. 成为产业互联网发展的重要组成部分和推动力；
2. 与 P2P、众筹等互联网金融方式结合更加紧密（**旧口径**：此后 P2P 全行业清退，该特点已被淘汰）；
3. 在线订单、在线仓单、在线保理等多模式并存向纵深发展；
4. 全球化供应链金融服务体系逐步走向成熟；
5. 风险控制体系更加完备。

## 与其他阶段论的关系

此为"供应链金融 N.0"阶段论的又一 2017 年版本表述，与 [[供应链金融10至40四阶段演进-2017口径]] 同族但内容不完全一致，可作 [[供应链金融阶段论三分法与四分法对比]] 的补充证据：各版本"3.0"内涵并不统一，阶段论更多反映各自叙事而非公认分界。
