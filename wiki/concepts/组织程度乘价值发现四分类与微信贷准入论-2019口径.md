# 组织程度×价值发现四分类与微信贷准入论（2019口径）

## 框架内容

[[宋华]] 2019 年提出评判产融实践的两个维度：

1. **组织程度**——能否把上下游及各利益相关者有机组织起来；
2. **价值发现**——能否把握每个要素/资产的状态，透明资产以发现价值。

由此将大多数产融实践分为四类：

| 类型 | 组织程度 | 价值发现 | 例证 |
|------|----------|----------|------|
| 传统借贷/无金融服务 | 无 | 无 | 传统信贷或不存在的服务 |
| 微信贷（准入型） | 有 | 无 | 蚂蚁金服收钱码授信 |
| 反应性供应链金融 | 弱（局部） | 有 | 欧普照明经销商融资 |
| 前摄性供应链金融 | 有 | 有 | 中粮贸粮食银行+种植贷 |

## 微信贷"准入型"论

宋华判断：微信贷有组织化程度、能完整反映流程，但不把握每个流程中的要素与资产状态，因此**只能叫"准入型的供应链金融"**——风控基于产业环境和群体网络中的个体信贷，资金规模被锁在"万级"（"再大控不住了"）。以蚂蚁金服为例：通过支付宝收钱码了解资金支付与流向，但机构并不了解借款人具体的业务操作与资产。

## 强度与张力

- 该论断是宋华个人观点，"万级"上限无量化数据支持，**不固化为 finding**。
- 与 2019 年蚂蚁系自我宣传口径（数据信用典范）存在张力，属于对平台系"数字信贷是否等于供应链金融"的核心批评，可作后续 synthesis 的观点对比素材。
- 对产品设计的启示：仅有交易流程组织而无要素级（货物/资产）把握时，风控天花板受群体网络规模约束，难以支撑大额授信。
