# "ALL DOCUMENTS"与"SHIPPING DOCUMENTS"释义及汇票排除规则

## 问题背景

"ALL DOCUMENTS"（ALL DOCS）是信用证实务中出现频率很高的措辞，但 UCP600 与 ISBP745 均未对其定义，各家银行理解不一，易成为信誉不佳开证行无理拒付的切入点。

## 现行口径（2020 年整理）

- **"SHIPPING DOCUMENTS"（装运单据）有明文定义**：ISBP745 A19 a 款——信用证要求的所有单据，但**不包括**汇票（DRAFTS）、电讯传送报告（TELETRANSMISSION REPORTS）、以及证实寄送单据的快递收据、邮政收据或邮寄证明。
- **"ALL DOCUMENTS" 无明文定义（惯例空白）**：依据 ICC 2016 年秋季 TA853 号意见（场景为 47A 规定 "ALL DOCS TO SHOW CONTRACT NO. AND DATE"，受益人汇票未显示合同号与日期），ICC 最终意见为 "ALL DOCS" **不包含 DRAFT**，单证相符。详见 [[findings/TA853号意见-all-docs不包含汇票-ICC-2016口径]]。

## 适用边界与张力

- TA853 的场景是"显示合同号"类条款，直接类推到 H.S CODE / IRC NO. / LCA NO. 等技术编码类条款存在一定跳跃；本案例中开证行最终付款但仍扣不符点费，说明其并未完全接受该论点。
- 开放问题持续跟踪于 [[queries/查询-TA853号意见原文及其对技术编码类条款适用边界]]。

## 实务要点

- 界定 "ALL DOCS" 应从功能而非字面出发：汇票是否属于"单据"，取决于其功能定位（见 [[concepts/汇票功能性定位论]]）。
- 开证环节即应识别此类有歧义的单据化条款并事前协商修改，而非事后交涉。
