# 场景化费用管理SCO模式（招银云创口径）

场景化费用管理SCO是[[招银云创]]推出的新一代智慧费用管理SaaS产品，通过聚合企业差旅、出行用车、企业采购等高频费用支出场景，以"信息流+资金流"双闭环连接企业与银行，为银行"场景融入"式场景金融建设提供载体。以下内容均为公司披露口径（2022年），未经第三方验证。

## 信息流闭环（全流程服务）

聚合采购、机票、酒店、出行等服务商资源，通过银企直联接入上百家银行；企业实现：

预算管控 → 在线预订 → 发票管理 → 支付入账 → 账户管理 → 账户可视 → 资金归集 → 数据分析

## 资金流闭环

实现"资金需求—资金授信—平台消费"闭环，"一个平台一个账户"。企业资金账户三种模式：

1. 企业预存
2. 银行授信（银行根据企业需求及平台历史数据授信）
3. 信用卡

关键机制：企业授信额度在平台内**定向使用**并有数据追踪；多维可视化数据分析为银行风控提供抓手。

## 场景金融生态四主体

| 主体 | 角色 |
|------|------|
| 资金方 | 银行：金融服务开发与生态圈风险管理 |
| 场景运营方 | 招银云创：场景建设与运营 |
| 场景服务方 | 机票/酒店/采购等服务商 |
| 消费方 | 企业 |

## 对银行的含义

银行不必在场景建设和营销获客上花费过多精力，可专注于金融服务的创新和风控；以非金融服务联接用户、提升粘性，弥补传统"以销售金融产品为出发点"客户价值转化模式的不足。

## 张力与局限

差旅、用车等被描述为"零碎长尾、运营成本过高"的市场，本模式的商业可持续性无数据验证；"定向使用+数据追踪"与融资性贸易/资金用途追踪议题相关，但风控细节未展开。
