# 供产销消四层企业需求框架（招行2017口径）

招商银行在 2017 年的供应链金融方案介绍中以“企业马斯洛需求”为喻，按**供、产、销、消**四个层面归纳企业需求，作为产品设计的需求坐标系（修辞包装，实质为分层需求清单）。

## 四层需求清单（2017 转述口径）

| 层面 | 企业需求 |
|---|---|
| **供** | 降低采购成本、适度延长账期、采购资金融通、便捷财务结算、稳定供应渠道 |
| **产** | 降低原材料库存、盘活闲置资产、固定资产投资、加强成本管理、企业发展规划 |
| **销** | 降低产成品库存、扩大市场份额、加快资金回笼、便捷财务结算、管理分销渠道、回笼资金增值 |
| **消** | 在线结算、小额信贷、个人闲置资金理财 |

## 用法与局限

该框架可作为供应链金融产品需求分析的核对清单：付款代理对应“供”层（账期与采购融资），C+智慧票据池对应收付结算与融资变现需求。注意“马斯洛”类比属修辞包装，各层需求为并列而非层级递进关系。
