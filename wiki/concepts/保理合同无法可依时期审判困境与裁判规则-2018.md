# 保理合同"无法可依"时期审判困境与裁判规则（2018 年口径）

> ⚠️ **时效性标注**：本页为 2018 年历史口径。2021 年《民法典》第三编设保理合同专章（第 761–769 条）并出台配套司法解释，"无法可依"状态已被取代。本页保留供历史对照，现行裁判以民法典口径为准（见 [[queries/查询-民法典保理合同章对2018年三个典型案例裁判规则的吸收与修正]]）。

## 立法真空状态（2018 年）

- 《合同法》《民法通则》《物权法》均无保理专章，最高法院无专门司法解释，民事案由中亦无保理合同案由。
- 规范层级：仅《中国银行业保理业务规范》《中国银行业保理业务自律公约》及上海、天津地方规范，且多为行政性规定。
- 国际层面：《国际保理公约》（国际统一私法协会，唯一专门性公约）与 UNCITRAL《国际贸易中的应收账款转让公约》中国均未加入；FCI《国际保理通则》作为国际惯例可被适用。

## 四大审判困境

1. **性质模糊**：合同性质与案由各地不一（金融借款合同纠纷、债权转让合同纠纷等混用）。
2. **法律空缺**：只能适用散见于其他法律的规定，法律适用难以统一。
3. **诉讼地位不明**：保理商、供应商、债务人三方诉讼地位无统一做法。
4. **争议不定**：反索追索事由、通知效力等问题一、二审可完全改判。

## 三案例确立的裁判规则（有判例价值）

| 案例 | 规则 |
|------|------|
| 云纺诉中行北京分行（1994） | 无追索权保理中，因出口商责任的商业纠纷（反索）仍可追索；未转让合格应收账款即不发生风险卖断 |
| 某银行有追索权保理案 | 央行转让登记仅为"公示服务"，无强制排他对抗效力，不能免除通知义务；《更改付款账户申请》不能推定为转让通知 |
| 有追索权保理反转让案 | 保理商有先向债务人追索的选择权；未受偿部分可要求供应商反转让（79.52:100 折算）并清偿融资本息 |

## 后续

民法典保理合同章吸收了债权转让定性、通知效力等基本框架，但具体裁判规则（登记对抗、反索除外、隐蔽保理）的吸收与修正程度待核实——见对应 query 页。
