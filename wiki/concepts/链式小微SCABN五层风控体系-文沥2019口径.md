# 链式小微S-C-A-B-N五层风控体系（文沥2019口径）

文沥提出的小微金融风险管理方法论："链式小微"——将小微企业放在供应链交易中看待，而非孤立评价个体主体信用。小微企业天然主体风险高、经营波动大，孤立进行主体信用评价困难，故需依托交易链数据。

## 五个层面（原文结构保留）

| 层面 | 代码 | 内容 |
|---|---|---|
| 卖方评价 | S | 对卖方的信用评价 |
| 客户甄选 | C | 甄选交易客户 |
| 授信管理 | A | 主要指行方对主体信用的评价，是银行主动风险管理构建的重点 |
| 用信管理 | B | 对每笔用信行为的管理 |
| 贷后预警 | N | 贷后风险监测预警 |

## 核心原则

**主体信用必须与交易信用相结合，授信与用信并重**，方能有效降低风险；信贷审批从"授信"转向"授信用信并重"，评价从主体信用转向每笔交易信用融合。

## 与既有观点的呼应

与 [[重债项轻主体与交易额度代替授信额度-王鹏虎2019口径]]（王鹏虎/中信银行，2019）高度同源，同属 2019 年银行数据信用/交易信用转型观点簇，可互相参照。
