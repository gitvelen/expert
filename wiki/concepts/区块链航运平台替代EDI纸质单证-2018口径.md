# 区块链航运平台替代EDI与纸质单证（2018 口径）

> **历史口径提示**：本条目为 2018 年区块链热潮时期的技术乐观口径，作为"数字化承诺史"存档；该方向的代表平台 TradeLens 已于 2023 年关停（见 [[queries/查询-IBM马士基合资平台TradeLens的后续发展与关停原因]]）。

## 口径内容

据 [[entities/IBM]] 与 [[entities/马士基]] 2018 年合资筹建公告（转述口径）：

1. **替代对象**：EDI（电子数据交换，已有约六十年历史）+ 主要依靠书面文件的货运信息系统
2. **新平台架构**：区块链 + API 应用程序接口为底层，供应链各方实时分享信息、提高透明度
3. **效率宣称**：加快海关与港口管理方批文审批，减少集装箱在收货区搁置数星期的情况
4. **成本宣称**：每年为全球航运业节约数以十亿美元计的成本（预测性测算，无出处，证据弱，见 [[queries/查询-区块链航运平台数十亿美元成本节约测算的出处]]）

## 私有链与联盟链的选择

文中提及的通用技术判断：在公司内部搭建私有链，还是在可信合作伙伴间搭建联盟链，取决于投入方对网络上信息传播控制的需求。

## 评价

该口径反映了 2018 年行业从"概念科普"到"概念验证"的阶段性判断（安永 Paul Brody），但其乐观预期与后续 TradeLens 关停的事实形成重要对照，是评估"区块链 + 供应链"类叙事时必引的历史基准点。
