# 融资性贸易三模式：托盘贸易、循环贸易、委托采购（2024口径）

来源：万联网 2024-04-08 文章，含三个代表性判例。

## 1. 托盘贸易

托盘方（通常是国企）与买卖双方分别签订采购合同，利用账期为卖方/买方提供融资。资金需求方 A 因缺乏资金，引入托盘方 B 分别与下游 A、上游 C 签订买卖合同，B 向 C 支付全部货款，加固定价格后分批出售给 A。

**判别要点**：
- 通常有真实货物流转，但资金方不直接参与货物流转过程
- B 仅收取固定利润（与货物价格波动无关），不承担货物转移相关风险
- B 既不控制货物也不承担流转风险
- 上下游客户由 A 直接指定，非 B 自由选择

**判例**：（2010）民提字第110号——查莉莉与杭州天恒实业有限公司、上海豫玉都钢铁贸易有限公司、常熟科弘材料科技有限公司企业借贷纠纷案

## 2. 循环贸易

相同或关联企业间签订内容相同的多份买卖合同，形成闭合的货物流转回路，无实际货物流转，帮助融资方取得资金使用权。

- 货物流：资金需求方 → 资金供给方 → 过桥方 → 资金需求方
- 资金流：资金供给方 → 资金需求方 → 过桥方 → 资金供给方
- 各方事前对"假买卖真融资"知情并主动参与

**判例**：（2015）二中民（商）终字第09571号——中国五金交电化工公司与江苏利协金属材料有限公司买卖合同纠纷案

## 3. 委托采购

提供资金的企业接受融资方委托代为采购，将收购、保管、销售三环节全部或大部分交由融资企业（或其关联方）完成，不直接有效控制货权。与托盘贸易的最大区别：买卖法律关系变为**委托法律关系**，货物转移风险与控制权均由资金需求方承担。

**判例**：（2014）民申字第1178号——唐山建源钢铁有限公司、吕金弟等与厦门成大进出口贸易有限公司委托合同纠纷案
