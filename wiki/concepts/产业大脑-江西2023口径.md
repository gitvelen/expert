# 产业大脑（江西2023口径）

产业大脑在《江西省产业大脑建设指南（2023年版）》（试行）中被定义为：以工业互联网为重要支撑、以数据资源为核心要素、运用新一代信息技术、以产业链整合重构为路径，集成企业侧、产业侧、政府侧应用场景，服务产业数字化、数字产业化、经济治理现代化的**公共智能系统和新型数字基础设施**。其关键特征是"由政府牵头，具有行业公共属性"，通过数据协同、数据赋能推动全产业链协同数字化转型。

## "五链融合"总体框架

以产业大脑驱动，构建以下产业发展新业态：

| 链 | 定位 |
|---|---|
| 产业链 | 变革目标 |
| 创新链 | 抓手 |
| 资金链 | 保障（供应链金融的政策接入点） |
| 人才链 | 保障 |
| 政策链 | 保障 |

## 关键机制

1. **"一个行业一个大脑"**：整体规划、集约共享，一地建设全省共享，各级产业大脑通过统一数据接口接入产业大脑总平台。
2. **三类应用**：政府管理端应用（G端，工业运行管理、经济风险预警等）、政府服务应用（G2B）、企业间服务应用（B2B，产业生态构建、智能化改造、共性技术和转型问诊服务）。
3. **数据机制**："授权才可用"的数据利用机制；探索区块链、多方安全计算强化核心数据防篡改、关键操作可信存证、风险预警与事件追溯。
4. **揭榜挂帅**：政府申报、专家评榜、建设期两年、动态考核与摘牌机制。

## 与知识库其他概念的关联

- "授权才可用"与区块链/多方安全计算思路与 [[交易证据链与产业可信数字环境-众陶联2023口径]]、[[公共数据授权运营-2023口径]] 同构，共同印证：产业可信数据环境是供应链金融数据信用的前置条件。
- 产业大脑的公共数据中心与 B2B 应用可为供应链金融提供行业级数据信用基础。

## 内部张力

"政府牵头、具有行业公共属性"与"遵循市场化路线、成立市场化运营主体"之间存在政府主导与商业化可持续之间的平衡难题（见 [[查询-江西产业大脑揭榜名单与建设成效后续]]）；"一行业一大脑"与实际多平台并存的产业现实也可能存在张力。
