# 大中小企业"七条链"融通创新

"七条链"融通创新指促进大中小企业在**创新链、产业链、供应链、数据链、资金链、服务链、人才链**七个维度全面融通，构建大中小企业相互依存、相互促进的企业发展生态。其目的是释放大企业创新活力、激发中小企业创新潜力。

## 七链内容（以山东实践为表述）

| 链 | 关键举措 |
|---|---|
| 创新链 | 联合技术攻关；研发测试环境、仪器设备共享；高校科研成果分类分级评估入库并免费向中小企业开放 |
| 产业链 | 省属企业强基补链；培育专精特新"小巨人"（"补短板""锻长板""填空白"） |
| 供应链 | "专精特新"企业卡位入链；征信机构信用评价与风险管理；省属企业供应链预警机制 |
| 数据链 | 大企业开放数字化应用与工业互联网平台；低成本中小企业数字化解决方案 |
| 资金链 | 金融机构与产业链核心企业专项对接，为上下游打造综合金融服务方案 |
| 服务链 | 大中小企业携手提升服务能力 |
| 人才链 | 大中小企业共建人才队伍 |

## 关联概念

- 该概念是"大中小企业融通发展"在供应链金融语境下的具体框架，与 [[供应链融资支持大中小企业融通发展]]（国务院"稳经济33条"）相呼应；山东"链长制"与 [[央企供应链金融服务平台链长模式]] 可作央地对照。
- 供应链维度的抓手为 [[专精特新卡位入链工程]]。
