# 国企大宗贸易微利倒挂与规模考核困局（2026口径）

指国有供应链企业在大宗商品（铝锭、钢材等）购销中"越做越亏却不能停、不敢停"的结构性困局。来源为万联网 2026-07-07 观点文章（一般公众号口径，财务数据均来自匿名案例，证据强度低，引用须注明）。

## 一、微利倒挂的量化事实（匿名省属企业2024年铝锭专项财报口径）

| 项目 | 数值 |
|---|---|
| 含税单价 | 2.2万–2.4万元/吨 |
| 单吨价差 | 100–200元（毛利率不足1%） |
| 全年贸易量 | 12.8万吨 |
| 账面毛利 | 1860万元（单吨145元） |
| 资金利息支出 | 920万元（年化3%–4%，30天账期单吨近60元） |
| 增值税及附加 | 410万元 |
| 仓储物流及人工风控分摊 | 680万元（单吨50–80元） |
| **板块净利** | **净亏150万元** |

民企可通过灵活拆借、灰色渠道压缩成本；国企流程规范、全程留痕，纯现货购销天然陷入成本倒挂。

## 二、"不能停"的三重结构性原因

1. **唯规模论考核与评级/融资绑定**：营收、吞吐量是硬性考核指标，直接关联绩效薪酬、评优、主体信用评级。匿名地级市平台案例：百亿硬指标下增值业务仅贡献12亿营收，靠大宗贸易拉升至92亿仍亏830万；2024年收缩致营收降40%、评级被审慎下调、年度融资成本增近千万。收缩即触发评级下调→授信压缩→融资成本上升的负反馈。
2. **市场竞争无退路**：放弃采购则上游货源配额流向民企；拒接低毛利赊销则下游客户全部流失，统筹保供的平台初衷不复存在。
3. **属地保供等政策性职能**：2022年匿名华东案例——单吨亏超80元仍刚性完成10.5万吨保供，主动承担政策性亏损800余万元；大宗贸易带来的增值税与流通统计量也是属地商贸指标，企业无自主收缩权限。另有"以贸易养服务"逻辑：微利贸易摊薄每年数千万的固定运营成本，全面停摆则增值业务不足以覆盖刚性开支，企业面临缩编关停。

## 三、困局的危险出口

持续倒挂下，账户沉淀的大额现金流成为"无奈兜底手段"——挪用贸易沉淀资金跨界套利填补亏损，即 [[贸易现金流沉淀套利与空转贸易模式-2026口径]] 所述的暴雷路径。

## 四、破局方向（作者观点，非官方口径）

弱化规模考核（部分地方国资已取消营收硬性增速）、产业增值服务转型（[[浙商中拓]]、[[物产中大]] 标杆：氧化铝集采、仓储加工、合规仓单质押、套保服务）、合规资金统筹机制、清理空转走单业务。
