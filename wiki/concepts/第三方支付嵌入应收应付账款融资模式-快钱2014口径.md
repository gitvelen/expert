# 第三方支付嵌入应收应付账款融资模式（快钱2014口径）

## 模式结构

以 IT 分销核心企业 A 与众多下游分销商 B 的赊销场景（"先货后款"，回款周期数月）为例：

1. **订单整合与数据筛选**：快钱将数百上千个 B 的订单整合集成，分析 B 与 A 的历史交易记录、B 的业务健康状况并做筛选；
2. **打包交付银行**：将小订单打包成一个大订单交付银行；
3. **银行常规放款**：银行按常规审核标准审核，符合信贷条件则对 A 融资；
4. **到期回款**：B 在赊账到期日将账款打还给 A。

快钱自称角色"相当于保理商"。效果：核心企业 A 资金回笼加快、财务成本降低、资金周转提速。

## 意义与定位

- 本质是"**数据信用 + 订单整合**"式供应链金融早期实践：以历史交易数据分析筛选替代对单一主体的信贷调查，是 2014 年"数据信用"替代"主体信用"工作论点的雏形案例。
- 与 [[在线供应链金融定义与四化收益-2014口径]] 同期，反映支付机构借助交易数据切入 B 端融资的路径。
