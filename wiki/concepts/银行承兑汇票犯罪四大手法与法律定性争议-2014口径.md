# 银行承兑汇票犯罪四大手法与法律定性争议（2014口径）

本概念页汇总 2014 年《法制日报》报道所归纳的银行承兑汇票犯罪典型手法、法律定性争议与风控启示，是票据操作风险与欺诈风险知识簇的核心框架。

## 四大作案手法

1. **截收查询、冒名确认**：买通开票行与邮政人员截收查询电报/传真，盗用银行名义确认查复，甚至当面冒充开票行人员接受查询——直接击穿“向承兑行查询验证”这一传统风控环节。
2. **“克隆”汇票与票据调包**：以传真件仿制票据（模仿笔迹、印章），调包后持真票到银行兑付提现，出票人手中只剩废纸。教训：不应向交易对手传真票据原件。
3. **无真实贸易背景圈钱**：伪造交易合同、反复使用同一增值税发票原件、集团内对开发票、企业/券商/银行三方默契开票 + 保证金 + 关联企业贴现，套取资金流入股市——即“虚假贸易票据化”的典型形态。
4. **利用银票逃债**：销售回款全部走承兑汇票结算，收票后背书转让购原料或由关联企业贴现套现，使银行债权管理失控、逃避收贷收息。

## 法律定性争议（2014 年口径，学界与实务三说并存）

- **实务（青岛警方）**：承兑汇票非现金，盗窃不构成刑事犯罪，按民事纠纷处理。
- **于阜民**：本质是诈骗犯罪；后续行为符合刑法第194条五种情形之一的定票据诈骗罪，否则按诈骗罪论处。
- **刘明祥**：盗窃银票行为本身不构成盗窃罪（银票只是信用凭证，未使用则不造成损失），关键看后续使用行为——直接贴现→金融凭证诈骗罪；质押骗贷→贷款诈骗罪。

**牵连犯罪名交叉**：伪造金融票证罪（手段）→ 票据诈骗/金融凭证诈骗/贷款诈骗（目的），通说从一从重处断，但理论与实践中数罪并罚存在分歧。

## 制度性风险根源

票据见票即付 + 银行只能做形式审查（逐笔实质审查不经济、否则失去票据便利意义），构成固有犯罪空间。

## 风控启示

- 查询验证环节不可依赖电报/传真等可被截收截获的通道，需直连承兑行官方系统。
- 禁止向交易对手传真票据原件（克隆票源头）。
- 贴现环节须穿透核验贸易背景（增值税发票应联网核验防重复使用）。
- 关注借款人结算方式异常（回款全走承兑汇票可能是逃债信号）。
