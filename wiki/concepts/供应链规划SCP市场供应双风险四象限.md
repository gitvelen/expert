# 供应链规划（SCP）市场端×供应端风险四象限策略

宋华（2020）依据 Gartner 2019 年调查（供应链规划是企业供应链管理最重要能力之一）提出的运营模式决策框架。两个决策维度：

- **市场端风险**：订单波动、销售渠道中断、分销物流中断等。
- **供应端风险**：供应链中断可能性、供应物流阻碍、供应商复工与经营状况等。

## 四象限策略

| 市场端风险 | 供应端风险 | 运营策略 |
|---|---|---|
| 低 | 低 | 维持原有经营，加强效率管理、降本增效 |
| 高 | 低 | 快速响应与敏捷：寻求替代销售渠道/物流、调整销售分销计划、协同法务人事评估财务影响 |
| 低 | 高 | 供应风险管理：本地或可及区域多源供应，关键原料建缓冲库存 |
| 高 | 高 | 双端风险管理与调整，并准备充足流动性资金渡过困难期 |
