# 供应链四流框架（2017 科普口径）

供应链一般包括四个流程：

1. **物资流通**：商品由供货商经厂家、批发与物流、零售商指向消费者，**单向**流动。
2. **商业流通**：接受订货、签订合同等商业流程，供货商与消费者之间**双向**流动。
3. **信息流通**：商品及交易信息流程，**双向**流动。
4. **资金流通**：货币由消费者经零售商、批发与物流、厂家等指向供货商，**反向**流动。

配套的五要素结构为：供应商 → 厂家 → 分销企业 → 零售企业 → 消费者；文中特色表述为“消费者是整条供应链的唯一收入来源”。

> 口径说明：2017 年通识性科普整理（私募通综合整理），证据强度为一般转述，作为基础框架快照使用，不作为权威定义来源。
