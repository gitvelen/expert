# 供需不确定性 2×2 供应链战略矩阵（2017 赵先德口径）

以"需求不确定性"与"供应不确定性"为坐标轴，将产品/细分市场映射到四个象限，每象限对应一类适用战略（赵先德、王骊静，2017）：

| 象限 | 适用战略 | 思路 |
|---|---|---|
| 低需求不确定性 + 低供应不确定性 | 高效型 | 规模化生产标准化产品，以规模经济取胜 |
| 低需求不确定性 + 高供应不确定性 | 风险对冲型 | 集合、共享多种供应资源，共担供应波动与风险 |
| 高需求不确定性 + 低供应不确定性 | 快速响应型 | 对多元化客户需求快速灵活反应 |
| 高需求不确定性 + 高供应不确定性 | 敏捷型 | 快速响应型与风险对冲型的集合 |

- 常见需求不确定性：需求难预测、个性化、变化快、SKU 多而单品销量低；供应不确定性：产量低且不稳、提前期不定、流程变化多、产线难转换、供应源不可靠。
- 指导思想：将不同细分市场的产品线分别定位到象限，选择匹配战略。案例演示见来源页 [[sources/4-news--7-04-业务基础--4-2017--25-物流要发展需要知道供应链管理的这三层境界供应链管理--17ikehw]]（宇通、梅花、聚慧）。
- 与 [[推拉式供应链]] 的关系：按需求不确定性划象限实质上是推拉边界选择的方法论化。
