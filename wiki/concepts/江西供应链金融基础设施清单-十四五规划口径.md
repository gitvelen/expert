# 江西供应链金融基础设施清单（十四五规划口径）

《江西省"十四五"金融业发展规划》（2021）第五节"增加供应链金融基础设施供给"部分提及的机构与平台（万联网转述口径）：

| 基础设施 | 功能定位 |
|---|---|
| 省普惠金融综合服务平台 / "赣服通"金融服务专区 | 金融机构与核心企业接入，依法合规利用公共数据为供应链上下游中小微企业融资提供便利 |
| 赣南金融资产交易中心 | 供应链金融底层资产的产权交易服务 |
| 省联交运登记清算中心 | 资金监管、信用信息等供应链金融服务 |
| 特色小额贷款、融资担保、商业保理、融资租赁机构 | 服务于供应链金融的地方金融组织 |
| 地方交易场所 | 专注服务产业客户，建设配套仓储、物流体系，提升大宗商品等现货实物交易服务水平 |
| 中国人民银行征信中心应收账款融资服务平台（中央设施） | 鼓励核心企业、金融机构对接，发展线上应收账款融资 |

## 备注

- 公共数据支持融资条目属"数据信用"落地路径的地方实践。
- 交易场所配套仓储物流与知识库仓单/货押主题直接相关；保险条款中的仓单财产险亦同。
- 各机构实际业务开展情况未验证，待后续跟踪。
