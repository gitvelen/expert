# 期货公司常态化压力测试机制

指期货公司按照《[[期货公司压力测试指引试行]]》建立的定期与不定期相结合的风险测试制度。

## 机制要点

- **频率**：每年至少一次年度综合压力测试；可根据市场变化、业务规模、风险状况和监管要求不定期开展
- **报送**：压力测试报告须于4月30日前按要求上报
- **覆盖范围**：全面覆盖公司及子公司（资产管理、风险管理等）各业务领域，并考虑各类风险间的相关性

## 压力传导路径

```
假定的、极端但可能发生的压力情景
  → 经纪业务 / 资产管理业务 / 自有资金投资 / 收入利润的变化
  → 六项风险监管指标的预警达标情况
```

## 背景与参照系

期货公司此前缺乏压力测试工作机制，《指引》借鉴**银行、证券公司**等金融机构的成熟经验构建该机制。

## 后续悬念

- 风险管理业务的压力测试规则"另行规定"
