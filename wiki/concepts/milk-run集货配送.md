# Milk Run 集货配送

Milk run（集货配送）是一种物流优化策略：对同一配送路线的多个经销商/取货点安排订货或取货时间，由一辆车按固定路线巡回集货/送货，实现合并运输、提高车辆满载率、降低物流成本。

在 2010 年 SCM 选型语境中，milk run 与订货体积计算（满载）、零担合并整车、直送二批、运输商装载时间规划等并列，作为供应链第三层面（优化）中的物流业务优化策略（见 [[SCM需求三层面论-2010口径]]）。
