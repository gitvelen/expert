# 无追索权保理四项基本服务功能与全流程操作要点（2018口径）

无追索权保理（综合保理）是保理业务中最完整的一种保理形态，包含全部四项基本保理业务服务功能：**资金融通、销售分户账管理、应收账款催收、坏账担保**。以综合保理为例考察其操作流程，是理解保理基本原理与掌握其他保理品种的一条捷径（2018 年培训科普口径，出处：《商业保理业务最全路演》《保理业务的技术操作要点与原理详解》）。

## 四项基本功能

1. **资金融通**：卖方转让应收账款后可提取已收付款项或预付款（贸易融资）；保理商设立资金使用账户（FIU，Fund In Use），按"可融资余额 = 合格发票 × 融资比例 − 已融资余额"控制融资；收到买方付款后先充抵融资本息、扣除手续费后划入卖方账户。
2. **销售分户账管理**：保理商为卖方建立销售分户账，记录保理商、卖方、买方三方债权债务变动，控制额度使用，提供对账单与销售/财务分析报表。**管理功能是保理区别于一般贸易融资的最重要方面，是企业赊销管理外包的重要体现**。
3. **应收账款催收**：从发票到期开始，按买方资信、交易记录与卖方客户关系需要分层催收——一般流程为《逾期发票付款催收函》三份（间隔约 10 天、措辞逐次加重），辅以电话、走访；三函后仍未付款考虑法律手段，事先将最后催收函副本发给卖方，卖方反对则反转让。
4. **坏账担保**：见 [[受核准未核准债权与坏账担保额度机制-2018口径]]。

## 全流程操作要点（银行口径）

原文出自银行保理部门（"我行"），整体流程为：卖方考察 → 应收账款适格性评估 → 需求分析与品种选择 → 审批 → 《保理业务要约函》与辅助担保措施（质押权人弃权书等）→ 签约建账（并账/账户转移/保理专户）→ 《保理业务导入函》通知 → 发票转让与审核 → 收款（防间接付款）→ 催收 → 融资 → 月度检查与风险处置（提高融资比例 → 缩减额度 → 暂停融资 → 终止协议）。过程管理依赖客户经理、产品经理、账户经理、稽核人员、信用控制人员五类岗位分工及十余张配套表单。各环节要点如下：

1. **卖方客户考察**：企业内部（财务报表、销售分户账、管理层面谈）+ 企业外部（往来银行评价、行业机构情况、买方印证）双路径；七维度生存能力评价（组织结构/资本构成、管理层能力、财务流动性与盈利、产品/服务、买方分散度与业务关系、资金管理、发展前景）；按业务量确定费率与工作量，形成《卖方整体情况调查报告》。
2. **需求分析与品种选择**：通过九问（现金支撑扩张、增强现金流、规划现金流、开辟市场、借助专业能力、增进供应关系、其他筹资渠道、信用风险控制服务、信用控制咨询）确定需求，形成《需求分析与保理业务品种选择报告》，复杂贸易背景由产品经理协助方案设计。
3. **审批**：提交《卖方整体情况调查报告》《需求分析与保理业务品种选择报告》《企业应收帐款报告》《企业买方付款记录》、有代表性的《贸易合同》、三张财务报表，由审批部门做最终决定。
4. **要约与谈判**：发出《保理业务要约函》（载明品种与服务、费率、辅助担保措施要求），商业条件谈判与辅助担保落实并行，起草签署保理协议。
5. **建账**：卖方将现有应收账款并账后一次性转让，填制《未结发票清单》；保理商剔除逾期、未发货、买方破产、债权不完整、存在争议的发票；据审核后账款建立销售分户账与融资账户。亦有省略并账、仅管建账后新发生账款的安排（保理商不担建账前责任）。建账方式包括并账、账户转移、保理专户。
6. **导入通知**：卖方以自己函头纸按保理商格式制作《保理业务导入函》发给现有及新增买方，告知债权安排，为转让与付款奠基；有时保理商直接寄送已转让应收账款通知以核验双方记录一致性。
7. **日常管理**：账户经理记账维护、记录三方债权债务变动、控制额度使用、提供对账单与销售/财务分析报表；为卖方开立保理专户或签订账户监管协议接收买方付款（防间接付款）。

配套表单包括《卖方整体情况调查报告》《需求分析与保理业务品种选择报告》《异常业务情况调查表》等。

## 关联与张力

- 与 [[保理名实分离与流动资金贷款化批评-2017协会口径]] 形成对照：本框架强调管理/坏账担保功能为保理本质，是"正名"一侧的论据；而 2018 年国内实际以有追索权保理为主，无追索占比低，本文属"理想型"范本。
- 来源为专业公众号培训内容，无数据与案例佐证；文中"我行"等表述提示其范式可能源自银行（出口/国际保理）教材，与国内商业保理实务存在差异，见 [[查询-本文银行保理范式的出处与国内商业保理实务差异核验]]。
- 引用时须注意银行口径 vs 商业保理实务的主体差异（2018 年正值监管划转银保监会）；国内商业保理实务中无追索权保理的占比与操作与该范式可能不一致，引用时注意语境。
