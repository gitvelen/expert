# 物联网/区块链智能风控技术（155号文真实性审查条款）

## 概述

银保监办发〔2019〕155号文"加强真实性审查"条款中，监管首次在供应链金融领域系统性地鼓励将新技术嵌入交易环节，以应对虚假交易、虚构融资风险。本概念页收录早期报道版本中列出的具体技术清单（见[[sources/4-news--7-01-政策合规--4-2019--33-重磅银保监会发文规范供应链金融严防虚假交易虚构融资附全文供应链技术--1eylpq]]）。

## 政策原文要点（报道转述）

> 鼓励银行保险机构将物联网、区块链等新技术嵌入交易环节，运用移动感知视频、电子围栏、卫星定位、无线射频识别等技术，对物流及库存商品实施远程监测，提升智能风控水平。

## 技术清单

| 技术 | 用途 |
|---|---|
| 物联网 | 整体技术底座，嵌入交易环节 |
| 区块链 | 交易信息可信存证与流转 |
| 移动感知视频 | 货物动态的远程视频监控 |
| 电子围栏 | 库存/货物移动边界的自动预警 |
| 卫星定位（GPS/北斗） | 物流在途位置跟踪 |
| 无线射频识别（RFID） | 库存商品的识别与盘点监测 |

## 与风险案例的呼应

该技术清单与wiki中记录的供应链金融典型造假手法形成"技术对策—风险"对应关系：

- 应对**仓单重复质押与空单质押**：RFID、电子围栏、远程视频可对同一批库存货物实施唯一化、实时化监测；
- 应对**一女多嫁重复抵押融资**：区块链存证配合第一手原始交易信息的直接获取（交易信息可得原则），可压缩同一债权重复融资的操作空间；
- 应对虚假交易与虚构融资：卫星定位与物流监测使"货物流"可验证，补齐"三流合一"审查短板。
