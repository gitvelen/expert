# 快消品切入与高频复购建黏性策略（一号店2014口径）

## 策略逻辑

一号店拒绝垂直品类切入（垂直电商扩张遇瓶颈，顾客要全品类一站式），而以"网上超市"即快消品切入，理由有三：

1. **大众所需 + 大品牌 + 标准化** → 高转化率：平均转化率 2-3%，上海超 10%，同等流量效率大幅提高。
2. **高频重复购买** → 建立顾客黏性与信任依赖：食品、饮料、洗发水等快消天然高频，与电脑、手机等低频品类形成对比。
3. **迎难而上建立壁垒**：超市商品大、重、易漏、易损、有保质期，履约难度高，恰好围绕仓储配送建立供应链核心竞争力。

## 品类扩张路径

上线时 3 千多个品类 → 2014 年 170 多万 SKU（文末另有 1700 万表述，疑笔误）；快消占比从早期约 70-80% 降至 30% 多，扩展至服装、珠宝、箱包等。

## 口径标注

转化率与占比数据均为当事人 2014 年自述，无外部核验；引用须注明口径来源。
