# 应收账款证券化产品特点与风险特征框架（2016中债资信口径）

## 基础资产六大特点

1. **期限较短**：国外一般半年以内；
2. **无利息收入**：赊销形成的宽限期债权，债务人无需付息；
3. **可能价值摊薄（Dilution）**：非信用事件导致的应收账款减少，如贷项通知单（清单错误、质量问题）、价格折扣、数量折扣、定价优惠，严重时可直接减至零；
4. **通常无抵质押担保**：纯粹以商业信用为担保；
5. **同质性不高**：与业务类型密切相关（大企业间金额大、对下游小企业金额小）；
6. **入池资产数量灵活**：可按金额大小灵活选择（公共事业小额多笔 vs 大企业大额少笔）。

## 交易结构四大特点

1. **回收不能与发起人完全隔离**：应收账款产生与回收依赖发起人持续经营能力；
2. **发起人数量灵活**：单一（结构简单）或集团多主体联合（降低发行成本）；
3. **多采用循环结构**：支持长期证券发行；
4. **一般设有准备金账户**：覆盖无利息收入下的费用与利息支出。

## 风险特征与对应缓释

| 风险特征 | 缓释措施 |
|---|---|
| 发起人信用/经营风险暴露 | 组织与服务政策的陈述与保证；**证券优先级别上限一般不超过发起人主体级别**（充分分析后可适度上调） |
| 循环结构不确定性大 | 严格循环期合格标准、信用事件触发提前摊还机制 |
| 无利息收入的流动性风险 | 准备金账户（静态/动态增级） |
| 无担保的信用风险 | 外部保证（高信用担保公司、母公司不可撤销担保）或超额抵押 |
| 同质性不高、表现波动大 | 严格入池标准（4–5 年历史数据、债务人分散） |
| 摊薄风险 | 第三方流动性保证、超额抵押、现金抵押、准备金账户 |

## 与其他产品的区分

应收账款证券化兼具资产支持型（依赖资产自身回收）与财务报表型（依赖发起人持续经营）的双重特征——回收不能完全隔离发起人意味着它并非纯粹的主体信用替代，与 [[concepts/ABL资产支持型贷款与财务报表型融资二分法]] 中的二分法形成有价值的对照。

## 时效标注

全部为 2016 年中债资信口径。
