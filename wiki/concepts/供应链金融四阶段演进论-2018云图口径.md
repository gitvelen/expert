# 供应链金融四阶段演进论（2018 云图口径）

出自 2018 年公众号综述（云图金融转述口径），将供应链金融演进划分为四个阶段：

## 1. "1+N"时代（1.0）

"1"为核心企业，"N"为其上下游企业。银行通过把控核心企业批量开发上下游，依托核心企业信用外溢、以真实贸易为支撑重塑传统信用评价体系。本质是商业银行为主导，方式以保理、库存融资为主。

## 2. 虚拟化时代

线下业务线上化：供应链成员自发利用互联网与 IT 技术对物流、信息流、资金流进行虚拟化，利益链条与 1.0 无本质区别，但信息整合提高效率并衍生综合服务需求。案例：[[entities/橙e网]]、宝钢 2014 年钢铁现货电商平台、汉得信息转型、[[entities/怡亚通]]。

## 3. 平台与跨界时代

在单个行业/部门供应链基础上建立互联网+物联网结合的广义金融平台，分四大平台：供应链运营平台、信息化工作平台、供应链金融服务平台、风险管理平台。案例：[[entities/创捷供应链]]（信息化工作平台）、[[entities/UPS资本]]（物流商跨界金融）。

## 4. 产融结合的生态系统（供应链金融 4.0）

将工业 4.0、商业 4.0、农业 4.0 有机结合的跨条线、跨部门、跨区域金融生态平台，基于云计算与大数据创建金融生态系，实现产业跨界融合与产金回路。

## 与其他分期论述的关系

该四阶段论为 2018 年多家分期论述之一，可与储雪俭、中金、前瞻等口径并列对比，比较各家对“去核心化”“数据信用”阶段的划分差异。
