# 交易银行网关（2017文沥口径）

交易银行网关是王志修（[[文沥WelinkData]]）在 2017 年提出的新一代银企直连工具概念：有别于传统银企直连偏重收付款指令，交易银行网关可掌握**订单、收发货、对账、发票、结算支付**等全供应链环节的贸易数据，并支持数据类与 API 接口类处理，实现数据自动采集、传输与转换，对接银行的贸金、供应链金融、信贷、网银系统。

## 配套技术

- 安全传输采用国际协议 **AS2**（Applicability Statement 2），以数字证书加密解决点对点传输的身份验证、消息完整性、保密性与隐私问题。

## 数据获取成熟度三阶段模型

1. **人工阶段**：核心企业按约定频率/格式以邮件上传文档（经销商/供应商主档、订单、退货、应付账款等）。
2. **FTP 阶段**：ERP 定时转出数据，经 FTP 自动发送至金融机构后台，但仍需人工加工汇总。
3. **网关阶段**：交易银行网关实现全面自动化采集与业务流程集成。

## 证据强度与后续核验

- 属专业公众号分析层级（厂商方法论主张）；文中宣称"部分领先的全国股份制商业银行已实际落地"，但**未具名、无量化效果**。
- 2017 年口径，落地与后续演进情况待核验：见 [[queries/查询-交易银行网关2017年落地银行与后续发展状况]]。
- 与同期的区块链路线（[[区块链供应链金融平台模式-2017口径]]）是 2017 年数字化供应链金融的两条不同路径。
