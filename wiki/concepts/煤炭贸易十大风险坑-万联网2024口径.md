# 煤炭贸易十大风险坑（万联网2024口径）

煤炭贸易品类的欺诈与风险类型学清单，来自万联网 2024-11-04 匿名"煤老炮"经验口径（见 [[4-news--7-03-行业研究--4-2024--26-煤炭贸易最容易踩到的10大坑一位煤老炮的血泪史-趋势--1rrn8ze]]）。风险集中在三大类：**货物真实性**（质级掺杂、调包）、**货权与物流控制**（途中换煤、司机环节）、**交易对手信用**（扣款、拖欠、居间与合伙卷款），与知识库工作论点"贸易背景真实性 + 货权控制力"一致。

## 十坑清单

| 坑名 | 手法 | 风险类别 |
|------|------|----------|
| 瞒天过海 | 高硫充低硫、电煤当喷吹煤、矸石顶炭块 | 货物质级造假 |
| 暗度陈仓 | 表优里劣"包饺子"式夹心掺杂 | 货物质级造假 |
| 偷梁换柱 | 所见之货与所收之货不符、劣换优 | 货物调包/货权 |
| 混水摸鱼 | 司机途中进小煤场换煤、卖煤 | 物流控制 |
| 上屋抽梯 | 业务员跳槽带走客户 | 人员依附 |
| 无中生有 | 货与指标合规仍恶意压卡扣款 | 对手方信用 |
| 趁火打劫 | 货到付款变拖延、账期被动拉长 | 账期/应收风险 |
| 声东击西 | 装车打款发货流程正常但司机环节纠纷 | 物流控制 |
| 顺手牵羊 | 居间人收款后卷款消失 | 居间人风险 |
| 金蝉脱壳 | 合伙卖煤被诈骗、合伙人卷款跑路 | 合伙融资诈骗 |

## 与判例口径的映射（不可互相转引结论）

- "偷梁换柱"可映射到权利竞合/"一女多嫁"问题（[[权利竞合-一女多嫁四类风险-货权判例研究2024口径]]）；
- "混水摸鱼""声东击西"可映射到持续占有问题（[[持续占有问题-货权判例研究2024口径]]）；
- "金蝉脱壳"与 [[安徽华文国际经贸股份有限公司]] 融资性贸易被骗案同构；
- 整体清单是 [[4259判例货权风险11类分布与证据问题36.6]] 在煤炭品类的经验化具体化，但本清单**证据强度低于判例研究**，仅作品类风控检查表使用。

## 使用注意

- 属公众号经验口径（匿名、无数据支撑），作为煤炭品类尽调与风控检查表的**素材**，而非经核验事实；
