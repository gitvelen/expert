# 金融租赁监管指标体系（2014 第四十八条）

新《办法》第四十八条规定的七项监管指标（除特别说明外均为合并会计报表口径）：

| 指标 | 限额 |
|---|---|
| 资本充足率 | 资本净额/风险加权资产不低于银监会最低监管要求 |
| 单一客户融资集中度 | 对单一承租人全部融资租赁业务余额 ≤资本净额 30% |
| 单一集团客户融资集中度 | 对单一集团全部融资租赁业务余额 ≤资本净额 50% |
| 单一客户关联度 | 对一个关联方全部融资租赁业务余额 ≤资本净额 30% |
| 全部关联度 | 对全部关联方全部融资租赁业务余额 ≤资本净额 50% |
| 单一股东关联度 | 对单一股东及其全部关联方融资余额 ≤该股东出资额 |
| 同业拆借比例 | 同业拆入资金余额 ≤资本净额 100% |

相对 2007 年旧版新增：单一集团客户集中度（50%）与单一股东关联度（不超出资额）。

**张力**：航空、航运、轨道交通、能源等市场需求巨大的行业，集中度上限较易突破，与业务扩张导向存在冲突；特定行业经银监会认可可适当调整。本指标体系与 [[区域债务率8%红线]] 等"红线式监管"思路同构。
