# ISC 集成供应链六大模块与 IBP（普华永道 2020 口径）

## 背景问题清单（原文列举的企业管控环节挑战）

- 供应链管理模式和职责分工缺乏界定
- 产品 SKU 长尾严重
- 工厂多且定位不清
- 内部交易定价混乱
- 成本与费用控制乏力
- 年度预算与计划脱节
- 产销矛盾日益激烈
- 经营缺乏计划性统筹
- 各级分子公司业务规则五花八门

## ISC 六大模块（顶层设计）

ISC（Integrated Supply Chain，集成供应链）实施需自上而下，涵盖：

| 模块 | 内容 |
|------|------|
| A | 供应链战略与运营模式 |
| B | 组织管控 |
| C | 产品梳理 |
| D | 工厂定位 |
| E | 内部结算价 |
| F | 整合计划体系（IBP，Integrated Business Planning） |

## 实施步骤（对应 A–F）

- A：对供应链集中/分散管理模式与职责边界全局规划，明确外包与自建能力、不同渠道各产品线对供应链模式的不同需求；
- B：明确总部/区域/工厂在决策、执行、监督环节的权责界限；
- C：制定高效的产品组合；
- D：合理定位各工厂对接的产品与销售区域；
- E：对内部交易重新定价；
- F：年度预算与运营计划纵向打通、产销计划横向打通，构建从预算到预测的"端到端"业务计划体系。

**IBP** 是集成战略规划/年度预算/业务计划的核心环节，是打通端到端信息流、实现计划协同与管理的关键所在。

## 意义

该框架将供应链定位为企业经营管理的核心战略资产，影响销售增长、盈利能力、资产表现与现金流。与 [[供应链金融生态治理五维框架-宋华团队2020口径]] 互补：ISC 从企业管理视角做体系化设计，宋华框架从生态治理视角展开。

证据强度：专业机构方法论观点（2020 年口径），无案例实证。
