# 统计性工具书编辑体例规范（供应链金融年鉴2023口径）

来源：《中国供应链金融年鉴（2023）》编辑要求原文（2024 年口径）。

## 核心原则

年鉴作为统计性、资料性工具书，必须**客观平实、数字优先、排除评价性语言**（禁用"意义重大""全国前列"等），这与本知识库"证据分层、结论可溯源、统计数值标注年份"的原则同源。

## 关键口径约定

| 维度 | 规范要点 |
|------|----------|
| 名称 | 首现用全称，复现用规范简称，前后一致；人名直书 |
| 时间 | 禁用"今年""目前""至今"等模糊表述，必须写明具体年月日（阿拉伯数字） |
| 数字 | 统一阿拉伯数字；小数保留 2 位；5 位以上用"万"、9 位以上用"亿"；同类目单位一致 |
| 范围 | 浪纹号"～"，前后均加单位："10％～20％"、"250 万元～300 万元" |
| 倍数 | "倍"只用于增长/提高/扩大，不用于减少/降低/缩小 |
| 量词 | 企业统一用"家" |
| 文号 | 年份用六角括号，如"国发〔2018〕37 号" |
| 图表 | 编号引用；图表与正文数据一致；分项之和等于合计 |

## 表格数据语义约定（重点）

| 表格状态 | 语义 |
|----------|------|
| 空（无任何数字及符号） | 不适用，无此数据 |
| "-" | 数据无法获得 |
| "0" | 有数据，数值为 0 |
| "0.00" | 有数据但值极小，四舍五入后为 0.00 |

## 对知识库的实操价值

1. **"逾期率为 0"类口径考证**：解读统计快照时须区分"数值为 0"与"数据缺失/无法获得"——将"-"或空误读为"0"是常见错误，参见 [[queries/查询-九江银行全产业链数字化服务逾期率为0口径考证]] 的同类问题。
2. **finding 页统计快照制作**：小数统一 2 位、范围用"～"且前后加单位、企业用"家"、文号用六角括号、每个数值标注统计年份。
3. **旧口径处理**：本页为 2023 卷编辑要求口径；若后续年份年鉴发布新体例要求，旧口径保留于此并标注被取代。
