# 票据介入供应链三阶段：1.0/2.0/3.0（2020 九银票据研究院口径）

[[江西财经大学九银票据研究院]]（2020）提出的票据介入供应链金融的分期口径：

| 阶段 | 结构 | 特征 |
|---|---|---|
| 1.0 | "1+N" | 依托核心企业授信，上下游与核心企业赊销赊购，票据发挥支付结算作用；多为线下，效率低、信息不对称 |
| 2.0 | 网络化 | 四流经互联网传递，不再局限于一条产业链，形成以核心企业为中心的网络；任一节点可形成票据池融资 |
| 3.0 | "N+1+N" | "1"不再是核心企业而是供应链服务平台，网状平台提高效率、实现批量授信 |

基础设施支撑：[[上海票据交易所]]与 ECDS 系统使票据背书、交易全程留痕，便于追查信用主体。
