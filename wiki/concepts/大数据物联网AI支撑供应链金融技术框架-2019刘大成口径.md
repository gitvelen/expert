# 大数据+物联网+AI 支撑供应链金融技术框架（2019 刘大成口径）

刘大成（2019）提出的供应链金融技术支撑框架，旨在解决核心企业信用确认、动产质权与信用质押真实性验证、产业封闭供应链环境形成三大问题。

## 四层技术分工

| 技术 | 功能 |
|------|------|
| 第三方大数据 + 云服务 | 受安全保护且可共享，形成穿透全供应链真实信息的**征信信用平台** |
| 物联网 | 精准控制全链资源的**实时监控**与自动匹配，支撑闭环供应链万物互联 |
| 人工智能 | 资金闭环中低成本、高效率实现**机器授信与智慧风控** |
| 5G + 边缘计算（MEC） | 2019 年起赋能更快连接与更实时通信，带动数据高质量、高安全性、高交互性 |

## 征信分化判断

- B2B/B2C 头部电商可凭平台真实交易流水自建企业与个人信用评价体系，已实现头部电商物流企业的供应链金融创新。
- 广大中小微物流企业受益甚微，须依赖**不直接涉及投资企业受益的第三方大数据模式**做强征信与风控。

## 关联与对比

- 第三方大数据征信路径与 [[文沥信用分多源数据信用评估-2018口径]] 一致。
- 物联网实时监控与闭环控制思路，与 [[动产融资监管模式三阶段-2019高达口径]] 的 2.0/3.0 物联网仓库/监管仓阶段相互印证。
- 可作为 [[区块链万能论与工具属性论对比]] 的替代性技术框架素材：本文主张以大数据/物联网/AI 而非区块链为主轴解决供应链金融风控问题。
