# 生态圈金融三要素与供应链金融3.0四大趋势（沈亦文2020口径）

## 生态圈金融发展方向（三要素）

产业互联网时代，生态圈金融（含供应链金融）的发展方向：

**核心企业信用价值 + 互联网金融科技 + 多元化资本市场**

## 供应链金融3.0四大趋势（2020年判断）

1. 核心企业自金融和产融结合趋势；
2. 产业互联和生态开放趋势；
3. 全球产业链布局和内外资金联动趋势；
4. 资本市场直融取代传统银行信贷趋势。
