# 长江云链 SaaS 定制化供应链金融平台招标（2024口径）

2024年招投标信息显示，湖北又一省属国企（长江产业集团体系）启动供应链金融平台建设，反映供应链金融平台在省级国企间的扩散趋势。

## 招标要点

| 项目 | 内容 |
|------|------|
| 项目名称 | "长江云链"定制化供应链金融平台系统开发项目 |
| 招标方式 | 比选招标，开标时间 2024-07-05 |
| 牵头方 | 湖北长江产业载体运营管理有限公司（[[长江产业集团]] 全资子公司），负责建设与运营 |
| 技术要求 | SaaS 部署方式定制化开发：专属平台名称、专属域名、专属门户界面、专属 LOGO |
| 业务要求 | 与各商业银行系统对接，支持供应链金融业务线上操作，维护平台稳定运行 |

## 与知识库的关联

"白标式 SaaS 定制 + 银行系统对接"是省属国企自建供应链金融平台的典型技术路线，与湖北联投资本"省地共建"（[[供应链金融省地共建模式与一地一链一县一品-联投资本2024口径]]）等模式并列，是关键问题5"不同主体商业模式与风险结构"的重要观察点。中标结果与平台上线情况待跟踪。
