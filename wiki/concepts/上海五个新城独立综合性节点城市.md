# 上海五个新城独立综合性节点城市

上海对嘉定、青浦、松江、奉贤、南汇五个新城的总体定位：区别于传统郊区卫星城，强调"独立"的综合功能，使其成为承担国家战略、服务构建新发展格局、参与国际合作与竞争的重要载体。

## 五新城主导产业品牌矩阵

| 新城 | 主导产业品牌 |
|---|---|
| 嘉定新城 | 国际汽车智慧城 |
| 青浦新城 | 长三角数字干线 |
| 松江新城 | 长三角G60科创走廊 |
| 奉贤新城 | 东方美谷 |
| 南汇新城 | 数联智造 |

## 功能集聚方向

四个功能导入方向（[[关于推动向新城导入功能的实施方案]]）：企业总部、研发创新、要素平台、公共服务。

## 与其他政策的关联

- 松江 G60 科创走廊与 [[上海市推动制造业高质量发展三年行动计划2023-2025]]、[[长三角产业科技金融高水平循环试点]] 同属上海产业政策空间布局脉络。
- 南汇新城依托临港新片区制度优势；临港亦为 [[上海未来产业先导区]] 之一。
- 与 [[上海2+3+6+4+5现代化产业体系]] 互为空间与产业维度补充。
