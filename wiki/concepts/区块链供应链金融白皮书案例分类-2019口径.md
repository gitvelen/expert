# 区块链供应链金融白皮书案例分类（2019 口径）

2019 年可信区块链推进计划白皮书对落地区块链供应链金融案例的分类：

- **应收/应付账款融资类**：腾讯金融科技、布比、联动优势、航天信息、宜信；
- **应收/应付 + 实物融资类**：易见天树、泛融、点融。

四个代表案例：微企链（资产网关上链 + 多签名 + UTXO 映射 + 财付通清算 + 过桥基金秒级放款）；航天信息发票融资；联动优势跨境保理；贵阳银行跨域合作。案例均为自述口径，证据强度弱-中。
