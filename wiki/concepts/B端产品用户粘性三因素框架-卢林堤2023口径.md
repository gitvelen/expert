# B端产品用户粘性三因素框架（卢林堤2023口径）

卢林堤（2023）提出：与 C 端依赖市场份额与网络效应不同，B 端产品粘性取决于三因素——

1. **价值吸引力**：产品能否帮企业赚钱或省钱、简化流程、降本增效。
2. **系统迁移成本**：新旧系统更换难度——与内部多系统已打通的连通性、以及复杂历史数据的迁移代价。
3. **学习成本**：新产品上线对多部门操作员乃至高层的再学习成本（人员层面迁移成本）。

## 配套判断："份额 ≠ 粘性"

B 端用户（N 家企业）之间难建立有效互动，难产生 C 端式网络规模效应；"抢占市场份额"只能作为前期"攻城略地"策略，不能作为主要运营手段。B 端产品须围绕"能给企业带来什么价值""与企业的业务绑定有多深"打造。

对供应链金融平台设计的参考意义：平台粘性应建立在深度业务绑定与价值创造上，而非注册企业数量指标。属作者观点口径（中等强度）。
