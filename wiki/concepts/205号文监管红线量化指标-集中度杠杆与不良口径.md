# 205号文监管红线量化指标：集中度、杠杆与不良口径

[[关于加强商业保理企业监督管理的通知205号文|205号文]]（2019年10月，银保监会办公厅）首次为商业保理企业设定全国统一的量化监管指标：

## 五项核心监管要求（原文口径）

| 指标 | 要求 |
|---|---|
| 单一债务人集中度 | 受让同一债务人的应收账款，不得超过风险资产总额的 **50%** |
| 关联债务人集中度 | 受让以关联企业为债务人的应收账款，不得超过风险资产总额的 **40%** |
| 不良口径 | 逾期 **90天** 未收回或未实现的保理融资款纳入不良资产管理 |
| 风险准备金 | 计提的风险准备金不得低于融资保理业务期末余额的 **1%** |
| 杠杆上限 | 风险资产不得超过净资产的 **10倍** |

另附报告事项：单笔超过净资产5%的重大关联交易、10%的重大债务、20%的或有负债、10%的重大损失或赔偿责任、重大待决诉讼仲裁，均须在发生后10个工作日内报告金融监管局。

## 2019年注解口径下的市场影响（观点，非原文）

- **40%关联红线**：冲击央国企/上市公司集团内部反向保理规模（体系内公司做债务人的模式受限），防止集团内保理公司沦为股东融资工具或通道，倒逼开拓外部资产；对依赖少数大核心企业的供应链ABS（尤其地产类）影响较大。市场讨论出现“表外代持、机构间互持分散集中度”的灰色操作空间。
- **90天纳入不良**：被注解认为不分类、一刀切，与实际操作流程不符。
- **风险资产定义未明确**：205号文未规定计算方法；此前天津市口径为“风险资产=总资产−现金−银行存款−国债”，是否全国适用待明确（见 [[查询-205号文再保理与同业拆借禁止的边界如何明确]] 及相关开放问题）。
- **考核时点无定论**：集中度按月末/季末/任意时点考核未明确，注解认为特定时点考核几率更大，存在“鼓肚子”空间。

## 融资渠道边界

- 禁止：吸收存款；通过 P2P、地方各类交易场所（金交所）、资产管理机构、私募基金融入资金；与其他商业保理企业拆借或变相拆借；放贷或受托放贷；专门催收/讨债；基于不合法基础交易、寄售合同、权属不清应收账款、票据及其他有价证券付款请求权开展保理融资（与2016年《中国银行业保理业务规范》及交易所ABS挂牌指南口径一致）。
- 允许：向银保监会监管的银行和非银行金融机构融资，以及股东借款、发行债券、再保理。**再保理与拆借禁止之间的边界**是注解提出的开放问题。
