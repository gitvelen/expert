# 煤炭贸易价格术语体系：坑口到港口价格链（2024万联网口径）

煤炭贸易的价格术语按货物所处的物流节点依次叠加费用，形成一条"坑口 → 站台/码头 → 港口装船 → 目的地"的价格链。理解这条链是核算煤炭供应链金融货值、费用结构与质押率的基础。本口径来自 2024 年万联网科普文（专业公众号分析层级）。

## 价格链示意

```
坑口价（裸价，无加工/运输费）
  + 短途汽运 + 站台税费 + 铁路计划费 + 税费
= 车板价 / 船板价（装上车/船、发运前除干线运费外的一切费用；分含税/不含税）
  + 港杂费（卸车、堆存、装船，国内各港约 15-20 元/吨）
= 平仓价（港口装船后，卖方不付海运费）
  + 海运费 + 途中费用
= 到站价（交货地火车站交货）/ 到库价（到达指定仓库）
```

- **CIF / FOB**：国际贸易视角的对照。FOB（离岸价）以货物越过船舷为界，装船前费用风险归卖方，此后归买方；CIF（到岸价）由卖方承担至目的港的运费与保险（原文解释残缺，此处为通行含义补正）。
- **场地价**：某堆放场地交货价，一般不含税。
- **包干价**：运至用户指定地点的一口价，分含税/不含税（取决于买方是否需要发票）。

## 重要勘误与口径提示

- 文中两处按 **17%** 增值税率举例（"不含税价 100、含税价 117"）。17% 为旧税率，**2019 年 4 月起煤炭销售适用税率为 13%**，采信时应予修正。
- 原文第 10/13 条对"含税车板价"定义重复；"车板含税价"与"含税车板价"实为同一概念的不同表述。
- 原文第 7 条 CIF 解释明显残缺口语化，不能照录为权威定义。

## 风控意义

- 价格链各节点的费用构成（港杂费、铁路计划费、运费）是核验贸易背景真实性与费用合理性的对照基准。
- 含税/不含税、一票/两票口径直接影响开票金额与发票流，详见 [[一票制与两票制-煤炭贸易发票口径]]。
