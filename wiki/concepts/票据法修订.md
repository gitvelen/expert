# 票据法修订

《票据法》自1996年施行以来，仅2004年做过小幅修改，面对票据实务与司法实践的发展，滞后性日渐凸显。

## 修订时间线

| 时间 | 事件 |
|---|---|
| 1996年 | 《票据法》施行 |
| 2004年 | 小幅修改，此后未大改 |
| 2010—2012年 | 首次尝试研究推动修法 |
| 2016年 | 票交所成立时期再次尝试推动修法 |
| 2022年10月 | 时任央行行长易纲在全国人大常委会作金融工作报告，提出加快修订票据法等基础性法律 |
| 2023年2月 | 央行[[2023年金融市场工作会议]]明确"推动修订票据法" |

## 修法动因（媒体评论，证据强度中等偏弱）

1. 法律滞后于票据实务与司法实践（官方与媒体共识较强）。
2. 票据市场风险事件频发，[[融资性票据]]重大隐患被放大，宝塔等恶性票据事件成为最高法2020年最忙碌的案件之一，最高法为此出台票据法修改判罚的解释。
3. 电票、票交所、[[供应链票据]]等基础设施已成熟，为修法提供条件。
4. 宏观层面，经济发展是法律修改的根本动因，票据作为主要支付手段与信用工具的作用日益重要。
