# 加盟制物流平台网点授信指标建模方法论（顺和同信口径）

顺和同信为加盟制零担快运平台上的小微网点建立金融画像与授信额度的一套方法论（2020 年演讲口径），是数字化风控落地细节的典型样本。

## 建模流程

1. **数据接入**：合作平台将网点的**运单明细**推送至顺和同信
2. **指标加工**：在运单明细基础上加工指标，仅围绕“订单收入”即建立十余个指标
3. **系数综合建模**：

| 系数/基数 | 含义 |
|---|---|
| 定额基数 | 授信额度的基础量 |
| 风险敞口系数 | 风险暴露调整 |
| 数据质量系数 | 依据数据完整性与质量打折 |
| 折扣系数 | 综合折扣 |
| 经营系数 | 经营状况调整 |

4. **输出**：网点的授信额度、账期、贷款利率
5. **推送**：风控结果输出给外部资金方，由金融机构出资

## 设计逻辑

网点场景的资金痛点结构：上游货主压账期，而网点在平台发货时需实时支付干支线运费——即“应收未收”与“应付即付”的错配。该建模方法论即针对此错配，以运单交易数据替代抵押担保，实现信用贷定价。

> 注意：方法论细节为顺和同信单方口径，系数的具体取值与有效性无独立验证。
