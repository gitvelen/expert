# 医疗供应链云平台模式（2017口径）

2017 年业内分析人士对医疗物资管理平台四种路线的比较判断（观点性内容，见来源页）：

| 路线 | 短板 |
|---|---|
| 医药工业/流通企业自建平台 | IT 技术储备不足，且面临监管争议 |
| HIS/HRP 系统厂商物资管理模块 | 整体功能简单，不能满足医院需求 |
| 物资管理软件本地部署 | 只有院内、缺少院外云平台，不能汇集大数据，形成数据孤岛 |
| **医疗供应链云平台公司**（如[[飞医网]]） | 被认为更具优势 |

## 纵向与横向覆盖（以飞医网为例）

- 纵向：科室计划、库房进销存、采购过程、供应商采购、临床科室消耗、财务应付款、监管部门业务。
- 横向：药品、耗材、血液试剂、办公用品等。

## 门槛与切入难点

[[京颐集团]]董事长李志："只有与医疗服务密切的机构才能真正切入医院"；医院信息化意愿（主动提效降本）与物资科管理水平参差（纯手工/半手工、账目断流）并存，构成转型需求。金融功能的可行性最终依赖平台沉淀的真实交易数据——即数据信用替代主体信用逻辑在医疗场景的早期应用。
