# 商流物流分离四类型与五好处（2019 口径）

出自唐文全 2018 年会演讲（观点性内容，非经核验事实）。

## 分离四类型

| 类型 | 时序 |
|---|---|
| 预购 | 商流在前，物流在后 |
| 赊销 | 物流在前，商流在后 |
| 大宗贸易 | 商流层进，物流直达 |
| 房产销售 | 只有商流，没有物流 |

## 分离五好处

1. 制造企业集中分销物流业务量，规模效应增强；
2. 减少物流随商流移动的迂回时间与成本；
3. 物流标准化管控，经销企业/终端客户满意度提高；
4. 制造企业直接管控 E2E 物流，市场敏感度增强、库存降低；
5. 分销企业剥离非核心物流业务、专注营销，专业分工价值最大化。

## 与供应链金融的关联

商流与物流分离意味着"货物实物流向"与"贸易合同/资金流向"可能不一致，对供应链金融的**贸易背景真实性**审核是关键考量：需借助 SEC 类数据系统与货权管控手段交叉验证（参见 [[统仓共配SEC模式-联想2019口径]]）。文中"直供替代分销是必然趋势"为 2019 年强观点口径，与现实长期并存格局不符，不作当前事实引用。
