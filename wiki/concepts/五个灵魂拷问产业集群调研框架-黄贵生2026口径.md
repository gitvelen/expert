# 五个灵魂拷问产业集群调研框架（黄贵生2026口径）

黄贵生（2026）提出的地方国企供应链公司切入本地特色产业集群前的调研框架，核心主张：拒绝"打卡式调研"（领导带队、开会座谈、拍照留念），像创业者一样深入一线；先了解顾客（集群企业），再谈服务与创造价值。

## 五个灵魂拷问

1. **调研覆盖**：调研了多少家企业？每家多久？见了哪些人？——初期至少调研集群内 10% 的企业，覆盖龙头、腰部、长尾；既见企业家/高管，也见车间负责人/采购人员；需二次回访、反复验证。
2. **意见领袖**：集群的意见领袖/知名企业家是谁？谈了多久？听懂了没？——重点问：供应链环节最浪费钱的地方、融资最难痛点、原料采购与产品销售堵点。
3. **产业链地图**：能否画出工序图、产品品类规模排序、十大核心产品、原料辅料排序？明确强链/弱链/断链环节（冠县即据此推出动产融资、预付款融资）。
4. **个体不经济但平台规模经济的事项**：单个企业做不划算的事——集采议价弱、物流成本高、融资门槛高。国企凭信用与资金优势搭平台实现集采规模化、物流集约化、融资集约化，赚取服务费/贸易差价。**这是国企切入的核心抓手。**
5. **集群共同浪费与损耗**：各企业自建仓库/自找物流导致资源浪费、采购分散无规模优势、存货积压资金无法盘活——对应共享仓储、物流整合、存货融资等服务机会。

## 配套集群调研表（8模块）

| 模块 | 核心调研要点 |
|------|------|
| 基础信息 | 集群名称、地域、主导产业、主管部门、头部企业家、行业协会、技术专家 |
| 集群概况 | 发展历史（阶段/全球全国地位）、地理物流（海铁公优势/产业集中度）、政策支持（国家级认定/税收/用地/人才补贴） |
| 产业链 | 全链图谱（上中下游+终端市场，需图示）、强链/弱链/断链、产品体系（核心产品>50%产值） |
| 生产运营 | 年产能/设备智能化水平、原料来源与痛点、用工缺口与薪资涨幅 |
| 市场销售 | 内外销比例与渠道模式、同质化/价格战/汇率/回款周期、品牌需求 |
| 技术创新 | 研发投入/发明专利/技术难题、近期与长期创新方向 |
| 企业生态 | 头部TOP10/腰部/长尾分层、服务支持（集采/金融/助贷/ERP/MES/低碳）、公共平台 |
| 金融资本 | 供应链金融规模、上市企业数、专项政策与风险对冲 |
| 挑战规划 | 同质化/融资难/数字化短板；补链/创新/扩产能重点 |

（另有附件：产业链图谱、头部企业审计报告、爆款产品清单、政策文件汇编）
