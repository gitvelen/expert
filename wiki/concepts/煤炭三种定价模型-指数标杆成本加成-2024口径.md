# 煤炭三种定价模型：指数定价、区域标杆定价、成本加成定价（2024口径）

黄贵生（2024）主张：价格指数只能作参考，供应链公司必须**根据业务所在地自建价格走势分析模型**并定期盯市。常用三种定价模型：

## 1. 指数定价法

长协使用较多。2024 最新长协定价公式（作者转述，中等证据强度）：

```
长协价 = 675 × 50% + (上月最后一期全国煤炭交易中心综合价格指数
        + 上月最后一期环渤海动力煤综合价格指数
        + 上月最后一期 CCTD 秦皇岛动力煤综合交易价格指数) / 3 × 50%
```

> 注：原文"CCTD泰皇岛"疑为"秦皇岛"笔误；675 基准价的官方出处待核验（见 [[查询-煤炭长协定价公式675基准的官方出处核验]]）。

## 2. 区域标杆定价法

- 陕西：以陕煤为区域标杆，可参考其旗下秦岭云商各期不同品类成交价
- 下游：参考电力集团每月公开招标的成交价
- 中转地：指数价格参考性较高

## 3. 成本加成定价法

按业务所在地核算，重点监控坑口价与运费：

```
终端下游场地价格 = 坑口价 + 汽运费 + 站台费用 + 港口费用 + 海运费
                + 资金成本 + 质检费 + 保险费 + 税费 + 利润 + 时间成本 + ...
```

港口、站台费用变动不大；主要变动因素为坑口价和各类物流费用（可参考汽运、海运运价指数）。

## 影响与干扰因素

- 基本面因素：供给、需求、库存（产地/中转地/销地）、运力
- 干扰因素：安监、治超、反腐、天气、事故等
- 其他定价方式：期货关联品种参考定价等
