# 钢银场景化供应链产品矩阵（2017 口径）

2017 年钢银电商基于用户真实交易场景推出的五款供应链产品：

| 产品 | 场景指向（依命名推断） |
|------|----------------------|
| 任你花 | 应收/账期类融资 |
| 帮你采 | 代采/采购融资 |
| 随你押 | 存货质押/动态质押 |
| 为你赚 | 闲余资金增值服务 |
| 订单融 | 订单融资 |

## 意义

- 是“场景金融/数字债权凭证”在钢铁垂直领域的早期实例群
- 产品命名与后续存续情况是追踪 2017 年钢铁电商供应链金融产品兴衰的线索（见 [[queries/查询-钢银2017年持续盈利表述与后续财报表现考证]]）
