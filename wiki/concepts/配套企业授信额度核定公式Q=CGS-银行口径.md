# 配套企业授信额度核定公式 Q=C×G×S（银行口径）

基于经营循环资金周转量测算供应链配套企业（供应商/经销商）授信额度的结构化公式（2010 年前后银行培训口径，verbatim 保存）。

```
Q = C × G × S

Q：当期最高授信额度

C：经营循环资金周转量 = 应收账款平均余额 + 存货平均余额 + 预付平均余额
   + 应收票据平均余额 - 预收账款平均余额 - 应付账款平均余额 - 应付票据平均余额
   （平均余额 = 期初余额/2 + 期末余额/2；货币资金应扣除保证金）
   注：应收账款剔除一年以上及其他明显可能损失项；平均存货剔除一年以上或明显滞销存货

G：预期销售增长率系数，参考宏观经济环境、行业景气程度和客户经营业绩综合确定，
   通常取值 1.0–1.3，超过上限应充分说明理由

S：目标市场份额系数，反映银行在全部金融机构对该客户信贷业务中的目标份额，
   参考上年实际份额与本年度营销策略确定
```

管理规范、经营规模较大的经销商，授信金额可适度增加。

## 配套企业准入条件

**供应商**：①信誉较佳、履约记录良好、无违约记录；②专业化、一定规模化的生产供货能力；③与核心客户建立长期稳定的供应链关系、交易履约记录较好。

**经销商**：①所处区域市场需求旺盛、货物周转快；②信誉良好、无违约记录，销售与服务直接在核心客户支持与监督下进行；③内部管理规范、专业团队配合银行业务；④重点支持核心客户排名靠前的经销企业。

一般应由核心企业推荐，列入核心企业供应商/经销商名录的优先支持。

## 单一额度 vs 双额度管理

- 核心企业承担回购担保、连带责任担保、付款（退款）承诺或见证回购责任 → 经审批部门认定可实行**单一额度管理**：额度由核心企业授信申报银行根据协商结果及贸易特点核定，不再走一般信贷审批流程。
- 核心企业不承担上述责任 → **双额度管理**：配套企业授信仍按一般审批流程报批。
- 运行质量好、风控能力强的双额度网络可经审批机构核准转为单一额度。

## 额度占用逻辑辨析

文前段称供应商、经销商授信额度**等额占用核心客户额度**（无论核心客户是否实际提供担保）；后段的单一额度管理是另一层逻辑（协商核定、免走一般流程），两者须区分，避免混淆。

## 时效标注

（2010 年前后口径。公式原理仍具设计参考价值，但“单一额度管理下不再走一般流程”在后续监管环境下须重审。）
