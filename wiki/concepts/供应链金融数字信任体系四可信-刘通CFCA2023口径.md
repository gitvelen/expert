# 供应链金融数字信任体系与"四个可信"（刘通/CFCA 2023口径）

## 要解决的问题

供应链金融数字化发展面临的三大难题：**数据可信、信息安全、合法合规**。数字化提升了贸易、物流、仓储全链条的透明度，但要长远发展须先夯实这三项基础。

## 总体框架

综合运用金融科技手段构建数字信任体系，达成四个可信目标：

1. **主体可信**
2. **交易可信**
3. **行为可信**
4. **资产可信**

体系聚焦数据的安全与应用，整合数字证书、国密应用、电子签约、电子存证、数据治理、数据风控和大数据应用等能力，分三方面落地：

### 一、电子签约与存证（"核、签、存"全流程）

- 法律基础：《电子签名法》——可靠的电子签名等同于手写签名或盖章（法律原文口径）。
- CFCA 服务内容：个人/企业多维度实名认证、电子合同模板管理、内容审批、浏览器/APP/公众号多平台签署、数据存证；司法纠纷时出具电子签名验证报告与电子存证报告。

### 二、大数据风控（贷前/贷中/贷后三段式）

- 系统支撑：决策引擎、知识图谱、变量加工平台。
- 应用体系：数字画像、风险模型计算、企业信用评分、异动风险监控、账户在线身份认证。
- 三段式：贷前尽职审查与情报监控 → 贷中内外部数据建模智能风控 → 贷后持续监控识别风险。
- 延伸：通过隐私计算进行多方数据安全建模，辅助获客与客户画像。

### 三、数据安全治理

呼应"数据二十条"（2022年底发布）。治理模型路径：依据法律法规、监管要求、标准与行业实践 → 数据分类分级 → 数据安全风险评估 → 安全规划与整改方案 → 技术措施与平台落地 → 制度建设与培训。

## 定位与张力

- 该框架可视为"交易信用/物的信用替代主体信用"论（[[concepts/主体信用与交易信用之变-黄奇帆2022口径]]）在技术基础设施层面的落地路径。
- **注意**：此为企业演讲转述口径（2023），具产品推广性质，"四个可信"提法的独创性与业界采纳度未经验证，不应作为权威方法论直接引用。见 [[queries/查询-数字信任体系四个可信提法的业界采纳与后续考证]]。
