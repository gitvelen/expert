# 民生银行六大行业场景链式服务（2019 口径）

## 长尾覆盖四障碍（问题框架）

民生银行段开篇指出银行信贷难以覆盖供应链长尾端中小微企业的四重因素：

1. 多层级信用穿透难
2. 核心企业准入门槛高
3. 下游融资风险大
4. 跨地区辐射半径减弱

该框架与 [[concepts/多层级信用传递痛点]] 高度相关。

## 模式与组织

民生银行专门成立供应链金融事业部，以链式服务模式、线上化/网络化/可视化方式提供融资、支付结算、资金增值类产品。

## 六大行业场景（2019 口径）

1. 汽车经销商：采购融资
2. 白酒经销商：采购融资 + 资金结算方案
3. 家电经销商：订单融资和采购融资
4. 医药流通领域：流通企业应收账款解决方案
5. 大型施工企业上游中小微供应商：应收账款融资
6. 政府采购场景：供应商获取订单后的运营资金融资

配套数据：2018 年合作核心企业约85个，带动上下游近5000家（95%为民营小微），年内投放表内外信贷800余亿元（银行自报口径）。其中"医药流通应收账款"一节与既有 query [[queries/查询-民生银行乳业产业链金融后续存续]] 呼应，可作行业场景布局的旁证。
