# 链长制四机制（江西）

《江西省推动产业链链长制深入实施工作机制》（2022年3月）确立的四大运行机制：

## 一、产业链完善提升机制

1. **项目为王做大总量**：以"项目大会战"为牵引，建立重点项目建设库，实行清单化管理、立体化保障、精细化服务"三化联动"。
2. **改造提升做优存量**：分产业链组织转型升级改造诊断，"一链一策"精准改造，以智能化、高端化、绿色化、融合化、服务化为引领。
3. **精准招商做多增量**：摸排弱链、断链、缺链环节，按"高大上、链群配"要求开展补充式、填空式招商。
4. **创新驱动做强变量**：统筹基础研究、关键共性技术攻关、高能级创新平台建设、科技成果转移转化。

## 二、产业链循环畅通机制

1. **"链主"引领**：每条细分产业链遴选2-3户"链主"企业，在技术攻关、产销合作、标准制定等领域发挥牵头协调作用。
2. **企业协作**：每条产业链打造2-3个重点产业集群，促进大中小企业融通发展。
3. **产销对接**：每年分行业分领域举办约20场产供销对接活动。
4. **区域合作**：加强跨区域产业链建设合作联动、园区合作开发。

## 三、产业链要素保障机制（地/能/财/融/人）

1. **用地**：合规项目快速供地"通道"、混合产业用地政策、闲置土地二次开发。
2. **用能**："双控""双碳"衔接，增强能源消费总量管理弹性。
3. **财政**：完善贷款风险补偿、应急转贷机制和政府性融资担保体系；设立省现代产业发展升级引导基金，省市县三级联动。
4. **融资**：统筹银行、证券、保险、融资担保、融资租赁、区域性股权交易市场、商业保理、基金/风投/创投等资源，构建覆盖企业全生命周期的金融产品和服务机制，实现融资供需精准匹配。
5. **人力资源**：制定急需紧缺人才目录，健全人才引进培养与稳岗用工政策。

## 四、产业链精准服务机制

帮扶服务（重大问题协调会议、企业特派员）、咨询服务（全省产业链发展战略咨询支撑机构/"外脑"）、中介服务（行业协会、产业联盟等常态化联系）、平台服务（研发设计、检验检测、物流配送等公共服务平台）、国资服务（国有资本对接"2+6+N"行动计划）、政务服务（减环节、减时间等"六减"）。
