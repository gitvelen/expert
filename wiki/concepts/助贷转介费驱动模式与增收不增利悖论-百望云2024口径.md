# 助贷转介费驱动模式与"增收不增利"悖论（百望云2024口径）

百望云助贷业务与典型大数据金融科技公司的差异在于：**流量不掌握在自己手中**，主要依赖线下代理商转介绍客户资源（"包装后"分类推荐给金融机构），赚取推介服务费，未触及底层资产。

## 结构性数据（招股书口径，2020 / 2021 / 2022 / 2023前三季）

- 营销代理数量：172 / 299 / 511 / 516 名。
- 向代理商支付的转介费：2450万 / 6420万 / 1.54亿 / 1.65亿元，占数据驱动智能解决方案收入的 39% / 36% / 58% / 62%；占总销售成本的 15.6% / 27.0% / 49.3% / 49.5%（2022与2023前三季）/ 49.7%。
- 转介费率区间：
  - 信贷融资产品：0.46%–0.58% → 0.3%–0.69% → 0.1%–0.72% → 0.37%–0.79%
  - 贷款产品：0.07%–0.97% → 0.05%–1.18% → 0.17%–1.6% → 0.2%–1.2%
- 客户端：金融机构客户 68 / 91 / 101 / 88 名，2023年前三季户均收益305万元。

## 悖论机理

1. 竞争激烈，代理商不专属于任何单一平台，百望云须"跟上行业平均费率"以维持合作（招股书原文承认）。
2. 在助贷行业缺乏相对优势，只能以更高佣金吸引代理商，采取"低价跑量"策略。
3. 结果：营收增长（2.91→5.26亿元）伴随亏损扩大，毛利率41.4%→29.1%，四年累计净亏损超12亿元。

## 风险与脆弱性

- 现金缓冲薄（2023年9月末2.11亿元），若持续亏损或上市融资失败，现金流承压。
- 小微助贷风险叠加，高风险票贷产品甚至出现"佣金倒扣"现象（媒体口径）。
- 政策风险：若"数电票"全面推广削弱线下转介价值，该模式可能被重构。
