# 融资租赁公司授信控制指标体系（2017口径）

指 2017 年银行对融资租赁公司授信时设置的行业特色控制指标（2017 年口径，已被 2020 年《融资租赁公司监督管理暂行管理办法》部分扩展和取代，对比见 [[查询-融资租赁授信指标2017口径与2020年暂行办法现行口径对比]]）。

## 五项指标

| 指标 | 要求 | 说明 |
|---|---|---|
| 风险资产倍数 | 风险资产（总资产减非风险资产）≤ 净资产 10 倍 | 国家监控融资租赁类公司的核心指标（对应原商务部《融资租赁企业监督管理办法》口径） |
| 资产负债率 | ≤ 65% | 银行管理要求及行业惯例 |
| 单一客户融资集中度 | 对单一承租人融资余额 ≤ 资本净额 30% | 原文自述"与国家监管要求一致" |
| 集团客户关联度 | 对承租人全部关联方融资余额 ≤ 资本净额 50% | 原文自述"与国家监管要求一致" |
| 租金回收逾期率 | < 2% | 类似银行贷款不良率；公式：逾期租金所对应项目尚未归还的余额 / 融资租赁公司对外融资的全部余额 |

集中度 30%、关联度 50% 可与当时监管文件交叉验证，证据强度高于文中其他参数，详见 [[2017年银行对融资租赁公司授信参数快照-公众号转述口径]]。
