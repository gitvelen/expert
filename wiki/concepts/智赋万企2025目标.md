# “智赋万企”2025年量化目标（湖南）

《湖南省“智赋万企”行动方案（2023—2025年）》设定的工作目标：

| 指标 | 2025年目标 |
|---|---|
| 企业上云 | 70万家 |
| 企业上平台 | 4万家 |
| 规上制造业数字化网络化 | 75% |
| 工业互联网平台普及率（规模工业企业） | 50% |
| 智能制造企业 / 生产线（车间）/ 智能工位 | 1000家 / 3000条（个）/ 15000个 |
| 创新型中小企业（孵化，累计） | 约1万家 |
| 省级专精特新中小企业 | 约3500家 |
| 国家级专精特新“小巨人” | 约1000家 |
| 国家级制造业单项冠军企业（产品） | 约150个 |
| 两化融合管理体系贯标 | 1000家以上 |

## 口径提示

方案内部存在两种口径，需注意区分避免误读：
- **工作目标**：孵化“1万家左右”创新型中小企业（累计至2025年）；
- **中小企业数改工程**：每年培育“3500家左右”创新型中小企业、每年遴选500家左右省级专精特新中小企业（年度口径）。

## 保障指标

省财政每年统筹安排专项资金；数字经济年均增长15%（数字产业集聚工程）。
