# 期货保税交割与保税标准仓单质押先行先试（青岛2020口径）

文康文章梳理的政策依据链：在海关监管的保税货物范围内开展仓单质押融资先行先试，具备政策与环境基础（2020 年 3 月口径）。

## 时间线

| 时间 | 事件 |
|---|---|
| 2019-01-25 | 国务院发布《关于促进综合保税区高水平开放高质量发展的若干意见》，支持综合保税区开展铁矿石、天然橡胶等商品期货保税交割业务 |
| 2019-07-22 | 海关总署发布公告，明确经海关许可，**保税标准仓单可以质押** |
| 2019-08-05 | 上海期货交易所在青岛新设 8 家交割库，其中 7 家具保税交割资质 |
| 2019-08-26 / 08-31 | 国务院印发山东自贸区总体方案（允许拓展仓单质押融资功能、完善仓单确权）；青岛片区挂牌 |
| 2019-10-10 | 青岛证监局商请青岛海关，拟开展商品期货保税交割仓单质押融资，力争建设中国北方最大的橡胶期货保税交割中心 |
| 2019-11 / 12 | 全国首票 201.6 吨 20 号胶期货保税交割货物青岛口岸通关入库；12 月生成全国首票期货保税标准仓单，**预计 2020 年 2 月完成实物交割（预判性表述，待验证）** |
| 2019-12-30 | 青岛海关与上海期货交易所签署战略合作协议（协同推进期货保税交割、共同开展区块链课题研究等五方面） |
| 2020-01-01 | 《青岛片区金融改革创新试点实施方案》发布 |
| 2020-02-17 | 八部门印发 [[关于促进全市供应链金融发展的指导意见-青岛-2020]] |

后续落地情况见 [[查询-青岛首票期货保税标准仓单交割与北方橡胶交割中心落地情况]]。
