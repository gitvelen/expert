# 供应链协同伙伴选择方法谱系（2012口径）

供应链合作伙伴关系是供应商与顾客之间达成的长期合作战略关系；伙伴选择对供应链形成良好协同效应具有关键作用。2012 年综述《供应链协同技术与方法的发展》系统梳理了既有方法谱系，并提出一项改进方法（见 [[sources/4-news--7-04-业务基础--4-2012--18-供应链协同技术与方法的发展供应链管理--1dfldr7]]）。

## 既有方法谱系

| 方法 | 要点（文中评述） |
|---|---|
| 直观判断法 | 传统经验方法 |
| 招标法 | 传统方法 |
| 协商选择法 | 传统方法 |
| 采购成本比较法 | 以成本为比较基准 |
| ABC成本分析法 | 成本分析方法 |
| 层次分析法（AHP） | 定性与定量结合，两两比较重要性等级，可靠性高、误差小 |
| Fuzzy聚类分析 | 模糊聚类 |
| TOPSIS法 | 距理想方案尽可能近、距最不理想方案尽可能远；权重多用专家调查法/AHP 确定，主观性强 |
| 神经网络法 | 可综合处理不同类型量化数据与不同性质评价指标 |

## 改进方法：考虑指标均衡度与权重区间数

在指标**无量纲化**基础上引入两个要素：

1. **指标均衡度**：使指标间的协调和均衡程度在评价中得到反映；传统方法不能区分选择时，可利用均衡度拉开差距进行评价。
2. **权重区间数**：使模型具有较大伸缩性与柔性，符合人们的模糊认识规律，增强模型的使用范围与灵活度。

配套特点：

- **动态评价**：收集企业不同阶段（年度）数据并赋予相应权值（效用系数），反映动态评价特点。
- **数据缺失处理**：少数数据不可获得或资料不全时，可酌情放弃对不同评价阶段和个别指标的评价，增强评价结果的客观性。

## 应用价值

该谱系可复用于供应链金融产品方案设计中的核心企业、合作方准入与评价环节——尤其在多方权责设计与贸易背景真实性核验所需的伙伴筛选逻辑上具有方法论参考意义。

> 口径说明：2012 年综述转述口径，改进方法原文文献未注明出处，证据强度低；"TOPS IS"为原文排版讹误，应为 TOPSIS。
