# 银行跨组织联合风控模式（王鹏虎2019口径）

[[王鹏虎]]（2019 年口径）主张在风控体系中建立银行、电商平台、物流企业和金融科技公司的合作机制，通过合作获取多渠道数据、建立联合风控体系，并认为这种跨组织风控模式将成为**供应链金融独特的风控模式**。分工如下：

| 参与方 | 风控职能 |
|---|---|
| 电商平台 / 供应链核心企业 | 提供供应链交易数据 |
| 物流企业 | 提供物流数据与货物仓单风险管控 |
| 金融科技公司 | 提供数据分析服务 |
| 商业银行 | 核心的风险管理职责与融资服务 |

## 关联

- 该模式以"物的信用"（物流/仓单管控）与"数据信用"（交易数据）共同支撑风控，呼应本库工作论点。
- 国内实践案例（2018-2019 快照口径）：工商银行、[[中信银行]]、平安银行与核心企业电商平台合作；京东金融、怡亚通、阿里一达通基于平台数据开展融资并与银行合作获客引流与部分风控职能。
