# 供应链金融1.0至4.0发展阶段（2020 口径）

《2019 供应链金融创新发展报告》（2020）提出的中国供应链金融四阶段演进框架。起点为 1998 年深发展银行（现平安银行）在广东首创货物质押业务。

## 四阶段

| 阶段 | 名称 | 主要特征 |
|---|---|---|
| 1.0 | 传统供应链金融（“M+1+N”） | 线下作业，以核心企业为中心的 “1+N” 银行授信模式 |
| 2.0 | 线上化 | 业务流程线上迁移 |
| 3.0 | 平台化 | 平台生态整合多方主体，金融科技助推（报告判断 2019-2020 年中国处于此阶段） |
| 4.0 | 智能化 | 产业互联网时代，预见性、智能化服务模式 |

报告强调：各阶段之间无明确分界线，是行业逐步进化的过程。

## 时效性说明

（2020 年口径。）该阶段划分是当时的行业判断，后续年份的演进框架（如数据信用、产业数字金融叙事）可与之对比，引用时标注年份。
