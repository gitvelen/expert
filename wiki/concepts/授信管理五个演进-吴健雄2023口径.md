# 银行授信管理"五个演进"（吴健雄2023口径）

出处：吴健雄《产业数字金融生态下客户授信管理"五个演进"》，《中国银行业》2023年第12期（[[sources/4-news--7-03-行业研究--4-2024--36-产业数字金融生态视角下如何看产业金融的挑战和银行授信管理方式的演进-观点--fdopnp]]）。

## 五个演进

| 传统模式 | 演进方向 | 要点 |
|---|---|---|
| 核心企业风险管理 | 产业生态风险管理 | 核心企业不愿确权/回购/占用授信额度；银行自主判断生态风险，构建"事前感知-事中侦测-事后处置"全生命周期闭环（呼应 [[concepts/供应链脱核模式-央行八部门2023口径]]） |
| 主体信用审批 | 数字信用审批 | 产业特征库+同期/同类/同业阈值；模型参数+策略规则覆盖信贷全流程 |
| 借款主体"二八法则" | "八二法则" | 将80%持续稳定交易的小微客户纳入目标客群；靠场景闭环、生态限额、综合收益覆盖风险 |
| 流动资金贷款管理 | 滴灌贷款管理 | 预授信+随借随还，每次放款触发模型重检（即 KYC/KYB 数据尽调） |
| 微观调查分析 | 中观产业研究 | "强中台、简前台"，组建"行业+生态+客户"研究团队，商务经理与信贷经理分离 |

## 八二法则的四项风险控制措施

1. 将公司类授信客户发展为生态合作伙伴，做好生态限额管控，防范群体风险；
2. 选定交易场景，将信贷资源配置在交易信用良好、可形成风险闭环的环节（数字保理、数字产品池、数字政采贷等）；
3. 提高资产定价能力，以综合收益覆盖信用风险——但定价受行业毛利率/周转率约束，不能套用消费贷逻辑；
4. 借款责任个人化（企业主贷款或连带责任保证）。

## 知识库定位

五个演进可视为"结构性信任"（见 [[comparisons/文健君结构信任与储雪俭三信用体系对比]]）在银行审批端的制度化版本，是"以数据信用与物的信用替代主体信用"工作论点的银行视角展开。
