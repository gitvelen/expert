# 产融服务平台函数与"以产业为基础"红线论（文健君 2023 口径）

## 产融服务平台函数

文健君总结的产融商业模式：

> **产融服务平台 = f(战略、产业链、技术、服务、金融)**

各要素定位：

| 要素 | 定位 |
|------|------|
| 供应链金融 | 重要**获客黏性手段** |
| 供应链协同服务 | 业务**竞争手段（抓手）** |
| ABCD 等融合科技 | **技术手段** |
| 特色产业/园区、基地、集群 | **基础**（行业隐性知识、产品、流程、渠道） |
| 战略 | 商业模式即"实现战略的一套逻辑体系" |

即：以特色产业集群为基础，以现代科技为基础手段，以供应链协同服务为竞争手段，以供应链金融为获客黏性手段，最终实现产业和金融的融合。

## "以产业为基础"红线论

"产融商业模式创新一定是以产业为基础构建的，如果没有产业作为基础，纯粹空转，这样的企业出事是早晚的事情！"

正面观察：成都几大国有平台均设供应链服务板块，且一定依托特色产业、特色园区、特色基地、特色集群发展。

## 与知识库工作论点的呼应

该红线论与知识库核心工作论点"供应链金融脱离产业运行即为伪供应链金融、警惕融资性贸易"高度一致，与 [[concepts/融资性贸易]] 页互为佐证；其"三重信任/自偿性结构"表述与 [[concepts/三种信用重塑论-数字信用主体信用物的信用-宋华口径]]、[[concepts/主体信用与交易信用之变-黄奇帆2022口径]] 同属产融融合论述谱系。
