# 宜家全环节供应链控制低价战略（2012口径）

## 论点

宜家中国（零售业务）总裁吉丽安 2012 年受访口径：宜家低价的根源在于"控制了供应链的所有环节，能使每个环节都有效地降低成本"，贯穿**产品设计（造型、选材）→ OEM 厂商选择/管理 → 物流设计 → 卖场管理**全流程，而非单一环节压价。

## 各环节降本要点

1. **设计端**：设计直接决定选材、工艺、储运成本。
   - 邦格杯子：低成本色料（绿/蓝/黄/白，避开高价红色系色料）；锥形设计缩短机器加工时间；改进高度与杯把形状以高效叠放，节省运输、仓储、展示与家居空间。
   - 奥格拉椅：复合塑料替代木材；气体注入复合塑料技术（节省材料、降重、提速生产）。
   - 模块化拆装设计：模块按成本分地区生产、部分模块跨家具通用，同时降低设计成本与产品总成本。
2. **储运端**：平板包装（见 [[平板包装与顾客成本共担模式-宜家2012口径]]）。
3. **供应商端**：销量驱动的"正循环"与信息系统改造（见 [[供应商正循环与信息系统改造-宜家2012口径]]）。
4. **顾客端**：顾客自提自装的成本共担（见 [[平板包装与顾客成本共担模式-宜家2012口径]]）。

## 内部张力

宜家主打低价，但其品牌资产调查显示 56% 中国顾客不认为宜家所有产品都是低价的——"低价能力"与"消费者低价感知"存在落差，宜家以本地化研发与持续降价应对（2012 年口径）。

## 产业意义

与 [[供应链成本管理三阶段演进-2012口径]] 中"价值增值链/网络联盟"阶段互证：将供应链控制能力作为成本与竞争优势的来源，而非依赖单体环节议价。对供应链金融而言，这是"以供应链真实运作能力构建竞争力"的产业本位典型案例。
