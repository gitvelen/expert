# 六大重点领域供应链框架（上海《实施意见》）

沪府办发〔2018〕26号以六大重点领域 + 一个支撑体系组织任务，呼应国办发〔2017〕84号文的国家框架：

| 领域 | 核心抓手 |
|---|---|
| 制造供应链 | 工业互联网平台、协同制造、服务型制造、中小企业上云上平台 |
| 流通供应链 | 数字商务、智慧流通网络、单元化物流（整托下单、带板运输、信任交接；"三次不倒筐"） |
| 农业供应链 | 农业产业化联合体、种源农业、全链条质量追溯 |
| 供应链金融 | 服务平台与线上应收账款融资；双评级与真实交易风控（见 [[供应链金融双评级风控与真实交易要求]]） |
| 绿色供应链 | 绿色伙伴式供应商管理、绿色信息管理平台、两网融合 |
| 全球供应链 | 一带一路桥头堡八大功能性平台、"6天+365天"常年展示交易平台 |
| 支撑体系 | 供应链政府治理与公共服务（信用评价、标准体系、政策环境） |

## 特点

- **长三角一体化**为贯穿线索：示范平台、农产品配送、进口集散地均辐射长三角。
- 区别于郑州试点的物流标准化切入（见 [[concepts/供应链体系建设首批试点城市]]），上海以全球资源配置中心定位切入。
