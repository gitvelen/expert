# "双过程—主动"供应链金融风控体系（2020 口径）

"双过程—主动"风控体系是 2020 年中国储运观点文章在"四三三"逻辑之上提出的风控框架：基于供应链融资行为，通过供应链中的**有形与无形过程控制**（"双过程"），使风控从被动向**主动**转变——根据四流变化及趋势，由风控模型主动开展基于真实贸易的风险预警、风险转化、风险反思与风险处置。

## 核心内容（四组结合）

1. **风控对象**：有形货物控制 + 无形的信息过程管控相结合。
2. **风控手段**：线下风控手段 + 线上风控相结合。
3. **风控模式**：人为经验控制 → 风控模型智能化控制转变。
4. **风控过程**：贷款全生命周期风险控制，尤其是彻底解决贷后风控难点。

## 配套落地条件（作者口径）

- 过程风险控制是供应链金融发展的基石，弥补银行主体信用强、过程风控弱的短板。
- 过程管控需依赖金融科技 ABCD（AI / Blockchain / Cloud / Data）处理海量交易与物流数据。
- 发展供应链协作平台集中四流数据（例：东莞 12 家陶瓷企业共建平台，集中采购、物流、交易结算数据为上游企业提供融资）。
- 作者形象表述："不让坏人变成坏人"——持续观察贸易流，发现问题提前预警，在金融科技支持下实现智能化风控。

## 口径警示

- "双过程—主动"为作者提法，其成效仅有自述（"已在几个项目平台试验、银行非常认可"），无具名证据。
- 平行进口车案例（匿名）佐证"有形货物控制"不足：车在可控仓库仍因政策与海关准入问题致贷款无法收回，风控须从贸易源头全链条管控。
