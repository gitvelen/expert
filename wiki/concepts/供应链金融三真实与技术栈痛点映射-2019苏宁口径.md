# 供应链金融三真实与技术栈痛点映射（2019 苏宁口径）

出自 [[entities/苏宁财富资讯]] 2019 年综述文（见 [[sources/4-news--7-05-数字科技--4-2019--20-详解金融科技如何赋能供应链金融供应链融资--7htpsf]]）。

## 融资模式归纳

供应链金融三种融资模式——买方融资、卖方融资、物流融资——可归纳为两类：

- **以票融资**：依附票据/应收凭证的融资
- **以物融资**：依附货物/存货的融资

风控四要素：**核心企业信用 + 票据真实性 + 交易真实性 + 货物真实性**。

## 四大痛点 × 技术方案映射

| 痛点 | 技术方案 |
|------|----------|
| 票据真实性 | 机器视觉、OCR、自然语言处理（票据识别、结构化提取、智能归类） |
| 交易真实性 | 爬虫、NLP、机器视觉、语音识别（双录分析）、风控模型 + 规则引擎、流媒体 |
| 货物真实性 | 物联网传感器、机器视觉、流媒体（远程视频监控）、区块链 |
| 事件可溯源防篡改 | 区块链 + 物联网（设备认证与鉴权相辅相成） |

## 配套观点

- **邮件比流水更可信论**：外贸场景中买卖双方邮件沟通协商过程可能比交易流水更能证明交易真实性——对"三真实"验证框架的有益补充，可交叉参照 [[concepts/应收账款三真实框架与虚假应收账款-2019口径]]。
- **区块链不能单独承载**：因链上文件大小限制、TPS 有限，货物监控不能仅靠区块链传输层；传感器原始数据需独立于区块链的存储方案。
- **金融科技南北向技术栈**：接入层（机器视觉、语音识别）、传输层（区块链、流媒体、低延时低抖动 QoS）、算法层（NLP、风控模型）、网络层（物联网传感器管理）。

## 评价

本框架是 2019 年对"供应链金融风控本质 + 技术手段"较清晰的结构化梳理；其"邮件更可信"论与区块链局限判断具实操价值，结语"金融科技巨头之争"叙事带有苏宁自夸语境（观点性内容）。
