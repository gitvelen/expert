# 山东港口群"一中心两翼四支撑"格局与内陆港海铁联运网络

《山东省世界级港口群建设三年行动方案》（2023）确立的区域港口一体化政策样本。

## 港口格局

- **一中心**：青岛港（国际枢纽海港）
- **两翼**：日照港、烟台港（国家主要港口）
- **四支撑**：威海港、潍坊港、东营港、滨州港（地区性重要港口）
- **外部联动**：与津冀苏辽港口紧密合作互动（落实国发〔2022〕18号）

## 陆向物流网络（2025年目标）

| 指标 | 2025年目标 |
|---|---|
| 内陆港总数 | 50个（含河南焦作、甘肃武威、重庆、新疆等布局，推进中亚物流节点） |
| 集装箱海铁联运量 | 420万标准箱（保持全国领先） |
| 中欧班列累计开行 | 超10000列（济南、青岛、临沂集结中心，齐鲁号联动） |
| 重要港区铁路进港率 | 超70% |
| 集疏运高速公路新建改建 | 620公里 |
| 外贸航线 | 278条，集装箱中转量740万标箱（占比超18%） |

## 对供应链金融的意义

多式联运与内陆港网络是大宗商品流通的基础设施，为港口场景下的仓单质押、货权管控（[[港云仓电子仓单综合服务平台]]）提供物理通道支撑；"四港联动"（海港、河港、空港、内陆港）形成货物全程可追踪的贸易背景结构。
