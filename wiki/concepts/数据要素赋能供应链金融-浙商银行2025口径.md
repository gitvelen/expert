# 数据要素赋能供应链金融（浙商银行2025口径）

[[浙商银行]]提出的供应链金融数据要素应用方法论，核心思路是通过多渠道获取信用数据强化主体识别，解决传统供应链金融的四大痛点。该案例于2025年入选[[国家数据局]]第三批"数据要素×"金融服务领域典型案例。

## 核心逻辑

围绕链上中小微企业"小额、高频、跨区域、纯信用"融资需求特点，整合多维度信用数据，强化企业主体识别，替代传统依赖抵押担保与人工尽调的路径。

## 数据维度清单

| 数据维度 | 来源类型 |
|----------|----------|
| 工商 | 政务数据 |
| 税务 | 政务数据 |
| 发票 | 政务/商业数据 |
| 水电气 | 公共事业数据 |
| 运费 | 物流数据 |
| 仓储物流 | 物流/仓储数据 |

## 四大痛点映射

| 传统痛点 | 数据维度应对 |
|----------|-------------|
| 操作流程长 | 多渠道数据直连替代人工尽调 |
| 授信审批难 | 工商/税务/发票等强化主体识别 |
| 技术对接慢 | 标准化数据接口嵌入场景 |
| 业务规模小 | 纯信用+小额高频实现规模扩展 |

## 与已有概念的关联

- 与 [[数据资产重构风险定价与价值分配机制-2025口径]]：本口径是"数据信用重构风险定价"在股份行的具体实践样本。
- 与 [[普惠型供应链数据信用贷]]：浙商银行"小额高频纯信用"属数据信用贷路径。
- 与 [[场景资产放贷与脱核不离核-享宇科技2025口径]]：路径相似性在于场景嵌入，但浙商银行更强调多维度数据整合而非单一场景资产。

## 未披露的关键信息

- 各数据维度的获取合规授权路径（特别是税务、发票等政务数据）。
- 数据整合后的风控模型架构与权重分配。
- "纯信用"融资的不良率数据。
