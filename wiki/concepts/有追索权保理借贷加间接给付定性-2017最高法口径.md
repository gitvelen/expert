# 有追索权保理"借贷+间接给付"定性（2017最高法口径）

该定性是最高人民法院在 [[2017最高法民再164号判决]] 中确立的、解释有追索权保理法律性质的理论框架：将保理商的融资拆解为借贷关系（原债务），将应收账款债权转让及其产生的求偿权理解为为清偿原债务而负担的新债务，属于间接给付（新债清偿旧债）结构。

## 定性论证链条

间接给付，指因清偿债务而以新债务替代原债务，新债务未履行时旧债务不消灭，新旧债务并存。与有追索权保理结构的对应关系：

| 间接给付要素 | 保理结构对应 |
|---|---|
| 原债务 | 债务人向保理商（出借人）偿还融资款的义务 |
| 新债务 | 债权转让后保理商取得的对次债务人的求偿权 |
| 新债未履行 | 次债务人未向保理商偿还应收账款 |
| 旧债不灭 | 保理商仍享有追索权，可要求债务人回购/反转让债权 |

## 三项推论

1. **求偿权与追索权实体共存**：新旧债务并存 → 两者可同时主张。程序上，2014年最高院管辖权裁定曾要求分案起诉（2014年口径，已被取代），现行共识为因同一事件引发、合并一诉审理。
2. **第一还款责任人**：依诚信原则债权人应先请求履行新债 → 次债务人为第一还款来源，债务人为第二顺位劣后责任人。
3. **债权转让非担保**：追索权才是对求偿权的担保，"类似放弃先诉抗辩权的一般保证"。

## 风控含义与时效

- 对保理产品设计的增信结构、确认书签署、追索权行使顺位有直接风控含义。
- **时效提示**：本定性为2018年文章阐述的2017年最高院个案口径；民法典保理合同章（第761-769条，2021年施行）已将保理合同有名化为独立有名合同，"借贷"定性不应与"名为保理实为借贷"的否定性评价混用，有名化后的存续见 [[查询-民法典保理合同章后有追索权保理借贷加间接给付定性的存续考证]]。
