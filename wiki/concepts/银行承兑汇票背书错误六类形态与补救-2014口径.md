# 银行承兑汇票背书错误六类形态与补救（2014 口径）

2014 年"贸易金融"公众号实务文章归纳的银行承兑汇票背书错误六类形态及其合规补救路径，为票据业务操作层的经验口径。**注意：电票普及后纸票背书瑕疵问题可能整体萎缩，本页为历史实务口径**（见 [[查询-电票普及后纸票背书瑕疵问题的萎缩验证]]）。

## 六类错误形态

| 错误类型 | 典型表现 |
|---|---|
| 签章错误 | 单位误盖营业用章/工程专用章/发票专用章；银行误盖财务专用章/公章/业务公章；委托收款函误盖他章 |
| 被背书人记载错误 | 被背书人写成背书人自身；简称不规范；印鉴不清 |
| 背书日期错误 | 后手日期早于前手，逻辑倒置 |
| 粘单/骑缝章错误 | 非粘单第一记载人在粘接处签章；不盖骑缝章 |
| 委托收款错误 | 多处"委托收款"字样；委托行与结算凭证不符；凭证填写不正确 |
| 背书转让给个人 | 违反《支付结算办法》第七十四条（真实交易关系、限法人或其他组织） |

## 补救路径

1. **"加盖 + 补证明"**：名称与印鉴不符时，由前后手依次出具书面证明，依法举证票据权利（《票据法》第三十三条"非经背书转让，而以其他合法方式取得票据的，依法举证"），承兑行在证据充足时应当解付；证明不足时行使追索权换票/退票。
2. **凭证错误**：委托收款行不符、凭证填写不正确等，可说明情况重新填写。
3. **个人背书**：路径一为持票人逐手行使追索权直至出票人，要求换票或退票；路径二为个人前后手达成书面协议证明背书无效，由个人前手单位委托收款。

## 实务提示

文中"承兑行应解付"为作者口径；实际银行审查尺度可能更严，补证明能否被普遍接受属开放问题。规避上述正方案而采用刻套章等民间手法的风险见 [[票据背书瑕疵民间变通操作风险-2014口径]]。
