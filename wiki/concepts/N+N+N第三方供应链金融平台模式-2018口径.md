# "N+N+N"第三方供应链金融平台模式（2018 口径）

"N+N+N"模式指"N 家银行 + N 家核心企业 + N 家上下游企业"的全线上第三方供应链金融平台模式，以中企云链为代表，是区别于产业集团自建与银行自建的第三条平台路径。

## 三种平台路径对比（2018 来源论证口径）

| 路径 | 特征 | 来源评价 |
|------|------|----------|
| 产业集团自建 | 局限于单一核心企业供应链，相对封闭 | 见下方第三方模式三点优势的反面 |
| 银行自建银企平台 | 银行有资金、支付结算及金融专业性优势，但企业加入后受其授信限制，其他金融机构无法加入 | 大企业被"绑架"在一家银行，产生巨大流动性风险，大企业不愿接受 |
| 第三方"N+N+N" | 开放、立体的产业链体系 | ① 不局限于单一核心企业供应链，具有明显的资金比较优势；② 资产丰富、风险分散，符合监管对资金端防风险、分散投资的要求；③ 规模优势，可提供综合一揽子解决方案 |

## 定位

中企云链通过整合大企业集团内部资源、供应链资源与金融资源，打破传统供应链金融封闭、单一壁垒，定位为互联网产融服务共享平台。此三方对比是回答项目关键问题 5（不同主体商业模式差异）的直接素材，但注意为 2018 年论证性内容（证据强度：中）。
