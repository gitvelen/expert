# 智慧供应链七流融合框架（2017刘大成口径）

在互联网、移动物联网、物联网与云计算、大数据、人工智能的支持下，传统供应链被塑造成具有高度**智能化、可视化、服务化**特征的智慧供应链——这是国办 84 号文"三年形成智慧供应链体系"目标的技术愿景底座。

## 七流融合

七种要素流向从传统形态向融合多重功能的网络平台转变：

| 传统流 | 转变为 |
|---|---|
| 商业流 | 销售网络 |
| 信息流 | 信息网络 |
| 资金流 | 资金网络 |
| 物流 | 物流网络 |
| 人员流 | 人员网络 |
| 制造流 | 制造网络 |
| 服务流 | 服务网络 |

融合后形成面向客户需求的全过程高效协同供应链网链结构，可实现：

1. 企业内外供应链各环节（设计、采购、生产、仓储、分拣配送、包装、销售、运输、交付、售后）的高效高质协同
2. 生产、销售、物流等不同行业的深度供应链融合与产业生态链，提高为终端客户"解难"的能力

此为 2017 年刘大成口径的表述（观点性内容）；与其他 2017 来源（如 [[供应链金融系统四层架构与四流合一-2017口径]] 的"四流合一"框架）相比口径更宽，参照使用时注意差异。
