# 金融仓储准入困境与七要点框架（中仓登口径）

指金融机构开展存货、仓单质押业务时，对仓储企业"金融仓储"职能胜任能力的准入评价问题。该框架由 [[中仓登]] 相关方于 2023 年提出（万联网观点文口径），核心主张：对金融仓储企业仅做主体信用评价远不足够，必须建立"按库准入 + 要素固化 + 动态稽核 + 按职责分类 + 黑白名单"的准入体系。

## 三条准入困境（2023 年口径）

1. **无法规门槛**：仓储行业无法规门槛与监管机制，金融机构无制度参考、无公开数据参照。
2. **无统一标准**：缺乏站在金融机构视角的统一金融仓储准入规则，只能在现行标准中拼凑。
3. **高门槛、低审查**：从业人员评估能力有限，实际操作以高门槛压缩业务空间。

## 四类风险

1. 仓库权属纠纷引发的法律风险（抵押物错误查封、变现受阻）
2. 保管能力不足引发货物损失风险（安全风险 + 质量风险）
3. 权属管理措施不当导致的权属瑕疵风险
4. 操作风险与道德风险（重复质押、一货多卖，丧失质权）

## 七条准入要点

1. 主体信用评价（必要但不足够）
2. [[按库准入-中仓登口径]]
3. 仓储基本要素固化机制（善用公共性公示平台固化仓库名称、位置、权属、实际使用企业等信息）
4. 动态稽核机制（委托行业协会/专业机构持续稽核规则执行）
5. 引入科技手段（兼顾技术投入成本与风控精度）
6. [[按职责分类评估-中仓登口径]]
7. 黑、白名单机制（与行业自律机制关联、第三方公示）

## 证据强度与使用提示

- 证据强度：弱至中等。全文为观点性论述，无案例、数据或司法判决支撑，出自利益相关方（中仓登），属"专业公众号分析/利益相关方口径"，低于监管原文与书籍。
- 该框架与历史爆雷案例共性的对应关系（重复质押、权属不清等）尚需独立来源交叉验证。
