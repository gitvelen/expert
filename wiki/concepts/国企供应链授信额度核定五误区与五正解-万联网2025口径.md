# 国企供应链授信额度核定五误区与五正解（万联网2025口径）

国企供应链公司在核定客户授信额度时的一套经验方法论框架，出自 [[sources/4-news--7-03-行业研究--4-2025--35-别让老交情坑死你国企供应链老总一声叹息授信额度到底怎么算才不被坑-观点--4i6nzo|万联网 2025-07-25 观点文章]]。核心主张：授信额度不是看交情、国资标签或同业行为，而应紧盯"**现金流 + 资产 + 舆情**"多维硬核指标，并随客户经营变化动态调整。

## 五大误区

| 误区 | 典型情形 | 关键要点 |
|------|---------|---------|
| 1. 迷信国资标签 | 僵尸国企、假央企/假国企、实际被民企操盘的国有集团三级子公司 | 光看股权结构与国资背景即授信，风险极大 |
| 2. 死磕财务数据 | 只看规模忽视经营性现金流与证据链；或因单一指标不佳一票否决 | "有含金量"的证据链（合同真实、单据对应、回款匹配）比销售规模更有说服力 |
| 3. 盲目跟随同业 | 跟风授信而不查同业授信理由与增信条件；如"有保险兜底的有追保理"风险已转出 | 同业授信只能当线索，不能当结论 |
| 4. 被增信魔术蒙蔽 | 临时借来的房产抵押、假盖章无法确权的应收账款质押 | 增信措施不能替代第一还款来源 |
| 5. 忽视软信息 | 小道消息早有但未捕捉、不实地走访、只看硬指标 | 走访、口碑、招聘点评、区域环境是防范假央国企的有效手段 |

## 五条正解

1. **深度了解真实经营**：现场走访 + 上下游沟通，掌握业务模式、市场竞争力、运营管理水平。
2. **合理分析财务数据 + 动态调整额度**：综合盈利能力、偿债能力、现金流，结合行业周期；经营改善（下游客户增多、品类扩展）可提额，行业遇冷应协商调整额度使用节奏（延长宽限期、优化还款方式）。
3. **同业授信可参考不跟随**：分析同业授信的原因与背景是否适用于自身，结合自身风险偏好决策。
4. **第一还款来源优先**：增信措施须与经营情况和资金用途紧密相关，不能替代企业自身还款能力。
5. **重视软信息**：行业口碑、招聘点评网口碑、区域经济与政策环境等的收集与分析。

## 两个典型增信造假手法

- **临时借来抵押**：企业老板为获取授信临时从朋友处借入第三方房产作抵押，抵押手续完备但第一还款来源无保障。
- **假盖章无法确权**：应收账款质押项下付款方假盖章，确权不成立，增信形同虚设。
