# 票据市场系统设施演进（1.0→3.0）

肖小和/九银票据研究院提出的票据市场基础设施三阶段框架（作者定位口径）：

- **1.0"纸电融合"**：纸质票据电子化处理融合阶段。
- **2.0"电交融合"**（作者定位）：电子商业汇票系统（ECDS）与中国票据交易系统融合，对应[[新一代票据系统]]建设。相比 1.0 的三大特点：实现"票据拆分"；优化票据托收与兑付；强化风险防控。2023 年推进新系统建设接入，工行等 20 余家机构倡议 2023-12-15 起新增电票签发转移至中国票据业务系统，并组织 ECDS 切换与数据迁移。
- **3.0"数字票据"**（作者定义：数字票据与新一代系统的融合）：系统设施的未来发展目标。数字票据作为数字金融的重要组成部分、数字货币的重要应用场景，发展方向包括：构建市场生态、做好顶层设计、强化信息披露、夯实科技赋能、以数据为核心服务实体经济、深耕中小企业、防范风险、分步有序推进。
