# 不良资产估值定价模型：评估变现率 + 五项修正参数（长城资产口径）

该模型由中国长城资产管理公司武汉办事处张洪涛、杨宏略提出（2020 年口径），针对当时不良资产定价体系的五大问题（建立在有效市场假设上、脱离处置实践、缺乏适应性、复杂权属资产主观判断过多、固定模式流于形式），以武断定价理论为基础构建"评估变现率 + 修正参数"的估值定价方法，主要用于不良债权处置参考价格的确定。

## 公式体系（原文口径）

```
公式Ⅰ：拟处置价格 = 待处置资产清算价格 × 待处置资产回收率
公式Ⅱ：待处置资产回收率 = 评估变现率 + 交易方风险偏好 + 提升系数
                        + 营销系数 + 关联信息调整系数 + 随机因子
其中：评估变现率 = 评估价格 / 待处置资产清算价格
回归式：Y = α + β1X1 + β2X2 + β3X3 + β4X4 + β5X5
```

- Y = 待处置资产回收率；α = 评估变现率（核心参数）
- X1–X5 依次为交易方风险偏好、提升系数、营销系数、关联信息调整系数、随机因子，取值范围 [−100%, +100%]
- β1–β5 为各修正参数权重，由资产公司分区域统计抽样、回归分析并验证显著性后确定
- 某参数信息缺失时其修正值取零
- 全部参数以百分比表示；采用加法结构系基于价值相加原理，可用加权平均调整

理论依据见 [[concepts/不良资产武断定价理论三因素价格框架]]。

## 操作步骤

1. **定价尽职调查**：收集评估所需资料 + 确定修正系数的信息（专家评定、实地调查、间接收集）；
2. **评估定价**：由评估部门按专业程序取得评估变现率；债权资产需尽调债务人主体情况、债务关系合法性与时效性、抵（质）押资产所有权及现状、保证合同时效性与保证人偿债能力、是否涉诉等；
3. **确定修正系数及权重**：对定性因素设等级标准评分，回归分析按相关性设权重，加权平均汇总；
4. **套用公式Ⅱ、公式Ⅰ** 计算交易价格标准，作为谈判目标价位。

## 可行性

- 数据可得：AMC 已建成涵盖资产成因、构成、现状、管理、处置的信息库；
- 专业判断：处置经验可弥补评估人员对处置业务和市场熟悉程度的不足；
- 价值发现：与市场行情、资产成长性、处置时机结合，具备价值发现功能；
- 通用性：以评估价格为核心修正调整，适用于任何形态与组合形式的资产。

## 自认局限（引用必附 caveat）

- 评估变现率源于评估价，继承评估的**时效性缺陷**；
- 提升系数、营销系数及各项信息均动态变化，动态分类管理只能部分弥补，作者自认"无法彻底解决定价和市场不能及时同步变动的问题"；
- 回归定权重自称理性量化，但五项修正参数本质多为定性判断的量化包装；
- 模型未附实证验证数据，β 权重确定依赖海量历史数据仓库，属方法框架主张而非已验证结论。
