# 供应链金融风险类型清单（2024万联网汇编口径）

本清单归并自 [[sources/4-news--7-02-产品案例--4-2024--26-近40大供应链风控实操要点做风控的你知道多少个-观点--890hig]] 的近 40 个 Q&A 要点，为该来源的风险类型框架整理，属专业公众号分析层级（观点性内容，非监管口径）。

## 风险类型归并

| 风险类型 | 要点 |
|---|---|
| 质押物选择风险 | 预付/存货模式下质押物需具备稳定性、流动性、保值性、产权明晰四特征 |
| 应收账款质量风险 | 真实性、合法性、可转让性三审；应收账款须可转让、特定、未过时效 |
| 抵质押资产风险 | 第一还款来源；价值低于信贷敞口时违约动机增大 |
| 贸易背景真实性风险 | 自偿性的根本依据；虚构交易套取资金是最根本风险 |
| 操作风险 | 信用风险向操作风险位移；内控失灵与人员操作失误；大数据系统还有技术故障/数据丢失风险 |
| 物流监管方风险 | 串通出空仓单骗贷、伪造出入库单、擅自提取处置质物、不尽职监管 |
| 质押担保物贬值与流通风险 | 仓储管理不当致丢失/变质；贬值或流动性差影响变现回收 |
| 信用风险 | 借款人不能按期还本付息；需结合征信记录、经营指标、行业预判全方位把关 |
| 供应链断裂/风险传导风险 | 核心企业信用风险沿链条向上下游扩散；与供应商股东公司经营状况多级关联 |
| 核心企业集中风险 | 核心企业是"决定风险的特异性变量"，违反风险分散原则 |
| 资金挪用风险 | 所有供应链融资最常见的风险事件（见[[风险转移与风险隔离模式]]） |

## 数据与透明度风控要点

- 四类数据来源：银行、企业及核心企业、物流运输企业、海关/工商/保险/征信平台
- 多级供应链透明度：核心企业至少监控 1、2 级供应商；大数据量化中断风险
- 去中心化融资：还款来源向下游延伸至终端消费者，分散单一主体依赖
