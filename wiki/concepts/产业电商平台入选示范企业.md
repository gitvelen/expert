# 产业电商平台入选电子商务示范企业现象

2023年商务部公布的132家电子商务示范企业名单中，除消费互联网平台外，还包含大量B2B产业电商平台，反映示范企业评价对产业数字化与供应链协同类平台的认可。

## 代表性产业电商平台（按领域）

| 领域 | 企业 |
|---|---|
| 钢铁/大宗 | 欧冶云商股份有限公司（上海）、成都积微物联电子商务有限公司（四川） |
| 物流/跨境供应链 | 浙江菜鸟供应链管理有限公司、西域智慧供应链（上海）股份公司、惠龙易通国际物流股份有限公司、广东卓志跨境电商供应链服务有限公司 |
| 产业互联网综合 | 卓尔智联集团有限公司（湖北） |
| 陶瓷产业 | 佛山众陶联供应链服务有限公司（广东） |
| 农产品/食品 | 广西泛糖科技有限公司、海南冻品云供应链科技有限公司、汇通达网络股份有限公司（江苏） |
| 再生资源 | 江西网优科技股份有限公司 |

## 与供应链金融主线的关联

上述平台中部分（如欧冶云商、卓尔智联）在行业实践中同时是供应链金融业务参与者，但**本来源未涉及任何金融内容**，不应将供应链金融属性归因于本文件。此现象仅为供应链金融研究提供产业生态背景：入选示范企业名单可作为平台合规性与行业地位的参考信号。
