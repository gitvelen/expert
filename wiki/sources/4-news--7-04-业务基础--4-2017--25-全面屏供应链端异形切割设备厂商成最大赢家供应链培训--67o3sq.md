# 全面屏供应链端：异形切割设备厂商成最大赢家（2017）

## 来源概况

- 发布：2017-10-27，来源手机报在线，经 sinotf"供应链金融"网站"04-业务基础"栏目转载。
- 主题：智能手机全面屏浪潮下，上游异形切割设备（激光 / 刀轮 / CNC 研磨）的工艺对比与竞争格局。
- **与供应链金融的关联度：接近于零**。全文无融资结构、保理、票据、存货质押、政策监管内容，属手机硬件制造工艺资讯，疑似公众号凑量转载。按知识库 Purpose 仅作"供应链行业背景知识"外围索引，低优先级收录。

## 内容要点（2017 年快照）

1. 全面屏对整机设计的约束：天线净空变小、整机跌落/抗冲击风险上升、指纹后置或被 Face ID 取代（苹果 iPhone X 以 Face ID 取消指纹识别）。
2. 异形切割的工艺必要性：屏幕四角 C 角/R 角切割防碎屏，顶部 U 型开槽为摄像头、距离传感器、受话器预留空间；关键工序为 CCD 拍照定位 + 精雕机在 0.3mm 玻璃上磨销外形、倒边精修。
3. 三种异形切割工艺（激光 / 刀轮 / CNC 研磨）的优劣对比，详见 [[异形切割三工艺对比-2017口径]]。
4. 文中判断：现阶段以激光切割为主流；业界有"CNC+激光结合成为主流"之说，但作者承认尚不好判断；异形切割核心技术当时主要由日本企业掌握。

## 值得留存的少量事实

- 华强北白牌市场全面屏出货占比在品牌厂商起量之前已超过品牌厂商（2017 年口径，一般新闻层级）。
- 苹果 iPhone X 以 Face ID 取代指纹识别（2017）。
- 夏普为异形切割（R 角/U 型槽/C 角）工艺的开创案例（2017）。

## 可信度与软文属性警示

- 证据强度：**一般新闻报道层级**（可信度分层中最低档）。
- 文中关于远洋翔瑞 CNC 设备的全部参数（双 X 双 Y 双 Z、10 万转速主轴、16 片承载、加工精度≤0.03mm、崩边≤30um、承压 110Mpa 等）均为厂商宣传口径，**未经独立验证，且通篇以该公司为正面案例，软文倾向明显**，不应固化为 finding。
- 文章软文倾向与其"CNC+激光结合为主流尚不好判断"的开放结论存在内在张力，引用时需注意。
