# 业务规模突破700亿元！湖北"联链通"破解中小企业融资难题，平均融资成本降至2.98%

**来源性质**：万联网原创报道 + 2025-10-30 武汉"2025数智供应链赋能地方产业高质量发展论坛"黄露演讲现场速记（未经嘉宾审阅，有适当删改）。属专业媒体转述的公司演讲口径，运营数据为公司自报，不可作独立验证事实引用。

## 核心运营数据快照（公司口径，2025-11）

| 指标 | 数值 |
|---|---|
| 业务资产规模 | 突破700亿元 |
| 服务链上企业 | 6300余家 |
| 累计融资 | 超200亿元（其中普惠融资超129亿元） |
| 合作金融机构 | 67家（银行、担保、保理、租赁等） |
| 覆盖产业链 | 20条（纺织服装、生物医药、电子信息、冷链物流、农业、化工等） |
| 笔均 / 户均融资 | 153万元 / 315万元 |
| 平均融资成本 | 2.98%（最低2.19%） |
| 融资方式 | 信用方式、无抵押要求（速记中另有"全额抵押"矛盾表述，见 query） |
| 不良记录 | 连续33个月"零不良" |
| 综合降本 | 5.92亿元（公司自算口径） |

## 发展历程时间线（可核验披露数据）

- 2023-01：联链通平台正式上线
- 2023-06：列入省委2023年度改革要点，成为湖北省商贸物流及大宗商品供应链金融试点平台
- 2023-12：获省委省政府1740万元奖补；获"最佳数字金融创新机构""金融服务实体经济贡献机构"两项奖
- 2024-03：发行首单供应链ABS，利率2.64%，创当时湖北省国企资产证券化发行成本新低
- 2024-10：业务资产规模破百亿
- 2024-12：获批20亿储架；发行首单省地共建ABS，利率2.5%
- 2025-01：省地共建首个地级市平台襄链通上线（首周14家核心企业、26家供应商，融资破3000万元）
- 2025-04：开启"省省共建"，与新疆博州、广西南宁合作落地
- 2025-06：接入票交所（上交所批复，湖北省首家获批供应链票据平台）
- 2025-09：签发湖北省首笔直连票交所供应链票据，单日业务规模破1亿元

## 市场空间论证（演讲口径，未注明统计出处）

- 2024年全国供应链金融市场规模超45万亿；湖北省约1.4万亿；湖北省规上工业应收账款+存货1.29万亿
- 银行解决约80%需求，剩余约20%（湖北约3000亿）为联链通定位的长尾市场
- 2024年湖北供应链票据80.6亿元，仅占全国（4367亿元）1.8%；山东近1000亿、广东/浙江超500亿
- 2025年1-9月湖北供应链及保理ABS 18.4亿元（其中联链通10.04亿），仅占全国（1334.78亿）1.38%
- 2024年湖北社融增量1.1万亿（对比江苏2.89万亿、浙江2.64万亿）；部分市县存贷比低至45%

## 平台建设思路

- **三池**：资产池（非标资产标准化金融化）、资源池（政策集成，参与《省属国有企业资产证券化工作方案》等顶层设计）、资金池（累计发行7期ABS，最低成本2.19%，盘活20多亿元；预计11月初发行新一期8.45亿元）
- **四变**：信用延伸、资产标准化（四流合一+担保增信+上交所发行）、综合金融服务（投单租保信）、政策集成
- **五化**：政策产品化→产品平台化→平台生态化→生态系统化→系统政策化；已上线11个产品、在研6个
- **四层风险共担**：业务端数据增信+履约保证金、担保端政银担分险、股权端供应链基金/共建公司、政策端贴息降低违约意愿

## 典型案例（政策产品化）

- 小药药："票据+担保"模式，融资成本由6%/年降至2%-4%/年
- 中国进出口银行首单应收账款电子凭证线上再保理：3.0%/年，助力国际经合乘用车出口阿塞拜疆、柬埔寨
- 宜都东阳光："供应链金融+集采"综合服务，产业链整体成本降3-4%
- 红安泛家居：联合福汉木业搭建"云联楚材"平台，协助出台"红安十条"，与工行及当地担保分险，引入1.5亿元普惠授信、政府贴息，综合融资成本2-2.5%，吸引金牌橱柜落户——提出"供应链招商"（见 [[concepts/供应链招商-金融优势转化为招商优势-联链通2025口径]]）

## "十五五"目标

平台规模超2000亿元；供应链票据超500亿元；ABS发行不低于300亿元（新一期50亿储架申报中）；省地共建省内地市州全覆盖、省省共建5省（累计共建业务规模超200亿元）；服务特色产业链30条、企业超2万家。
