# 储雪俭：数字化重塑产业物流+金融生态圈（观点，2020）

## 来源概况

- 体裁：观点演讲速记，万联网整理（略有删减，仅供参考），发布于 2020-10-09
- 场合：2020-09-17 万联网主办“第六届中国物流金融创新高峰论坛”（深圳），主题“推进物流数字化 助力产融一体化”，现场发布《中国物联网+供应链金融白皮书（2020）》
- 演讲人：[[entities/储雪俭]]（上海大学教授、现代物流研究中心主任）
- 证据强度：专业媒体速记，观点性内容，中等偏弱

## 核心主张

1. **科技赋能产业物流的切入点是把产业物流业务变为数据**：金融科技、物流科技、“A B C D + IoT”均服务于业务数据化；物流业务数字化产品是产业互联网发展的重要抓手。产业物流数字化需因时、因地、因人、因企演进。
2. **背景数据（2019 口径，转述）**：社会物流费用占 GDP 14.6%，运输费用约占社会物流总费用 55%（公路为大头，其后为水路、铁路、航空）；to B 端整车与大票零担高度碎片化。详见 [[findings/中国社会物流费用占GDP14.6与运输费用55占比-2019转述口径]]。
3. **SARS→消费互联网 / 新冠→产业互联网类比**：预测新冠疫情将推动产业互联网流行与 to B 端供应链物流变革（预测性判断，见 [[queries/查询-新冠疫情推动产业互联网及to-B供应链物流变革的兑现情况-2020储雪俭预测]]）。

## 分节要点

### 01 产业数字化与产业互联网
- 产业数字化循序渐进；产业物流重构是对现有企业利益的再分配（降本增效可能重组掉其他企业利益）。
- 传统供应链面临挑战：需求快速变化与不确定性、组织满足能力、预测与响应、成本与风控、贸易全球化与逆全球化及疫情冲击。
- 数字化供应链实现企业间协作与信息共享，从可视化到基于大数据与 AI 的自主认知分析与动态优化。

### 02 新基建为产业互联网按下“快进键”
- 新基建核心是信息基建（数据采集、传输、存储、计算、分析、应用、安全）。
- 路径：业务订单标准化与电子化 → 一切业务数据化 → 数据资产化 → 资产价值化。详见 [[concepts/业务数据化数据资产化资产价值化三段论-2020储雪俭口径]]。

### 03 从“O2O”到“OTO”
- 供应链金融要证明贸易真实性，需采集“货物数据、位置数据”等交易数据——这是物联网技术的由来。
- 传统物联网“物-物”串接存在断裂：营销渠道、商业角色等行为对象未被联通。解决方案是将终端客户、营销渠道、营销资源、组织成员、商业角色、服务处理等虚拟概念“对象（Object）”化，在物联网与区块链框架上建立虚实对应关系。
- 详见 [[concepts/O2O到OTO虚拟对象化与贸易真实性论证-2020储雪俭口径]]。

### 04 供应链金融从“中心化”向“智慧化”转型
- 通过物联网、区块链、AI 将物流商、金融商、制造商、贸易商、批发商整合赋能，见 [[concepts/供应链金融中心化向智慧化转型论-2020储雪俭口径]]。
- “物流是供应链金融的看门狗”：须接入物流执行数据，用数据模型分析业务风险点。
- 供应链金融业务含结算、融资、证券化三类（2020 年证券化业务发展较快：供应链物流基金、发债等）；风控重心在执行过程。
- 基础建设：订单融资、保理、形式贸易、存货融资、物流监管等的业务数据记录、流程与单证数据化。

## 数字化供应链金融物流四个关键点

1. 交易数据、物流执行数据如何被**及时采集**
2. 交易数据、物流执行数据如何**不可篡改**
3. 交易数据、物流执行数据如何**透明可视**
4. 如何**串接碎片化**的交易链与物流链数据，形成无缝衔接、可追溯的数据链

储认为解决这四个难点，才能实现“业务数据化 → 数据产品化 → 产品资产化 → 资产价值化”。

## 与既有知识库的连接

- 呼应 [[findings/动产上链瓶颈链圈共识判断-2019转述口径]]：储的物联网“货物/位置数据”采集论，正是“区块链不能自证物理真实性、动产上链需物联网成熟”判断的正面延伸。
- 与 [[concepts/核心化与去核心化模式竞争融合论-2019孟昭莉口径]] 表述接近但含义不同（智慧化强调技术整合多方，去核心化强调摆脱核心企业信用依赖），注意区分。
