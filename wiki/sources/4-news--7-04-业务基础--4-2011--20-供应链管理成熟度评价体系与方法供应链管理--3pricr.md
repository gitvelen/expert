# 供应链管理成熟度评价体系与方法（供应链管理，2011-04-03）

## 摘要

本文为一篇学术方法类文章（转自 CIO 时代，2011-04-03），主张将"供应链管理成熟度"作为供应链绩效评价体系的组成部分，从供应链管理职能（计划、组织、协调、控制，并新增创新）出发构建约 18 个指标的评价体系，并建议采用 AHP 层次分析法与模糊综合评价相结合的组合评价模型。全文不含具体企业案例或实证数据。

## 国内外研究现状（文献综述）

- Douglas M. Lambert 等（2000）：从管理结构、管理策略、管理环境三方面衡量供应链管理成熟度（另见 [[queries/查询-八大核心过程是否源自GSCF框架Lambert-Cooper核验]]）。
- PMG（2001）：将成熟度分为四阶段——关注部门职能阶段、内部整合阶段、外部整合阶段、跨企业合作阶段，并结合"供应链运作参考模型（原文写作 SCM，疑为 SCOR 之讹）"进行综合绩效评价。
- 国内：东南大学赵林度（供应链柔性与敏捷性）、同济大学霍佳震（供应链绩效评价体系）、杨军强（运营过程/管理过程/运营及管理效果三方面测评体系）、赵道致、张强、孙建勇（引入 MIcK-4FI 资源运营模式）。

## 核心框架：基于管理职能的五维指标体系

定义口径采用《物流术语》国家标准："利用计算机网络技术全面规划供应链中的商流、物流、信息流、资金流等，并进行计划、组织、协调与控制等"（与 [[供应链管理定义与主要领域-2010国标口径]] 互相印证；此"四流"口径为 [[queries/查询-供应链管理流口径四流五流与增值流的表述演变]] 提供 2011 年数据点）。

五维及代表性指标（公式照录原文，注意其中部分公式存在量纲/逻辑瑕疵，见下节）：

| 职能维度 | 指标 | 原文公式 |
|---|---|---|
| 计划 | 目标一致性（整体最优优先、人员价值取向一致度） | 人员价值取向一致度=具有一致价值取向的人数÷员工总数 |
| 计划 | 作业计划统一率 | 一致的作业计划÷供应链上的所有作业计划 |
| 计划 | 预测准确性 | 偏差较大的预测÷所有的预测 |
| 组织 | 组织变革度 | 内外环境变化周期内组织变革的次数÷周期时间 |
| 组织 | 先进技术使用率 | 某时期内使用的先进技术÷该时期内所有在用的技术 |
| 协调 | 节点间企业文化兼容性、信任度 | 专家打分 |
| 协调 | 风险分享度 | 节点间共同承担风险的次数÷发生风险的总次数 |
| 协调 | 信息准确率 | 信息正确传送次数÷信息传送总次数 |
| 协调 | 信息时效性 | 及时传送有效信息次数÷传送有效信息总次数 |
| 协调 | 信息系统先进性 | 该时段内总销售收入÷该时段内对信息系统总投入 |
| 协调 | 柔性四分：产品/时间/数量/联接柔性 | 产品柔性=新产品数量÷产品总数量；时间柔性=对顾客需求的平均响应时间；数量柔性=可满足的需求÷市场需求总量；联接柔性=1÷该时段内发生冲突的次数 |
| 控制（财务） | 成本节省度、净资产收益率 | 成本节省度=节省的成本÷总成本；净资产收益率=税后利润÷净资产×100% |
| 控制（产出） | 质量可靠性、准时交货率、客户满意度 | 质量可靠性=1÷质量问题次数；准时交货率=准时交货次数÷总交货次数；客户满意度=评分之和÷回访客户总数 |
| 控制（资源） | 资源利用率 | 合理利用的资源量÷所拥有的资源总量 |
| 创新 | 研发投入回报率、新技术采用率 | 研发回报÷研发总投入；新技术产品产值÷产品总产值 |

## 评价方法：AHP + 模糊综合评价

1. 建立目标指标评价体系；2. 用 AHP（1–9 标度法构造判断矩阵，CR<0.1 一致性检验）确定权重；3. 建立评语集 V=(优、良、中、差)；4. 专家调查法/德尔菲法确定隶属度矩阵；5. 模糊矩阵运算得各级隶属向量；6. 按赋分 Z=(10,7,5,3) 加总得分值 M，确定最终测评值。

## 可信度与瑕疵备注

- 证据强度：专业公众号转载的学术方法文章，方法论主张为主，**无实证验证数据**。
- 存疑公式：`预测准确性=偏差较大的预测÷所有预测` 实为偏差率而非准确性；`信息系统先进性=收入÷投入` 实为投入产出比而非"先进性"；`联接柔性=1÷冲突次数`、`质量可靠性=1÷质量问题次数` 为简化构造，量纲合理性弱。引用时须核对，不宜照单收入 findings。
- 原文疑为转载讹误："供应链运作参考模型"写作"SCM"，通常应为 SCOR（见 [[queries/查询-文中SCM是否为SCOR之讹]]）。
- 原文 OCR/排版错误较多（c1/CI/CR 混用、"bij=5 表示 Bi 比 Bf 明显重要"等），引用公式时需核对。
