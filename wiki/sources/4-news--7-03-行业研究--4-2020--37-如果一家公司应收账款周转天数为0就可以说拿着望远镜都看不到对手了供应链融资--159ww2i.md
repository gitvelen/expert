# 如果一家公司应收账款周转天数为0，就可以说拿着望远镜都看不到对手了

## 来源信息

公众号"供应链金融"2020-02-18 转载"马靖昊说会计"的财务分析科普短文。核心内容：用应收账款周转天数、存货周转天数、自由现金流三个指标刻画企业在产业链中的强势程度，并强调坏账/跌价准备对周转率指标的失真效应。属专业公众号财务科普/观点，非实证研究。

## 核心主张（马靖昊口径，2020）

1. **应收账款周转天数为 0 = 产业链极致强势**：营收利润良好且应收账款、应收票据均为零（款到发货），"望远镜都看不到对手"。
2. **存货周转天数 ≤ 半个月为强势企业**：产品畅销、大幅节约流动资金；举例苹果存货周转天数 5 天。
3. **减值准备会人为"美化"周转指标**：计提坏账准备/跌价准备使应收账款或存货基数缩小、周转率"虚快"，分析时须加回再计算。举例：影视企业对乐视 3000 万元应收全额计提坏账，存货受潮霉变计提 1000 万元跌价准备——指标"变好"但实质恶化。
4. **自由现金流与资金链预警**：自由现金流占营收 ≥5% 视为"印钞机"；快速扩张公司自由现金流常为负；经营现金流连续多年为负且应收账款增速超过营收增速，警惕资金链断裂风险。
5. **指标须结合产品属性**：白酒类企业（如茅台，2018 年存货周转率 0.29、2019Q3 为 0.22）存货战略决定了周转率天然偏低，此时应收账款周转率比存货周转率更重要。

## 关键公式

- 应收账款周转率 = 营业收入 /（（期初应收账款 + 期末应收账款）/2）；周转天数 = 365 / 周转率
- 存货周转率 = 营业成本 /（（期初存货 + 期末存货）/2）；周转天数 = 365 / 周转率

## 证据强度与使用注意

- 层级：专业公众号分析（科普/观点性内容），低于书籍与监管原文。
- "周转天数=0=望远镜看不到对手"是修辞性表达，不可直接作为供应链金融授信结论；应收水平取决于行业结算惯例，跨行业比较意义有限。
- 苹果 5 天、茅台 0.29/0.22 等数据仅针对该公司（公开财务常识，低证据强度），不可推广为行业基准。
- 可复用价值：减值准备失真口径对识别应收账款质量有实务价值；应收激增超营收增速可作为虚假贸易/资金链风险的辅助报表信号。
