# 基于CAS.14号收入准则的未来应收账款辨析（保理，2014）

## 概述

2014-11-04 发布于公众号“贸易金融” Factoring 栏目，署名大连银行贸易金融部周远祎。文章以《商业银行保理业务暂行办法》（银监会令[2014]5号）禁止基于未来应收账款叙做保理融资为背景，从 CAS.14 号收入准则出发，辨析企业收入确认过程中哪些“应收账款”实际构成《办法》定义的“未来应收账款”（合同项下卖方义务未履行完毕的预期应收账款），覆盖销售商品、提供劳务、让渡资产使用权三类收入，并以三张归纳表呈现约18种交易情形的判定结论。

**核心命题**：会计上“确认的应收账款”≠保理合规意义上的“合格应收账款”；判定标准是**确认时点上卖方合同义务是否履行完毕**，而非是否已入账。证据为 CAS.14/15/22 准则条文与《办法》定义的对照推演。

## 关键论点

- [[商业银行保理业务暂行办法]]（2014）将未来应收账款定义为“合同项下卖方义务未履行完毕的预期应收账款”，并明确商业银行不得据此开展保理融资。
- 销售商品收入确认五条件中，条件①②（风险报酬转移、无继续管理权/有效控制）是区分“未来/非未来”的关键。
- 劳务交易中，完工百分比法下合同订立即一次性确认收入、完工进度估计不准、成本补偿路径下超额确认，均导致部分/全部成为未来应收账款；BOT 参照 企业会计准则第15号-建造合同 + 劳务处理。
- 融资租赁“应收融资租赁款”具双重未来属性：出租人存在后续履约责任（技术咨询、保险费、维护费）时属未来应收账款；**担保余值**因属承租人/第三方履约义务且具或有事项性质，亦应认定为未来应收账款（作者较严的学理解读）。
- 经营租赁：免租期租金应在整个租赁期内直线分配，免租期前多确认的应收租金属未来应收账款。
- 边界情形：债权投资应收利息、股权投资应收股利确认时义务已履行完毕，不属未来应收账款；一次性收取使用费+后续服务的让渡使用权业务如一次性确认则属未来应收账款。

## 表1 销售商品交易判定（结构保真）

| 模式 | 判定（能否成为未来应收账款） | 关键理由 |
|---|---|---|
| 预收款销售 | 否 | 卖方不存在赊销问题 |
| 订货销售 | 否 | 一般不存在赊销问题 |
| 托收承付销售 | 否 | 收入、税费与应收账款确认同步 |
| 分期收款销售 | 否 | 确认时合同项下义务已履行完毕 |
| 交款提货方式销售 | 否 | 不存在赊销问题 |
| 视同买断方式委托代销 | 能 | 收代销清单前确认收入，风险报酬未转移 |
| 收手续费方式委托代销 | 能 | 收代销清单前确认，手续费等义务未履行完毕 |
| 含退货条款销售 | 能 | 退货义务未履行完毕 |
| 售后回购 | 否 | 属融资交易，不确认收入 |
| 售后租回 | 否 | 属融资交易，不确认收入 |
| 以旧换新 | 否 | 一般不存在赊销问题 |
| 同时销售商品和提供劳务 | 能 | 后续劳务义务未履行完毕 |

## 表2 提供劳务交易判定（结构保真）

| 项目 | 判定 | 关键理由 |
|---|---|---|
| 完工百分比法——合同订立后一次性确认 | 能 | 劳务尚未提供，义务未履行 |
| 完工百分比法——完工进度估计不准 | 能 | 未履行部分对应的应收款属未来 |
| 结果不能可靠估计——超额确认（超过已发生成本部分） | 能 | 超过已发生劳务成本部分必然属未来 |
| 同时销售商品和提供劳务 | 能 | 同表1 |
| BOT 参与公共基础设施建设 | 能 | 建造期间参照 CAS.15，运营期按劳务交易辨析 |

## 表3 让渡资产使用权判定（结构保真）

| 项目 | 判定 | 关键理由 |
|---|---|---|
| 融资租赁 | 能 | 后续履约责任存在时整体属未来；担保余值部分属或有事项，应认定 |
| 经营租赁 | 能 | 免租期前多确认的应收租金属未来 |
| 债权投资 | 否 | 确认应收利息时义务已履行完毕 |
| 股权投资 | 否 | 可行权日义务已履行 |
| 转让资产使用权（一次性使用费+后续服务） | 能 | 一次性确认时后续义务未履行完毕 |

## 证据强度与归属

- 属“专业公众号分析”层级（低于监管原文与书籍）；准则条文引用为原文口径，但各情形的具体判定属**作者专业推断**，非银监会官方解释。使用时须与《办法》原文区分。
- 判定框架归属周远祎/大连银行，不得表述为监管口径。

## 时效性提示

- 本文基于2014年旧 CAS.14；2017年新收入准则（五步法模型）与 CAS.21（2018修订）已重塑收入与租赁确认时点，旧判定框架的多数结论需重新映射（详见 [[查询-2017年新收入准则下未来应收账款判定框架的更新映射]]）。
- 正文引用“CAS.22”先称收入准则、后称租赁准则，且租赁准则在2006年口径应为 CAS.21，疑为原文讹误（详见 [[查询-文中CAS22文号归属与租赁准则版本核验]]）。
