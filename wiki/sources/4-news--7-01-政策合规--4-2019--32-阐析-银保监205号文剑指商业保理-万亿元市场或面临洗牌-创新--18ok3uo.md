# 阐析 | 银保监205号文剑指商业保理 万亿元市场或面临洗牌

## 基本信息

- 公众号：万联网（[[万联网]]）
- 日期：2019-11-01
- 原文：https://info.10000link.com/newsdetail.aspx?doc=2019110190004
- 文章来源于上海证券报、腾讯新闻

## 内容摘要

本文为银保监会《关于加强商业保理企业监督管理的通知》（银保监办发〔2019〕205号，见[[银保监办发2019年205号文]]）发布后的解读文章，并附通知全文。文章要点：

1. **更明确、更严格的风险控制**：205号文明确商业保理定义、给出5项监管指标（含10倍杠杆硬性上限）、负面清单、分类处置与统计报表报送要求，逾万家（2018年底11541家）注册商业保理企业将受到统一约束。
2. **集中度指标的冲击**（作者推断，证据强度中等）：集团公司内设保理公司仅围绕集团内部叙作业务、线上平台仅就单一核心企业应付账款叙作业务的模式，将受同一债务人50%与关联债务人40%集中度指标冲击；合规路径包括与同业合作、相互推荐优质资产、通过再保理降低集中度。
3. **风控人才短缺**（行业观察，证据较弱）：引简单汇副总裁向晓丹观点，高质量人才短缺导致风控能力不足，是保理公司踩雷的重要原因。
4. **回归本源、立足普惠金融**：205号文要求提高正向保理业务比重，重点服务产业链上下游中小企业，呼应2017年银发〔2017〕104号《小微企业应收账款融资专项行动工作方案》；转引腾讯新闻预判，基于受让小贷公司借款形成的应收账款等业务大概率被认定为偏离本源。

## 结构化数据保留

### 五项监管指标（通知第(七)条，原文照录）

```
1. 受让同一债务人的应收账款，不得超过风险资产总额的50%；
2. 受让以其关联企业为债务人的应收账款，不得超过风险资产总额的40%；
3. 将逾期90天未收回或未实现的保理融资纳入不良资产管理；
4. 计提的风险准备金，不得低于融资保理业务期末余额的1%；
5. 风险支持不得超过净资产的10倍。（原文误作"风险支持"，应为"风险资产"）
```

### 重大事项报告门槛（第(十一)条，发生后10个工作日内报告）

| 事项 | 门槛 |
|---|---|
| 重大关联交易 | 单笔金额超过净资产5% |
| 重大债务 | 单笔金额超过净资产10% |
| 或有负债 | 单笔金额超过净资产20% |
| 重大损失或赔偿责任 | 超过净资产10% |
| 重大待决诉讼、仲裁 | 无金额门槛 |

## 可靠性与张力说明

- 转载官方全文，条款证据强度高；行业数据（11541家）为媒体转述，可靠性中等。
- 文章标题"万亿元市场面临洗牌"属媒体渲染，正文未给出市场规模核算依据。
- 文章称"不得从事催收、讨债"表述不精确：官方定义第3项服务恰为"应收账款催收"，实际限制是"专门从事或受托开展与商业保理无关的催收业务、讨债业务"。
- 时间线：文中称通知"近日下发"，通知落款2019年10月22日。
