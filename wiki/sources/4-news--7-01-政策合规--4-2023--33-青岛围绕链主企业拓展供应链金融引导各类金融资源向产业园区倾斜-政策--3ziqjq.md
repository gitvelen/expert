# 青岛：围绕链主企业拓展供应链金融，引导各类金融资源向产业园区倾斜

万联网2023-04-19转载（来源：青岛市地方金融监督管理局）。核心文件为《[[青岛市金融服务新兴产业专业园区建设工作方案]]》（下称《工作方案》）。

## 要点

- 青岛高标准布局建设15个新兴产业专业园区，“一园一业”落实"5个1"机制。
- 工作目标（到2025年末）：园区"金融管家"全面覆盖；政策性、商业性银行机构每年安排不少于 **500亿元** 专项融资额度；培育十大新兴产业上市公司15家左右，百亿市值上市公司5家以上。
- 从**信贷投放、资本市场、金融科技、金融服务**四方面提出16条具体任务。

## 供应链金融核心条款（第3条：围绕链主企业拓展供应链金融）

详见 [[链主企业供应链金融-青岛条款]]。五种合作方式：

1. 融资推荐
2. 交易信息共享
3. 确认款项收付
4. 协助存货变现
5. 强化供应链金融管理

鼓励链主企业对接人民银行认可的供应链票据平台、应收账款融资服务平台（参见 [[中征应收账款融资服务平台]]）；支持链主设立小额贷款公司、商业保理、融资租赁公司。

## 其他关键机制

| 条款 | 机制 |
|---|---|
| 第2条 | “主办行+中期流动资金贷款”模式，审批材料"容缺"机制 |
| 第4条 | 园区融资企业"白名单”制度 + “整园授信”（整园建档、一次核定、随借随还、周转使用、动态调整），见 [[园区白名单制度-青岛]]、[[金融管家试点与整园授信-青岛]] |
| 第5条 | 园区企业奖补账户质押融资模式，见 [[园区奖补账户质押融资]] |
| 第8条 | 上市企业"春笋行动"，见 [[春笋行动-青岛]] |
| 第11条 | 打造“园易融”园区金融服务平台（依托"金企通"），见 [[园易融平台]] |
| 第13条 | 组建园区"金融管家"专属服务队，每周一次对接、每月一次蹲点 |
| 第16条 | 园区运营公司、链主企业债务风险常态化监测，防范非标债务风险 |

## 张力与跟踪点

- 投放激励（500亿专项额度）与债务约束（第16条控债务、防非标）之间需平衡。
- 2025年量化目标属待验证目标，见 [[查询-青岛园区金融工作方案500亿专项额度与2025目标完成情况]]。
