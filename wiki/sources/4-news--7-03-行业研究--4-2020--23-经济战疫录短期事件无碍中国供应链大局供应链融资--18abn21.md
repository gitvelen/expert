# 经济战“疫”录：短期事件无碍中国供应链大局

## 概要

2020-02-25 中国新闻网报道（中新社记者采访10位专家，文中出现9位具名观点），核心结论：疫情为短期事件，全球资本市场初期反应平淡有合理解释，中国在全球产业链的地位短期不可替代。

## 专家观点摘要

| 专家 | 机构 | 核心观点 |
|---|---|---|
| 彭支伟 | 南开大学国际经济贸易系 | 资本市场平稳基于基本面判断，2020-2021为全球经济温和回升期 |
| 东艳 | 中国社科院世经政所 | 春节淡季+库存缓冲掩盖疫情对供应链的影响 |
| 李慧勇 | 华宝基金 | “流动性盛宴”与金融传导时滞论；中国为第一大制造国、产业门类最广 |
| 谢亚轩 | 招商证券 | 韩国现代汽车因武汉周边零件采购中断股价下跌，证明中国地位 |
| 苏培科 | 对外经贸大学 | 长期停摆必伤全球 |
| 何伟文 | 人大重阳金融研究院 | 德国汽车产业受冲击；引中国英国商会97%/54%调查 |
| 贾晋京 | 人大重阳 | 产业转移重置成本论；停工超1年才有严重打击 |
| 白明 | 商务部研究院 | 产业转移决策以5-10年前景为前提 |
| 赵萍 | 中国贸促会研究院 | 全球价值链地位由综合竞争力决定 |
| 张燕生 | 中国国际经济交流中心 | “短期事件无碍大局”；贡献率超30%；当务之急是复工复产 |

## 内部张力

标题结论“无碍大局”与何伟文（德国经济受巨大冲击）、苏培科（长期停摆必伤全球）、李慧勇（传导时滞后不利影响终将体现）之间存在温和与审慎的分野——专家共识实为“短期无碍、长期取决于停工时长与复工速度”。
