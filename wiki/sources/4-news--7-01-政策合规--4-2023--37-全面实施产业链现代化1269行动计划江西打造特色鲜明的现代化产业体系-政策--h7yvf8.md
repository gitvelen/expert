# 全面实施产业链现代化"1269"行动计划，江西打造特色鲜明的现代化产业体系

## 概要

2023年11月7日，江西省政府新闻办、省工信厅、省科学院联合召开"以产业基础高级化、产业链现代化支撑江西现代化产业体系"新闻发布会。江西省工信厅党组书记、厅长应炯介绍江西推进产业基础高级化和产业链现代化工作情况，核心是全面实施产业链现代化"1269"行动计划，统筹推进传统产业改造升级、新兴产业发展壮大、未来产业抢位布局。

## 主要内容

### 一、产业基础能力和产业链竞争力研究

- **产业基础再造战略研究**：首批聚焦有色金属、电子信息、新能源、航空4大重点产业，围绕基础材料、基础零部件/元器件、基础工艺、基础软件和产业技术基础开展研究，编制产业基础再造研究报告及"一目录三清单"（详见 [[江西产业五基能力与一目录三清单]]）。
- **产业链综合竞争力调查评价**：构建以生产（制造）、市场、运营、技术四维评价指标体系（详见 [[产业链四维竞争力评价体系]]）。

### 二、产业基础再造工程

江西在全国率先出台实施产业基础再造工程行动方案。"五基"突破案例：

- 基础材料：九江德福科技高抗拉4.5微米锂电铜箔国内领先
- 基础元器件/零部件：乾照光电高均匀性LED外延与高可靠性LED芯片制备技术国内领先
- 基础工艺：LED制造工艺达国际前沿水平
- 产业技术基础：构建以企业技术中心、产业技术研究院、制造业创新中心为主体的产业技术协同创新平台体系
- 中央专项支持项目：江西佳时特数控、南昌虚拟现实研究院、赣州中科三环、睿宁科技

### 三、"1269"行动计划实施进展（截至2023年9月底）

| 指标 | 数据 |
|---|---|
| 12条产业链亿元以上项目 | 3370个（在建2869个、完工投产443个） |
| 四季度预计完工投产项目 | 1100多个 |
| 链主企业 | 初步遴选57家，一企一策培育 |
| 链长调研协调活动 | 30余次 |
| 重点任务及责任分工 | 52项 |
| 产销对接活动 | 1068场 |
| 产业链招商 | 2287场 |
| 产融对接 | 492场 |
| 人才对接 | 776场 |
| 收集产业链问题 | 1216个，办结1071个（办结率88.1%） |

链长制安排：省政府主要负责同志担任省链长制总链长，省政府其他负责同志担任各重点产业链链长（详见 [[江西链长制总链长与链主企业培育]]）。

其他配套：印发加快发展先进制造业集群实施意见、技改指导目录、《江西省产业关键共性技术发展指引》、江西省产业大脑建设指南（2023年版）；产业链发展基金建设方案初步形成，推动链主企业牵头组建锂电、光伏、半导体、铜等子产业链发展基金。
