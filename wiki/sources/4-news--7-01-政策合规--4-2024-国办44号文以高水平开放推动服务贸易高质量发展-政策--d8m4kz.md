# 国办44号文：服务贸易高水平开放（供应链相关条款摘录）

5方面20项任务。核心制度：全面实施**跨境服务贸易负面清单**（清单外境内外待遇一致，衔接 [[跨境服务贸易负面清单]]），自贸区/海南港"自上而下+自下而上"梯度开放、压力测试。呼应三中全会《决定》第24条制度型开放（[[中共中央进一步全面深化改革决定2024]]）。

## 供应链/供应链金融相关条款

| 条 | 内容 |
|---|---|
| (6) 跨境资金 | 外汇分级管理（按企业信用）；**扩大人民币在服务贸易跨境使用，支持开展人民币跨境贸易融资和再融资业务** |
| (7) 技术成果 | 知识产权证券化、科技保险；商业银行**知识产权质押、预期收益质押**融资 |
| (8) 数据跨境 | 国际互联网数据专用通道；高效便利安全的数据跨境流动机制 |
| (9) 国际运输 | **推进航运贸易数字化，扩大电子放货、电子提单在港口航运领域应用**；国际供应链一体化服务能力 |
| (11) 专业服务 | **"供应链"明列于专业服务机构国际化清单**（与金融、咨询、设计、认证认可、法律、会计等并列）——供应链服务作为可贸易服务的政策定位 |
| (13) 两业融合 | 综保区开展"**两头在外**"研发、检测、维修、文物艺术品仓储展示（保税监管模式优化）——注意与国企贸易"两头在外"禁令语境的"两头在外"是不同概念（保税业务形态vs融资性贸易界定） |
| (18) 政策支持 | 贸易金融、股权投资多元化工具；出口信保扩大服务贸易覆盖面、优化中小企业承保；服务出口增值税零税率 |
| (20) 区域合作 | 京津冀/长三角/大湾区/成渝区域性公共平台、服务贸易标杆城市 |

## 对照分析

- **电子提单/电子放货**入国家文件（第9条）——与2026年"首部电子单证应用新规"（todo 待入编）构成"应用推广→单证立法"的演进线
- 供应链服务国际化（第11条）为本 wiki"供应链服务出口"议题的首个国办级依据；与新能源汽车意见的境内外供金（第8条）共同构成"服务+货物"贸易的金融支撑组合
- 人民币跨境贸易融资**和再融资**的表述较罕见（再融资=跨境转卖/风险参与?），值得跟踪细则

## 开放问题

- 全国跨境服务贸易信息平台（第1条）的建设形态
- 供应链专业服务机构"国际化"的配套措施（哪些机构、何种支持）
