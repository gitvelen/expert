# 区块链可以解决供应链金融哪些痛点？（2019）

## 基本信息

- 发布：2019-05-13，公众号"供应链金融"（栏目 1082），原载于瑞通供应链金融 / sinotf.com
- 性质：一般专业媒体综述，多处为匿名"业内人士"观点，唯一具名观点人为[[张明裕]]（布比/壹诺金融相关）
- 证据强度：位于"专业公众号分析"层级下限，引用需谨慎标注

## 核心内容

### 供应链金融难点清单（业内人士，弱证据）

多层次信用穿透难、风险识别与把控难，是当前供应链金融面临的两大难点。

### 区块链本地见证核验贸易真实性

示意：企业 A、B 贸易的同时，银行 C 作为链上见证方记录全过程；企业 A 持贸易信息找银行 C 融资时，银行可从本地见证数据核对真实性，效率高，只需保障身份与交易合约的法律效力。详见 [[concepts/区块链本地见证与贸易真实性核对-2019瑞通口径]]。

### 供应链金融业务门槛

传统模式依赖核心企业参与及其上下游贸易数据，具门槛性：大型核心企业倾向自建平台走纵向深度；第三方平台联合中小型核心企业走横向多元。详见 [[concepts/供应链金融业务门槛与核心企业依赖论-2019瑞通口径]]。

### 分布式账本 + 隐私授权共享

多方加入链条共享交易数据、应收应付数据，同时做隐私保护：供应商授权融资银行查询其数据，数据依托核心企业的应付账款。此机制与微企链、布比壹诺系列来源的描述一致（见 [[concepts/区块链多级供应商融资四障碍四解法-2018布比壹诺口径]]）。

### 张明裕观点（厂商口径，弱）

区块链解决了信任传递问题，带来两重价值：一是降低整个产业的融资成本；二是有效挖掘优质资产。注意与 2018 年其"信息传递≠信任传递"表述存在口径差异，见 [[findings/信息传递不等于信任传递论断-2018演讲口径]] 与 [[queries/查询-张明裕信任传递表述2018到2019口径变化]]。

### 审慎与愿景差距（业内人士，弱）

区块链可"辅助解决"痛点，但大规模推广仍困难，应正视区块链发展阶段与美好愿景之间的差距，避免以偏概全和过度夸大。详见 [[concepts/区块链发展阶段与愿景差距论-2019瑞通口径]]，与 [[comparisons/区块链万能论与工具属性论对比]]、[[concepts/区块链非币化应用主流论-2019苏宁口径]] 同属审慎叙事。
