# 《商务部等8单位关于开展全国供应链创新与应用示范创建工作的通知》（2021-03-30）

2021年3月30日，商务部官网发布该通知，由商务、工业和信息化、生态环境、农业农村、市场监管部门，会同中国人民银行、各银保监局、中国物流与采购联合会共8单位联合发文。文件在 [[商建函2018-142号试点通知]] 试点基础上开启"示范创建"阶段，是 [[国办发2017-84号指导意见]] 的落实文件，直接催生同年7月公布的第一批 [[全国供应链创新与应用示范城市和示范企业]] 名单（见 [[商务部等8单位第一批示范名单通知2021]]）。

## 总体目标（5年，"四个新"）

1. 供应链优势培育取得新成效：创新链、供应链与实体产业深度融合；
2. 供应链效率效益得到新提高：全链条效率和效益系统化提升；
3. 供应链安全稳定达到新水平：涌现核心企业与专业领域单项冠军企业；
4. 供应链治理效能得到新提升：跨部门、跨行业、跨区域政策协调性凸显。

指导思想提出促进供应链 [[供应链五化发展方向]]（协同化、标准化、数字化、绿色化、全球化）。

## 示范城市五大任务

1. 完善供应链治理体系建设；
2. 健全产业供应链生态：推动重点产业集群 [[供应链延链补链强链固链]]，加大链主企业和专业领域单项冠军企业培育力度；
3. 推动 [[区域供应链一体化]]：明确提出"积极探索利益共享、税收分成等区域合作新机制"（罕见的正式表述）；
4. 推动提升全球供应链地位：稳定与扩大外资、发展跨境电商、优化公共海外仓布局；
5. 提高供应链安全发展水平：健全应急保供体系与 [[应急物流与联保联供机制]]。

## 示范企业六大任务

1. 提高供应链管理水平（流程再造、大中小企业协同）；
2. 强化供应链创新引领（物联网、大数据、边缘计算、区块链、5G、人工智能、AR/VR 等技术集成应用）；
3. 拓展供应链专业服务：**鼓励金融机构积极发展流程型、智能型供应链金融业务**，提供基于供应链的授信、保理、结算、保险等金融服务——与本项目供应链金融主线（如 [[湖南供应链金融规范发展若干措施2021]]、[[甘肃省供应链金融发展意见2021]]）相呼应；
4. 积极布局全球供应链；
5. 推动供应链绿色发展：企业环境和碳排放信息公开、绿色采购、共同配送、单元化载具循环共用；
6. 加强供应链风险防范。

## 组织实施六步流程

| 步骤 | 内容 |
|---|---|
| 1. 组织申报 | 省级商务主管部门核选后择优报送商务部（流通发展司）；**国资委直接管理的中央企业由集团总部直接报送商务部** |
| 2. 申报材料 | 申报书＋示范申报指标＋可复制推广典型经验精简版（**不超过1500字**），经商务部业务系统统一平台报送 |
| 3. 专家评审 | 商务部会同相关单位组织专家评估，必要时现场调研核实 |
| 4. 结果公示 | 商务部网站公布，可提异议 |
| 5. 公布名单 | 无异议或异议不成立的以商务部文件形式发布 |
| 6. 动态管理 | 依据《全国供应链创新与应用示范管理办法》（**另行制定**）开展年度绩效评价；对工作积极性不高、示范作用不明显、有重大违法违规行为及重大负面社会影响的企业及时取消示范资格（见 [[示范动态管理机制]]） |

第一批示范城市和示范企业从既有试点中推荐确定，报送截止日期为 **2021年4月12日**。

## 开放问题

《全国供应链创新与应用示范管理办法》"另行制定"，其出台时间及年度绩效评价的实际执行情况由 [[查询-示范管理办法出台时间与绩效评价执行情况]] 追踪，本文件是该查询的起点证据。
