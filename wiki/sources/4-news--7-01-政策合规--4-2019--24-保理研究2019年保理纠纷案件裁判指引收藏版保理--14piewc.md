# 保理研究：2019年保理纠纷案件裁判指引（收藏版）

作者杜长明（汇商金律）整理的保理纠纷判例汇编，按诉讼程序（案由—被告与第三人—管辖—合同效力—应收账款转让规则—胜诉案例—败诉案例）梳理各地法院裁判口径，核心权威为最高人民法院系列判例。发布于2019年7月26日。

## 内容结构

1. **保理的定义与立法现状**：保理＝债权人将现在或未来的应收账款转让给保理商，保理商提供融资、账户管理、催收、坏账担保等一项或多项服务。当时我国尚无保理直接立法和司法解释，各地法院审理口径逐步统一。
2. **诉讼案由**：保理合同为无名合同，实践中有三种案由处理——"保理合同纠纷"（前海指引）、"其他合同纠纷"（天津高院纪要）、"合同纠纷"（（2014）赣民二终字第32号）。
3. **被告及第三人的确定**：有追索权保理中保理商可同时向债务人与债权人主张（[[有追索权保理追索权的一般保证定性]]）；天津高院纪要规定追加债务人/债权人为第三人的规则。
4. **司法管辖**：八种管辖确定情形，详见 [[保理纠纷管辖权确定规则]]。
5. **保理合同效力**：基础合同无效不当然导致保理合同无效（善意保理商保护），详见 [[保理合同与基础合同相对独立性]]；名为保理实为借贷的认定见 [[名为保理实为借贷]]。
6. **应收账款转让规则**：通知规则群，详见 [[债权转让通知规则群保理]]；暗保理规则见 [[暗保理法律规则]]。
7. **胜诉与败诉案例**：择一主张规则见 [[保理纠纷择一主张规则]]。

## 核心判例索引

| 案号 | 要点 |
|---|---|
| （2014）民二终字第271号 | 追索权≈放弃先诉抗辩权的一般保证；基础合同无效不影响保理合同；债务人承诺排除一切抗辩 |
| （2016）最高法民辖终38号 | 追索权之诉与应收账款债权之诉属必要共同诉讼，应合并审理 |
| （2015）民申字第2394号 | 协议管辖与仲裁条款冲突且无主从关系时，按合同纠纷一般管辖 |
| （2015）民二终字第98号 | 转让通知书为保理合同附件，债务人签章视为接受管辖条款 |
| （2017）最高法民再164号 | 次债务人不得以债权瑕疵对抗善意保理商（珠海华润银行案） |
| （2017）最高法民申132号 | 已获回购判决后不得再诉债务人清偿（择一主张） |
| （2015）民二终字第134号 | 保理业务关系可构成取得票据权利的"真实交易关系"（票据无因性） |
| （2016）最高法民申7号 | 未收到通知即使实际知晓，转让对债务人不生效 |
