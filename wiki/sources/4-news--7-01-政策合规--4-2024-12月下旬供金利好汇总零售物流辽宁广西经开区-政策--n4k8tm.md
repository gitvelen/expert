# 2024年12月下旬供金政策汇总

| 文件 | 供金相关条款 |
|---|---|
| 商务部等7部门《零售业创新提升实施方案》（12-16，2029目标） | **全供应链共管共享库存**；集采集配、统仓统配、供应商直配、自动补货——"信息多跑路、商品少跑路" |
| 中办国办《有效降低全社会物流成本行动方案》 | 大宗商品精细物流工程：供应链组织平台、资源配置枢纽、储运设施；**鼓励银行开展重点领域大宗商品供金**（专档已入） |
| 辽宁13部门《标识解析"贯通"行动计划（2024-2026）》（12-10） | 星火·链网（沈阳）超级节点；**探索建设可信工业资产服务平台**——标识+区块链为企业增强信用、加快供金模式创新 |
| 厦门市商贸流通专项资金管理办法（12月修订） | 示范企业50万等（专档已入 t8k3wd） |
| 广西人大《加快打造国内国际双循环市场经营便利地的决定》 | 规范发展供金（应收/存货/仓单/订单/保单）；**中国—东盟金融基建**：跨境贸易金融互联互通平台、跨境征信平台、数字人民币东盟应用先行示范区、中国—东盟金融城 |
| 北京经开区《产业金融高质量发展若干措施（试行，征求意见）》（12-13~19） | 建立完善供应链金融体系；**整链授信**创新；保理/租赁公司年业务合同≥1亿按当年融资总额**0.1%**奖励、每户每年最高**500万** |
| 上海金山《进一步加强金融服务促进实体经济高质量发展的实施意见》 | 供金等首单业务且≥10家经营主体受益的金融创新项目奖**10万**（CCER质押贷款、认股权贷款等） |

## 对照分析

- **经开区0.1%按融资总额奖励**是保理/租赁行业罕见的"规模挂钩"财政补贴（对照江西10亿撬动试点、天津保理之都指标制）——地方抢供金机构的补贴竞赛升级
- 辽宁"可信工业资产服务平台"= 标识×区块链×供金的省域落地（国家贯通行动计划的第一个省级呼应，先于广东千标通粤的应用深化）
- 广西面向东盟的跨境金融基建（数字人民币示范区）为跨境供金开辟人民币计价场景
- 零售业的"共管共享库存"把供应链协同从制造业语汇扩展到流通业（VMI逻辑的政策化）
