# 最高奖励3000万元！一图读懂山西《重点产业链培育激励方案》

## 概述

万联网 2023-05-16 转载山西日报报道，附政策全文《山西省重点产业链培育激励方案》（晋工信新材料规字〔2023〕2号）。山西省工信厅、省财政厅联合印发，未来3年从省技术改造专项资金统筹安排资金，聚焦**企业培育、关键环节招引、协作配套强化、公共服务能力提升**四大领域，最高单项奖励3000万元。方案自 2023-04-27 施行，有效期3年，并规定此前不一致的相关省级奖励政策以本方案为准。

## 核心事实（政策原文口径）

- 2022年以来，山西实施全产业链培育工程、推行"链长制"。首批筛选10条重点产业链：特钢材料、新能源汽车、高端装备制造、风电装备、氢能、铝镁精深加工、光伏、现代医药、第三代半导体、合成生物；选取20家"链主"企业及一批"链核"企业重点扶持。
- 依据"关联性强、契合性严、协作性紧、盈利性好"要求确定激励对象；激励对象为与省级重点产业链相关的独立法人企业或其他法人单位。

### 奖励结构速览（原文口径）

| 激励条目 | 档位与金额 |
|---|---|
| 链主认定奖励 | 认定即奖100万元 |
| 链主营收档位奖（认定当年起） | 产业链年度营收10亿/50亿/100亿/500亿/1000亿元 → 100万/500万/1000万/2000万/3000万元；同档只奖一次，获高档不得再报低档 |
| 链上企业营收奖（2021为基年） | 首破5亿/10亿/20亿/50亿/100亿元 → 25万/50万/100万/250万/500万元；链上企业须非链主，且与链主年度交易额≥1000万元，或与5家以上同链条企业年度交易额>2000万元 |
| 链主以商招商引荐奖 | 引进落地企业固投≥1亿元，按实际固投2‰奖，上限500万元；同一项目仅一个引荐法人享奖 |
| 新引进落地企业奖 | 固投≥1亿元且建设期内全部投产，按实际固投2%一次性奖励，上限1000万元 |
| 链主协作配套奖 | 协作配套率每提高5个百分点，按增幅相应采购（销售）额的1%奖励，上限500万元 |
| 链上企业配套奖（2021为基年） | 供应/消纳配套金额首破2000万/5000万/1亿/5亿/10亿元 → 20万/30万/50万/100万/200万元 |
| 首台（套）装备采购奖 | 支付1000万/3000万/5000万/1亿元 → 采购方奖50万/150万/250万/500万元 |
| 首批次新材料采购奖 | 支付500万/1000万/2000万元 → 采购方奖25万/50万/100万元 |
| 开发区产业链集中度奖 | 链上营收占比达20%/40%/60%以上 → 50万/100万/150万元（高档累加）；每培育1家省级链主奖50万元 |
| 发展促进机构技术推广奖 | 首次成功应用按合同实际到账金额5%一次性奖励，全年累计上限100万元 |
| 产业链竞赛奖 | 县（市、区）政府、开发区管委会参赛（山西综改示范区太原片区可直报）；一/二/三等奖100万/70万/50万元 |

### 关键口径定义（原文）

- **协作配套率** = 供应配套率（链主从链上供应单位年度采购金额 / 链主年度全部采购金额）或消纳配套率（链主向链上用户单位年度销售金额 / 链主年度全部销售金额）。
- **收入认定依据**：企业自建产业链主导产品清单 + 具审计资质的第三方财务审计报告 + 属地市级及以上部门审核意见。
- **关联企业判定**：一方直接或间接持有另一方股份总和达25%以上；或双方直接或间接同被第三方持股达25%以上。第6、7条配套奖励中生产销售企业与采购企业不得为关联企业。
- **监管机制**："承诺+追溯"资金监管与绩效管理；已获省级奖励的同一项目原则上不得重复申报；申报审核依《山西省技术改造资金使用管理办法》（晋政办发〔2022〕72号）执行。

## 与知识库的关联

本来源是 [[concepts/链长制定义与各省实践框架-2021口径]] 谱系在2023年的地方落地新证据，可与 [[findings/深圳链主企业认定标准快照-2021媒体转述口径]] 对比：深圳口径侧重链主"认定标准"，山西方案进一步将链主及链上企业的协作配套行为**货币化激励**。部分回答 [[queries/查询-链长制与链主培育政策在2022年后的演进与与供应链金融政策的衔接]] 中"2022年后演进"的问题，并可延长 [[synthesis/供应链创新与应用试点示范政策演进2017-2022]] 的时间线至2023。

## 值得注意的张力

- 对"协作配套率"的财政奖励强化链内封闭交易倾向，与供应链金融中警惕关联交易虚构贸易背景的风控逻辑存在潜在张力；25%持股的关联企业排除条款仅覆盖股权维度，未覆盖实际控制维度。
