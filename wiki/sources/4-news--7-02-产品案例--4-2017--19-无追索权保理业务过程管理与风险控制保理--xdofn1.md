# 无追索权保理业务过程管理与风险控制（2017）

## 来源概况

- **类型**：贸易金融公众号转载的操作性长文（2017-08-22），末注"来源：百度文库"，**作者不明**。
- **内容定位**：以"综合保理"（无追索权保理）为样本的银行保理教科书式操作手册，覆盖全流程：卖方考察与风险评价 → 需求分析与品种选择 → 缔约建账 → 发票转让/收款/催收/融资 → 日常风险控制 → 坏账担保额度与债权核准 → 争议处理 → 人员分工与16个业务环节管理。
- **证据强度**：中等偏弱。体系完整、内部一致、部分法律口径与判例吻合，但作者不明、非监管原文、非书籍，按分层归入"专业公众号转载操作手册（作者不明）"层级；关键法律结论需与法规/判例页互证。

## 核心主张

1. 无追索权保理是**最完整的保理形态**，包含全部四项基本服务功能（资金融通、销售分户账管理、应收账款催收、坏账担保），其流程是理解其他保理品种的捷径。
2. 保理风险控制的本质可归结为四件事：**销售分户账准确记账 + 债权稀释量化 + 留置金充足 + 争议及时处理**。
3. 销售分户账管理是保理区别于一般贸易融资的最重要方面，构成企业**赊销管理外包**功能。

## 关键法律口径（2017年，须按时效性标注）

- **债权转让通知**：依合同法80条口径，通知须由卖方（原债权人）名义发出方具效力，受让人通知不具效力。此口径已被 [[concepts/债权转让通知生效规则-合同法80条到民法典546条]] 记录的民法典546条后实践更新。
- **法律效果三分**：接收发票 ≠ 接受转让（入账为准，债权转移）≠ 核准（承担担保付款责任，风险转移）。
- **额度可减不可溯**：保理商可单方减/撤坏账担保额度，但撤销前已发货部分仍按原额度担责。
- **争议期间效果**：已核准债权视为未核准、暂停担保；卖方懈怠（不积极作为或不通报进展）则保理商彻底免责。

## 重要实务概念（详见各概念页）

- 卖方风险评价三维度（应收账款适格性 / 卖方生存能力 / 业务量）→ [[concepts/无追索权保理四项基本服务功能与操作流程全景-2017口径]]
- **债权稀释（dilution）**：贷项清单、折扣、双向贸易、争议等扣减项须量化以定融资比例；中国无贷项清单传统，以退换发票替代，**换票频繁即稀释信号** → [[concepts/债权稀释与留置金融资赎回机制-2017口径]]
- **间接付款**：五项预防措施 + 四步事后处置；频繁间接付款是卖方挪用/欺诈预警 → [[concepts/债权稀释与留置金融资赎回机制-2017口径]]
- **坏账担保额度**：line cover（可循环）/ order cover（一次性）；受核准/未核准债权区分 → [[concepts/坏账担保额度与债权核准区分-2017口径]]
- **融资赎回（charge back）与留置金（retention）**：争议使合格应收账款变不合格，保理商融资安全本质建立在保留足够留置金之上 → [[concepts/债权稀释与留置金融资赎回机制-2017口径]]
- **有效争议认定**：无追索权保理中的争议限于"应收账款是否有效成立"，非一般合同纠纷；争议解决期限协商90天（GRIF为180天）、司法一年半（GRIF为三年）→ [[concepts/保理争议处理与有效争议认定-2017口径含GRIF对比]]

## 结构化数据摘录

### 日常风险控制财务指标（原文口径）

```
总资产周转率 = 销售收入 / 平均资产总额
平均资产总额 = (月初资产总额 + 月末资产总额) / 2

应收账款周转率 = 销售收入 / 平均应收账款
平均应收账款 = (月初应收账款 + 月末应收账款) / 2

资产负债率 = (负债总额 / 资产总额) × 100%
速动比率 = (速动资产 / 流动负债) × 100%
速动资产 = 流动资产 - 存货

销售收入增长率 = (销售收入增长额 / 上月销售收入) × 100%
```

### 可融资余额公式（原文口径）

```
可融资余额 = 合格的发票 × 融资比例 - 已融资余额
```

## 张力与限制

- 文中描述的含坏账担保完整形态更接近 FCI 国际保理实践，与国内以回购型（有追索）为主的业态（见 [[findings/2017年国内保理仅限商业发票贴现且保留追索的业态快照]]）存在张力；国内银行是否实际大规模开展含坏账担保的无追索权保理存疑，见 [[queries/查询-国内银行含坏账担保无追索权保理实际开展情况考证]]。
- 文中"债权转让通知须以卖方名义"系合同法口径，民法典后受让人通知效力已获承认——以最新口径为准。
