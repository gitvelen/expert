# 商业保理公司看过来！《上海市地方金融监督管理条例》发布，"7+4"类地方金融组织纳入监管

## 概述

本文为2020年4月14日"贸易金融"公众号转载的《[[上海市地方金融监督管理条例2020|上海市地方金融监督管理条例]]》全文报道。条例于2020年4月10日经上海市十五届人大常委会第二十次会议**全票表决通过**，自2020年7月1日起施行。条例对国家授权地方监管的"[[7-4类地方金融组织|"7+4"类地方金融组织]]"（小额贷款公司、融资担保公司、区域性股权市场、典当行、融资租赁公司、商业保理公司、地方资产管理公司等）作出基础性制度安排。

## 条例结构与核心条款

条例共六章四十三条：总则、地方金融组织行为规范、监督管理措施、风险防范与处置、法律责任、附则。

| 主题 | 条款 | 要点 |
|---|---|---|
| 设立许可 | 第九条 | 设立地方金融组织须取得许可或试点资格 |
| 备案 | 第十条 | 分支机构、名称/住所/注册资本/控股股东变更等须备案 |
| 信息报送 | 第十四条 | 定期通过监管平台报送经营报告、审计报告 |
| 重大风险事件报告 | 第十五条 | 24小时内报告；控股股东/实控人风险事件同样连带报告 |
| 行为底线 | 第十八条 | 四项禁止活动 |
| 剩余风险责任承诺 | 第十七条 | 控股股东/实控人可书面承诺承担解散后未清偿债务并公示 |
| 监管评级 | 第二十四条 | 分类监管，确定检查频次与措施 |
| 严重失信名单 | 第二十六条 | 联合惩戒法定代表人、董监高、实控人 |
| 营销宣传资质 | 第二十八条 | 无资质不得开展金融营销宣传，广告经营者负查验义务 |
| 属地处置责任 | 第三十条 | 市、区政府为防处非法集资第一责任人；一般登记注册企业不得变相从事金融业务 |
| 处罚 | 第三十五至三十九条 | 详见下文 |

## 行为底线四禁（第十八条）

1. 吸收存款或者变相吸收存款；
2. 出借、出租许可证件或者试点文件；
3. 非法受托投资、自营或者受托发放贷款；
4. 国家和本市禁止从事的其他活动。

## 处罚力度

- **擅自设立/非法经营**（第三十五条）：责令停业并没收违法所得；违法所得50万元以上处3–5倍罚款；无违法所得或不足50万元处50万–250万元罚款；责任人另处20万–100万元。
- **违反备案/报送/报告义务**（第三十六、三十八条）：1万–5万元，情节严重5万–20万元。
- **违反行为底线**（第三十七条）：没收违法所得并处50万–250万元罚款，情节严重可责令停业、吊销许可证件或取消试点资格。
- **责任人罚款**（第三十九条）：可对直接责任的董监高另处5万–50万元。

## 对商业保理的影响

商业保理公司属条例规范的"7+4"业态之一，须遵守行为底线、备案、信息报送、24小时重大风险事件报告等共性制度。条例与针对商业保理的《[[上海市商业保理公司监督管理暂行办法2020]]》构成"地方法规+业态细则"的层级关系，也是[[商业保理地方监管细则地方化浪潮]]的地方立法标志性节点。条例第三十条"一般登记注册企业不得变相从事金融业务"与[[供应链平台变相金融业务禁令]]（226号文第23条）形成互补。

## 张力与开放问题

- 第三条确立"安全审慎、有序规范、创新发展"三原则，第十九条要求监管措施与创新发展相适应，与临港新片区等区域的"监管创新试点"（第七条）之间存在需观察的张力。
- 条例为框架性立法，具体监管细则授权市地方金融监管部门另行制定，执行口径在当时尚不明确，见 [[查询-上海地方金融监管条例对商业保理的配套监管细则与执法案例]]。
- 当时中央层面的《地方金融监督管理条例》尚未出台，本条例不应泛化为全国性规则。
