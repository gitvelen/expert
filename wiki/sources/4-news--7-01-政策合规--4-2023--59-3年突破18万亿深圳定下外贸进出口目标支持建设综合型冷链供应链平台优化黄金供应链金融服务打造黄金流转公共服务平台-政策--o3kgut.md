# 3年突破1.8万亿！深圳定下外贸进出口目标，支持建设综合型冷链供应链平台，优化黄金供应链金融服务，打造黄金流转公共服务平台

万联网2023-09-13综合整理报道：深圳市人民政府办公厅发布《深圳市推动货物贸易进口高质量发展行动计划（2023—2025年）》，围绕7类重点商品进口提出26项具体举措，目标到2025年全市进口贸易总额突破1.8万亿元、占全省比重约50%、自RCEP市场进口占比约45%。详见 [[深圳市推动货物贸易进口高质量发展行动计划2023-2025]]。

## 量化目标（2025年，人民币）

| 商品/指标 | 目标 |
|---|---|
| 全市进口贸易总额 | 突破1.8万亿元 |
| 占全省比重 | 约50% |
| 自RCEP市场进口占比 | 约45% |
| 集成电路 | 突破8000亿元 |
| 液晶平板 | 突破1000亿元 |
| 大宗能源商品 | 突破900亿元 |
| 农产品 | 突破1500亿元 |
| 消费品 | 突破1800亿元 |
| 黄金珠宝 | 突破600亿元 |
| 医药产品 | 突破300亿元 |
| 飞机轮船 | 突破100亿元 |

注意：以上为"争取"目标而非约束性指标。

## 供应链金融相关重点（本Wiki主题）

1. **冷链**：支持国内外冷链企业在深建设集"国际贸易、代理采购、供应链金融、仓储物流、加工销售"于一体的 [[综合型冷链供应链平台]]。
2. **黄金珠宝**：全面落实罗湖区黄金金融发展若干措施，优化 [[黄金供应链金融与黄金流转公共服务平台]]，依托上海黄金交易所场外登记系统，创新民间黄金回购、换料、锁价、融资等业务模式；支持上海黄金交易所国际板指定仓库（工行深圳）升级。
3. **保障措施**：加强银企合作，推动银行业金融机构运用 [[贸易融资金融工具组合]]（关税保函、保证担保、未来货权质押、仓单质押、远期结售汇），降低融资成本、规避汇率风险。
4. **国资角色**：整合市属国有对外贸易促进资源，依托国资力量开展大宗商品等领域供应链业务。

## 其他要点（背景）

- 七大商品方向：先进技术设备及关键零部件、大宗能源商品、农产品、中高端消费品、黄金珠宝、医药产品、交通工具。
- 口岸通关便利化（"先入区、后报关""分送集报""物流一体化""按状态分类监管"）、跨境电商进口全业态、飞机船舶融资租赁（SPV外债备案）、平行进口汽车等26项举措。
