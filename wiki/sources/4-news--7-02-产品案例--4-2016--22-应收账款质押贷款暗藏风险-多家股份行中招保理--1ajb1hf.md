# 应收账款质押贷款暗藏风险 多家股份行中招（贸易金融/银通智略，2016）

## 来源信息

- 公众号：贸易金融，栏目 Factoring，2016-08-05 发布
- 原始出处：银通智略报告《银行风险管控实务》（2016 年 6 月）摘编
- 文体：案例分析 + 风险管理评论

## 案件时间线（媒体转述二审判决）

| 日期 | 事件 |
|---|---|
| 2014-03-25 | 某股份制银行向武汉本泰工贸有限公司授信 1 亿元，以对武钢原料分公司 2014-03-25 至 2016-03-24 的全部应收账款作质押；同日双方出具《应收账款质押通知书》，武钢原料分公司在《应收账款质押通知确认书》上确认（含公章及财务确认预留） |
| 2014-03-25 | 办理质押登记，登记应收账款 2508 万元 |
| 2014-06-02 | 同一模式追加质押 1254 万元并登记，质押规模合计 3762 万元 |
| 2014-06-04 | 银行发放贷款 1000 万元 |
| 2014-10-21 | 本泰公司拖欠利息 9 万余元，银行要求提前收贷，起诉武钢原料分公司及其母公司武钢资源公司 |
| 一审 | 判本泰公司还款，但不支持应收账款增信（撇开武钢方偿债责任） |
| 2016-02 | 武汉高院二审开庭，维持原判（质押无效） |

## 关键事实

- 武钢原料分公司/武钢资源公司抗辩：从未与本泰公司签订原材料供销合同，未在《应收账款质押通知书》《应收账款质押通知确认书》及《询证函》上签字盖章；相关公章此前已作废，印章及签名涉嫌伪造。
- 本泰公司自身对银行提供的质押材料亦不予认可。
- 银行经办员工出庭作证，但对经办场地是否为武钢原料分公司工作场地、印章真伪均无法确认——印证银行核实流程形式化。
- 同手法扩散：本泰公司与关联公司法尔公司以相同手法（均以武钢资源公司/武钢原料分公司应收账款质押）在民生、浦发、中信等多家银行办理四笔质押贷款，规模过亿，均被法院判定质押无效，贷款回收堪忧。

## 作者分析口径（银通智略，非司法口径）

三大风险点：出质人欺诈风险；法律风险（交易违反法律禁止性规定→基础合同无效→质押必然无效）；银行应收账款真实性审查缺陷。

作者将银行审查缺陷归纳为三条：

1. 未要求提供完整履约证明材料（货物交付凭证、货运凭证、经债务人确认的对账单），仅凭买卖合同 + 单方开具的增值税专用发票不足以证明应收账款存在；
2. 过分相信盖有债务人公章/合同专用章的确认文件，对私刻公章、作废印章缺乏警惕；
3. 仅做形式审查、不做实质审查，质押通知由出质人单方传递。

改进框架（实质审查三层）：明确审查内容（出质人信用 + 基础交易真实性 + 金额明细须债务人确认）；核实方式去出质人化（亲自向债务人核实、防假冒接待、现场 + 非现场直核）；完善流程标准并加强人员培训。
