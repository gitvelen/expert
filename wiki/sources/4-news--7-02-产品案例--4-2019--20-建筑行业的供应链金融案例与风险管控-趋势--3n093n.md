# 建筑行业的供应链金融案例与风险管控（万联网，2019）

## 来源信息

## 内容概要

以建筑业垂直采供平台 [[筑集采]] 为案例的趋势宣传型文章。分四部分：

1. **建筑业三大痛点**：行业信息化水平偏低（转述称我国建筑业信息化率 0.03%，仅为国际平均水平 0.3% 的 1/10；并引 2018 年数据推算"信息化率提高 0.1% ≈ 235 亿市场"）；中小企业融资难、账款拖欠导致资金周转率低；采购管理水平落后（"一单一询价/招标/签约/结算"的传统模式、供应商选择重当期报价轻历史资信）。文中引建设部原副部长谭庆琏在中国建筑业信息化高峰论坛的发言佐证信息化落后。
2. **筑集采的供应链金融服务**：第三方平台定位，提供"数据支持、辅助决策"的金融科技服务；以核心企业信用为担保、线上真实交易数据为风控依据；提供应收账款类国内保理与组合式供应链产品；提出"及时支付"理念。
3. **科技风控三件套**：
   - 精准风控：大数据、AI、风控模式算法画用户画像与业务画像（招中标关系、上下游关系、人企关系、资金交易关系、担保关系、舆情等）；
   - 事件可溯源防篡改：区块链、电子签章确保数据不可篡改可追溯，并预判区块链账本将被司法机关广泛采纳为证据；
   - 真实性识别：机器视觉、生物识别、OCR、NLP、电子证书、LBS 等识别用户身份与交易背景真实性，风控模型结合规则引擎全局监控。
4. **未来两层规划**：
   - 构建"M+1+N"供应链金融生态圈（详见 [[M加N供应链金融生态圈-2019筑集采口径]]），配合"资产数字化、资产标准化、资产可信化"三步法；
   - 授信资源穿透与分享（详见 [[区块链授信穿透与应收账款收款凭证-2019筑集采口径]]）。

| 论断 | 证据强度 | 备注 |
|---|---|---|
| 建筑业信息化率 0.03% vs 国际 0.3%；提高 0.1% ≈ 235 亿市场 | 低 | 转述行业论坛数据，无原始出处，一般公众号口径 |
| 筑集采模式：核心企业信用担保 + 线上真实交易数据风控 + 保理与组合产品 | 低（平台自述） | 宣传性内容，无第三方验证 |
| 区块链授信穿透：凭证拆分流转、哪层需求哪层融资、智能合约自动放款/兑付 | 低（设计蓝图） | 文中无融资规模、上线银行、违约数据 |
| 三关键词：融资时效、融资规模、融资成本 | 中低 | 援引平安银行、南通农商行、华瑞银行、欧冶、广联达实践归纳 |
