# 西安市"十四五"产业发展规划：至2025年文化产业营收达1000亿元

西安市人民政府于2022年2月印发《西安市"十四五"产业发展规划（2021—2025年）》，规划期限为2021—2025年，远景展望到2035年。万联网于2023-03-13转载全文。规划以构建"6+5+6+1"现代产业体系为主线，全面推行"亩均论英雄"综合改革与"链长制"。

## 核心量化目标（到2025年）

| 指标 | 目标值 |
|---|---|
| 经济总量 | 1.4万亿元以上 |
| 规上先进制造业总产值 | 超1万亿元，年均增长15%以上，占规上工业70% |
| 文化产业营业收入 | 1000亿元（标题要点） |
| 旅游业总收入 | 超5000亿元 |
| 规上文化企业数量 | 950个，国家级文化产业示范园区2个 |
| 三次产业结构 | 3∶33∶64 |
| 工业增加值占GDP | 25% |
| 文旅产业增加值占GDP | 16% |
| 数字经济规模 | 7000亿元，核心产业增加值占GDP 5%以上 |
| 国家高新技术企业 | 12000家 |
| 千亿级产业集群 | 形成6—8个 |
| 生产性服务业总收入 | 超5000亿元 |
| 新兴产业主营业务收入 | 超2000亿元 |
| 国际航线 | 120条 |
| 实际利用外资 | 100亿美元 |
| 陆港集装箱吞吐量 | 40万标箱 |
| 跨境电商交易规模 | 突破150亿元 |

## 规划原文要点（结构化保留）

> "6+5+6+1"："6"即6大支柱产业（电子信息制造、高端装备制造、汽车产业、新材料新能源、航空航天、食品和生物医药）；"5"即5大新兴产业（人工智能、机器人、卫星应用、大数据和云计算、增材制造）；"6"即6大生产性服务业（现代金融、研发设计、现代物流、软件和信息服务、检验检测认证、会议会展）；"1"即文化旅游特色产业。

**19条重点产业链**：光子、重卡、半导体及集成电路、输变电装备、航空、生物医药、钛及钛合金、乘用车（新能源）、乳制品、航天、太阳能光伏、轨道交通、民用无人机、氢能、增材制造、智能终端、物联网、传感器、陶瓷基复合材料。

**链长制"五个一"机制**：市政府主要领导担任总链长，市级领导任各重点产业链链长；每条链实行"一位领导、一条产业链、一个工作专班、一套工作方案、一支专家服务团"。规划明确"积极承接省上23条重点产业链中涉及我市的产业链"。

**空间布局"一核三带一通道多板块"**：文旅商贸核心（新城、碑林、莲湖、雁塔、未央及高新区、曲江新区等）；高新技术产业带（高新区引领）、先进制造产业带（经开区引领）、文化旅游产业带（曲江新区引领）；国际物流大通道（空港新城—高铁新城—国际港务区）；外围多个产业集群板块。

**两业融合试点**：西安高新区、陕西鼓风机（集团）有限公司、西安诺瓦星云科技股份有限公司承担国家"两业"融合试点，配套实施9大专项行动。

## 自我问题诊断（官方自认，可信度高）

- 2020年西安GDP（10020.39亿元）与工业增加值（1828.59亿元）在9个国家中心城市中排名**末位**；规上工业增加值总量仅为副省级城市平均规模的约1/2。
- 中国服务业企业500强中西安仅5家。
- 6大支柱产业中仅航空产业集群入选国家先进制造业集群决赛优胜者名单（2021年3月公示）。

## 创新基础

2020年R&D经费投入强度5.05%，位列副省级城市第一；国家高新技术企业超5000家；技术合同交易额1648亿元；拥有两院院士60余人、高等院校83所。布局国家超算（西安）中心、高精度地基授时系统、国家分子医学转化科学中心等重大科技设施，依托秦创原创新驱动平台（西咸新区为总窗口）。
