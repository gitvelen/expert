# 需求上升！《2021年6月中国通用仓储市场动态报告》发布

## 来源概况

- 发布方：[[物联云仓]]（在中国仓储与配送协会指导下发布），万联网 2021-07-26 转发，系该月度报告连续第 35 期。
- 性质：行业数据报告/平台通稿。数据来自物联云仓平台自报口径，未经第三方核验，可信度为"一般新闻报道/平台通稿"层级。
- 内容：全国主要物流节点城市通用仓储市场的需求、供应、租金与空置率月度动态。

## 市场总结（2021年6月）

全国通用仓储市场租赁需求小幅上升；新增供应大幅增加；32 个城市平均租金与空置率均小幅上升。注意：标题"需求上升"与空置率上升并存，系供应增幅大于需求增幅所致，属正常市场逻辑。

## 关键数据快照

| 指标 | 2021年6月数值 |
|---|---|
| 全国在线仓库总面积 | 超3.30亿㎡（环比+0.17%，新增56.58万㎡） |
| 在线可租面积 | 超4,545.75万㎡ |
| 覆盖范围 | 32省份、229城市、7,569园区 |
| 32城需求总面积 | 86.64万㎡（环比+16.86%） |
| 需求区域分布 | 东部54.69% / 西部28.16% / 东北3.24% |
| 新增供应 | 20起建成项目，193.89万㎡；TOP3：天津34.65万㎡、南京34.00万㎡、上海20.25万㎡ |
| 平均租金 | 27.66元/㎡·月（环比+0.33%；东部32.20 > 西部23.86 > 中部22.96 > 东北22.22） |
| 平均空置率 | 11.29%（环比+0.11pp；东北19.78%远高于东部9.71%、中部10.24%、西部10.92%） |

需求数据条目：

- 批发和零售业为需求主力军，制造行业需求较为旺盛。
- 1,000㎡以内仓库租赁需求占约56.31%；3,000–4,000㎡以上仅占3.88%；以长租为主，短租较少。

重点城市波动：

- **武汉**：租金环比上涨4.84%，为32城最大涨幅；驱动因素为社区团购快速布局扩张、租仓扩仓活跃，叠加部分地区仓库供应紧张。
- **南昌**：空置率环比下降4.63个百分点，为32城最大降幅；6月规模以上工业增加值增长10.9%，日化、五金等行业租赁需求旺盛，去库存加速。

## 口径注意

文中"32个城市"为报告统计样本城市口径，"覆盖229个城市"为物联云仓平台在线仓库覆盖口径，两者不同，引用时须区分。
