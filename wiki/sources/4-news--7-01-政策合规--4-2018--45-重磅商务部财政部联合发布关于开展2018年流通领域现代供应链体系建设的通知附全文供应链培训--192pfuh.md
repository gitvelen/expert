# 商务部、财政部《关于开展2018年流通领域现代供应链体系建设的通知》（财办建〔2018〕101号）

2018年5月28日，商务部、财政部联合发布财办建〔2018〕101号文，在开展四年物流标准化试点的基础上，对流通领域现代供应链体系建设发出"总攻"部署。本来源为政策全文转载（供应链金融公众号，综合自财政部网站、掌链传媒）。

## 总体思路与量化工作目标

原则为"市场主导、政策引导、聚焦链条、协同推进"，以城市为载体，围绕供应链"四化"（标准化、智能化、协同化、绿色化），以"五统一"为主要手段，发挥"链主"企业引导辐射作用与供应链服务商一体化管理作用。

政策设定了明确的量化绩效目标（原文数据）：

| 指标 | 目标值 |
|---|---|
| 城市消费品社会零售总额同比增速 | 高于全国平均水平 |
| 重点行业平均库存周转率 | 同比提高10%以上 |
| 供应链综合成本（采购、库存、物流、交易） | 同比降低20%以上 |
| 订单服务满意度（及时交付率、客户测评满意率等） | 80%以上 |
| 重点供应商产品质量合格率 | 92%以上 |
| 托盘、周转箱（筐）等物流单元标准化率 | 80%以上 |
| 供应链重点用户系统数据对接畅通率 | 80%以上 |
| 单元化物流占供应链物流比例 | 同比提高10%以上 |

## 主要任务（五方面）

1. **强化物流基础设施建设**：打造跨区域全国性物流枢纽，引导区域配送中心向快速周转型自动化仓库升级，推广快件末端自提设备、探索标准托盘箱替代快递三轮车箱体。
2. **发展单元化流通**：推广 1200mm×1000mm 标准托盘与 600mm×400mm 包装模数，将标准托盘/周转箱作为物流单元、计量单元、数据单元，鼓励租赁与循环共用体系。
3. **加强信息化建设**：推广 GS1 商品条码体系，推动托盘条码与商品条码、箱码、物流单元代码关联衔接；推动大数据、云计算、区块链、人工智能与供应链融合。
4. **聚焦重点行业协同化**：农产品供应链（标准化冷链、"不倒托、不倒箱（筐）"）、分销型供应链（快消品、药品、电商，统仓统配）、生产服务型供应链（家电、汽车零部件、日用电子产品）、柔性供应链（纺织服装、家具）。
5. **推广绿色技术模式**：新能源物流车、绿色包装、共同配送、单元化载具循环共用与社会化回收再利用。

## 中央财政支持重点与资金管理

资金来源为中央财政服务业发展专项资金（依据财建〔2015〕256号管理办法），定位"弥补市场失灵"、支持基础性公共性环节，采用财政补助、以奖代补、贷款贴息、购买服务等方式。

实施机制要点：
- 聚焦 3-5 条供应链，每条选 2-6 家规模大的承担主体，上下游企业联合申报；
- 推动城市"结联盟"、企业"结对子"跨区域联动；
- **资金负面清单**：不得用于楼堂馆所、办公楼、道路等建设；不得购买非标车辆和用于工作经费；不得支持有金融风险、发展模式不成熟的平台；不得将关联方交易额纳入申报项目总投资；不得将同一集团公司信息平台项目多地重复申报；
- 实施工作 2020 年底前完成并上报绩效评价结果。

## 申报城市条件与时间节点

申报城市须同时满足：
1. 属于《商贸物流发展"十三五"规划》明确的商贸物流节点城市；
2. 2017年GDP超过2500亿元，或位于国家全面深化改革开放试验区；
3. 前期获中央财政支持但尚未完成物流标准化/供应链体系建设工作的城市，不纳入2018年支持范围。

时间节点：申报方案 2018年6月5日前报送商务部、财政部参评；确定的重点城市须于 2018年9月30日前报送实施方案与项目表备案；年度进展报告次年2月底前报送；工作总结与绩效评价于建设结束后三个月内报送。
