# 山东《统筹加强产融合作促进工业和信息化高质量发展实施方案》

## 概述

2023年5月，山东省工业和信息化厅印发《统筹加强产融合作促进工业和信息化高质量发展实施方案》（以下简称"《实施方案》"），聚焦"十强"产业、标志性产业链、重点行业引领项目、高成长企业梯度培育项目、上市培育和创新创业成长项目，明确提出构建 [[两库一平台金融服务体系]]、实施"七大"专项行动，其中 [[产业金融强链行动]] 设定每年产业链供应链融资1000亿元以上的目标。

## "两库一平台"要点

- **重点融资项目库**：涵盖制造经济、数字经济、民营经济，2023年底力争入库企业项目3万家（个）以上，含五类项目：
  1. "十强"产业提升项目（省重点技改、新一代信息技术、高端装备、新材料、高端化工、现代轻工纺织）
  2. 重点行业引领项目（龙头企业、11条标志性产业链链主企业、先进制造业集群）
  3. 高成长梯度培育项目（专精特新、瞪羚、独角兽、制造业单项冠军、制造业领航企业）
  4. 上市培育和股权投资项目（上市培育入库企业、专精特新专板挂牌企业、省财政资金股权投资企业）
  5. 创新创业培育成长项目（"创客中国"优胜项目、孵化企业、创新型中小企业）
- **投融资机构资源库**：2023年优选入库300家以上，以后年持续新增100家以上，涵盖政策性银行、国有大型银行、股份制银行（招商、中信、华夏、浙商、恒丰等）、城商行（齐鲁、青岛、北京及各市城商行）、基金投资机构、担保保险公司（省再担保投融资集团、进出口信用保险等）、上市培育辅导机构。
- **投融资对接平台**：七个模块（优质投融资机构资源库、先进制造业融资项目库、产业资本智慧对接、企业在线路演等）+ 三大系统（信贷服务、基金投资、上市培育），对国家专项、重大技术攻关等重点项目实施"挂图督办"。

## "七大"专项行动与量化目标（均为政策目标值，非完成值）

| 行动 | 量化目标 |
|---|---|
| 银行信贷提升行动 | 每年实施500万元以上技改项目1万个、投融资增长7%以上；每年新增小微企业贷款户数和规模10%以上 |
| 基金投资引领行动 | "齐鲁企舞"路演"1+3+15"体系；每年路演100余场、合作意向100亿元以上 |
| 担保保险创新行动 | "见贷即保""见担即贷"；每年小微企业担保融资1000亿元以上 |
| 存量贷款接续行动 | 每年为5000家以上中小企业提供应急转贷1000亿元以上 |
| 上市培育助推行动 | "泰山登顶"行动，优选上市培育企业1000家以上；每年上市辅导80家、新三板挂牌40家、IPO 20家以上 |
| 产业金融强链行动 | 每年产业链供应链融资1000亿元以上 |
| 产投合作拓展行动 | 每年国际产投合作5家10亿美元、国内产投合作50家100亿元以上 |

## 产业金融强链行动的核心路径

推动政府部门、金融机构、核心企业、第三方专业机构等信息共享，围绕重点产业链加强财政金融资源协同联动，鼓励民营龙头企业探索发起行业市场化融资服务，支持核心企业扩大融资规模——签发商业汇票、供应链票据，发行债券和开展供应链存货、仓单和订单等特色融资，打通大中小企业融通的资金要素渠道。核心逻辑是**核心企业信用外溢 + 政银企信息共享**，与 [[银发2020-226号文]] 确立的供应链金融框架、[[供应链票据平台]] 及 [[鲁政办发2023-16号实施意见]] 的财金联动政策直接呼应。

## 保障措施

省工信厅成立金融促进工业和信息化高质量发展领导小组，按年度明确要点、按季度调度、按月督导；开展"三进一联"（进产业、进园区、进集群和联企业）投融资专项对接。
