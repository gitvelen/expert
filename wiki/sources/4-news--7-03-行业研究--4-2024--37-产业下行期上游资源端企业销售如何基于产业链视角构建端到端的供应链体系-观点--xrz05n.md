# 产业下行期，上游资源端企业销售如何基于产业链视角构建端到端的供应链体系（观点，万联网 2024-11-11）

## 摘要

万联网原创观点文章，作者黄贵生（万联网首席产业互联网专家、原东煤交易总裁）。核心论点：大宗商品三五年一个库存周期，经济大周期下行叠加库存周期时，产业链话语权向下游转移，下游决定交易、定价、结算与交割模式；上游资源端企业应以销售为导向构建端到端数字化供应链平台，为生态圈成员提供低成本运营环境，实现降本增效并探索增收路径。文章以宝武旗下[[欧冶云商]]（2015）与陕煤旗下[[秦岭数字]]（2022）为双案例，并提出发展物流业务（网络货运）与双购销/委托加工两条增收路径。

## 核心论点

1. **周期视角**：大宗商品三五年一个库存周期，价格上行期资源端坐地收钱，下行期"订单为王"、话语权在下游；部分大宗商品价格跌幅高达90%（文中称，未注明具体品类与时点）。
2. **端到端销售体系**：不是内部采购到销售的体系，而是与客户紧密联系、向下游延伸的数字化供应链体系，链接"制造现场到用户生产现场"（钢厂到炉口、坑口到炉口）。
3. **科技平台三种构建模式**：集团科技部门负责 / 依托销售体系构建 / 与科技公司合资。作者经验性判断：**销售体系驱动的平台更易成功**，"好系统是改出来的不是建出来的"；应用与建设分离很难成功（观点，无量化证据）。
4. **增收模式**：网络货运（货主优势转物流收入，重操作，文中未展开）；双购销/委托加工与中间品加工企业深度合作增收（"收入倍增或至少1.3倍增收"为作者口径，具体操作文中不详述，**未独立验证**）。

## 案例对照

| 维度 | 欧冶云商 | 秦岭数字 |
|---|---|---|
| 成立时间 | 2015年2月（钢价低谷期） | 2022年12月（煤价转折下行期） |
| 股东背景 | 宝武集团 | 陕煤集团 |
| 端到端 | 从钢厂制造现场到用户生产现场 | 从煤矿"坑口"到用户"炉口" |
| 生态圈 | 上游制造企业＋贸易商、资讯、仓储、金融、加工中心、物流机构 | 上游煤矿企业＋同类中间服务机构 |
| 核心价值 | 降本增效：降低交易、物流、资金成本，提升交易/交付效率 | 与欧冶一致 |
| 核心方案 | 场景数字化、业务化、平台化，生产性互联网综合解决方案 | 与欧冶一致 |
| 平台/产品 | ouyeel.com、bsteel.com.cn（东方钢铁循环宝）、ouyeelbuy.com（欧冶采购MRO）、ouyeelintl.com（欧冶国际跨境） | 一站式能源供应链产品体系（原文为图片，未文字化） |

- 欧冶云商**三个定位**（出自欧冶招股说明书）：大宗商品交易的服务者、基础设施的提供者、信用体系的构建者——为生态圈成员提供低成本运营环境，聚合全生态圈数据形成大数据智能决策。
- 价值判断标准：贸易商通过平台能否实际降低吨钢人工、物流、资金成本；"如果不能降低基本上毫无价值"。

## 关联与张力

- 与 [[生产性互联网服务平台-两网融合-黄贵生口径]]、[[云工厂模式-产业集群口径]] 方法论一脉相承，本文是其在上游资源端企业销售视角的应用扩展。
- "信用体系的构建者"定位与 [[脱核不离核]] 中核心企业建平台、构建数据信用的思路呼应。
- **潜在张力**：双购销模式若贸易背景不实，可能触碰"十不准"下虚增收入红线，参见 [[查询-双购销模式与十不准虚增收入红线的合规边界]]。

## 证据强度分层

- **专业公众号分析（中）**：双案例结构分析、"三个定位"经典论述（转引自欧冶招股说明书）。
- **作者经验性判断（弱-中）**：销售体系驱动的科技平台更易成功。
- **作者演讲口径（弱，待验证）**："1.3倍增收/收入倍增"、价格跌幅90%等数字均无出处，勿作为事实引用。
