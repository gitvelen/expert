# “今年营收要翻倍？”一位行业老炮对“十不准”有感而发（观点，万联网 2024-02-02）

## 来源基本信息

- 发布：万联网（原创），2024-02-02
- 作者：匿名从业者，自述十余年大宗商品流通服务经历（代采 → 重度参与物流 → 区域深耕与全产业链延展）
- 性质：**专业公众号观点文章**，全部为作者个人业务经验与判断，无数据支撑，非监管认定
- 文末为 2024-03-01 郑州“6位行业老炮”培训活动导流，与 [[sources/4-news--7-03-行业研究--4-2024--40-50多家国企供应链公司150多位高层2天1夜齐聚郑州跟6位实战老师都学了啥-趋势--eoab4t]] 构成“预热 → 复盘”证据链

## 引子与总体判断

- 开篇轶事：某国企供应链公司朋友称 2024 年考核指标“营收要翻倍”——与“十不准”形成制度性张力。
- 作者判断：本轮“十不准”引起的讨论热度和企业焦虑**远大于 2017 年国资财管〔2017〕652号文**；当前“从事疑似业务”的国企大多是 2017 年之后进入的。
- 肯定贡献（个人口径，证据弱）：国企进入有效解决一批民企资金需求，使民企资金使用成本“从 14.4% 起降到 8% 起”。
- 核心结论：出路 = **合规 + 从服务“贸易商”转型到服务“工厂”**（区域云工厂方向），慢但能构建壁垒，“半年能见效”。

## “十不准”逐条业务侧解读（观点性内容）

| 条款 | 作者解读要点 |
|---|---|
| 一、不准开展背离主业的贸易业务 | 背离主业的国企贸易公司是民企“割肉”目标画像（主业在外、团队外行、属地外省）；建议沿主业延展产业链或深耕本省市产业集群（“势力范围”内不会被当外人宰）；煤炭、石化、矿产、粮食等品类有“集团董事会批准保留”的活口 |
| 二、不准参与特定利益关系企业间无商业目的贸易 | 客户开始“脱敏”（成立非关联公司）；国企的“根”要扎到最终原料供应商/最终用户端或成为仓储方，两端“不扎根”被“包饺子”不出事是偶然；风险取决于参与运营深浅而非是否特定利益关系 |
| 三、不准人为增加不必要的交易环节 | 前半部分“对标”某已暴雷的号称全球 500 强供应链集团（影射雪松类“盖章套环”模式：一笔一个亿多套 8 圈放大营收，未点名、未经证实）；后半部分针对大型集团内部上下游交易因“不能赊销、不能预付”而引入贸易商的“通道刚需”，若堵死需改央企内控体系 |
| 四、不准开展任何形式的融资性贸易 | 引用 652 号文四大特征；回顾合同从“多协议 + 利息/本金条款”简化到纯销售合同甚至抽屉协议——形式合规化反而使客户更易钻空子；明确主张“不能以贸易方式做融资”；引申称“缺乏货权掌控必须严格禁止”同样适用于“连贸易公司都没有的机构”（暗指银行混业，个人引申）；出路是银行出资金、国企做“信用管理人/信用代理人” |
| 五、不准开展无控制权的空转、走单贸易 | 区分法律/财务意义控制权与实际处置能力；瞬时货权、铁路运单不体现所有权变更是行业常态瑕疵；“货到地头死”——非枢纽产地无置货处置能力；口诀“**不做旧货、不做地头货、不做民营库、不做客户仓**”；自建仓库应围绕产业集群（主业相关、地区可控、有产业密度） |
| 六、不准开展无商业实质的循环贸易 | “考核惹的祸”——规模考核驱动循环贸易；建议“向内求”，在省市县产业集群原料端做集采平台 |
| 七、不准开展有悖交易常识的异常贸易 | 内控太差所致；举例物流服务手册更新 n 版、几百页，按运输方式拆分操作细节与风险点并固化到系统 |
| 八、不准开展高风险非标仓单交易 | 仓单是专业领域，国外有成熟体系，国内仍在发展中 |
| 九、不准违反会计准则确认代理贸易收入 | 回忆“N 年前想记净额收入被税务否定”；肯定净额法可减少规模要求型业务（回填 [[concepts/净额法与代理角色做大营收动机]]） |
| 十、不准在内控机制缺乏的情况下开展贸易 | 去掉一把手同意权只留否决权；决策流程、内控岗、制度流程表单与系统建设；出问题多在控货环节（物流/仓储/盯市/巡检/质检制度）；**内控只能防“愚蠢级”错误，产业周期下行才是最大挑战，必须改商业模式** |

## 后续路径主张（文末）

- 从托盘贸易向产业链集成服务升级（物流、轻加工、价格管理），再向产业链整体运营商升级。
- 从信用责任人转型为信用代理人，与银行成为一致行动人，为银行批量拓客、共建行业“芝麻”信用。
- 深耕地方产业集群，服务客群从贸易商转到制造企业，构建区域云工厂（共享仓储、共享原料、共享中间工序、共享研发、共享模具）。

## 矛盾与张力

- 作者内部张力：既肯定国企贡献并坚决赞同整改，又指出“营收要翻倍”考核正是循环贸易根源，未给解法。
- 合规化悖论：合同为满足审计不断简化，形式合规反而削弱对客户约束、放大风险。
- 影射性表述：第三条未点名企业（语境指向 [[entities/雪松控股]]），引用须保持“影射、未经证实”标注。

## 证据强度

全部为单一匿名从业者个人经验与观点（专业公众号观点口径、可信度层级下位），适合作为转型方向的“专家共识”旁证，不宜作为事实性 finding 单独固定；“14.4%→8%”等数据仅作口径快照存疑记录。
