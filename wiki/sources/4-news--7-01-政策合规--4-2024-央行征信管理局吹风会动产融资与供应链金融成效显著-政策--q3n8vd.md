# 央行征信管理局吹风会：动产融资与供应链金融基础设施成效

2024年4月10日国务院政策例行吹风会（主题为《统筹融资信用服务平台建设提升中小微企业融资便利水平实施方案》），中国人民银行征信管理局局长任咏梅答记者问，披露征信市场与动产融资基础设施的**官方最新数据**（本源为万联网 2024-04-11 转载实录）。

## 核心数据速览（截至2024年3月末）

| 指标 | 数值 |
|---|---|
| 动产融资统一登记公示系统累计登记 | **3445.5万笔** |
| 动产登记系统累计查询 | 2.1亿次 |
| 应收账款融资服务平台累计促成融资 | **51.2万笔** |
| 金融信用信息基础数据库接入法人机构 | 6124家 |
| 数据库收录 | 11.6亿自然人、1.3亿户企业和其他组织 |
| 2023年数据库查询服务 | 53亿次 |

对比既有存档数据可看出增速：[[动产融资统一登记公示系统]] 截至2021年9月累计登记1265.76万笔 → 2024年3月3445.5万笔（约2.7倍）；[[中征应收账款融资服务平台]] 截至2016年5月促成融资近3.6万笔 → 2024年3月累计51.2万笔。

## 征信市场"政府+市场"双轮驱动

- **个人征信**：先后批设2家个人征信机构，2023年提供信用报告、信用评分、反欺诈评分等服务达420亿次。
- **企业征信**：引导"有数据、有技术、有市场"的机构进入，2023年149家企业征信机构提供服务223亿次。
- **地方征信平台市场化转型**（见 [[地方征信平台]]）：31家省级地方征信平台中**26家由专门设立的市场化机构运维**，全面采集当地企业公共信用信息与商业信息。

下一步：优化征信市场布局（大数据、AI产品创新）、会同发改委推动信用信息平台依法向征信机构开放数据（"数据乘数效应"）、"强监管、严监管"将所有征信活动依法纳入监管。详见 [[多层次征信市场]]。

## 对供应链金融的意义

1. **动产融资登记扩围在即**：下一步"进一步扩大动产融资统一登记公示系统的**登记范围**"——登记范围扩展（如活体、知识产权等新型动产）直接决定存货/仓单融资的可确权边界。
2. **应收账款融资平台加大推广**：与"金融25条"第（三）（二十二）条（[[中征应收账款融资服务平台]]）的"完善平台功能、加强应用"要求一脉相承。
3. **支付资金流信息共享**："研究推动中小微企业**支付资金流信息的共享应用**，形成与信贷信息互补的服务格局"，惠及无信贷记录的小微企业——为交易数据征信化（[[供应链脱核模式]] 的数据信用路径）提供央行层面的基础设施支撑。
4. 融资信用服务平台实施方案本身（国办发〔2024〕15号，"一省一平台"原则）已入编：[[4-news--7-01-政策合规--4-2024-国办15号文统筹融资信用服务平台一省一平台-趋势--m8k4tv]]，与本吹风会同属一个政策包。

## 开放问题

- 登记范围扩大的具体品类与时点（是否覆盖大宗商品仓单、碳配额等）。
- 支付资金流信息共享与商户数据保护、断直连整改的边界。
