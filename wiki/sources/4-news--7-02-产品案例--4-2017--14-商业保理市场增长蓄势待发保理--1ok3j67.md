# 商业保理市场增长蓄势待发（银行家杂志，2017）

《银行家》杂志署名文章（作者徐飞、陈卉，单位国金证券），经公众号"贸易金融"2017-01-04 转载。全文是 2017 年初对中国商业保理行业的市场综述，覆盖历史沿革、业务分类、市场规模、发展模式（"反保理"与信息平台）、行业特点、前景与问题，属"专业媒体/分析"可信度层级。

## 核心数据快照（2015 年口径，历史数据）

| 指标 | 数值 |
|------|------|
| 世界保理市场排名（FCI 2015 年报） | 中国大陆第二（仅次于英国）；2011–2014 年为第一 |
| 商业保理企业注册数（2015 年末） | 2514 家（新增 1294 家，同比 +144%） |
| 2015 年商业保理业务量 | 超 2000 亿元（较上年 +1.5 倍） |
| 开业比例 | 约 20%（假设值），约 500 余家开业公司服务 31500 家中小企业 |
| 户均融资额 | 635 万元（基于 20% 开业比例假设的推算值） |
| 银行保理业务量 | 2.3 万亿元，占保理市场约 92% |
| 国内/国际保理份额 | 约 64% / 36% |
| 采用"反保理"模式的商业保理公司 | 超 81%（商务部 38 家抽样调查，样本有限） |
| P2P 融资成本 | 8%–12%；保理应付账款融资利率 10%–15%；管理费约 0.5% |
| 商业保理杠杆上限 | 10 倍 |
| 工业企业应收账款余额 | 约 11.5 万亿元（截至 2016 年 5 月，与营收增速差值 5.9%） |

## 主要论点

- **保理定义与分类**：保理即保付代理，指企业赊销产生的应收账款转让，由保理机构提供资金融通、进口商资信评估、信用风险担保、销售账户管理、账款催收等综合金融服务。按服务内容分为有追索权、无追索权、单保理、双保理、融资保理、到期保理六大类；按经营主体分为银行保理与商业保理。
- **发展模式**：①"反保理"——超过 81% 的商业保理公司采用，依托供应链核心企业信用为上下游中小企业融资，根源是征信体系缺失与央行征信系统未开放；②信息平台合作——与第三方支付、电商平台、物流企业合作，借助交易历史与货物信息大数据风控。
- **行业特点**：重融资、轻担保；以有追索权保理、单保理为主；业务实质是应收账款抵押贷款而非综合保理服务，收入以利息为主而非服务费。融资渠道依次为股东资金、银行授信、ABS、P2P。
- **前景逻辑**：应收账款规模与增速双高、社融下行与银行不良率逼近 2% 警戒线加剧中小企业融资难、民间投资下滑寻求出口——商业保理迎机遇（属趋势推演的分析观点）。
- **问题清单**：无专门保理立法（质押优先顺序、转让通知等无法可依）；外汇与税收无国家层面规范；市场认知度低、开业率低；央行征信系统未向商业保理开放；经济下行期坏账风险。

## 内部张力与标注

- 文章一方面称商业保理"门槛较低、监管宽松、杠杆最高 10 倍"是优势，另一方面指出法律缺失、无法可依——优势与风险同源，需并存呈现。
- "户均 635 万元"基于 20% 开业比例假设，是推算值而非统计值。
- 国际保理 36% 份额与"双保理应用不多、以单保理为主"并存，暗示国际业务可能以出口单保理为主，细节待考。
