# 央行修订应收账款质押登记办法（贸易金融，2015-01-30）

2015年1月21日，[[中国人民银行]]对外公布《[[应收账款质押登记办法]]（修订征求意见稿）》，向社会公开征求意见。修订涉及六个方面，其中对保理行业最关键的是附则中新增应收账款转让登记条款。

## 六项修订要点

1. **附则增加应收账款转让登记规定（第三十二条）**：截至2014年底，[[应收账款质押登记公示系统]]记载59.5万余笔应收账款转让登记，占登记总量45%；21家全国性商业银行、300多家保理公司为主要用户。新增条款："权利人在登记平台办理保理业务当中的应收账款转让登记，参照本办法有关规定"。司法佐证：2014年11月19日天津市高级人民法院审理保理合同案件审判委员会纪要，明确在征信中心登记系统进行登记与查询可产生对抗善意第三人的司法效力。
2. **修改完善应收账款定义（第二条、第四条）**：详见 [[应收账款定义扩围2015]]。
3. **取消登记协议上传要求（第八条、第十条）**：降低操作成本，但实质上放弃了对恶意/虚假登记的事前防范。
4. **若干登记事项修改（第十条、第十二条、第十三条、第十五条）**：登记内容增加主债权金额及主债权合同信息；登记期限由5年延长至30年并删除届满失效规定（回应经营性公路收费权30年的行政法规）；出质人信息变更时限由4个月缩短为30日，并删除"未办理变更登记的，质押登记失效"条款。
5. **修改登记机构撤销异议登记的规定（第二十一条）**：删除登记机构根据当事人起诉情况主动撤销异议登记的规定，因法律未授予登记机构对登记事项真实性的实质审查权。
6. **增加登记费用条款（第三十一条）**：登记服务为有偿服务。另增加应收账款质押定义（第三条）、修改登记系统表述（第四条）、修改异议登记通知时限（第二十条）、增加仲裁裁决作为撤销登记依据（第二十一条）、增加征信中心信息安全保护义务并删除不可抗力条款（第二十八条）。

## 结构化条款映射（原文保留）

| 条款 | 修订内容 |
|---|---|
| 第三十二条 | 保理项下应收账款转让登记，参照本办法有关规定 |
| 第二条 | 应收账款定义扩围与排除条款 |
| 第三条 | 增加应收账款质押定义 |
| 第四条 | 列举范围扩大、登记系统表述 |
| 第八条、第十条 | 删除登记协议上传；登记内容增加主债权信息 |
| 第十二条、第十三条 | 登记期限5年→30年，删除届满失效 |
| 第十五条 | 出质人信息变更4个月→30日，删除未变更则失效 |
| 第二十条、第二十一条 | 异议登记通知时限；删除主动撤销；增加仲裁裁决依据 |
| 第二十八条 | 征信中心信息安全义务，删除不可抗力条款 |
| 第三十一条 | 登记收费 |

## 证据强度与关联

- 数据来自登记系统官方统计；司法效力佐证为天津高院正式纪要，强度中等偏强。注意第32条仅为"参照"适用，效力层级弱于正文规定。
- 主题上与保理监管框架系列互补（[[自贸区商业保理监管框架2015]]、[[商业保理企业管理办法2015]]、[[商业银行保理业务管理暂行办法]]），补充动产融资登记基础设施维度；并与 [[应收账款转让通知生效主义]]、[[债权转让通知对抗主义]] 形成"登记 vs 通知"公示方式对照。
