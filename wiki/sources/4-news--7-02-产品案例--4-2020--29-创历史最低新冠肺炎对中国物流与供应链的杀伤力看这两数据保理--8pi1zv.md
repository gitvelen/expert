# 创历史最低！新冠肺炎对中国物流与供应链的杀伤力看这两数据

公众号"供应链金融"2020年3月2日转载中物联科技部的官方指数发布：2020年2月中国物流业景气指数（LPI）与制造业PMI双双创历史性深跌，是新冠疫情对中国物流与供应链冲击的官方宏观数据记录。

## 核心数据

| 指数 | 2020-02值 | 环比变化 |
|---|---|---|
| 物流业景气指数 | 26.2% | -23.7pp |
| 仓储指数 | 39.0% | -12.1pp |
| 制造业PMI | 35.7% | -14.3pp |
| 生产指数 | 27.8% | -23.5pp |
| 采购量指数 | 29.3% | -22.3pp |
| 新订单指数 | 29.3% | -22.1pp |
| 新出口订单指数 | 28.7% | -20.0pp |
| 从业人员指数（PMI） | 31.8% | -15.7pp |
| 购进价格指数 | 51.4% | -2.4pp |
| 出厂价格指数 | 44.3% | -4.7pp |
| 产成品库存指数 | 46.1% | +0.1pp |

## 物流景气指数分项

- 业务总量指数 26.2%（-23.7pp）：供应链上下游物流运行出现暂时停滞休眠
- 设备利用率指数 39.1%（-11.1pp）：物流企业产能下降、设备设施利用率不足
- 从业人员指数 30.1%（-18.5pp）：复工延迟、员工返岗率低于正常水平
- 业务活动预期指数 44.9%（-6.7pp）

## 两类解读口径

- **何辉（中国物流信息中心主任，官方口径）**：疫情影响"短暂、可控"，复工复产加快，被抑制需求将释放，后市将出现"快速的恢复性增长"。（发布时点观点性预测）
- **张立群（特约分析师，谨慎口径）**：春节分布于1月，2月PMI本应环比上升、实际大幅下降，足见冲击力度；预计1-2月及一季度主要经济指标大幅下降，"必须充分估计，做好应对预案"。
