# 物流成本VS库存：供应链管理的出路究竟在何方？（供应链管理，2017）

2017年10月15日由"供应链金融"公众号转发的观点性文章，作者为 [[程晓华]]（TIM 全面库存管理咨询独立顾问，《制造业库存控制技巧》作者）。文章面向"供应链管理到底管什么"这一问题，给出作者个人的方法论回答，属"04-业务基础"理论层材料，非监管或风险案例类内容。

## 核心论点（程晓华个人口径，观点性内容）

1. **C-I 双基本点论**：供应链管理的根本目的是管 C（cost，成本）与 I（inventory，库存）。详见 [[成本与库存CI双基本点论-程晓华2017口径]]。
2. **实践中 C 压倒 QD(S)**：寻源采购的核心 KPI 是 CR（cost reduction），物流以运输/仓储/清关成本为重心；因"成本比较容易出成绩"，实际工作中普遍出现"买的便宜，用的贵"，牺牲品质（Q）、交付（D）、服务（S）。
3. **C 与 I 交织**：为控成本，生产制造可能牺牲库存，C vs I 是供应链管理部门与生产运营部门斗争的焦点；把 C 扣得太紧必然导致 I 控制不力，因此其"全面库存管理审核"延伸至寻源采购与 T&C 合同条款（呆滞责任、付款条件）。
4. **I 的双重含义**：库存本身（原材料/成品/半成品，含供应商与客户处的库存）+ 交付（delivery，即"库存的转移"）。库存控制与及时交付是"一码事"：在合适的时间持有合适的数量，交付就不成问题。
5. **库存 = 计划产物 + T-Q 执行错位**：计划（需求/生产/采购/库存计划）是供应链的灵魂；但从执行角度，库存是时间（T-timing）与数量（Q-quantity）的错位问题，计划再好、执行不到位则库存依然堆积。
6. **T、Q、M → 三流合一**：I 是 T+Q 问题，C 是 M（money）问题，最终归结为信息流（information flow）、物流（materials flow）、资金流（cash flow）的"三流合一"。

## 附属框架

- **QCDS**：品质、成本、交付、服务的取舍框架（作者指出实际工作中 C 占据重心）。
- **5R 理想状态**：合适的产品，以合适的价格，在合适的时间，以合适的数量，到达合适的地点；因客户化需求波动只能逼近而无法完全达成。

## 证据强度说明

全文为作者个人经验性论断，无数据、案例或引用，按可信度分层属"专业从业者观点"，只作观点口径记录，不作 findings 事实来源。
