# 供应链金融的产生机制（网盛供应链研究院，2020）

2020-03-05 发布于“供应链金融”公众号（栏目 1081），来源 [[entities/网盛供应链研究院]]。属科普/综述性文章，以杜撰的“外地人100元化解小镇连环债”故事引入，解释供应链企业间赊购赊销形成的复杂债权债务关系（“三角债”），进而给出 SCF 产生机制、定义、主流模式与适用行业，末尾补充 3D1C（DOI/DSO/DPO/CCC）资金收付时间框架与供应链金融资产证券化四种实操形式。全文为业内通行框架的复述，证据强度属“一般公众号/行业媒体”层级。

## 核心内容

1. **产生机制（观点）**：链上企业普遍压缩 DSO、拉长 DPO，某时段现金净流入为负；“很多企业倒闭不是因为亏损，而是因为资金链断裂”。SCF 围绕供应链中的真实交易，（事中/延时）为交易环节注入资金，帮助链上企业盘活流动资金。
2. **SCF 定义（作者典藏口径）**：SCF 是根据交易对手、行业规则、商品特点、市场价格、运输安排等交易条件，为供应链上不同交易层次和交易地位的交易主体度身定制的专业金融解决方案。
3. **担保物扩展（观点）**：将传统信贷“重房产、重抵押”的担保条件扩展到会计学定义的“资产”范畴，降低融资门槛。
4. **主流模式“核心企业决定论”（观点）**：融资金额/周期/利率取决于交易主体的资源禀赋、展业能力、上下游关系紧密度与谈判地位；“在过去和将来可预见的若干年内”，国有企业、上市公司等核心企业对方案要素起决定性作用。两类适用场景：
   - 核心企业为制造商/销售方，为扶持下游经销商授信（典型产品：保兑仓、厂商银、国内卖方信贷）；
   - 核心企业处于买方地位、上游链条长且供应商体量小数量多——典型为 E信模式，将核心企业信用与付款能力辐射至直接/间接供应商，代表为 [[entities/中企云链]] 的“云信”、中铁建的“银信”。
5. **去中心化前瞻（2020 观点）**：随物联网、区块链应用，SCF 交易结构将向“去中心化”发展，更多关注“交易关系”与“交易标的”本身。
6. **适用行业**：制造、商贸（批发零售）、工程项目三个传统行业为主，另分布于农业、养殖业、物流运输业、民生服务业等不符合传统抵押信贷要求的领域。

## 结构化内容（保留原表述）

**3D1C 与 CCC 计算关系**：

```
DSO =（年平均应收账款金额 / 年销售成本）× 365
DPO =（年平均应付账款金额 / 年销售成本）× 365
CCC = DOI + DSO - DPO
```

- DOI（days of inventory outstanding）：存货天数；DSO：应收账款天数；DPO：应付账款天数（从收到供应商货物到支付货款的时间）。
- CCC > 0：资金流入天数比流出天数长，产生“资金缺口”（时间空洞）；CCC < 0：企业获得“资金盈余”。

**供应链金融资产证券化四种实操形式**：

1. 基于央企、国企、上市公司等优质主体的应收账款资产证券化；
2. 以互联网电商平台为主导的保理债权资产证券化；
3. 基于产业链核心企业的反向保理资产证券化；
4. 基于信用证、保函、保贴的贸融类应收账款资产证券化。
