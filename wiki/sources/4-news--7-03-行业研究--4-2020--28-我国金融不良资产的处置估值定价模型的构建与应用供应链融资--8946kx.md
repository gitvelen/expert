# 我国金融不良资产的处置估值定价模型的构建与应用

## 概述

本文原为一篇学术/实务论文，作者张洪涛、杨宏略，单位为中国长城资产管理公司武汉办事处，2020-04-20 由"供应链金融"公众号转载。核心内容是基于武断定价（arbitrage pricing）理论提出不良资产（主要是不良债权）处置估值定价模型，包含参数体系、计算公式与可行性分析。对知识库而言属于**边缘相关资料**：不良债权/抵质押物处置估值是供应链金融风险出清环节的定价工具，但主题偏 AMC 处置而非供应链金融主流产品。

## 现行定价体系的五大问题（作者批判性前提）

1. 建立在有效市场假设之上，脱离中国实际，评估价格偏离市场价值；
2. 脱离处置实践，未综合处置历史规律及相关信息；
3. 缺乏适应性，过分倚重资产内在价值分析，未发掘交易中的价格提升空间；
4. 权属不明确、债权债务关系复杂的资产定价主观判断多于理性判断，定价依据不充分；
5. 固定因素套用固定模式或单纯依赖评估人员主观判断，未综合处置历史规律、市场行情、资产经营潜力与发展前景，定价流于形式。

## 理论基础

国际金融界普遍认为中国金融市场当时尚处于无效状态、或无效与弱势有效临界点，信息不对称严重。武断定价理论认为：市场非有效时缺乏市场参考价格信息，估值不能完全采用市场定价，须从不同角度考察资产价格、建模建立交易价格基准判断，而非单纯依赖评估价格。金融学理论将影响资产价格的因素分为不确定性、能力性、信息性三类，不良资产价格相应由不确定性价格、能力性价格、信息性价格三部分组成（详见 [[concepts/不良资产武断定价理论三因素价格框架]]）。

## 模型公式（原文口径）

```
公式Ⅰ：拟处置价格 = 待处置资产清算价格 × 待处置资产回收率
公式Ⅱ：待处置资产回收率 = 评估变现率 + 交易方风险偏好 + 提升系数
                        + 营销系数 + 关联信息调整系数 + 随机因子
其中：评估变现率 = 评估价格 / 待处置资产清算价格
回归式：Y = α + β1X1 + β2X2 + β3X3 + β4X4 + β5X5
Y = 待处置资产回收率；α = 评估变现率；X1–X5 ∈ [−100%, +100%]，
依次为交易方风险偏好、提升系数、营销系数、关联信息调整系数、随机因子；
β1–β5 由资产公司分区统计抽样、回归分析并验证显著性后确定；
某参数信息缺失时其修正值取零。
```

公式Ⅱ 为模型核心，全部参数以百分比表示；使用加法是因为各参数为分层次的价值部分，依价值相加原理可通过加权平均调整。详见 [[concepts/不良资产估值定价模型-评估变现率加五项修正参数-长城资产口径]]。

## 六参数内涵

| 参数 | 类型 | 内涵 |
|---|---|---|
| 评估变现率 | 核心参数 | 评估机构评估、测算、分析而来的待处置资产即时变现率（属不确定性价格因素） |
| 交易方风险偏好 | 修正参数 | 交易方投资不良资产的风险承受能力，靠历史交易对象主观判定或专家评价法取得 |
| 提升系数 | 修正参数 | 通过资产重组等处置手段提升资产内在质量与价值所获超额收益幅度 |
| 营销系数 | 修正参数 | 细化资本市场、运用营销手段、引入充分竞争后形成的价格调整空间 |
| 关联信息调整系数 | 修正参数 | 通过交易方关联方、竞争对手、主管部门、工商税务等渠道掌握背景资料后确定的谈判价格调整幅度 |
| 随机因子 | 修正参数 | 高层决策、政策性原因、市场变化、宏观形势、竞争激烈程度等随机因素确定的价格调整幅度 |

## 操作步骤

1. **定价尽职调查**：确定评估价格所需资料 + 收集确定修正系数的信息（专家评定、实地调查、间接收集）；
2. **评估定价**：由评估部门取得评估变现率；债权资产需尽调债务人主体情况、债务关系合法性与时效性、抵（质）押资产所有权及现状、保证合同时效性与保证人偿债能力、是否涉诉等；
3. **确定修正系数及权重**：对定性因素设定等级标准评分，再用回归分析按相关性设定权重、加权平均汇总；
4. **套用公式Ⅱ、公式Ⅰ** 计算交易价格标准，作为谈判目标价位。

## 可行性与自认局限

可行性四点：AMC 信息库保证数据可得；专业判断弥补评估人员对处置业务和市场熟悉程度的不足；与市场行情结合，具备价值发现功能；以评估价格为核心进行修正，适用于任何形态、任何组合形式的资产。

自认局限：模型以评估价为核心，继承评估的时效性缺陷；提升系数、营销系数与各项信息均动态变化，动态分类管理信息只能部分弥补，"无法彻底解决定价和市场不能及时同步变动的问题"。

## 证据强度

属"专业机构从业者论文"层级（高于一般公众号分析、低于监管原文），但为 2020 年前后转载、年代较久，且模型未给出实证验证数据，β 权重确定依赖大量历史数据仓库——更多是方法框架主张而非已验证结论。引用时应保留作者自认的时效性 caveat，并注意"能力性价格因素"中"利用资产公司在交易市场的垄断地位优势"表述与知识库产业本位立场的语境差异。

## 与知识库的关联

不良债权与抵质押物处置估值是动产融资风险出清的下游定价环节，可补充知识库"资产处置与估值"空白方向；与 [[concepts/供应链金融欺诈六分类与六化原则风控框架-2020口径]] 等风控类概念互链（不良资产处置是风控失败的下游环节）。
