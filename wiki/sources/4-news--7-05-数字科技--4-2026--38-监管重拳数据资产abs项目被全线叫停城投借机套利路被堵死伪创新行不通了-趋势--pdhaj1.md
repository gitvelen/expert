# 监管重拳！数据资产ABS项目被全线叫停：城投借机套利路被堵死，伪创新行不通了

## 事件概要

2026年6月3日，沪深交易所通过窗口指导方式，全面暂停数据资产ABS的申报与发行审核流程，已过会项目亦被暂停封卷。新项目、已过会项目及已拿批文的存量项目均被按下暂停键。

## 叫停背景：野蛮生长

数据资产ABS市场在2026年前5个月出现爆发式增长，远超2025年全年水平：

| 指标 | 2025年全年 | 2026年前5个月 |
|------|-----------|--------------|
| 落地/发行单数 | 11单 | 21单 |
| 融资总额 | 45.9亿元 | 154.33亿元 |

全市场累计申报数据（截至叫停前）：

| 指标 | 数值 |
|------|------|
| 累计申报项目数 | 88单 |
| 累计申报总规模 | 接近2000亿元 |
| 深交所申报项目数 | 75单 |
| 深交所申报规模 | 约1679.88亿元 |
| 上交所申报项目数 | 13单 |
| 上交所申报规模 | 316.54亿元 |
| 在审项目数 | 近70单 |

| 单笔融资额区间演变 | 10亿元以内 → 30~60亿元 |

## 叫停核心动因

### 1. 市场全面跑偏

数据资产ABS设立的初衷是帮科技企业或国企盘活沉睡数据，靠真实数据运营收入融资。但真正靠纯数据现金流支撑的项目不足2%，绝大多数项目偏离产品设计初衷。

### 2. 城投非标转标套利

大量区县级城投平台将数据资产ABS当作变相融资提款机：
- 打着智慧停车、政务运维幌子，将权属模糊的公共数据包装入表
- 底层资产实为非标债权或信托贷款
- 数据不起作用、不产生实际现金流，仅作增信噱头7
- 投6兑付依托城投主体信用和第三方担保兜底
- 本质：9;非标转标套利，变相增加地方隐性债务

### 3. 合规底线缺失

按财政部规定，数据要变成资产须走完确权、审计、估值整套流程。实际大量项目：
- 未走完数据资源入表法定流程
- 无对应数据运营收入台账
- 无会计师出具专项入表鉴证报告
- 账面不存在对应数据资产
- 仅凭罗列几个数据名称即申报ABS

### 4. 券商批量承揽

券商为赚承销费批量承揽不合规项目，导致伪创新产品充斥市场。

## 影响研判

- **短期**：所有在审和待发行项目原地踏步，储备项目暂停等待新规
- **中介机构**：靠宽松审核环境快速赚通道费的日子结束
- **预期**：交易所将出台细致审核细则，重点盯防数据入表规范、底层现金流核验及城投主体准入
- **长期定调**：数据要素资本化国家方向不变，监管意图是挤干水分、去伪存真
