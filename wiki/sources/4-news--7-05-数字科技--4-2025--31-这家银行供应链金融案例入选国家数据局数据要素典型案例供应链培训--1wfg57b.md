# 浙商银行供应链金融案例入选国家数据局"数据要素×"典型案例

## 来源概要

2025年11月，浙商银行"数据要素赋能供应链金融 助力产业链高质量发展"案例入选国家数据局会同中央网信办、工业和信息化部、国家金融监督管理总局、中国证监会发布的第三批"数据要素×"金融服务领域典型案例。来源为浙商银行微讯官宣，由"供应链金融"公众号转载。

## 核心主张

### 主张1：案例入选第三批"数据要素×"典型案例

国家数据局等五部门正式发布第三批"数据要素×"金融服务领域典型案例，浙商银行案例成功入选。属官方发布+银行官宣，可信度高。

### 主张2：多维度信用数据整合解决传统供应链金融四大痛点

| 传统痛点 | 数据维度应对 |
|----------|-------------|
| 操作流程长 | 多渠道数据直连替代人工尽调 |
| 授信审批难 | 工商/税务/发票等强化主体识别 |
| 技术对接慢 | 标准化数据接口嵌入场景 |
| 业务规模小 | 纯信用+小额高频实现规模扩展 |

数据维度清单：工商、税务、发票、水电气、运费、仓储物流。

### 主张3：运营数据快照（截至2025年8月末）

| 指标 | 数值 |
|------|------|
| 累计发放融资 | 超9000亿元 |
| 累计服务核心企业 | 超3700家 |
| 延伸上下游客户 | 超9万户 |
| 五篇大文章客群占比 | 近90% |

### 主张4：中小企业占产业链工业企业比例超95%

引用党的二十大报告战略部署，属政策原文+广泛引用的统计口径。

## 关键概念标记

- **"四通一链一白条"**：浙商银行供应链金融创新服务模式的产品组合名称，本源未展开各子产品定义。
- **"行业化+嵌入式"**：场景化服务范式，形成"全链条、全场景、全产品、全生态"综合服务。
- **"数据流通难、价值变现慢"**：金融业数据要素应用的共性瓶颈。

## 张力与缺口

1. **"纯信用"与风控可持续性**：强调"纯信用"融资但未披露不良率数据，与规模扩张声明存在张力。
2. **"五篇大文章客群占比近90%"口径模糊**：科技金融、绿色金融、普惠金融等分类存在交叉，90%占比的实际含义取决于统计口径与去重规则，本源未说明。
3. **"四通一链一白条"未展开**：各子产品定义与适用场景完全Cite缺失。
4. **数据获取合规路径@&授权8授权路径**：税务、发票等政务数据的合规授权路径未"未涉及，对可复制性至关重要。
