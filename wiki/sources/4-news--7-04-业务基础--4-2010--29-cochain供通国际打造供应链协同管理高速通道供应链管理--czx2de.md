# Cochain供通国际：打造供应链协同管理高速通道

2010-08-31《国际商报》刊发、经中国贸易金融网转载的企业宣传类文章，主体为[[entities/国富通信息技术发展有限公司]]自主研发的 [[entities/Cochain供通国际供应链平台]]。内容分两部分：供应链协同管理的通识论述 + Cochain 产品方案介绍。证据强度：低（专业媒体转述 + 厂商宣传口径）。

## 一、通识论述部分（2010 年口径）

- 开篇引杰克·韦尔奇（通用电气）语："如果你在供应链运作上不具有竞争力的话，就干脆不要竞争"。**出处未标注，系二手转引**，注意"名言转嫁"风险。
- 供应链定义：以过程观描述企业活动，从原材料获取到最终产品交付给最终用户的"供-需"环节有序链接过程。
- 供应链协同管理定义：对供应链所涉及组织的集成和对物流、信息流、资金流的协同，以满足用户需求和提高供应链整体竞争能力。
- 协同三前提：①基于技术和 Internet 的信息与知识创新成果共享；②各节点企业树立"共赢"意识；③在信任、承诺和弹性协议基础上合作。

## 二、供应链协同管理四大优势（vs 传统供应链管理）

1. 树立"共赢"意识，变各自为阵的松散关系为紧密合作的伙伴关系。
2. 以信息共享为基础、以优化供应链绩效为目标进行协同决策，既克服分散决策导致的整体绩效低下，也避免集成式管理中单一决策者的弊端。
3. 加强节点企业及部门内外联系，将整个供应链视为有机联系的整体。
4. 借助他人核心竞争力强化自身核心竞争力，同时帮助上下游提升满意度，实现整链价值最大化。

## 三、Cochain 供通国际供应链平台（厂商宣传口径）

隶属[[entities/中国国际电子商务中心]]的国富通公司出品，基于 [[entities/RosettaNet]] 标准建立的新一代电子供应链协同管理系统，实现物流、信息流、资金流的互动、整合与同步。包含子系统（原文口径，保留）：

| 子系统 | 说明 |
|---|---|
| 供应商协同管理系统（eSRM） | 供应商协同 |
| 采购询源管理系统 | 寻源/询价 |
| 采购协同管理系统（gTE） | 采购执行协同 |
| 仓储管理系统（WMS） | 仓储 |
| 运输管理系统（TMS） | 运输 |
| 逆向物流管理系统 | 退货/逆向 |
| 订单交付协同管理系统 | 订单交付 |
| 客户关系管理系统（CRM） | 客户关系 |

覆盖"从客户订单接收，物料采购准备和预测下达，仓储配送，运输管理，逆向物流管理**直至财务结算、企业融资**"的全方位电子化与自动化。

# 国富通信息技术发展有限公司

隶属[[中国国际电子商务中心]]的企业，依托商务部软硬件资源，主营供应链协同管理解决方案与物流信息化。2010 年口径：多年从事物流信息化研究与开发，倡导运用信息技术提升现代供应链管理水平，提供从需求分析、应用实施到运行维护的一体化全流程服务（上述均为厂商宣传口径，见 [[sources/4-news--7-04-业务基础--4-2010--29-cochain供通国际打造供应链协同管理高速通道供应链管理--czx2de]]）。
