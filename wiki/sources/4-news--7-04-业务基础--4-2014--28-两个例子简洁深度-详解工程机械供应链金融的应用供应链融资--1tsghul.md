# 两个例子简洁深度 详解工程机械供应链金融的应用（供应链融资，2014）

## 概要

2014-09-22 公众号"供应链金融"（sinoscf）转载自 sinotf.com 的分析文章。以**苏宁电器**（上游占款型核心企业）与**"某某重工"**（匿名工程机械核心企业，数据指向 2011 年年报）两家核心企业的 2011 年报财务数据为例，从供应链整体融资成本最小化视角，讲解供应链金融两种典型应用：上游应付端信用释放（承兑汇票、保理）与下游信贷支持（按揭、融资租赁）。

## 苏宁电器案例（上游占款型）

2011 年报数据（单位：千元，媒体转述口径）：

| 项目 | 2011年 | 2010年 |
|---|---|---|
| 总资产 | 59,786,473 | 43,907,382 |
| 负债总计 | 36,755,935 | 25,061,991 |
| 净资产 | 23,030,538 | 18,845,391 |
| 货币资金 | 22,740,084 | 19,351,838 |
| 应收账款 | 1,841,778 | 1,104,611 |
| 应收票据 | 7,265 | 2,505 |
| 存货 | 13,426,741 | 9,474,449 |
| 金融性负债 | 1,665,686 | 317,789 |
| 应付票据 | 20,617,593 | 14,277,320 |
| 应付账款 | 8,525,857 | 6,839,024 |
| 营业收入 | 93,888,580 | 75,504,739 |
| 营业利润 | 6,444,081 | 5,431,948 |
| 净经营性现金流 | 6,588,520 | 3,881,336 |

要点：

- 应付票据 + 应付账款占总负债 **79.3%**（作者计算口径），应收仅相当于应付的 **6.3%**——渠道为王的电器行业中苏宁以经营性负债为资产融资，上游占款。
- 作者论断：现实中供应商自行高成本融资，与"应由苏宁代表供应链对外融资"的理论最优相悖；苏宁融资后以现金支付供应商属帕累托改进。
- 改善路径：① 开具银行承兑汇票替代现金支付（成本 = 贴现利息 + 承兑费 + 保证金沉淀成本，需与苏宁直接发债成本比较）；② 供应商以对苏宁的应收账款融资：质押贷款 / 出售（保理）/ 证券化。有追索权保理风险本质等同于应收账款质押贷款，无追索权保理本质为出售债权。

## 某某重工案例（下游信贷支持型）

2011 年报数据（单位：元，媒体转述口径，企业匿名）：

| 项目 | 2011年 | 2010年 |
|---|---|---|
| 总资产 | 71,581,771,679.19 | 63,081,564,271.45 |
| 负债总计 | 35,947,011,758.44 | 35,607,117,456.09 |
| 净资产 | 35,634,759,920.75 | 27,474,446,815.36 |
| 金融性负债 | 12,417,046,984.49 | 14,089,320,106.30 |
| 应付票据 | 4,967,376,666.73 | 5,441,684,623.34 |
| 应付账款 | 7,136,420,984.75 | 6,885,584,475.09 |
| 其他应付款 | 3,742,945,481.54 | 2,272,748,535.58 |
| 货币资金 | 17,744,514,431.30 | 20,519,895,456.36 |
| 应收账款 | 11,658,065,230.17 | 6,947,232,058.99 |
| 应收票据 | 1,138,568,850.74 | 626,608,952.51 |
| 长期应收款 | 12,805,272,043.36 | 9,799,311,028.34 |
| 存货 | 9,655,357,242.28 | 8,678,146,510.00 |
| 营业收入 | 46,322,580,713.20 | 32,192,673,210.38 |
| 营业利润 | 9,514,369,773.66 | 5,373,872,292.6 |
| 净经营性现金流 | 2,093,234,777.59 | 545,177,864.66 |

要点：

- 经营性应收（应收票据 + 应收账款 + 长期应收款/融资租赁租金）合计 **256 亿元**，经营性应付合计 **158.5 亿元**，差额约 **100 亿元**——核心企业实际在为供应链融资。
- 应收账款与长期应收款承担类银行信用风险；行业下行 → 坏账吞噬利润 → 债权人信心受损 → 挤兑式流动性风险（引 [[entities/爱多VCD]] 先例）。
- 厂商金融比较优势：行业信息优势 + 租赁物处置优势；劣势：流动性风险管理能力不足，需结合资本市场治理。

## 关键论断

> "坏账潮非供应链金融之错，而是公司经营政策冒进之错。"

该判断对 2012 年后工程机械行业应收账款危机有很强的事后印证价值。

## 证据强度

- 财务数据来自两家企业 2011 年报（表内数据完整保留），但为媒体转述，未附原文页码——**证据强度：中（专业公众号分析）**。
- "某某重工"匿名与真实年报数据并存，主体身份待核验，见 [[queries/查询-某某重工2011年报数据指向的具体企业与匿名化原因]]。
- 文中"劳宁电器"为错别字（苏宁）。
- 时效提示：本文为 **2014 年口径**，呈现的是监管收紧前"核心企业占款 + 厂商系金融"黄金期叙事；其乐观前提（核心企业信用恒高于上下游）在工程机械 2012–2015 应收危机中已被现实挑战，仅作历史快照。
