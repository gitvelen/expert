# 深圳8部门《关于进一步支持中小微企业纾困及高质量发展的若干措施》（2023）

万联网2023-02-08报道：2023年2月6日，深圳市工业和信息化局、市发展改革委、市科技创新委、市财政局、市商务局、市国资委、市地方金融监管局、国家税务总局深圳市税务局等8部门联合印发《关于进一步支持中小微企业纾困及高质量发展的若干措施》，围绕**降低生产经营成本、有效扩大市场需求、支持中小企业创新发展、促进中小企业转型升级**四方面提出20条措施。文件信息来源为[[深圳市中小企业服务局]]。

## 政策定位

2023年初"开门红"稳增长背景下的"纾困+高质量发展"双轨政策：纾困条款多为阶段性措施（风险补偿、贴息等限定2023年Q1/Q2窗口），而专精特新培育目标为年度性量化目标，二者时间尺度不一致，落地成效需分窗口追踪。

## 关键量化条款

| 条款 | 量化内容 |
|---|---|
| 风险补偿（第5条） | 2023.1.1–3.31新增贷款（展期视同新增），风险损失补偿比例提高30个百分点，最高80% |
| 首贷贴息（第5条） | 2023年1-3月首贷企业2%贴息，单户≤20万元，期限≤6个月 |
| 担保费（第6条） | 政府性融资担保机构对小微企业担保费率最高减免40%且不高于1%，鼓励"见贷即担" |
| 延期还本付息（第7条） | 2022Q4到期小微贷款最长延至2023.6.30 |
| 金融驿站（第8条） | 2023年网点达150个、活动100场、解决融资金额超1000亿元 |
| 政府采购（第9条） | 面向中小企业预留份额阶段性提高至40%以上，延续至2023年底 |
| 科技型中小企业（第13条） | 利息贴息支持比例提高30个百分点，最高按实际支付利息80%资助；入库企业2万家以上 |
| 专精特新梯度目标（第14条） | 2023年底累计：创新型中小企业1.3万家以上、专精特新中小企业5000家以上、"小巨人"500家以上 |
| 上云上平台（第17条） | 优质平台商每年≤1000万元资助，推动10万家以上中小企业深度上云上平台 |
| 人才培训（第18条） | 专精特新企业培育工程每年培训1000人次以上 |
| "创客中国"深圳赛区（第16条） | 获奖项目最高30万元奖励；全国500强可直接认定专精特新中小企业；全国50强获"小巨人""创新能力"指标直通资格 |

## 主要内容

- **降低生产经营成本（1-8条）**：税收优惠、降费缓缴、[[工业上楼与优质产业空间-深圳]]（不少于2000万平方米厂房、平均租金不高于35元/月/平方米、"总成本+微利"分割销售）、账款清理、[[深圳中小微企业贷款风险补偿资金池]]、[[深圳首贷贴息机制]]、担保费减免、延期还本付息、[[金融驿站项目-深圳]]。
- **扩大市场需求（9-12条）**：消费补贴、政府采购预留份额、开拓国内外市场、应用场景示范。
- **支持创新发展（13-16条）**：科技型中小企业贴息、专精特新梯度培育（第14条）、融资支持（专精特新上市专家服务团，责任单位含深圳证监局、深圳证券交易所）、[[创客中国大赛直通认定机制-深圳]]。
- **促进转型升级（17-20条）**：数字化转型、人才培育、质量标准品牌赋能中小企业专项行动、依托"深i企"平台健全三级企业服务体系。
