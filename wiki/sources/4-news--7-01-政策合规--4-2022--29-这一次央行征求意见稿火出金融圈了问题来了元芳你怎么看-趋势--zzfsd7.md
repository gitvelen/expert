# 这一次，央行征求意见稿火出金融圈了！问题来了：元芳，你怎么看？

## 基本信息

- 媒体：[[万联网]]，2022-01-06
- 原文：https://info.10000link.com/newsdetail.aspx?doc=2022010690005
- 事件：2021年12月31日，[[央行]]发布《关于〈[[地方金融监督管理条例草案征求意见稿]]〉公开征求意见的通知》，附《草案征求意见稿》全文及起草说明
- 意见反馈截止：2022-01-30

## 内容要点

报道的核心价值在于**附有《草案征求意见稿》全文（五章四十条）及起草说明**，是 wiki 中多个政策概念页的第一手文本依据。

### 条款结构速览

| 条款 | 内容 |
|---|---|
| 第五条 | 央地协调双机制：金融委办公室地方协调机制 + 地方政府金融工作议事协调机制 |
| 第九条 | 地方金融组织定义：小贷、融资担保、区域性股权市场、典当行、融资租赁、商业保理、地方资产管理公司等七类 |
| 第十一条 | 持牌经营 + "原则上不得跨省级行政区域开展业务"，跨省规则由国务院或授权制定 |
| 第十二条 | 名称禁止条款：未经批准不得使用"金融""贷""商业保理"等字样 |
| 第十三条 | 变更持有5%以上股权的股东、实际控制人须经省级地方金融监督管理部门批准 |
| 第二十五条 | 非法金融活动处罚 + 逐次处罚（过罚相当） |
| 第二十七条 | 违规跨省处罚：没收违法所得 + 1-10倍罚款（无违法所得处50万-500万），可责令停业整顿/吊销许可证 |
| 第三十一条 | 双罚制：对直接责任董监高警告并处5万-50万罚款，情节严重可限期或终身禁业 |
| 第三十二条-三十六条 | 四类机构（交易场所、信用互助合作社、投资公司、社会众筹机构）参照监管 |
| 第三十八条 | 过渡期安排：已跨省展业机构由国务院金融监督管理部门明确过渡期 |
| 第四十条 | 实施日期留白 |

### 起草说明要点

- 立法必要性：缺乏国家层面统一地方金融监管立法，"监管依据不够充分、执法手段不足"
- 框架原则："中央统一规则、地方实施监管，谁审批、谁监管、谁担责"
- 央行自2018年6月牵头启动起草

## 不确定性与矛盾

- 报道引"业内人士透露"称草案拟于2022年6月实施，但第四十条实施日期空白——**仅为传闻，证据弱**，后续实际也确未如期出台。不应作为事实记录。
- "原则上不得跨省"+"跨省规则另行制定"留下的模糊空间，正是行业争议焦点（如保理公司注册地深圳但业务全国），与 [[queries/查询-地方金融监督管理条例正式稿跨省展业条款最终定调]] 跟踪的问题一致。
