# 国企供应链公司必看的36个供应链风控问题！（万联网 2024-10-14）

## 来源定位与可信度

万联网公众号的**汇编型/导流型**文章，整理约36个供应链风控问答，内容偏基础科普，文末导流至风控公开课与《国企供应链公司新质发展行动白皮书》（付费选购）。在可信度分层中处于"一般专业媒体汇编"层级，**证据强度低**，其中观点性内容须注明口径；文中无具体判决、金额、判例编号等结构化数据。

## 导语背景（本条最有价值的索引信息）

- 74号文"十不准"（[[国资发财评规2023-74号通知]]）与[[国有企业管理人员处分条例]]颁布实施后，叠加[[专网通信案]]、[[云南惠嘉伪造货权转让事件]]、[[金凰珠宝百吨假黄金案]]等融资性贸易事件，大宗商品供应链圈"不敢随便开展业务"。
- 提及"明年央国企需推行末等调整和不胜任退出制度"的消息——**系传言/消息，非正式文件口径**，以 [[查询-央国企末等调整和不胜任退出制度的正式文件依据与实施进展]] 跟踪。

## 36问内容概要（按主题归并，非逐条转述）

| 主题 | 要点 | 备注 |
|---|---|---|
| 质押物选择（第1、16、20条） | 质押物应具备**稳定性、流动性、保值性、产权明晰**四特征；仓储与第三方联保，控制出借金额与担保物价值比例 | 教科书式科普 |
| 应收账款质量（第2、10、12条） | 真实性、合法性、可转让性；特征四条为可转让性/特定性/时效性/提供者资格；应对措施含单据证明、交叉核验、指定回款账户 | 第2条引用《合同法》——**旧口径，该法已被《民法典》（2021年施行）取代** |
| 第三方物流监管（第3、6条） | 审核物流企业管理运营能力、规模、信用记录、数据共享程度；外包致信息不对称，存在串通出具无实物仓单、擅自提取质物等风险 | 与已有河北粮仓案、仓储道德风险知识线相关 |
| 贸易背景真实性与自偿性（第4、21条） | 自偿性依赖真实交易；强调 KYC、财务分析与贸易活动价值分析结合 | 业界共识表述 |
| 操作风险与道德风险（第5、9、18、35、36条） | 信用风险向操作风险位移；内控失灵、人员操作失误、大数据技术风险；管理需符合监管要求与行业标准 | |
| 核心企业风险与挑选（第8、11、22-23、26-27条） | 核心企业信用风险沿链条传导；三重考察：经营实力、上下游管理能力、对银行协助能力；产业类核心企业靠产品标准化+仓储能力，平台类靠大数据 | 第22-25条为模板化重复的"准入模型+动态监测"通用模板，价值有限 |
| "风险转移"与"风险隔离"（第30-31条） | "风险转移"侧重核心企业信用分析，致操作/道德风险失控；资金挪用使转移失效，需有效风险隔离 | 有一定框架价值，见 [[风险转移与风险隔离模式辨析-公众号汇编口径]] |
| 数据与信息不对称（第28-29、32条） | 数据来源四渠道（银行、企业/核心企业、物流企业、海关工商保险征信平台）；多级供应链透明度与大数据风险预测 | "去中心化"（第13条）等表述显示部分内容整合自约2017-2019年旧文，与2024年监管语境存在时代错位 |

## 白皮书发布事实

《国企供应链公司新质发展行动白皮书》由万联网与万联供应链新质发展智库于 **2024-09-26** 在"2024新质生产力赋能大宗商品供应链创新发展论坛"上发布，称基于**300多家国企调研**，案例企业包括：协同资本、国联股份-蛋多多、[[秦岭数字]]、草都集团、简单汇、翔桥供应链、冠之链、数链科技、河钢供应链、[[中仓登]]、全联农科、汇融数科。调研口径待 [[查询-国企供应链公司新质发展行动白皮书300家国企调研口径的独立验证]] 核实；若白皮书全文可获取，应单独 ingest。
