# 全国人大代表朱献福：构建面向产业的智慧生鲜供应链生态圈（2018）

> **证据强度提示**：本文为一般新闻报道（公众号转载大河财立方 2018-03-12 两会报道），核心内容为 [[entities/朱献福]]（[[entities/鲜易控股]] 董事长）的**企业自我宣传口径与人大代表政策建议**，可信度低。文中"顺利完成蝶变""共创共享"等正面叙事，与 [[entities/鲜易控股]]/[[entities/众品食业]] 后续出现的债务危机形成尖锐对照，详见 [[queries/查询-鲜易控股与众品食业后续债务危机与转型成败]]。

## 一、来源概况

- **日期**：2018-03-12（全国两会期间）
- **体裁**：人物访谈 / 企业正面报道
- **核心叙事**：从 [[entities/众品食业]]（生鲜食品制造）脱胎而来的 [[entities/鲜易控股]]，沿"生产型服务业 → 平台型企业 → 生态型企业"路径转型，构建"面向产业的智慧生鲜供应链生态圈"。

## 二、鲜易控股业务结构（2018 年口径）

"左手食品产业链、右手温控供应链"：

| 层 | 板块/平台 | 定位 |
|----|-----------|------|
| 线上 | 云农牧产业平台 | 农牧产业平台 |
| 线上 | 鲜易网 | F2S2B 生鲜电子商务平台（B 端） |
| 线上 | 冷链马甲 | 冷链资源交易平台 |
| 线下 | 众品 | 生鲜食品服务型制造业 |
| 线下 | 鲜易通 | 生鲜食品集采分销服务平台 |
| 线下 | 鲜易供应链 | 流通服务平台 |

报道宣称其利用互联网、物联网、大数据实现"场景在线化、业务数据化"（企业自述，未经验证）。

## 三、主要观点

1. **B 端产业互联网定位**：新零售是 to C 端，市场已被 BAT 基本瓜分；河南等制造业省份应关注"新流通"与产业互联网平台，走"产地即销地、产销结合"路线。
2. **中美 B 端服务企业占比差距**：称中国生产型服务企业占比"百分之十几"，美国超 50%，美上市企业中 B 端服务型企业占 70% 以上（数据未注明出处，仅作观点背景）。
3. **张大卫建议**：[[entities/鲜易网]] 客户为 B 端（渠道端），可与针对 C 端的盒马鲜生等电商平台链接互补（后续未经验证）。
4. **政策四点建议**（人大代表建议性质，反映 2018 年行业诉求）：
   - 确定供应链服务行业的战略新兴产业地位，生鲜产业供应链率先纳入统筹；
   - 加大政策扶持，引导供应链各环节主体向平台集聚和信息共享，培育平台模式供应链龙头企业；
   - 鼓励龙头企业开展供应链金融服务，尝试组建"物流银行、供应链金融银行、交易性银行"，以贴息、无息解决融资难融资贵；
   - 加快供应链复合型高端人才培养，高校开设现代供应链专业课程。

## 四、史料价值与警示

- 本文是 [[entities/国办发2017-84号文]] 出台背景期的两会行业声音，"龙头企业开展供应链金融"的诉求在后来国企融资性贸易整治语境下（74 号文、《国有企业管理人员处分条例》）需重新审视。
- 产融结合（企业同时经营食品产业链与供应链金融服务）的自我监管风险在本文中完全不可见，与 wiki 已有"正面叙事爆雷"案例（华业资本、辉腾金控）模式一致。

# 鲜易控股

鲜易控股是以互联网思维构建的**生鲜产业互联网平台**，从生鲜食品制造企业 [[entities/众品食业]] 转型而来，董事长为 [[entities/朱献福]]。

## 业务结构（2018 年口径）

- **线上**：云农牧产业平台、F2S2B 生鲜电商 [[entities/鲜易网]]、冷链资源交易平台 entities/冷链马甲
- **线下**：服务型制造业众品、生鲜集采分销平台鲜易通、流通服务平台鲜易供应链

报道宣称其定位为"以平台为支撑、以数据为驱动，食品产业链与温控供应链多业融合"的智慧生鲜供应链生态圈（见 concepts/智慧生鲜供应链生态圈）。

## 时效性警示

（2018 年口径，已被后续风险事件挑战）2018 年报道呈现"顺利完成蝶变"的正面叙事；鲜易/众品后续实际出现债务危机（众品食业 2019 年前后债券违约、鲜易进入重整），本文叙事不构成对其经营状况的可靠判断。后续进展见 [[queries/查询-鲜易控股与众品食业后续债务危机与转型成败]]。

# 朱献福

朱献福，[[entities/鲜易控股]] 董事长，创始人起家于 [[entities/众品食业]]。2018 年任全国人大代表，两会期间提出"关于加快供应链创新与应用"建议，核心为构建"面向产业的智慧生鲜供应链生态圈"。

## 2018 年四点政策建议（人大代表建议口径）

1. 确定供应链服务行业的战略新兴产业地位；
2. 加大政策扶持，引导供应链主体向平台集聚、培育平台模式龙头企业；
3. 鼓励龙头企业开展供应链金融服务，尝试组建物流银行、供应链金融银行、交易性银行；
4. 加快供应链复合型高端人才培养（高校开设现代供应链专业）。

其中"龙头企业开展供应链金融服务"的诉求，在后来的国企融资性贸易整治监管语境下需重新审视。其提出的"BAT 是平台型盟主、河南需要产业链链主"对比见 concepts/产业链链主与平台型盟主。

# 智慧生鲜供应链生态圈（2018 年口径）

由 [[entities/朱献福]] 提出的生鲜产业互联网定位：通过"全国统一、分布式的生鲜产业布局"，构建**以平台为支撑、以数据为驱动**，食品产业链与温控供应链多业融合，线上线下多网协同的生态圈。

## 要点

- **B 端产业互联网路线**：区别于被 BAT 主导的 C 端消费互联网/新零售，强调"新流通"、产地即销地、产销结合、一二三产融合。
- **场景在线化、业务数据化**：以互联网、物联网、大数据实现供应链敏捷性与精准性，概念上呼应 [[concepts/场景供应链金融]] 中"数据信用"的叙事。
- **产融结合诉求**：生态圈叙事伴随"龙头企业开展供应链金融服务"的政策诉求。

## 警示

（2018 年口径，已被后续风险事件挑战）此类"生态圈"叙事常见于企业自我宣传；提出主体 [[entities/鲜易控股]] 后续出现债务危机，说明生态圈叙事与实际货权控制力、贸易真实性、财务稳健性之间无必然对应关系。评估此类模式应回到本 wiki 的产业本位工作论点：贸易背景真实性与货权控制力。

# 产业链链主与平台型盟主对比框架

[[entities/朱献福]] 在 2018 年提出的区域产业战略框架：

- **平台型盟主**：以 BAT（百度、阿里、腾讯）为代表，依托消费互联网（C 端）流量与数据的平台型企业；认为该赛道已基本瓜分完毕。
- **产业链链主**：制造业为主的省份（如河南）应培育整合全产业链的服务型企业，打通产业链上下游，以大枢纽带动大流通、大流通带动大产业，实现产销结合。

## 分析价值

该框架本质是"C 端消费互联网平台 vs B 端产业互联网平台"的差异化定位论述，可用于分析各产业互联网平台（如找钢网、国联股份等）的自我定位叙事。注意：这是提出者为其企业定位辩护的观点性框架，非中立产业分析；引用时应注明（2018 年口径）。

# 查询：鲜易控股与众品食业后续债务危机与转型成败

2018 年 3 月两会报道呈现 [[entities/鲜易控股]] "顺利完成蝶变"的正面叙事（见 [[sources/4-news--7-02-产品案例--4-2018--31-全国人大代表朱献福构建面向产业的智慧生鲜供应链生态圈供应链方案--185iyq2]]），但据公开信息众品食业 2019 年前后出现债券违约，鲜易体系进入重整。本页跟踪：

1. 众品食业债券违约与重整的具体时间线、债务规模与偿付结果；
2. 鲜易网、冷链马甲等平台的存续与处置；
3. "智慧生鲜供应链生态圈"模式失败的根因：产融结合过度、货权控制力不足，还是行业周期；
4. 与华业资本、辉腾金控等"正面叙事爆雷"案例（见 [[queries/查询-辉腾金控与中铁中基供应链集团后续风险与兑付情况]]、queries/查询-华业资本爆雷对医疗供应链金融正面叙事的验证教训）的共性归纳。
