# 曹流浪：疫情对于企业贷款的影响远比预想的大！（观点，2020）

## 来源信息

万联网 2020-02-10 原创报道，记录悦融易创始人兼CEO [[entities/曹流浪]] 于 2020-02-05 在万联网系列公益直播课第三课的主题分享：“疫情下的银行贷款问题及建议”。

## 核心论点

### 疫情对企业贷款的三类短期影响

1. **征信问题**：因疫情延迟复工导致到期贷款不能按期还款。依据五部委 [[entities/五部委关于进一步强化金融支持防控新型冠状病毒感染肺炎疫情的通知]]，因疫情影响未及时还款不影响企业贷款征信；但曹强调政策有具体操作细则，须**提前与贷款银行沟通**。
2. **贷款集中到期的流动性问题**：比单笔到期更棘手，建议企业对 2 月甚至 3 月的到期贷款提前集中与银行沟通。
3. **新增/存量贷款审批时效延迟**：银行工作效率降低不可避免，需及时沟通将影响降到最低。

### 中长期影响与应对建议

- 做好现金流预算管理；盘点应收应付、做好资金规划，确保流动性安全。
- 有银行贷款的须加强与合作银行沟通，确保到期正常续期，避免被抽贷断贷。
- **政策与商业的张力**（本文核心论点）：曹一方面称五部委文件对中小企业是“重大利好”（不得盲目抽贷断贷压贷、可展期续贷、下调利率、增加信用贷款和中长期贷款），另一方面强调“**银行在商言商**”，企业经营受影响、现金流紧张时银行并不保证续贷；一旦经营受损再被抽贷断贷，将雪上加霜。

### 疫情下中小企业贷款的机会

- 国家利好政策将陆续出台，与抗疫直接相关及受疫情直接影响的企业可留意政策信息、争取银行贷款。
- **银行考核窗口期**：各银行“开门红”任务受疫情影响存在考核压力，3 月或出现小窗口期，企业可借此争取贷款（详见 [[concepts/银行考核窗口期融资机会-2020曹流浪口径]]）。

### 线上问答要点（2020 年预判，均需追踪验证）

| 问题 | 曹流浪回答 |
|------|-----------|
| 会否放宽对保理、小贷、互金、助贷的严监管 | 强监管不可逆，不大可能放宽 |
| 疫情下供应链停滞，供应链金融是否无用武之地 | 相反，供应链金融是解决中小企业融资难题、降低融资成本、减少供应链风险的有效手段，更应发挥作用 |
| 疫情是否会对线上供应链金融有大的正面促进 | 并不大可能，**供应链金融的发展空间还是线下为主** |
| 小微企业放款政策会否放宽 | 已发放贷款利率不可能降低，未来新发放有可能降低；申请贷款资料须全面及时 |
| 动产质押如何加快发展 | 动产（存货、机器设备、应收账款）盘活只有供应链金融能做到，但一般银行重点关注核心企业，动产产品发展较慢 |
| 疫情后房产估值会否下调 | 不会，预计疫情 2 月底 3 月初将变小 |
| 对深圳市金融局出台政策的建议 | 重点关注各大银行，将普惠金融落到实处 |
