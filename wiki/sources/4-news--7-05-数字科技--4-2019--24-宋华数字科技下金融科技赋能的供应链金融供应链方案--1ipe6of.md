# 宋华：数字科技下金融科技赋能的供应链金融（2019）

## 来源信息

- **演讲人**：宋华（中国人民大学商学院教授）
- **场合**：万联网主办的"CSCFIS 2019 第六届中国供应链金融创新高峰论坛"（2019-03-19，深圳），大会主题"产业、金融、科技、监管"
- **整理**：万联网速记（内有删改），2019-03-24 转载于 sinotf.com
- **可信度层级**：专业公众号分析（演讲观点），无官方文件或数据表佐证，正文均为"宋华 2019 演讲口径"的观点性内容

## 演讲五部分框架

1. 供应链金融的演化与智慧化
2. 金融科技的功能作用
3. 金融科技作用下供应链金融各类主体的组织模式
4. 金融科技作用下的供应链金融模式
5. 融合性供应链金融风险控制体系

## 核心观点摘要

### 一、四阶段演化与广义供应链金融

- 演化分期：2001 年商业银行主导（应收应付、存货短期借贷）→ 2008 年核心企业主导（自建平台服务上下游，风控基于商流物流把控）→ 网络平台推动（风控基于网络结构与关系）→ 金融科技赋能。见 [[供应链金融四阶段演化论-2019宋华口径]]（与瑞通四阶段 1.0–4.0 口径为两套并存分期）。
- 狭义供应链金融 = 面向特定环节特定中小企业的点对点借贷；广义 = 面向全链条所有参与方、目标是优化整条供应链的现金流。宋华倾向广义："不要把供应链金融看做融资这么简单"。
- **CCC 批判**（演讲金句："很多企业搞供应链金融是站在 CCC 的角度耍流氓"）：CCC = 应收天数 + 库存天数 − 应付天数；单一企业压缩 CCC 可能只是把应付转嫁为上游应收（"我们的应付就是别人的应收"），须看全供应链流动性。详见 [[广义供应链金融与CCC批判-2019宋华口径]]。

### 二、ABS 资产穿透预警

- "今天大部分发行的 ABS 不是严格意义上的资产证券化……是发企业债，只不过把表内拿到表外。"
- "如果不解决资产穿透，资产证券化就是假的证券化"；预言广泛开展不穿透资产的供应链 ABS"将来一定会爆发供应链金融的金融危机"。

### 三、金融科技的功能

- 天平论：资产端赋能 = 底层交互客观化、末端业务自治化；资金端赋能 = 债项结构客观化、主体信用自治化。
- 三大功能：识别搜集有用信息、过滤冗余信息、结构化整合信息——"不结合场景看金融科技都是没有用的"。
- 三类可采集信息：中小企业完全不可控信息、无意识行为信息、部分可控信息（由第三方判定）。详见 [[金融科技三功能三类信息-2019宋华口径]]。
- **单一区块链不可行论**："严格意义上单纯的区块链+供应链金融不存在"，需 IOT + AI + 移动边缘计算/云计算 + 电子凭证区块链流转的融合应用；"不要炒作概念"。这是对 2019 年区块链乐观叙事的克制派对照，见 [[comparisons/单一区块链不可行论与区块链赋能乐观论对比-2019口径|单一区块链不可行论与区块链赋能乐观论对比]]。

### 四、组织模式与业务模式

- 按"供应链参与者 / 生态组织者 / 信号中介 / 流动性提供者"四角色组合出六类组织模式：UPS（KABBAGE + UPS Capital，四合一）、TCL（生态组织者 + 外部银行）、中驰车福（平台型金融科技 + 外部产业与银行）、微众税银（专业信号中介做银行后台风控）、招商银行×中建集团（商业银行平台化，集中招标标准化上区块链）、以及平台+科技+流动性全能型。
- 详见 [[供应链金融组织模式六类型-2019宋华口径]] 与 [[招商银行中建集团招标区块链平台-2019演讲口径]]。

- 产融四象限（组织者 × 价值发现者）：传统借贷 / **微信贷**（有组织化但无价值发现，如蚂蚁芝麻信用，"准供应链金融"，资金最多不超过万级）/ **反应型**（把握某环节资产与业务，如欧普照明经销商融资）/ **前摄性**（全产业链把控、能动改造产业，商流、物流、资金流可能分离）。详见 [[产融四象限微信贷反应型前摄性-2019宋华口径]]。

### 五、风控：结构化信用 + 数字化信用

六个信号（各以结构与数字双维度刻画）：网络信号、业务信号、交易信号、管理信号、能力信号、声誉信号。详见 [[结构化信用加数字化信用六信号风控框架-2019宋华口径]]。
