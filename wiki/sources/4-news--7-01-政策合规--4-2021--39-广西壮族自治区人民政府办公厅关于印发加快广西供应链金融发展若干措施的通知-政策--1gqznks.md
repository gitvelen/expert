# 《加快广西供应链金融发展若干措施》（桂政办发〔2021〕86号）

广西壮族自治区人民政府办公厅于 2021 年 8 月 13 日印发，共 11 部分 28 条，是继山东之后又一省级系统性供应链金融支持政策。政策依据银发〔2020〕226 号八部委文件制定，目标是力争 2021 年广西供应链融资达到 1000 亿元并实现可持续增长。

## 政策结构

| 部分 | 条款 | 主题 |
|---|---|---|
| 一 | （一）（二） | 围绕"7+4"产业链打造特色供应链融资模式：白名单制度、"一链一策"、桂惠贷贴息 |
| 二 | （三）（四） | 广西供应链金融服务平台（依托广西征信融资服务平台构建） |
| 三 | （五）（六） | 推广中征应收账款融资服务平台、核心企业 30 日内确权 |
| 四 | （七）—（九） | 物流与供应链金融融合：西部陆海新通道物流金融联盟、"三单"融资、跨境金融区块链服务平台、第三方专业机构 |
| 五 | （十）—（十二） | 供应链票据：核心企业签发奖励、平台接入奖励、国企举债红线 |
| 六 | （十三）—（十五） | 金融机构服务能力：品牌打造、业务规范、排名奖励 |
| 七 | （十六）（十七） | 金融科技赋能、平台联动、跨境融资纳入桂惠贷研究 |
| 八 | （十八）（十九） | 动产融资统一登记公示系统与动产权利融资 |
| 九 | （二十）（二十一） | 挂牌上市与债权融资工具奖励 |
| 十 | （二十二）—（二十四） | 供应链金融示范区创建与激励 |
| 十一 | （二十五）—（二十八） | 指挥部组织保障、100 亿再贷款再贴现、失信黑名单联合惩戒 |

## 财政奖励体系（原文量化指标）

| 奖励项目 | 金额与规则 |
|---|---|
| 中征平台核心企业接入奖励 | 每年 1200 万元资金池，20 万元/家一次性奖励，先到先得、用完即止 |
| 跨境金融区块链平台信息平台直接接入奖励 | 每年 300 万元资金池，50 万元/家一次性奖励 |
| 第三方专业机构奖励 | 按支持供应链融资额 0.2% 奖励，单家年度上限 50 万元（需与 3 家以上金融机构互联互通） |
| 供应链票据签发 Top10 | 按签发增长量 0.2% 奖励，单户年度上限 50 万元 |
| 供应链票据平台接入奖励 | 每年 500 万元资金池：间接接入 50 万元、直接接入 100 万元、升级再奖 50 万元 |
| 金融机构供应链融资 Top10 | 第 1 名 40 万元，第 2—5 名各 30 万元，第 6—10 名各 20 万元 |
| 新三板挂牌 | 100 万元一次性奖励 |
| 沪深 IPO | 分阶段累计 600 万元奖励 |
| 债务融资工具/ABS | 中介费用 50% 补助，每户每类产品上限 100 万元 |
| 绿色债务融资工具/绿色 ABS | 每户每类产品补助上限 200 万元 |

## 资金与组织保障

- 人民银行南宁中心支行安排不低于 100 亿元再贷款再贴现额度，优先支持供应链企业贷款和贴现。
- 国家开发银行广西分行、中国进出口银行广西分行分别安排 15 亿元、7 亿元转贷资金，发放优惠利率贷款。
- 成立[[广西供应链金融发展指挥部]]，指挥长由自治区人民政府分管领导担任，办公室设在[[人民银行南宁中心支行]]；自治区工业和信息化厅组织每个设区市推动不少于 2 家核心企业加入中征平台和上海票据交易所供应链票据平台。

## 合规红线

- 国有企业不得通过供应链金融业务利用政府信用、公益性资产等方式融资举债，违者严肃问责；金融机构亦不得引导、支持此类行为（第十二条、第十四条）。详见供应链金融隐性债务防控。
- 定期披露核心企业恶意拖欠中小企业账款失信"黑名单"，纳入广西公共信用信息平台与国家企业信用信息公示系统（广西），开展联合惩戒。

## 主要论断

1. 广西以"财政奖励 + 央行额度 + 政策性银行转贷"组合拳推动供应链金融，属政策承诺而非结果，量化指标需后续数据验证（见既有查询页）。
2. 以人民银行地方分支机构为核心（指挥部办公室设置）的省域供应链金融治理模式。
3. 政策同时强调发展与合规，反映 2021 年监管对供应链金融套利与隐性债务风险的警惕。
