# 对"ALL DOCUMENTS"理解差异引发拒付的思考

## 概要

作者李欣（中国银行淄博分行交易银行部），原载公众号"贸通齐鲁"，"贸易金融"公众号 2020-01-15 转载。文章通过一单出口信用证拒付交涉案例，讨论 UCP600 与 ISBP745 均未定义的 "ALL DOCUMENTS" 概念的范围问题，核心依据是 ICC 2016 年秋季 TA853 号官方意见。本文是该知识库中信用证/单证实务板块的起点。

## 案例事实链

- 即期信用证，开证行 B银行，申请人 C公司，受益人为国内 A公司，金额 USD25,660.00
- 47A 附加条款第八条：ALL DOCS MUST BEAR LC NO. AND H.S CODE NO. IRC NO. AND LCA NO.
- 2019-07-25 交单，审核相符后单据直寄开证行
- 08-14 收到拒付电：汇票未按 47A 要求显示 H.S CODE NO. / IRC NO. / LCA NO.
- 交单行依据 TA853 反驳；08-30 开证行付款但扣除不符点费 USD70
- 09-02 再次发文追索不符点费无果，升级警告级别施压后，09-16 收回 70 美元

## 核心论证

1. **惯例空白**：UCP600/ISBP745 均未定义 "ALL DOCUMENTS"；仅 ISBP745 A19 a 款定义 "SHIPPING DOCUMENTS"，明确排除汇票、电讯传送报告、快递/邮政收据。
2. **TA853 判例**：ICC 意见认定 "ALL DOCS" 不包含 DRAFT，故汇票未显示技术编码类信息不构成不符点。
3. **汇票功能性定位**：汇票本质为结算/支付工具而非单据，早于信用证出现，不应归入 "ALL DOCS"。

## 案例启示

- 开证环节应逐条审视单据化条款，争议条款事前协商修改。
- 国别风险与条款风险叠加：开证行所在国信誉差时更易借条款歧义无理拒付。
- 惯例无明文时，ICC 官方意见是不符点反驳的关键权威依据。

## 证据强度与局限

- 案例细节为银行一线叙述，属专业公众号分析层级；ICC 意见系转述，需核验 [[findings/TA853号意见-all-docs不包含汇票-ICC-2016口径]] 中标注的原文。
- 类推张力：TA853 针对的是 "ALL DOCS TO SHOW CONTRACT NO." 场景，直接类推至 H.S CODE 等技术性条款存在跳跃；且开证行最终付款但仍扣费，表明其并未完全接受论点。开放问题见 [[queries/查询-TA853号意见原文及其对技术编码类条款适用边界]]。
