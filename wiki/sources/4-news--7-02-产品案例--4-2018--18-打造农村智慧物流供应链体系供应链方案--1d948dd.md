# 打造农村"智慧物流"供应链体系（2018-03-20）

## 内容概要

2018 年全国两会期间，全国人大代表、西南大学资源环境学院教授[[谢德体]]提出建议：物流是制约农村电商发展的"瓶颈"，应以信息技术与共享物流打造农村"智慧物流"供应链体系，打通农村电商物流"最后一公里"。

## 核心建议要点

1. **问题描述**（经验性陈述）：农村电商物流缺少统一规划，存在配送路径不畅、专业人才缺乏、服务网点偏少、成本居高不下等问题。
2. **供应链一体化服务体系**：加强绿色智能农产品供应链核心技术研发，构筑仓、配、客、售后全供应链一体化服务体系。
3. **县域智慧物流网络平台**：以县域为单位建设统一配送平台，与省、市级物流管理体系数据共享；区县级物流公共配送中心承担培训、孵化、众创、物流快递、集散职能。
4. **"多站合一"物流网络**：整合交管站、客运站、农村物流点、邮政所、农资站等节点及农村（物流）综合服务站，促进资源整合、统一配送。
5. **共享物流**：线上将县域智慧物流系统与电商、第三方快递系统对接；线下调动乡镇、行政村闲置人车运力（供销社、农家乐、小卖部），实现商品"到镇进村入户"、农副土特产品"出村进城到户"。

## "五不问题"

农村末端配送的本土化经验总结（详见 农村电商物流最后一公里问题）：认不得路（交通不熟）、进不了村（路况不便）、识不了户（门牌信息缺失）、听不懂话（口音不同）、等不了人（农忙、外出）。

## 证据强度评估

- 本文为一般新闻报道转述的人大代表建议，属**观点/政策动向层**，不构成可核验事实，不应作为事实引用。
- 概念层价值在于共享物流与"多站合一"模式描述，对农村供应链金融场景中"物的流通"基础设施设计有参考意义（关联 [[物流企业主导型供应链金融模式]]、[[融通仓与国内物流金融三种形态]]）。

## 内部张力

建议依赖供销社、小卖部、农家乐等非专业物流主体承接末端配送，其服务可控性与货损责任划分未论及——与供应链金融所要求的货权控制力（[[主体信用数字信用物的信用三位一体]] 中"物的信用"）存在落地差距。

## 后续演进

2018 年口径的该建议，其后已部分被客货邮融合、县域商业体系建设等政策兑现或超越（跟踪：[[查询-县域智慧物流与客货邮融合2018年后的政策兑现情况]]）。

# 共享物流与县域智慧物流网络平台

## 概念定义（2018 年口径）

由[[谢德体]]在 2018 年全国两会建议中提出的农村物流组织模式，包含两个层面：

### 县域智慧物流网络平台

- 以**县域为单位**建设统一配送平台，与省、市级物流管理体系形成**数据共享**；
- 区县级物流公共配送中心承担农村电子商务的培训、孵化、众创、物流快递、集散职能；
- 整合交管站、客运站、农村物流点、邮政所、农资站等**"多站合一"**物流网络及农村（物流）综合服务站，促进节点资源整合。

### 共享物流

- **线上**：县域智慧物流网络系统与电商、第三方物流快递系统对接，实现多渠道、多平台一体化订单管理；
- **线下**：调动乡镇、行政村闲置的人、车、运力——本身有车、有人且熟悉当地交通人情的**乡镇供销社、农家乐、小卖部**——承接物流订单，实现商品"到镇进村入户"、农副土特产品"出村进城到户"。

## 价值与局限

- **价值**：与城市端"众包配送"同源，是农村末端物流低成本组网思路；对农村供应链金融而言，是"物的流通"基础设施前置条件（关联 [[物流企业主导型供应链金融模式]]、[[融通仓与国内物流金融三种形态]]）。
- **局限**：非专业主体承接物流的货损责任划分与服务可控性未论及，与供应链金融要求的货权控制力存在差距——供销社/邮政系节点能否升级为仓配监管节点，见 [[查询-县域智慧物流与客货邮融合2018年后的政策兑现情况]]。

## 后续演进

2018 年口径的建议，其后被客货邮融合、县域商业体系建设等政策部分兑现或超越，引用时注意标注口径年份。

# 农村电商物流"最后一公里"问题

## 问题界定（2018 年口径）

农村物流末端配送难题，被视为农村经济发展的痛点、焦点、难点。结构性成因（经验性陈述，无量化数据）：

- 缺少统一规划
- 配送路径不畅
- 专业人才缺乏
- 服务网点偏少
- 成本居高不下

## "五不问题"

社会物流到乡镇一级以下常见的本土化困难总结：

| 表现 | 成因 |
|------|------|
| 认不得路 | 交通不熟 |
| 进不了村 | 路况不便 |
| 识不了户 | 农村门牌等信息缺失 |
| 听不懂话 | 口音不同 |
| 等不了人 | 遇上农忙、外出 |

## 应对思路

信息技术驱动的县域统一配送与共享运力模式，详见 共享物流与县域智慧物流网络平台。
