# 国企下场干煤炭业务，必须要懂的19大行业术语！（万联网，2024）

## 来源概况

- 媒体：万联网（公众号/资讯栏目），2024-11-18 发布，未署名作者。
- 性质：术语科普型文章，罗列并解释煤炭贸易 19 个常用价格、费用与结算术语；文末为太原《煤炭供应链业务实操课》招生宣传（11 月 21-22 日，4 位讲师）。
- 知识定位：为"国企下场干煤炭"的行业背景层（04-业务基础）补充价格链与费用结构快照，对理解煤炭供应链金融的货值与费用构成直接有用。

## 19 个术语要点（科普口径整理，已去重）

文中第 10/13 条"含税车板价"定义重复，此处合并；个别条目（如 CIF）原文解释残缺，已按通行含义补正并标注。

| 术语 | 口径要点 |
|---|---|
| 坑口价 | 煤矿挖出后未经加工筛选、坑口交易价，裸价，不含加工与运输费 |
| 车板价 / 车板含税价 / 含税车板价 / 不含税车板价 | 煤装上火车（或船）后、除火车运费外的一切费用：坑口价、税费、汽车运费、站台税费、铁路计划费等；含税与否指是否含增值税 |
| 船板价 | 船已装煤、发运前的一切费用：坑口价、税费、汽车运费、船码头税费 |
| 场地价 | 某堆放场地交货价，一般不含税 |
| 平仓价 | 港口装船后的价格 = 煤价 + 港杂费（国内各港约 15-20 元/吨），卖方负责装船但不付海运费 |
| 到库价 | 到达指定仓库的价格 = 车板价 + 运费 + 途中其他费用 |
| 到站价 | 交货地火车站交货价 = 基础价（如出库价）+ 运输费用 |
| CIF（到岸价） | 原文解释残缺；通行含义为卖方承担至目的港的运费与保险费 |
| FOB（离岸价） | 货物越过船舷后卖方即可收款；装船前费用风险归卖方，租船订舱、海运费、保险归买方 |
| 港杂费 | 卸车、堆存、装船等港口费用，各船公司/港口标准不一 |
| 含税价 / 不含税价 | 是否含增值税；文中按 17% 举例（100 → 117）——**注意：17% 为旧税率，2019 年 4 月起适用税率为 13%** |
| 含税/不含税包干价 | 运至用户指定地点的一口价；需发票则以煤价+运费为基数加税 |
| 一票制 / 两票制 | 一票 = 煤炭增值税票与运输发票合并开具；两票 = 分开开 |
| 小款 | 签约后支付的居间费/中介费，付给提供煤炭资源渠道的居间人 |
| 大款 | 开票价格 + 运费 + 装卸费 + 杂费，即开票口径的全成本 |
