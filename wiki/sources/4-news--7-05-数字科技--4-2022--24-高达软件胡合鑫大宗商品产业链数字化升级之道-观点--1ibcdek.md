# 高达软件胡合鑫：大宗商品产业链数字化升级之道（观点，2022）

万联网 2022-06-15 发布的 CSCFIS 第九届中国供应链金融创新高峰论坛（2022-05-31）现场报道，依据演讲速记整理、未经嘉宾审阅、内容有删减。演讲人：高达软件副总经理 [[entities/胡合鑫]]。

## 核心论点

1. **产业集群生态系竞争论**：企业竞争实质是产业集群生态系之间的竞争；交易、物流、仓储、金融构成"铁三角"，产业金融必须站在产业链整合能力之上。详见 concepts/产业集群生态系竞争论-2022胡合鑫口径。
2. **"交易不是痛点"论**：2014-2015 年约 300 家钢铁电商平台，如今第三方交易模式基本出清；更核心的能力是基于产业集群的整合（尤其仓储与货物安全），"如果整合不了仓储，货物不安全，那怎么敢做代采"。详见 concepts/交易不是痛点论-2022胡合鑫口径。
3. **仓储业态演进**：前店后铺 → 2003 公共仓（高达第一套仓储系统）→ 商贸大楼+电子商务 → 2012 钢厂前置库（产能过剩产物）→ 仓储物流联盟（自由库/合作库/加盟库）+ 物联网监管仓。详见 concepts/仓储业态演进四阶段-2022胡合鑫口径。
4. **6+1+N 与微服务中台**：综合服务平台 + 六位一体（采购、电商平台、贸易、仓储、物流、金融）+ N 个中台（技术/业务/数据/物联网中台及 AI），统一合同中心、客商中心；2021 年获华为鲲鹏认证并与华为数据库联调。详见 [[concepts/6加1N数字供应链服务平台方案-2022高达口径]]。
5. **物联网监管仓与场景化风险管理**：云仓+物联网+云监管三位一体；仓库准入、仓储数据与物联网数据 PK、风控数字表达；预警逐级推送（10 分钟不处理逐级上报至银行管理层）；物联智盒专利；行车改造实现钢卷三维立体定位（耗时半年、24 小时轮班）、激光雷达测体积反算重量；**金属绝缘导致贴标签方案不可行，只能改造作业设备而非物资本身**。详见 [[concepts/物联网监管仓三位一体与场景化风险管理-2022高达口径]]。

## 重要合作与案例事实（自述口径）

- 高达钢铁社会库仓储软件占有率自述第一；欧冶在钢厂端仓储系统占有率第一，双方强强联合，高达成为欧冶在钢铁仓储软件**唯一合作伙伴**。
- 与钢银成立合资公司。
- 2017 年 4 月与平安总行签订协议，高达作为物联网技术监管单位，共建 47 大类风控体系。
- 历史节点：2003 首套仓储系统（银行仓单融资）、2004 仓储系统质押管理模块、2014 物联网平台、2017 技术中台迭代。

## 数字大宗产业链十大典型案例（名单与数据）

| 案例 | 要点 |
|---|---|
| 物产中大物流 | 企业物流转型物流企业，2 库→50 库，常规库存突破 200 万吨，年吞吐 5 千万吨 |
| 三钢闽光（福建） | 合作库物联网改造后开展仓单融资 |
| 本钢恒达物流园 | 园区智慧管理为基础的钢铁综合供应链服务 |
| 宁夏亿博丰 | 传统监管公司线上化数字监管（含活体奶牛物联网监管） |
| 库尔勒冷库（新疆，与万联网对接） | 100 多个冷库改造，代采代销 + 农产品融资 |
| 滨易融（山东，地方国企） | 叉车改造实现三维定位，物联网支持当地产业集群 |
| 广珠物流（珠海） | 火车专运线+码头+公路一体化，贸易物流一体 |
| 广物中南建材 | 广物金属+中南钢铁+欧冶合资，十四五目标 800-1000 亿规模；对接钢铁王国电商/云仓/物流、韶钢、云筑网等多系统接口 |
| 中国兵器阳光七采 | 集采平台 2019 年成交量突破 2100 亿，后有航天平台 |
| 湖南钢铁电商 | 与湖南钢铁集团的销售电商平台 |

规模数据（200 万吨、5 千万吨、2100 亿、800-1000 亿）均为演讲自述/转述口径，未独立核验，详见 findings/高达软件合作与案例数据快照-2022自述口径 与 [[queries/查询-高达软件物联网监管仓落地案例与10大典型案例明细考证]]。
