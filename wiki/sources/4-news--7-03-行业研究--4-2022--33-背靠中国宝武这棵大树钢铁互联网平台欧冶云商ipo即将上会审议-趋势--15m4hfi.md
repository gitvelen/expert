# 背靠中国宝武这棵“大树”，钢铁互联网平台欧冶云商IPO即将上会审议

- **日期**：2022-10-31
- **来源**：[万联网](https://info.10000link.com/newsdetail.aspx?doc=2022103190002)，部分内容参考证券时报《钢铁互联网平台欧冶云商IPO即将上会审议》
- **证据强度**：一般新闻报道 + 招股书转述口径（财务数据可溯源至招股书，但为媒体转述）

## 核心内容

2022年10月28日，深交所创业板上市委公告：11月4日审议欧冶云商发行上市申请。欧冶云商2015年2月由宝钢集团（现中国宝武）整合大宗商品电子商务资源设立，定位为集交易、物流、加工、知识、数据和技术综合服务为一体的第三方产业互联网平台，控股股东为中国宝武（2022年《财富》世界500强第111位）。截至2021年末，中国宝武、宝钢国际、宝钢股份、太钢创投合计直接持股61.38%。

## 关键数据（招股书转述口径）

- 平台（截至2022-06-30）：企业注册用户16.3万家，钢铁交易SKU 216万个；2022H1钢铁交易及服务量3,302万吨，仓储服务量1,725万吨
- 营收：2019–2021年分别为559.84 / 747.72 / 1,266.69亿元；2022H1为566.08亿元（同比-12.91%，上海疫情影响，统购分销成交量同比-28.6%）
- 归母净利润：5,125.55万 → 2.77亿 → 4.48亿元；2022H1约2.06亿元
- 业务结构（2021年）：互联网交易业务营收1,101.98亿元、占比87%；物流服务2.83%；互联网服务仅0.2%
- 扣非归母净利润：2019年 **-1.01亿元**、2020年2.06亿元、2021年1.78亿元；政府补助3,607.27万 / 5,212.9万 / 7,950.74万元，非经常性损益1.84亿 / 1.01亿 / 3.32亿元
- **关联交易**：2019–2022H1向关联方采购商品/接受劳务金额211.27 / 251.30 / 405.40 / 159.50亿元，占当期营收38.38% / 34.04% / 32.32% / 28.47%
- IPO拟募资15亿元，投向生态运营平台升级、研发中心、大宗商品智慧物流平台、智慧加工服务系统四项目

## 批判性要点

1. **“第三方平台”定位与控股股东依赖的张力**：自称第三方产业互联网平台，但关联采购长期占营收30%+，市场对平台独立性存疑——本文最有价值的批判性信息。
2. **千亿营收与盈利质量的张力**：净利率不足0.4%，扣非利润单薄且2019年为负，政府补助依赖明显；“统购分销”重资产自营模式撑大流水。
3. 本文为宣传性叙事（董事长表态等），证据价值弱于财务数据部分。
