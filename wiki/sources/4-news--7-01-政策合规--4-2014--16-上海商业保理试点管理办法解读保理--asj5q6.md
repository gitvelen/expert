# 《上海市商业保理试点暂行管理办法》解读（2014）

2014-07-22 发布于中国贸易金融网（sinotf.com），转载并解读上海市商务委员会、上海市工商行政管理局于 2014 年 7 月 1 日发布的《上海市商业保理试点暂行管理办法》（见 [[上海市商业保理试点暂行管理办法]]）。

## 背景

- 《办法》共五则 29 条，2014-08-01 实施，有效期至 2016-07-31。
- 自 2012 年 6 月起，天津、上海、深圳、广州、重庆等地先后试点商业保理，各地办法不一；上海工商登记注册的商业保理企业约 66 家。
- 上海市政府常务会议定调：既鼓励大胆试、不预设条条框框，又强调底线思维、防范风险。
- 解读观点主要来自上海市中茂律师事务所保理法律研究中心主任 [[林思明]]。《办法》整合了此前浦东新区、嘉定区、黄浦区、青浦区、上海自贸区的试点实践，形成全市统一规范。
- 注意：自贸区内设立商业保理企业仍按区内规定（第二十八条），与市级办法并行。

## 商业保理定义（办法第三条）

供应商与商业保理商（非银行机构）签订保理协议，将现在或将来的应收账款转让给商业保理商，从而获取融资，或获得分户账管理、账款催收、坏账担保等服务。区别于银行的保理业务，见 [[商业保理]]。

## 林思明总结的五大亮点

1. **经营业务分类准确、范围广**（第十二条）：按功能分类为应收账款融资、销售分户账管理、应收账款催收、坏账担保、经许可的其他业务，覆盖全部业务；自贸区/浦东办法按跨境与否分类（进口保理、出口保理、离岸保理）不够严谨。用"应收账款融资"替代"贸易融资"更准确，可覆盖服务合同项下应收账款。浦东原有办法不含进口保理，若与市级办法一致可能拓宽业务范围。
2. **对投资者要求更严格**（第七条）：投资者资产总和 ≥5000 万元且两年内无违法违规和不良记录——其他试点办法所没有。
3. **风险管控新规**（第十七、十八条）：按季度提取资产损失准备金（参照《非银行金融机构资产风险分类指导原则（试行）》）；为股东及关联实体担保或融资总余额不得超过该股东出资金额。均为上海独有；背景是试点中确有保理公司向股东关联公司提供融资的情况。
4. **引入社会机构参与风险评估**（第二十六条）：每两年一次第三方评估并公示。林思明保留意见：律所如何参与尚不清楚，需避免加重企业"负担"。
5. **建立行业协同监管机制，公安局在列**（第二十三、二十七条）：首次将公安部门列入行业监管及法律责任追究部门，列举七类刑事违法情形，对"借保理洗白高利贷""涉嫌非法吸收公众存款"等风险起警示作用。

## 关键量化约束（条款原文摘要）

| 条款 | 约束 |
|---|---|
| 第七条 | 投资者资产总和 ≥ ¥5000 万且两年无不良记录；注册资本 ≥ ¥5000 万（实收货币资本）；≥1 名投资者（或关联主体）有保理相关行业经历；≥2 名 3 年以上金融高管 |
| 第十一条 | 持股 >5% 的股权转让、增股东、合并、分立须参照设立程序变更 |
| 第十三条 | 禁止：吸收存款；放贷或受托放贷；专职催收/讨债；受托投资等 |
| 第十六条 | 风险资产 ≤ 净资产总额 × 10 倍 |
| 第十八条 | 对股东及关联实体担保/融资总余额 ≤ 该股东出资额 |
| 第十九条 | 须在人民银行征信中心应收账款质押登记公示系统办理应收账款转让登记 |
| 第二十条 | 在境内已加入国际性保理企业组织的商业银行开设运营资金人民币专用存款账户 |
| 第二十二条 | 重大事项 5 个工作日内报告（含净资产 5%/10%/20% 阈值的关联交易/债务/或有负债/损失等八类） |
| 第二十六条 | 第三方评估每两年一次并公示 |
| 第二十八条 | 自贸区内按区内有关规定执行 |
| 第二十九条 | 2014-08-01 至 2016-07-31 有效 |

## 与本 wiki 其他条目的关联

- 与 [[商业保理协同监管机制]]：协同监管信息系统、公安入列、第三方评估、资金存管与信息报送均属该主题。
- 与银行保理监管（银监发[2013]35号、《商业银行保理业务管理暂行办法》）属不同监管主体与适用对象，对照见 [[银行保理与商业保理监管对比]]。
- 第十九条转让登记与 [[应收账款转让与质押的区别]] 同系统呼应。
- 第二十七条"应收债权重复质押、转让或欺诈性交易"与 [[重复质押一女多嫁]]、[[青岛港国际]] 的风险模式相通。
- 第三条明确"现在或将来的应收账款"，为 [[未来应收账款保理的监管边界演变]] 提供商业保理侧的重要证据。
