# 探索地方供应链公共服务新模式！湖北首家县域综合型供应链公共服务平台在南漳上线（趋势）

## 来源概况

- 公众号：万联网（资讯栏目），2024-08-08，转载自南漳政府网/县融媒体中心。
- 体裁：趋势类资讯，内容为官方宣传口径，无独立验证。

## 核心事实

1. **2024-07-31**，襄阳（南漳）地方供应链公共服务平台上线，为**湖北省首家县域综合型供应链公共服务平台**。
2. 平台功能：原材料集采、供应链物流、供应链金融、数智仓储已上线；产品/人才供需对接、惠企政策兑现、信息服务等增值服务在建。
3. 运营模式：**政府主导、国企运营、市场化运作**，以"半公共产品"形式服务县域企业。县长陈栋称其最大特点是"以平台为核心"，解决山区县缺少龙头企业、产业链不完善导致的供应链弱势。
4. 供应链金融：依托湖北省"4321"担保体系，与[[entities/襄阳市融资担保集团有限公司]]合作，"国企出资、政策性担保公司担保、会员企业白名单支撑、政银企共同兜底"，形成"金南漳园区贷"授信模式；[[中国农业银行]]、[[entities/邮储银行|中国邮政储蓄银行]]等多家银行入驻。
5. 省县协同：南漳县委县政府与[[entities/湖北供应链物流公共信息服务股份有限公司]]（[[湖北港口集团]]下属，董事长董政）对接建设；平台连接国家、省、市大数据平台，依托省级运力池与大数据宣称确保"交易主体、交易信息、交易标的、交易行为"四真实性，提供"资产信用和数据信用双重支撑"；数智仓储宣称"金融增信'贷得到'、数仓控货'管得住'"。

## 量化数据快照（政府/平台自述口径）

| 指标 | 数值 |
|------|------|
| 上线企业 | 110余家（规上工业、物流运输、电商类） |
| 入驻金融机构 | 近10家 |
| 上线两天签约授信 | 4200万元 |
| 2023年全县工业物流总产值 | 近10亿元 |
| 平台预计年营收 | 约255万元（收支相抵、略有盈余） |

## 论点与证据强度评估

- **"以平台替代龙头企业"的县域公共服务模式**（县长陈栋口径）：证据强度**低**，属官方自述愿景。
- 量化数据：证据强度**中低**，县政府口径、无独立来源。
- 集采降本、物流撮合、数智仓储存货融资支撑等均为规划性/宣传性描述，引用须注明口径。

## 内部张力与风险暗点

- 平台定位公益性，但以近10亿元物流产值仅支撑255万元年营收"略有盈余"，**抗代偿能力极弱**：一笔代偿（"政银企共同兜底"中县级国企份额）即可击穿财务模型。
- "国企出资 + 政策性担保 + 白名单 + 共同兜底"实质为政府信用密集介入；数智仓储"管得住"无任何货权管控机制细节，属宣称而非验证，与本库融资性贸易、货权管控议题相关。
