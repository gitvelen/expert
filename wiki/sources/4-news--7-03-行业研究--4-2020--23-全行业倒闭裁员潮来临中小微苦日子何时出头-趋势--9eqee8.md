# 全行业倒闭/裁员潮来临！中小微苦日子何时出头（趋势，2020）

万联网 2020-04-15 原创资讯文章，盘点疫情冲击下各行业倒闭/裁员情况。核心论点：服务业（餐饮、旅游、家电）受创最重，但**真正受影响最深、恢复最慢的是中小微企业**——它们不会迎来报复性消费/订单，只能靠政策"供氧输血"。文中明确提到"供应链金融成为很多中小微企业的不二选择"，是疫情期中小微融资主题的关键连接点。

## 内容要点

### 一、行业倒闭/裁员盘点（2020年前两月至3月）

- 餐饮：2020年前两个月全国餐饮业企业注销超 1.3 万家。
- 旅游：据企查查数据，截至 2020-03-25，全国共 11,268 家旅游类企业注销、吊销经营。
- 家电（制造业代表）：海信集团传闻裁员——知情人士称措施为"高管带头降薪、末位淘汰"，但"定向裁员1万人"信息不实，执行程度视国外市场疫情而定；海尔否认裁员，称从 CEO 到总经理均自愿放弃绩效薪酬以保一线员工利益。（传闻与公司否认并存，证据强度弱。）
- 畜牧业：封城封路致饲料原料供应中断，部分养殖场限制畜禽日消耗量，甚至出现大量扑杀畜禽降产能的极端现象。

### 二、中小微经营压力数据（媒体转引"有报告数据"，出处未署名）

| 指标 | 数值 |
|---|---|
| 面临成本压力的公司 | 86.9% |
| 存在现金流短缺问题 | 69.7% |
| 现有现金难以支撑超过3个月 | 约半数 |
| 难以支撑1个月 | 近14% |
| 租金压力 | 59.13% |
| 员工工资和五险一金压力 | 45.5% |

三重短缺：用工短缺、现金流短缺、原材料短缺。应对方式：降低成本、向商业银行贷款、裁员，以及**供应链金融**（被定位为中小微应急融资选项）。

### 三、政策应对（2020-03-25 国新办吹风会，人社部副部长游钧解读国办《意见》）

1. 减负提速：阶段性减税降费，抓好社保费阶段性减免落地。
2. 稳岗提标：不裁员/少裁员的中小微企业，失业保险稳岗返还标准由上年度缴费的 50% 提高到最高 100%。
3. 扩就业加力：企业端社保补贴、定额税收减免、担保贷款和贴息；个人端限额税收减免、担保贷款和贴息、场地安排。
