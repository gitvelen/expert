# “1+2+3+5”目标确定！《福建省“十四五”金融业发展专项规划》重磅发布

万联网2021年10月11日报道：福建省人民政府印发《福建省“十四五”金融业发展专项规划》，将“十四五”期间金融业主要发展目标概括为“一中心、两平台、三个示范区、五个更加”，并提出“六大重点任务”和“十大专项行动”。

## 核心内容

- **一中心**：把福建打造为特色金融优势突出、国际化特征鲜明的区域金融中心
- **两平台**：海丝金融合作平台、两岸金融融合发展平台
- **三个示范区**：普惠金融改革示范区、绿色金融改革示范区、金融服务实体经济示范区

## “十三五”成果数据

| 指标 | 数据 |
|---|---|
| 金融业增加值占GDP比重 | 提高0.9个百分点 |
| 金融机构、地方金融组织数量 | 增长近70% |
| 2020年金融业税收 | 占全省财政总收入14.3% |
| 地方法人金融机构总资产 | 突破10万亿元 |
| 存贷款余额年均增速 | 8.9%和12.2% |
| 保费收入年均增速 | 9.8% |
| “十三五”末境内上市企业 | 151家，居全国第7位 |

## “十四五”目标（2025年）

| 指标 | 目标 |
|---|---|
| 金融业增加值 | 5000亿～5100亿元，占GDP约7.7%～7.85% |
| 地方法人金融机构资产总量 | 14.5万亿元 |
| 存款余额 | 8.2万亿元 |
| 贷款余额 | 9万亿元 |
| 非金融企业直接融资 | 年均5000亿元以上 |
| 新增上市公司 | 年均13家以上 |
| 保费收入 | 超2000亿元，年均增速超10% |
| 政府性融资担保放大倍数 | 4倍 |
| 平均融资担保费率 | 1%左右 |

规划还提出制造业贷款、绿色信贷等增速高于“十三五”时期。

## 十大专项行动

直接融资跨越发展、保险发展、海洋金融、金融支持乡村振兴、普惠金融、碳金融、数字金融、闽台金融合作、海丝金融、金融风险防控。

## 与本wiki主线的关联

本规划未直接部署供应链金融，属于背景性省级金融政策；但其普惠金融改革示范区定位与 [[普惠金融定向降准三档两优]]、[[小微企业金融服务监管评价办法2020]] 等普惠金融议题可衔接，绿色金融/碳金融内容则可延伸至绿色信贷相关研究。另可视为 [[供应链金融地方政策竞赛20192020]] 所述省级金融政策竞赛在“十四五”阶段的续篇观察对象。
