# 2023第五届中国西部航空物流合作大会（趋势）

万联网 2023-07-08 报道（记者毛莉），记录 2023-07-07 在成都举办的“第五届中国西部航空物流合作大会”。大会主题为“增强航空物流连通性，赋能国际国内双循环”，由成都市人民政府、四川省人民政府口岸与物流办公室、成都市口岸与物流办公室、成都市贸促会指导，[[中国航空运输协会]]、[[中国民用机场协会]]、北京北辰会展集团联合主办，约 300 名政企学界代表参会。

## 会议脉络与要点

| 演讲者 | 机构 | 要点 |
|---|---|---|
| 刘学军 | 成都市口岸与物流办公室 | 成都国际航空货运枢纽建设成绩与政策：引育多元化市场主体、航空通道与适航产业协同 |
| 王云访 | 中国民航管理干部学院 | 航空货运枢纽两种发展模式框架，详见 [[concepts/航空货运枢纽两种发展模式-王云访口径]] |
| 尤怀墨 | 中国民航科学技术研究院 | 市场恢复至 2019 年的 94.7%；行业由“高度依附型”向“独立发展型”转变，“科技+平台”双加持，四特征（前低后高、品类分化、价值提升、产品融合） |
| 焦林 | 骄冠科技 | RFID 物联网赋能航空货运（企业宣传口径） |
| 刘欣 | 国药控股 | 进口药械多口岸联动，[[concepts/医药进口多口岸多仓联动模式-国药口径]] |
| 肖尧 | 成都双流国际机场 | 2022 年货邮吞吐量首达 22 万吨、增长近 50%；[[concepts/机场两场一体与双枢纽错位运营]]、跨境电商专班保障、“客货并举” |
| 赵菁 | 翌飞锐特 | 数字化本质（连接、共生、当下）；[[concepts/ONE-Record航空货运数据交换标准]] 实践 |
| Samuel Girma | 埃塞俄比亚航空 | 中非航线与非洲市场推介 |
| 侯薇 | 北京首都机场集团 | 北京“一市两场”双枢纽错位：首都机场“提质”（跨境电商、航材高端物流），大兴机场“上量”（中转、冷链、多式联运） |
| 李庆洋 | 巴西航空工业公司 | 预测未来二十年中国市场需 240 架小型/跨界窄体货机（企业预测口径） |
| Natig Khalilov | 阿塞拜疆驻华使馆 | 欧亚“中间走廊”推介 |
| 赵杰 | 成都通用机场运营管理公司 | 通航物流；准州机场为四川省、成都市唯一全面对公众开放的 A1 类通用机场，34 家驻场单位、23 架航空器、102 家签约单位（招商口径） |

下午圆桌由邹建军主持，伊藤洋华堂（中国）、波兰驻成都总领事馆、菜鸟国际、埃塞俄比亚航空嘉宾围绕“航空物流助力新消费”探讨生鲜、中波、医药冷链、中非等话题（仅概述，无具体数据）。

## 证据与引用注意

- 官方机构口径（民航科学技术研究院、民航管理干部学院、成都市口岸与物流办）可信度中高；各企业主张（骄冠 RFID、翌飞生态圈、国药“全国一盘棋”、巴航货机预测、准州机场数据）为宣传性/利益相关口径，引用时须标注为企业披露。
- 内部张力：“独立发展型”转型是趋势判断而非已实现事实，现状仍以腹舱恢复为主。
- 94.7% 恢复口径的时间区间（2023 年上半年？货量还是运量？）待核，见 [[queries/查询-中国航空货运恢复至2019年94.7口径考证]]。
