# 保理业务术语表（贸易金融，2014）

## 来源概况

- 发布渠道：贸易金融公众号，栏目 Factoring，2014-11-05，无作者署名
- 内容性质：译自英文维基百科的发票保理（invoice factoring）专业术语表，按 A–Z 字母序罗列约 40 个术语，为入门级定义
- 语境警示：术语反映**美国普通法语境**（UCC、mechanics lien、Medicaid/Medicare 等），非中国大陆监管口径；翻译讹误较多（详见下文"讹误备注"）

## 关键定义性内容（结构化保留）

| 英文术语 | 页面译名 | 含义要点（2014 译介口径） |
|---|---|---|
| factoring | 保理 | 公司通过向保理公司出售发票实现应收账款融资的业务形式 |
| ABL (asset-based loan) | 基于资产的贷款 | 以库存、房地产、设备或应收账款担保的短期贷款 |
| advance / advance rate | 前进 / 进展速度 | 预付融资额及其占发票面值的百分比，通常 **70%–85%** |
| factoring fee | 保理费 | 以发票面值折扣计，随时间按每 30 天递增（示例约 1.5%） |
| rebate / reserve | 退税 / 储备 | 客户付清发票后释放的余款 / 用于覆盖坏账与短收的留存比例 |
| lockbox | 锁箱 | 银行代收付款项并扫描单据的国库管理制度 |
| notice of assignment | 任务（讹误，应为 notice） | 通知客户发票已转让并告知付款地址 |
| verification | 验证 | 保理商与客户核对发票真实性与价值 |
| recourse / non-recourse | 追索权 / 无追索权保理 | 无追索权下保理商吸收客户违约信贷损失，**最常见仅覆盖破产情形** |
| confidential factoring | 机密保理 | 不通知客户的保理，即中文语境"暗保理" |
| construction factoring | 施工保理 | 面向建筑分包商的特殊保理形式 |
| medical factoring | 医疗保理 | 对接私人保险公司、Medicare/Medicaid 等第三方支付方 |
| freight factoring | 运货单保理 | 面向运输/货运代理的保理 |
| PO financing | 采购订单融资 | 仅为成品采购提供资金，通常与保理配对解决回款 |
| concentration / credit limit | 浓度 / 信用额度 | 单一账户占组合比例的风控管理 / 对单个客户的授信上限 |
| UCC / UCC lien | UCC / UCC连战（讹误，应为 lien） | 美国统一商法典及其担保利益登记制度 |
| offset account | 抵销账户 | 互为客户与供应商的两家公司，融资困难 |
| debtor financing | 债务国融资（讹误） | 澳大利亚用语，泛指保理/发票贴现 |

## 讹误备注

原文机翻讹误明显，引用前需对照英文原术语：'债务国融资'应为 debtor financing；'诺亚'应为 notice；'UCC连战'应为 UCC lien；'任务'条目实为 notice of assignment。详见 [[查询-保理业务术语表翻译讹误与英文原版对照核验]]。

## 证据强度

属一般公众号/维基转译层级，低于书籍与监管原文，且为美国语境术语，仅作术语参照系，不构成中国监管口径依据。
