# 供应链高手必须掌握的79个专业术语（供应链融资，2017-03-25）

## 来源概况

- **性质**：公众号科普资料，2017-03-25 发布于“供应链金融”公众号，源自 sinotf.com，尾注注明“物流指闻、博润微信平台整理发布”，属二次转载整理稿。
- **内容**：79 条英中对照的供应链/物流/库存管理术语，条目体系（activity-based costing、ATP/CTP、BOM、EOQ、bullwhip effect、postponement、risk pooling 等）与 APICS 词典高度相似，且文中自称定义"Customer"以终结术语争论，呈词典式编纂口吻，疑为 APICS 词典译本衍生。参见 [[查询-供应链术语表2017的英文原始出处是否为APICS词典译本]]。
- **可信度**：专业公众号转载，可信度层级最低；译文质量粗糙，存在多处讹误（见下），不宜单独采信。

## 译文讹误记录（不照搬）

| 条目 | 问题 |
|---|---|
| #1 activity-based costing | “简介成本”应为“间接成本” |
| #38 distribution newwork | “newwork”系 network 拼写错误 |
| #61 make-to-order strategy | 中文解释（“在需求预测的基础上进行生产，形成产品库存”）实为 make-to-stock 的定义，与 #73 pull chain 的解释直接冲突 |
| #16/#55 carrying cost 与 holding cost | 同条互指，术语不一致 |
| #13/#33 bullwhip effect 与 demand amplification | 互为别名 |
