# 保兑仓产品操作流程及其4大风险点（万联网微课堂，2019）

万联网微课堂 2019-12-21 发布的课程内容，系统讲解预付类供应链金融三大产品（代采、保兑仓、经销商融资）的本质区别，重点拆解保兑仓的定义、十二步操作流程与四大风控要点。属专业公众号分析，可信度居中。

## 核心内容

1. **预付类三产品对比**：代采 = 一手交钱一手交货；保兑仓 = 控货 + 供应商回购等担保；经销商融资 = 不控货但控回款 + 回购/差额补足，风控难度最高。
2. **保兑仓双重必要条件**：货物质押（直接或间接掌握所有权）+ 核心企业承担一系列责任（按约定交货、退款回购、调剂销售、差额补足、取消经销商资格），缺一不可。
3. **十二步操作流程**：购销协议 → 核心企业推荐经销商 → 授信申请 → 核定担保/银承额度 → 四方协议 → 缴纳保证金 → 银票直达核心企业 → 生产发货入指定仓库 → 质押监管入库 → 缴保证金申请解押 → 银行出具解质通知书发货 → 违约时核心企业兜底。
4. **四大风控要点**：
   - 核心企业推荐经销商是首要风控要点，核心企业不愿配合即不愿承担担保，风险大；
   - 赊销场景下核心企业可能串通经销商提前回款、借经销商授信加杠杆，须评估经销商真实销售消化能力（本文独有洞见）；
   - 核心企业授信额度统一管理，援引155号文（2019年7月）要求，勿盲信核心企业；
   - 银票须真实送达核心企业并确认签收，防经销商截留银票伪造背书贴现致核心企业免责；控货对核心企业亦有价值——回款保障本质来自未售货物可回购。

## 术语与笔误提示

- 原文"保兑仓/保税仓"混用；"职务监管确认书"应为"货物监管确认书"；"新企业"应为"核心企业"；"大企业暴利"应为"大企业暴雷"。引用时须校准术语。
- "强担保/软担保"界说较粗（"汇入表的担保"表述不严谨），引用时注意。
