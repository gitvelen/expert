# 市场份额缩水 众品专心发展供应链（经济视点报，2012）

## 概述

原载《经济视点报》2012-02-23，天屹网（sinotf.com）供应链栏目存档。报道 [[河南众品食业]] 在肉食品市场份额被双汇、金锣、雨润挤压的背景下，将发展重心转向冷链物流与供应链服务，标志性事件为 [[昆山冷链物流基地]]（投资10.3亿元）。核心论点是 [[全产业链竞争替代产品竞争论-众品2012口径]]。

## 关键事实

1. **重心转移动因**：《规划》称众品已在肉食品行业建立较强影响力，但面临生猪屠宰和肉制品行业垄断竞争格局，双汇、金锣、雨润占据主要市场份额，企业持续快速发展面临压力。注意：报道同时存在"市场份额缩水"（标题）与"已建立强大影响力"（正文）两种表述，属企业战略话术的两面并存。
2. **昆山冷链物流基地**：筹建中，称有望年底投产；对标苏沪最大冷链基地。借鉴法国汉吉斯、深圳农产品海吉星（见 [[深圳市农产品股份有限公司]]）、杭州五丰、普飞斯、西肉、美冷等案例，整合物流、商流、信息流、资金流（详见 [[冷链物流园区四流整合与多案例对标模式-2012口径]]）。
3. **众品布局**：2006年在美国纳斯达克主板上市（中国食品行业首家），全国布局15个标准化食品加工和冷链物流产业基地；定位"专业从事农产品加工、食品制造和冷链物流服务于一体的企业集团"。
4. **河南供应链管理滞后**：受访人（陈伟、卢秋义）称河南企业对供应链管理概念意识不深、服务能力低下；河南服务业培训中无来自河南的优秀案例。

## 结构化数据快照（企业宣传口径，2012）

```
昆山冷链物流基地（筹建中，2012）
- 总投资: 10.3亿元
- 年物流量（达产后）: 146万吨
- 建设内容: 冷库、生鲜农产品加工配送中心、展示交易中心、信息系统、品质检测中心
- 定位: 苏沪规模最大冷链物流基地 / 长三角标准化程度最高枢纽之一
借鉴案例: 法国汉吉斯、深圳农产品海吉星、杭州五丰、普飞斯、西肉、美冷
产业基地: 全国15个标准化食品加工和冷链物流产业基地
上市: 2006年，纳斯达克主板（中国食品行业首家）
```

## 证据强度说明

- 项目数据全部来自企业提供的《规划》与总监张金萍资料，属企业宣传口径，证据强度低。
- 卢秋义（河南省供应链管理协会筹备组联络人）、仝新顺（郑州轻工业学院教授）言论为评论性观点，不作事实引用。
- 陈伟"曾获国际供应链管理大奖"无具体奖项名称，真实性存疑（见 [[查询-陈伟国际供应链管理大奖真实性核验]]）。
- 众品后续（约2018-2019年）发生严重债务危机并从纳斯达克退市，与本篇2012年乐观叙事形成强烈对照，详见 [[查询-众品2012年冷链转型与后续债务危机退市的事实验证]]。
