# 供应链合同敏感词与担保条款实务口径快照（媒体转述口径2025）

## 事实条目

1. **审计敏感词五类**（2025年万联网培训口径）：固定收益/保底利润；无实际货权转移/货物不移动；仅提供资金服务/走账通道；上下游是关联方；循环交易。
2. **定金上限20%**：《民法典》法定规则，通识性口径。
3. **违约金上限约合同金额30%**：文中称"法院一般认这个数"。注：《民法典》第585条实际以实际损失为基准调整，30%系约定俗成说法，司法口径待核验（见 query）。
4. **"60%的亏损源于合同漏洞"**：万联网培训口径，无出处，属营销性归因——与审计口径（违规贸易结构本身为主因，参见浙江/多地审计 finding）不同，弱化处理。
5. **两则匿名案例**（质量条款净亏500万、担保不明1000万预付款落空）：匿名化转述，无法核验，仅作条款设计教训参考。

## 证据强度分层

| 证据 | 强度 | 依据层级 |
|------|------|------|
| 定金≤20%（法定上限） | 高 | 法律通识（《民法典》） |
| 质量条款法律依据（《民法典》511条、《标准化法》2条） | 高 | 法律通识 |
| 违约金30%司法口径 | 中低 | 媒体说法，需司法实践核验 |
| 审计敏感词清单 | 中 | 专业公众号观点（万联网2025） |
| "60%亏损因合同漏洞" | 低 | 无出处营销口径 |
| 两则匿名案例 | 低 | 未核验转述 |
