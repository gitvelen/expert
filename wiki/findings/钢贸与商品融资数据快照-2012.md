# 钢贸与商品融资数据快照（2012）

以下数据均出自 2012 年 3 月理财周报报道，属**一般新闻/匿名信源级证据**，不得当作监管统计引用。

| 数据项 | 数值 | 信源 |
|---|---|---|
| 钢、煤质押占全部商品融资业务量 | 70% 以上 | 某大型股份制银行高层 |
| 质押融资贸易商集中地 | 河北、辽宁等 | 同上 |
| 单笔贸易所需银行贷款比例 | 交易额的 70%–80% | 沈阳钢贸商 |
| 信用证保证金比例 | 20%–30% | 某国有行高层 |
| 商品融资较银行借贷成本差 | 低 4%–5%（利率口径模糊） | 上海小型钢贸商 |
| 钢贸商融资额度压缩 | 被砍 1/3 至一半 | 沈阳钢贸商李先生 |
| 还款高峰 | 2012 年 3 月（上年 9 月借款到期） | 同上 |
| 续贷放款时间 | 从两三天延长至大半个月以上 | 上海宝山钢贸商群体 |
| 钢材流通量变化 | 从七八十万吨降至四五十万吨 | 沈阳钢贸商 |
| 融资铜进口主要操作方 | 五矿、迈科、万向（传闻口径） | 市场},

## 证据强度分层

- 全部条目均为**一般新闻报道**，多数出自匿名信源（银行高层、钢贸商个人），中等至弱证据强度。
- "70% 以上质押占比"出自某股份制银行高层个人转述，非监管统计。
- "工行为云南铜业第二大股东"等股权信息属媒体表述，与融资服务混同，未经核实，不纳入本快照事实。

## 时效性

2012 年快照，仅作历史对照；后续数据以更新的来源页为准。
