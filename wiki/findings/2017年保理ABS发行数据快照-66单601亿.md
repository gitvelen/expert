# 2017年保理ABS发行数据快照：66单 / 601.19亿元

- 2017年保理资产证券化产品共**66单**（交易所ABS 65单 + 交易商协会ABN 1单），发行金额**601.19亿元**，占资产证券化市场整体约**4%**，为交易所ABS发行市场**第5大产品**（数据来源：cnabs，中国资产证券化分析网）。
- 其中供应链金融模式贡献近半：**18单 / 218.14亿元**。
- 底层资产分布：房地产**49单 / 467.04亿元**，电商**10单 / 63.20亿元**。
- 首单参照：2016年"平安证券-一方保理万科供应链金融1-4号"融资52.25亿元（深圳市前海一方商业保理 + 平安证券）。
- ABN首单参照：2017年12月底前海结算商业保理（深圳）通过五矿信托发行碧桂园供应链保理ABN，融资9.28亿元。
- 2018年初（截至2018-02-11）已发行5只 / 53.2亿元；储架剩余供给预测≥1300亿元（**机构观点，非事实**）。

## 证据强度分层

- **中等（专业研究机构转述市场数据）**：cnabs 发行统计（66单 / 601.19亿、行业分布），转引自元亨智库文章（2018）。
- **观点（机构推介性内容）**：千亿储架供给预测与"配置空间"表述，仅适用2018年口径。
