# 2014年前海跨境贷规模与成本数据快照（前海管理局与受访人口径）

## 规模数据（前海管理局披露口径，截至2014-10-20）

- 备案金额：526亿元（人民银行年初“500亿”备案目标提前完成）
- 实际用款：82亿元（约备案额的15.6%）

## 成本数据（某国有大行前海业务负责人何平[化名]自述口径，2014）

| 模式 | 成本 |
|------|------|
| 传统模式（融资性保函） | 5.9%–7.4%（保函手续费1%–2.5% + 境外融资4.2%–4.4% + 税费；≈基准下浮2.7%至上浮23.3%） |
| 同业授信免保函模式 | 5.4%（≈基准下浮10%） |
| 融资租赁通道（售后回租，含增值税抵扣） | 5.03%–7.02% |

## 证据强度分层

- **规模数据（526亿/82亿）**：前海管理局官方披露，经专业财经媒体（21世纪经济报道）转述——证据强度较高。
- **成本数据与模式描述**：单一银行受访高管（化名）自述，媒体转述，未经交叉验证——证据强度中等，不可推广至其他银行或跨境融资产品。
- **风险评价（同业授信不具担保效力）**：某股份行国际部人士评论——观点性内容，非监管口径。
