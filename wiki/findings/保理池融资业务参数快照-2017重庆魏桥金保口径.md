# 保理池融资业务参数快照（2017重庆魏桥金保口径）

以下参数来自 2017-07-18 公众号"贸易金融"发布的重庆魏桥金保实务口径文章，均为"原则上"表述，非监管规定，仅代表该公司一家口径（2017 年口径）。

| 参数 | 2017 重庆魏桥金保口径 |
|------|----------------------|
| 融资期限 | 可长于实际付款期限，原则上最长不超过一年 |
| 融资比例 | 原则上不超过 80% |
| 应收账款付款期限 | 原则上不超过 120 天 |
| 转让方式 | 对特定买方或所有买方应收账款整体转让，存续期间持续入池 |
| 回款路径 | 增值税发票开户行账号变更为保理专户/监管账户；买方付款付至专户或监管账号 |
| 风险保障 | 实时池余额监控，任一时点余额×折扣比例须覆盖融资余额 |

## 证据强度分层

- **专业公众号分析（厂商自述口径）**：全部参数均来自 [[重庆魏桥金保]] 通过公众号"贸易金融"发布的产品介绍文，属厂商自述的实务操作标准，非监管要求，代表性与执行情况未经独立验证。
- **对比基准**：低于监管原文（如 [[商业银行保理业务管理暂行办法]]）与书籍层级；与 [[银行保理应收账款负面清单-暂行办法口径]] 所载银行口径不可等同视之。

## 注意事项

- 上述参数不可推广为行业统一标准。
- 2019 年 205 号文后商业保理监管收紧，期限错配等口径可能已被重新框定，见 [[查询-池融资期限错配与不通知买方结构在205号文及民法典后的合规空间考证]]。
