# 2011年IMF《世界经济展望》宏观预测快照

2011年4月WEO口径（经中国证券报专访转述）：

| 指标 | 2011年预测 |
|---|---|
| 全球经济增速 | 4.4% |
| 发达经济体增速 | 2.4% |
| 新兴市场和发展中经济体增速 | 6.5% |
| 发达经济体CPI | 2.2%（美国2.2%、欧元区2.3%） |
| 新兴经济体通胀率 | 6.9% |

另：IMF当时下调了美国与日本2011年增速预期。

## 证据强度分层

- IMF WEO数据：官方报告口径，经专业财经媒体（中国证券报）转述，证据强度较高（次级转述，建议后续对照IMF原文）。
- 萨特尔对上述数据的认同与延伸判断：访谈观点，非事实性数据。
