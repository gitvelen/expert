# 央企融资性贸易监管文件演进快照（2013至2024）

国资委对融资性贸易、"空转""走单"的监管政策已从"管控"发展到"严禁"，演进链条：

| 年份 | 文件 | 核心要求 |
|---|---|---|
| 2013 | 国资厅发评价【2013】31号 + 评价函〔2013〕92号 | 严禁无商品实物、无货权流转或原地转库的融资性业务（钢贸危机背景） |
| 2014 | 国资评价〔2014〕1200号 | 通报央企融资性业务风险，要求处置风险、规范核算、责任追究 |
| 2017 | 国资财管〔2017〕652号 | 一经发现立即停止并退出；明确"空转""走单"属虚假贸易；依国办发[2016]63号严肃问责 |
| 2023-04 | 《关于做好2023年中央企业违规经营投资责任追究工作的通知》 | 对融资性贸易、"空转""走单"虚假业务"零容忍" |
| 2023-10 | 《关于规范中央企业贸易管理 严禁各类虚假贸易的通知》（"十不准"） | 划定虚假贸易禁区，含"不准开展任何形式的融资性贸易"等十项 |

另：国资委在《关于加强地方国有企业债务风险管控工作的指导意见》及各年度央企财务决算通知中多次提及"清理、杜绝"融资性贸易、"空转""走单"。2022年财务决算期间国资委以会议形式要求会计师事务所年审中特别关注、发现即上报。
