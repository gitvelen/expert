# 2016 年社会物流宏观数据快照（中物联口径）

据薛洪言文章转引中国物流与采购联合会数据（2016 年）：

| 指标 | 数值 |
|------|------|
| 社会物流总额 | 229.7 万亿元 |
| 物流业总收入 | 7.9 万亿元 |
| 社会物流总费用 | 11.1 万亿元 |
| ——运输费用 | 6.0 万亿元 |
| ——保管费用 | 3.7 万亿元 |
| ——管理费用 | 1.4 万亿元 |

另引工商总局口径：截至 2016 年底，全国个体私营经济从业人员实有 3.1 亿人，接近人口总量的四分之一（线下小 B 规模的佐证）。

## 证据强度分层

- 中物联、工商总局数据：**监管/官方统计口径经媒体转引**，数值可信度较高，但建议与官方原始发布核对。
- 文中"万亿市场"的规模判断：作者推论（观点），非统计结论。
