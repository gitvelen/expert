# 山东世界级港口群2025年量化目标快照

出自《山东省世界级港口群建设三年行动方案（2023-2025年）》（鲁政办字〔2023〕98号，2023-07-26印发）原文。

| 指标 | 2025年目标 |
|---|---|
| 沿海港口货物吞吐量 | 突破20亿吨（2022年底基数：突破16亿吨） |
| 集装箱吞吐量 | 突破4000万标准箱（2022年底基数：突破3700万标箱） |
| 万吨级以上泊位 | 总数达380个（新建深水泊位20个，重点实施52项工程） |
| 自动化泊位 | 新增5个 |
| 零碳码头/零碳港区 | 4个/1个 |
| 港口清洁能源和新能源占比 | ≥60% |
| 外贸航线 | 278条；集装箱中转量740万标箱（占比超18%） |
| 内陆港 | 50个 |
| 集装箱海铁联运量 | 420万标准箱 |
| 中欧班列累计开行 | 超10000列 |
| 大宗商品平台交易额 | 5000亿元 |
| 骨干航运企业控制总运力 | 突破2000万载重吨，船舶超200艘 |
| 青岛新华·波罗的海指数 | 全球第13名（航运服务第17名） |
| 安全生产信用A级及以上企业占比 | 超50% |

## 证据强度分层

- **官方文件原文**：上表全部目标与任务分工——最高档，直接引用政策文本。
- **媒体转述**（万联网导语）：2022年基数16亿吨/3700万标箱"继续稳居全球第一、第三位"——一般新闻报道层级，排名口径建议另行核验。
