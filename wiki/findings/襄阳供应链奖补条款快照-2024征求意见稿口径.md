# 襄阳供应链体系奖补条款快照（2024 征求意见稿口径）

以下为《关于加快全市供应链体系建设的若干措施》（襄阳，征求意见稿，2024-05-22发布征求意见）各奖补条款的原文数字口径。

## 全量条款表

| 场景 | 奖补对象 | 标准 | 上限 |
|---|---|---|---|
| 数字化平台建设 | 平台开发方（部署襄阳云计算基地、纳入统计，投资≥500万） | 实际投资额20%（一次性） | 500万/项目 |
| 上链企业数字化改造 | 上链企业（投资≥100万） | 实际投资额10%（一次性） | 50万/项目 |
| 上链企业数量补贴 | 供应链平台 | 规上500家补50万；规下1000家补30万 | 一次性 |
| 平台交易规模补贴 | 综合平台/重点行业平台（汽车、电子、纺织、特色农产品） | 年交易10亿补100万/年；行业3亿补30万/年 | 本地收入占比≥50%可上浮50%；入驻企业真实年交易≥1亿的一次性补10万/企业 |
| 物流枢纽费用补贴 | 枢纽节点转运主体（仓储、短驳、装卸费用优惠） | 视减免幅度，≤合同价格20% | 200万/年 |
| 集货疏货物流企业营收补贴 | 服务枢纽联运企业（年营收≥1亿、纳入统计） | 营收额0.5% | 100万/年 |
| 应收账款融资撮合 | 对接中征应收账款融资服务平台的核心企业（年促成≥1000万） | 促成贷款0.5% | 200万/户/年 |
| 供应链票据签发 | 核心企业 | 签发量0.2% | 200万/户/年 |
| 订单/预付款融资责任承担 | 核心企业（订单确认付款、担保/回购） | 支持贷款额0.5% | 200万/户/年 |
| 第三方存货担保监管 | 仓储机构 | 实际服务费率50%（≤融资额0.5%） | 500万/年 |
| 商业保理投放 | 保理服务企业 | 实际投放额1% | 200万/年 |
| 存货融资 | 金融机构 | 贷款额1% | 200万/年 |
| 平台企业贷款贴息 | 供应链平台入驻企业 | 1年期LPR的50%且不高于实际利率 | 50万/户/年 |
| 科创项目撮合 | 重大项目（市科技计划项目内） | ≤项目投入总额25% | 300万/项目 |
| 技术转移机构/高校院所撮合 | 技术转移机构2%、本地高校院所10% | 按实际到位资金 | 30万/年/家 |
| 评级创优 | 国家5A/4A/3A/2A供应链企业 | 50/40/20/10万 | 一次性 |
| 示范企业 | 全国供应链创新与应用示范企业 | 50万 | 一次性 |
| 绿色供应链 | 国家级/省级绿色供应链管理企业 | 50万/20万 | 一次性 |

## 通用规则（原文口径）

- 同一项目同一事项符合其他文件的，按**就高不重复**原则享受；
- 奖补资金按现行财政体制**分级负担**；
- 自发布之日起实施，**有效期三年**，由市发改委、市财政局会同有关部门解释。

## 证据强度分层

- **官方原文（征求意见稿）**：上述全部条款数字，出自万联网转载的襄阳市人民政府政策原文，层级最高；但属征求意见稿，正式发文可能调整条款。
- **媒体转述**：万联网正文中的背景性说明（如“还将出台……提供强有力保障”），层级低于原文。
- **广告内容**：文末研修班课程推广，不具证据价值。
