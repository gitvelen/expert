# 利丰供应商网络规模快照（2012口径）

据 2012-09-21《中国商界》摘编（经"供应链金融"公众号转载）：

| 项目 | 数据 |
|---|---|
| 供应商网络覆盖 | 全球 40 多个国家和地区 |
| 合规供应商数量 | 15000 多家 |
| 供应商类型 | 生产商、运输商、设计公司、市场营销公司 |
| 供应商守则依据 | 相关国家法律 + 国际劳工组织（ILO）主要公约 |
| 不合格供应商分级 | 持续改善 / 立即行动 / 零容忍（零容忍即逐出体系） |
| 哈佛教案 | 曾四度被哈佛商学院作为教案 |

## 证据强度分层

- **一般新闻报道/杂志摘编（证据强度：中等）**：以上数据均出自《中国商界》摘编文章，文中未提供原始统计出处（公司年报、第三方审计等），属二手转述，引用时须注明"2012 年媒体口径"并避免作为硬事实单独引用。
