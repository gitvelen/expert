# 上市银行应收款项类投资规模与结构数据快照（2016年6月末口径）

数据来自26家上市银行公开披露，经穆迪分析师尹劲桦整理（《中国银行业》2016年第9期）。

| 指标 | 数值 | 口径 |
|---|---|---|
| 应收款项类投资余额 | 2.5万亿元 → 11.7万亿元 | 2012年底 → 2016年6月末 |
| 占总资产比 | 8.9% | 26家上市银行，2016.6 |
| 投向：信托/资管计划 | 68% | 2016.6 |
| 投向：其他银行理财 | 13% | 2016.6 |
| 投向：债券 | 19% | 2016.6 |
| 拨备余额/投资余额 | 0.4% | 2016.6 |
| 剩余期限>1年 | 44.6% | 2015年底，17家披露 |
| 剩余期限3个月-1年 | 34.2% | 同上 |
| 股份行CAGR（9家） | 97% | 2012-2016.6 |
| 地方行CAGR（12家） | 65% | 2012-2016.6 |
| 占总资产：股份行/地方行/五大行 | 21.2% / 23.0% / 2.5% | 2016.6 |
| 9家股份行非存款负债/总资产 | 30%（2014）→ 36%（2016.6） | — |
| 证券类投资利息收入增速 | +29.7%（总利息收入仅+5.4%） | 2015年同比 |
| 2015年新增贷款收益权转让登记额 | 222亿元，多为城商行出售 | 银登中心登记 |

## 证据强度分层

- **事实数据**（上市银行公开披露，专业期刊整理）：规模、投向结构、增速、占比、期限分布等上表数字——可信度较高。
- **观点/推断**（穆迪作者判断，非既成事实）："拨备潜在不足""私募ABS未登记""负面作用超过积极影响""贷存比低估"等风险判断，应作为前瞻性观点引用。
- 适用边界："中小银行风险更大"仅指9家上市股份行与12家上市地方性银行样本。
