# 雅下水电工程核心参数与效益快照（新华社/媒体口径2025）

## 官方口径（新华社，2025-07）

| 项目 | 数值/表述 |
|------|-----------|
| 成立/开工时间 | 2025年7月19日（雅江集团揭牌） |
| 业主单位 | [[中国雅江集团]]（第99家央企，国资委直管序列第22位） |
| 工程位置 | 西藏自治区林芝市 |
| 开发方式 | 截弯取直、隧洞引水；5座梯级电站 |
| 总装机容量 | 6000万千瓦（约3个三峡电站） |
| 总投资 | 约1.2万亿元 |
| 官方定位 | 水风光互补清洁能源基地；低碳绿色工程；落实能源安全新战略与治藏方略 |

## 媒体测算口径（未经官方确认，证据强度：中）

- 水电装机占比由16%提升至22%，非化石能源消费占比突破35%。
- 年减排二氧化碳约3亿吨。
- 每年为西藏贡献财政收入超200亿元，带动西藏GDP年均增长2-3个百分点。
- "数十万就业岗位"：以三峡工程20万岗位×3倍规模的类比推算。

## 推测性主张（证据强度：中低，须与事实区分）

- 向印度、孟加拉国出口绿电、构建"亚洲能源共同体"。
- 碳汇交易开辟绿色金融新空间。
- 墨脱—察隅—米林复合走廊的应急投送等军事化解读。

## 证据强度分层

1. **高**：央企成立时间、国资委公告、业主定位——有国务院国资委2025年第1号公告与新华社报道背书。
2. **较高**：装机6000万千瓦、投资约1.2万亿元、5座梯级电站、截弯取直隧洞引水——新华社转述口径；具体技术表述（如"派镇以上600亿立方米"）建议与新华社原始通稿比对核验。
3. **中**：能源结构占比变化、减排量、财政贡献、GDP拉动、就业——媒体测算与类比推断。
4. **中低**：绿电出口、"亚洲能源共同体"、地缘投送——推测性/观点性内容。
