# 2018年平安-四川广电供应链金融1号ABS发行数据

2018年3月初，"平安-四川广电供应链金融1号资产支持专项计划"公告成立，为首单传媒行业供应链金融ABS暨全国首单精准扶贫供应链融资项目，拟于深圳证券交易所挂牌交易。计划管理人为平安证券，托管人为平安银行成都分行。

| 项目 | 数值 |
|---|---|
| 总发行规模 | 2.73 亿元 |
| 优先级证券 | 2.58 亿元（94.51%），评级 AA+（上海新世纪资信评估） |
| 次级证券 | 0.15 亿元（5.49%） |
| 底层资产 | 四川广电上游中小微供应商的货物贸易应收账款 |
| 原始权益人/资产服务机构 | 深圳市前海明生商业保理有限公司 |
| 贫困县分公司 | 19 家（宣汉、古蔺、北川羌族自治县、马边彝族自治县等） |
| 贫困县涉及货款 | 3,356.61 万元，占发行规模约 12.30% |

## 证据强度分层

- **一般新闻报道**（万联网转载，单一来源）：上述全部发行数据与"首单"表述。未见交易所挂牌公告或评级报告佐证，强度**中等**，重大引用建议复核深交所与登记结算信息。
- 文中"精准扶贫的社会效益"叙事为报道口径，不构成信用增强事实。
