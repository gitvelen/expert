# 2017 年转口贸易套利产品组合快照（华夏银行口径）

来源：张继翊（2017）。**本页为 2017 年汇率利差环境下的历史套利手法存证，用于风险识别与历史研究，不构成操作指引。**

## 以套利为目的的六类产品组合

1. **存美贷美**：存入 >300 万美元保证金同时办理美元表内融资，赚取存款收益与融资成本之差（占银行外币贷款规模）。
2. **存美元 + 美元保付**：保付受益人境外贴现或境内 NRA 福费廷贴现（不占外币贷款规模）。
3. **存人民币 + 美元保付**：签订远期购汇基础上办理美元进口保付，赚价差并博远期与即期汇率之差的汇兑损益。
4. **存人民币 + 外币表内融资**：融资品种为外币流动资金贷款、进出口押汇、进出口代付（占外币贷款规模）。
5. **票据质押 + 美元保付**：未到期票据直接质押，省去贴现成本。
6. **票据质押 + 外币表内融资**：同上原理。

另有存美元+人民币开证/保付、"欧贷通"等变体，原理均为利差+汇差套取。

## 融资套现型

敞口开证为典型（10% 保证金开 200 万美元、90 天远期信用证进口电解铜，转卖境外第三方电汇结算，可套取约 2 个月资金，滚动开证实现长期占款；跨境人民币信用证不受短债指标限制可拉长期限）。此外有保税区内仓单质押/货物质押非开证模式，作者归入供应链金融范畴未展开。

## 证据强度分层

- 专业公众号实务分析（银行从业者）：第三层可信度，作为 2017 年套利环境的历史标本使用。
