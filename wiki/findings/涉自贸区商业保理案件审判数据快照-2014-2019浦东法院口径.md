# 涉自贸区商业保理案件审判数据快照（2014-2019 浦东法院口径）

数据来源：上海市浦东新区人民法院 2020 年 4 月发布的审判情况通报，统计区间 2014-2019 年（2014-2019 年末口径）。

| 指标 | 数据 |
|---|---|
| 受理案件（逐年） | 2 / 24 / 41 / 82 / 141 / 182 件，共 472 件 |
| 未纳入统计的批量案件 | 2015-2016 年 358 件某商业保理（上海）有限公司案（经审理未被认定为保理合同纠纷） |
| 审结案件 | 共 417 件；结案率 100% / 87.5% / 87.8% / 89.0% / 87.9% / 88.5% |
| 结案方式 | 判决 178 件（42.7%）、调解 80 件（19.2%）、撤诉 122 件（29.3%）、其他 37 件（8.9%），调撤率 48.5% |
| 平均审限 | 91.5 天 |
| 公告送达率 | 56.0%（264 件） |
| 财产保全率 | 68.4%（323 件） |
| 标的额 | 200 万元以内 307 件（66.4%）；超千万 91 件（19.2%） |
| 涉诉保理公司 | 64 家，逐年增加（2016-2019 增速 200% / 90% / 75% / 39.2%） |
| 保理公司作被告 | 仅 6 件，占 1.3% |
| 被告行业 | 第三产业为主：交通运输业 36.8%、信息服务业 26.4% |
| 业务类型 | 明保理 290 件（61.5%）、暗保理 182 件（38.5%） |
| 被告结构 | 仅债权人 238 件 + 债权人与债务人共同 132 件（合计 78.39%）；仅债务人 102 件（21.61%） |

**结构解读**：被告以债权人为主、且普遍约定回购/反转让条款，反映涉自贸区商业保理以融资性保理为主的业务结构。

## 证据强度分层

- 监管/官方原文（法院官方统计通报）：**高**——以上全部数据。

## 历史数据说明

该快照为 2014-2019 年累计口径，反映自贸区保理纠纷爆发期的结构特征；民法典保理专章（2021 生效）后案件结构与裁判口径可能变化，需另行跟踪。
