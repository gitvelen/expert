# 2014年大宗商品现货电子交易特征口径快照（营销文章转述）

## 事实条目（2014 年从业方口径）

1. 交易对象为商品的**仓单合约**（商品所有权凭证），非商品本身；对应货物须符合"国市标准"（原文表述，含义存疑）并存放于市场**定点仓库**。
2. 采用**履约保证金制度**：买卖双方以履约金为事前保障，交易完结时计算机系统即时结清资金。
3. 采用**同货异地、同步集中竞价**模式，购买者在最近的定点仓库提货，以降低交易成本。
4. 交易品种范围受"国市标准"限制，窄于传统现货交易。

以上口径出自一般商业/营销文章（原始来源"奉皇商贸"，疑为交易平台相关方），**不可直接作为结论性事实**，仅作 2014 年现货电子交易市场推广叙事的快照留存。
