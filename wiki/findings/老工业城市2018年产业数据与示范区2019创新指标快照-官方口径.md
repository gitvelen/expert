# 老工业城市2018年产业数据与示范区2019创新指标快照（官方口径）

## 老工业城市经济体量（2018年，95个地市级）

| 指标 | 占全国比重 |
|------|-----------|
| 人口 | 25% |
| GDP | 22% |
| 工业总产值 | 27% |
| 规上工业企业 | 23% |
| 工业固定资产 | 29% |
| 装备制造业产值 | 1/3 |
| 钢铁工业产值 | 2/3 |

## 示范区创新指标（2019年同比增速，首批12个）

| 指标 | 增速 |
|------|------|
| 高新技术企业数量 | +49.0% |
| R&D投入占GDP比重 | +27.2% |
| 省级以上科研平台数量 | +14.4% |
| 高新技术产业增加值 | +13.7% |

## 其他快照

- 2013年国务院规划：120个老工业城市（地市级95个）、262个资源型城市（地市级126个）。
- 示范区：2017年起两批共20个，配套47个示范园区，15份政策文件。
- 自贡彩灯2019年出口6800万美元、+92%；大连政务服务网办率96.54%（地方上报口径）。

## 证据强度分层

- **监管原文/官方答记者问层级（较强）**：2018年老工业城市占比数据、2019年示范区增速数据、示范区与示范园区数量——均出自国家发改委振兴司负责人专访（《经济日报》转述，未见原始文件文号）。
- **媒体转述/地方上报口径（较弱，宣传属性）**：各城市案例数据（徐州90%宕口改公园、联合国人居署推广、大连网办率、自贡出口、黄石PCB排名、萍乡增速等），未提供核验来源。
- 49.0%等增速未列基数；示范区覆盖率（20/120+262）提示外推谨慎。
