# 第二届 2018 中国供应链金融年会嘉宾阵容与议题快照

**事实**：第二届 2018 中国供应链金融年会于 2018 年 4 月在北京举办，主办：《贸易金融》杂志、中国供应链金融网、中国贸易金融网。嘉宾（宣传名单口径）：

| 嘉宾 | 头衔 |
|---|---|
| 李毅中 | 第十二届全国政协常委、工业和信息化部原部长、中国工业经济联合会会长 |
| 魏建国 | 中国国际经济交流中心副理事长、商务部原副部长 |
| 张燕玲 | 国际商会全球理事会执行董事、中国银行原副行长、中国交易银行50人论坛（CTB50）主席 |
| 张竞强 | 中国中小企业协会常务副会长 |
| 蔡进 | 中国物流与采购联合会副会长 |

主题演讲主题：“数字供应链金融时代的破局与立势”。圆桌议题：①B2B 与供应链金融融合发展（电商 3.0 定制产品、金融资产平台交易闭环、平台/风控/融资/盈利一站式模式、四流合一、跨境 CBT 五角度）；②金融科技驱动的数字供应链金融；③资本视角下的供应链金融创投机遇；④细分行业对接供应链金融。

## 证据强度分层

- **中（可核验事实，但仅为宣传名单口径）**：年会时间、地点、主办方、嘉宾名单与议题设置——建议与主办方后续公告交叉核验。
- **低（软文观点）**：同文“2018 供应链金融井喷年”“B2B 弃烧钱转供应链金融”等判断，见 [[concepts/B2B电商弃烧钱转供应链金融论-2018软文口径]]，不属本 finding 固定的事实。
