# 2011年3月日本地震全球汽车供应链冲击数据快照（第一财经口径）

以下数据均出自《第一财经日报》2011-04-01 报道（丁彬），统计/报道时点为 2011 年 3 月下旬：

| 项目 | 数据 |
|------|------|
| 日本变速器年出口量 | 650 万台（IHS 预计，原文讹写为"HIS"） |
| 其中出口北美 | 200 万台 |
| 日本发动机和变速箱工厂停产 | 72 家中至少三分之二停产（上周口径） |
| 德尔福日本供应商受灾 | 200 个中 20 个确认位于震中 100 英里内 |
| 雷诺釜山工厂减产 | 15%-20%，约 3000 辆（因 SM7 日本供应商受影响） |
| 通用停产 | 西班牙、德国两家欧洲工厂及一家北美工厂（3 月 21 日起） |
| 在华日系车企零部件库存 | 部分只能支撑到 2011 年 3 月底 |

## 证据强度分层

- **一般新闻报道**（本文全部数据）：第一财经日报引述企业宣布、企业发言人及 IHS 预计，未经独立核验；"72 家工厂三分之二停产""650 万/200 万台"为咨询机构（IHS）预计口径。
- **观点性内容**：陈文凯"三四级供应商你中有我、影响还在扩散"的判断，属专业媒体分析口径，非量化定论。
