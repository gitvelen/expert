# 中小微企业数字化转型调研数据快照（2023 中国中小企业协会口径）

以下数据来自 [[entities/中国中小企业协会]]《中国中小微企业数字化转型状况分析报告》（2023-09-27 发布，454 份企业调研样本），经万联网转述。

| 维度 | 数据（2023 年口径） |
|---|---|
| 已开展数字化转型 | 62.11%（另有口径：69.38% 部分或核心业务已开展） |
| 核心业务全面数字化 | 7.27% |
| 未开展 | 5.51%（另有口径：30.61% 尚未开始） |
| 转型后生产/运营效率提升 5% 以上 | 85.24% |
| 转型后同期营收增长 5% 以上 | 68.28% 与 65.28%（文中两处数值不一致） |
| 通过固定服务商转型 | 60.79% |
| 通过云厂商网站 | 57.93% |
| 通过赋能活动 | 近半 |
| 依托所在园区 | 43.61% |
| 无完整战略和框架支持 | 54.41% |
| 数据整合利用能力不足 | 50.88% |
| 找不到适配产品和服务 | 46.70% |
| 资金压力为关键制约 | 67% |
| 担忧数据安全 | 55.29% |

## 证据强度分层

- **中**：行业协会调研口径（样本 454 份，代表性有限；效率/营收提升为企业自述，存在归因偏差与幸存者偏差可能）。
- **低（媒体转述层）**：开展率与营收增长数值在转述文中前后不一致，采信前须核对原始报告，见 [[queries/查询-2023数字化转型报告开展率口径矛盾与原始报告溯源]]。
