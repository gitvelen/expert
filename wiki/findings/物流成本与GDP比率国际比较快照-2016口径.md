# 物流成本与GDP比率国际比较快照（2016 口径）

以下数值系 [[蔡进]]（[[中国物流与采购联合会]] 副会长）2017 年解读 84号文时转述的中物联口径，为口径快照而非官方统计原文：

| 指标 | 数值（年份） |
|---|---|
| 中国物流成本总额 | 11.1 万亿元（2016） |
| 中国物流成本/GDP | 14.9%（2016）；18%（2012） |
| 全球平均 | 13% |
| 美国 | 8%–9% |
| 日本 | 约 8% |
| 中国：服务业占 GDP 每升 1pp 对应物流成本/GDP 降幅 | 约 0.5pp（1991–2016，中物联测算） |
| 美国：同上 | 0.56pp（1980s–2000s） |
| 作者推算 | 比率降至 8% 可节约"几万亿"（粗略推算，非统计） |

注意：物流成本/GDP 的国际可比性在学界有争议（统计口径差异），横向数值引用需谨慎；下降趋势本身可作方向性判断依据。

## 证据强度分层

| 证据 | 层级 | 说明 |
|---|---|---|
| 数值本身（11.1 万亿、14.9% 等） | 专业公众号分析（第三层） | 官员署名文章转述中物联口径，高于一般新闻、低于官方统计原文；原始出处待考（见 [[查询-2016年物流成本11.1万亿与14.9%比率的数据出处考证]]） |
| "降到 8% 省几万亿" | 观点推算 | 作者粗略估算，不得作为事实引用 |
| 供给驱动 vs 需求驱动之辨 | 观点性判断 | 未经实证 |
