# 2012年中国零售业供应链管理调查数据快照（媒体引述口径）

以下数据逐条归属于 2012 年一篇未署名零售企业调查（经中国行业研究网/[[4-news--7-04-业务基础--4-2012--20-我国零售业供应链管理的实施对策供应链管理--1napl50|来源页]] 引述），不可迁移至其他行业或年份。

```text
认知与组织：89.6% 不理解供应链管理；80.6% 未设供应链管理部门；
  已设部门中普遍等同于物流部门；93.8% 按职能设部门，6.3% 按品类设部门；
  50.7% 实现部门间信息共享共同决策；零售业内部供应链脱节 13.5%（制造业 3.5%）
零供关系：44.8% 与供应商合作 1–2 年
物流：85.1% 零售 / 65.2% 制造自备运输工具；94.0% 零售 / 97.2% 制造自备仓库；
  3.0% 尝试 VMI；库存周转 ≤20 天 32.8%，21–60 天 52.2%，>60 天 15%；
  73.1% 零售企业反映有缺货
技术：61.2% 零售终端全面条码；74.6% 人工点货；62.7% 有局域网；
  38.8% 网上公布商品信息；17.9% 提供网上购物
```

## 证据强度分层

- **一般新闻报道/媒体引述调查（低层证据）**：以上全部数据。调查执行方、样本框、样本量均未标注，可比性与代表性存疑，仅作 2012 年时点参考。文中"西方跨国零售巨头均已采用先进 SCM"为印象式判断，不固化为事实条目。
