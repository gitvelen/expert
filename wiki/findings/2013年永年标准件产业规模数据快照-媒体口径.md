# 2013年永年标准件产业规模数据快照（媒体口径）

据生意社 2013-08-05 报道（媒体转述产业数据，未经官方统计核验）：

| 指标 | 数值 |
|---|---|
| 标准件生产企业数 | 3880 家（标题/首段口径为“四千家/4000 余家”，两口径并存） |
| 从业人员 | 30 万人 |
| 产销量占全国比重 | 45% 以上 |
| 专业运输车辆 | 1500 余辆（运输从业人员 7600 多人） |
| 销售网络覆盖 | 全国 31 个省市自治区 |
| 物流市场年吞吐量 | 650 万吨 |
| 电商平台设计需求基准 | 300 万吨 |

永年为全国最大标准件生产基地和销售中心，系河北省十大特色产业之一。

- **一般新闻报道/媒体转述**：以上全部数据来自生意社报道，属媒体口径，未见官方统计来源。引用时应标注“2013 年媒体口径”。
