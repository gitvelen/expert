# 2021年545家中小板制造业现金循环周期数据快照（宋华自算口径）

宋华在 2022-05-31 演讲中自述基于 2021 年数据对 545 家中小板制造业上市公司的计算结果：

| 指标 | 数值 |
|---|---|
| 应收账款周转天数（均值） | 82.12 天 |
| 存货周转天数（均值） | 127 天 |
| 应付账款周转天数（均值） | 81.69 天 |
| CCC（现金循环周期）均值 | 128.42 天 |
| CCC 中位数 | 99.2 天 |

解读口径：均值大于中位数，说明大多数中小板制造业企业 CCC 偏大，营运资金压力显著。

## 证据强度分层

- **专业分析 + 个人计算口径**：为演讲者自行计算的转述结果，样本筛选口径（545 家的具体范围）与计算方法未经审计或论文形式发表，引用时须注明"宋华自算/速记口径"。
