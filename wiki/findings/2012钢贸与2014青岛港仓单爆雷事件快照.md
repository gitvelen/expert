# 2012 钢贸与 2014 青岛港仓单爆雷事件快照

（据万联网 2020-09-11 加佳科技案例文章口径）

## 2012 年钢贸事件

- 2012 年 8 月被爆出，是大宗行业形势急转直下的导火索。
- 主因：① 被业内认为"最安全、最可靠"的**仓储机构参与仓单造假**；② 虚假仓单是行业内公开的秘密，出事后多谋求低调处理。
- 后果：银行、国企甚至民间资本到期贷款收回后不再续贷，大规模收缩贷款导致钢贸商资金链大面积断裂，钢贸危机全面暴发。

## 2014 年青岛港重复质押仓单骗贷事件

- 贸易商将**同一批货开具不同仓单**，涉事企业"一单多压"，用同一批货重复质押向银行贷款。
- 涉及多家中资商业银行，**涉嫌骗贷贷款总额超过百亿元**（媒体口径数字，需核验）。

## 共性启示

两次事件共同指向：仓储环节失控 + 银行间质押信息割裂 → 仓单造假/重复质押得逞。这是动产融资爆雷的典型共性，也是区块链仓单/物联网监管仓类方案（[[entities/加佳科技]]、[[entities/货兑宝]]）试图解决的问题。

## 证据强度分层

- **中等（一般新闻报道/企业案例文章口径）**：事件经过与因果描述，来自万联网转载的企业白皮书案例文章，非监管通报或司法文书原文。
- **需核验**：青岛港案"贷款总额超过百亿元"的具体数字、涉案银行名单——建议回溯 2014 年当时监管通报与司法判决。
- **背景佐证（较可靠）**：两次事件在行业内为公认标志性事件，与本 wiki 多篇来源的叙事一致。
