# 2020年3月CCFI各航线春节后跌幅快照

**事实（2020 年口径）**：2020 年春节后 CCFI 由 964.95 降至 936.65（-2.93%），显著超出 2008–2019 年春节后正常波动区间（12 年中 9 升 3 降，最大跌幅 -1.26%）。分航线春节后变化（WIND 数据，作者计算）：

| 航线 | 变化 |
|---|---|
| 地中海 | -10.1% |
| 韩国 | -8.5% |
| 波斯湾红海 | -6.0% |
| 南美 | -5.4% |
| 欧洲 | -3.6% |
| 日本 | 2.5%（疑漏负号，存疑待核验） |
| 南非、东西非 | 上升 |

同期 CICFI 变化约为 0，进口冲击尚不明显。案例佐证：菲亚特-克莱斯勒塞尔维亚工厂、现代汽车、日产汽车因中国零部件短缺停产/部分停产。

## 证据强度分层

1. **强**：CCFI/CICFI 指数本身为官方发布的运价指数数据。
2. **中等偏强**：分航线跌幅与历史区间对比为研究员基于 WIND 数据的计算，方法透明但依赖间接代理变量。
3. **中等**：车企停产案例来自彭博社等媒体报道转述。
4. **存疑**：日本航线 "2.5%" 疑漏负号，与正文"日本受较大冲击"表述矛盾，待核验。
