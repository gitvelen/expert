# 周转率指标减值准备加回分析口径快照（2020马靖昊口径）

## 事实条目

1. **减值准备加回口径**（2020）：计算应收账款周转率/存货周转率时，须将已计提的坏账准备/跌价准备加回资产基数，否则指标失真。
2. **产业链强势度判读**（2020）：应收账款+应收票据为零且营收利润良好 = 产业链极致强势；存货周转天数 ≤ 半个月亦为强势信号。
3. **资金链预警**（2020）：自由现金流占营收 ≥5% 为优质；经营现金流连续多年为负且应收账款增速超营收增速，警惕资金链断裂。
4. **案例数据**（公开财务数据，仅针对该公司）：苹果存货周转天数 5 天；茅台存货周转率 2018 年 0.29、2019Q3 0.22（白酒企业存货战略使然，此时应收指标更重要）。

## 证据强度分层

| 条目 | 层级 | 说明 |
|---|---|---|
| 减值准备加回口径 | 专业公众号分析 | 财务分析通行原则的科普表述，方向可靠但非监管/准则原文 |
| 强势度判读（应收=0） | 专业公众号分析（观点） | 经验性/修辞性判断，受行业结算惯例约束，评论区有反例 |
| 自由现金流与资金链预警 | 专业公众号分析 | 经验法则，非实证结论 |
| 苹果/茅台数据 | 公开财务常识 | 低证据强度，标注年份口径，不可推广为行业基准 |

## 使用限制

- 不可将"应收周转天数=0=望远镜看不到对手"直接作为授信结论。
- 指标判读须结合行业属性与结算惯例，最终以贸易背景真实性与货权控制核查为准。
