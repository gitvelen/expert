# 城商行经营与供应链金融布局数据快照（2014-2015口径）

## 经营数据（2014年）

| 指标 | 数值（2014） |
|---|---|
| 城商行资产增速 | 年初22.9% → 年末19.1% |
| 城商行资产增速峰值 | 2012年7月32.1% |
| 城商行总资产市场份额 | 10.8%（2014年末，历史最高） |
| 城商行资产收益率 | Q1 1.3% → Q4 1.12% |
| 北京银行净利增速 | 30.72% → 14.33% |
| 南京银行净利增速 | 28.15% → 21.68% |
| 宁波银行净利增速 | 36.15% → 16.24% |

（香港上市4家城商行截至报告时点仅公布2014年半年度业绩，基本呈下滑态势。）

## 供应链金融布局

- 截至2015年末口径：资产总量排名前30位的城商行均已开展供应链金融相关业务，但业务差异性较大。
- 盈利下滑归因：资产增速下降、利率市场化利差收窄、发改委严查商业银行服务收费影响中间业务收入。

## 证据强度分层

- **专业机构报告分析（中等强度）**：以上数据与布局判断均出自银通智略报告《银行业务创新与营销案例》（2015年12月），经公众号“供应链金融”2016年2月转载；未附原始监管统计出处，引用时建议对照银监会/监管总局历年监管统计指标复核。
- **个案披露（弱-中等强度）**：大连银行三案例数据（5亿元汽车间接授信、1亿元轮胎投放预期等）为银行自我营销口径，无第三方核验。
