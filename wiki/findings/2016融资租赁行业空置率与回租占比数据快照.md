# 2016融资租赁行业空置率与回租占比数据快照

以下为2016年口径数据（2016-11-29 中国经营报报道），后续年份如有新口径应移入"历史数据"并更新本页。

## 数据条目

| 指标 | 数值 | 口径归属 |
|---|---|---|
| 全国开业一年内无业务的租赁企业空置率 | 65% | [[杨海田]]（中国融资租赁联盟召集人） |
| 部分地区空置率 | 85% | 杨海田 |
| 上海业务做得好的企业占比 | 不到1/4 | [[高传义]]（上海市租赁行业协会会长） |
| 上海刚开始做业务的企业占比 | 1/4 | 高传义 |
| 上海没怎么做业务的企业占比 | 50% | 高传义 |
| 国内售后回租模式占比 | 约70% | 转引公开媒体报道 |
| 即征即退实收资本门槛 | 1.7亿元 | 财税〔2016〕36号文（原文口径） |

## 证据强度分层

- **监管原文口径**：1.7亿元即征即退门槛（财税〔2016〕36号文条款）——最高。
- **专业媒体引述行业权威**：65%/85%空置率、上海1/4-1/4-50%分层（杨海田、高传义）——中高，属观察性行业协会口径，非统计部门数据。
- **专家判断 + 个案佐证**：至少70%小公司被挤出回租市场、城投回租搁置案例（刘军厂）——中。
- **二手转引**：约70%业务为售后回租——低-中，未见原始统计来源。
- **观点性**：P2P渠道评价、小公司中介化出路——中低。

## 注意事项

- 空置率不等于资金缺乏：有一定资金实力但不开展业务的情况不少见。
- 2016年口径，2018年银保监会统一监管与外资准入放开后是否改善，属开放问题，相关跟踪见 [[queries/查询-财税2016年36号文融资租赁即征即退1.7亿门槛的后续调整与现行口径考证]]。
