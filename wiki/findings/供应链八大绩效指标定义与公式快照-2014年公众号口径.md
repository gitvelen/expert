# 供应链八大绩效指标定义与公式快照（2014年公众号口径）

来源为 2014-03-21 公众号“供应链金融”转自与非网文章，以下公式为原文逐字保留。

```text
产销率 = 一定时期内供应链某节点已销售产品数 / 一定时期内供应链该节点已生产产品数

产需率 = 一定时期内某节点已生产的产品数（或提供的服务）/ 一定时期内下游节点对该产品（或服务）的需求数

准时交货率 = 准时交货（或服务）次数 / 总交货次数 × 100%

成本利润率 = 单位产品（服务）净利润 / 单位产品（服务）总成本 × 100%

产品质量合格率 = 质量合格的产品（服务）数量 / 产品（服务）总产量 × 100%
```

```text
库存周转率 =（使用数量/库存数量）×100%
库存周转率 =（使用金额/库存金额）×100%
库存周转率 =（该期间出库总金额/该期间平均库存金额）×100%
          = 该期间出库总金额×2/(期初库存金额+期末库存金额)×100%

以月平均为例：
  原材料库存周转率 = 月内出库的原材料总成本 / 原材料平均库存
  在制库存周转率   = 月内入库的成品物料成本 / 平均在制库存
  成品库存周转率   = 月销售物料成本 / 成品在库平均库存
```

其他指标定性口径：
- **产品出产（或服务）循环期**：各节点出产节拍或出产间隔时间，可取循环期总值或最长节点值作整体指标。
- **供应链总运营成本**：通讯成本 + 各物料/在制品/成品库存费用 + 各节点内外部运输总费用。
- 产需率总体评价按“木桶原理”取最低节点值。
