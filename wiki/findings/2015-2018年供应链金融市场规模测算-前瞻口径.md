# 2015-2018年供应链金融市场规模测算（前瞻口径）

前瞻产业研究院《中国供应链金融市场前瞻与投资战略规划分析报告》口径：

| 年份 | 市场规模 | 备注 |
|---|---|---|
| 2015 | 11.97 万亿元 | |
| 2016 | 约 13 万亿元 | |
| 2017 | 14.42 万亿元 | |
| 2018 | 约 16.51 万亿元 | **初步测算/预测口径**，理由为监管冲击互金 C 端、B 端有望爆发 |

配套基础设施数据（官方口径，较强）：

- 规模以上工业企业应收账款：2011 年 7.0 万亿 → 2018 年 11 月 15.0 万亿（年均复合增速 11.5%）；2018 年末 14.3 万亿（+8.6%），产成品存货 43119.1 亿元（+7.4%）。
- 融资租赁：2018 年末合同余额约 66500 亿元（较 2017 年末 60800 亿 +9.38%），公司 11777 家。
- 小微贷款余额：2017 年末银保监会口径 30.74 万亿（占银行贷款总余额 24.67%）；人民银行口径 24.3 万亿（占全部企业贷款 33%，+16.4%）；2018Q3 末 25.8 万亿（+10.0%）——两口径差异见 [[查询-2017年末小微贷款余额银保监会与人民银行口径差异]]。

## 证据强度分层

- 国家统计局、人民银行数据：**较强**。
- 前瞻市场规模测算：**中等偏弱**——"初步测算"，统计边界（是否含 B2B 原文标注、保理等）未明，见 [[查询-前瞻16.51万亿市场规模测算方法与后续修订]]。
