# 深发展供应链金融起源时间线快照（1999–2005 口径）

依据 2019 年公众号转述口径，深圳发展银行的供应链金融业务起源时间线为：

1. **1999 年**：个别分行开始供应链金融的探索与尝试。
2. **2003 年**：在业内率先提出"1+N"融资模式（1 = 核心企业，构成信贷风险管理"安全港"；N = 上下游成员企业）。
3. **2005 年**：推出"供应链金融"品牌产品，核心定义要素为：供应链内部交易结构分析 + 自偿性贸易融资信贷模式 + 引入核心企业、物流监管公司、资金流导引工具等风险控制变量 + 封闭授信。

- **公众号转述口径（中）**：本条时间线唯一来源为 [[sources/4-news--7-04-业务基础--4-2019--26-供应链金融出现动因运作模式特点风险防控分析供应链管理--1nbc2z1]]（供应链金融公众号转云票据/保理人，无署名），属二手拼贴综述。
- **原始文件（缺）**：1999/2003/2005 各节点的深发展原始文件（年报、新闻发布会、产品文件）尚未核验，已建 [[查询-深发展1N模式与2005品牌化的原始文件出处]] 跟踪。
- 行业影响：该口径与行业通说一致（深发展=中国供应链金融发源地），但精确年份归属建议以书籍或深发展原文复核后再升格为高强度事实。
