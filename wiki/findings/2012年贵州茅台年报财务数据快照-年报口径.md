# 2012 年贵州茅台年报财务数据快照（年报口径）

据贵州茅台 2012 年报（经 2013-08-21 新闻报道引述）：

- 销售收入 264.55 亿元，同比增长 43.76%
- 营业利润 188.31 亿元，同比增长 52.65%
- 利润总额 187.00 亿元，同比增长 51.61%
- 归属上市公司股东净利润 133.08 亿元，同比增长 51.44%；每股收益 12.82 元
- 拟每股派息 6.64 元，分红率 50%
- 1998 年以来实现“十四连增”

## 证据强度分层

- **较强**：上述财务数字引自上市公司 2012 年度报告（监管原文/定期报告层级经媒体转引），可复核年报原文。
- **较弱（企业宣传口径）**：“主导产品销售量、利税总额、利润等高居中国白酒行业榜首”、“世界蒸馏酒第一品牌”、“中国白酒行业绿色管理标杆”等评价性表述，出自企业自述/一般新闻报道，未经独立验证。
