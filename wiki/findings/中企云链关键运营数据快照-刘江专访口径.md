# 中企云链关键运营数据快照（刘江专访口径，2025-02）

以下数据出自 2025-02《中国经营报》刘江专访（万联网转载），均为企业负责人自述口径，尚未经财报或官方披露独立核对。

| 指标 | 数值 |
|---|---|
| 合作核心企业 | 近 5000 家 |
| 合作银行分支行 | 3000 余家（与各大银行总对总合作） |
| 服务企业 | 超 50 万家 |
| 累计确权金额 | 1.8 万亿元（自称国内首个确权破万亿的独立产业数字金融平台） |
| 银行投放应收账款融资 | 1.3 万亿元 |
| 平均融资成本 | 5 年间从年化 5.3% 降至 3.2%，且仍在下降 |
| 融资时效 | T+0 当天完成 |
| 产业数字化项目 | 800 多个 |
| 数据融资 | 近 50 亿元 |
| 亏损史 | 2015 年起亏损七年（刻意低费率战略） |

## 证据强度分层

- **专业媒体报道（转载企业负责人自述）**：以上全部数据，来源为《中国经营报》专访。属一手人物访谈，但数据独立验证有限，引用时应标注“刘江口径”。
- **待核对项**：确权 1.8 万亿、投放 1.3 万亿、首破万亿平台等无可核对出处，见 [[queries/查询-中企云链确权投放与融资成本数据的独立验证]]。
