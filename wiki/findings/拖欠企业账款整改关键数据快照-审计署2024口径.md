# 拖欠企业账款与隐性债务整改关键数据快照（审计署2024口径）

| 指标 | 数值 | 时点/口径 |
|---|---|---|
| 金交所违规涉众融资余额 | 373.42亿元（形成政府隐性债务112.58亿元） | 2023年底，审计署2024年6月报告 |
| 隐性债务问责 | 25批问责建议函、追责428人、曝光24起典型案例 | 2022年以来，财政部口径 |
| 新增拖欠 | 76.31亿元（其中5地区无预算项目新增69.5亿元） | 2023年3月以来，10省市56个地区 |
| 虚报存量清偿 | 53.28亿元 | 7省30个地区，2023年度 |
| 已偿还新增拖欠本息 | 37.96亿元 | 截至2024年9月底 |
| 整改虚假清偿涉及资金 | 17.74亿元 | 截至2024年9月底 |
| 化债置换安排 | 每年8000亿元、累计4万亿元 | 2024–2028年，财政部口径 |

## 证据强度分层

- **监管原文/官方文件层级**：上述数据均出自审计署报告与财政部公开信息（经万联网综合转述）——高。
- **媒体转述层级**：具体执行细节（抽查台账2万多笔、赴20多省80多市复核等）出自《报告》披露的部委整改表述——较高，但属部委自述。
