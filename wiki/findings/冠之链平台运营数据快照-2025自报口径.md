# 冠之链平台运营数据快照（2025 自报口径）

来源为万联网 2025-03-17 报道，数据由平台运营方/受访方提供，**未经审计**。统计时点为平台上线约一年（约 2025 年初）。

| 指标 | 数值 |
|---|---|
| 上线时间 | 2024-02-29 |
| 注册企业 | "近150家"（另一处表述为 140 家，截至 2024 年 1 月，见矛盾记录） |
| 企业融资意向 | 16.5 亿元 |
| 银行准入 | 4 家完成合作准入；3 家上报总行准入中（含工商银行、莱商银行） |
| 放款 | 18 户钢板企业、30 笔、累计 2.22 亿元 |
| 首笔贷款 | 300 万元（莱商银行，上线当日） |
| 首笔综合融资成本 | 较传统托盘模式降低 6.5 个百分点 |
| 传统代采成本参照 | 综合成本实质年化 12% 以上（高达软件受访口径） |

## 矛盾与口径问题

- 注册企业数"近150家"与"140家"内部不一致（可能为不同时点），见 [[查询-冠之链平台注册企业数与融资成本降幅口径考证]]。
- "降低 6.5 个百分点"同时被表述为"首笔贷款成本降幅"与"较托盘模式的普遍降幅"，且与高达"降低一半甚至以上"口径基数不同，需区分。

## 证据强度分层

- **一般新闻报道（万联网公众号原创，2025）**：上述全部数据均出自此层级，运营方自报、未经审计，强度较低。
- 无监管文件或审计报告交叉验证；与同类"政府主导平台自报数据"（如秭归脐橙平台）一样，后续实效待跟踪。
