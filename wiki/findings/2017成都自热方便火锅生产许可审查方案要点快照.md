# 2017 成都自热方便火锅生产许可审查方案要点快照

2017 年，成都市食品药品监督管理局发布《成都市自热式方便火锅生产许可审查方案（试行）》，要点（媒体转述口径）：

1. 从制定依据、适用范围、基本条件、生产许可条件审查、产品相关标准、原辅材料要求、标签标识和贮存运输、其它要求等八部分作出规定。
2. 申证企业须具备生产火锅底料和至少一种主要配菜包（蔬菜制品或肉制品）的生产加工能力。
3. 其他组配包可委托有资质企业生产或外购，但须设立独立的组合配装车间。
4. 原料及配菜包原则上应可在常温下储存。
