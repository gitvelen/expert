# 区块链落地场景清单（2019 益链专访口径）

据朱浩冰 2019 年受访列举，区块链的落地场景包括：

1. **健身产业**：教练认证 + 场地（围栏）认证，"双保险"确保服务体验。
2. **无车承运**：物流数据具备资产化特征，解决平台类无车承运企业的资金池制约痛点。
3. **大物流行业**：解决散、小、乱、杂、数据难以整合、商业模式催生难、业务转型难等问题。
4. **公益慈善**：解决捐赠容易跟踪难、被动参与体验差、组织众多分级缺等问题。

另有无结构化数据：自 2012 年以来全球以区块链为主的创新公司增速"超过 65.2%"（出处不明，见 [[查询-区块链创新公司65.2%增速数据出处]]）。

## 证据强度分层

- **一般新闻报道（企业自述转述）**：以上场景清单与 65.2% 数据均来自万联网对益链科技董事长的专访转述，属厂商宣传口径，无第三方验证与具体案例数据，使用时须标注"2019 益链专访口径"。可信度层级：一般新闻报道，低于监管原文与书籍。
