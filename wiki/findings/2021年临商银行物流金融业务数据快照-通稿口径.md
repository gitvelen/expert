# 2021年临商银行物流金融业务数据快照（通稿口径）

以下数据来自临商银行通稿（经万联网 2021-12-28 转述），**均为单方宣传口径，未经第三方验证**：

| 指标 | 数值 | 时点 |
|---|---|---|
| 临沂商城市场交易额 | 4403.5 亿元 | 2020 |
| 临沂商城物流总额 | 6847 亿元 | 2020 |
| 临沂商城网络零售额 | 269.7 亿元 | 2020 |
| 商通宝日均代发（峰值） | 约 3000 余万元 | 业务最高峰期 |
| 商通宝年累计代发（峰值） | 120 亿元 | 业务最高峰期 |
| 商通宝总发卡（峰值） | 约 10 万张 | 业务最高峰期 |
| 临商银行物流业贷款余额 | 60 余亿元 | 2021 |
| 服务物流商贸客户 | 3 万余户 | 2021 |
| 西城支行“物流贷”投放 | 300 余笔 / 6600 万元 | 截至 2021-12 |

注意：物流贷数据仅覆盖西城支行，不能外推为全行规模。
