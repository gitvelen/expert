# 商业保理行业空壳化数据快照（2015-2016 口径）

## 核心数据（2015 年底 / 2016 年转述口径）

截至2015年底，全国注册商业保理企业2514家，已开展业务约500家，仅约10%进入成长期——近八成企业处于"沉睡"状态。行业瓶颈为市场认知度不高、融资渠道受限、征信渠道不畅、政策法规不完善。

另一组多源表述与此互为同义口径：全国注册商业保理企业超2000家，实际开展业务的不足两成（即约八成"沉睡"/空壳）。其表述来源包括：

- 人民网2016年报道"八成商业保理公司在沉睡"。
- 《中国商业保理行业发展报告2015》与保理专委会（张燕玲、韩家平等）相关表述。
- 韩劲捷（京西保理总经理）2016-03在《中华工商时报》访谈中确认"超2000家、实际开展业务不足两成"，并将主因归结为**资金来源依赖银行**——商业银行不擅长供应链融资贷前贷后管理，对纯债权信用融资授信审慎。

三种"不足两成"表述互为同义口径（"八成沉睡" = "实际开展不足两成"），源头相近（均指向保理专委会系统），强度中。

## 结构性配套数据

| 指标 | 数值 |
|---|---|
| 注册商业保理企业 | 2514 家 |
| 已开展业务 | 约 500 家（约10%进入成长期） |
| 规模以上工业企业应收账款 | 11.46 万亿元 |
| 注册资本1亿元以下占比 | 63% |
| 注册地与经营地不一致占比 | 61% |
| 对P2P平台有合作需求的保理公司 | 83% |

该数据为理解2016年行业基线及后续监管（清理空壳保理企业）动机提供了背景。

## 相关结构性证据

同期京西保理自称获建行、北京银行、华夏银行、北京农商行累计15亿元类信用授信（公司自述，未经核验）——侧面印证银行授信是商业保理公司的核心资金约束。

## 证据强度分层

- **中高**（《中国商业保理行业发展报告2015》，行业报告原文，经行业协会负责人场合转述）：2514家/约500家/10%、11.46万亿应收账款。
- **中**（媒体转述行业调查，未见原始调查文件）：63%、61%、83%；人民网2016年报道（一般新闻）。
- **中低**（从业者观点/软文，但提供成因解释——银行授信约束）：韩劲捷2016访谈。
- **观点性内容，不作为事实引用**：张燕玲"银行惜贷让渡空间"论、韩家平双保理生态论。
