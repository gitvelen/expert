# ICC 供应链金融困惑五项排序调查（2019 年转述口径）

据国际商会（ICC）年度调查报告（张燕玲 2019 年文章转述），供应链金融的主要困惑按比例排序：

| 困惑项 | 占比 |
|---|---|
| KYC/KYCC/KYCB/KYD（了解你的客户/客户的客户/客户的业务/自己的文件） | 40% |
| 平台间缺乏共同一致的数据交换标准 | 34% |
| 内部政策不明确 | 31% |
| 会计核算不清楚 | 27% |
| 缺乏政策、监管支持 | 11% |

张燕玲认为中国虽无同类调查，但情况大体相同。
