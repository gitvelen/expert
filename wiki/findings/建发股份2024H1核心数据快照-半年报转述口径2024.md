# 建发股份 2024H1 核心数据快照（半年报转述口径 2024）

数据来源：建发股份 2024 年半年报（2024-08-31 披露），经万联网综合转述。

| 指标 | 2024H1 数值 | 同比 |
|---|---|---|
| 营业总收入 | 3190.15 亿元 | -16.80% |
| 归母净利润 | 11.99 亿元 | -37.67% |
| 扣非净利润 | 8.48 亿元 | -26.87% |
| 经营性现金流 | -221.12 亿元 | 上年同期 +233.85 亿元 |
| 供应链运营业务收入 | 2635.69 亿元 | -24.81% |
| 供应链运营分部归母净利 | 14.21 亿元 | -15.07% |
| 大宗商品经营货量 | 近 10,500 万吨 | +9% |
| 钢材经营货量 | 超 3,300 万吨 | +13% |
| 农产品经营货量 | 超 2,000 万吨 | +28% |
| 进出口及国际业务额 | 186.58 亿美元 | 占供应链运营业务约 40% |
| 转口占国际业务比重 | 48.7% | +8.74pct |
| 消费品出口 | 超 5.38 亿美元 | +22% |
| 二手车出口 | 超 8,000 台 | +310% |
| 生活家电经营规模 | 12 亿元 | +74% |
| 中西部客户销售签约 | 超 1,000 亿元 | +9% |

## 解读要点

- 收入大降而货量增长，印证大宗价格下行期的"以量补价"与市占率提升逻辑。
- 国际化（含转口业务占比近半）为对冲内需疲软的主要增长动能。
- 经营性现金流大幅转负主因地产业务，非供应链运营板块独有现象。

## 证据强度分层

- **半年报数据本身**：上市公司定期报告口径，但本页为**媒体转述（万联网综合）**，未经与原始半年报逐项核对，强度中等。
- **"稳健经营国企样本、ROE 24.85% 排名、两大主业从未亏损"等叙事**：公关化表述（企业自述/Wind 转述），强度低，引用需谨慎。
