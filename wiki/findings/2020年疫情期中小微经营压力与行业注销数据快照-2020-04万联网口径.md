# 2020年疫情期中小微经营压力与行业注销数据快照（2020-04万联网口径）

依据 [[sources/4-news--7-03-行业研究--4-2020--23-全行业倒闭裁员潮来临中小微苦日子何时出头-趋势--9eqee8]]（万联网，2020-04-15）整理的结构化快照。

## 行业注销/吊销数据

- 2020 年前两个月，全国餐饮业企业注销超 1.3 万家。
- 截至 2020-03-25，全国 11,268 家旅游类企业注销、吊销经营（企查查数据）。
- 家电业：海信"高管降薪+末位淘汰"传闻、海尔否认裁员（传闻与澄清并存）。
- 畜牧业：饲料原料供应中断，部分养殖场扑杀畜禽降产能。

## 中小微经营压力数据（出处未署名的报告口径）

| 指标 | 数值 |
|---|---|
| 成本压力 | 86.9% |
| 现金流短缺 | 69.7% |
| 现金撑不过3个月 | 约半数 |
| 撑不过1个月 | 近14% |
| 租金压力 | 59.13% |
| 工资五险一金压力 | 45.5% |

三重短缺：用工、现金流、原材料。应对方式：降本、商业银行贷款、裁员，以及**供应链金融**（媒体称其为"很多中小微企业的不二选择"）。

## 政策应对（官方口径）

国办《意见》（2020-03-25 国新办吹风会）：减负提速（社保费减免）、稳岗提标（失业保险稳岗返还 50%→最高 100%）、扩就业加力（补贴/税收减免/担保贷款贴息）。详见 [[entities/国办应对新冠肺炎疫情影响强化稳就业举措的实施意见]]。

## 证据强度分层

- **较高**：国办《意见》政策条款——国新办吹风会官方口径转述（监管原文层级）。
- **中**：餐饮注销超 1.3 万家、旅游注销/吊销 11,268 家——企查查工具口径数据，媒体转引。
- **弱**：中小微压力百分比数据（86.9%/69.7% 等）——媒体转引"有报告数据"，出处未署名，待考证（见 [[queries/查询-疫情期中小微经营压力报告数据出处考证]]）。
- **弱**：海信/海尔裁员传闻——"知情人士+公司否认"，传闻与澄清并存，不应固化。
