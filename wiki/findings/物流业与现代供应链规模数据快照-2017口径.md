# 物流业与现代供应链规模数据快照（2017口径）

以下均为2017年报道/统计时点口径的历史快照，**不宜作为当前口径使用**。

| 指标 | 数值 | 时点/来源 |
|---|---|---|
| 社会物流总额 | 198万亿元 → 230万亿元（十八大以来五年） | 何黎明 |
| 社会物流总费用 | 超11万亿元，全球最大物流市场；公路、铁路货运量和港口吞吐量多年世界第一 | 何黎明 |
| 社会物流总费用/GDP比率 | 降至15%以下 | 2017年报道 |
| A级物流企业 | 超4600家 | 何黎明 |
| 供应链专业服务企业 | 超5000家（不完全统计），集中于沿海三大经济带 | 不完全统计，来源与口径不明 |
| 物流园区 | 运营/在建/规划共1210家 | 中物联《第四次全国物流园区(基地)调查报告》，截至2015年上半年 |
| 装备制造/高新技术物流需求增速 | 10%以上 | 2017年 |
| 单位与居民物品物流增速 | 30%以上 | 2017年 |
| 麦肯锡测算 | 供应链运营转型可提升中国劳动生产率15%+；发展全球供应链再提升10%+ | 麦肯锡研究报告（预期性测算，非事实） |

## 证据强度分层

- **行业协会权威口径**：何黎明（中物联会长）披露的社会物流总额、总费用、A级企业数等——中物联为行业统计发布方，可信度较高，但系转引媒体，最终以官方统计为准。
- **一般新闻报道（转载）**：社会物流总费用/GDP比率、细分市场增速数据。
- **研究机构测算**：麦肯锡生产率提升数字，属预期性研究结论，不可与实际成效混用。
- **口径不明**："供应链专业服务企业超5000家"为不完全统计，与其他市场主体口径（如商业保理公司数）引用时须区分，考证见 [[查询-供应链专业服务企业超5000家统计口径考证]]。
