# 深圳2017年度典当企业年审八项内容与量化指标快照（2018口径）

据媒体报道，2018 年 3 月 28 日深圳市金融办发布开展 2017 年度典当企业年审工作的通知（媒体转述口径，未见文号），年审共八项：注册资本实收、资金来源、法人股东存续及股东资金往来、业务结构与放款、绝当物处理、当票使用、息费收取、企业及分支机构变更。

## 量化指标（年审报告书审计附注必须披露）

| 指标 | 红线 |
|---|---|
| 对同一法人或自然人典当余额 | ≤ 注册资本的 25% |
| 对股东典当余额 | ≤ 该股东入股金额 |
| 财产权利质押典当余额 | ≤ 注册资本的 50% |
| 房地产抵押典当余额 | ≤ 注册资本 |
| 房地产抵押典当单笔当金 | ≤ 注册资本的 10%（注册资本不足 1000 万元的，≤ 100 万元） |
| 净资产 | 不得低于注册资本的 90% |

## 资金来源禁令

不得非法集资、吸收或变相吸收存款、从商业银行以外的单位或个人借款。
