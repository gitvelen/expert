# 深数所数据交易与数据商数据快照（2023 披露口径）

以下数据均为 [[深圳数据交易所]] 于 2023 年 7-8 月对外披露口径，来源为南方财经报道（万联网 2023-08-14 转载），未经独立验证。

## 平台总量（截至 2023-07-31）

| 指标 | 数值 |
|------|------|
| 累计登记数据交易 | 950 笔 |
| 参与主体合计 | 1055 家（覆盖 32 省 98 市） |
| 数据卖方 | 202 家 |
| 数据买方 | 669 家 |
| 数据产品 | 超 1600 个 |
| 应用场景 | 超 170 个 |
| 供需撮合 | 超 50 笔 |
| 服务交易规模 | 破千万 |

## 认证数据商

- 合计 184 家：生态级 106、核心级 65、战略级 13。
- 八类分布（截至 2023-07）：科技型 73、资源型 25、知识型 16、渠道型 13、平台型 12、集成型 11、委托型 8、媒体型 1（加总 159，与 184 存在缺口）。

## 证据强度分层

- **中等（企业/交易所披露口径）**：上述全部数据，来自深数所向南方财经披露，属宣传性披露，未经第三方验证。
- **背景佐证**：万联网为一般性新闻转载渠道，可信度较低，仅作来源标注。

## 使用提示

1. "服务交易规模破千万"与全国性交易所定位相比规模很小，引用时应说明数据场内交易处于早期，避免夸大数据交易生态成熟度。
2. 184 与 159 的缺口可能因统计时点不同或部分数据商未归类，见 [[查询-深数所数据商184家与八类加总159家口径差异考证]]。
