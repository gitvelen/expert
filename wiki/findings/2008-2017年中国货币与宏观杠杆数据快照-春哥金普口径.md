# 2008-2017年中国货币与宏观杠杆数据快照（春哥金普口径）

## 事实条目

据2020年7月公众号「春哥金普」文章（经「供应链金融」公众号转载）：

| 指标 | 2007年底 | 2017年底 |
|------|----------|----------|
| M2 | 40万亿 | 169万亿（增3倍多） |
| M2/GDP | 150% | 200% |
| 宏观杠杆率（债务/GDP） | 145% | 244% |
| 非金融企业部门 | 96% | 158% |
| 居民部门 | 19% | 49% |
| 政府部门 | 30% | 36% |
| 央行资产负债表 | 17万亿 | 36万亿 |

2020年一季度：宏观杠杆率上升约10个百分点，广义货币增速创2017年以来新高。

## 证据强度分层

- **低**：以上全部数据仅来自一般公众号分析，**未注明数据出处**。数值大致与官方统计（如社科院/BIS 口径宏观杠杆率、央行 M2 统计）方向一致，但未经核验到原始统计文件。仅可作为宏观背景叙事的弱证据，撰写正式分析报告时应回溯社科院国家资产负债表研究中心、人民银行统计等原始出处。
- **观点类（非事实）**：文中"2020年危机应对后果或与2008年后十年相似甚至恶化"为作者推测，不作为事实收录。
