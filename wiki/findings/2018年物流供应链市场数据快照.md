# 2018 年中国物流供应链市场数据快照

- 2018 年全国社会物流总额 **283.1 万亿元**；全国社会物流总费用 **13.3 万亿元**（2018 年统计口径）。
- 文称中国已成为"全球最大的物流供应链市场"。
- "据不完全统计，国内外披露的无币区块链项目中，物流供应链方向的项目超过 35%"——该占比出处不明，另设 query 考证。

## 证据强度分层

- 物流总额/总费用数据：**中等偏弱**——行业会长署名文章转述口径，未注明原始统计部门（通常应为 国家发改委/中国物流与采购联合会 发布），使用时宜与官方《全国物流运行情况通报》核对。
- "全球最大物流供应链市场"：**弱**——修辞性表述，无统计口径。
- 35% 占比：**弱**——"据不完全统计"，无方法论说明，仅作 2019 年舆论快照记录，不作事实引用。
