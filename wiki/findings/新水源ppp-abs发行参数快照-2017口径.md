# 新水源PPP ABS发行参数快照（2017口径）

| 项目 | 参数 |
|---|---|
| 产品名称 | 太平洋证券新水源污水处理服务收费收益权资产支持专项计划 |
| 发行总规模 | 8.4亿元 |
| 优先级 | 8亿元，分10档，评级均为AA+ |
| 次级 | 0.4亿元 |
| 基础资产 | 特定期间内提供污水处理服务产生的污水处理服务费及其他应付款项的收费收益权 |
| 付款方 | 乌鲁木齐税务局 |
| 原始权益人 | 新疆昆仑新水源科技股份有限公司（依据《特许经营协议》） |
| 股东及担保 | 昆仑环保51%、碧水源（300070.SZ）49%，均提供无条件不可撤销连带责任担保 |
| 发行场所 | 机构间私募产品报价与服务系统（备案制） |
| 筹备时间 | 2016年8月（公司财务人士证言） |

## 证据强度分层

- **发行规模、分层、评级、股东持股比例**：媒体报道援引公开信息，一般新闻报道层级，中等偏可信；
- **"首单"定性**：媒体称"市场首单"，但证监会债券监管处副处长闫云松官方表态其**不属于**《通知》框架下资产证券化——官方口径优先，应采"框架外早期案例"定性；
- **筹备时间**：新水源公司财务人士与碧水源人士证言，中等强度。
