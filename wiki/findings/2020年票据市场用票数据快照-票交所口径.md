# 2020年票据市场用票数据快照（票交所口径）

来源：[[上海票据交易所]] 数据，经万联网 2021-02-26 报道转引。

| 指标 | 2020 年数值 |
|------|------------|
| 企业用票金额（承兑+背书+贴现） | 82.7 万亿元，同比 +4.27% |
| 用票企业家数 | 270.58 万家，同比 +11.22% |
| 小微企业用票金额 | 44.03 万亿元，占比 53.24% |
| 小微企业用票家数 | 250.31 万家，占比 92.5% |

另据同篇报道：商票签发呈小额化趋势，更适应供应链上下游中小企业用票需求。

## 证据强度分层

- **票交所官方统计（82.7 万亿、270.58 万家等）：监管原文/官方统计口径，强度高**
- 商票小额化趋势判断与"票据服务小微企业成效显著"的定性结论：媒体归纳，强度中等
- "供应链票据 + 标准化票据 = 新蓝海"叙事：媒体/专家乐观解读，强度低—中，不宜固化为事实
