# 中国流通成本占 GDP 快照（2018 万联网/怡亚通口径）

以下数据来自 2018-08-27 万联网转载文章，**未标注统计来源**，证据强度为最低档（企业/媒体观点口径），引用时必须注明"2018 年企业/媒体口径"：

| 指标 | 数值（2018 口径） |
|---|---|
| 中国社会化供应链成本占 GDP | 约 18% |
| 欧洲、美国占比 | 7%–8% |
| 日本占比 | 5%–6% |
| 日本综合商社市场集中度 | 4 家服务 80% 以上市场 |
| 中国快消品分销渠道成本 | 长期维持 30%–50% 以上 |

## 已知口径矛盾

官方统计的社会物流总费用占 GDP 比例约为 14%–15%（同期），与文中 18% 的"社会化供应链成本"口径不一致，可能因统计范围（物流费用 vs 全链条流通成本）不同。该矛盾待 [[查询-流通成本占GDP18%口径与官方社会物流总费用口径的核对]] 跟踪。

## 证据强度分层

- 一般新闻报道/企业宣传（本来源）：所有数值的唯一出处，最低档。
- 监管/官方统计：社会物流总费用口径（约 14%–15%），层级更高，与本来源数值冲突。
