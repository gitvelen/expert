# 2014年潮宏基多啦A梦世界杯专款O2O销售数据快照（品途网口径）

据 2014-07-07 品途网报道（吴梅梅），潮宏基多啦A梦世界杯专款（黄金+硅胶组合，可换 8 国球衣）销售节奏与数据：

| 项目 | 数据 |
|---|---|
| 天猫店预售开始 | 2014-05-12，价格 1699 元 |
| 线上线下同步预售 | 2014-05-16 |
| 全国现货上柜 | 2014-05-25，统一售价 1880 元 |
| 不到一个月销量 | 超 1200 件 |
| 销售额 | 200 多万元 |
| 其中微信引流到店成交 | 500 多件 |
| 预售前需求预测 | 700 件（实际远超） |
| 天猫 DSR 评分 | 4.9 |

## 证据强度分层

- **专业媒体报道（企业自述转述）**：以上全部数据来自品途网对潮宏基的报道，属媒体转述的企业单方口径，**未经审计或第三方验证**，证据强度中等偏弱；
- **可核验途径**：潮宏基为 A 股上市公司，2014 年年报及后续披露可用于事后对照，见 [[queries/查询-潮宏基2014年O2O战略的后续成效与年报对照]]。
