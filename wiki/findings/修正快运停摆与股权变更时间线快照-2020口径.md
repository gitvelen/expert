# 修正快运停摆与股权变更时间线快照（2020口径）

经核验的事件时间线（来源：万联网综合 800里加急、企查查，2020-03-15）：

| 时间 | 事件 |
|---|---|
| 2018-12 | 修正快运股份有限公司成立 |
| 2019-08 | 发布“修橙正裹”品牌，创始人史大兴扬言三年产值百亿、全国24小时送达 |
| 2019-12-24 | 公司停运（公司公告追溯口径） |
| 2020-01-02 | 总裁办通知：承诺1月6日发放9/10月剩余薪酬及离职/仲裁员工基础工资，1月15日发放11/12月薪酬 |
| 2020-01 | 员工爆料欠薪数百人、总额达百万元 |
| 2020-02-28 | 企查查显示更名“裹然速运集团股份有限公司”；修正发展（吉林）退出，史大兴持股40%成大股东 |
| 2020-03-01 | 公司对内公告：筹措资金、预计3月底新股东进入、4月1日恢复运营 |

## 证据强度分层

- **股权变更与更名**：企查查工商记录 + 公司公告原文，**高**。
- **停运时间与恢复承诺**：公司公告原文（对文件真实性而言**高**；承诺是否兑现**未验证**）。
- **欠薪事实**：公司内部通知 + 多名员工爆料（800里加急，非权威媒体），**中高**；欠薪总额百万元为媒体综合估算，**中**。
- **业务量悬殊（5吨 vs 3000吨）**：单一当事人（李博宇）口径，**中低**，不可直接作为全公司业务量证据。
- **失败归因（赛道拥挤、资金门槛）**：媒体分析性判断，**弱—中**，属观点。
- **修正药业年营收624亿元、2019民企百强制药榜首**：媒体引述全国工商联名单，**中**。
