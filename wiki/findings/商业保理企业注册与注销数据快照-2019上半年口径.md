# 商业保理企业注册与注销数据快照（2019 上半年口径）

统计时点：2019-06-30；统计方：中国服务贸易协会商业保理专业委员会；转引：《金融时报》2019-08-27。

## 数据

| 指标 | 数值 | 备注 |
|---|---|---|
| 注销、吊销企业累计 | 927 家 | 截至 2019-06-30 |
| 其中 2019 上半年注销吊销 | 434 家 | 占累计 46.85%，接近前 7 年总和 |
| 2019 上半年新增注册 | 734 家 | 法人企业 689 + 分公司 45 |
| 2018 上半年新增注册 | 2322 家 | 法人 2272 + 分公司 50；同比下降 70.33% |
| 全国注册存量（不含注销吊销） | 12768 家 | 截至 2019-06-30 |
| 山东新增 | 380 家 | 全国第一，同比 125 家增长两倍有余 |
| 广东新增 | 88 家 | 同比 1628 家，断崖式下降 |
| 深圳新增 | 0 家 | 全面进入排查阶段、暂停注册 |

背景：2018 年 5 月商务部将商业保理等三类机构监管职责划转银保监会满一年；地方金融监管部门清查"空壳""失联""僵尸"企业，原试点地区注册窗口纷纷关闭。专委会预计行业未来两年（即约 2019–2021）迎来调整高峰期。

## 证据强度分层

- **较高**：注册/注销/存量/地区分布数据——行业自律组织（商业保理专委会）官方统计，经《金融时报》转引，接近监管原文层级。
- **观点性（不作事实采信）**："2016–2018 保理涉诉案件笔数和金额成倍增长"（赵永军）、"行业进入平台期"（张明星）等业内人士言论。
- 注意：公众号条目"来源"标注"网友评论"，但正文末注明"来源：金融时报"，以金融时报口径为准。

## 历史数据说明

本快照为 2019-06-30 口径；后续年份（2020 之后）数据如有新来源，旧值移入历史对照，不覆盖删除。后续演变考证见 [[queries/查询-商业保理行业调整高峰期2019-2021实际演变与监管尘埃落定考证]]。
