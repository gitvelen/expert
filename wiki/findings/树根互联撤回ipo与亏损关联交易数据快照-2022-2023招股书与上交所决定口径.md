# 树根互联撤回IPO与亏损、关联交易数据快照（2022–2023）

**事实**：2023-08-17，树根互联与保荐人中信建投共同撤回科创板 IPO 申请；上交所 2023-08-22 终止审核。

```text
扣非净利润:        2019 -3.59亿 / 2020 -4.81亿 / 2021 -7.76亿
归母净利润:        2022H1 -3.71亿
累计未弥补亏损:     15.46亿（截至2022-06-30）
股份支付费用:       8801万 / 3亿 / 3.68亿（2019-2021，占同期净利润26%/102%/51.7%）
研发投入:          三年累计5.34亿（占累计营收56.3%）；研发人员191→697
三一客户收入占比:   73.62% / 68.24% / 56.24%（2019-2021）
三一客户毛利占比:   103.77% / 79.32% / 80.20%
平台订阅三一收入占比: 96.95% / 94.85% / 95.02%
连接设备:          超120万台，5000+设备类型，链接工业总资产超万亿元
预计盈利时间:       2026年（公司答复口径）
```

**提示**：三一客户 2019 年毛利占比超 100% 意味着非三一客户毛利为负，与"服务近千家工业企业"的规模叙事相矛盾，系 IPO 问询焦点；招股书"经济效益 258 亿+"为公司自评宣传口径，不宜直接采信。

## 证据强度分层

1. **高**：IPO 撤回与终止审核——上交所官网《关于终止对树根互联股份有限公司首次公开发行股票并在科创板上市审核的决定》。
2. **较高（公司申报口径）**：财务数据、关联交易占比、亏损归因——招股书及对上交所问询的回复。
3. **中（观点层）**：行业普及率 17.5% vs 45% 目标、行业"政策补贴驱动为主"判断——艾瑞咨询报告与国家工业信息安全发展研究中心数据经媒体转述。
4. **低（市场猜测）**："撤回或与持续亏损/关联交易有关"的因果归因——媒体与市场分析，官方未明。
