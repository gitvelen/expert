# 两票制后上市药企应收账款激增（2017年报数据）

来自 2017 年上市公司年报/信息披露（经 2019 年健康界文章转述）：

- **陇神戎发**：应收账款余额 9073.71万 / 13589.35万 / 15778.64万元（2015–2017 年末），占流动资产 31.62% / 44.34% / 60.27%，逐年上升；同期销售费用 2017 年同比增长超八成但收入不升反降。
- **卫信康**：两票制前先款后货、应收账款较小；实施后因配送企业约 3 个月账期，付款周期延长、经营现金流净额下降。
- **西藏药业**：应收账款期末较期初增加 2.74 亿元、增长 445.92%，公司归因于配送商由现款现货改为账期结算。
- **天士力**：截至 2017-12-31 应收账款账面余额 69.10 亿元，坏账准备 1.62 亿元，账面价值 67.48 亿元，占 2017 年营收 41.93%、年末总资产 31.34%。

## 证据强度分层

- 底层为上市公司披露，强度高；具体数字经媒体转述，引用前建议核对原始年报。
- 统计年份为 2017 年时点数据，不反映集采时代现状。
