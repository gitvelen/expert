# 票据市场2019年关键数据快照（票交所口径）

据票交所 2019 年票据市场运行分析报告（经 2020 年九银票据研究院文章转引）：

- 全市场累计签发承兑票据 20.38 万亿元，同比增长 11.55%；
- 累计贴现 12.46 万亿元，同比增长 25.33%；年末贴现余额 8.18 万亿元，比年初增长 24.03%；贴现增量占企业贷款增量 16.77%；
- 全年已贴现比例 61.13%；
- 出票人为中小微企业的票据占比超过三分之二；
- 2019 年末中小微出票承兑余额 8.89 万亿元，占全部承兑余额 69.84%；中小微贴现申请人贴现余额 6.66 万亿元，占全部贴现余额 81.39%；
- 承兑和贴现主要集中在制造业、批发和零售业。

另（国家统计局口径，注意 2019 年起含票据）：规模以上工业企业应收票据及应收账款 2019 年末 17.40 万亿元（+4.5%）；历史数据：2018 年末 14.34 万亿（+8.6%）、2017 年末 13.48 万亿（+8.5%）。

## 证据强度分层

- **票交所运行报告数据**（承兑/贴现/中小微占比）：监管官方基础设施口径，证据强（转引自专业研究院文章，建议核对票交所原报告）。
- **国家统计局应收账款数据**：官方统计，证据强，但口径需注明。
- **"贴现利率低于贷款利率 100BP 以上"**：作者论断，属专业公众号分析层级的观点，证据中，待溯源。
- **世界银行 2018 融资缺口报告数据**（需求 4.4 万亿美元、缺口 1.9 万亿美元、43.18%）：转述口径，证据中，建议溯源。
