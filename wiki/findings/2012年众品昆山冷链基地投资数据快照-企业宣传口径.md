# 2012年众品昆山冷链基地投资数据快照（企业宣传口径）

以下数据来自《河南众品食业股份公司供应链物流战略规划》及总监张金萍提供的资料，经《经济视点报》2012-02-23报道，属企业宣传口径，证据强度低，实际兑现情况待事后验证。

```
昆山冷链物流基地（筹建中，2012）
- 总投资: 10.3亿元
- 年物流量（达产后）: 146万吨
- 建设内容: 冷库、生鲜农产品加工配送中心、展示交易中心、信息系统、品质检测中心
- 定位宣称: 苏沪规模最大冷链物流基地 / 长三角标准化程度最高枢纽之一
借鉴案例: 法国汉吉斯、深圳农产品海吉星、杭州五丰、普飞斯、西肉、美冷
产业基地: 全国15个标准化食品加工和冷链物流产业基地
上市: 2006年，纳斯达克主板（中国食品行业首家）
```

## 证据强度分层

- **一般新闻报道（低）**：上述全部数值与定位宣称，均转引自企业提供的《规划》与资料，未经独立核实。
- **一般新闻报道（低，存疑）**：陈伟"曾获国际供应链管理大奖"，无具体奖项名称，见 [[查询-陈伟国际供应链管理大奖真实性核验]]。
- **一般新闻报道（中低）**：众品2006年纳斯达克上市、15个产业基地等背景事实，属可交叉核验的公开信息但本来源内无独立佐证。
