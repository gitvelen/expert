# 链接者塑化产业集群平台效能数据快照（2023，演讲披露口径）

以下数据来自黄贵生 2023-06-28 在成都"2023第三届产业数字化与供应链金融论坛"的演讲（万联网 2023-07-04 整理），为演讲/公司自报口径，无第三方验证。

## 平台配置

- 产业基金：2000 万元（专项扶持）。
- 线上区域产业集群服务平台：1 个。
- 功能模块（8 项）：生产数字化、云生产管理中心、县域产业运营大脑、原料直采、成品销售平台、银行资金赋能、培训中心、管理赋能；形成 N 个数字化应用产品。
- 模式：订单+资金+科技（"让聋哑设备会说话"）+物流+交易+管理+集成园区综合服务+产业科技创新。

## 效能数据

| 指标 | 数值 |
|------|------|
| 集采降本 | ≥5% |
| 物流优化 | 15% |
| 人均产值增加 | 21% |
| 规模增效 | 30% |
