# 2022年两化融合指数与供应链数字化协同数据快照

## 事实条目（双口径并存）

**2021年口径（《中国两化融合发展数据地图（2021）》）：**

| 指标 | 数值 |
|---|---|
| 两化融合发展指数 | 96.6（同比 +5.9%） |
| 数字化研发设计工具普及率 | 73.7% |
| 关键工序数控化率 | 53.7% |
| 经营管理数字化普及率 | 69.0% |
| 产供销集成企业比例 | 28.9%（近五年 +8.9 pct） |
| 产业链协同企业比例 | 12.3%（近五年 +5.7 pct） |

**2022年二季度口径（工信部数据）：**

| 指标 | 数值 |
|---|---|
| 关键工序数控化率 | 55.7%（较2012年 +31.1 pct） |
| 数字化研发设计工具普及率 | 75.1%（较2012年 +26.3 pct） |
| 两化融合发展指数较2015年 | +28 pct |
| 产业链数字化协同企业比例 | 约13% |

## 口径冲突说明

同篇文章内 2021 数据图（53.7%/73.7%）与 2022Q2 口径（55.7%/75.1%）并存，可解释为统计时点更新的正常演进；"产业链协同企业比例" 12.3%（2021）与约13%（2022Q2）基本一致。引用时必须注明统计时点。

## 证据强度分层

- **监管原文层级（转引）**：数据出自工信部网站及《中国两化融合发展数据地图（2021）》，经万联网转引——但本资料为二手转载、无署名作者，且存在"工信化"等表述瑕疵，实际强度为"官方口径的媒体转述"，中等偏上。
- 未附原始图表与统计方法说明，精确到小数的数值建议引用前核对工信部原文。
