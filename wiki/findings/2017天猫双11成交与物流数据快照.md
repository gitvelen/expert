# 2017天猫双11成交与物流数据快照

2017年天猫双11最终数据（媒体报道口径，逐年过时，仅作历史快照，不作当前口径）：

| 指标 | 数值 |
|------|------|
| 总成交额 | 1682 亿元（历史新高） |
| 无线成交占比 | 90% |
| 物流订单 | 8.12 亿 |
| 支付宝支付笔数 | 14.8 亿笔 |
| 支付峰值 | 25.6 万笔（上年 2.1 倍） |
| 参与国家和地区 | 225 个 |
| 1小时过亿品牌数 | 62 家（中国品牌占比过半） |

品牌榜单：耐克官方旗舰店为天猫服饰史上首个破10亿商家；耐克与海澜之家开场不足1分钟同时破亿；男装第一海澜之家、第二优衣库；女装第一优衣库、第二 VERA MODA；运动品牌前五：耐克、阿迪达斯、安踏、New Balance、李宁。

配套产能数据（2017年淘工厂口径）：入驻工厂20000家、备选工厂50000家、覆盖16省；江西共青城羽绒服产业带储备100万件产能。

## 证据强度分层

- **一般新闻报道层（弱-中）**：上述全部数据来自《中国纺织报》等媒体转引（来源：中国纺织报、时尚头条网、正和岛），非平台或物流方一手披露，逐年被新数据取代。仅作历史对照使用，不得作为分析报告中的当前口径。
