# 冠之链平台2024-2025运营数据快照

[[冠之链供应链服务平台]]在冠县落地的运营数据，2025年4月口径（胡合鑫演讲披露）。

## 核心数据

| 指标 | 数值 |
|------|------|
| 平台注册企业 | 140家 |
| 提报融资需求 | 16.5亿元 |
| 预付款货物需求 | ~167万吨 |
| 准入银行 | 7家（含工行） |

## 关键时间线

| 时间 | 事件 |
|------|------|
| 2024年2月 | 试运行 |
| 2024年4月15日 | 山东新闻联播专题报道 |
| 2024年7月 | 正式上线运行 |
| 2024年7月11日 | 山东省金融顾问团走进冠县（省人民银行副行长、省内六大银行、城商行总行代表、聊城市副市长等参加） |
| 2024年8月7日 | 全省财金联动会议（财政厅+聊城市政府主办，16地市财政局局长+34财金联动县局长参加） |
| 2024年12月12日 | 高层领导牵头召开相关会议 |

## 其他信息

- 日照银行在冠县新增两个支行（其中一个在冠县）
- 县级国企对向邯郸/唐山钢厂预付货款仍有顾虑，迫切需要与省国企建立合作关系

## 证据强度分层

- **企业/政府自报口径**：注册企业数、融资需求、货物需求、准入银行数均为平台自报，未经第三方审计
- **媒体报道**：山东新闻联播报道可视为中等强度证据，确认平台存在及受关注
- **政府行为**：金融顾问团走访、财金联动会议属政府公开活动，可独立核验
- **需外部核验**：140家/16.5亿/167万吨等量化数据
