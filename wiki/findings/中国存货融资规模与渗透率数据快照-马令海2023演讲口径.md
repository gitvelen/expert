# 中国存货融资规模与渗透率数据快照（马令海 2023 演讲口径）

2023-12-08 南昌论坛演讲披露（万联网 2023-12-25 实录）：

| 指标 | 数值 | 原始出处 |
|---|---|---|
| 中国存货资产规模 | 接近 120 万亿 | 社科院国家金融发展实验室《中国资产负债表 2019-2020 年》 |
| 中国存货市场规模预估 | 75 万亿（当时）→ 未来五年 100 万亿 | 世界银行 |
| 存货融资渗透率 | 中国约 5%–6%；欧美 60%–70% | 演讲人预估，未注明统计来源 |
| 中仓登登记仓库 | 近 6000 个，覆盖 34 个省级行政区 | 中仓登自述 |
| 货权公示 / 仓单登记 | 400+ 项 / 200+ 笔 | 中仓登自述 |
| 生态合作伙伴 | 300+ 家 | 中仓登自述 |

## 证据强度分层

- **一般新闻报道/演讲转述（弱）**：渗透率 5%–6% 与欧美 60%–70% 均为演讲人口头预估，无统计来源；且演讲人为利益相关方（中仓登即存货登记基础设施提供方），归因与数据可能过度指向己方业务价值。数据出处待考，见 [[查询-中国存货融资渗透率5-6%与120万亿存货规模数据出处考证]]。
- **转述的官方/研究口径（中）**：120 万亿（社科院）、75→100 万亿（世行）为二手转述，具体统计范围未核验。
- **企业自述（弱）**：中仓登运营数据未经独立验证。
