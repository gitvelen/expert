# 众企安链业务规模数据快照（企业自述口径，2023）

- 服务产业龙头企业 50 余家（含数家世界500强）；下游场景服务龙头 20 余家（含数家世界500强），涵盖食品、饮料、酒水、建材、农牧、大宗等行业。（余俊，万联网专访，2023-03）
- 石化订货贷案例：链主为山东某化工集团（1988年成立，年营收超800亿，匿名）；上线半年数百下游客户、数亿纯信用授信。
- 防水建材订货贷案例：链主为防水行业知名上市公司（匿名）；运营不到半年贷款投放增 200%。

**以上数据全部为企业自述，无独立验证。**

## 证据强度分层

| 证据 | 层级 | 说明 |

| 50家/20余家服务企业数 | 专业公众号分析（企业宣传性采访） | 弱，属媒体转述企业自述 |
| 石化案例数亿授信、数百客户 | 同上 | 弱，且链主匿名 |
| 建材案例200%增幅 | 同上 | 弱，链主匿名，基数未知 |
| 2022年政策与风险事件背景 | 客观背景陈述 | 可与监管原文交叉验证 |
