# 湖北港口集团2025年目标与上半年进展数据快照（万联网口径）

## 2025年目标（2022-04-29 改革重组大会公开目标）

| 指标 | 2025年目标 |
|---|---|
| 货物吞吐量 | 2.5亿吨 |
| 集装箱吞吐量 | 500万标准箱 |
| 资产总额 | 1000亿元 |
| 营业收入 | 400亿元 |
| 利润总额 | 10亿元 |
| 全国港口企业排名 | 前15强 |
| 上市公司 | 培育2–3家 |

## 进展数据（2024–2025H1）

- 2024年湖北全省港口货物吞吐量7.5亿吨，+8.6%，首破7亿吨（全省口径）。
- 2025H1 集团货物吞吐量11817.62万吨，+2.95%；集装箱226.35万标箱，+1.28%（集团口径）。
- 多式联运通道111条（阳逻港71条），覆盖长三角、川渝、东北、粤港澳等城市群，通达全球100多个国家和地区。
- 2025-08-25 “荆州—日韩”直航首航：物流时间压缩7天、综合成本降40%。

**口径警示**：“全省吞吐量”与“集团吞吐量”为两个不同口径，不可混用。

## 推断

按H1集装箱226.35万标箱（+1.28%）推算，全年约450–460万标箱，500万标箱目标大概率难达；营收/利润目标进展无数据。

## 证据强度分层

- **中**：2025年目标（2022年改革重组大会官方公开口径）；2025H1 吞吐量与集装箱数据（官方通报口径，经万联网转引）；任命消息（转引“湖北港口”官方公众号）。
- **低—中**：长江产业集团“八倍增长”数据（媒体叙述，未经审计口径验证，属 [[长江产业投资集团]] 而非港口集团）。
- **观点（不计为事实）**：对周勇士个人的溢美叙事与“化学融合”展望；“荆州—日韩”航线效果的量化表述（时间压缩7天、成本降40%）未见第三方验证。
