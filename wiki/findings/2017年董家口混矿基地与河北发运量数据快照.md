# 2017年董家口混矿基地与河北发运量数据快照

以下均为 2017 年齐鲁网报道中的港口方口径（含客户方佐证），统计年份 2017：

| 条目 | 数值/内容 |
|------|-----------|
| 40 万吨码头投运 | 约 2014 年，国内第一个 40 万吨矿石作业码头，当年吸引九成多进出中国的 40 万吨大船 |
| 大船经济性 | 一条 40 万吨船较两条 20 万吨船节省约 1200 万元 |
| 混矿基地投资 | 2600 多万元，国内最大规模 |
| 混矿能力 | 最多五种矿同时配比，重量精度千分之三以内 |
| 混矿规格示例 | 北矿 65% + 南矿 60% → 62%（客户要求） |
| 河北发运量 | 从约 7000 吨/日增至约 23000 吨/日，年约 600 万吨纯增长 |
| 靠泊份额 | 国内新增 7 个 40 万吨泊位后，仍有六成多大船靠泊董家口 |
| 港口体量与业绩 | 跻身 5 亿吨级港口；五年营收保持两位数增长（宣传口径） |
| 铁路疏运规划 | 预计增加 1500–2000 万吨矿石疏运量 |

## 证据强度分层

- **一般新闻报道/地方宣传**（低层级）：以上全部数据来源于齐鲁网 2017-09-14 宣传性报道，港口方受访人自述，无独立财务或物流数据验证。两位数增长、5 亿吨级等业绩表述仅作背景，不宜作为分析结论的主证据。
- **客户方佐证**（同层级）：山东西王特钢业务经理张朋关于 62% 配矿需求的表述与港口方口径互相印证，但同属该报道单一信源链。
