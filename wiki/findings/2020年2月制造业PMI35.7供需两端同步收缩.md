# 2020年2月制造业PMI 35.7%、供需两端同步收缩

中物联、国家统计局服务业调查中心联合发布：2020年2月中国制造业PMI为 35.7%，比上月下降 14.3 个百分点，供给端与需求端指数均大幅收缩。

## 分项数据（2020年2月）

| 分项 | 数值 | 环比 |
|---|---|---|
| 生产指数 | 27.8% | -23.5pp |
| 采购量指数 | 29.3% | -22.3pp |
| 新订单指数 | 29.3% | -22.1pp |
| 新出口订单指数 | 28.7% | -20.0pp |
| 从业人员指数 | 31.8% | -15.7pp |
| 购进价格指数 | 51.4% | -2.4pp |
| 出厂价格指数 | 44.3% | -4.7pp |
| 产成品库存指数 | 46.1% | +0.1pp |

## 解读要点

- 上下游双向挤压：原材料价格上升（购进价格处扩张区间）而出厂价格下降、产成品库存上升。
- 张立群（特约分析师，观点口径）：春节分布于1月，2月PMI本应环比上升，实际大幅下降足见冲击力度；预计1-2月及一季度主要经济指标大幅下降，"必须充分估计，做好应对预案"。

## 证据强度分层

- **官方发布（高）**：指数数值为中物联与国家统计局服务业调查中心联合发布。
- **专家观点（中）**：张立群对经济指标降幅的预测属观点性内容。
- **官方预测（中）**："疫情基本控制后需求集中释放、经济回归正常轨道"为发布时点预测，须与后验事实对照。
