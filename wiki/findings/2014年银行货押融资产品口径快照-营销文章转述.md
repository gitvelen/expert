# 2014 年银行货押融资产品口径快照（营销文章转述）

## 事实条目（均标注 2014 年，营销口径）

1. **货押融资定义（2014 年口径）**：以仓储货物作为质押、无需其他任何形式担保，向银行申请贷款、银行承兑汇票等授信。
2. **赎货方式（2014 年口径）**：还款、存保证金、定期存单质押三种。
3. **监管模式二分（2014 年口径）**：入库监管（银行指定/认可仓库、仓库监管）与实地监管（企业指定仓库、银行委托合作监管方进驻）。
4. **场景匹配（2014 年口径）**：季节性囤货不换货 → 静态质押；质押期间货物持续流转 → 动态质押。
5. **适用行业（2014 年口径）**：钢铁、汽车、有色金属、木材、木浆、纸、石油化工、煤炭、棉花、粮食等易储存、易变现货物的流通型、贸易型、生产型企业。

## 证据强度分层

- 一般新闻报道/营销文章（**最低层级**）：以上全部条目仅来自无作者署名的银行产品宣传文（贸易金融公众号转载中国贸易金融网，2014-08-30）。仅可作为 2014 年市场宣传口径快照，**不得**作为风控标准或法律效力依据。
- 概念层面的静态/动态质押、入库/实地监管二分法属行业通用知识，可参照专业书籍与监管文件进一步加固。

## 使用注意

该口径与同期钢贸风险暴露的现实（重复质押、虚假仓单、监管合谋）形成对照，“无需任何担保、门槛低”的表述具有时代局限性。后续引入监管文件或爆雷案例复盘时，以更新口径为准。
