# 2017年东莞智能手机出货量与产业转型数据快照（媒体/统计转述口径）

以下数据来自《南方日报》2017年报道（对官方统计与企业口述的媒体转述），统计年份为2016年（个别为2017年时点信息）：

```text
2016年广东省手机产量：9.7亿台，占全国 42.8%（世界智能手机及移动终端产业大会口径）
2016年东莞智能手机出货量：3.02亿台 / 全球14.7亿台 ≈ 20.5%
盛翔精密营收：2013年7000多万 → 2014年4.8亿 → 2015年6.3亿 → 2016年7.4亿元
台式电脑时代东莞整机配套率 95%+；石碣镇"不出镇组装一台电脑"
2016年东莞专利申请 56653件 / 授权 28559件；发明申请 17024件（+52.46%，占30.05%，全省第四）
创新型研发机构 32家；孵化载体 59家（国家级11家）；省创新科研团队26个（全省第三）
科技信贷：12家签约银行、655家企业、1017笔、44.62亿元
昆山笔记本产量：2010年峰值1.2亿台 → 2014年6500万台，产值减少1000亿元
```

## 证据强度分层

- **官方统计经媒体转述（中等）**：手机产量/出货量、专利与科技信贷数据，源自大会通报与东莞市官方数据，经《南方日报》转述，未见原始文件。
- **企业口述（较低）**：盛翔精密营收、长盈精密"无人工厂"描述，为企业自述经媒体转述。
- **专家访谈观点（观点性内容）**：丁力、邬贺铨的判断，非事实数据。

## 口径疑点

- "全球五部智能手机有其一"与"每5台有1台"（20.5%）表述一致，但全球出货量14.7亿台的分母出处未注明，需核验。

## 历史口径提示

此为2017年口径。金立2018年崩盘、品牌格局剧变，引用品牌梯队数据时必须结合后续核实（见 [[查询-东莞智能手机风口布局与品牌格局2017年后演变核验]]）。
