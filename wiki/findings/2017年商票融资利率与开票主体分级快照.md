# 2017 年商票融资利率与开票主体分级快照

据西政投资集团 2017 年实务转述：

| 开票主体 / 渠道 | 利率区间（年化） |
|---|---|
| 联想、中兴、比亚迪、万科等优质商票，银行贴现 | 5%–8% |
| 市场资金方（小贷/保理等）普遍接受的利率 | 11%–14% |
| P2P 平台普遍接受的利率 | 约 15% |
| 主板上市公司商票可接受的融资成本 | 10%–12% |
| 中小板上市公司商票可接受的融资成本 | 13%–14% |

## 补充口径

- 各机构最青睐国企、央企及主板/中小板上市公司商票，但国企央企信息不透明、难配合尽调，仅少数资金方承办。
- 上市公司选择标准：资产规模、主营稳定性、近年盈利、经营现金流、资产负债率、流动比率、速动比率、短期负债情况。

## 证据强度分层

- 利率区间：**专业机构实务转述（中等强度）**——西政投资集团实务总结，原文未说明统计来源与样本；非官方定价数据，仅作 2017 年市场快照使用，不可外推至当前。
