# 2020年2-3月联想深圳工厂复工数据快照（企业/媒体口径）

| 指标 | 数值 | 时点 |
|------|------|------|
| 产能恢复 | 70%（预计 3 月第二周 100%） | 2020-02-28 |
| 在岗人数 | 3000+（正常约 4000） | 2020-02-28 |
| 防疫订单 | 武汉防疫大数据平台服务器，定点交付广东/湖北/四川/重庆，5 天交付首批 | 2020-01-29 接单 |
| 返岗识别系统 | 申报率 99%，快于深圳市系统 7 天 | 2020-01-29 投用 |

| 首批开工人员 | 130 人（涵盖订单管理、生产、发货全环节） | 2020-01-30 前后 |
| 正式复工 | 当天近千人参与生产 | 2020-02-10 |
| 在线教育订单 | 紧急完成超 8000 台电脑 | 截至 2020-02-14 凌晨 |
| 单日面试 | 600+ 人（超平日一倍） | 2020-02-23 |
