# 2014年木林森产能与产值目标快照（企业自述口径）

来源：木林森照明总经理林纪良在 2014 年 4 月 11 日高工LED 中山站研讨会演讲，经媒体转述。

| 指标 | 2014 年口径（企业自述） |
|------|------------------------|
| 封装月产能（当时已达到） | 16000KK |
| 2014 年扩产计划 | 由 20000KK/月上调至 25000KK/月 |
| 新增员工（2 月起） | 5000 人 |
| 2014 年产值目标 | 60 亿元 |
| 2015–2016 年产值目标 | 突破百亿元规模 |
| 导线架自制 | 100% 自制，同面积产能为同行两倍（1000 → 2000 颗灯珠） |
| 封装设备 | 由 ASM 量身打造 |
| 芯片来源 | 与上游芯片厂合作研发 |

## 证据强度分层

- **一般新闻报道（低）**：以上全部数据均为企业自述经专业媒体转述（高工LED → 供应链金融公众号转载），未经核验；产值目标属预测，实际演变可能不符。引用时必须注明"2014 年企业自述口径"。
- 飞泰科技的成本数据（石墨烯散热综合成本降 50%+、整灯加工成本降 30%、系统成本至少降 30%）为供应商宣传口径，证据强度更低，不列入本快照。
