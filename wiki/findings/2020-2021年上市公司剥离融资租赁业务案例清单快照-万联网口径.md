# 2020–2021年上市公司剥离融资租赁业务案例清单快照（万联网口径）

据万联网 2021-10-25 报道统计（媒体统计口径，各案例均引用公司公告，可逐条复核）：

| 时间 | 公司 | 动作 |
|---|---|---|
| 2018-12 | 珠海港股份 | 设立珠海港惠融资租赁仅半年后，董事会决定转让 |
| 2020-04 | 山鹰纸业 | 公告拟作价 5.6 亿元转让山鹰（上海）融资租赁 100% 股权（注册资本 5 亿元，2016 年设立） |
| 2020-05 | 诺德股份（600110.SH） | 拟公开挂牌转让诺德租赁 41.46% 股权 |
| 2020-09 | 山鹰国际 | 出售山鹰融资租赁 100% 股权完成工商变更登记 |
| 2020-09 | 南纺（南京纺织品进出口） | 全资子公司香港新达国际放弃南京金旅融资租赁同比例增资权 |
| 2020-09 | 晨鸣纸业 | 董秘表示自 2019-01 起剥离非核心业务，融资租赁业务计划 2020 年压缩至 100 亿元以内 |
| 2020-10 | 融钰华通 | 更名为"融钰华通租赁（天津）有限公司"，经营范围取消融资租赁 |
| 2020-11 | 露笑科技（002617.SZ） | 审议通过注销全资子公司天津露笑融资租赁 |
| 2020-12 | 美康生物（300439.SZ） | 决定 2021-06-30 前注销宁波美康盛德融资租赁 |
| 2020-12 | 新金路（000510.SZ） | 拟注销控股子公司融资租赁公司（业务未达预期，降低管理成本） |
| 2020-12 | 中信海直（000099.SZ） | 宣布不将募集资金直接或变相用于中信海直融资租赁业务 |
| 2021-06 | 永达汽车（03669） | 签订一系列股权转让协议，出售永达融资租赁 80% 股权 |

## 证据强度分层

- **高（公告原文口径）**：各公司剥离动作与公告动因表述（控制类金融风险、降低疫情不确定性、聚焦主业）——均为上市公司公告表述的转述，可逐条对照公告原文复核。
- **中（媒体统计）**：案例清单的完整性与"至少 11 起"的规模归纳——万联网记者自行统计，可能存在遗漏。
- **低（观点）**：来源页"融资租赁不会持续低迷、出路在产融结合"的未来判断——程东跃与记者观点，不作为事实引用。
