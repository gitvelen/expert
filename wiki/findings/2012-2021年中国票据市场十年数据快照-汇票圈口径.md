# 2012-2021年中国票据市场十年数据快照（汇票圈口径）

## 事实条目（统计区间 2012–2021）

- **业务总量（2021）**：累计签发 24.2 万亿元（较 2012 +6.3 万亿，CAGR 3.9%）；贴现 45.9 万亿元（+14.3 万亿，CAGR 5.0%）；交易总量 69.9 万亿元（较 2018 +28.1 万亿，CAGR 9.4%），其中转贴现 30.7 万亿、回购 23.0 万亿。
- **余额（2021 末）**：承兑余额 15.0 万亿元（CAGR 9.0%）；贴现余额 9.9 万亿元（CAGR 43.9%，待考证）。
- **电票**：2021 年出票 2688.2 万笔 / 23.5 万亿元，分别较 2012 年（9.4 万笔 / 2731.7 亿元）增长 286 倍 / 87 倍；2021 末电票占承兑 99.3%、占贴现 100%。
- **商票（2021）**：承兑 3.8 万亿元（较 2018 +1.2 万亿，CAGR 16.3%）；贴现 1.2 万亿元（CAGR 16.3%）。
- **服务实体**：2021 末用票企业 318.9 万家（+17.7%）、用票金额 95.7 万亿元（+15.75%）；26 个行业用票增长、覆盖面 86.67%；批发零售 + 制造业占签发量 67.64%。
- **融资成本**：贴现利率由 2012Q1 的 7.3% 降至 2021Q4 的 2.3%；2021 全年贴现利率低于 1 年期 LPR 均值 100 个基点。
- **小微**：2021 末用票中小微企业 314.7 万家（占 98.7%）、用票金额 69.1 万亿元（占 72.2%）；小微签发金额占比 39.3%；银票平均面额 80.44 万元、商票 108.57 万元（票据小额化）。
- **宏观占比**：贴现余额 / 人民币贷款由 2012 年 3.2% 升至 2021 年 5.1%。

## 证据强度分层

- **中等强度（专业公众号转引）**：以上全部数字来自汇票圈公众号文章（2022-12-29，万联网转载），其声称数据源自票交所统计，属"公众号转引票交所数据"口径，建议溯源上海票据交易所年报（更高证据层级）验证。
- **口径倾向提示**：原文为纯正面成就叙事，未涉及标准化票据暂停、票据套利、逾期兑付风险等负面事实，使用本快照时应与中性监管文件口径对照。
- **待考证项**：贴现余额 CAGR 43.9% 明显异常偏高（2012 年基数低所致但需验证原文），见 [[查询-票据贴现余额年均增速43.9%口径考证]]。

## 历史数据

- 2012 年：电票承兑 2814.56 亿元、贴现 1095.8 亿元；贴现余额 2.0 万亿元（占人民币贷款 3.2%、占短期贷款 6.3%）。
- 2018Q3：票据承兑平均面额突破 100 万元。
