# 煤炭贸易价格术语与费用构成快照（2024文章口径）

以下事实条目来自 2024-11-18 万联网科普文（专业公众号分析层级），注明年份与口径，采信时需后续书籍/官方来源佐证。

- **坑口价**（2024 万联网口径）：煤炭挖出后未经加工筛选、坑口交易的裸价，不含加工与运输费用。
- **车板价/船板价**（2024 万联网口径）：煤装上火车/船后、发运前除干线运费外的一切费用，含坑口价、税费、汽车运费、站台（码头）税费、铁路计划费等；分含税与不含税口径。
- **平仓价**（2024 万联网口径）：港口装船后价格 = 煤价 + 港杂费；国内各港口港杂费约 **15-20 元/吨**（2024 文章口径）。
- **到库价/到站价**（2024 万联网口径）：分别为到达指定仓库、交货地火车站的价格，均为基础价加运输及相关途中费用。
- **增值税率口径**：原文按 17% 举例（不含税 100 → 含税 117）；**该税率已于 2019 年 4 月起调整为 13%，17% 系转载旧文残留，引用时必须修正**。
- **一票/两票**（2024 万联网口径）：一票 = 煤炭增值税票与运输发票合并开具；两票 = 分开开。
- **大款/小款**（2024 万联网口径）：大款 = 开票价 + 运费 + 装卸费 + 杂费的开票全成本；小款 = 签约后支付给居间人的居间费/中介费。

## 证据强度分层

- 专业公众号分析（万联网 2024）：以上全部条目的唯一来源，术语定义多为行业通行惯例，可信度中等；其中税率条目已确认过时。
