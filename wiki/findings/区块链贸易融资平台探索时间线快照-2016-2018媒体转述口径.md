# 区块链贸易融资平台探索时间线快照（2016–2018，媒体/研究转述口径）

以下时间线转述自 [[sources/4-news--7-05-数字科技--4-2018--19-区块链与贸易融资的珠联璧合贸易融资资讯--1l68pa8]]（挖财研究院周报，2018-09）：

## 国际线

| 时间 | 事件 |
|---|---|
| 2016-09 | 巴克莱银行完成全球首笔区块链出口贸易结算（10 万美元，信用证下电子交单，进口商为塞舌尔 Seychelles Trading Company）——**年份口径与既有 wiki 条目（2017 口径）存在出入** |
| 2017-01 | 汇丰、德意志、比利时银行、法国 Natixis、荷兰合作银行、意大利联合信贷银行等七大银行签署 MoU，拟在布鲁塞尔开发区块链贸易融资平台（文中"法国业兴银行"疑为"法国兴业银行"笔误） |
| 2017-05 | 香港金管局、汇丰、中国银行、东亚银行、恒生银行、渣打及德勤共同发起区块链贸易融资平台，业务涵盖借贷、信用证、保理、出口信贷和保险 |
| 2017-10 | IBM 与多国银行合作开发 Batavia 平台 |
| 2018-02 | R3 + TradeIX 与主要银行合作的 Marco Polo 平台进入试点 |
| 2018-03 | 9 家马来西亚银行联合研发区块链贸易融资应用 |
| 2018-05-14 | 汇丰宣布完成全球首笔区块链贸易融资交易，为嘉吉（Cargill）出具信用证 |
| 2018-08 | 渣打银行与西门子金融部门试点区块链银行担保（TradeIX 提供应用层） |

## 国内线

| 时间 | 事件 |
|---|---|
| 2018-09 前后 | 中国人民银行数字货币研究所在深圳成立全资子公司"深圳金融科技有限公司"，参与贸易金融区块链开发 |
| 2018-09-04 | "湾区贸易金融区块链平台"在深圳正式上线试运行 |
| 2018-05 | 五大国有银行（工农中建交）2017 年报显示均已开展区块链研发，场景包括扶贫、金融欺诈、贸易金融、数字票据等 |

## 证据强度分层

- **专业研究转述（中等偏弱）**：全部条目来自挖财研究院周报的媒体转载，未经原始公告核对；文中存在明显笔误（"法国业兴银行"、"爱来兰"），转述可靠性一般。
- **与既有条目冲突**：巴克莱首单年份（本文 2016-09 vs 既有 [[concepts/区块链贸易融资结算首案-巴克莱2017口径]] 2017 口径），双口径并存，由 [[queries/查询-巴克莱2016区块链贸易结算案的原始出处与交易细节考证]] 跟踪。
- **国内官方线**（央行数研所、湾区平台上线日期）相对可信，但仍属媒体转述，建议核对央行公告原文。
