# 秦岭数字平台业绩快照（自述口径，2024-11）

以下数据全部来自 [[entities/秦岭数字科技有限责任公司]] 自述、经万联网转述（2024-11-12），截至发文时点：

| 指标 | 数值 |
|---|---|
| 成交额 | 突破 800 亿元（成立不到 2 年） |
| 成交量 | 1.18 亿吨 |
| 服务货主 | 近 3000 家 |
| 整合重卡 | 12 万辆 |
| 整合司机 | 12 万 |
| 承运商 | 400 多家 |
| 派车单 | 超 700 万单 |
| 为贸易商节省人工成本 | 10 万元/年以上 |
| 人效比提升 | 1 倍以上 |
| 贸易商资金成本降低 | 平均 1–2 个百分点 |

## 证据强度分层

- **弱–中（自述/转述层）**：上述全部数字为平台/关联方自述，经万联网转述；万联网兼营培训课程与白皮书售卖（秦岭数字为其白皮书入选案例），存在夸大动机，无独立审计或第三方验证。
- **口径不明**：成交额是否含物流费、是否重复计算、平台实际营收与收入确认方式（全额/净额）均未披露。
