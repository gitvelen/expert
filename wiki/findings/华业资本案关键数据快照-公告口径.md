# 华业资本案关键数据快照（公告口径，2018）

- 2018-09-26 华业资本公告：子公司投资的应收账款未按期回款，触发差额补足义务共计 **8.88亿元**，占公司 2017 年底经审计净资产的 **13.06%**。
- 涉事应收账款累计 **101.89亿元**，转让方均为恒韵医药；其中自有资金购买 **27.75亿元**，其余为杠杆加购。
- 底层资产为恒韵医药对陆军军医大学第一、第二、第三附属医院的应收账款，遭医院否认并说明**公章伪造**，债务不真实。
- 存量应收账款面临部分或全部无法收回的风险。

## 证据强度分层

| 证据 | 层级 |
|------|------|
| 8.88亿差额补足、13.06%净资产占比、101.89亿/27.75亿金额 | 高——源自上市公司公告（经光大证券研究报告转述） |
| 医院公章伪造、债务不真实 | 高——医院方面公开否认（公告转述） |
| “杠杆加购”表述 | 中——券商研究转述，未见原始公告条款核对 |
