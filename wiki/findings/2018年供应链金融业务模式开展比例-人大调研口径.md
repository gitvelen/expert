# 2018年供应链金融业务模式开展比例（人大调研口径）

据中国人民大学中国供应链战略管理研究中心调研（前瞻产业研究院整理转述），2018 年被调研供应链金融服务企业中各业务模式开展比例：

| 业务模式 | 开展比例 |
|---|---|
| 应收账款融资 | 60% |
| 订单融资 | 39% |
| 预付款融资 | 38% |
| 存货质押融资 | 32% |
| 纯信用贷款 | 26% |
| 上游担保融资（依托核心企业） | 24% |

另据同源调研：2018 年 78% 的供应链金融服务企业业务实现全国覆盖（2017 年仅 39%），区域扩张趋势明显。参与主体构成上，供应链公司/外贸综合服务平台与 B2B 平台类约占 45%。

## 证据强度分层

- 人大调研数据：**中等**——学术机构调研，但转载未交代样本量与抽样方式，建议核对原始报告。
- 转述层级为前瞻产业研究院整理，中间多一层失真可能。

可与 [[供应链金融三大基础模式与场景对应-2020口径]] 的模式框架对照使用：应收账款融资开展面最广，印证"应收账款是供应链金融第一场景"的行业判断。
