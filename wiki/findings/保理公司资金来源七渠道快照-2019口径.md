# 保理公司资金来源七渠道快照（2019口径）

2019 年公众号"贸易金融"（转载自"保理法律研究"）归纳的国内商业保理公司七类资金来源：

1. 自有资金（注册资本金与自身盈利）
2. 银行融资
3. 股东借款或股东委托贷款
4. 与其他保理公司合作的再保理融资
5. P2P 等互联网金融平台
6. 资产证券化（专项计划模式）
7. 资管计划、私募基金、信托计划等融资

配套论断：除大型国有、上市公司背景保理公司能获得银行低息授信外，其他渠道资金成本不低，保理 ABS 的出现意在缓解此问题（定性陈述，无数据）。

## 证据强度分层

- 专业公众号分析：七渠道列举与成本论断（本文，2019）——业界通行归纳，无数据出处。
- 注意事项：P2P 渠道在 2019 年后行业清退背景下已基本不可用，本条目为 2019 年历史口径存档，不构成当前口径。
