# 2021年云筑集采业务规模快照（通稿口径）

以下数据来自云筑网宣传通稿（万联网 2021-12-13 转载），均为**厂商自报口径，统计截至 2021 年 12 月**：

| 指标 | 数值 |
|------|------|
| 云筑集采累计采购金额 | 突破 5 万亿元 |
| 分供商数量 | 逾 70 万家 |
| 标准物料 | 190 余万条 |
| 累计招标次数 | 117 万次 |
| 云筑蜜蜂会员企业 | 超 10 万家（上线不到一年） |
| 招采开放平台入驻中建外企业 | 数十家 |
| 招采开放平台在线定标金额 | 超 450 亿元 |
| 中建集团国资委采购管理对标 | 连续三年建筑行业第一名 |

行业背景口径：材料约占整个工程项目成本的 50%（行业通说）。

## 证据强度分层

| 证据 | 强度 | 说明 |
|------|------|------|
| 云筑集采业务规模数据（5 万亿、70 万家等） | 弱（一般新闻/宣传通稿） | 厂商自报，无第三方核验 |
| "领跑业内""规模和 SKU 居头部" | 弱，宣传性宣称 | 不作为事实采信 |
| 材料占工程成本约 50% | 中（行业通说） | 可引用但需标注口径 |
