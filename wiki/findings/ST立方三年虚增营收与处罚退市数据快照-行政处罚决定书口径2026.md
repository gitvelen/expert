# *ST立方三年虚增营收与处罚退市数据快照（行政处罚决定书口径2026）

经媒体转述的证监会安徽监管局《行政处罚决定书》数据（2026 年披露）：

| 指标 | 数值 |
|---|---|
| 虚假记载年度 | 2021、2022、2023 年 |
| 2021-2022 虚增营收合计 | 5.92 亿元（占两年披露营收 50.91%） |
| 代理业务总额法虚增（3年累计） | 2.76 亿元 |
| 融资性贸易虚增（3年累计） | 3.1 亿元 |
| 虚假贸易（2022，某度文化） | 交易额 5100 万元，虚增利润 51 万元 |
| 各年虚增营收占比 | 50.09%（2021）/ 51.67%（2022）/ 24.00%（2023） |
| 罚款 | 1000 万元（《证券法》第 197 条第 2 款） |
| 退市依据 | 深交所创业板上市规则第 10.5.1 条第一项、第 10.5.2 条第六/七项 |
| 停牌日期 | 2026-02-24 |

## 证据强度分层

- **高**：三重造假手法认定、各年虚增占比、合计金额、退市条款、罚款金额、停牌日期——行政处罚决定书转述口径（监管原文的媒体转述，可靠度较高但非文书原文）。
- **中**：听证申辩细节（"会计差错""不知情"及监管回怼）、46 号令外推至上市公司的"达摩克利斯之剑"表述——作者评论/解读，46 号令原文仅适用于央企。
- **低/待核**：三年合计虚增总额（标题称"超6亿"、文首称"近6亿"，正文仅给出两年合计 5.92 亿元）、2023 年单独虚增金额——见 [[queries/查询-ST立方三年虚增营收总额与2023年虚增金额明细核验]]。
