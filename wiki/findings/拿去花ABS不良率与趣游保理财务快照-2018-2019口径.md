# 拿去花ABS不良率与趣游保理财务快照（2018-2019口径）

| 2018年7月 / 2019年1月 | 0 | 0 |
| 2018年8月 / 2019年2月 | 0 | 0.07% |
| 2018年9月 / 2019年3月 | 0 | 0.06% |

- 1号8期-12期（2019年1-5月）期末不良率：0.18%、0.35%、0.39%、0.18%、0.20%。
- 2号第6期（2019-05-04~06-03）：不良率 0.27%（期初 0.11%），不良额度 102.93 万元（+132.66%）；第5期不良率 0.11%（期初 0.06%），不良额度 44.24 万元（+99%）。
- 不良率 = 该时点全部不良基础资产 ÷ 设立日保理债权余额之和；不良为逾期超90日或其他重大违约；分母固定，分子随循环购买累积（结构效应详见 [[concepts/商业保理ABS循环购买结构与不良留存机制]]）。
- 逾期分布（跟踪评级报告2019，2018年末在贷余额口径）：30天以内 0.60%、31-60天 0.34%、61天及以上 0.91%，合计 1.85%。
- 历史逾期率（2号说明书，截至2018年2月底）：免息类 0.3%、分期类 1%；基础资产以分期类为主，免息类占比≤25%。

## 趣游保理与拿去花产品数据

- 产品（2018年末）：在贷余额 10.8 亿元（+32.75倍）；自有资金授信总额度 508 亿元（+8.26倍）；授信用户 722.50 万户（+13.93倍）；在贷用户 70.89 万户（+5.19倍）。
- 趣游保理：2018年末资产 11.46 亿元（+21.04倍）；2019年3月末 12.8 亿元（较2017年末+23.62倍）；2018年末应收账款 10.65 亿元（占资产 92.97%，为净资产 1.96 亿元的 5.43 倍）；资产负债率 4.89%（2017末）→ 69.87%（2018H1）→ 82.92%（2018末）→ 84.70%（2019Q1末）；2018年净利 -401.86 万元、2019Q1 净利 29.60 万元；注册资本 2 亿元。
- ABS结构：1号 2018-06-01 成立（3.1亿元、两年期）；2号 2018-12-04 成立（4亿元、一年期、总额度≤30亿元）；循环期/摊还期对半；未出表；无不良回购安排。
- 对照：蚂蚁两家小贷公司 2017 年发行企业 ABS 2974.1 亿元（+362.68%）。

## 证据强度分层

1. **较强**：不良率、逾期分布、财务数据——来自华泰资管月度服务报告与跟踪评级报告（准官方文件），经《投资时报》引用。
2. **中等**：产品运营与说明书口径数据（2号说明书历史逾期率）。
3. **当事方口径**：拿去花 ABS 未出表、"循环购买下累计不良率上涨正常""不良率低于很多信用卡"——携程网相关负责人表态，非独立核验。
4. **一般报道层级**："保理类 ABS 出表难度颇大"（匿名行业人士）、"2号不良增速远快于1号同期"（记者比对）。
