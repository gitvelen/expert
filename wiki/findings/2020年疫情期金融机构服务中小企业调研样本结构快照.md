# 2020年疫情期金融机构服务中小企业调研样本结构快照

据《[[疫情下企业融资与供应链金融调研报告]]》预告稿（万联网 2020-03-26），该调研采用问卷调查，周期一个半月，累计调研 300 多家代表性企业，样本结构如下：

| 机构类别 | 占比 | 细分 | 占比 |
|---|---|---|---|
| 持牌金融机构 | 52.5% | 商业银行 | 17.6% |
| | | 保理公司 | 14.2% |
| 助贷机构（非金融机构） | 47.5% | 供应链管理服务公司 | 16.7% |
| | | 金融科技服务商 | 13.2% |
| | | 行业互联网平台 | 7.8% |

## 伴随的定性结论

大部分受调研企业表示将加强业务线上化（线上获客、申请、审批、签约、单据电子化），依据参见 [[银保监会155号文]] 第十二条。

## 证据强度分层

- 一般新闻报道/公众号（万联网原创预告稿，活动方自述口径）：以上全部数据与定性结论——**证据强度中偏下**，发布方即报告出品方之一，存在宣传动机；"首份报告""300 多家企业"等表述应标注为活动方自述。
- 监管原文（[[银保监会155号文]] 第十二条引文）：为媒体转述，需与原文核对。
