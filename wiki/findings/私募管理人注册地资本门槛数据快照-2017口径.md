# 私募管理人注册地资本门槛数据快照（2017口径）

2017 年"保理课堂"文章转载的地方注册与资本门槛数据，仅作历史快照，**不代表现行规定**。

| 项目 | 数值/规则 |
|---|---|
| 深圳前海：股权投资基金管理企业（股份有限公司形式） | 注册资本不低于 1000 万元 |
| 深圳前海：有限责任公司形式 | 实收资本不低于 500 万元 |
| 上海浦东 | 相应为 500 万元 / 100 万元 |
| 前海企业所得税优惠 | 符合条件企业减按 15% 征收（国函〔2012〕58 号），天津滨海、上海浦东不具备 |
| 信托投顾门槛 | 《信托公司证券投资信托业务操作指引》：第三方担任信托产品投资顾问实收资本不低于 1000 万元 |
| 管理人主体要求 | 依《证券投资基金法》及证监会/基金业协会口径，须为依法设立的公司或合伙企业，自然人不能登记 |

## 证据强度分层

- **专业公众号分析（转载自"保理课堂"，2017）**：上表全部地方门槛与优惠数据——中等强度，属转载性描述，未见原始地方文件核对。
- **监管原文（转引）**：《信托公司证券投资信托业务操作指引》投顾 1000 万要求、《证券投资基金法》管理人主体要求、《私募投资基金管理人登记和基金备案办法(试行)》（2014-02-07 实施）登记规则——较强，但应回查原文确认条文细节。
- **观点性内容（不计为事实）**：信托通道投资应收账款合规性的作者解读、契约型基金"难以对接银行优先资金"的判断。

## 时效

2017 年口径。此后前海/浦东相关准入与税收政策、私募管理人登记要求均已多次调整，本页数据不可作为现行依据；现行口径待查证（见 [[queries/查询-商业保理投资基金模式在资管新规及私募新规后的存续与演变考证]]）。
