# 宋群2019小微企业与账期数据快照（企业演讲口径）

以下数据来自2019年3月宋群在第三届中国供应链金融年会的发言，**均无出处标注**，整体证据强度弱（企业高管演讲/宣传口径），使用时须再核验。

| 指标 | 数值 |
|---|---|
| 大型企业户数 / 央企国企占比 | 29万户 / 约46% |
| 中型企业 | 约460万户 |
| 小微企业与个体工商户 | 接近8000万户，仅约10%与银行有授信关系 |
| 小微企业资金缺口 | 超20万亿元；48%企业每年1–2次缺口；单次平均约70万元 |
| 应收账款总规模 | 超20万亿元，头部企业约3万亿经银行满足 |
| 小微企业平均生命周期 | 约2.7年 |
| 平均账期 | 中国92天（同文另处95天，**内部不一致**）、全球66天、美国51天、英国53天 |
| ABS/ABN发行 | 2018年6000多亿，2019年预计7000亿 |

## 证据强度分层

- **一般新闻报道/演讲实录转述**（本页全部条目）：企业高管演讲口径，无原始统计出处；账期92/95天自相矛盾，可信度最低，仅作行业叙事参考。
