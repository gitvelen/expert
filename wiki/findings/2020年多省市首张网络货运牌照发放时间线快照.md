# 2020年多省市首张网络货运牌照发放时间线快照

依据《网络平台道路货物运输经营管理暂行办法》2020-01-01 生效，多省市陆续发放首张网络货运牌照，逐条日期如下（均为媒体/路歌文章口径）：

| 日期 | 地区 | 备注 |
|---|---|---|
| 2020-01-01 | 江苏 | 全国首张网络货运资质 |
| 2020-01-22 | 山东青岛 | 山东省首张 |
| 2020-02-21 | 河南郑州 | 河南省首张 |
| 2020-03-05 | 广西南宁 | 广西（原文作"广西省"，规范为广西壮族自治区）首张 |
| 2020-03-15 | 天津 | 天津市首张网络货运道路运输经营许可证 |
| 2020-03-16 | 福建厦门 | 福建省首张，亦为中国石材行业首张 |
| 2020-03-17 | 湖南岳阳（城陵矶新港区） | 湖南省首张 |
| 2020-03-31 | 陕西榆林绥德县 | 陕西省首张 |
| 2020-04-03 | 贵州铜仁 | 贵州省首张 |

## 证据强度分层

- **中（媒体口径，未独立核验）**：全部逐条日期均出自万联网 2020-04-15 转载的路歌文章，属"专业公众号分析/一般新闻报道"层级，未见官方名单交叉验证；引用时应注明"2020 年路歌文章口径"。
- **中高（政策事实）**：办法 2020-01-01 生效、网络货运取代无车承运人试点的制度背景，可与官方文件交叉验证。
