# 冠县模式关键数据快照（2025口径）

以下数据均为 [[entities/杜敏]] 2025-10-30 演讲自述口径（万联网 2025-11-10 刊发速记，未经嘉宾审阅），统计时点约为 2025 年 11 月。

## 平台运营数据

| 指标 | 数值 |
|---|---|
| 试运行 / 正式上线 | 2024-02-29 / 2024-07-11 |
| 注册企业 | 140 家（均为冠县生产制造型企业） |
| 融资需求 | 92 亿元（其中预付款融资 60 亿元） |
| 已放款 | 26 家企业、13.55 亿元 |
| 累计业务 | 146 笔，自述零违约零不良 |
| 物联网监管仓 | 分布式 35 个 |
| 综合融资成本 | 4.5% 以内，自述降幅超 50% |
| 年预付款融资潜在需求 | 360 亿元（调研口径） |
| 合作金融机构 | 日照银行、“山东省来商银行”（疑为临商银行之误）等 8 家 |

## 产业与项目数据

- 钢板年加工 1600 万吨（山东第二）；交通护栏全国份额 60%；纱锭 150 万枚；轴承年加工超 100 万吨（全国约 1/4）；灵芝产量与交易量全国第一。
- 冠州国际陆港：总投资 102 亿元、占地 3207 亩、建筑面积 77.7 万㎡，“一港六区六中心”，铁路专用线计划 2026 年 6 月建成。
- 冠县社会信用中心：正科级事业单位，1700 多项措施，归集信用信息 6300 余条。

## 证据强度分层

- **专业公众号刊载的演讲速记（自述型数据，未经独立核验）**：本页全部数值均属此层。速记未经嘉宾审阅，融资成本“降 50%”未说明基准口径，待验证事项见 [[queries/查询-冠县融资成本降50与146笔零不良数据的独立验证]]。
- **间接佐证线索（仍属单方转述）**：两次山东省金融现场会观摩点、2024-12 省现场会要求推广“冠县经验”、建设银行总行试点、[[entities/宋华]] 调研评价（经演讲者转述）。
- **缺失层**：无监管原文、无审计或银行侧独立披露、无学术论文核验。
