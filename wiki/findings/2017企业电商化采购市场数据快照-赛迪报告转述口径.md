# 2017企业电商化采购市场数据快照（赛迪报告转述口径）

据工信部赛迪研究院与中国电子报社《中国企业电商化采购发展报告(2017）》（本文为公众号转述）：

- 京东企业购占整体企业电商化采购市场份额 **48.6%**，接近半壁江山。
- 2017 年我国电商化企业采购市场规模已达 **千亿元** 级。
- 企业对消费型通用产品和服务的线上交易额同比增速超 **70%**。
- 企业开展在线采购的比例将超过 **50%**。

## 证据强度分层

- **专业公众号分析（转述报告）**：以上数据均来自 2019 年公众号文章对赛迪报告的转述，非报告原文核对；证据强度中等，引用时应注明"赛迪报告转述口径"。
- 统计年份为 2017 年，后续年份不适用；更新数值时按时效性规则移入历史数据。
