# 盛业2022年报核心数据快照（企业公告口径）

2023-03-23 港交所公告口径（转引自万联网，2023-03-27）：

| 指标 | 2022年数值 | 同比 |
|---|---|---|
| 经调整净利润 | 约2.5亿元 | +10% |
| 主营业务收入及收益 | 8亿元 | +39% |
| 数字金融解决方案收入 | 6.25亿元 | +45.3% |
| 供应链资产余额 | 约119.3亿元 | +46.9% |
| 其中：平台普惠撮合余额 | — | 约+22.5% |
| 累计处理供应链资产 | 1,591亿元 | +20% |
| 累计客户数量 | 1.28万家 | +23% |
| 科技收入（平台服务+供应链科技服务） | 超1亿元 | +106%（营收占比13%） |
| 产业互联网中标及签约合同额 | 约7,800万元 | 约+15倍 |
| 供应链科技服务收入 | 3,230万元 | 超+18倍 |

## 证据强度分层

- **较强**：财务数字来自港交所公告（2022年报口径）。
- **企业自述/预期口径，需考证**：增长归因、“国企合资每年撬动近百亿级增量资金”（预期非实绩）、“国内首笔双重ESG架构银团贷款”、“N+N+N”储架ABS创新性界定。
- **媒体转述**：原野采访观点（重交易轻主体共识、落地三难等），为观点性内容。
