# 供应链服务监管政策演进时间线快照（文健君转述口径，2025）

## 时间线（文健君文章转述）

| 年份 | 文件 | 要点（转述） |
|---|---|---|
| 2015 | 国资委政策法规局《融资性贸易法律风险防控及管理课题报告》 | 首次系统性分析融资性贸易风险特征与表现形式 |
| 2017 | 国发84号文《关于积极推进供应链创新与应用的指导意见》 | 供应链创新提升至国家战略；聚焦实体经济（⚠️ 文中误写发布主体为"商务部"，通行口径为国务院） |
| 2017 | 国资发评价〔2017〕45号《关于加强中央企业融资性贸易业务风险防范的指导意见》 | "十不准"原则前身，全面风险防控 |
| 2017 | 国资财管〔2017〕652号《关于进一步排查中央企业融资性贸易业务风险的通知》 | 首次将"空转""走单"定义为虚假贸易；界定融资性贸易核心特征（虚构贸易背景、上下游关联控制、标的物失控） |
| 2020 | 银发〔2020〕226号（央行等八部门） | 供应链金融顶层设计；首次明确定义内涵；禁止虚构贸易背景融资 |
| 2022 | 银保监发〔2022〕29号 | 普惠导向；应收账款质押/订单融资创新；防止核心企业滥用地位延长账期 |
| 2023 | 国资发财评规〔2023〕74号 | "十不准"；禁止背离主业、融资性贸易、无实物流转业务；"两头在外"界定及例外 |
| 2024 | 《国有企业管理人员处分条例》 | 融资性贸易与虚假交易分级处分，情节严重可开除；监管范围从央企扩展至全体国企 |
| 2025 | 《关于规范供应链金融业务的通知（征求意见稿）》（央行等六部门） | 应收账款电子凭证须基于真实贸易背景；付款期限原则上不超6个月（最长1年）；央行征信中心登记；技术公司不得承担信用中介职能 |

## 作者归纳的监管逻辑

- 演进路径：风险研究 → 规范界定 → 风控加强 → 责任追究 → 规则细化强化。
- 由单一禁止性措施转向法律、制度、技术手段的综合治理；一以贯之的原则是"打假"，核心目标是预防虚假贸易引发的国有资产流失与金融风险。

## 证据强度分层

- **高**：上述监管文件的存在、文号与核心取向（官方文件转述，可交叉核验）。⚠️ 84号文发布主体表述与通行口径（国务院）不一致，见 query。
- **中**：2025年征求意见稿细节（6个月/1年期限、征信中心登记）需与原文核对。
- **中**：审计署20家央企审计数据（18家虚增收入2001.6亿、虚增利润202.95亿，占同期0.8%/1.7%），转引东方财富网，需溯源审计署公告原文。
- **低**：作者对监管逻辑的归纳性解读，属个人观点框架。
