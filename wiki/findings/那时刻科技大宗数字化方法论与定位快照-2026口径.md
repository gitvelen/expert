# 那时刻科技大宗数字化方法论与定位快照（2026口径）

## 公司定位

"科技底座 + 平台运营"双轮驱动的产业服务联合体，以数字技术、智慧物联和场景平台化运营重塑产业商品流通与供应链协同模式。

## 四大核心方向

| 方向 | 内容 |
|------|------|
| 平台系统 | 产业交易平台系统 |
| 智慧仓储 | 物联网监管仓、智慧金融仓改造 |
| 数据中台 | 数据沉淀与资产化 |
| 合规支撑 | 合规闭环保障 |

技术架构：交易科技为主导，物联网为底座，目标五流合一（物流、货权、交易、资金、票据）。

## 核心诊断：数字化倒施工

先立项搭系统过验收，再逼迫线下真实贸易迁就线上死板流程，导致平台沦为"政绩展示牌"。

## 四大失效模式

1. 拿消费品电商模板套大宗（标准化SaaS无法承载非标流程）
2. 一口价静态挂单焊死交易（无价格公信力则无产业粘性）
3. 仅有单据数字化而无货权数字化（数据虚胖，审计不认/银行不用/纳统不算）
4. 仅撮合挂单无后端增值服务（无法自主造血，沦为成本中心）

## 五条务实路径

1. 先摸产业家底再建平台（头三个月不碰系统开发）
2. 系统适配生意——垂直行业深度定制
3. 动态市场化定价——基差联动、阶梯调价、批量议价
4. 做实货权物联底座——五流合一
5. 驻场式陪跑——交付即开始

## 典型失效案例

某地方城投砸300万建钢材交易平台，上线验收半年后后台仅2个账号登录（运维+汇报副总），线下生意照旧。

## 证据强度分层

| 证据 | 强度 | 说明 |
|------|------|------|
| 大宗贸易非标特性（长协锁价、分批交货、磅差补差等） | 行业常识级事实 | 论证坚实 |
| 无货权数字化的单据数据无资产与合规价值 | 强 | 与监管"贸易背景真实性""货权可控"原则一致 |
| "90%踩坑"覆盖率 | 经验性推断 | 基于上百个项目复盘，缺乏严谨统计抽样 |
| 城投300万平台失效案例 | 单一案例 | 仅作引子，非统计代表性样本 |
| 后端增值服务创造产业粘性 | 逻辑推演 | 符合产业互联网"以服务换数据"普遍规律 |
