# 2014年3月国产千元机大战价格与配置快照

据媒体报道（2014-03-31），2014年3月以小米、华为荣耀、联想、酷派为代表的国产厂商掀起千元机大战，共同配置为联发科 MT6592 八核处理器、高清大屏、只走电商渠道：

| 产品 | 定价（元） |
|------|-----------|
| TCL S720T 么么哒 | 778 |
| 红米Note（低配/高配） | 799 / 999 |
| 联想黄金斗士S8（低配/高配） | 788 / 988 |

TCL 么么哒另采用 MTK HotKnot 接触式无线传输技术（阿里巴巴支付平台后端安全机制支持其移动支付）。

## 证据强度分层

- **一般新闻报道**：上述价格、配置、参战厂商名单——来自 OFweek电子工程网综合报道（转载自 sinotf.com），层级最低。
- **企业自述（强度更低）**：王激扬"供应链与成本控制更具优势、不牺牲利润"及"Q3推出5模13频4G千元机"——属企业负责人表态，未经独立验证。
- **历史人物言论（2003年口径）**：万明坚"供应链对供应链竞争"论——有明确时间地点（2003-12-08 TCL首届移动通信全球供应商大会），但仍经媒体转述。

## 注意事项

文中无 TCL 供应链运作实质细节（库存周转、供应商账期、自制率），"供应链解密"名不副实，原文疑截断。后续验证问题见 [[查询-TCL供应链成本优势在2014年价格战后的实际兑现程度]]。
