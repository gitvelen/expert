# 全国 4000 多家生鲜电商盈亏分布快照（2018 年报道口径）

## 事实内容

据中国农业生鲜电商发展论坛发布数据（经中国商报 2018-03-07 报道转述），全国 4000 多家生鲜电商企业中：

| 状态 | 占比 |
|------|------|
| 盈利 | 1% |
| 持平 | 4% |
| 亏损 | 88% |
| 巨额亏损 | 7% |

同来源补充：2016 年以来鲜品会、菜管家、美味七七等十几家生鲜电商陆续倒闭，水果 O2O 平台许鲜随后也无法正常运营。

## 证据强度分层

- 中国商报报道转述中国农业生鲜电商发展论坛数据：**一般新闻报道（低—中强度）**，无原始报告可溯，统计口径与年份不明。
- 倒闭名单为媒体转述统计，具体名单与时间待考证。
