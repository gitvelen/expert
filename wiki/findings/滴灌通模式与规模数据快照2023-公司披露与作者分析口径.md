# 滴灌通模式与规模数据快照（2023）

以下数据与条款均为2023-11时点，来源为嵇少峰评论所引滴灌通披露与媒体专访，均未经独立验证。

## 模式与规模

| 项目 | 数值/内容 | 口径 |
|---|---|---|
| 已投店铺数 | 1万多家 | 滴灌通披露 |
| 合作品牌数 | 超过600家 | 滴灌通披露 |
| 商业模式 | 投资连锁加盟店，按每日营业收入比例分成；非股非债，无借款人、无担保人、无代偿责任 | 滴灌通披露 |
| 合作期 | 一般约4年（前两年回本、后两年回收投资收益的估算前提是店铺投资回报周期控制在6-12个月） | 作者估算+滴灌通披露 |
| 分成比例 | 传闻接近年化24% | 传闻，作者明言未看到具体条款 |
| 资金端 | 自有资金 + 滴灌通澳门金融资产交易所（DRO/DRP凭证挂牌） | 滴灌通披露/媒体专访 |
| 模式自述 | “业主出店铺、滴灌通出钱、开店者出力运营管理”的联营模式 | 滴灌通披露 |
| 老店问题 | 已投1万多家店中，部分投资投向品牌已有老店的营收分成 | 滴灌通披露 |

## 欧洲RBF参照数据

- 欧洲2000年以来出现10多家RBF初创公司，换取未来销售额5-20%的分成。
- Liberis（2007年成立）已为欧美英17,000家中小企业提供超过5亿英镑融资。

## 证据强度分层

1. **无（截至2023-11）**：内地监管对滴灌通模式的正式定性；澳交所运营与挂牌规模的第三方审计数据。
2. **传闻/公司自述层（最弱）**：年化24%分成比例、4年合作期条款细节、1万+店铺与600+品牌投资规模——均依赖滴灌通自我披露或市场传闻。
3. **专业分析层（中等）**：嵇少峰关于非P2P判定、法律追索弱化、监管套利风险、老店融资危险的分析——逻辑推演扎实但基于公开信息，属个人观点。
4. **媒体报道层**：腾讯新闻对李小加的专访内容（本库未直接收录原文）。
