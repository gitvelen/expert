# 2014年中国食材节活动数据快照（媒体转述口径）

2014-03-23 于武汉国际会展中心举办的"2014′良之隆·第二届中国食材节"（[[武汉良中行供应链管理有限公司]] 主办）活动数据：

| 指标 | 数值（2014 年） |
|---|---|
| 参展企业 | 300 余家（海内外水产及冻品厂商、经销商、物流商、连锁餐饮酒店） |
| 参会人数 | 20000 余名 |
| 参展新菜 | 1500 款 |
| 发布创意菜 | 108 款（2014 良之隆） |
| 现场招标年度订单 | 50 余家大型餐饮连锁酒店、30 亿元 |
| 现场订货酒店 | 6000 家 |
| 网上同步订货餐厅 | 30000 家 |

## 证据强度分层

- **一般新闻报道（最低层级）**：以上全部数据均出自中国水产频道活动报道（公众号"供应链金融"转载），系媒体/主办方转述口径，未经独立核实；"30 亿元订单招标"为招标规模而非成交额，实际成交与履约情况不明。
