# 欧冶绿融与欧冶金融 2016–2017 业务规模快照

**口径：企业（欧冶方面）向中国经济时报提供的自述数据，经 2017-09-13 报道发布，无独立审计验证。**

## 欧冶绿融（截至 2017 年报道时点）

| 指标 | 数值 |
|---|---|
| 首笔业务日 | 2016-10-14 |
| 累计业务笔数 | 18,402 笔 |
| 累计发生额 | 34.91 亿元 |
| 授信用户 | 2,500 余家 |
| 合作仓库 | 500+ 家 |
| 融资余额 | 6.43 亿元 |
| 平均放款时间 | 2 小时（最快 30 分钟） |
| 小额授信门槛 | 300 万以下仅需平台注册并上传三证 |

## 欧冶金融整体

| 指标 | 2016 年底 | 2017 年上半年 |
|---|---|---|
| 融资额/余额 | 融资额 200 亿元（欧冶金服） | 融资余额约 72 亿元 |
| 支付规模 | 1200 亿元 | 超 711 亿元 |
| 财富管理 | 累计投资超 100 亿元 | 新增投资超 15 亿元 |

注：2016 年底"融资额 200 亿元"与 2017 上半年"融资余额约 72 亿元"统计口径不同（累计发生额 vs 余额），不能直接对比。

## 欧冶物流

- 全国仓储合作单位超 1,500 家（2017 年报道时点）。

## 证据强度分层

- **一般新闻报道（弱）**：全部数值均来自中国经济时报记者张一鸣转述的企业自述，属新闻层级证据；张周平的分析为专业分析师观点层级。使用于报告时须注明"企业自述、未经审计"，并以后续年报/审计口径复核。
