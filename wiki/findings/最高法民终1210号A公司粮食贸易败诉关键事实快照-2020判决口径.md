# 最高法民终1210号A公司粮食贸易败诉关键事实快照（2020判决口径）

（2020）最高法民终1210号判决：国企控股（51%）物流公司 A公司 与 B公司 的粮食购销纠纷中，法院以贸易真实性证据不足为由驳回 A公司 全部诉讼请求。判决作出于2020年，早于2023年国资委"十不准"（74号文）监管框架，但司法证伪逻辑与之方向一致。

## 关键数据快照

| 项目 | 数值 |
|---|---|
| 《粮食产品购销合同》 | 10份 |
| A公司累计付款 | 10.3亿元（银行转账+银行承兑汇票） |
| B公司开具增值税发票 | 9.39亿元 |
| 双方确认供货 | 378,460吨 / 9.39亿元 |
| 争议预付款 | 9203.4万元 |
| A公司诉请违约金 | 2730万元 |

## 裁判要旨

- 争议焦点：正常贸易关系 vs 资金出借关系。
- 法院调查交货地国有粮库：粮库与A公司无仓储物流关系，A公司及受其委托的第三方均未在粮库提过货，B公司亦未出具委托提货书。
- 形式证据（合同、协议、价格函、收货确认函、委托出库书、对账函等）不足以证明真实货物流转；发票不能证明货物流转。
- A公司拒绝变更诉讼请求（坚持买卖合同关系），法院驳回全部诉请。判决本身未直接宣告构成借贷关系。

## 五项不合规事实

1. 无赴粮库尽调证据（数万吨级采购未核实数量、质量、存储条件）。
2. 未与粮库建立仓储/委托合同关系。
3. 《委托出库书》未经粮库盖章确认（拟制交付欠缺保管人参与，参照《民法典》第910条）。
4. 缺乏仓储、运输、质检、过磅、对账等过程证据与货款台账。
5. 对1亿元级"先款后货"预付款未尽注意义务。

## 证据强度分层

- **监管原文/司法层级（最高）**：裁判要旨与五项不合规事实——来自最高法二审判决书披露内容（经媒体转述），证据强度高。
- **专业公众号分析（媒体观点）**："不出事是正常贸易，出了事就是融资性贸易"名言及"被认定为融资性贸易"的定性表述——作者归纳与解读，非判决原文；判决实际口径为"贸易真实性证据不足、驳回诉请"。
