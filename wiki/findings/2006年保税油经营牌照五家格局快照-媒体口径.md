# 2006年保税油经营牌照五家格局快照（媒体口径）

依 2014 年媒体转述（文中称"2006 年，光汇石油跻身国内五家拥有保税油经营牌照的企业"），当时中央政府下发的保税油牌照给予五家企业：

| 企业 | 性质 |
|---|---|
| 中石化长燃有限公司 | 央企合资（中石化与长航） |
| 中石化舟山公司 | 央企 |
| 中海集团燃油销售公司 | 央企合资（文中称"中石化与中海合资"，表述存疑） |
| 中船集团燃油销售公司 | 央企合资（中石油与中船集团） |
| 光汇石油 | **唯一民企** |

- 光汇石油借此成为当时国内五家保税油牌照持有者中唯一的民营企业，为其后海上供油业务（2012 年成为新加坡第三大海油供应商）的资质基础。

## 证据强度分层

- 上述名单与合资关系表述均为 2014 年媒体转述的 2006 年口径，层级为一般新闻报道，未核实；"中海集团燃油销售公司"的合资关系表述存在疑点，建议以 [[queries/查询-2006年保税油牌照五家名单与合资关系核验]] 跟踪。
- 属历史口径，牌照格局此后如有变化以最新有效口径为准。
