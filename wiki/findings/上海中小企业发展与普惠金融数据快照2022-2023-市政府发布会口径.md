# 上海中小企业发展与普惠金融数据快照（2022-2023，市政府发布会口径）

数据出自2023年5月17日上海市政府新闻发布会（市经信委主任吴金城介绍），属官方披露的媒体转述口径。

## 上海中小企业基本盘（2022 年数据）

| 指标 | 数值 |
|------|------|
| 规上中小企业工业产值 | 超2万亿元，占全市规上工业产值49.4% |
| 工业出口交货值 | 2871.2亿元，占全市32.3% |
| 市场主体 | 327.3万户（民企+个体占93.4%） |
| 创新型中小企业 | 10416家 |
| 市级专精特新中小企业 | 7572家（全国占比10%） |
| 国家专精特新"小巨人" | 500家（全国占比5.6%） |
| 制造业单项冠军示范企业和产品 | 38家 |
| 国家级中小企业特色产业集群 | 金山、青浦、宝山、松江、临港共5个（全国第一） |
| 科创板上市企业 | 79家，总市值约1.5万亿元，融资约1956亿元（首发募集总额与总市值全国第一） |
| 专精特新企业建国家级/市级企业技术中心 | 353家 |
| 建院士专家工作站 | 309家（占全市48.3%） |

## 金融赋能与担保数据（2022-2023 年口径）

| 指标 | 数值 |
|------|------|
| 政策性担保基金规模 | 由50亿元扩至100亿元 |
| 年融资担保规模 | 700亿元 |
| 信贷奖补不良率门槛 | 0.5%，补偿比例最高55% |
| 国家中小企业发展基金落地上海 | 总规模357.5亿元 |
| 2022年国家中小企业发展专项资金（上海） | 约3亿元 |
| 减负总额（近年累计） | 超3000亿元 |
| "免罚""免强"惠及市场主体 | 8400多家，免罚金额超6亿元 |
| 无分歧欠款化解率 | 100%；50万元以下清偿率100% |

## 《若干措施》量化目标（2023 年口径）

- 普惠贷款余额达1.1万亿元；无缝续贷累计投放突破1.2万亿元；节约成本100亿元以上；平均担保费率≤1%。
- 市级以上企业技术中心突破1000家；2023年推动3000家规上工业企业完成智能制造成熟度测评；25万家中小企业上平台上云。
- 政府采购工程面向中小企业预留份额提至40%以上（延续至2023年底）；培育10个左右市级、力争再建5个左右国家级特色产业集群。

## 证据强度分层

- **官方新闻发布会披露（媒体转述）**：以上全部数据——官方口径，可信度较高，但非文件原文，个别数字建议使用前核对原始文件。
- 按时效性规则，普惠贷款1.1万亿等均为2023年目标口径，后续年份如有更新数据应移入历史数据条目。
