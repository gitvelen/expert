# 煤炭贸易流程风控三原则与货权管控举措快照（期刊口径2024）

## 事实条目（2024 年期刊口径）

1. "以销定进"：除库存当量管理允许的库存外，所有采购必须购销对接、具备生效销售合同。
2. "先货后款"：取得煤炭所有权后付款；港口平仓须办妥装船手续后付款。
3. "款到发煤"：未经批准赊销的客户一律款到发货；每批销售须取得有效收货证明。
4. 货权管控：与港口明确约定印鉴、出库指令、存货凭证，货权交接连续收集各环节单据。
5. 三个物流监管部门人员不定期轮岗、调岗，防驻外物流部门与第三方串通。
6. C 公司 2012 年囤积进口煤遭遇煤价暴跌巨亏；2014 年前子公司财务各自独立为危机内因。
