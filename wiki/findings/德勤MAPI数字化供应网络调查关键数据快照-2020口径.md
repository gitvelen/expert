# 德勤-MAPI 数字化供应网络调查关键数据快照（2020口径）

**口径说明**：以下数据来自德勤（Deloitte）与 MAPI 联合调查的中文译文（2020-02-22 转载），受访主体为**制造企业**（以美国为主），不可转嫁至中国供应链金融主体。原始样本量与调查方法文中缺失，见 [[查询-德勤MAPI数字化供应网络调查原始报告样本与方法核验]]。

## 关键量化指标（德勤报告口径，2020）

| 指标 | 数值 |
|------|------|
| 自评 DSN 成熟度"高于平均水平" | 51% |
| 已实际执行 DSN 方案 | 28% |
| 加入生态体系共享数据 | 6% |
| 认为 DSN 能创造巨大效益 | 约 1/10 |
| 最重要技术：高级分析 / 建模仿真 / 优化预测分析 | 40% / 34% / 32% |
| 愿意投资区块链 / 可穿戴技术 | 17% / 13% |
| 认为 DSN 有助于提高决策速度与质量 | 52% |
| 最大风险因素：抗拒变革 / 独立运作 / 缺商业案例 / 目标不切实际 | 37% / 33% / 26% / 25% |
| 过去一年未做网络风险评估 / 不确定是否做过 | 40% / 22% |
| 无法从内部网络充分获取汇总数据 | 43% |
| 认为需全职技能人员现场支持 | 70% |
| 现有预测准确率 | 70%-75% |
| 美国制造业员工缺技术技能 / 数学技能不足 | 近 2/3 / 60% |
| 未来十年美国制造业岗位缺口（德勤估计） | 200 万 |

## 核心结论：认知-行动脱节

多数企业认知到 DSN 优势并自评成熟度乐观（51%），但实际执行（28%）与生态数据共享（6%）严重滞后；报告认为部分企业高管自评"过于乐观"，存在认知盲点风险。

## 区块链遇冷

仅 17% 制造企业愿意投资区块链，与 2019-2020 年中国供应链金融圈区块链热捧叙事形成对照。注意：报告作者"采用率将快速提升"的预期属作者观点，非数据结论。
