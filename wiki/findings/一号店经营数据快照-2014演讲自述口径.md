# 一号店经营数据快照（2014演讲自述口径）

以下数据均为于刚 2014 年演讲自述，未经外部核验，引用时须标注"2014 演讲自述口径"。

| 项目 | 数值 | 备注 |
|---|---|---|
| 营收 | 2008 年 400 多万 → 4000 多万 → 2013 年 200 多亿 | 年度口径 |
| 品类（SKU） | 170 多万个 | 文末另出现"仓位品类 1700 万"，疑笔误 |
| 仓储面积 | 28 万平米 | 当年预计超 30 万平米；东莞获约 400 多亩地 |
| 注册会员 | 3000 多万 | |
| 掌上一号店会员 | 1000 万 | 移动购物高峰在晚 9-11 点及周末 |
| 订单处理时长 | <80 秒 | 含 17 件商品订单，目标 50 秒以下 |
| 转化率 | 平均 2-3%，上海超 10% | 快消切入优势 |
| 快消占比 | 早期约 70-80% → 2014 年 30% 多 | 品类扩张结果 |
| 配送 | 自建 40 多城 + 近 30 家三方物流 | 上海及时到达率 99.5%+ |
| 自建配送密度临界点 | 日均 30 单 | 低于此成本不划算 |
| 物流相关投诉 | 占周度投诉 60% 多（自建前） | |
| 目录营销失败成本 | 印刷 14 元/本 + 邮寄 3 元/本 | 印 10 万本、发 2 万多本，3 天订单衰减归零 |
| 顾客满意度 | 84.4% → 92%（一年） | 三方衡量并与全员薪资挂钩 |
| 天涯一号店活动 | 单次 40 万人参加 | 社交购物案例 |
| 虚拟超市（2011） | 手机销售翻近 3 倍、媒体关注升 4 倍 | 后拓展 GPS 虚拟货架 1000 个点 |
| 一号商城商家 | 近 1 万家 | SBY 入驻服务商家近 1000 家 |

## 证据强度分层

- **中等（当事人自述，细节具体）**：目录营销失败全过程、自建配送决策与密度临界点、顾客满意度机制——一手亲历详述，但无外部核验。
- **中等偏弱（当事人自述的汇总数据）**：营收、SKU、仓储面积、会员数、转化率——口径无法独立验证，且 SKU 存在内部矛盾（170 万 vs 1700 万）。
- **弱（事前预测，已被取代）**："未来 5 年年增 27%"、中美渗透率对比——2014 年专家判断口径，仅作历史对照。
