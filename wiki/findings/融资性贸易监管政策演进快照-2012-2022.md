# 融资性贸易监管政策演进快照（2012–2022）

据泰和泰律师事务所文章整理的政策检索表（2024 年口径），监管主线为**从适度压缩 → 全面清理 → 严禁开展**。

## 演进脉络

| 时间 | 文件 | 关键内容 |
|---|---|---|
| 2012-05-27 | 国资委《关于加强中央企业资金管理有关事项的补充通知》 | 适度压缩融资性贸易规模，全面清理"预付加赊销"业务，不得变相出借资金 |
| 2015 | 国资委年度报告填报/财务决算通知 | 披露融资性贸易重点业务事项；加大风险管控力度 |
| 2016-08-02 | 国办《关于建立国有企业违规经营投资责任追究制度的意见》 | 购销管理责任追究：交易行为虚假或违规开展"空转"贸易、变相融资或投资等 |
| 2018-04-10 | 八部门《关于开展供应链创新与应用试点的通知》 | 加强供应链金融监管，打击融资性贸易、恶意重复抵质押、恶意转让质物 |
| 2018-07-13 | 《中央企业违规经营投资责任追究实施办法（试行）》第九条（三） | 违反规定开展融资性贸易业务或"空转""走单"等虚假贸易业务列为追责情形 |
| 2019-10-23 | 《国务院关于2018年度国有资产管理情况的综合报告》 | 坚决清理融资性贸易 |
| 2020-06-17 | 上海市属国企违规经营投资责任追究实施办法（试行） | 地方版追责情形 |
| 2021-02-28 | [[国资发财评规2021-18号文]] | 严禁融资性贸易和"空转""走单"等虚假贸易业务（口径由"清理"升格为"严禁"） |
| 2021-12-06 | 国资委 2021 年度央企财务决算通知 | 全面清理融资性贸易、"空转""走单"等风险业务 |
| 2022-01-08 | [[央企司库体系建设意见2022]] | 严禁开展融资性贸易业务和虚假贸易业务 |
| 2022-04-20 | 广东省国资委"合规管理强化年"行动方案 | 准确把握融资性贸易实质，不得违规开展 |
| 2022-09-22 | 成都市属国有企业融资及担保监督管理办法 | 不得开展名为贸易实为对外提供资金的业务 |

## 证据强度分层

- **政策原文/官方答复**（高层级）：上表各文件内容均转引自律所文章中的政策原文摘录，文号、日期明确，可直接核对原文验证。
- **专业公众号分析**（中层级）：对演进主线的归纳（"适度压缩→全面清理→严禁"）与四案例判断逻辑，为泰和泰律所作者观点。
- 注意：2023 年国资委政务咨询答复公开 652 号文口径后，"四大特征+实质判断"为当前最新有效界定标准。
