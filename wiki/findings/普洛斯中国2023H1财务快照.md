# 普洛斯中国 2023H1 财务与资产快照（半年报转述口径）

以下数据截至 2023 年 6 月 30 日（2023 年口径，来自普洛斯中国 2023 年半年报的媒体转述）：

| 指标 | 数值 |
|------|------|
| 营业收入（2023H1） | 约 6.4 亿美元，同比 +6.5% |
| 工业物流基础设施收入 | 4.24 亿美元，毛利率 75%，占收入 66% |
| 其他业务板块收入 | 2.19 亿美元，毛利率 7%，占收入 34% |
| 完工稳定物业面积 | 3758 万㎡ |
| 完工未稳定物业面积 | 192 万㎡ |
| 在建/重新调整物业面积 | 622 万㎡ |
| 土地储备面积 | 349 万㎡ |
| 总建筑面积 / 可供出租 / 实际出租 | 3758 万㎡ / 3710 万㎡ / 3139 万㎡ |
| 投资性房地产账面余额 | 136.4 亿美元，占合并总资产 36.65% |
| 投资性房地产公允价值变动损益 | 1.45 亿美元，占利润总额 65.2% |

## 证据强度分层

- **半年报转述（较强）**：上表财务与资产数据，源自普洛斯中国 2023 年半年报，经万联网综合整理转述；建议在正式报告中核对半年报原文。
- **关联背景（中等）**：普洛斯中国覆盖 70 个地区市场、450 多处基础设施，控股股东为 CLH Limited（普洛斯集团 100% 持有），来自公开资料转述。
