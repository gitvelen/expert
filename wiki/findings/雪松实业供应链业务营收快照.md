# 雪松实业大宗商品供应链管理业务营收快照（2016–2020）

| 年份 | 供应链销售收入（亿元） |
|------|----------------------|
| 2016 | 505.45 |
| 2017 | 1302.44 |
| 2018 | 1983.86 |
| 2019 | 2500.47 |
| 2020 | 1917.29 |

- 占雪松实业营业总收入比例**超过 90%**。
- 口径：公开资料转述（万联网 2022-03-30 文章引述），非雪松实业原始评级报告/财报直接核对。

## 证据强度分层

- **较强**：财务数字本身有公开资料可循（评级报告/财报类来源转述），2022 年口径。
- **弱（关联推断，不作认定）**：离职人士"融资性贸易"指控为传闻口径；营收高企与兑付违约并存仅是线索，不构成融资性贸易认定。
