# 煤炭"十四五"14基地产量控制与结构目标数据快照（官方口径）

依据中国煤炭工业协会《煤炭工业"十四五"高质量发展指导意见》（经万联网2025-07-01文章转述，建议回溯原文核验）：

## 总体目标（"十四五"末）

- 全国煤矿数量控制在 **4,000 处以内**
- 建成煤矿智能化采掘工作面 **1,000 处以上**
- 建成千万吨级矿井（露天）**65 处**，产能超 **10 亿吨/年**
- 培育 **3–5 家**具有全球竞争力的世界一流煤炭企业

## 14个大型煤炭基地产量控制

| 基地 | 产量控制（亿吨/年） |
|---|---|
| 蒙东 | 5 |
| 云贵 | 2.5 |
| 冀中 | 0.6 |
| 鲁西 | 1.2 |
| 河南 | 1.2 |
| 两淮 | 1.3 |
| 晋北+晋中+晋东 | 合计 9 |
| 神东 | 9 |
| 陕北+黄陇 | 合计 6.4 |
| 新疆 | 3 |
| 宁东 | 0.8 |

## 历史去产能数据（2015年口径）

- 截至2020年底，全国累计退出煤矿约 5,500 处，退出落后煤炭产能 10 亿吨/年以上（《煤炭清洁高效利用行动计划（2015-2020年）》相关成效）。

## 证据强度分层

- **官方文件转述口径（证据较强）**：以上数据源自中国煤炭工业协会、国家能源局发布文件，但经由媒体文章转述，最终核验需回溯原文。
- 文章中的行情判断（周期4年、500元/吨触发线等）不属于本 finding 范围，证据弱。
