# 联链通平台运营数据快照（公司口径，2025-09 → 2025-11 更新）

以下数据全部来自[[联投资本]]自述（2025-09万联网转载；2025-11黄露演讲万联网速记），**均无独立核验**，引用时须注明口径。

## 当前口径（2025-11，黄露演讲，万联网速记）

- 业务资产规模：突破 **700亿元**
- 服务链上企业：6300余家；累计融资超200亿元（其中普惠融资超129亿元）
- 合作金融机构67家；覆盖20条产业链
- 笔均153万元、户均315万元；平均融资成本2.98%/年（最低2.19%/年）
- 融资为信用方式、无抵押要求（速记另有“全额抵押”矛盾表述，待澄清）
- 连续33个月“零不良”；综合降低企业成本5.92亿元
- 发展里程碑：2024-10业务规模破百亿 → 2024-12获批20亿储架 + 落地首单省地共建ABS（利率2.5%）→ 2025-06获准接入上海票据交易所供应链票据系统（湖北省首批）→ 2025-09-27落地湖北省内首笔直连票交所的供应链票据业务，单日规模突破1亿元

## 历史数据（2025-09口径，已被上表取代）

来自2025-09来源页的观测点，为700亿（2025-11）前一观测点，属自然增长，非口径冲突：

| 指标 | 数值 |
|---|---|
| 服务链上企业 | 超6200家 |
| 累计融资 | 超208亿元 |
| 业务资产规模 | 超689亿元 |
| 覆盖范围 | 湖北17个地市州、20个行业、4个省级重点产业链供应链平台 |
| 合作金融机构 | 66家（另一处表述为“资金方超60家”） |
| 累计带动普惠融资 | 超129亿元 |
| 综合降低企业成本 | 超5.92亿元 |
| 平均融资成本 | 2.98%/年（最低2.19%/年） |
| 户均 / 笔均 | 315万元 / 153万元 |
| 获省级奖补 | 1740万元 |
| 风控声明 | 100%无不动产抵押、连续33个月零不良 |

注：2025-09口径称累计融资“超208亿元”，2025-11口径称“超200亿元”；两处表述并存，均出自公司自述，待核实是否为不同统计口径。

## 可核验性较高的事实

- 2025-06-18 获准接入上海票据交易所供应链票据系统（湖北省首批）。
- 2025-09-27 落地湖北省内首笔直连票交所的供应链票据业务，单日规模突破1亿元。
- ABS发行利率、省级奖补金额、襄链通上线时间（公司口径但属可独立查证事件）。

## 证据强度分层

- **公司自报演讲口径**（专业媒体速记，未经嘉宾审阅；强度低）：全部运营数据、“零不良”风控声明、降本金额、省地/省省共建项目效果（如融强科技降本3%–4%）——不可作独立验证事实引用。
- **可核验披露事实**：票交所接入批复、ABS发行利率、奖补金额、襄链通上线时间。
