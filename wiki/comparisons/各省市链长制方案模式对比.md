# 各省市链长制方案模式对比

依据来源：[[4-news--7-01-政策合规--4-2021--26-盘点各省市链长制方案核心-一枝独秀迎来全面开花-政策--p769f8]]。

| 省市 | 关键机制命名 | 链长层级 | 重心/目标差异 |
|---|---|---|---|
| 浙江 | “九个一”机制 | 开发区层面，率先实践 | “做强”：块状特色产业、园区系统性重构 |
| 江西 | “一位省领导、一个牵头部门、一个工作方案、一套支持政策” | 11位省领导任14链 | “稳”：疫情对冲、填补链条缺口 |
| 深圳 | 链主认定 + 链式服务 | 市政府 | 培育链主（年产值≥100亿元）+ 用地支持 |
| 河北 | “一链一图、一链一制、一链一策” | 省级 | 高新区新兴产业强链补链延链 |
| 河南 | "1+10"工作体系（“一个产业链、一个方案、四个清单、一套班子、一抓到底”） | 省级领导 | 10个新兴产业链精准配套 |
| 山东 | “1个图谱”+“N张清单”（10类清单） | 省市携手 | 35条关键产业链工程化、项目化，“双招双引” |
| 湖北 | 金融链长制（“链链对接”“一链一策”） | 省级银行业金融机构任金融链长 | **金融对接**（唯一以金融机构任链长的模式） |
| 广东 | “总链长”+“五个一”工作体系 | 省长任总链长 | 20个战略性产业集群自主可控 |
| 湖南 | “一链一行”主办行名录（半年动态调整） | 人民银行长沙中心支行+省工信厅 | 供应链金融、供应链票据、应收账款票据化 |
| 西安高新区 | “一位链长、一个牵头部门、一套工作方案” | 党工委/管委会领导 | 招商引资（“招商链建在产业链”） |
| 黑龙江 | 总链长+链长分层 | 省政府主要领导/副省长 | 7条重点产业链贯通关键环节 |
| 合肥 | “123+10”行动 | 市级 | “六稳”“六保”，延链补链强链 |
| 南京 | “四个一”（一链、一市领导、一专班、一负责人） | 市领导 | 八大产业营收年增20%，2025年打造全国影响力链条 |
| 天津 | “四个一”（一链、一市领导、一专班、一方案） | 市领导任10链链长 | 强链5条、新链2条、短链3条，培育链主 |

## 观察结论

1. **工作方法谱系高度趋同**：浙江“九个一”、江西“四个一”、南京/天津“四个一”、河南"1+10"、山东"1+N"均为“一链一专班/一方案/一清单”式变体，反映同一治理模板的本地化。
2. **目标分化**：浙江重“做强”、江西重“稳”（疫情语境）、深圳重“培育链主+要素（土地）”激励、湖北重金融对接。
3. **链长主体差异**：多数由党政领导担任；湖北独树一帜由**银行省级机构负责人**担任“金融链长”，湖南的“一链一行”是相近但不同名的金融化变体。
4. 天津方案的链长条款可进一步纳入 [[区域金融改革方案供应链金融条款对比天津成渝长株潭]]。
