# 保理与应收账款质押11维区别框架（2019法律口径）

| 维度 | 应收账款质押 | 应收账款转让（保理） |
|---|---|---|
| 法律性质 | 担保物权（权利质押），从属法律关系，适用《物权法》223/228条 | 债权让与，独立债权买卖，适用《合同法》79–83条 |
| 含义范畴 | 融资的从属担保方式，可支撑贷款、承兑、信用证、保函等 | 转让本身即为融资，兼具催收、管理、坏账担保功能 |
| 生效要件 | 质权自信贷征信机构登记时设立（登记生效） | 未经通知债务人，对债务人不生效力（通知生效） |
| 对受让人/质权人 | 优先受偿权、诉权、代位物与担保利益追及权、破产别除权 | 债权人变更、主从权利随同转移、转让人瑕疵担保责任 |
| 对债务人 | 抗辩效力无法律规定；通知前抗辩事由一般可对抗质权人 | 享有抗辩权与抵销权 |
| 运行机制 | 清算型：多退少补，不足继续追偿 | 买断型：回款风险与转让人无关 |
| 追索权 | 风险分散于出质人与账款债务人两方 | 受让人独担坏账（无追索为原则，回购型/附追索除外） |
| 收益 | 仅融资利息 | 贴现差价+保理费、管理费、发票处理费 |
| 对应收账款权利 | 出质人清偿主债务后质权消灭、权利恢复 | 出让人立即丧失权利，除非反转让 |
| 适用范围 | 宽（五类，含不动产收费权、贷款债权等） | 窄（销售/服务应收账款，排除信用证与现金交易） |
| 通知债务人 | 是否生效要件有争议，银行实践要求通知并取得确认 | 存在暗保理等隐蔽做法，逾期后通知效力有争议 |

## 风控意义

登记公示（质押）与通知确权（转让）是防止应收账款重复融资、重复质押的法律机制，直接支撑本知识库"货权/债权控制力"工作论点。

## 时效提示

本框架全部法条基于《物权法》《合同法》2019年口径，2021年起已被《民法典》对应条款取代，对照更新见 [[查询-民法典时代保理与应收账款质押区别框架条款对照更新]]。
