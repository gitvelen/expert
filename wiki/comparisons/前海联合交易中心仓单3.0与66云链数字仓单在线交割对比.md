# 前海联合交易中心仓单3.0与66云链数字仓单在线交割对比（2023）

两条同属"平台 + 仓单 + 资金清算基础设施"的大宗商品交割数字化路径，各自解决物权管控与钱货两讫问题。

## 对比维度

| 维度 | 前海联合交易中心仓单 3.0 | 66 云链数字仓单在线交割 |
|---|---|---|
| 平台属性 | 前海联合交易中心（QME） | 66 云链"仓海帮"（中国中化+中信双央企投资） |
| 品类起点 | 大宗商品（详见仓单 3.0 口径） | 油气能源化工（原油、燃料油、汽油、柴油） |
| 资金清算 | 平台自身清算/保购机制（详见仓单 3.0 口径） | 对接上海清算所清算通，实体账户跨行秒到账 |
| 风控核心 | 仓单 3.0 标准化与保购保险机制 | 可信仓库 + 数字孪生账实交叉验证 + "车船库"物流监控 + 订单-物流-资金三方交叉验证 |
| 落地证据（截至 2023） | 仓单 3.0 落地规模待考（见对应 query） | 油气行业首单 1000 吨柴油交割（2023-09，通稿口径） |

## 共同点

- 均试图以平台化仓单 + 资金基础设施替代熟人圈交易与主体信用依赖；
- 均强调仓库/交割库在保障提货权真实性中的深度参与。

## 差异要点与注意

- 66 云链路径的资金清算依托独立金融基础设施（上海清算所），前海路径以平台自身机制为主——这一差异决定其合规属性与可扩展性可能不同；
- 双方落地证据均为 2023 年单点/自述口径，规模化成效均待考证。
