# 应收账款质押与保理对比

| 维度 | 应收账款质押融资 | 保理 |
|------|----------------|------|
| 法律性质 | 物权担保（来源称"物权转让"） | 债权转让 |
| 当时法律基础 | 《物权法》（已被《民法典》取代） | 《合同法》（已被《民法典》取代） |
| 登记要求 | 须在《应收账款质押登记公示系统》登记，避免重复质押 | 转让通知核心企业/债务人 |
| 附加服务 | 单纯融资 | 集应收账款催收、管理、坏账担保及融资于一体 |
| 风险转移 | 无 | 无追索权模式下可转嫁商业信用风险、优化资产负债表 |
| 担保要求 | 应收账款作质押品，随用随支 | 无须传统流动资金贷款的抵质押和其他担保 |

## 来源表述的纠错

来源（2017 科普文）称应收账款质押下"银行拥有对货物物权的处置权"——**此表述不严谨**：应收账款质押的标的是应收账款债权，银行并不因此取得货物物权。该句应视为科普文常见错误，不作为口径引用。
