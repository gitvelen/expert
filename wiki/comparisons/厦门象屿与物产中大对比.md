# 厦门象屿与物产中大对比

依据郑建贤（建原数科，2024）的口径——作者明确表示在CR5中"最推崇物产中大"。

| 维度 | 物产中大 | 厦门象屿 |
|------|----------|----------|
| 期现结合毛利率（2023，作者测算） | 优于象屿 | 1.41%，CR5垫底 |
| ROE vs ROIC | 高ROE系高负债堆出（与浙商中拓同） | 高分红+高负债推高ROE，ROIC显著低于同行 |
| 现金循环周期 | 可比公司中最优：无大额预付款、应收周转合理、不过度占用上下游资金 | CR5可比公司中最长（2023年预付款302亿） |
| 融资成本 | CR5最低（3年期公司债利率最低） | 接近物产中大/建发的近2倍，使用永续信托59.18亿 |
| 固定资产/物流投资 | 领先且完善的物流基础设施 | 2016-2017年后放缓，2023年后加强但额度仍小 |
| 价格风险（存货贬值计提，2023） | 计提绝对额与占比均为CR5最高（货种集中黑色系所致） | 较低 |
| 转型路径 | "供应链集成服务"概念发源地 | 农产品+新能源全产业链（粮食全产业链仍亏损） |

## 说明

- 本对比为单一作者测算口径（证据强度中等偏弱），与象屿官方宣传口径（服务收入占比70%+、物流网络优势）两说并存；
- 与 [[厦门国贸与厦门象屿对比]] 互补，共同构成CR5横向对比视角。
