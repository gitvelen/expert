# 卖好车与车镇模式对比

两家均为 2018 年前后活跃的汽车 B2B 供应链平台，服务对象均为中小车商/车贸商。

| 维度 | 卖好车 | 车镇 |
|---|---|---|
| 创始人 | 李研珠（淘宝 162 号员工、前蘑菇街） | 冯璋 |
| 定位 | 自建仓储物流网络的第三方基础设施提供商 | 车辆供应链金融服务平台（车链云技术体系） |
| 货权控制 | 自有中级仓 100+（2018 自述），逐台定位、富士康级管理标准 | 依托技术平台与外部合作网络管控 |
| 资金来源 | 无银行资质，靠老阿里借款跑数据，后获金融机构授信 | 2018 年获建设银行深圳分行 10 亿授信 |
| 风控特色 | 物流方完全担保协议 + 创始人个人无限连带担保 | 场景风控六要素（见 [[车辆供应链金融场景风控六要素]]） |
| 规模口径 | 2017 年参与服务交易额约 200 亿（自述） | 年交易额破千亿宣称（2018） |
| 风险实质 | 风险集中于平台自身资产负债表（垫资 + 担保） | 待考 |

## 共同的开放问题

两家平台的后续经营存续与供应链金融风险兑现均未定，属同一主题：2018 年汽车 B2B/新车平台供应链金融平台的存活率。分别跟踪于 [[查询-卖好车2018年后经营存续与供应链金融风险暴露]] 与 [[查询-车镇平台2018年后的经营存续与B2B新车平台供应链金融风险兑现]]。

## 证据强度说明

卖好车侧数据为创始人演讲自述（低强度）；车镇侧数据来自媒体报道（中低强度）。对比结论以方向性差异为主，不宜作精确数字比较。
