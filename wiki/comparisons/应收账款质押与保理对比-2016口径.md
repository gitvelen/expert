# 应收账款质押与保理对比（2016口径）

依据来源：[[sources/4-news--7-04-业务基础--4-2016--22-应收账款质押与保理的16大重要区别和联系保理--soee02]]（贸易金融，2016-05-06，转自"保理课堂"）。

## 一、法律层面（11 项）

| 维度 | 应收账款质押 | 应收账款转让（保理） |
|------|------------|-------------------|
| 法律性质 | 担保物权（权利质押），从属法律关系 | 债权让与，本身即融资 |
| 法律依据（2016年口径） | 《物权法》223、228条；《应收账款质押登记办法》 | 《合同法》79–83条；国际保理惯例 |
| 含义范畴 | 支撑贷款、承兑汇票、信用证、保函等融资的从属担保 | 保理以转让为核心，兼具催收、管理、坏账担保、融资 |
| 生效要件 | 信贷征信机构登记时设立 | 通知债务人方对债务人生效 |
| 对债权人一方效力 | 优先受偿权、追及权、别除权等 | 债权主体变更、主从权利随同转移、转让人瑕疵担保 |
| 对债务人效力 | 抗辩效力法律无规定 | 债务人享有抗辩权与抵销权；禁止转让约定有效主义 |
| 运行机制 | 收款余额退还、不足追偿 | 回款风险归受让人 |
| 追索 | 风险分散于出质人与应收账款债务人两方 | 无追索时受让人独担坏账；有追索/回购除外 |
| 收益 | 仅利息 | 贴现差价 + 保理费/管理费/发票处理费；FCI 认为商业结果与担保权益一致 |
| 对应收账款的权利 | 标的价值归出质人，清偿后质权消灭 | 受让人立即取得全部权利，出让人丧失（除非反转让） |
| 适用范围 | 较广（登记办法五类权利） | 一般限于销售/服务债权，排除信用证、现金交易结算 |

### 是否通知债务人（第 11 项）

- 质押：通知是否生效要件有理论争议，但银行实践普遍要求通知并取得确认
- 转让：可隐蔽（暗保理、商业发票贴现），但逾期后通知效力存在争议、当时法律无规定

## 二、企业层面（5 项）

1. 资产负债率：无追索保理降低、改善财务结构；有追索/回购按财会[2003]14号计入负债，与质押相同。银行视角：转让掩盖债务，二次融资加大风险
2. 避税：转让损失可按国家税务总局令2005年13号税前扣除
3. 融资种类：质押可支撑表内表外业务；转让限于表内保理预付款
4. 功能：保理独有管理、催收、坏账担保功能；银行内部账户归集回款防司法查冻扣
5. 质押可配合"财务报表型"融资与 ABL 模式（见 [[concepts/ABL资产支持贷款-2016口径]]）

## 三、联系

1. 出质后经协商可转让（《物权法》228条第2款），亦可协商转让给质权人以抵债
2. 权利冲突优先权：登记/合同时间/通知时间三规则，作者主张登记优先（已登记>未登记，先登记>后登记，均未登记按债权比例）——该开放问题已由《民法典》第768条正面解决，见 [[queries/查询-民法典768条确立登记优先规则对2016年优先权三规则争议的解决]]
3. 共同问题：未来/一揽子应收账款效力、禁止转让约定后果、登记要素描述等

## 张力与延伸

文中一边强调转让与质押"质的差别"，一边承认与有追索权保理"很相似"、FCI 认为经济结果一致——法律形式与商业实质的张力，正是后来融资性贸易"名为贸易实为借贷"司法认定的伏笔之一（参见 [[concepts/融资性贸易与贸易融资二分-2016司法科普口径]]）。

## 时效性说明

本对比框架为 **2016 年口径**。2021 年《民法典》生效后，质押对应第440、445条，债权转让对应第545–550条，且第768条已正面规定保理优先权规则。旧法条引用保留作历史对照。
