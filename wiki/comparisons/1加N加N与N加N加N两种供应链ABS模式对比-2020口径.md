# 1+N+N 担保模式 ABS 与前交所 N+N+N 模式 ABS 对比（2020口径）

两条 2019-2020 年供应链金融 ABS 创新路径，各自解决不同痛点：

| 维度 | [[concepts/1+N+N担保模式ABS-2020口径]]（联易融） | 前交所 "N+N+N" 模式 ABS |
|---|---|---|
| 结构特征 | 围绕单一核心企业的 1+N 结构，引入担保增信 | 每期专项计划含 N 个原始权益人、N 个核心企业、N 种确权方式（商票/确权/电子付款承诺函） |
| 核心创新点 | 担保模式破解核心企业确权难题 | 确权方式多元化 |
| 风险结构 | 集中于单一核心企业 | 风险分散至 N 家核心企业 |
| 门槛 | 依托核心企业信用，门槛较高 | 多家核心企业底层资产搭配发行，降低发行门槛，覆盖更多企业 |
