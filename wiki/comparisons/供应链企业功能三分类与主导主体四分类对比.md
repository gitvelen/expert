# 供应链企业功能三分类与主导主体四分类对比

两种分类框架回答不同问题，撰写报告或设计产品方案时应按用途选用，不可混为一谈。

| 维度 | 功能三分类（2019 科普口径） | 主导主体四分类（2019） |
|------|------------------------------|--------------------------|
| 划分依据 | 企业提供的服务重心与核心竞争力 | 供应链金融生态中的主导方 |
| 分类 | 综合物流企业 / 贸易企业 / 咨询企业 | 银行系 / 核心企业系 / 金融科技系 / 物流仓储系 |
| 回答的问题 | "这家供应链公司靠什么挣钱、做什么事" | "这个供应链金融业务由谁主导、风险结构如何" |
| 典型案例 | [[华贸物流]]、[[怡亚通]]、[[普路通]] | 见 [[供应链金融四主体分类口径2019]] |
| 证据强度 | 一般公众号科普（弱） | 专业公众号口径（中等） |
| 适用场景 | 分析供应链公司的商业模式与盈利来源 | 分析供应链金融产品的主导方与风险分担 |

## 关联

- 两者的"物流"类目有交集：功能三分类中的综合物流企业对应主体四分类中的物流仓储系，可结合 [[物流企业主导型供应链金融模式]] 理解
- 功能三分类的盈利模式三分法中"供应链金融（垫资）"部分直接连接主体四分类下不同主导方的资金与风险结构分析
