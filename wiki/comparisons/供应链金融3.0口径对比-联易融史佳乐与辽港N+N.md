# 供应链金融3.0口径对比：联易融、史佳乐与辽港 N+N

"供应链金融 3.0"在 2019 年前后存在多种互不兼容的口径：

| 口径 | 来源 | 3.0 的含义 |
|------|------|------------|
| 五时代进化论 | [[供应链金融五时代进化论-2019联易融口径]]（联易融宋群/冀坤） | 1.0–5.0 线性演进中的一环，强调去核心化与底层资产透明 |
| 线上化三模式 | [[线上供应链金融平台本质两论与模式演进-2019史佳乐口径]]（史佳乐，《中国银行业》） | 线上供应链金融的平台化演进 |
| "N+N"平台模式 | 辽港电商平台（2019，本来源） | 从 B2B 一对模式向多对多平台化演进，以港口为节点 |

## 分析

- 共同点：均以"平台化、多对多、数据驱动"为 3.0 的方向性特征。
- 差异点：辽港口径最简（N+N 即 3.0），且以物流枢纽而非核心企业为锚；联易融口径最细（五时代）且强调主体信用转资产信用。
- 该口径之辨与既有 [[供应链金融3.0演进口径对比-瑞通SCS-SCM-SCF与奥拓思维三阶段]] 一脉相承，进一步说明"3.0"在 2019 年是营销性叙事而非统一定义。
