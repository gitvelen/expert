# 银行保理与商业保理监管对比

本 wiki 中的保理知识存在**双轨监管格局**：既有针对商业银行的保理规则（银监会体系），也有针对非银行商业保理企业的地方试点办法（商务部门体系）。二者不可混同。

| 维度 | 银行保理 | 商业保理（上海试点） |
|---|---|---|
| 适用对象 | 商业银行 | 非银行商业保理企业 |
| 监管主体 | 银监会 | 商务部门（市/区县商务委牵头，工商、公安、金融、税务等部门协同） |
| 规范文件 | [[商业银行保理业务管理暂行办法]]、[[银监发2013-35号]] | 《上海市商业保理试点暂行管理办法》（2014，有效期至 2016-07-31） |
| 定义/服务范围 | 保理定义与四类服务（[[保理定义与四类服务]]） | 应收账款融资、销售分户账管理、催收、坏账担保等五类（按功能分类） |
| 未来应收账款 | 受限（见 [[未来应收账款保理的监管边界演变]]） | 第三条明确允许"现在或将来的应收账款" |
| 禁止业务 | [[五类禁止保理融资业务]]（对银行） | 吸收存款、放贷/受托放贷、专职讨债、受托投资等（第十三条，对保理企业） |
| 资金管理 | [[保理专户管理]] | 专用存管账户 + 资金管理协议（第二十条） |
| 特有风控 | 银行资本与风险管理体系 | 风险资产 ≤ 净资产 10 倍；季度计提准备金；对股东关联实体担保/融资 ≤ 股东出资额 |
| 追责 | 银行业监管处罚 | 协同监管 + 公安部门处理七类刑事违法情形 |

## 适用范围提示

上海办法第二十八条规定，中国（上海）自由贸易试验区内设立商业保理企业仍按区内有关规定执行，市级办法与自贸区办法并行——引用规则时须先确认适用范围。
