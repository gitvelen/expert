# 苏美达“双链协同”与厦门象屿“供应链服务+生产制造”模式对比

两家头部供应链上市公司均以“贸易/供应链集成服务 + 自持产业环节”对冲纯贸易低利润率，但结构差异显著。

| 维度 | 苏美达（2025H1口径） | 厦门象屿（2025口径） |
|---|---|---|
| 模式命名 | “供应链+产业链”双链协同 | “供应链服务+生产制造”产业链运营 |
| 产业利润主力 | 船舶制造与航运（利润7.5亿元，+98%，占利润总额33%） | 制造化布局更分散（大宗农产品全产业链等） |
| 供应链基座 | 大宗商品运营 + 机电设备进出口 | 大宗商品采购分销与物流 |
| 市场策略 | “审势取势、非美拓展、国内深耕”，对美进出口占比约6.5%，海外自有实业（多国制造） | 规模约2000亿级（2025H1营收2039.5亿），双循环布局 |
| 盈利结构风险 | 利润1/3依赖船舶周期，板块单一化风险突出 | 非经常性损益（减值冲回）占比需核验（见 [[查询-象屿扣非净利与归母净利差异构成核验]]） |
| 净利率量级 | 约1.2%（6.46亿/551亿） | 同为低利润率大宗模式 |

## 结论

两者同构的深层逻辑一致：以自持产业的“物的信用+产业利润”替代纯贸易撮合。差异在于苏美达产业利润高度集中于单一强周期行业（船舶，订单排期至2028年提供短期确定性但放大周期顶部风险），象屿则以更分散的产业链布局对冲。此对比可作为“供应链公司产业链延伸路径”主题下持续跟踪的样本对。
