# 农产品数字仓单与数字债权凭证信用基础对比

## 对比概要

[[农产品数字仓单模式]]与[[数字债权凭证自建平台模式]]同属供应链金融"脱核"方向的创新路径，但信用基础与风控逻辑存在根本差异。

## 维度对比

| 维度 | 农产品数字仓单 | 数字债权凭证 |
|------|--------------|------------|
| **信用基础** | 物的信用（货物/仓单）+ 国有平台信用背书 | 核心企业确权（应付账款） |
| **放贷依据** | 场景中的货物/仓单等实物资产 | 核心企业确认的应付账款 |
| **核心企业角色** | 不承担授信，国有平台作为监管方 | 核心企业确权，承担付款义务 |
| **"脱核"实质** | 从产业核心企业转向国有平台信用背书 | 依赖核心企业确权，实质未脱核 |
| **适用场景** | 农产品/大宗商品等有形动产 | 制造业/商贸等核心企业供应链 |
| **风控核心** | 物联网监管+实物交割+实际控货 | 核心企业信用+贸易背景真实性 |
| **平台定位** | 服务方+监管方+信息撮合方 | 核心企业自建或第三方运营 |
| **标准化前提** | 产地溯源+定品定价+保鲜贮运 | 核心企业ERP/财务系统对接 |
| **风险处置** | 货物处置（贸易商接货）+跌价平仓 | 核心企业到期付款 |
| **融资成本** | 3.8%（彭州口径） | 因核心企业信用等级而异 |

## 共性

1. 均以数字化手段实现信息流转与信用构建
2. 均试图降低对传统主体信用的依赖
3. 均需解决贸易9贸易背景真实性问题

## 关键差异

- **数字仓单**的信用锚定在"物"上，通过物的信用+数据信用+国有平台背书构建信用体系
- **数字债权凭证**的信用锚定在"核心企业确权"上，本质仍是主体信用的延伸
- 数字*数字仓单更适合缺乏强势核心企业但拥有有形动产的农业/大宗商品场景
- 数字债权凭证更适合拥有强势核心企业的制造业/商贸供应链
