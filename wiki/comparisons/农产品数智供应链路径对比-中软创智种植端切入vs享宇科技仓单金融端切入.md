# 农产品数智供应链路径对比-中软创智种植端切入vs享宇科技仓单金融端切入

## 对比维度

| 维度 | 中软创智（种植端切入） | 享宇科技（仓单金融端切入） |
|------|----------------------|--------------------------|
| 切入点 | 种植端（离钱最远但最重要） | 仓储端/金融端（离钱最近） |
| 核心产品 | [[汇柿数智农业系统]] | [[数字仓融通]] |
| 数据架构 | [[种植端四套基础数据-农田农户农事收入交易]]→全链路 | 仓单数据→金融端 |
| 信用基础 | 数据信用（全链路实时采集） | 物的信用+国有平台信用背书 |
| 金融角色 | 不做金融，提供数据供金融机构风控 | 金融端逆向切入产业链 |
| 典型案例 | 观音阁黑糖（产能预售）、香蕉企业 | 彭州蔬菜（电子仓单融资） |
| 平台架构 | [[四位一体平台-交易数据金融监管]] | 国有平台监管方定位 |
| 核心判断 | 数据掌握行业话语权 | 场景资产放贷与脱核不离核 |

## 共同点

- 均涉及农产品+数据+金融的交叉
- 均强调数据对金融风控的支撑作用
- 均关注农产品合规与溯源

## 差异本质

中软创智从产业最底层（种植端）向上构建数据资产，认为源头数据是全链可信性的根基；享宇科技从金融端（仓单）向下切入产业，以物的信用与国有平台背书解决融资问题。两条路径分别代表"数据驱动"与"金融驱动"两种农产品数智化逻辑。
