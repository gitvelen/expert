# 《国务院办公厅关于积极推进供应链创新与应用的指导意见》（国办发〔2017〕84号）

## 状态

现行有效。国务院办公厅 2017 年发布的纲领性文件，将供应链创新与应用上升为国家层面推动事项，是"供应链国家战略化"脉络的纲领文件。

## 印发情况

- 2017-10-13 由国务院办公厅印发，**首次对供应链创新发展做出全面部署**（媒体转述口径，官方原文待另行收录核验）。
- 该文是 2017 年供应链政策升温的标志性文件，河南同日印发《河南省物流业转型发展规划(2018—2020年)》作为地方响应，见 [[2017年84号文与河南物流业转型规划同日印发快照]]。
- 与 [[两部委17城供应链体系建设试点-2017商务部口径]] 同属 2017 年供应链政策落地脉络。

## 本库中的角色

- 是供应链领域人才培养、行业分类、产业政策等一系列后续进展的政策源头：
  - 2017年《国民经济行业分类》修订中"供应链管理服务"成为新行业（见 [[供应链管理服务行业分类-2017国民经济行业分类]]）
  - 2018年起供应链管理本科专业获批、2020年"供应链管理师"入选新职业（见 [[供应链管理本科专业-120604T]]、[[供应链管理师新职业-2020]]）
- 本库尚未录入84号文原文全文，条文要点待补（见 查询-国办发2017-84号文原文要点与后续落地文件）。

> 注：本页仅依据媒体转述（河南商报等）建立占位，84 号文原文要点与后续演进（含 2020 年后的接续政策）待补充官方原文来源后扩充。
