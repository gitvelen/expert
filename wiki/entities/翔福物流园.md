# 翔福物流园（福建翔福智慧物流数据产业园）

翔福物流园原属福建翔福物流股份有限公司，是位于福州市长乐区漳港尚迁路140号的大型综合物流园区，曾被誉为“全省规模最大、设施最完善”的临空临海电商物流园，2013 年启动建设、2016 年一期投运，总投资 18 亿元、占地 615 亩，定位为集国际仓储、跨境电商、保税物流、快件配送于一体的现代化综合物流枢纽。（以上为来源口径。）

## 区位与历史运营

- 紧邻福州长乐国际机场（8 公里）、马尾港与松下港，具备“空海陆”多式联运条件
- 曾集聚京东商城、阿里巴巴、邮政速递、德邦物流、日日顺物流等百余家电商与物流企业

## 兴衰时间线

| 时间 | 事件 |
|---|---|
| 2013 | 启动建设（总投资18亿元，占地615亩） |
| 2016 | 一期投入运营 |
| 2025-01-20 | 福州市中级人民法院 (2025)闽01破申2号裁定受理福建翔福物流股份有限公司破产清算 |
| 2025-09 | 首次上架拍卖，起拍价5.64亿元，流拍 |
| 2025 年内 | 历经三次降价拍卖，均流拍 |
| 2025-12-29 | 第五拍以2.56亿元底价成交，竞得方为 [[福建长乐产投集团]] |

## 衰败归因（媒体归纳）

“圈地—融资—建设—空置”粗放模式的典型缩影：盲目投资与产能过剩、功能同质化、现金流管理薄弱（依赖土地增值与融资输血）、政策红利退坡后抗风险能力不足。

## 拍卖标的构成

土地使用权约 26.55 万㎡（398.28 亩）、45 栋房屋建筑（总建筑面积约 24.81 万㎡）、附属设施、157 项设备及少量车辆，整体评估值约 5.64 亿元。
