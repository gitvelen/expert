# 商务部等8部门《关于复制推广供应链创新与应用试点第一批典型经验做法的通知》（2020）

2020年4月，由商务部、工业和信息化部、生态环境部、农业农村部、人民银行、市场监管总局、银保监会、中国物流与采购联合会八部门联合印发，与"进一步做好供应链创新与应用试点工作"通知相隔两日先后发布。

## 内容结构

在55个试点城市、266家试点企业一年多的试点成效基础上，提炼 **三大主要内容、12类典型经验做法、36个试点主体** 予以全国复制推广：

| 内容方向 | 经验类别数 | 试点主体 |
|---|---|---|
| 政府公共服务和治理新模式 | 5类 | 浙江省、江苏省、上海市、安徽省等15个省市 |
| 提升供应链管理和协同水平：供应链平台建设 | 1类 | 欧冶云商、九州通医药 |
| 提升供应链管理和协同水平：一体化专业化服务 | 1类 | 厦门建发、物产中大、浙商中拓、怡亚通、传化智联、江苏物润船联等8家企业 |
| 供应链与现代信息技术深度融合 | 1类 | 菜鸟供应链、联想集团、中国移动、盒马生鲜 |
| 创新供应链发展新模式 | 1类 | 国家电网、海尔集团、浙江吉利 |
| 积极布局全球供应链 | 1类 | 青岛双星、酷特智能、云南云天化 |
| 推动绿色供应链发展 | 1类 | 苏宁易购、超威电源 |
| 提升供应链金融服务科技水平 | 1类 | 招商银行（唯一金融机构） |

## 意义

《通知》称，借鉴学习和复制推广上述典型经验做法，对促进供应链创新与应用、探索经济新发展方式具有重要意义；是对 [[国办发2017年84号供应链创新与应用指导意见]] 试点落地阶段的关键政策节点。
