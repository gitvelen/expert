# 《商业银行监管评级办法》（2021）

中国银保监会于 2021 年 9 月 10 日印发，自印发之日起施行。适用于开业满一个完整会计年度以上的商业银行和农村合作银行、农村信用社、村镇银行法人机构；其他经银保监会批准设立的银行业金融机构参照执行（开发银行和政策性银行另行规定）。评级周期为一年，年度评级原则上每年 3 月底前完成。

## 九大评级要素及标准权重

| 评级要素 | 标准权重 |
|---|---|
| 资本充足 | 15% |
| 资产质量 | 15% |
| 公司治理与管理质量 | 20% |
| 盈利状况 | 5% |
| 流动性风险 | 15% |
| 市场风险 | 10% |
| 数据治理 | 5% |
| 信息科技风险 | 10% |
| 机构差异化要素 | 5% |

## 评级结果分档标准（第七条）

```
90-100分：1级（95分含以上为1A，90-95为1B）
75-90分：2级（2A：85-90；2B：80-85；2C：75-80）
60-75分：3级（3A：70-75；3B：65-70；3C：60-65）
45-60分：4级（4A：55-60；4B：50-55；4C：45-50）
30-45分：5级；30分以下：6级
```

正处于重组、被接管、实施市场退出等情况的银行直接列为 S 级，不参加当年评级。

## 强制下调调整因素（第八条）

核心监管指标不达标或重大负面因素（党建严重弱化、公司治理严重缺陷、重大涉刑业内案件、财务/数据造假、重大行政处罚或监管强制措施、重大舆情应对严重不当等）→ 3 级及以下；出现信用危机 → 5 级或 6 级；风险化解明显不力 → 不高于最近一次评级结果。

## 关联

评级结果保密与内部使用原则（第二十四条）：不得用于广告、宣传、营销，向境外监管当局提供遵循对等原则。与 [[银保监会205号文]]、[[郭树清]]“金融科技统一监管与资本充足率要求”同属银行业强监管脉络。
