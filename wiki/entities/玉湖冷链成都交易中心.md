# 玉湖冷链（成都）交易中心

玉湖冷链（成都）交易中心是 [[玉湖冷链]] 在成都投资建设的进口冷链食材交易与物流园区，为四川省重点项目（连续4年入选）、成都市"平急两用"公共基础设施项目，也是成都国家骨干冷链物流基地建设的组成部分。

## 项目概况（项目方自述口径，2024）

- 占地 419 亩，库容超 28 万吨
- 投运达产后预计年交易额 600 亿元，其中外贸额 300 亿元
- 预计带动周边产业创造约 7500 个就业岗位
- 计划 2024 年下半年正式投运
- 区位：紧邻成都中欧班列始发站，坐拥亚洲最大集装箱中心站与西部最大铁路枢纽，拟利用中欧、中老、中越方向冷链运输打通进口肉类直达成都的物流与商流通道

## 物流区设施（2024-06-30 首仓开仓）

| 设施 | 参数 |
|------|------|
| D2、D5 首仓（立体高标库） | 总库容约 1.4 万吨，约 20000 个托盘位，温区 −25℃~−18℃；双首层坡道设计，冷藏车直通二楼装卸 |
| 1-8 号冻库 | 双层坡道库，覆盖变温区、恒温区、冷藏区、冷冻区四温区 |
| 10、11 号 | 多层楼库 |
| 9 号 | 加工中心 |
| 配套 | 4 栋宿舍楼 |

投运后冷库接入物联网，配备智慧仓储物流管理系统，全程温控不断链，园区内人、货、车分流。
