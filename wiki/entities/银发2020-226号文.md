# 银发〔2020〕226号文

银发〔2020〕226号，即《关于规范发展供应链金融 支持供应链产业链稳定循环和优化升级的意见》，2020年9月由中国人民银行牵头，联合工业和信息化部、司法部、商务部、国资委、市场监管总局、银保监会、外汇局共八部委印发（一处口径记为9月18日，另一处记为9月22日）。这是我国供应链金融领域首份多部委联合的纲领性/规范性文件，全文共六部分23条。

## 核心定位

- 界定了供应链金融的官方内涵（真实交易背景、物流/资金流/信息流整合、核心企业与上下游一体化风控）。其中**一体化风险评估**要求一体化地评估供应链上核心企业与中小企业的整体风险——在核心企业近年风险频发背景下尤具意义。
- 确立了“规范、发展、创新”并行的政策基调。
- 强调核心企业在供应链金融中的参与度，鼓励其积极确权、参与供金运作；同时防范核心企业滥用市场权力、借扶持中小微名义强行推动供应链金融。这种“既鼓励核心企业参与、又防范其滥用”的双重立场，构成此后政策对核心企业规制口径的基线。
- 首次提出“金融机构、核心企业、仓储及物流企业、科技平台应聚焦主业，立足于各自专业优势和市场定位，加强共享与合作”，确认产业参与者的独特作用（转述口径，待以原文核对）。
- 明确商业文明建设关键在于强化支付纪律和账款确权。
- 提出了配套基础设施建设方向（供应链票据平台、动产和权利担保统一登记公示体系建设）。
- 构建了以[[三信合一风控框架]]（第十八条）为代表的风控方法论，并以“[[强信用强资产强结构强数据]]”多方式结合识别和管理风险。

## 关键条款

| 条款 | 主题 | 核心要求 |
|---|---|---|
| 第（四）（二十一）条 | 支付纪律 | 依据《保障中小企业款项支付条例》，逾期未付信息公示，限制新增债券融资 |
| 第（八）（十三）条 | 供应链票据 | 支持与人民银行认可的[[供应链票据平台]]对接，明确接入标准 |
| 第（十一）条 | 存货仓单融资 | 系统互联互通，核验存货、仓单、订单真实有效性 |
| 第（十四）条 | 统一登记 | [[动产和权利担保统一登记公示]]，接口批量查询登记 |
| 第（十六）条 | 信用约束 | [[商业汇票信息披露制度]]，商票-债券交叉披露 |
| 第（十八）条 | 风控框架 | [[三信合一风控框架]]，全流程线上资金监控 |
| 第（十九）条 | 真实性审核 | 防范虚增/虚构应收账款、重复抵押质押 |
| 第（二十二）条 | 生态约束 | 禁止“占款+关联保理赚息”，应付账款流转不得封闭循环、不得限定融资服务方 |
| 第（二十三）条 | 业务监管 | 保理、小贷、财务公司不得无牌或超范围经营；第三方平台不得变相开展金融业务 |

## 政策谱系与沿革

226号文与 [[155号文供应链金融服务实体经济指导意见2019]] 构成供应链金融监管文件谱系的重要节点，也是本 wiki 监管演进关键问题（226 → 155 → 74 → 金融监管总局时代）的起始政策节点。

- 文中“银保监会”作为责任部门已由[[国家金融监督管理总局]]承继（2023年机构改革）。
- 2023年打击非法金融活动局对商业保理、融资租赁监管制度的收权，是第二十三条的机构性延续。
- 第（二十二）条是“信单类”产品合规边界的源头条款，与[[供应链金服平台与数字权证]]相关讨论直接相关。
- 后续政策演进后，相关规制口径已有更新，引用本页时须标注年份口径。
