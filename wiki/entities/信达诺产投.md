# 厦门信达诺产业投资有限公司（信达诺产投）

2025年12月为承接西安迈科等26家公司破产重整投资而设立的合资公司，是“债权人转重整投资人”路径的执行主体。

## 股权与交易结构（2025年公告口径）

| 项目 | 数据 |
|---|---|
| 注册资本 | 3亿元 |
| 厦门信达 | 出资2.85亿元，持股95%（自有或自筹资金） |
| 西安高科物流发展有限公司 | 出资1500万元，持股5% |
| 承接标的 | 陕西丝路易联供应链有限公司（重整平台）75%股权 |
| 交易对价 | 3亿元：1.5亿元付重整管理人 + 1.5亿元以实缴注册资本方式注入重整平台用于后续经营 |
| 底层资产 | 重整平台100%控股四家项目公司，持有西安多处物流与商业物业，评估值14.56亿元（截至2025-07-31），重整平台净资产约7.42亿元 |

## 风险提示

底层资产尚未完成权属变更登记；交易存在因核心条件无法满足而终止的风险。
