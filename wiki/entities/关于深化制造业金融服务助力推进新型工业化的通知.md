# 《关于深化制造业金融服务 助力推进新型工业化的通知》

- **发文机关**：[[国家金融监督管理总局]]、工业和信息化部、国家发展改革委（三部门联合）
- **落款日期**：2024年4月3日；公开发布：2024年4月16日
- **发文对象**：金融监管总局各监管局，各地工业和信息化主管部门、发展改革委，各政策性银行、大型银行、股份制银行、外资银行、直销银行、金融资产管理公司、金融资产投资公司、理财公司，各保险集团（控股）公司、保险公司、保险资产管理公司
- **性质**：监管导向文件，不设罚则、无量化指标

## 条款结构（十七条）

| 部分 | 条款 | 主题 |
|---|---|---|
| 一、总体要求 | 第一、二条 | 指导思想、工作要求 |
| 二、重点任务 | 第三至六条 | 产业链供应链安全稳定、科技创新、结构优化升级、智能化绿色化 |
| 三、优化金融供给 | 第七至九条 | 信贷结构、产品供给、服务对接 |
| 四、完善服务体系 | 第十至十三条 | 多层次体系、服务机制、激励约束、专业水平 |
| 五、风险防控 | 第十四、十五条 | 风险防控能力、市场秩序 |
| 六、组织保障 | 第十六、十七条 | 金融监管、协作联动 |

## 关键条款

- **第三条**（本wiki核心）：规范发展供应链金融，强化对核心企业的融资服务，通过应收账款、票据、仓单和订单融资促进上下游协同；银团贷款、联合授信支持重点产业链。详见[[供应链金融四工具-应收账款票据仓单订单融资]]。
- **第九条**：开展"一链一策一批"中小微企业融资促进，见[[一链一策一批中小微企业融资促进]]。
- **第十一条**：质量融资增信，见[[质量融资增信]]。
- **第十二条**：尽职免责、"敢贷""愿贷"机制。
- **第十四条**：严防票据贴现虚增贷款规模，加强信贷资金流向监控。

## 与其他政策的关系

属"监管条款中的供应链金融"谱系，与[[银保监会支持山东新旧动能转换实施意见11号文]]（山东动产质押）、[[中国银保监会办公厅2023年乡村振兴重点工作通知]]（农业供应链金融）同系列。其"规范发展"导向与[[74号文十不准]]的禁止性约束构成"促发展与防风险"两端。
