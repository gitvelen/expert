# 《关于金融支持浙江高质量发展建设共同富裕示范区的意见》（"金融31条"）

## 基本信息

- 联合发文单位：中国人民银行（[[央行]]）、[[银保监会]]、[[证监会]]、国家外汇管理局、浙江省人民政府
- 印发日期：2022-03-10；公布日期：2022-03-18
- 性质：区域综合金融改革的国家级政策，将金融支持共同富裕的改革试点任务优先赋予浙江

## 31条结构摘要

| 部分 | 条款 | 要点 |
|---|---|---|
| 一、总体要求 | 1–4 | 服务实体经济、金融为民、金融向善、防范系统性金融风险 |
| 二、优化金融资源配置 | 5–8 | 科创金融（科技支行，杭州/嘉兴定位）、**先进制造业供应链金融（第6条）**、资本市场服务、数字化金融运行体系 |
| 三、跨境金融服务 | 9–11 | 贸易新业态、QFLP/QDLP、本外币一体化资金池、汇率避险 |
| 四、小微金融 | 12–14 | "贷款码"、"三张清单"、低收入群体增收、财富管理 |
| 五、农村金融 | 15–18 | **农业供应链金融（第15条）**、涉农保险、山区26县"一县一策"、农村信用社改革 |
| 六、公共服务均等化 | 19–22 | 保障性租赁住房金融、保险保障、移动支付与数字人民币试点 |
| 七、绿色金融 | 23–24 | ESG 披露、绿色债券、碳账户转型金融（衢州）、环境权益抵质押 |
| 八、风险防控 | 25–27 | 全链条监管、反垄断、防资本无序扩张、金融消费权益保护 |
| 九、保障措施 | 28–31 | 党建、工作保障、重大改革先行试点机制、金融支持共同富裕评价体系 |

## 与供应链金融的关联

- 第6条：制造业方向供应链金融（结算、融资、财务管理综合解决方案 + 期货风险管理服务）。
- 第15条：农业方向供应链金融（核心企业 + 利益联结 + 小农户融资可得性）。
- 与 [[央企供应链金融新业态政策背书]] 共同构成"国资委 + 央行系"的多部门政策背书脉络。

## 备注

本文件为方向性意见，供应链金融相关条款暂无量化指标与执行细则；评价体系（第31条）正式文本是否发布待跟踪（见 [[查询-浙江金融31条中供应链金融条款落地情况]]）。
