# 百望云（百望股份 / 百望股份有限公司 BAIWANG CO., LTD.）

中国企业数字化解决方案提供商，通过"百望云平台"提供 SaaS 财税数字化及数据驱动的智能解决方案。2015年4月由 [[陈杰]] 与其兄弟陈琳合伙创办，主营业务为电子发票及财税服务。截至2023年9月30日，累计处理约127亿份交易凭证，对应交易总额约569.1万亿元人民币。旗下发票融资平台为 [[小望金科]]。

## 概况（2020年企业口径）

创始人兼CEO为 [[陈杰]]，首席战略官为杨正道（2020年口径）。2020年7月28日第四次上榜长城战略咨询"中国独角兽"榜单，并称是企业服务领域唯一"前沿科技独角兽"。2017、2018年两次被科技部火炬计划评为中国税控行业唯一独角兽企业（估值11.2亿美元）。

## 业务布局（2020年企业口径）

- 形成"**采购、结算、发票、财税、金科**"五大云平台，贯穿"云+端+数据"服务。
- 宣称累计服务 2000+ 集团型企业、600000+ 成长型企业客户。
- 快递物流行业客户覆盖近万家企业供应链条，宣称形成"陆路运输行业级商业社交网络"；计划覆盖15大行业26个细分领域。
- 2020年7月发布核心产品 [[百望云脑]]，主张以"商业社交"切入数字经济，实践 P2P（Procure-to-Pay）全流程数字商业平台，末端环节为"支付融资"——这是其供应链金融叙事的落点。

## 供应链金融能力（2020年媒体/厂商口径）

- 以发票大数据为核心资源，切入企业管理数字化：以专票电子化为契机，提供电子印章签约、供应商结算协同、发票开具与管理，协同 SRM/ERP/财务软件，接入物流、生产监控、库存、经销数据，实现供应链全场景信息流转。
- 数据可采信性机制：发票数据确认交易真实性 → 业务信息反向溯源 → 区块链上链 → 发票二次证实。
- 风控方法论：[[经营风控加场景风控双核风控模型-2020百望云口径]]。
- 业务主张：[[非信用传导型供应链金融-2020百望云口径]]、[[点状供应链金融元年论-2020陈杰口径]]。

> [!注意]
> 上述供应链金融能力与"独创"表述均为厂商自述（2020 年媒体报道口径），未经第三方验证。

## 业务结构（2024年招股书口径）

三大收入来源：财税数字化解决方案、数据驱动的智能解决方案、本地部署财税数字化解决方案。数据驱动的智能解决方案含数字精准营销服务（助贷导流）与智能风控服务（依托发票及财务数据为持牌金融机构提供小微企业经营报告、用户分析、风险分析）。2023年前三季助贷等业务收入占比达57.2%，媒体据此质疑其"实质是助贷机构"（观点性定性，见 [[查询-百望云港股IPO结果与业务本质监管定性]]）。

## 股权与融资

- 创始人陈杰持股27.1%，控制43.22%投票权（招股书口径）。
- 2020年口径：此前累计融资超10亿元人民币，投资方包括复星、阿里巴巴、深创投、东方富海、国家中小企业发展基金、朴素资本；2020年7月前后获红塔证券旗下红正均方投资有限公司、大湾区共同家园投资有限公司战略投资。
- 2024年招股书口径：2015年以来累计融资约13.11亿元，股东包括阿里巴巴、复星国际、深创投、大众公用等。
- 提交招股书时总股本约2.17亿股，按最后一轮融资价格计，IPO前估值约61亿元。

## 财务与业务数据（招股书口径，2020–2023Q3）

- 营业收入：2.91 / 4.54 / 5.26 / 4.68 亿元；净亏损：3.89 / 4.48 / 1.56 / 2.13 亿元，四年累计超12亿元。
- 毛利率由截至2022年9月末九个月的41.4%降至截至2023年9月30日止九个月的29.1%。
- 截至2023年9月末持有现金及现金等价物2.11亿元；经营活动所用现金净额8010万 / 1400万 / 6430万 / 1.28亿元。
- 营销代理数量：172 / 299 / 511 / 516名；服务金融机构客户：68 / 91 / 101 / 88名（2023年前三季户均收益305万元）。
- 已交付企业经营报告涵盖约223万家企业；数字化精准营销服务促成贷款约356亿元。
- 市场地位（弗若斯特沙利文，2022）：中国云端财税相关交易数字化市场第一（份额6.6%）；面向小微企业融资的交易相关大数据市场第二（份额5.9%）。2022年完成约7亿次发票处理请求、开具约17亿张增值税发票。

## 客户与发展节点

- 2016年拿下淘宝（协助建立阿里发票平台），此后为中国移动、工商银行、万达集团、滴滴出行、美团等提供定制化涉税解决方案。
- 行业政策背景：2015年国家税务总局《"互联网+税务"行动计划》推动电子税务局建设；2021年全国统一电子发票服务平台与"数电票"试点开启第二轮政策窗口。
- 同业可比：金蝶、畅捷通、慧算账（2021年获D轮8000万美元融资）。
