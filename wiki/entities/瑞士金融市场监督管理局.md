# 瑞士金融市场监督管理局（FINMA）

瑞士金融市场监督管理局（简称"瑞士金管局"，FINMA）是瑞士金融市场的联邦监管机构，负责对金融机构授权与监督。

## 在 API 骗局中的作用

2015-01-16，FINMA 就阿尔卑斯资产管理信托公司和 [[api卓越瑞士信托公司]] 提供的信息发出**公开警告**，声明这两家公司均未获得 FINMA 执照，其行为可能构成违法提供服务。该声明与国内投资者获得的"受瑞士金融市场监督机构授权和监管"宣传完全相反，成为戳穿"伪监管背书"的关键证据。

FINMA 发言人文森特（Vincent）就此事接受了央视记者采访。

## 启示

境外监管机构的公开警告名单（public warning）是核验"境外持牌机构"宣传真伪的直接渠道；本案中投资者若在投入前查询 FINMA 警告，即可识别骗局。参见 [[境外外汇传销骗局]]。
