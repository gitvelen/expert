# Dowsure豆沙包

Dowsure 豆沙包是一家跨境电商金融云服务商（金融科技公司），定位为"连接跨境电商卖家与银行的桥梁"，深耕跨境领域多年。核心产品为 **XFCloud 跨境电商金融云**（2022 年企业自述口径），向银行等金融机构提供一站式跨境电商供应链数字科技赋能。以下信息主要来自 2022 年万联网通稿（公司自述口径），未经第三方验证。

## 产品结构（企业自述口径，2022）

- **SaaS**：一站式整合服务——卖家授权店铺数据 → 店铺经营数据风控模型（店铺评估与风险识别 + 全流程资金管控）→ 信贷产品设计/申请/授信/风控全生命周期管理。
- **API**：插件式提供流量API、数据API、双锁API，无缝集成银行产品流程；覆盖创新金融产品设计、店铺经营模型评估、账户双锁、获客全流程云服务。
- 与 Amazon、eBay、Shopee 等电商平台深度合作，以 API 与隐私计算联合建模方式将平台店铺数据转化为企业信用资产。

详见 [[跨境电商店铺数据风控与账户双锁模式-Dowsure2022口径]]。

## 商业模式（企业自述口径，2022）

- 收入来源：按 API 调用次数收取技术服务费 + SaaS 订阅费。
- 宣称金融云最早与中银、浦发共建，超十几家合作金融机构使用；累计服务数万商户、覆盖跨境电商 GMV 数百亿（自报，待考证）。

## 生态合作方（企业自述口径，2022）

- 电商平台：Amazon、eBay、Shopee（称"深度合作"）
- 支付公司：连连、万里汇（WorldFirst）、Skyee、PingPong、艾贝盈等

## 银行合作落贷产品（企业自述口径，2022）

- 浦发银行"跨商贷"：5 分钟申请、2 分钟审核、0 秒放款（"520"模式）。
- 建设银行"豆方贷"：最高 1000 万元，FBA 库存可计额度（最高月回款 3 倍）。
- 蚂蚁银行"美金贷"：最高 150 万美元纯信用贷。

## 平台合作资质（自报，待考证）

宣称是亚马逊在中国重要的"贷款合作计划"合作伙伴之一，并称该计划全球仅 4 家公司有类似资质。

## 未来方向（2022 年演讲口径）

- 拓展海外市场与更多 API 对接。
- 将数字资产应用延伸至物流、采购、广告等服务商场景，结合数字资产与传统供应链金融逻辑打造更低风险、更低利率、更大额度的产品。

## 证据与存疑

- 2022-08 万联网通稿（来源：豆沙包）称"赋能多家银行"切入万亿级跨境市场，但通稿全文零案例、零合作银行名称，落地情况待考证（见 [[查询-Dowsure合作银行落地案例与业务存续考证]]）。
- 背景对照：2021 年亚马逊封号潮后，"店铺数据贷"类产品的实际坏账与存续表现存疑。
- "最早与中银、浦发共建""超十几家合作金融机构""全球仅 4 家公司有类似资质"等均为公司自报数据，未经第三方验证。
