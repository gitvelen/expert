# 数字仓融通（彭州农产品电子仓单融资系统）

"数字仓融通"是四川省彭州市于 2022 年 3 月上线的农产品电子仓单动产融资服务系统，全称为"远程智能监控 + 农产品电子仓单"金融服务系统。由人民银行牵头搭建、[[四川享宇科技有限公司]]承建，依托全国动产和权利担保统一登记系统，联合 [[中仓登数据服务有限公司]] 构建。核心定位是以货物为质押物生成仓单、凭仓单向银行融资，整合数据流、资金流、货物流，服务县域蔬菜等农产品经营主体的仓单质押融资需求。

## 平台架构

### 组织角色

| 角色 | 主体 |
|------|------|
| 牵头方 | 人民银行 |
| 承建方 | [[四川享宇科技有限公司]] |
| 信用背书 | 国有平台公司（监管方、服务方、信息撮合方，不承担担保/兜底） |
| 登记确权合作 | [[中仓登]] + 人行中登网抵质押登记 |

### 技术架构

- **物联网远程智能监控**：覆盖所有准入冻库，并与"农贷通"平台深度嵌合，将分散冻库集中在同一平台管理，向银行和保险公司提供质押物出入库数据与实时监控。
- **RPA 电子仓单系统**：基于机器人流程自动化，实现评估、保险、仓储等环节无缝衔接、同步操作。
- **区块链上链**：货主信息、货单信息、质押信息、风险信息等上链，保障仓单不可篡改、可溯源，以数据增信支撑金融服务。
- **AI 计算**：作为技术底座的组成部分，配合物联网监管运行。

### 风控机制

- 线下实物交割 + 实际控货
- 全流程证据链存证
- 跌价平仓缓冲周期

## 登记机制

辖内银行将新增及存量未结清农产品仓单在统一登记系统登记，"实现实质意义上的质押"，逐步减少对风险基金的依赖。登记确权与 [[中仓登]] 对接，并在人行中登网完成抵质押登记。

## 运营数据

### 彭州落地数据（2025 年口径）

| 指标 | 数值 |
|------|------|
| 上线时间 | 2022 年 3 月 |
| 参与银行机构数 | 5 家 |
| 质押品类 | 从单一大蒜 → 10 余种耐储农产品及中药材 |
| 蔬菜类单户资金需求 | 300–500 万元 |
| 川芎品类户均融资额 | 超千万元 |
| 融资成本 | 从民间借贷 12% 降至 3.8% |

### 业务成效（截至 2023 年末，报道转述口径）

- 贷款申请周期从 72 小时缩短至 3 小时；质押品类从大蒜扩展至 10 余种耐储存农产品及中药材。
- 累计办理 111 笔，放贷 1.2 亿元，撬动社会资金约 7 亿元，受益农户 2 万余户。详见 [[彭州数字仓融通业务规模快照-2023年末口径]]。

## 局限与下一步

报道明确坦承：在货权风险方面"未进行突破和创新"，实施主体、风险防控、标准化程度不足，跨区域复制推广难。彭州金融监管支局副局长胡九雄表示下一步将完善全流程货权管理机制、建立[[双层物权登记机制-央行统一登记加行业物权登记公示-2024彭州口径|央行统一担保物权登记 + 行业基础资产物权登记公示机制]]，并建立标准与运营服务体系。后续演变跟踪见 [[查询-彭州数字仓融通模式后续复制推广与规模演变考证]]。

## 关键缺失数据

- 累计放贷总额（2025 年口径下未披露）
- 不良率
- 单笔平均融资额
- "3.8% 融资成本"的构成拆解（是否含平台服务费）
