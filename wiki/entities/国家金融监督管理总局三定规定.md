# 《国家金融监督管理总局职能配置、内设机构和人员编制规定》（"三定"方案）

## 基本信息

- **发布方**：中央机构编制委员会办公室（中国机构编制网，2023-11-10 公开）
- **施行日期**：2023年10月29日
- **法律依据**：《党和国家机构改革方案》《国务院机构改革方案》《中国共产党机构编制工作条例》
- **性质**：确定国家金融监督管理总局职责权限、人员配备和工作运行的基本依据

## 核心内容

| 项目 | 内容 |
|---|---|
| 机构性质 | 国务院直属机构，正部级 |
| 组建基础 | 中国银行保险监督管理委员会 |
| 划入职责 | 人民银行金融控股公司日常监管与金融消费者保护职责；证监会投资者保护职责 |
| 内设机构 | 27个正司局级机构 + 机关党委 |
| 行政编制 | 910名；局长1名、副局长4名；司局级领导职数114名 |
| 直属机构 | 稽查总队（正司级） |
| 派出机构 | 垂直管理 |

## 要点

1. 主要职责共15项，涵盖除证券业外的金融业统一监管、[[金融消费者权益保护统筹]]、打击非法金融活动、[[行政执法与刑事司法衔接机制]] 等。
2. 职能转变强调"既管合法又管非法"、强化中央和地方监管协同、消除监管空白和盲区。
3. 第九条（二十）明确"打击非法金融活动局"拟订小贷、融担、典当、融资租赁、商业保理、地方AMC等[[地方金融组织监管制度上收|地方金融组织监管制度]]。
4. 第七条细化与人民银行、证监会、外汇局、行业主管部门、地方政府的职责分工；地方政府承担辖内非法集资防范处置属地责任。
