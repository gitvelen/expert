# 《立足数字经济新赛道推动数据要素产业创新发展行动方案（2023-2025年）》

《立足数字经济新赛道推动数据要素产业创新发展行动方案（2023-2025年）》是上海市人民政府办公厅于 2023 年 8 月印发的省级数据要素产业专项行动方案，目标是将上海建设成具有国际影响力的数据要素配置枢纽节点和数据要素产业创新高地。（以上为来源所述；文件效力与全文条款以上海市政府办公厅原文为准。）

## 目标体系（2025 年，目标值）

| 指标 | 目标值 |
|---|---|
| 上海数据产业规模 | 5000 亿元（CAGR 15%） |
| 数商企业 | 引育 1000 家 |
| 高质量数据集 | 1000 个 |
| 品牌数据产品 | 1000 个 |
| 品牌数据企业 | 500 家 |
| 国家级大数据产业示范标杆 | 20 个 |
| 上海数据交易所挂牌产品 | 5000 个 |
| 数据交易所服务供需主体 | 10 万家 |
| 临港新片区数据要素型龙头企业 | 100 家 |
| 临港相关产业规模 | 突破 1000 亿元 |

## 主要措施（七方面、23 条，要点）

1. **提升 [[上海数据交易所]] 能级**：打造国家级数据交易所，建立“上海数”市场发展指数；多板块运营（国际板推动海外数据在沪交易）。
2. **数据资产化评估试点**：以数交所场内交易为纽带的数据资产评估机制，金融、通信、能源领域试点；数据要素国民经济统计核算制度率先在浦东试点。
3. **数据产品新供给**：技术端聚焦行业知识图谱发现、新型语义网络构建、大模型训练；产品端构建面向大模型的高质量语料库。
4. **发展数商新业态**：见 [[数商三类分类-2023口径]]。
5. **数字资产板块**：支持数交所设立数字资产板块，研究结合实体经济的数字资产上市发行和流通交易机制，配套 [[四不五可六类数字资产上市标准-2022口径]]。
6. **空间布局**：张江国家级数据要素产业集聚区；临港新片区国际数据港先导区、数字贸易国际枢纽港临港示范区，探索增值电信业务外资股比放开与数据跨境制度创新。

## 与上位政策的关系

本方案是 [[关于构建数据基础制度更好发挥数据要素作用的意见]]（“数据二十条”，2022-12）在上海的地方实施蓝图，为“数据资产入表与数据要素市场化”提供省级政策落地细节（见 [[数据资产入表与数据要素市场化-2023口径]]）。

## 引用注意

方案中产业规模、挂牌数等均为**政策宣示性目标**而非实绩；对照上海数交所 2022 年交易额仅 1 亿元、挂牌 800 个产品的基数，引用时须标注“目标值”。
