# 京东金融供应链产品体系（六产品）

京东基于电商平台交易流水与记录建立的综合供应链金融服务体系，是B2C电商主导供应链金融模式的代表。以下为2019年来源的转述口径，产品现状需另行考证。

## 六产品（2019年来源口径）

| 产品 | 融资模式 | 要点 |
|---|---|---|
| 京小贷 | 订单融资+信用贷款 | 根据商家平台经营情况信用评级，提供授信额度 |
| 易贷 | 定向采购融资 | 面向品牌方下游经销商，依据历史采购/销售财务数据 |
| 动产融资 | 融通仓模式下的动产质押 | 数据+模型自动评估商品价值，与仓储公司合作交叉验证全链条数据，实时监测调整质押物数量，实现[[动态质押-2019京东口径]] |
| 京东快银 | 信用融资 | 基于平台商户销售、税务数据 |
| 企业金采 | 赊购/账期管理 | 白名单商户"先采购、后付款"信用支付 |
| 京保贝 | 应收账款融资+预付账款订单融资 | 依据商家采购/销售财务数据及历史应收账款融资数据确定额度 |

其中动产融资的动态质押做法是货权管控主题的重要样本，详见 [[动态质押-2019京东口径]]。
