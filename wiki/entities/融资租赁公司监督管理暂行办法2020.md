# 《融资租赁公司监督管理暂行办法》（银保监发〔2020〕22号）

银保监会2020年6月印发的融资租赁行业全国性监管办法，共六章五十五条，适用于从事融资租赁业务的有限责任公司或股份有限公司（不含金融租赁公司）。业内称为"最严"监管办法。作为各地方金融监管局开展融资租赁行业清理规范、认定与处置"空壳""失联"企业的制度依据，2021年起各地陆续依据22号文开展存量清理。

## 主要监管指标（第三章，详见 [[融资租赁审慎监管指标-2020办法]]）

| 指标 | 要求 |
|---|---|
| 租赁资产比重 | ≥总资产60% |
| 风险资产总额 | ≤净资产8倍 |
| 固定收益类证券投资 | ≤净资产20% |
| 单一客户融资集中度 | ≤净资产30% |
| 单一集团客户融资集中度 | ≤净资产50% |
| 单一客户关联度 | ≤净资产30% |
| 全部关联度 | ≤净资产50% |
| 单一股东关联度 | ≤该股东出资额 |

银保监会可根据监管需要对指标作出调整（第29条）。

## 禁止业务（第8条）

1. 非法集资、吸收或变相吸收存款
2. 发放或受托发放贷款
3. 与其他融资租赁公司拆借或变相拆借资金
4. 通过网络借贷信息中介机构、私募投资基金融资或转让资产
5. 法律法规、银保监会和省级地方金融监管部门禁止的其他业务或活动

## 租赁物规则（第7条等）

租赁物为固定资产（另有规定的除外），须权属清晰、真实存在且能够产生收益；不得接受已设置抵押、权属存在争议、已被司法机关查封扣押或所有权存在瑕疵的财产作为租赁物。售后回租不得低值高买。

## 分类处置与"失联""空壳"定义

三类分类处置（正常经营/非正常经营/违法违规经营）。"失联"与"空壳"各四条量化认定标准，详见 [[融资租赁行业减量增质]]；第四十五条的具体条文条件见 [[融资租赁空壳失联企业认定标准]]。

## 监管职责分工

- 银保监会：制定业务经营和监督管理规则。
- 省级人民政府/地方金融监管部门：实施细则、日常监管、风险处置；建立非现场监管、现场检查、监管谈话制度；每年4月30日前向银保监会报送年度监管情况；与市场监管部门建立会商机制严控登记注册。

## 过渡期安排

- 第52条：存量公司应在省级规定过渡期内达标，原则上不超过三年；省级可根据特定行业实际情况适当延长。
- 第51条：省级可对租赁物范围、特定行业的集中度和关联度要求适当调整，报银保监会备案。

## 落地执行

2021年起，各地依据22号文开展存量清理。例如，深圳市地方金融监管局于2021年11月公示疑似"空壳"融资租赁企业732家、疑似"失联"1198家（见 [[4-news--7-01-政策合规--4-2021--34-深圳市地方金融监管局公示关于疑似空壳失联融资租赁公司的企业名录-趋势--1tx1sk9]]）。

## 与征求意见稿的差异

过渡期由明确截止日（2021-12-31）改为"原则上不超过三年+省级可延长"；第8条"集资"改为"非法集资"；第9条增加"另有约定的除外"。
