# 浦发银行

上海浦东发展银行（SPDB，简称浦发银行），总部位于上海的全国性股份制商业银行。截至 2023 年初，党委书记、董事长为 [[郑杨]]。（主体身份为可独立核验的公开背景；本条目业务内容依据所引来源的公司披露。）

## 数字化与开放银行

### API Bank 无界开放银行（2020 年口径）

在 2020 年的商业银行智慧转型研究中，浦发银行是国内**开放银行**的关键样本：

- 推出 **API Bank 无界开放银行**，突破物理网点与手机 APP 的局限，聚合优势线上金融产品和服务。
- 基于人性化服务路径模式打造虚拟“**数字人**”服务（基于 HUI），为金融服务注入新活力。

见 [[开放银行O-banking-2020口径]]、[[商业银行智慧转型五大路径-2020交银口径]]。

### 全场景 API 金融模式（2022 年 6 月）

据 2022 年 6 月报道，浦发银行致力于打通信息渠道、全链路对接核心及上下游企业，建立稳定的产业链供应链生态圈。具体做法：基于 API 媒介切入全场景金融模式，形成数十个标准接口，将银行服务“无感嵌入”政府平台、产业互联网、供应链平台、电商平台、核心企业等场景。

## 与供应链金融的关联（2021 政策语境）

在 2021-09 [[人行上海总部供应链金融指导意见2021]] 报道中，浦发银行人士表示：存货质押融资市场潜力巨大，但受大宗商品行业市场风险影响，银行业对缺乏“背书”的动产安全性与质押有效性担忧日益增加；《指导意见》的科技核验条款为动产融资创新发展提供政策支持。

> [!note] 相关表态属利益相关方观点，引用时需与官方定性区分。

其汽车场景实践项目 [[浦发车盟]] 是该行动产融资能力的代表案例。

## 与供应链金融的关联（2023 上海两会语境）

在 2023 年上海两会语境下，[[郑杨]] 以浦发银行董事长身份提出供应链金融顺周期特征会放大供应链的不稳定性，并建议依托“链主”企业加大金融服务供给；浦发银行自身是否推出对应供应链金融产品/举措，见 [[查询-郑杨链主链式服务模式与中小企业信用评价体系后续落地考证]]。
