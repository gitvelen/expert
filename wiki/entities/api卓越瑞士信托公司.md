# API卓越瑞士信托公司

API 卓越瑞士信托公司（及关联的"阿尔卑斯资产管理信托公司"）是一家自称总部位于瑞士日内瓦的"跨国资产管理公司/外汇经纪商"，2013 年前后通过微信社交网络在中国境内发展个人外汇投资者。

## 运作方式

- 以"云端智能交易系统"自动交易为卖点，宣称月均 5% 收益（年化 60%）。
- 开户、账号密码均通过微信群传递，投资者不接触公司负责人。
- 提供层级返佣计算表，发展下线每层有提成，宣称月收入可达百万美元以上，呈金字塔式扩张；部分投资者"自挂下线账户自赚佣金"。
- 资金直接打入对方提供的个人账户，而非受监管的第三方资金账户。

## 2015 年 1 月"黑客攻击"事件

2015-01-07 零点，公司宣布遭"黑客攻击"，投资者账户变负数（如北京王先生一万美元涨至一万三后瞬间变为负三千五）。公司自称损失 32 亿美元，但报道转述的投资者投入总额约为 12 亿美元，两组数字矛盾。公司未提供攻击证据、盈利报表，无高层露面；日内瓦总部办公室在开业典礼后即无人。

## 监管与司法状态

- 2015-01-16，[[瑞士金融市场监督管理局]] 发布公开警告：API 卓越瑞士信托公司与阿尔卑斯资产管理信托公司均未获得执照，可能违法提供服务。
- 银监会消费者保护局局长邓智毅指出国内未批准任何境外公司来华做外汇投资。
- 工行交易员唐皓阳判断其为"打着境外机构幌子非法吸收资金的地下外汇交易平台"。
- 国内警方已立案，瑞士已进入司法程序（2015-03 报道时点），后续结局见 [[api瑞士外汇骗局司法结局]]。
