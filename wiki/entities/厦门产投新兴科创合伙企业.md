# 厦门产投新兴科创合伙企业

厦门产投新兴科创合伙企业是一家于 2025 年 12 月 3 日在厦门成立的有限合伙制科创投资平台，出资额 68.6 亿元，由厦门建发、国贸、象屿三大世界500强供应链集团旗下投资公司联手厦门市、区两级国资平台共同出资设立（以上信息为媒体引企查查口径）。

## 基本信息

- 成立时间：2025-12-03
- 出资额：68.6 亿元
- 经营范围：科技推广和应用服务、以自有资金从事投资活动、资产管理服务、信息咨询；**不涉及金融牌照类业务**
- 执行事务合伙人：厦门产投新圆科技投资有限公司（委派代表谢洁平，任法定代表人）

## 合伙人结构（8 名，企查查口径）

| 合伙人 | 关联方 |
|---|---|
| 厦门建发新兴产业股权投资有限责任公司 | 建发集团旗下 |
| 厦门海翼集团有限公司 | 国贸控股旗下 |
| 厦门象屿创业投资管理有限公司 | 象屿集团旗下 |
| 厦门市产业投资有限公司 | 金圆集团控股 |
| 厦门市湖里区产业投资有限公司 | 区级平台 |
| 厦门市思明区产业投资有限公司 | 区级平台 |
| 厦门火炬产业股权投资管理有限公司 | 区级/园区平台 |
| 厦门产投新圆科技投资有限公司 | 执行事务合伙人（GP） |
