# 国信证券-逸锟保理供应链金融资产支持专项计划

“国信证券-逸锟保理供应链金融资产支持专项计划”是 2017 年 10 月 18 日经交易所审批通过的供应链金融（反向保理）ABS 产品，以新城控股为共同债务人/核心企业，是反向保理 ABS 的标杆案例。

## 项目要素（文章口径）

| 要素 | 内容 |
|---|---|
| 审批通过 | 2017-10-18 |
| 储架额度 | 20 亿元，计划分三期发行 |
| 第一期 | 6.37 亿元，2017-11-29 发行 |
| 第二期 | 5.51 亿元，2018-2-5 发行 |
| 计划管理人 | 国信证券 |
| 原始权益人/资产服务机构 | 逸锟保理 |
| 核心企业（共同债务人） | 新城控股（AAA，中诚信） |
| 登记结算 | 中证登深圳分公司 |

## 基础资产池概况（文章口径）

| 指标 | 数值 |
|---|---|
| 应收账款余额 | 6.97 亿元 |
| 合同笔数 | 230 笔 |
| 融资人 / 债务人 | 143 个 / 53 个 |
| 剩余期限 | 均为 547 天 |
| 资产类型 | 工程类 204 笔占 92.61%；采购类 26 笔占 7.39% |
| 债务人分布 | 浙江、江苏、安徽等 13 个省份 |

## 增信安排

1. 优先级/次级分层：次级档占比 5.02%，由原始权益人全部认购并持有到期；
2. 新城控股出具《付款确认书》加入债务为共同债务人；
3. 不合格基础资产赎回；
4. 提前清偿条款（下属公司或新城控股触发时提前清偿价款）。

> 5.02% 次级自留在此为**增信目的**，与出表判定中的自留比例口径不同，参见 [[queries/查询-出表次级自留比例5%与10%口径差异及会计准则本源考证]]。
