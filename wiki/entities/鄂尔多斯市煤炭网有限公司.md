# 鄂尔多斯市煤炭网有限公司

## 基本信息（2020 年企业自述口径）

- 成立时间：2015年9月（但同一来源商业模式部分又称"鄂尔多斯市煤炭交易中心有限公司成立于2014年"，主体口径混乱，见 [[查询-鄂尔多斯煤炭网与煤炭交易中心主体关系及国资持股结构]]）
- 性质：国有企业与民营企业共同组建的混合所有制平台企业
- 定位：智慧煤炭物流大数据平台，运营 www.ocoal.com（鄂尔多斯地区煤炭价格发布窗口）

## 发展历程

| 年份 | 事件 |
|------|------|
| 2015.9 | 公司成立 |
| 2016 | 研发智慧煤炭物流服务平台，获著作权专利 |
| 2017 | 成为内蒙古自治区煤炭物流工业互联网试点企业 |
| 2018.4 | 与 [[鄂尔多斯市东胜区绿动能源投资有限公司]] 达成煤炭物流结算试点战略合作 |
| 2018.7 | 东胜区煤炭大数据平台启动暨煤炭运销结算中心揭牌 |
| 2019 | 与鄂尔多斯市国资委共同成立 [[鄂尔多斯市绿动大数据科技股份有限公司]] |
| 2019.6 | 与鄂尔多斯十方物流共同成立 [[内蒙古盛世欣源电子商务有限公司]] |

## 业务板块

煤炭交易（坑口100余家交易服务站，撮合/寄售）、网络货运（东胜区国资委共建结算大厅）、智慧物流、大数据产品（鄂尔多斯煤炭网与中国榆林煤炭网，获内蒙古发改委大数据与工业互联网试点）、物联网仓云平台（智能监管仓+供应链金融）、智慧矿山、煤质检测。

商业模式核心为 [[煤炭产业互联网业务闭环模式-煤炭网2020口径]]："交易为核心、服务收费"。
