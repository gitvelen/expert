# 董峰

董峰是eRWA（enhanced Real World Asset，增强现实世界资产）概念的提出者与"资产端数字化"理论框架的构建者，现任[[深圳前海鹏峰数贸科技有限公司]]董事长。

## 履历

| 项目 | 内容 |
|------|------|
| 现职 | 深圳前海鹏峰数贸科技有限公司董事长 |
| 前职 | 港交所前海联合交易中心总经理 |
| 创业时间 | 2023年 |
| 学历背景 | 普林斯顿大学博士（宇宙大尺度结构研究） |

## 实践脉络

董峰的产业数字化实践经历以下阶段：

1. **区块链仓单**——早期探索
2. **数字工厂/委托加工模式**——提出产业数字化中间形态
3. **甘蔗数字化种植**（2024年起，广西隆安）——利用"无人机+算法"实现大田农业每日厘米级低成本数据采集
4. **eRWA红糖链品**（2025年10月发布）——首个基于实物锚定的eRWA产品

## 核心主张

- **RWA的本质应是"资产端数字化"**，而非金融化与代币化；后者"选错了对象"
- 技术主线为**"去中心化+连续簿记"**：去中心化将商业主体解析至每单交易/每个物理资产动作（空间维度颗粒度颠覆），连续簿记实现全流程不间断计量管理（时间维度精细化）
- 资产端数字化与数字化的资金端直接匹配，实现**金融脱媒**，重构商业与金融体系
- RWA底层资产须满足三特征：可彻底数字化、一对一严格映射特定物、物理分割后具独立可拆分使用价值
