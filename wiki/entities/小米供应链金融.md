# 小米供应链金融

小米供应链金融是小米集团依托其智造基因和产业生态开展的产业金融业务板块（据来源为"小米金融/小米产业金融业务中重要板块"），2018 年 3 月正式开展供应链金融业务，致力于以金融科技助力消费升级与产业升级。

## 全链金融 1.0 → 4.0 演进（宋华《数字供应链》案例，转述口径）

| 阶段 | 特征 |
|---|---|
| 全链金融 1.0 | 只做小米生态企业的订单融资 |
| 2.0 / 3.0 | 向生态金融服务、新制造金融服务演进 |
| 全链金融 4.0 | 紧随新制造浪潮，推进智能制造协同系统，打通生产各阶段 |

## 全链金融 4.0 的核心风控逻辑

- 建立产销协同平台，打通全链条数据，**还原工厂的信用画像**。
- 结合工业互联网整理关键数据节点——"人（人员）机（机器）料（物料）法（工艺）环（环境）"——从**时点**与**时段**两个维度建立工厂生产经营模型，评估工厂信用，据此拓宽制造企业融资路径。
- 目标：做宽做广放款量、在产业链中做透做深，植入体系外合作伙伴场景，赋能小米客户及体系外制造业客户，为制造业降本增效。

## 意义与注意

"工厂信用画像"是数据信用替代主体信用的代表性实例，可对照 [[主体信用向结构信用与物的信用转变-2023口径]]。"4 年发展至 4.0"为业务方/书籍案例转述口径，落地规模无第三方核验。
