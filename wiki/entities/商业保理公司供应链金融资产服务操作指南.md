# 《商业保理公司供应链金融资产服务操作指南》（深圳地方标准，2023）

**状态**：现行，推荐性地方标准（条款以"宜"字表述为主，非强制监管规定）。2023-12-22 由[[深圳市市场监督管理局]]批准发布，[[深圳市商业保理协会]]牵头、前海一方等相关负责人主笔。万联网报道称其为"全国首个针对商业保理的地方标准"（宣传口径，未见官方文件明示）。

## 定位与适用范围

为商业保理公司开展**基于核心企业类型**的供应链金融资产服务（ABS/ABN 及非标产品的资产审核、筛选、存续期管理、敦促偿付）提供全周期业务流程、智能化科技应用和服务可视化指引。

## 核心要点

1. **全周期七阶段流程**：准入尽调 → 项目论证及申报 → 资产收集 → 资产审核 → 转让支付 → 存续期 → 回款，详见 [[供应链金融资产服务全周期七阶段流程-深圳标准2023]]。
2. **资产审核实质导向**：以保证真实性、合法性、有效性、防范重复融资为目的，不以流程完整为目的。
3. **中登网逐笔排他登记**：对拟融资应收账款在中国人民银行征信中心动产融资统一登记公示系统逐笔排查转让/质押记录，无权利负担者登记；再转让（再保理、ABS）同样须完成排他登记并取得债务人书面知悉文件。
4. **智能化审核路径**：数据对接（中登网、核心企业系统、第三方数据）→ 图像识别/NLP 数据处理 → 规则引擎自动审核。
5. **信息安全合规**：按 GB/T 22080—2016 与 GB/T 35273—2020 建设信息安全体系与个人信息保护机制。

## 背景与意义

发布于保理行业监管压降（205 号文等）之后，反映深圳作为保理重镇从监管整顿走向标准化规范化的节点；国家层面此前无商业保理公司开展供应链金融资产服务的标准规范。该标准将抽象的"贸易背景真实性"原则转化为可执行的操作清单。

## 引用注意事项

原文条款编号存在排版错误（4.5 与 4.6 重复为"转让支付阶段"、4.5 下两个 4.5.1），引用条款编号需核对原文。
