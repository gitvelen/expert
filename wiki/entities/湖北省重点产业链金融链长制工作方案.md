# 《湖北省重点产业链金融链长制工作方案》

由人民银行武汉分行联合湖北省经信厅、省农业农村厅、省地方金融监督管理局、湖北银保监局发起设立，是**金融链长制**的制度载体——由省级银行业金融机构担任“金融链长”，产业链所在地人民银行分支机构牵头当地重点产业链金融服务工作，推进金融惠企政策与产业链融资需求高效对接。

## 覆盖范围

全省 10 条农业主导产业链 + 16 条重点制造业产业链，共 26 条重点产业链全部配备金融链长，与产业链“链链对接”“一链一策”，形成覆盖核心企业和上下游小微企业的综合金融服务方案。

## 首批 8 条先行先试产业链

| 产业链 | 担任金融链长的机构（示例） |
|---|---|
| 特色淡水产品（小龙虾） | 中国银行、农业银行、农发行、省农信联社、建设银行等省级金融机构 |
| 蔬菜（香菇） | 同上 |
| 茶叶（青砖茶） | 同上 |
| 道地药材（艾草） | 同上 |
| 航空航天 | 同上 |
| 集成电路 | 同上 |
| 汽车 | 同上 |
| 现代化工 | 同上 |

（原文未逐条对应链与机构，仅列出上述 8 条链及机构名单。）
