# 万象风控云平台

万象风控云平台（简称"万象风控云"）是 [[中诚信征信]] 推出的 SaaS 化数字化智能风控云平台，面向企业管理上下游商业伙伴信用风险。（以下产品能力描述均来自万联网 2021-08-27 软文，为厂商宣传口径，未经独立验证。）

## 产品定位

以 SaaS 模式变革传统企业信用风险管理服务形态，基于中诚信征信多年信用风险管理理论，利用大数据、机器学习、云计算等技术，从供应链全局风控视角构建贯穿"事前风险准入—事中动态风险监测—事后催收管理"全链条风控的云端在线协作平台。

## "五环节"标准化业务流程

1. **风险信息搜索**：统一 API 接口采集目标企业工商、税务、司法、经营、行业等维度信息；
2. **风险画像及扫描**：风险标签体系 + 可配置预警规则信号等级体系，自动化风险筛查与风险等级标记；
3. **智能建模及在线报告**：可配置行业量化风控模型，线上化、批量化评价，自动生成评价分数与分析报告；
4. **风险监测**：动态监测交易主体行为变化，可视化定位风险点及传导关键路径；
5. **风险催收**：在线商账催收，含催款流程、案情分析、催收报告、催记与案件委托。
