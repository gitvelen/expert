# 麦杰科技

麦杰科技是一家曾于 2010 年代初申报 IPO 的公司，因"IPO 冲关失败"而成为财务分析领域讨论应收账款造假的经典案例素材（此身份背景来自来源文章；其主营业务与后续经营状况本库尚未核验）。

## 来源中的财务特征（2016 年文章，作者推断口径）

2009–2011 年：应收账款净额 3395.32 / 4995.1 / 6062.41 万元，占总资产比例高达 50.58% / 49.08% / 50.77%，占流动资产约 55%；应收账款账面余额年均增幅 33.35%，占营业收入 80.34% / 83.83% / 83.16%；应收账款周转率 1.5 / 1.6 / 1.46 次，对比同行上市公司为 5.83 / 6.19 / 5.41 次；经营现金流净额占净利润比例仅 44.35% / 47.53% / 54.81%。

"马靖昊说会计"据此推断其极可能虚构应收账款虚增收入。**注意**：此为自媒体推断，非监管处罚或司法认定，证据强度属"专业公众号分析"层级。IPO 冲关失败的具体原因文中亦未说明。
