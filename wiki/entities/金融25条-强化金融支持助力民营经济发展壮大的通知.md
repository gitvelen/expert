# 《关于强化金融支持举措 助力民营经济发展壮大的通知》（"金融25条"）

2023年11月27日，[[中国人民银行]]、[[国家金融监督管理总局]]、中国证监会等八部门联合印发。政策定位：深入贯彻党的二十大精神和中央金融工作会议要求，全面落实《中共中央 国务院关于促进民营经济发展壮大的意见》，坚持"两个毫不动摇"，引导金融机构树立"一视同仁"理念。

## 25条结构化要点

| 部分 | 条目 | 要点 |
|---|---|---|
| 一、信贷资源投入 | （一）—（五） | 年度服务目标、提升民企贷款占比、首贷信用贷、[[供应链脱核模式]]（第三条）、资金接续、不盲目抽贷断贷、不良容忍度与尽职免责、防风险与资金流向监控 |
| 二、债券市场 | （六）—（九） | 科创票据、绿色债券、储架式注册"快速通道"、民企债券融资支持工具（中债信用增进、证金公司）、机构投资者配置、探索高收益债券市场 |
| 三、多层次资本市场 | （十）—（十二） | 上市融资与并购重组、区域性股权市场、股权投资基金 |
| 四、外汇便利化 | （十三）—（十五） | 经常项目便利化、跨境投融资便利化试点扩围、跨境金融服务平台 |
| 五、正向激励 | （十六）—（十八） | 支农支小再贷款、财政奖补与保险保障、金融债券与资本工具 |
| 六、融资配套 | （十九）—（二十三） | 信用信息共享、政府性融资担保风险补偿、票据市场信用约束（第二十一条）、应收账款确权（第二十二条）、以物抵债差额增值税 |
| 七、组织实施 | （二十四）—（二十五） | 宣传解读、部门协调督导、统计监测与政策效果评估、各金融机构制定实施细则 |

## 后续安排

人民银行等部门将指导金融机构制定具体实施细则，加强统计监测和政策效果评估。详见 [[查询-金融25条银行实施细则出台进度与脱核模式落地]]。
