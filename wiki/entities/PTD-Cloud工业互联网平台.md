# PTD Cloud 工业互联网平台

PTD Cloud 工业互联网平台是 [[国联股份]] 数字工厂/云工厂业务的实施载体平台，与多多云工厂共同构成国联云工厂建设的技术底座。据本文（公司披露口径），国联股份的“数字工厂+PTD Cloud 工业互联网解决方案”被工信部认定为“2020年工业互联网试点示范项目”，立足于同一产业链、供应链、价值链上、下游数字工厂的共构链接，帮助实体企业实现生产、管理、质检、能耗、物流的数字化。
