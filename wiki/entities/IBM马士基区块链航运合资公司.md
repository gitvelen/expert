# IBM×马士基区块链航运合资公司（TradeLens 前身）

## 概述

2018 年 1 月，[[IBM]] 与马士基（Maersk）宣布筹建合资公司，配置以区块链为底层技术的电子航运系统，取代 EDI 与纸质单据货运体系。该公司即后来的 **TradeLens** 平台。首任 CEO 为马士基北美航线前总裁 **Michael White**。

## 2018 年宣布时的愿景（当时口径）

- 以 API + 区块链为底层技术，实现航运信息不可篡改、实时共享
- 提升海关与港口审批效率，减少集装箱滞留
- 防范货物伪造、偷盗与诈骗
- 媒体口径称每年可为全球航运业节约"数以十亿美元"成本（无测算出处，证据弱）

## 后续结局（待补充核实）

据公开报道，TradeLens 于 **2023 年初宣布关闭**，2018 年的愿景与结局形成鲜明对照。此为本文的关键后续事实，具体停运原因与时间线见 [[queries/查询-TradeLens最终落地成效与2023年停运原因]]。
