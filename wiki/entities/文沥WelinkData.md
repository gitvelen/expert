# 文沥（WelinkData）

文沥（上海文沥信息技术有限公司，WelinkData，官网 http://www.welinkdata.com）是一家总部位于上海的大数据供应链金融服务商，定位为"企业与业务伙伴、金融机构之间的数据桥梁"，主营企业交易大数据征信、供应链管理与供应链金融服务，旗下另有上海文沥企业征信有限公司。按其 2017 年自述，公司将全球价值链经验与数据采集、交换、处理、分析技术结合：一方面连接价值链核心企业与全渠道业务伙伴，建立需求驱动的供应链体系；另一方面通过真实、实时、持续的数据服务连接企业与金融机构，建立基于量化评估的信贷和风险管理体系，目标是建立大数据为基础的供应链金融生态。（以上主体身份信息均为来源自述口径，公司后续存续状态待核验。）

其新型数据模型以业务交易数据为基础、以深度行业企业运营分析为核心，为金融机构提供动态征信、真实贸易背景与运营健康实时评判、授信评估与自动化贷后预警服务（2017 年公司自述口径）。

## 产品线（2017 年口径）

- **B2BGateway / API Gateway**：网关软件，融合 EDI 数据交换与 API 技术，按业务场景组合使用
- **SCF Gateway（交易网关）**：2017 年 6 月"即将发布"，部署于企业端与金融机构业务系统交互，采用非对称加密签名传输；支持非区块链场景与区块链场景（R3、HyperLedger、以太坊）下的分布记账与智能合约。文中自称"全球首款区块链数据网关产品"——**厂商宣传口径，需存疑核验**
- **基于 B2B 网关技术的"加速器"程序**：宣称可智能自动识别和抽取 **300 种以上**小微企业常用 ERP/进销存程序数据，整理成企业数据征信报告并做可信度评分，支持金融机构对小微企业数据的动态定时获取、自动审批与风险预警（产品自述，未见第三方验证）
- **大数据供应链金融生态**：宣称以业务/交易数据为基础的数据模型提供动态征信、真实贸易背景与运营健康评判、授信评估与自动化贷后预警

## 业务模式（2017 年自述口径）

- 连接企业上下游与各类金融机构，通过真实、实时、持续的数据服务建立大数据为基础的供应链金融生态。
- 以业务数据/交易数据为基础，以深度行业企业运营分析为核心，为金融机构提供**动态征信**：实时评判企业真实贸易背景和运营健康，执行授信评估与自动化贷后预警。
- 点状基础设施服务之一为**交易征信**（文沥企业征信），对应钟胜九"金融基础设施纵向路径"框架——详见 [[交易信用与ETC-TPC-TBC三层征信体系-文沥2017口径]]。

## 方法论贡献

文沥以公众号连载形式输出大数据供应链金融方法论，2017 年系列包括：

- **连载之一**：2017 年 6 月，文沥 CEO [[钟胜九]]在"供应链金融"公众号发布《文沥大数据供应链金融方法论连载之一》，提出 [[文沥供应链金融SRODCF方法论-2017口径]]（结构、责任、在线、数据、现金管理、资金引入六位一体），核心论断为"数据驱动是趋势，但供应链金融设计绝不仅仅是数据"。
- **连载之七**：供应链金融模式下的小企业批量授信（作者赵婧）→ [[供应链金融小企业精细化批量授信四步法-文沥2017口径]]、[[链式族群与核心企业数据掌握度选择论-2017口径]]、[[ERP进销存数据标准化获取难题与文沥加速器-2017口径]]
