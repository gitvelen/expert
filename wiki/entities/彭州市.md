# 彭州市

彭州市是成都市下辖县级市，为[[农产品数字仓单模式]]的首发落地标杆案例城市，也是[[数字仓融通]]平台的运营地。

## 农业产业概况（2025年口径）

| 指标 | 数值 |
|------|------|
| 主要种植品种 | 莴笋、大蒜、生姜、川芎（地理标志中药材） |
| 蔬菜年产量 | 230余万吨 |
| 蔬菜年产值 | 约120亿元 |
| 家庭农场/合作社数量 | 1100余家 |
| 从业人员（蔬菜流通） | 约10万余人 |
| 冷藏保鲜库数量 | 300余个 |
| 冷藏保鲜库总容量 | 20万吨 |
| 民营三方仓储占比 | 90%以上 |
| 农产品年交易额（四川国际农产品交易中心） | 500亿元 |

## 数字仓单实践

- **2022年3月**：[[数字仓融通]]上线
- **参与银行**：5家
- **质押品类**：从单一大蒜扩展至10余种耐储农产品及中药材
- **融资成本**：从民间借贷12%降至3.8%
- **川芎品类户均融资额**：超千万元
- **蔬菜类单户资金需求**：300-500万元
- **2023年**：获农业农村部十大经典案例表彰

## 产业特征

- 蔬菜贸易采取"买全球、卖全球"模式
- 拥有西部最大的农产品集散物流中心——四川国际农产品交易中心
- 农产品具有集中上市、集中收储特点，收购资金需求旺盛
- 仓储以分散的民营三方仓储为主（90%以上），非集中收储
