# 人民银行广州分行等七部门转发通知（2017）

2017年9月1日，中国人民银行广州分行、广东省经济和信息化委员会、广东省财政厅、广东省商务厅、广东省人民政府国有资产监督管理委员会、中国银行业监督管理委员会广东监管局、国家外汇管理局广东省分局七部门联合转发银发〔2017〕104号文（[[entities/小微企业应收账款融资专项行动工作方案2017-2019]]），是中央专项行动在广东的落地文件。

## 六项工作要求

1. 宣传推广：分批组织培训会、座谈会、银企对接会。
2. 政府采购供应商融资便利：采购合同信息公开 + 采购单位经平台确认应付账款。
3. 供应链核心企业反向保理：国资部门组织控股核心企业分批对接平台；对确认账款笔数多、助融总额大的核心企业给予支持鼓励。
4. 丰富资金提供方：引导商业保理公司参与平台；应收账款融资纳入银行综合考评与信贷政策导向效果评估；风险可控前提下鼓励金融机构向商业保理公司提供再保理融资和综合授信。
5. 应收账款质押和转让登记：依托中征动产融资统一登记系统，推动保理项下、ABS项下、资产转让交易项下转让登记。
6. 优化商业信用环境：债务人付款信息入信用体系；非银金融机构"成熟一家接入一家"接入金融信用信息基础数据库。
