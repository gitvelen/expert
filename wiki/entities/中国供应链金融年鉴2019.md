# 《中国供应链金融年鉴（2019）》

《中国供应链金融年鉴（2019）》由中国供应链金融年会组委会、《贸易金融》杂志、北京财资和供应链应用技术研究院共同发布，于 2019-03-14"2019 第三届中国供应链金融年会"上正式发布。

## 内容结构（八部分）

卷首语、行业发展综述、行业生态图谱、银行系发展篇、核心企业系发展篇、金融科技系发展篇、物流仓储系发展篇、附录。

其中"银行系 / 核心企业系 / 金融科技系 / 物流仓储系"四分法，是 2019 年时点行业媒体对供应链金融参与主体的分类口径（见 [[供应链金融四主体分类口径2019]]）。

## 优秀案例征集（2019 年口径）

- 征集时间 2019-01-18 至 2019-03-01；案例 2000–4000 字，A4 宋体小四。
- 征集对象覆盖商业银行、实体企业、金融科技公司、物流仓储公司。

## 时效性说明

本条目为 2019 年口径。该年鉴 2019 年后是否持续发布、版本演进如何，尚待核实。
