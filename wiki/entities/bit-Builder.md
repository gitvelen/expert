# bit-Builder

bit-Builder 是九科信息推出的云原生企业级低代码开发平台，服务于应用设计开发、应用生命周期管理、应用运营支撑与系统集成连接，与 [[bit-Worker]]（RPA）、[[bit-Miner]]（流程挖掘）共同构成九科企业级敏捷应用平台。

## 主要能力（2021 年口径）

- 应用全生命周期管理：多环境部署、元数据与源代码管理，支持 DevOps 与 CI/CD；提供测试平台、数据埋点、用户反馈等第三方集成
- 多模式开发（厂商自称“业内首先”）：以模型驱动开发为主，兼支持表单、表格、报表设计及数据建模、复杂 UI 界面等方式
- 基线能力与客制化能力分离：客户可通过插件定制而不影响版本升级

## 说明

“业内首先支持多模式开发”为厂商自述宣称，未经第三方验证。
