# 德邦-中铝商业保理供给侧改革1号资产支持专项计划

德邦-中铝商业保理供给侧改革1号资产支持专项计划是由 [[中铝商业保理有限公司]] 主导发起、在上交所发行的企业资产支持专项计划，2019年6月28日成功发行，为**全国首单有色行业供应链ABS**。

## 发行要素

| 要素 | 内容 |
|------|------|
| 发行日期 | 2019年6月28日 |
| 发行场所 | [[上海证券交易所]] |
| 原始权益人/主导发起 | [[中铝商业保理有限公司]] |
| 计划管理人 | [[德邦证券]]（以"德邦-"前缀体现） |
| 产品规模 | 10.04亿元 |
| 优先级规模 | 9.53亿元 |
| 优先级评级 | AAA（联合评级） |
| 优先级发行利率 | 3.77% |
| 底层资产 | 有色行业供应链应收账款（核心企业为中铝集团体系） |

## 意义与口径

- 行业节点：全国首单有色行业供应链ABS，继中铝集团央企供给侧结构性改革租赁债权ABS后的又一创新，服务央企降杠杆与"三去一降一补"（通稿宣传口径，标注为媒体解读）。
- 风险结构：优先级AAA与3.77%利率佐证其高度依赖 [[中铝集团]] 央企主体信用；与承兴案（第三方信用伪造型ABS）形成同期对照。
- 降杠杆的会计实质（是否出表/无追索安排）通稿未涉及，见 [[查询-德邦中铝保理供给侧改革1号ABS出表实质与有色行业供应链ABS后续扩容考证]]。
