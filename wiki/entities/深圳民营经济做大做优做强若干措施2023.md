# 《关于促进民营经济做大做优做强的若干措施》（深圳"民营经济20条"）

2023年8月16日经深圳市委、市政府同意，由中共深圳市委办公厅、深圳市人民政府办公厅印发，共20条举措，是中央"民营经济31条"（2023-07-19）的地方落实文件。

## 20条举措与责任单位

| 序号 | 举措 | 责任单位 |
|---|---|---|
| 一 | 推动平台经济高质量发展（2023年底前出台行动计划） | 市发展改革委、市总工会、市人力资源保障局 |
| 二 | 培育中小企业特色产业集群、专精特新奖励 | 市工业和信息化局、市发展改革委、市科技创新委、市财政局 |
| 三 | 加快推进应用场景开放 | 市发展改革委、市工业和信息化局 |
| 四 | 激发民营企业科技创新活力 | 市科技创新委、市发展改革委、市工业和信息化局、市民政局 |
| 五 | 加强民营企业融资支持（50亿风险补偿资金池、担保费率<1%、地方征信平台信用画像） | 市地方金融监管局、市政务服务数据管理局等九部门 |
| 六 | 支持民间资本参与重大项目建设（三类项目清单、REITs试点） | 市发展改革委、市国资委、深圳证监局 |
| 七 | 支持民营企业投标竞标（分类入围，民企占比原则上≥1/3） | 市住房建设局、市市场监管局、市发展改革委、市国资委 |
| 八 | 健全公平竞争审查机制（前海设公平竞争委员会） | 市市场监管局、市司法局、市前海管理局 |
| 九 | 优化统一大市场准入环境（放宽24条特别措施，电信/能源电力/数据要素） | 市发展改革委、市工业和信息化局、市商务局、市地方金融监管局 |
| 十 | 支持民营企业拓展海外市场（绿电绿证服务机构、境外投资指引） | 市发展改革委、市商务局、市市场监管局、市贸促委 |
| 十一 | 优化信用服务机制（信用报告代替无违法违规证明） | 市市场监管局、市政务服务数据管理局等 |
| 十二 | 加快企业合规示范区建设（2023年底前发布企业合规地方标准） | 市检察院、市市场监管局、市司法局 |
| 十三 | 坚持有案必立、有诉必理（统一立案服务标准） | 市中级法院 |
| 十四 | 依法维护民营企业涉外地刑事案件合法权益 | 市公安局 |
| 十五 | 推进规范文明监管执法 | 市市场监管局、市公安局、市检察院、市中级法院 |
| 十六 | 加大拖欠民营企业账款清理力度 | 市工业和信息化局、市财政局、市国资委等十一部门 |
| 十七 | 全面构建亲清政商关系 | 市委统战部、市工业和信息化局、市工商联 |
| 十八 | 支持行业商协会搭建政企沟通平台 | 市民政局、市工业和信息化局、市工商联 |
| 十九 | 优化服务民营企业家水平 | 市工商联、市委统战部、市工业和信息化局 |
| 二十 | 大力培育弘扬优秀企业家精神 | 市工商联、市委宣传部、市公安局等 |

## 2023年底前配套文件承诺

1. 平台经济高质量发展行动计划
2. 促进中小企业特色产业集群发展的政策措施
3. 扩大民间投资若干措施
4. 深圳市信用报告代替企业无违法违规证明改革实施方案
5. 企业合规地方标准
6. 境外投资指引
7. 前海深港现代服务业合作区设立公平竞争委员会（议事协调机构）
