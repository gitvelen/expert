# 碳减排支持工具

[[中国人民银行]]于 2021-11-08 推出的结构性货币政策工具，旨在支持"碳达峰、碳中和"目标，属"做加法"的增量资金支持，重点支持清洁能源领域。

## 核心机制参数

| 参数 | 内容 |
|---|---|
| 发放对象 | 暂定为全国性金融机构 |
| 机制 | "先贷后借"直达机制（见 [[先贷后借直达机制]]） |
| 资金支持比例 | 贷款本金的 60% |
| 资金利率 | 1.75% |
| 期限 | 1 年，可展期 2 次 |
| 质押要求 | 金融机构需提供合格质押品 |
| 贷款利率要求 | 与同期限 LPR 大致持平 |
| 重点领域 | 清洁能源、节能环保、碳减排技术 |
| 信息披露 | 申请时提供碳减排数据并承诺公开；获支持后按季度披露领域、项目数量、贷款金额、加权平均利率、碳减排数据（见 [[碳减排信息披露制度]]） |
| 核查 | 央行会同相关部门委托第三方专业机构核实验证披露真实性 |

## 碳减排量测算

参考碳减排项目可行性研究报告、环评报告或市场认可的专业机构评估报告，以及贷款占项目总投资的比例，计算贷款的年度碳减排量。

## 首批落地数据（2022 年披露）

- 人民银行向有关金融机构发放第一批碳减排支持工具资金 **855 亿元**。
- 支持金融机构发放符合要求的碳减排贷款 **1425 亿元**，共 **2817 家企业**，带动减少排碳约 **2876 万吨**。

## 定位

- 结构性货币政策工具（见 [[结构性货币政策工具]]）。
- 强调金融机构"自主决策、自担风险"，对重点领域内各类企业一视同仁。
- 通过明确重点领域与强化信息披露发挥政策示范效应。

## 相关工具

- [[煤炭清洁高效利用专项再贷款]]：同期推出的另一结构性工具，2000 亿元，重点支持煤炭煤电清洁高效利用。

## 张力与待跟踪

- 央行强调市场自主性，同时设定贴近 LPR 的利率要求与强制信息披露，政策引导与市场自主的平衡值得跟踪。
- 发放对象"暂定为全国性金融机构"，后续是否扩展至地方法人机构待确认；实际发放规模与展期使用成效见 [[查询-碳减排支持工具发放规模与展期使用成效]]。
