# 出海问问

出海问问是[[奥格跨境]]推出的跨境商贸智能查询/辅助决策 Bot Agent 产品（2025 年口径）。据其自述，产品面向跨境商贸中的差异化专业流程提供低成本、高精准的决策支持，典型场景如马来西亚与泰国榴莲进口等专业流程查询。

与同公司的[[鸭梨匠]]（资源调优型 Agent）构成产品线互补：出海问问偏"辅助决策/知识查询"，鸭梨匠偏"调度执行"。
