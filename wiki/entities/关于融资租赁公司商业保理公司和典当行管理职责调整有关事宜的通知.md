# 《商务部办公厅关于融资租赁公司、商业保理公司和典当行管理职责调整有关事宜的通知》

《商务部办公厅关于融资租赁公司、商业保理公司和典当行管理职责调整有关事宜的通知》是商务部于 2018 年发布的政策文件，将制定融资租赁、商业保理和典当行三类公司的业务经营与监管职责划给银保监会。文中记载商务部已于 2018-04-20 完成划转。

## 意义

- 终结了此前商务部监管商业保理、银监会监管银行保理的**双轨分管格局**，为后来商业保理与银行保理监管标准的统一奠定制度起点。
- 是知识库"监管演进"主线（226 号文 → 155 号文 → 205 号文 → 金融监管总局时代）中 2018 年的关键节点。

## 划转后的政策不确定性（2018 年末口径，已被后续文件部分回应）

据 2018 年末行业人士表述（见 [[sources/4-news--7-02-产品案例--4-2018--18-2019年商业保理市场的发展趋势保理--1nk45hm]]），当时尚未明朗的问题包括：

1. 行业准入门槛如何设定；
2. 杠杆率、股东关联业务占比限制；
3. 现有存量保理业务如何过渡；
4. 商业保理监管标准是否与银行保理完全统一，抑或采取针对性措施。

上述不确定性后来由 2019 年银保监会 205 号文等文件部分回答（待后续年份资料入库后补齐演进脉络）。
