# Waffo

全球支付与变现平台，定位“从工具到基础设施”，服务游戏、AI、SaaS、数字内容等数字企业出海变现。以下信息**均为企业自述口径**（2026 年融资通稿），无第三方验证。

## 自述要点（2026 年口径）

- 单一 API 接入 50+ 国家/地区的 430+ 种本地支付方式；覆盖北美、东亚、东南亚、拉美等主要市场。
- 模块化方案：全球支付网关、智能路由、订阅管理、统一结算、合规风控（KYC、PCI DSS）。
- 技术指标：PCI DSS v4.0 一级认证、2000TPS 高并发、99.99% 服务可用性（厂商宣传口径，仅记录不作结论）。
- 融资：累计 3000 万美元，A 轮超 1500 万美元，Illuminate Financial 与高榕创投共同领投，HSBC、BAI Capital 参投。
- 自称为 [[连连国际]] 及 HSBC 等机构提供底层支付技术支持——单一来源，待核验。
