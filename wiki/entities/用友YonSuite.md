# YonSuite

YonSuite 是用友面向成长型企业的一体化、云原生 SaaS 产品，覆盖财务、人力、营销、制造、供应链、研发、协同等“十大领域应用”。

## 厂商叙事要点（2026口径，证据强度：弱）

- **统一底座主张**：与通过 API 或 MCP 协议外挂 AI 能力的产品不同，YonSuite 声称其 AI 能力从统一数智底座“长出”，所有智能体共享统一身份、权限和知识体系，嵌入销售订单、智能报价、财务核算等业务单据与流程。
- **HAI 品牌主题（2026）**：三层含义——Human and AI（人与AI协同）、Harness AI（驾驭AI，对应 [[Harness-Engineering企业级AI工程框架-2026口径]]）、High（高远的企业潜能）。
- **IP 形象 "yowo"**：谐音“有我”，代表 YonSuite 的数智员工。
