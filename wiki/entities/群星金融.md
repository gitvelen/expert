# 群星金融

群星金融是一家由姚猛创办的 Fintech（金融科技）供应链金融服务平台，定位于依托互联网与大数据技术撮合核心企业上下游中小企业基于应收账款的融资，其代表性产品为基于区块链技术的“星金券”。（以上身份信息来自本 wiki 导入的 2017 年来源；其后续存续状态尚未核验，见开放问题）

## 业务模式

- 以核心企业信用为锚，覆盖 N+1 多级供应商：一级供应商不缺钱且资质获金融机构认可，但二三级供应商资金短缺；星金券让核心企业信用凭证沿供应链流转至多级供应商。
- 资金来源呈多渠道格局（2017年口径）：除银行、企业自有资金外，供应链金融交易平台等互联网金融企业成为重要资金入口。

## 运营数据快照（2017年，公司自述口径）

| 指标 | 数值 |
|---|---|
| 核心企业客户 | 150+ 家 |
| 中小企业客户 | 4万+ 家 |
| 撮合交易总额 | 130 亿元 |
| 单笔融资额度 | 几千元至几千万元，以 5万–50万元 居多 |
| 期限 | 以 2–3个月 居多 |
| 中小企业融资成本 | 约 10%–12% |

## 注意事项

- 以上数据与成本口径均为 2017 年媒体转述的企业自述（宣传口径），证据强度中等偏弱，不能作为行业结论依据。
- 10%–12% 融资成本仍高于同期银行对公利率，平台实际改善的是融资可得性而非绝对成本。
- 2017年的乐观叙事需与其后平台类业务的爆雷周期对照核验（待建开放问题页跟踪）。
