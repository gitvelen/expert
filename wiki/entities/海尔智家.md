# 海尔智家

海尔智家（海尔智家股份有限公司）是海尔集团旗下的 A 股上市公司，主营家电业务，作为核心企业其采购体系连接大量经销商。（上市公司身份为可独立核验的公开背景信息。）

## 星展银行合作案例（2020 年 1 月口径）

- 签署可持续数字化供应链金融战略合作协议。
- 交易结构：通过 API 系统技术将星展银行与海尔采购平台直接对接，实现银行系统与核心企业采购平台的技术直连。
- 落地速度：据星展中国企业及机构业务部总经理郑思祯称，不到三个月已有 40 余家经销商通过平台与海尔智家完成供应链对接（企业自述口径）。
- 模式意义："API 直连核心企业采购平台"的批量服务经销商模式，是银行—核心企业数字化供应链金融协同的代表性样本。
