# 《关于加强金融服务民营企业的若干意见》

《关于加强金融服务民营企业的若干意见》是**中共中央办公厅、国务院办公厅**于**2019年初**印发的中央政策文件（2019年2月14日印发），新华社受权发布全文。文件共**五部分十八条**，旨在提高民营企业融资可获得性。2023-03-06由万联网转载（属政策回顾）。

## 核心定位

针对民营企业融资难融资贵的制度性、结构性原因，提出标本兼治的政策框架，目标是在融资方面实现各类所有制企业平等待遇。

## 十八条措施体系概览

| 层面 | 条款 | 要点 |
|---|---|---|
| 货币信贷 | 第四条 | 宏观审慎参数调整、普惠金融定向降准、再贷款再贴现扩围、票据融资支持 |
| 直接融资 | 第五条 | 科创板试点注册制、新三板改革、民企债券发行 |
| 机构能力 | 第六条 | 资本补充工具创新、信用保险与债券信用增进 |
| 信息基础设施 | 第七条 | 金融/税务/市场监管/社保/海关/司法大数据互联互通 |
| 增信体系 | 第八条 | 国家融资担保基金、取消反担保、风险补偿专项资金 |
| 考核激励 | 第十至十一条 | “敢贷、愿贷、能贷”长效机制、差异化考核、“头雁”作用 |
| 信贷方式 | 第十二至十四条 | 减轻抵押担保依赖、供应链“三流闭环”融资、禁止运动式投放 |
| 纾困与清欠 | 第十五至十六条 | 股票质押风险化解、清理拖欠民企账款 |
| 落实保障 | 第十七至十八条 | 民企规范经营、第三方评估 |

## 第十二条：供应链金融专项部署

第十二条单独部署供应链金融，是中办国办层面对供应链金融价值的再次认可，也是国家级层面对供应链金融的早期系统性表述。要点：

- 减轻对抵押担保的过度依赖。
- 商业银行依托产业链核心企业信用、真实交易背景和物流、信息流、资金流闭环，为上下游企业提供无需抵押担保的订单融资、应收应付账款融资。
- 强调核心企业的作用与“四流”的作用。

## 在供应链金融政策演进中的位置

第十二条向上承接此前零散政策，向下与2022年及2023年政策形成中央—省级纵向演进脉络：

- 向下衔接 [[供应链金融政策年度演进2022]]（票据新规等）及2023年省级政策（沪、鄂、晋、深）。
- 相关演进脉络见 [[供应链金融政策演进中央到地方2017-2019]]。
- 第十六条清欠条款是 [[拖欠民营企业账款清理联动机制]] 的上位政策依据。
