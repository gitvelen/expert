# 厦门象鼎新能源有限责任公司

厦门象鼎新能源有限责任公司是 [[象屿集团]] 与 [[青山控股集团]] 的合资公司，2025-01-20 注册，2025-02-27 正式揭牌。

| 项目 | 内容 |
|---|---|
| 成立时间 | 2025-01-20 |
| 揭牌时间 | 2025-02-27 |
| 注册资本 | 5000 万元人民币 |
| 股权结构 | 厦门象屿新能源公司 51% / 浙江鼎森控股 49% |
| 法定代表人 | 苏主权 |
| 注册地址 | 厦门市同安区西柯街道云谷路36号501室之一百九十二单元 |
| 所属行业 | 科技推广和应用服务业 |
| 经营范围 | 电池、光伏设备、半导体器件销售及供应链管理；新兴能源技术研发 |

## 战略定位（公司口径）

宣示“资源+渠道+技术”立体化协同，深耕非洲新能源市场，布局锂电、光伏产业链。青山方提供印尼镍资源（动力电池正极材料原料），象屿方提供全球物流网络与跨境供应链服务（曾为印尼250万吨不锈钢项目提供原材料采购与销售支持）。
