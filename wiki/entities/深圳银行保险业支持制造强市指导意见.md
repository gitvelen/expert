# 《关于银行业保险业支持深圳制造强市建设的指导意见》（金融21条）

2023年7月26日由国家金融监督管理总局深圳监管局、深圳市发改委、深圳市工业和信息化局、深圳市地方金融监督管理局联合发布，共6个方面、21条措施。

## 联合发布方

- 国家金融监督管理总局深圳监管局（第一署名）
- 深圳市发展和改革委员会
- 深圳市工业和信息化局
- 深圳市地方金融监督管理局

## 重点支持对象

- 深圳"20+8"产业集群
- 核心基础零部件等"四基"企业
- "工业上楼"、产业园区项目（参见 [[工业上楼与优质产业空间-深圳]]）
- 高新技术企业、"专精特新"中小企业、科技型中小企业、制造业单项冠军企业
- 生产性服务业（工业设计、第三方物流、服务外包）

## 关键条款

| 条款 | 内容 |
|---|---|
| 第九条 | 制造业小微企业不良容忍度可较各项贷款不良率提高不超过3个百分点，与尽职免责挂钩 |
| 第十一条 | 探索"贷款+外部直投"，科创金融服务前移（见 [[贷款加外部直投]]） |
| 第十二条 | 加强供应链融资提升产业链韧性（见 [[供应链融资提升产业链韧性-深圳条款]]） |
| 第十四条 | 首台（套）、新材料首批次、首版次软件保险及保单融资 |
| 第十六条 | 重点企业"白名单"与融资对接清单；"深惠万企 圳在行动"工程，发挥金融驿站、深圳金服平台作用（参见 [[金融驿站项目-深圳]]） |

## 性质

属监管指导意见，无资金规模与兑现指标，主要依靠统计监测、现场检查与督导落实。
