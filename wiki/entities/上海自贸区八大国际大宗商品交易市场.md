# 上海自贸区八大国际大宗商品交易市场

2014 年报道披露、拟落户上海自贸区并首批拿到"通行证"的八家国际大宗商品交易市场：

| 市场 | 发起方 | 品类 |
|---|---|---|
| 铁矿石交易中心 | 宝钢集团 | 铁矿石 |
| 有色金属交易中心 | 上海有色网 | 有色金属 |
| 有色金融交易中心 | 迈科金融 | 有色金融 |
| 棉花交易中心 | 北京全国棉花交易市场 | 棉花 |
| 液化工品交易中心 | 易贸集团 | 液化工品 |
| 石油天然气交易中心 | 上海石油交易所 | 石油天然气 |
| 白银交易中心 | 上海华通铂银交易市场 | 白银 |
| 大宗商品交易中心 | 上海钢联电子商务有限公司 | 大宗商品 |

涉及能源化工、农产品、矿产品、有色金融、黑色金属等多个品种。报道认为在《规定》出台后八家市场有望率先受益；但其实际运营成效为开放问题。
