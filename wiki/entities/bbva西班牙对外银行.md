# BBVA（西班牙对外银行）

BBVA（Banco Bilbao Vizcaya Argentaria，西班牙对外银行）是西班牙大型银行，被广泛视为全球银行业数字化转型的标杆之一（此为独立可核验的公共背景知识）。本文提供了其 2011–2018 年最完整的转型时间线案例。

## 转型时间线（2020 年文章口径）

- 2007 年全球金融危机后重新思考银行与客户关系，着力交互范式再造。
- **2011-11**：推出个人金融服务平台 **BBVA Contigo Adviser**，客户可通过手机与金融顾问实时互动。
- 将数字化能力引入核心业务：从支付交易数据中挖掘金融行为与人类社会活动的关系（如从支付行为看西班牙旅游分布与趋势）。
- **2015**：宣布转型目标为建设"21 世纪全球最佳数字银行"，致力于成为完全数字化的公司。转型途径：内部投资组合驱动业务转型；对金融科技创业公司资本输出以获取智力资源；大规模资本运作倒逼组织转型；在开放平台、云计算、大数据领域加大投入，将基础设施平台化。
- **2018-01**：南美洲用户数字占有率整体突破 **50%**。

另：BBVA 也是海外开放银行 API 平台的先行者之一，见 [[开放银行O-banking-2020口径]]。
