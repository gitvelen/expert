# 中国商业保理行业发展报告2015

《中国商业保理行业发展报告2015》（简称《报告》）是由[[商务部国际贸易经济合作研究院]]（商务部研究院）、[[中国服务贸易协会商业保理专业委员会]]（CFEC）等单位联合编写的商业保理行业年度发展报告，是中国商业保理行业最早、引用最广的权威数据来源之一，也是本知识库中2015—2016年商业保理行业总量数据的核心出处，以及该时期行业规模与结构数据的重要基线。2016 年多篇媒体报道的核心数据均出自该报告（数据由 CFEC 副主任兼秘书长[[韩家平]]对外发布）。

关于发布主体存在两种表述：一种记载为由商务部国际贸易经济合作研究院与中国服务贸易协会商业保理专业委员会等单位联合发布/编写；另一来源则表述为由中国服务贸易协会商业保理专业委员会发布。两说均予保留。

## 发布与结构

2016年4月6日在第四届（2016）中国商业保理行业峰会上发布。报告分四部分：全球保理行业发展状况、我国商业保理行业发展环境、发展现状、存在的主要问题与发展展望。

## 关键数据（2015 年底口径）

| 指标 | 数值 |
|---|---|
| 全国注册商业保理企业及分公司 | 2,514 家（截至 2015 年 12 月底） |
| 2015 年新设注册 | 一份来源记载为 1,294 家（为 2014 年的 1.44 倍），另一来源记载为 1,211 家（同比 +43.3%，为 2012 年的 27.52 倍）；口径略有出入，均予保留 |
| 信用交易比例 | 超 70% |
| 2015 年商业保理融资业务量 | 超 2,000 亿元，同比增 1.5 倍；主要指标连续第三年成倍增长 |
| 融资余额 | 约 500 亿元（同比增幅约 150%） |
| 已开展业务公司 | 约 500 家，约 10% 进入成长期——近八成企业处于“沉睡”状态 |
| 进入成长期公司（年业务量 >10 亿元） | 约 50 家（占注册总数约 2%） |
| 服务的中小企业 | 约 31,500 家（按开业率 20%、500 余家开业公司推算） |
| 户均保理融资额 | 635 万元 |
| 注册资本 1 亿元以下的公司占比 | 63% |
| 规模以上工业企业应收账款 | 一份来源记载为 11.45 万亿元，另一来源记载为 11.46 万亿元（口径略有出入，均予保留） |

## 报告预测与行业挑战

- 预测“十三五”末业务规模达万亿级，约占中国保理市场三分之一。
- 同时指出行业面临政策法规空白、监管协调不足、融资渠道待拓展、人才匮乏等困难。

## 引用注意

- 注册数 ≠ 开业数，引用“27 倍”数据时须注明口径为工商注册。
- 本报告数据主要经媒体（人民网 2016 年报道）与行业协会负责人场合转述引用，属中高强度证据；后续年份报告数据应以最新版为准并保留演进脉络。（此处实体描述依据本知识库来源；报告的年度系列性属可独立核验的行业背景。）
