# 商务部等8单位（示范创建联合发文机制）

"商务部等8单位"指全国供应链创新与应用示范创建工作的联合发文主体，由以下部门（机构）组成：

| 单位 | 申报工作联系人 |
|---|---|
| 商务部（流通发展司为受理部门） | 刘杰洲、蔡少锋 |
| 工业和信息化部 | 郦水清 |
| 生态环境部 | 石峰 |
| 农业农村部 | 白玲 |
| 中国人民银行 | 陈玮 |
| 市场监管总局 | 邱丽君 |
| 金融监管总局 | 侯宝升 |
| 中国物流与采购联合会 | 彭新良 |

该联合机制先后印发了[[全国供应链创新与应用示范创建工作规范]]（商流通函〔2022〕123号）和2023年度申报通知（[[商流通函2023-577号通知]]），由商务部会同相关单位组织专家评估并按程序确定示范名单。

## 备注

- [[中国物流与采购联合会]]为8单位中唯一的行业协会，其余为政府部门/监管机构。
- 金融监管总局（国家金融监督管理总局）在本wiki [[打击非法金融活动局]]页面中亦有出现，属同一机构体系。
