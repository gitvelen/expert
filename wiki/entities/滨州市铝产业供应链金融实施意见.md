# 滨州市铝产业供应链金融实施意见

《滨州市人民政府办公室关于加快滨州市铝产业供应链金融发展的实施意见》，发文日期 **2020年9月16日**，全文十二条，是 wiki 中首个以单一垂直产业（铝）为对象的市级供应链金融政策。

## 定位

- 依据银保监办发〔2019〕155号文及中央支持民营企业改革发展意见制定
- 列入滨州"7+3"重点改革攻坚任务和政府工作报告重点工作
- 目标：解决铝产业上下游民企融资难、融资贵问题

## 核心机制

| 机制 | 内容 |
|---|---|
| "1+N"模式 | 核心企业主导、上下游链条企业参加（见 [[1+N供应链金融模式]]） |
| 名单制管理 | 涉铝规上企业纳入金融重点支持企业名单（见 [[涉铝企业名单制管理-滨州]]） |
| 线上平台 | 人民银行应收账款融资服务平台 + 滨州智慧产融综合服务平台 |
| 标准化仓单 | 依托标准化厂房改造与仓储物流企业拓展仓单融资 |
| 风险补偿 | 省级30% + 市级20%双层叠加贷款损失补偿（见 [[贷款损失风险补偿省市双层叠加-滨州]]） |
| 金融辅导 | 市县两级金融辅导体系、首贷培植、百行进万企（见 [[金融辅导员与首贷培植-山东]]） |

## 责任体系

- 牵头：市地方金融监管局
- 配合：人行滨州市中心支行、滨州银保监分局、市财政局、市税务局、滨州海关、市大数据局、市财金集团、市工业和信息化局、市发展改革委、市统计局、市科技局、市人力资源社会保障局、市教育局
- 产业支撑：市铝行业协会、魏桥国科研究院、渤海科技大学
- 保障：成立市政府分管领导任组长的工作专班，涉铝供应链金融纳入市级银行机构年度综合考核

## 证据局限

仅有政策文本，无落地成效数据；2023年后监管框架变化，时效性需跟踪（见 [[查询-滨州铝产业供应链金融实施意见落地成效与后续修订情况]]）。
