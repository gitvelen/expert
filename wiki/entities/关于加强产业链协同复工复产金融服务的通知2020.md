# 《关于加强产业链协同复工复产金融服务的通知》（2020）

## 基本信息

- 发文主体：中国银保监会办公厅
- 发布时间：2020年3月26日
- 背景：贯彻落实党中央、国务院关于统筹推进新冠肺炎疫情防控和经济社会发展工作的决策部署
- 官方全文：http://www.cbirc.gov.cn/cn/view/pages/ItemDetail.html?docId=895429&itemId=924&generaltype=1

## 六方面内容

1. **加大产业链核心企业金融支持力度**：支持核心企业通过信贷、债券等方式融资后，以适当方式减少对上下游企业的资金占用。
2. **优化产业链上下游企业金融服务**：应收账款融资、订单融资、预付款融资、存货与仓单质押融资等信贷支持方式。
3. **加强金融支持全球产业链协同发展**：稳外贸信贷投放，落实中小微企业贷款临时性延期还本付息，拓宽短期出口信用保险覆盖面。
4. **提升产业链金融服务科技水平**：线上线下结合；鼓励大中型银行、政策性银行与主要依靠互联网运营的银行合作。
5. **完善考核激励和风险控制**：差别化授信安排；明确核心企业准入标准，严格审核供应链交易背景。
6. **加大保险和担保服务支持力度**：保险机构、政策性担保机构增信；人身险保单质押贷款期限适度延长、额度提升。

## 政策定位与关联

- 是 [[银保监办发2019年155号文]] 在疫情场景下的促进性加码，交易背景真实性与核心企业准入要求一脉相承。
- 与 [[银发2020年226号文]]（2020年9月）构成"3月促进、9月规范"的监管节奏对比。
- 第三条明确落实 [[6号文-中小微企业贷款临时性延期还本付息通知2020]]。
- 与3月10日国常会"核心企业以预付款形式向上下游支付现金、降低承兑汇票保证金比例"条款直接呼应，涉及 [[应收账款票据化]] 与 [[核心企业信用传导]]。
