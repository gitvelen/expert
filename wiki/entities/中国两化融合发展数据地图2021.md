# 《中国两化融合发展数据地图（2021）》

《中国两化融合发展数据地图（2021）》是 2021 年度我国两化融合发展水平的权威数据集（经万联网 2022-11-03 转引），为评估制造业数字化、网络化、智能化进程提供年度指数口径。

## 核心数据（2021年口径）

| 指标 | 数值 |
|---|---|
| 两化融合发展指数 | 96.6（同比 +5.9%） |
| 数字化研发设计工具普及率 | 73.7% |
| 关键工序数控化率 | 53.7% |
| 经营管理数字化普及率 | 69.0% |
| 产供销集成企业比例 | 28.9%（近五年 +8.9 pct） |
| 产业链协同企业比例 | 12.3%（近五年 +5.7 pct） |

## 与后续口径的关系

工信部 2022 年二季度口径给出更高数值（关键工序数控化率 55.7%、研发工具普及率 75.1%），应理解为统计时点更新的正常演进，双口径并注（见 [[2022年两化融合指数与供应链数字化协同数据快照]]）。
