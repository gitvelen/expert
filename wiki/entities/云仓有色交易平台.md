# 云仓有色交易平台

云仓有色交易平台是 [[光谷金信]] 联合 [[九江银行]] 于 2021 年合作推出的有色金属产业数字化交易平台，集交易、仓储、物流、检测、金融服务于一体（来源：万联网 2025 年报道）。

## 产业痛点解决

针对有色金属行业熟人交易模式规模小、金属成分鉴定不规范、线下交易易纠纷、存货占用资金等痛点，通过数字化平台实现标准化交易与金融嵌入。

## 三层架构

### 基础设施层：[[仓配检一体化数字化仓储架构]]

- 仓储物流中心布局于产业聚集地，金融监管仓标准建设，高水平仓管团队运营
- 数字化手段：线上预约 → 就近自动分配工单 → 自研称重过磅系统（无人干预） → "一件一码"智能封签 → AI 无人值守 → 库位级精细化管理
- 仓配一体化：自有物流 + 三方物流合作，库到库、库到厂全程封闭式服务
- 检测：第三方权威中立检测机构战略合作，快速取样制样，"一袋一码"防拆样本袋
- 未来方向：智能货架 + 机器人 → 无人化"黑灯工厂"
- 结合物联网与区块链，货物入库到出库全程可追溯、可验证

### 交易层：线上挂牌现货交易

- 卖家挂牌库内经检测现货，买家挂采购需求，支持询价报价与匿名成交，打破"熟人圈子交易"潜规则
- 交易产品准入：专业团队产业链调研，挑选流通性好、有统一规格标准的产品
- CFCA 数字签名电子合约：保障真实性与不可篡改性
- 账户验资功能：保障成交意愿，降低恶意竞拍
- 支付方式：银行账户直接支付 / 金融机构授信支付
- 资金结算：第三方金融机构管理，结算完成后实时货权变更
- 金融产品：订单融资（金融机构配资尾款采购库内现货）、预付类金融产品（委托平台销售至下游核心企业）

### 金融层：[[资产池风险管理策略]]与"货的银行"

- **产业金融统一平台**：打破仓储、物流、检测、交易数据割裂，实时采集行情、动态评估抵押货值，为金融机构提供贷后管理抓手
- **四流合一**：商流、物流、资金流、信息流统一整合，为金融机构创造安全可控可信融资条件
- **资产池风控**：客户统一调配在库押品与在贷余额比例，水位控制线内"钱货转换"，替代单笔抵押模式；详见 [[存货资产池风险管理模式-2025云仓有色口径]]
- **货值管理**：每日采价 + 货值管理算法实时更新资产价值，银企互联产融接口
- **风控分层**：
  - 贷前贷中：合同数据 + 单据信息 → 业务逻辑核查（上下游合同对比、运输凭证核实、质与量验收核验） → 精准匹配资金流与合同流 → 定向支付 → 资金闭环（杜绝资金挪用）
  - 贷后：企业基础信息与交易数据实时/定期更新 + 多维预警（工商登记、履约记录、信用表现、交易行为异常检测）

## 安全保障

- 物联网 + 区块链：数据安全性与真实性
- 系统直对接地磅系统 + 加密技术防篡改：在库货物重量精准采集与实时监控
- 视频监控 + 物联网设备：出入库关键节点 24 小时不间断记录人/车/货信息
- 异常自动预警 + 任务分配跟进
- 交易账户金额由金融机构结算支付，验货验资双重保障

## 商业模式：[[全产业链服务模式-云仓有色口径]]

单点服务 → 综合服务 → 全产业链服务，沿产业链向上下游延伸综合服务（采购分销、库到厂全程物流、库存管理、供应链金融、委托加工、信息咨询等）

## 发展脉络与运营数据

详见 [[云仓有色平台运营数据快照-2025口径]]

- **首个切入点**：江西省赣州市钨和稀土产业（2021–2023）
- **支持品种**：钨、稀土、锂、钴、铟、锗等 20+ 种有色金属
- **服务区域**：已扩展至江西、云南、广东、内蒙古等主要有色金属工业中心区域
- **服务客户**：数百家（2025 年企业自报口径）
