# 中国原油期货（SC合约）

中国原油期货（交易代码 SC）于2018年3月26日在[[entities/上海国际能源交易中心ine|上海国际能源交易中心]]挂牌，是我国第一个允许境外投资者参与交易的商品期货，并为铁矿石等品种国际化积累经验。

## 合约细则

| 项目 | 内容 |
|---|---|
| 交易标的 | 中质含硫原油（见 [[中质含硫原油差异化定位]]） |
| 交易单位 | 1000桶/手 |
| 交易保证金 | 合约价值的 7% |
| 涨跌停板 | 5%（首个交易日 10%） |
| 适当性门槛 | 个人 50万元；机构 100万元（须有交易经验与风险承受能力） |
| 最后交易日 | 合约月份前一月最后交易日 |
| 交割期 | 最后交易日后连续五个工作日（仓单交割） |
| 仓储费 | 0.2元/桶·天 |
| 交割方式 | 实物交割 + 保税交割 |

## 挂牌合约与基准价（2018-03-26）
- 挂牌合约：SC1809、SC1810、SC1811、SC1812、SC1901、SC1902、SC1903、SC1906、SC1909、SC1912、SC2003、SC2006、SC2009、SC2012、SC2103
- SC1809–SC1903：416元/桶；SC1906–SC2003：388元/桶；SC2006–SC2103：375元/桶（三段平行式结构）

## 可交割油种（装运港）
- 阿联酋迪拜：法特港
- 阿联酋上扎库姆：兹尔库岛
- 阿曼：费赫勒港
- 卡塔尔海洋油：哈卢尔岛
- 也门马西拉：席赫尔
- 伊拉克巴士拉轻油：巴士拉油码头或单点系泊浮筒
- 中国胜利原油：中国石化胜利油田分公司东营原油库

## 定价属性
SC 锚定中东交割油种的人民币到岸价格，隐含人民币汇率敞口（见 [[sc隐含人民币汇率风险]]）。机构测算理论价约 434–441.5元/桶，高于挂牌基准价 416元/桶。
